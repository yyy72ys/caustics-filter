## 0. 位置づけ

- cf-0075 は解析側の再計算のみを行った。同じ実現モード集合（同じ k、同じ |H0|²）に対し、ω を量子化値 ω_q と分散関係の真値 ω_true で差し替えて ν を出し直し、「量子化で説明できる分はギャップの 17.1%、残存比 0.829」という結論を得た。
- しかし cf-0075 §8.2 が明記するとおり、ν_true は「そのモード集合を連続 ω で積分した値」であって「実現する場の ν」ではない。場を作り直せば、時間発展・位相・折り返しの効果が入る。プローブ ν は場そのものが 8 s 周期で構成されているため、場を作り直さない限り分離できない（cf-0075 §7）。
- 本実験は、生成器の**コピー**側で ω 量子化を外して場そのものを再生成し、実際の場の ν を測る。紙の上の 17.1% が場でも成り立つかどうかが、本実験の唯一の問いである。
- 大原則の確認: 真の分散関係 ω(k) が物理であり、量子化は 8 s ループを閉じるためだけの都合である。量子化を外すことは「それっぽくする」調整ではなく、物理に戻す操作である。逆に、本実験の結果をもって量子化側を正当化することはしない。

## 1. 問いと2つの競合する結末（判定基準は事前に数値で固定する）

### 1.1 問い

量子化を外して再生成した実際の場では、P5-CLEAR と SWELL-1 の ν ギャップはどうなるか。紙の再計算（cf-0075）が予測する「ギャップは 0.0680 から 0.0564 へ、残存比 0.829」どおりに場でも残るのか、それとも場では別の結果になるのか。

### 1.2 基準数値（cf-0075 の実測、全て5シード平均、seed 1 = 本番シード）

| 量 | P5-CLEAR | SWELL-1 | ギャップ（SWELL − P5） |
| --- | --- | --- | --- |
| ν_q（量子化 ω、モード集合） | 0.3272 | 0.3952 | 0.0680 |
| ν_true（真の ω、モード集合の紙再計算） | 0.3254 | 0.3817 | 0.0564 |
| ν_probe（量子化場のプローブ実測、cf-0067 保存 npz） | 0.2848 | 0.3755 | 0.0906 |

- 説明率（紙）= (0.0680 − 0.0564) / 0.0680 = 17.1%。残存比（紙）= 0.0564 / 0.0680 = 0.829（シード別 0.763–0.888）。
- 本番シード単独では gap_true = 0.0505（残存比 0.817）。連続スペクトルの解析ギャップ（cf-0077）も 0.0505 で、モード集合の真値ギャップ 0.0564 とは別経路で近い値に着いている。本設計では 0.0564 を主たる予測値、0.0505 を下側の参照値とする（§1.3 の判定帯はこの2値から作る）。

### 1.3 判定量と判定基準（測定前に固定する。測定後に動かさない）

主判定量は2つで、どちらも「同じ推定量・同じシード対」で取る。

- R_mode: 再生成したモード集合での残存比 = gap（非量子化コピーの ν_mode）/ gap（量子化側の ν_mode = 0.0680）。これは内部ゲートでもある（§4.2）。
- R_field: 実際の場のプローブ ν での残存比 = gap_probe（非量子化場）/ gap_probe（量子化場 = 0.0906）。分母は cf-0067 保存値を使い、本実験内でも量子化場のプローブ ν を同一手順で再測して分母の再現を確認する（§4.3）。

結末は次の2つが競合する。

- 結末 A「量子化は残りのギャップを（場でも）説明しない＝紙の結論が場で確認される」: R_field が 0.80 以上、かつ gap_probe（非量子化場）が予測帯 [0.0505, 0.0564] を中心とする許容帯の中にある。許容帯は cf-0077 の前例（基準の25%）に倣い、0.0564 ± 0.0141 = [0.0423, 0.0705] とする。この帯は 0.0505 を含む。
- 結末 B「量子化が残りのギャップを場では説明する＝紙の結論は場では成り立たない」: R_field が 0.50 以下。すなわち場のギャップが量子化場の半分以下に潰れる（gap_probe で 0.0453 以下）。
- 中間（0.50 < R_field < 0.80）または予測帯の外: 決着をつけない。数値そのものを報告し、§6 の「どちらでもない」枝に従う。cf-0075 §5 の教訓どおり、しきい値の上下ではなく数値を主張の中心に置く。
- シード単独での判定は禁止する。cf-0075 §5.1 のとおりシード別の残存比は 0.763–0.888 と 0.8 の線をまたぐため、判定は5シード平均で行い、シード別の値を必ず併記する。

## 2. 変更点（コピー側の正確な変更箇所）

### 2.1 対象ファイルと変更行

対象は生成器 `v10_state.py`（本番は PC の `D:\yohey2026\dsh\muse\caustics-filter\offline\v10_state.py`、凍結写しは `~/workspace/caustics-freeze-staging/repo/offline/v10_state.py`）の**コピーのみ**。本番ファイルは変更しない（§5）。

量子化は `_realise` メソッド内の次の3行で実装されている（凍結写しの行番号）。

    206: om = P8.dispersion_omega(np.maximum(k, 1e-12), self.depth)
    207: n = np.maximum(1.0, np.floor(om / OMEGA0 + 0.5))
    208: casc.omega_q = (n * OMEGA0).astype(np.float32)

コピー側の変更は1箇所だけである。

- 206行は無変更。om が分散関係の真値 ω_true である。
- 207行を削除する（量子化の丸めそのもの。最近接丸め＋下限 n ≥ 1）。
- 208行を `casc.omega_q = om.astype(np.float32)` に置き換える。属性名 `omega_q` は下流の読み手（`_cascade_fields` の時間発展、`_quantisation_node`、記録系）が全てこの属性を読むため、コピー内では名前を変えず中身だけを真値にする。コピーの冒頭 docstring には「この写しでは omega_q 属性に真の ω が入る（量子化なし）」と明記し、量子化前提の記述（凍結写し冒頭の cascade 説明・§4 TIME の記述）を実験用に書き換える。

### 2.2 真の分散関係（毛管項を含むコードの式を使う）

ω_true は `v8_physics.py` の `dispersion_omega`（凍結写し123–128行）そのものである。

    ω_true(k) = sqrt( (g·k + (σ/ρ)·k³) · tanh(k·h) )
    g = 9.81 m/s²（v8_physics.py:62）
    σ/ρ = 7.28e-5 m³/s²（同65行、SIGMA_SURF = 0.0728 N/m、RHO_W = 1000 kg/m³）
    h = 深さ（両条件とも 4.0 m）

- 毛管項 (σ/ρ)·k³ は必須である。cf-0075 §2 の実測では、k = 300 rad/m で毛管/重力比 0.668、k = 1000 rad/m で 7.421 に達し、重力のみの式では P5 の ν が大きく下がってギャップがむしろ広がる（説明率 −61.2%）。「真値」の定義を重力のみに取り替えることは本実験では行わない。
- 量子化の刻み Ω0 = 2π/8 = 0.7854 rad/s（v8_physics.py:71）は、コピー側ではもう使わない。ただし記録・照合のために定数自体は残す。
- 下限 n ≥ 1 の削除も変更の一部である。ω_true < Ω0 のモード（例: k = 0.1 rad/m で ω_true = 0.611、SWELL の最低波数モード k = 0.082 もこの側）は、これまで ω_q = Ω0 に切り上げられていた。コピーでは真値のまま進める。P5 ではこの帯の m0 シェアは 1e-10 級で無視できるが、SWELL は低波数帯が m0 の大半を占めるため、この削除が SWELL 側の結果に効きうることを明記する。

### 2.3 変更しない読み手

- `_cascade_fields`（凍結写し413行付近）は `casc.omega_q` を読み `exp(i·ω·t)` で場を進める。コピーでは自動的に真の ω で場が進む。これが本実験の本丸であり、読み手側の変更は不要である。
- `_quantisation_node` は量子化誤差の自己点検になる。コピーでは量子化誤差が float32 の丸め水準（相対 1e-7 級）まで落ちるはずであり、これをコピーの正しさのゲートとして使う（§4.2）。
- 本番の記録ビルダ（`run_v4_1_11.py` の n_idx 復元など、omega_q から量子化インデックスを逆算する系）は実験では使わない。実験の読み出しは実験専用スクリプトが行う（§9）。

## 7. コスト見積もり

実測アンカーは cf-0075 の stage2 である。モード集合の再計算（状態構築＋読み出し）10ユニット（2条件×5シード）の合計 wall は約126 s、すなわち状態構築は1ユニット約13 s（N = 2048）。

- 段0＋段1: 状態構築は seed 1 の2ユニット＋ゲート確認。数分級。
- 段2のモード集合分: 10ユニットで約2–3分（cf-0075 と同規模）。
- 段2の場の再生成が本実験の主コストである。`fields_at` は時刻ごとに cascade あたり5本の 2048² IFFT を回すため、フルフレームを多数時刻で取る設計にすると時間級に膨らむ。したがって本実験はフルフレームではなくプローブ点の時系列で取る（cf-0067 のプローブ方式の再利用）。それでも非量子化場は記録長が延びる分（§4.3 の T_obs ≥ 32 s）だけ量子化側の再測より重くなる。
- 見積もり: プローブ方式で seed 1 の2条件を先行実施（パイロット）し、wall を実測してから残り8ユニットへ外挿する。パイロット込みの総量は、プローブ方式が cf-0067 と同規模に収まれば30–60分級、収まらなければパイロットの実測をもって再見積もりし、ブリーフに記録してから本走に入る。パイロットなしに10ユニット一括で走らせない。
- メモリ: 2048² の complex128 一時配列が複数枚重なる（1枚約67 MB）。両条件とも格子は N = 2048 で共通であり、パッチの大きさ（4.8 m / 76.8 m）はコストを変えない。

- 【リスク R3】折り返し: プローブ帯の上限（75.4 rad/s）より上のモードは折り返して消えるか混入する。|H0|² シェアは P5 で約0.1%と小さいが、SWELL と P5 で帯の内訳が違うため、ギャップへの影響が完全に対称とは限らない。両腕共通の条件として記録し、必要なら帯域分解で内訳を示す。
- 【リスク R4】コピーの混入: コピーを本番の import 経路に置くと、本番実行が誤ってコピーを読む危険がある。配置は本番 workdir の外とし、段0/段3のハッシュ証明で混入がなかったことを示す。
- 【リスク R5】属性名の意味の反転: コピーでは `omega_q` という名前に真の ω が入る。実験スクリプト以外がこの属性を「量子化済み」として読むと誤読になる。実験出力の numbers には `omega_semantics: true_dispersion_unquantised` のような明示フィールドを必須とし、レポートにも同じ明記をする。
- 【リスク R6】しきい値近傍: 紙の残存比 0.829 は 0.8 の線から 0.029 しか離れていない。場の R_field も線の近傍に着く可能性が高く、その場合は §1.3 のとおり「決着なし」ではなく数値の報告が成果になる。線の上下だけで結末を語らない。
- 【リスク R7】8 s ループの喪失の下流影響: 非量子化場は 8 s で戻らない。実験出力をループ前提の処理に流すと無言で壊れる。§5 の明記に加え、実験出力のメタデータにも非ループであることを機械可読な形で残す。
- 【未決 R8】float32 保存: 真の ω を float32 で保存する丸め（相対 1e-7 級）は量子化刻み（低 n 帯で相対 10% 級）に対して無視できる中立な数値として扱う。ただし段1のゲート（§4.2）で ν_mode が紙の値と float32 水準で一致することを確認するまでは、この扱いは仮置きである。
