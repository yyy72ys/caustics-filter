## 前提（メイン側のスクラッチ実測で確定）
- FIX-13 で網は本物になったが、表示が「グラフィックに均一に眩しい」: バッファ実平均が約2.5（正規化定数は1.0前提）でピークが飽和し、フィラメントの明暗差が潰れる。分散フリンジも全線に強く出過ぎる。
- スクラッチ実験で以下2点が有効と確認済み:
  - Cn へのソフトショルダー `Cn' = Cn·1.6/(1+0.6·Cn)` で、セルが持ち上がりピークが滑らかに圧縮され、場が自然な質感になる。

## 変更要件（shader.js 合成 FRAG のみ）
1. **ソフトショルダー**: 前方分岐で CnR/CnG/CnB を avg で割った直後に、各チャンネルへ `Cn = Cn * 1.6 / (1.0 + 0.6 * Cn)` を適用する。後方（フォールバック）分岐には適用しない。
2. **分散シフト半減**: `csh = cdl * 8.0 + ...` の 8.0 → **4.0**。
3. **グリッター格子の乱し**（セクション5のグリッター）: cellUV の格子フレームを固定角 0.615 rad 回転させ、行ごとにハッシュ由来の横オフセットを加えて、軸平行な点線列を崩す。グリッターの強度・スケール・サブフレーム時間index（8秒ループ性）は現行を維持する。回転はグリッターのセル判定とハッシュ入力にのみ適用し、spark の法線計算（ndh）自体は変えない。
