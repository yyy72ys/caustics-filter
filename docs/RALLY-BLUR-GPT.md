# 敵対的査読：初期スタックの「波が画像をぼかす」現象

## 総合判定

最有力は A（ワープ再サンプリング）と B（明示ローパス）の複合。

ただし、両者は同じ種類のぼけではない。

- A：基底画像の空間周波数を変化させる。局所的な圧縮・拡張、サンプリング、エイリアシングが関与する。
- B：コースティクス場に明示的な低域通過処理を施す。これは直接的なピーク・エッジの鈍化。
- C：画像のぼけというより、光の空間的な広がりとコントラスト低下。
- D：コースティクスの鋭さを失わせるが、底画像そのものをぼかす直接原因ではない。
- E：v2期の密度推定を使った場合に限る追加の平滑化要因。

重要なのは、観察された「ぼやけ」を単一の現象として扱わないことだ。画像の解像感、コースティクスのピーク、光学的なハローは別々に評価しなければならない。

## 1. 候補別判定

| 候補 | 判定 | 確信度 |
|---|---|---|
| A. ワープ再サンプリング | 主因 | 高 |
| B. Blow σ=3 px | 主因 | 非常に高い（コースティクス側） |
| C. 散乱ハロー | 副因 | 高 |
| D. マスター格子解像度 | 副因 | 高 |
| E. 密度推定カーネル | 副因（v2期限定） | 高 |

以下、個別に攻撃する。

### A. ワープ再サンプリング

根拠

底画像を変位場でサンプリングする方式は、波面による像の変形を表現できる。しかし、これをそのまま「物理的な像形成」と同一視するのは危険。

出力画像を I_out(x) = I_base(x + u(x)) とすると、局所的な座標変換のヤコビアンは J = I + ∇u となる。

この変換は場所によって画像の空間周波数を変える。

特に、局所的な圧縮方向では高周波成分が出力側で高密度になり、拡張方向では低密度になる。

ただし、ここで重要な反論がある。

変位量13.25 pxや23 pxという数値だけでは、ぼけの強さは説明できない。

一定変位なら、画像は移動するだけでぼけない。

問題になるのは変位の空間微分、つまり局所的な変形率と、その変形によって生じるサンプリング不足である。

さらに、双線形補間を使っているなら、補間カーネル自体が高周波を減衰させる。

したがって、Aを主因とするなら「変位が大きいから」ではなく、次の組み合わせが原因になる。

- 局所的な変形勾配
- 再標本化の補間フィルター
- 出力解像度に対する局所的な周波数不足
- エイリアシング抑制処理

判定を覆す測定方法

同じ変位場、同じ入力画像で、再標本化方式だけを切り替える。

1. Nearest-neighbor
2. Bilinear
3. Bicubic
4. EWAなどの異方性フィルタリング
5. 十分な高解像度でのオーバーサンプリング後の縮小

局所MTFと高周波エネルギーを比較する。

もし再標本化方式を変えてもぼけがほとんど変わらず、変位場を恒等変換にしても同じぼけが残るなら、Aを主因とする判定は崩れる。

### B. 合成の明示ローパス（Blow σ=3 px）

主因

根拠

これは最も直接的な証拠がある。

コースティクス場にガウスぼかしが明示的に適用されている。

ガウスフィルターの周波数応答は H(f) = exp(-2π²σ²f²) である。

σ=3 pxなら、標準偏差3 pxの平滑化が確実に入る。

例えば、振幅が半分になる周波数は f_{1/2} ≈ 0.0625 cycles/pixel。

つまり、およそ16 px周期より細かい構造では強い減衰が起きる。

これは単なる推測ではなく、フィルターの数学的な帰結だ。

ただし、Bについても反論がある。

Bがぼかすのは、適用対象であるコースティクス場であって、必ずしも底画像ではない。

「水底の写真がぼやける」という観察と「コースティクスの網目がぼやける」という観察を混同してはならない。

Blowがコースティクス成分だけに作用するなら、底画像のMTFは直接変化しない。

判定を覆す測定方法

Blowだけを完全に無効化したA/Bレンダリング。

- 同一フレーム
- 同一の入力場
- 同一の合成条件
- σ=0 と σ=3 px

コースティクスのエッジ幅、ピーク値、空間周波数スペクトルを比較する。

σ=0でも同等のエッジ幅・ピーク減衰が残るなら、Bをコースティクスの主因とする判定は崩れる。

### C. 散乱ハロー（FF-CDF rms 224 px）

副因

根拠

rms半径223.68 px、ハローの92%捕捉という数値は無視できない。

これは画像上の広い範囲に光を分配する処理であり、局所コントラストを下げる可能性がある。

澄んだ水プリセットでも μ=3.37という点も疑わしい。

ただし、ここには重大な論理的問題がある。

ハローの半径が大きいことは、局所像がぼけることを直接意味しない。

散乱カーネルが正規化されていても、広い範囲に光を分配すれば、局所的なコントラストが落ちることはある。

しかし、これは画像全体の解像度低下とは異なる。

例えば、暗い領域と明るい領域の間に広い光の裾ができる場合、輪郭がぼやけたように見えるが、元の画像の細部が同じカーネルで畳み込まれたとは限らない。

さらに、実装上の重要な確認事項がある。

- FF-CDFが何を入力としているか
- ハローがコースティクス光だけに適用されるのか
- 底画像全体に適用されるのか
- 直達成分と散乱成分のエネルギー比率
- カーネルが空間的に正規化されているか

この情報なしに、224 pxを画像ぼけの半径と呼ぶのは誤り。

判定を覆す測定方法

散乱を完全に無効化したレンダリングと、通常レンダリングの比較。

底画像の局所MTF、Michelson contrast、低周波ハローのエネルギーを別々に計測する。

散乱を切っても局所コントラストとハローが変化しないなら、副因という判定も崩れる。

逆に、散乱を切ると画像のぼけがほぼ消えるなら、Cは主因に昇格する。

### D. マスター格子の解像度

副因

根拠

2048²格子上で変位が約40セル分あるという記録は、明確な数値的問題を示している。

ただし、ここでも表現を正確にする必要がある。

「40セル分移動するからピークが鈍る」という説明は、それだけでは成立しない。

格子上の移動距離と、ピークの解像度は別の量だからだ。

問題は、移動する折り目を格子に堆積するときに、

- 折り目の位置が格子セル間を移動する
- 堆積が離散化される
- 細い構造が複数セルに分配される
- ピーク位置とピーク値が格子位相に依存する
- 補間・再構成でさらに平滑化される

といった現象が生じること。

40セルという移動量が問題なのではなく、折り目の空間幅に対して格子が十分細かいかが問題である。

例えば、折り目幅が2セル未満なら、ピークは格子位相によって大きく変化する可能性がある。

一方、折り目幅が100セルなら、40セルの移動そのものは致命的とは限らない。

反論

現在の面積保存メッシュ堆積との比較は、D単独の検証にはなっていない。

現在の方式では、

- 堆積方法
- 保存量
- カーネルの有無
- 格子への投影方法

が同時に変わっている。

したがって、現在の鋭い網目をもって「初期スタックのぼけは格子解像度が原因ではなかった」と結論づけることはできない。

判定を覆す測定方法

格子解像度を2048²、4096²、8192²と変え、同一の連続折り目場を同じ物理スケールで堆積する。

ピーク値、FWHM、線幅、格子位相依存性を測定する。

解像度を上げてもピーク幅・ピーク値がほとんど改善しないなら、Dの寄与は小さい。

### E. フォトン密度推定のカーネル

副因・v2限定

根拠

v2期の400万本/フレームのフォトンマッピングは、密度推定によって連続的な光分布を再構成する方式。

通常のフォトン密度推定は、 Ê(x) = 1/(π r²) Σ_{i=1}^{N} Φ_i K_r(x - x_i) のようなカーネル集約を使う。

カーネル半径 r が有限なら、空間的なピークは平滑化される。

したがって、v2のコースティクスがぼやける原因としては十分に成立する。

しかし、400万本というフォトン数は平滑化の強さを決めない。

重要なのは、

- カーネル半径
- カーネル形状
- 局所フォトン密度
- 半径の適応性
- 推定バイアスと分散のトレードオフ

である。

反論

Eは初期スタック全体の説明には使えない。

v2期のみの方式である以上、v10〜v20系の現象を説明する主因に持ち上げることは時系列的に誤り。

また、フォトン数を増やすだけではカーネルバイアスは消えない。

判定を覆す測定方法

同一フォトン集合に対してカーネル半径だけを変化させる。

半径を縮小し、フォトン数を固定したままピーク値・FWHM・ノイズ分散を測る。

半径を縮小してもピーク幅が変わらないなら、Eの寄与は小さい。

## 2. 実在の水中で波面が像をぼかすことは物理的にあり得るか

ここは3つに分けないと誤った結論になる。

### ① 瞬時像：あり得る。ただし意味を限定する必要がある

物理的に成立

水面の波は、屈折率境界の法線方向を変化させる。

その結果、底面からの光線は異なる方向に屈折する。

幾何光学的には、 d2 = η d1 + (η cosθ1 - cosθ2) n というSnellの法則に従う。

ここで水面法線 n が場所によって変化する。

重要なのは、瞬時像でも像の局所的な解像度が低下し得ること。

例えば、

- 光線写像が局所的に圧縮される
- 光線写像が拡張される
- 複数の光線が同じ観測位置に集まる
- 有限開口・有限画素で複数の光線が平均化される
- 光学的な焦点ぼけが生じる

といった現象がある。

ただし、

理想的な幾何光学で、波面が一枚の静止した滑らかな屈折面であるなら、光線の写像は基本的には像を変形する。必ずしもぼかすわけではない。

光線写像が一対一で、検出器の開口も十分小さければ、局所的な像は鋭いままでもよい。

したがって、「波面があるから瞬時像がぼける」という一般化は間違い。

### ② 時間積分：明確にあり得る

物理的に成立

こちらは特に重要。

実際のカメラは露光時間中の光を積分する。

I_exposure(x) = 1/T ∫_0^T I(x, t) dt

水面が時間とともに変化するなら、瞬時像が鋭くても、その異なる像を重ね合わせた露光像はぼけ得る。

例えば、ある瞬間に文字の輪郭が右へ変形し、次の瞬間には左へ変形する場合、時間積分では輪郭が広がる。

これは物理的な時間平均であり、人工的なガウスぼかしではない。

ただし、重要な反論がある。

時間積分によるぼけは、露光時間と水面変動の時間スケールに依存する。

露光時間が十分短ければ、時間積分によるぼけは小さい。

また、時間変動があっても、平均像が必ず単純なガウスぼけになるわけではない。

変位の分布、時間相関、非線形な屈折写像によって結果は異なる。

### ③ 散乱：あり得る。ただし波面による屈折とは別の機構

物理的に成立

水中の散乱は、光を元の進行方向から逸らす。

散乱光が検出器に入ることで、

- 直達光の減少
- 局所コントラストの低下
- 広い空間的ハロー
- ベール状の明るさ
- 空間周波数の減衰

が起こる。

これは物理的なぼけの原因になる。

ただし、散乱の影響は水の透明度、粒子濃度、観測距離、波長、視線方向などに依存する。

ここで今回の実装に対して強く指摘したいことがある。

澄んだ水プリセットで μ=3.37、rms半径224 pxという設定を使っているなら、その設定が実在の澄んだ水の散乱を適切に表現しているか、独立に検証する必要がある。

プリセット名が「澄んだ水」であることは物理的妥当性の証拠ではない。

## 3. 最も重要な反論：現在の鋭い網目は物理的正しさの証明ではない

ここが今回の査読で最も注意すべき点。

現在の面積保存メッシュ堆積は、

- 三角形面積の厳密な配分
- カーネルなし
- 折り目の鋭い堆積

という性質を持つ。

しかし、面積保存はエネルギー保存や放射輝度の保存と同義ではない。

また、カーネルを使わないことも物理的な正しさを保証しない。

現実の水面では、屈折した光線が有限の観測開口、画素、露光時間、散乱媒体を通して観測される。

その結果、鋭い幾何学的コースティクスが最終画像では平滑化されることもある。

したがって、

初期実装はぼけていた。現在の実装は鋭い。だから現在の方が物理的に正しい。

という推論は成立しない。

両方とも別の物理過程を欠落させている可能性がある。

特に、現在の実装が瞬時の幾何学的な光線集中を計算しているなら、それを実際のカメラ画像と直接比較すること自が測定対象の不一致になる。

## 4. 最終裁定と優先検証順序

| 順位 | 要因 | 何をぼかすか | 検証優先度 |
|---|---|---|---|
| 1 | A | 底画像の局所解像度 | 最優先 |
| 2 | B | コースティクスのピーク・エッジ | 最優先 |
| 3 | C | 局所コントラスト・広域ハロー | 高 |
| 4 | D | コースティクスの空間解像度 | 高 |
| 5 | E | v2期のコースティクス密度場 | v2限定 |

ただし、AとBの順位は対象によって逆転する。

- 底画像の写真がぼやけたならAを最優先。
- コースティクス網がぼやけたならBを最優先。
- 画面全体が白っぽく、コントラストが落ちたならCを最優先。

### 最後に、私なら最初に実施する実験

1つの固定フレームから、以下の4枚を出す。

実験マトリクス

| 出力 | ワープ | Blow | 散乱 |
|---|---|---|---|
| R0 | OFF | OFF | OFF |
| R1 | ON | OFF | OFF |
| R2 | OFF | ON | OFF |
| R3 | ON | ON | ON |

それぞれについて、底画像とコースティクスを別々に保存する。

この4枚だけでは相互作用を完全には分離できないが、最初の切り分けとしては有効。

さらに厳密にするなら、A・B・Cの2³完全要因実験を行う。

測定項目は次の4つ。

1. 底画像の局所MTF50
2. コースティクスのピーク値とFWHM
3. 局所コントラスト
4. 低周波ハローのエネルギー比

最終結論：初期スタックのぼけを「水面波による自然な光学現象」と説明するのは、現状の証拠では不適切。

AとBという実装上の平滑化機構が既に確認されている。Cも強い疑いがある。DとEもそれぞれ異なる段階でピークを鈍らせる。

したがって、初期映像のぼけを物理現象として採用する前に、少なくともA・B・Cを独立に除去した対照実験が必要である。
