## 補完回答（verbatim、全文）

1. 冒頭の判定文の欠落部分

2. K4 — 成立条件
成立条件
• Wilton共鳴について、入力上限 k_max=120 rad/m から 2k_max=240 rad/m < 260 rad/m となることは、対称な最大和波数が260 rad/mに達しないという限定的な構造確認として成立します。ただし、これだけでは非対称な入力ペアの共鳴を排除できません。したがって、各ペアについて和・差の (k±, ω±) と毛管重力分散関係を照合する検査が必要です。
• 共鳴判定の相対離調度は、分母を max(|ω±|, ω(k±)) とすることで、ω₋→0 近傍のゼロ除算を回避できます。閾値0.05は物理定数ではなく設計上の判定値です。これを採用するなら、閾値超過ペアの数と、その寄与する m₂, m₄ を別途報告し、通常のQTF計算から分離する必要があります。
• k>100 rad/m の実測エネルギー比0.51%は、P5のseed 1・単一実現に基づく値です。したがって「全seed・全実現で高波数エネルギーが0.51%以下」と一般化してはいけません。現状では、当該測定条件での参考値として扱い、seed間の変動を別途確認する必要があります。
• 出力側では、入力を k≤100 rad/m に制限しても、和波数は最大240 rad/mまで達し得ます。毛管項比は k=120 で10.7%、k=200 で29.7%、k=240 で42.7%です。よって、出力側の高波数成分を純重力成分と呼んではいけません。QTF帯域と全帯域の m₄ を分け、除外帯域の寄与を定量報告することが条件です。除外帯域の m₄ 寄与が1%を超える場合、全帯域 m₄ の合格を主張できません。
• k>100 の線形エネルギー比が5%を超えた場合は、現行の帯域制限を前提とした判定を不成立とします。0.51%という単一実現の値だけで、この条件を恒常的に満たすとは判断できません。
• 毛管重力QTFが未導出である以上、phase 1の主張は「重力帯域に限定した純重力QTFによる近似」に留めます。U-3の経路A（毛管項を動力学的境界条件に含めたQTFの導出）はphase 2開始前に必要です。期限までに着手・完了しなければ phase 2へ進めません。
3. K5 — G3/G7、加速度、低周波 η₂⁻、τ_int
判定：条件付き成立
最強の反論
R5は、a_z < −0.5g の判定対象を重力帯域 k≤100 rad/m に制限し、低周波 η₂⁻ の定義から静的成分を分離した点で、R4までの曖昧さをかなり減らしています。しかし、これらは物理的な普遍閾値を確立したものではありません。特に0.5gは純重力Stokes波の波頂加速度に基づく診断閾値であり、毛管重力成分を含む全帯域の加速度にそのまま適用できません。また、谷反転バンプ率1%も事前登録された設計上の判定値であって、物理法則から導かれた限界値ではありません。さらに、m₄ > 1.5 m₄,lin となる帯域を含めて全帯域の異常・非線形性を評価するなら、QTF入力帯域外の毛管汚染を無視できません。入力を k≤100 に制限したQTFの結果だけで、その帯域の高次統計まで説明したとは言えません。
成立条件
• a_z < −0.5g は、η₁+η₂ から重力帯域 k≤100 rad/m の成分を抽出した後の加速度として定義します。全帯域の生の加速度に閾値を適用してはいけません。
• 0.5gは純重力Stokes波の波頂加速度を根拠とする診断閾値として扱い、1%の谷反転バンプ率は事前登録された設計上の判定値として扱います。両者を物理的な普遍定数として記述してはいけません。
• m₄ > 1.5 m₄,lin の判定は、対象帯域と比較対象となる線形 m₄ の計算範囲を固定して行います。QTF帯域外の寄与を含む全帯域の m₄ と、QTF帯域内の m₄ を混同してはいけません。
• 低周波 η₂⁻ は f < 0.5 f_p と定義します。P5では f_p=1.875 Hz なので、カットオフは 0.9375 Hz です。この定義をseedごとに変更せず、5 seedの平均として報告します。
• 自己相関 R(τ) は、η₂⁻ から時間平均の静的成分 ⟨η₂⁻⟩_t を差し引いた変動成分に対して計算します。静的成分は別に評価し、分散比 ≤0.05 を確認します。静的成分を残したまま自己相関を計算して、長い相関時間があると解釈してはいけません。
• τ_int の積分範囲は [0,4s] に固定し、打ち切り規則も事前に明記します。積分値が4秒の端点に依存する場合の扱いを曖昧にしてはいけません。
• 8秒・16秒の計算結果が4秒の結果と一致しても、それは指定した打ち切り範囲での数値的一致を示すだけです。長周期成分を十分に捕捉したことや、積分範囲の物理的十分性を証明するものではありません。
失敗条件
• a_z < −0.5g の判定に全帯域成分を混ぜる、または重力帯域のフィルタ仕様が固定されていない。
• 1%を物理的に確立された閾値として扱う、あるいは結果を見た後に閾値を変更する。
• m₄ > 1.5 m₄,lin の対象帯域や線形基準の計算範囲がseed間で異なる。
• 低周波カットオフを f < 0.5 f_p 以外に変更する、5 seed平均を行わない、またはseed間の失敗を平均で隠す。
• R(τ) に静的平均成分を残す、静的成分の分散比を別途確認しない、あるいは積分・打ち切り規則を事後変更する。
• 8秒・16秒との一致を根拠に、長周期成分まで十分に評価できたと主張する。
