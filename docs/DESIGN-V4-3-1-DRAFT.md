## 0. 第3段が外す仮定（現行スタックの均一性）

現行の水中光学（v3.6 の a(λ)/b(λ) 分離＋v16 の FF 位相関数・FF-CDF ハロ核）は、その級では実測検証済みだが、次の均一性を焼き込んでいる。第3段の仕事はこの5つを外すことであり、それ以外（位相関数の形、堆積の面積保存、太陽円盤求積）は再提案しない。

- H1: 屈折率 n が場面ごとに定数 → 体積内で光線が曲がらない
- H2: a, b が空間定数 → 光学的深さが光線ごとに計算できない
- H3: ハロ核が空間一様 → 濁りの局所差がボケの局所差にならない
- H4: 経路放射（視線内への散乱光＝ベール／水中で見える光の筋）が無い
- H5: 単一散乱のみ（現行場面 cL≈0.2 では妥当だが、cL→1+ では未測定の仮定）

## 1. 分解案（v4-3.x）

### v4-3.1 — GRIN 輸送コア＋熱シュリーレン（淡水・池）
- **目的**: n の場を導入し、光線方程式の積分で曲がる光線を輸送に入れる。最初の場は池の底加熱プルーム（見える熱シュリーレンの本命ケース）。
- **物理の根拠**: 光線方程式 d/ds(n·dr/ds) = ∇n。n(S,T,λ) は Quan & Fry (1995) の実測適合式（400–700 nm、0–30 °C、S 0–35）。積分は RK 系（BOS/シュリーレン分野の標準実務）。場の生成は B3 裁定（対流の力学そのものは範囲外、生成物だけをパラメトライズ： プルーム位置は底アルベド／湧水入力から、間隔は水深 H 級、ΔT は表面エネルギー収支から）。
- **ラリー改訂（RALLY-V4-3-1 §2, §3）**: (i) 場の生成は「物理制約付き場生成」として明示する — プルームの形状パラメータ（幅・壁厚・希釈）は Morton–Taylor–Turner 型の浮力スケーリング（b ∝ αe·z、ΔT ∝ z^-5/3 希釈）で縛り、自由な形パラメータで信号振幅を決めない。全パラメータは画像外の入力に固定し、出所・生成モデル・有効範囲・不確かさをメタデータとして保持する。パラメータを画像の見た目で調整することは大原則違反として禁止する。(ii) n 場の補間は ∇n が不連続にならない滑らかさ（C¹ 級）を要求する（trilinear の面境界での ∇n ジャンプは偽の筋を作る）。波長帯ごとに光線を追うか、無色収差近似の誤差 bound を示す。(iii) 水面での出入り口の屈折は局所 n（T/S 依存）で行い、体積 GRIN と面屈折を分離したまま足し合わせない（3.4 に統合検証場面を置く）。
- **入出力（既存パイプラインに対して）**: 入力＝レシピ媒体部の拡張（T 場の生成パラメータ）＋第2段の底（形状とアルベド地図）。出力＝堆積 C の変位場が GRIN 分だけ変わること、画素ごとの累積偏向角マップ（検証用）。表面（第1段）と底の幾何は無変更。
- **検証**: (i) 均一 n の極限で現行スタックと一致（回帰、H は不変）。(ii) 層状 n(z) の極限で Snell の階段と一致。(iii) 一定 ∇n 場の解析解（円弧）との一致。(iv) 底加熱ケースの変位量が導出帯（0.5 m 路径で見かけ変位 1–4 mm）に入るか — これは「当てる目標」ではなく導出の検算として扱う。

### v4-3.2 — 不均一 RTE（a/b/CDOM の場＋空間可変ハロ＋経路放射）
- **目的**: H2–H4 を外す。a(x), b(x), CDOM(x) の場を持ち、光線ごとに τ=∫c ds を積分する。視線内散乱のベール項を合成に足す。
- **物理の根拠**: RTE の不均一形そのもの — 空間的に変化する散乱源項（周囲の放射輝度場と位相関数の方向積分）を扱う輸送として定義する。**ラリー改訂（RALLY-V4-3-1 §2 C4）**： 当初案の「ハロ核（FF-CDF）を局所 (τ, b/c) で評価すれば足りる」は落ちた。ハロの広がりは散乱点から対象面までのレバーアーム (L−s) に依存し、同じ総 (τ, b/c) でも濁り層の位置で変わるため、局所カーネル評価は「滑らかな単一集団場（勾配スケール ≫ 1/c かつ ≫ ハロ幅）」という適用域を明記した高速近似として残し、輸送の定義にはしない。位相関数は v16 の FF（形は実測で確定済み）を粒子状散乱の既定として維持するが、場の入力は粒子クラスを持てる構造にする： 純水分子散乱 bw(λ)（レイリー様位相関数、澄んだ場面では後方散乱の 20–60% を担いうる）を FF 粒子散乱 bp(λ) と分離する／気泡（第2段が供給する場合）は FF とは別の位相関数で受ける／粒径分布の空間変化に拡張できる。GRIN 媒質での放射輝度輸送は L/n² 不変量と光束のヤコビアンを含めて 3.1 との結合仕様で定義する（曲線光路上で係数だけを積分しない）。検証参照としてデルタトラッキング（Woodcock）MC トレーサーを別建てする（不均一媒質で無偏＝中立な数値手法。製造エンジンではなく測定器）。
- **入出力**: 入力＝濁度/CDOM の場（流入プルーム等の場生成器、または入力マップ）＋粒子クラス情報＋v4-3.1 の曲がった光路。出力＝画素ごとの τ マップ、空間可変ハロ適用後の堆積、ベール項の分離出力（検証用に単独で出せること）。**ラリー改訂**： ベールの出力は RGB 画像ではなく境界放射輝度（波長・位置・方向）とする。経路放射の源項には体積内コースティクス放射場 E(x,t)（第1段の波＋3.1 の GRIN が作る水中の集光場）を含める — これが無いと光の筋（ライトシャフト）は構造のない霞になる。太陽円盤の有限サイズは体積内でも円盤積分として扱う（屈折で変わる実効立体角込み）。非弾性過程（CDOM 蛍光・ラマン）は拡張口を持つか、ゲート許容以下であることを bound で示す。偏光は当面スカラー輸送の誤差 bound として記録する。
- **検証**: (i) 均一場の極限で v16 の数値に一致。(ii) 小格子で MC 参照と統計一致（堆積の帯域エネルギー・ハロ内包率曲線）。MC 参照の合格条件を明記する： GRIN 曲線光路のステップ内部での null-collision 統合、水面屈折＋GRIN を迂回する直線シャドウレイでの NEE は禁止、統計誤差の申告、均一極限と解析 τ の再現。(iii) **多重散乱の要否測定**： 同じ場で MC の散乱次数を 1 回に制限した版と無制限版を比べる。**ラリー改訂**： 掃引の制御変数は cL でなく散乱光学的厚さ bL=ω₀cL（ω₀ を 0.2–0.9 で振る）とし、判定量は堆積の帯域エネルギー・ハロ内包率・線深さ分布に分離ベール画像を加える（ベールは堆積より低い bL で多重散乱が第一級になりうる）。許容差は判定量ごとにここで名指しする（値は実装ブリーフで事前登録）。H5 を好みでなく数で決める方針は不変。

### v4-3.3 — 2層密度レーン（汽水ゲート、塩水くさび＋プルーム前線）
- **目的**: 塩分が実変数になる場面（v5 A6.2 ゲート）でのみ、2層の力学と層別光学を入れる。優先ケースは河川プルーム前線（B2、密度系で最も見えて最も計算可能）。
- **物理の根拠**: 2層浅水方程式（g′ 結合）＋ entrainment 閉鎖 w_e = E(Ri)·ΔU（Ellison & Turner 1959 の実験形、Turner 1986 の集約、Hallberg の TP 解析形）。解像した KH billow は持たない（静水圧モデルのパラメトライズ対象という裁定どおり）。
- **ラリー改訂（RALLY-V4-3-1 §2 C8, C9）**: (i) E(Ri) は「無修正で移せる実験曲線」ではなく「同じ関数形の候補＋現場スケール係数は 3.4 で実測較正する対象」として採用する。Re の適用範囲・底面摩擦の扱い・bulk Ri の定義・係数の不確実さを明記する。係数表は Turner (1986) から確定させる（宿題のまま実装に入らない）。(ii) 界面の表現は物質種（塩分＝階段／温度＝連続）で決めない。基準は界面の実厚さ δ_interface と光学スケール（1/c、ハロ幅、勾配スケール）の比： δ が全てより十分小さければ階段（v4-3.1 の層状極限）、そうでなければ剪断で決まる混合厚さ（臨界勾配 Ri からの見積もり hi ~ 0.25ΔU²/g′ 級）を持つ連続層として 3.1 の GRIN で解く。傾いた前線で階段にすると偽の Fresnel 反射・全反射帯が出るため、前線形状が傾くケースは連続扱いを既定とする。淡水の温度溢流も同じ基準で統一する（当初案の (iii) と C8 の物質区別はこの改訂で解消）。
- **入出力**: 入力＝レシピの塩分（2層パラメータ： ΔS、層厚、流入流量）＋第1段の表面＋第2段の底地形（くさびの誘導・密度水の滞留に効く）。出力＝くさび位置・前線位置・層厚の時系列、層別の (a, b, n) を v4-3.1/3.2 へ、前線上のスリック署名（粗さ帯変調の入力）を第1段の膜/ひずみレーンへ。泡・残滓の線そのものは第1段の素材線レーンの領分のまま。
- **検証**: (i) 前線速度と実測級の収束（0.05 s⁻¹ 級）・下降流（0.2–0.35 m/s 級）の再現範囲。前線速度の参照形は有限水深比を入れた √(g′h₁h₂/H) とし、深い周囲水の極限 √(g′h₁) は h₁/H→0 の場合に限る（h₁/H 0.3–0.7 では 40–50% 速く出る）。風・波の混合で Ri>1 でも entrainment が続く場面を対照に含める。(ii) entrainment 閉鎖の係数は Turner (1986) から直接引く（リサーチ側で係数表を未確定のままにしない）。(iii) 淡水アナログ（温かい／濁った流入が冷たい／澄んだ池水に広がる場面）で塩なしに同じレーンが動くこと。

### v4-3.4 — 場の時間発展＋統合検証
- **目的**: 8 秒ループの中で場がどう生きるか（プルームの上昇、前線の移動、統計的定常の更新）を決め、第3段を通した場面を検証サイズ三枠（メイン v2／サブ v19／対比 v20）で通し検証する。
- **物理の根拠**: 場の移流・更新は各生成器の力学（3.3 は自身の時系列、3.1 のプルーム場は上昇速度と寿命のパラメトライズ）から。**ラリー改訂（RALLY-V4-3-1 §3 N7, N9）**： 場の時間発展は物質輸送（移流・拡散・沈降・再懸濁）と保存則（質量・熱量・塩分量）を明示し、温度・塩分・濁度は共通の状態（n=n(S,T,λ) と密度を同時評価）で結合する。ループ閉合は数値上の要請であり、場の物理を曲げない形でのみ許す — 物理的な時間発展（自然の時間スケール）とレンダリング上の 8 秒ループ（物理を歪めない切り出し方）は分離して設計する。前線のような非周期の伝播現象に周期境界をそのまま適用することは矛盾として扱い、場面ごとに閉合方法を申告する。
- **入出力**: 入力＝3.1–3.3 の全場。出力＝本編相当の静止画/2 秒動画＋ゲート一式。
- **検証**: 既存ゲート群（G-ENERGY／G-LINE 統計形／G-LINE2）に第3段の新規測定（偏向角マップ、τ マップ、ベール分離）を加えた統合判定。味の判定は納品で止める（自律推進の許可の範囲どおり）。**ラリー改訂で追加する検証**： (a) GRIN＋RTE 統合マトリクス（均一＋GRIN なし／GRIN のみ／散乱のみ／GRIN＋散乱／GRIN＋不均一散乱＋多重散乱の 5 条件で MC と空間・方向別放射輝度を照合）。(b) 太陽側のみ／視線側のみ／両側の GRIN 3 条件比較（C1 の大きさの決着）。(c) 実測照合： BOS/シュリーレン実測・温度/塩分プローブ横断・a/b 横断・ベールの絶対放射較正のうち最小限のデータセットを用意するか、実測が無い項目は不確かさを全ゲートに伝播させて申告する（MC との一致だけでは「自然の再現」を名乗らない）。(d) 有限領域の側面境界の申告と、計算窓拡大に対する中央領域の収束。(e) 分光エネルギー閉合監査（太陽入力＝水吸収＋底吸収＋上方透過）。(f) コースティクス時系列の自己相関によるループ周期性ゲート（場だけでなく画像で測る）。(g) 第1段との結合（波の軌道運動による水中場の振動、面＋体積の統合場面）。

## 2. ラリーで攻撃してもらう主張（C1–C10）

- **C1**: GRIN の曲がりは視線側（底→目）だけでなく太陽側（太陽→底）にも第一級で効く。つまりシュリーレンは底の「見え方」だけでなくコースティクス堆積そのものをずらす。片側だけ入れる設計は物理的に欠けている。
- **C2**: 底加熱プルームの見かけ変位は、メイン検証サイズ（深さ 0.6 m 級）で画素閾値を超える（導出では 1–4 mm＝数画素）。第3段の最初の場として底加熱を選ぶ根拠はこの大きさであり、表皮対流（サブ画素）は記録のみで正しい。
- **C3**: パラメトライズしたプルーム場（位置・間隔・ΔT をエネルギー収支と底入力から決める）は、本プロジェクトの大原則の下で「ラベル付き入力」として許容できる — 2次流セルの表面パターンを入力として認めた前例と同じ地位である。対流ソルバーが無いことは、この場の使用を禁じない。
- **C4**: 不均一 RTE への一般化に新しい核の形は要らない。v16 の FF-CDF 核を局所 (τ, b/c) で評価すれば足り、変えるべきは核ではなく経路積分の帳簿である。
- **C5**: 経路放射（ベール項）は第4段（カメラ）を待たずに、現在の固定した真上視点に対して建ててよい。第4段では目の側の端を付け替えるだけで済む。
- **C6**: 検証参照はデルタトラッキング MC が正しい。平面平行を仮定する HydroLight 級ソルバーは、有限パッチ＋底という我々の幾何を表せないため参照にならない。
- **C7**: 多重散乱は cL≈0.2 の現行場面では単一散乱で足りるが、汽水・濁水場面（cL→1+）では第一級になりうる。境界は好みで引かず、散乱次数を制限した MC との対照測定で決めるべきである。
- **C8**: 塩分躍層は連続 GRIN ではなく急界面（階段）として扱うのが物理であり、逆に温度プルームは階段化すると勾配が潰れて別物になる。2つの場で表現を分けるのは恣意ではなく界面の実在の差である。
- **C9**: entrainment 閉鎖 E(Ri)（Ellison & Turner 系の実験曲線）は水路・溢流スケールのデータだが、0.6 m 級の渓流場面へ無修正で移せる。第1段で Dolcetti の水路データが移せたのと同じ地位にある。
- **C10**: 第3段に完全な 3 次元体積ソルバー（速度場・密度場の時間発展 PDE）は要らない。体積の状態は「縮約モデルが作る時間変化する 3 次元場（n, a, b）」として持ち、輸送だけを正確にやる分業で、自然の再現という基準は満たせる。

### ラリー裁定（2026-11-14、RALLY-V4-3-1）— 上記 C1–C10 の現在の地位

- C1： 両側必須は確定。ただし最初の場（底加熱×斜め太陽）での太陽側の大きさは未証明 → 3.4 に3条件比較を追加済み。
- C2： **落ちた（根拠として）**。1–4 mm は ΔT からは決まらず、場を固定した上での導出検算としてのみ残す。底加熱の選定根拠は「因果連鎖が入力から定義できること」に差し替え。検証サイズごとの画素ピッチを明記し、閾値は画素数で書く。
- C3： 条件付きで存続。ラベル付き入力の義務を明文化（全パラメータの画像外固定、出所・生成モデル・有効範囲のメタデータ、不確かさの申告、保存則の充足、画像適合の禁止）。
- C4： **落ちた（主張の形で）**。3.2 は RTE 輸送として再定義し、局所 FF-CDF 評価は適用域明記の近似に降格（§1 v4-3.2 参照）。

### R2-1 — 水面境界の輸送条件（親 §1 v4-3.1 (iii) と v4-3.2 の境界節を置き換える条文）

**置き換える対象**： 親の「水面での出入り口の屈折は局所 n（T/S 依存）で行い、体積 GRIN と面屈折を分離したまま足し合わせない」という一文。以下が置き換え後の条文である。

- **境界法線**： 水面の出入り口で使う法線は、第1段の水面形状から得る瞬時法線 n̂_s(x, y, t) とする。平面・平均法線による近似は使わない。
- **屈折**： 入射・出射とも、評価位置の局所屈折率 n(x, y, z, λ)（T/S 依存、Quan & Fry 1995）で Snell 則を適用する。出射時の n は水面の直下（水側）で評価し、入射時の n は直上（空気側、n≈1）で評価する。波長帯ごとに光線を追うか、無色収差近似の誤差 bound を示す（親の 3.1 の既定を維持）。
- **反射・透過**： Fresnel の振幅反射率・透過率（非偏光は s/p の平均）を境界条件として適用する。偏光は当面スカラー輸送の誤差 bound として記録する（親の 3.2 の既定を維持）。
- **放射輝度変換**： 境界通過時の放射輝度は L/n² 不変量で変換する（L₂ = L₁·(n₂/n₁)²）。光束は断面積の変化を含めて保存する（3.2 の光束ヤコビアンと同一の計算で扱い、二重補正しない）。
- **反射光の再入射**： 水面で反射された光は輸送対象に戻す（再入射させる）。反射を追う回数は、寄与が総エネルギーの 1% 未満であることを場面ごとに bound で示して切る。bound を示せない場面では回数を切らない。1% という値は実装ブリーフで事前登録する。
- **一つの輸送経路**： GRIN 内部の輸送と水面境界の輸送は、一つの光輸送経路として扱う。1本の光線は GRIN 内を曲がり、水面で屈折・反射し、再び体積に入るまでを一本の経路として追う。内部輸送と境界輸送を分離したまま足し合わせてはならない。
- **検証の追加**（親 §1 v4-3.1 検証へ追加）： (v) 水面境界のエネルギー収支： 入射フラックス＝反射フラックス＋透過フラックスを、波長帯ごとに監査する。(vi) 均一 n の極限で、境界条件が現行スタックの水面処理（Snell＋Fresnel）と一致する。

### R2-2 — MTT の適用条件と熱量収支（親 §1 v4-3.1 (i) を置き換える条文）

**置き換える対象**： 親の「プルームの形状パラメータ（幅・壁厚・希釈）は Morton–Taylor–Turner 型の浮力スケーリング（b ∝ αe·z、ΔT ∝ z^-5/3 希釈）で縛り」という一文。以下が置き換え後の条文である。

- **仮想原点**： MTT のスケーリングは仮想原点付きで書く。b(z) = α_e·(z + z₀)、ΔT(z) ∝ (z + z₀)^-5/3。z₀ は熱源の有限面積から決める（点源極限では z₀→0、有限面積熱源では熱源の代表半径相当）。z=0 で ΔT が発散する形は使わない。z₀ の値は生成器の入力に固定し、メタデータに保持する。
- **適用域の宣言**： MTT 型スケーリングは、浮力支配・定常・乱流の純粋プルーム領域に限定する。適用域の判定は次の入力から行う： 熱源形状（点源／有限面積）、熱流束、周囲水の成層（ブラント–ヴァイサラ振動数 N²）、Reynolds 数。判定の結果、適用域外（熱源近傍の境界層、成層による浮力抑制が支配的な領域、プルーム同士の干渉域）では MTT を使わず、実測入力または別の物理モデルを要求する。適用域の判定結果は生成器のメタデータに残す。
- **壁厚**： MTT はプルーム半径 b(z) と中心過剰温度 ΔT(z) を決めるが、プルームの「壁厚」は決めない。壁厚は生成器の独立したパラメータとし、画像外の入力に固定する（画像の見た目では決めない）。
- **プルーム間隔**： 「間隔は水深 H 級」という層流 Rayleigh–Bénard 由来の文言は削除する。間隔は MTT の独立プルーム条件（隣接プルームの間隔 ≫ b(z)）と、底加熱の実測入力（底アルベド／湧水入力）から決める。独立条件を満たさない場合は、干渉補正を入れるか実測入力に切り替える。
- **熱量収支の実装仕様**： 生成された温度場の体積積分熱量 Q_field = ∫ρc_p·ΔT dV と、ベッドから入力された熱量 Q_in の収支を検証項目に入れる。判定は |Q_field − Q_in| / Q_in ≤ ε_Q で、ε_Q は実装ブリーフで事前登録する（値の先送りではなく、定義式と登録の義務をここに固定する）。粒子（濁度）についても、供給量と場内に保持される粒子量の収支を同じ形で検証する。粒子の供給・除去・境界流出入の扱いは、生成器の入力仕様に明記する。
- **検証の追加**（親 §1 v4-3.1 検証へ追加）： (v) 熱量収支（上記の式）。(vi) 適用域の判定記録（MTT を使った領域と、実測入力・別モデルに切り替えた領域の区分）。(vii) §2 C10 の感度検証： 導関数（dΔT/dz、db/dz）と鉛直プロファイルへの感度を、生成パラメータの不確かさを伝播させて縛る。

### R2-3 — 界面と閉鎖（親 §1 v4-3.3 の改訂 (i)(ii) と検証 (i)(ii) を置き換える条文）

**置き換える対象**： 親の (ii)「基準は界面の実厚さ δ_interface と光学スケール（1/c、ハロ幅、勾配スケール）の比」、検証 (i)「前線速度の参照形は有限水深比を入れた √(g′h₁h₂/H)」、検証 (ii)「entrainment 閉鎖の係数は Turner (1986) から直接引く」。以下が置き換え後の条文である。

- **界面判定の物差し（訂正）**： 階段（不連続 Snell＋Fresnel）で扱うか連続 GRIN で扱うかの判定に、散乱の減衰長 1/c やハロ幅を持ち込んではならない。判定は次の二つの比で決める： (a) 不連続 Fresnel 反射の有無は、界面厚さ δ と波長 λ の比 δ/λ で決める（δ/λ ≪ 1 なら階段の Fresnel が立つ）。(b) 幾何光学的な偏向の差は、界面の曲率半径 R と画素サイズ（および光線束の横幅）の比で決める。親の「1/c、ハロ幅、勾配スケールとの比」という文言は、この訂正で置き換える。
- **「十分小さい」の定量化**： 階段近似を許す条件は δ/λ ≤ 0.1 とする（値は実装ブリーフで事前登録する。ここでは条件の形と登録の義務を固定する）。誤差の測り方は、階段近似と有限厚さ GRIN 解の間の放射輝度差とする。輸送精度に必要な厚さと、場生成モデルに必要な厚さは分けて記述する（前者は光学の判定、後者は流体力学の界面厚さ）。
- **GRIN 補間との整合**： 連続 GRIN 領域では n 場の補間に C¹ 級の滑らかさを要求する（親の 3.1 の既定）。不連続界面は補間で平滑化せず、境界条件として別処理する。有限厚さの界面は、実厚さを解像できる格子で補間する。この三つの扱いを混同してはならない。
- **前線速度の定義**： 参照形 √(g′h₁h₂/H) の H は全水深 H = h₁ + h₂ と定義する。この式は二層内部波の位相速度であり、非線形な重力流の先端速度とは区別する。検証は両者を別項目で測る： (i-a) 内部波の位相速度と参照形の一致、(i-b) 前線の実測位置の時系列との一致（相対誤差を実装ブリーフで事前登録）。親の検証文言「前線速度と実測級の収束（0.05 s⁻¹ 級）」は未定義のため削除する。
- **係数の二段構造（内部矛盾の解消）**： entrainment 閉鎖は E_field(Ri) = k_field · E_Turner(Ri) の二段構造で書く。E_Turner(Ri) は Turner (1986) の関数形と係数表を基準値として固定する（親の「Turner から直接引く」は「基準値として引く」に書き換える）。k_field は現場較正で推定する無次元のスケール係数で、k_field = 1 が「較正不要」の判定である。較正は 3.4 の実測データセットで行い、k_field の推定方法・許容範囲・データ要件は実装ブリーフで事前登録する。現場較正がどこで・どのデータで行われるかは 3.4 の検証 (c) に明記する（§4 R2-4 参照）。
- **Ri>1 の風・波混合**： w_e = E(Ri)·ΔU は Ri>1 で E→0 になるため、風・波の混合で entrainment が続く場面はこの式だけでは出力できない。混合速度に風・波の寄与を加えた実効速度 ΔU_eff を導入し、w_e = E(Ri)·ΔU_eff と書く。ΔU_eff の形は Turner 系の実験曲線の適用外として、3.4 の実測で較正する（関数形の候補と較正方法は実装ブリーフで固定する）。3.3 の検証対照には、Ri>1 でも entrainment が続く場面を含める（親の既定を維持）。

### R2-4 — 実測照合と分光エネルギー閉合（親 §1 v4-3.4 の検証 (c)(e)(f) と物理の根拠を置き換える条文）

**置き換える対象**： 親の検証 (c)「最小限のデータセットを用意するか、実測が無い項目は不確かさを全ゲートに伝播させて申告する」、検証 (e)「分光エネルギー閉合監査（太陽入力＝水吸収＋底吸収＋上方透過）」、検証 (f)「コースティクス時系列の自己相関によるループ周期性ゲート」。以下が置き換え後の条文である。

- **実測照合の必須化**： 最初の場である底加熱プルームについては、温度場または光学的偏向の実測（BOS／シュリーレン実測、または温度プローブ横断）を必須とする。不確かさの伝播は、実測が無いことの代替にはならない。実測が無い項目は「未検証」として扱い、申告だけではゲートを通さない。実測のデータセット（何を・どこで・どの精度で測ったか）は 3.4 の検証 (c) に明記する。
- **分光エネルギー閉合の完全な式**： 波長別に、入射フラックス（太陽）＝ 水面反射 ＋ 水中吸収 ＋ ベッド吸収 ＋ 上方境界の正味放射フラックス ＋ 側面境界の正味放射フラックス、とする。散乱によるエネルギー移送は内部の方向移送として扱い、生成・消滅項と混同しない。入射・反射・透過・吸収は同じスペクトル範囲で定義する。側面境界の物理条件（開放／反射／周期の選択基準）は 3.4 の検証 (d) に明記する。既定は開放境界（有限パッチの外側は同種の水が続くとみなす）とする。
- **太陽円盤の実効立体角と光束ヤコビアンの統合**： 屈折による実効立体角の変化と、3.1/3.2 の光束ヤコビアンは、一つの保存計算で扱う。二重補正を禁止する。3.4 の統合検証 (a) に、両者の整合チェック（立体角変化とヤコビアンの積が光束保存を満たすこと）を明記する。
- **MC 許容差の扱い**： 許容差の数値そのものは実装ブリーフで事前登録する（前回ラリーで確定した方針を維持）。設計書に固定するのは、判定量ごとの許容差の定義式と登録の義務である。判定量は帯域エネルギー、ハロ内包率、線深さ分布、分離ベール（境界放射輝度）の四つとする。登録が無い測定はゲートとして数えない。
- **周期性ゲートの分離**： ループ周期性のゲートを二つに分ける。(f1) ループの視覚的接続性： 画像の自己相関と、継ぎ目での不連続量（継ぎ目前後の画素差の統計）で測る。(f2) 物理時間発展の正しさ： 熱量・質量の時間変化、場の自己相関時間、保存則の充足で測る。(f1) が良くても (f2) が悪ければ、場の時間発展は自然でない。
- **太陽側 GRIN の定義・入出力（3.1 側への追加）**： 3.4 の検証 (b)「太陽側のみ／視線側のみ／両側の 3 条件比較」の決着を 3.4 に投げっぱなしにしない。3.1 の出力に、太陽側の光路束（太陽→底の曲がった光路とその光束ヤコビアン）を追加する。3 条件比較の判定量は、堆積の帯域エネルギーとベール分離出力とする。

### R2-5 — 製造用 RTE ソルバーの置き場（Gemini の致命指摘への回答。親 §3 の範囲外規定を条件付きで改める条文）

**問題**： 3.2 が局所 FF-CDF を「滑らかな場のみの高速近似」へ降格させた一方、親 §3 は体積フォトンマッピング／ビームトレーシング／MC の製造利用を禁止したままである。その結果、成層プルームや急勾配場で不均一ハロ（レバーアーム (L−s) 重み付き積分）や体積内コースティクス放射場 E(x,t) を実際に計算する製造手法が、設計書から消えている。

**条文**：

- **製造ソルバーの定義**： 製造用の RTE 解法は、曲線光路上での決定論的解法（離散方向法）とする。GRIN の曲がった光路束（§6 R2-6）を入力に、各光路に沿って方向別放射輝度を解く。フォトンマッピング／ビームトレーシングは製造エンジンとしては使わない（親 §3 の禁止を維持）。MC は測定器としてのみ使う（親 §2 C6 の裁定を維持）。
- **製造と堆積の分業**： 製造ソルバーの出力は、画素ごとの τ マップ、空間可変ハロのパラメータ、体積内コースティクス放射場 E(x,t) である。画像への堆積そのものは、検証済みの面積保存メッシュ投影（v4-1.8）のレーンを使う。製造ソルバーは堆積レーンを置き換えない（この分業が §3 の禁止の趣旨である）。
- **適用域の切替え**： 滑らかな単一集団場（適用域は §7 R2-7 の書き換え条件を満たす場）では局所 FF-CDF の高速近似を使ってよい。適用域外（急勾配場・成層プルーム）では決定論的 RTE 解法を使う。切替えの判定は場の勾配スケールと光路長の比で行い、判定結果をメタデータに残す。
- **検証**： 製造ソルバーは、均一場の極限で v16 の数値と一致すること（親の 3.2 検証 (i) を維持）。方向分割数と収束条件は実装ブリーフで事前登録する。GRIN＋RTE 統合マトリクス（3.4 検証 (a)）の 5 条件で、製造ソルバーと MC 測定器の空間・方向別放射輝度を照合する。

### R2-6 — 3.1/3.2 結合 I/O の書き直し（逐次形から非逐次形へ。親 §1 v4-3.1 と v4-3.2 の入出力を置き換える条文）

**問題**： 親は 3.1＋3.2 を「結合輸送として定義する」と書きながら、I/O は「3.1 の曲がった光路 → 3.2」という逐次形のままである。3.1 の出力は「堆積 C の変位場が GRIN 分だけ変わること」で、3.2 の入力は「v4-3.1 の曲がった光路」となっており、結合の定義と I/O が食い違っている。

**条文**：

- **3.1 の出力（書き直し）**： 3.1 の出力は、(a) n 場（位置・波長・T/S 別の屈折率場）、(b) 太陽側と視線側の両方の光路束（各光線の位置・方向・光束ヤコビアン、§4 の太陽側追加を含む）、(c) 体積内コースティクス放射場 E(x,t) の生成に使う集光情報（波＋GRIN が作る水中の集光場の位置・波長・方向別の放射輝度）、とする。堆積 C の変位場は 3.1 の出力ではない（変位場は 3.2 の RTE 輸送と堆積レーンを経て決まる）。
- **3.2 の入力（書き直し）**： 3.2 の入力は、(a) 3.1 の光路束（太陽側・視線側）、(b) E(x,t)（位置・波長・方向別の放射輝度場として定義し、散乱源項への接続は方向積分で与える）、(c) 濁度／CDOM の場と粒子クラス情報、とする。E(x,t) が 3.1 の出力にも 3.2 の入力にも記載されていない状態は、この書き直しで解消する。
- **結合の定義**： 3.1 と 3.2 は逐次処理ではない。光路束を共有する一つの輸送として定義する。GRIN による光路の曲がりと、RTE による散乱源項の評価は、同じ光路束の上で行う。曲線光路上で係数だけを積分する形にはしない（親の既定を維持）。

### R2-7 — 文言の掃除と残件（親 §1 各節の記述ズレを直す条文）

- **FF-CDF 適用条件の書き換え**： 親の「勾配スケール ≫ 1/c かつ ≫ ハロ幅」という適用条件は、澄んだ水（c≈0.2 ⇒ 1/c ∼ 3 m）と噛み合わない。適用条件を「場の勾配スケールが、光路長と鉛直層厚の両方より十分大きいこと」に書き換える。「十分大きい」の形は、勾配スケール／光路長 ≥ 5 および勾配スケール／鉛直層厚 ≥ 5 とする（値は実装ブリーフで事前登録し、MC 照合で検証する。ここでは条件の形と登録の義務を固定する）。
- **気泡の位相関数**： 気泡は「別の位相関数」と書くだけでは足りない。気泡の位相関数は Mie 理論による球形気泡位相関数を既定とする。気泡径分布は第2段の供給する濃度場の入力に固定する。幾何光学的な空気泡散乱への切替えは、Mie との差が許容差以内の場合に限る。
- **C2 の画素換算**： 親 §1 v4-3.1 検証 (iv) の「0.5 m 路径で見かけ変位 1–4 mm」には画素換算を付ける。メイン枠（窓 1.4755×1.0828 m、736×540）では画素ピッチ約 2.0 mm/px のため、1–4 mm は約 0.5–2.0 画素である。検証サイズごとの画素換算は実装ブリーフで明記する。なお 1–4 mm は「当てる目標」ではなく導出の検算である（親 §2 C2 裁定の既定を維持）。
- **C5 の表記統一**： 親 §1 v4-3.2 検証 (iii) の「分離ベール画像」という旧表記を「分離ベール（境界放射輝度）」に統一する。
- **C10 の感度検証の配線**： §2 C10 が約束した感度検証（導関数と鉛直プロファイルへの感度）は、§2 R2-2 の検証 (vii) と 3.4 の検証 (a) に配線する（§1 の検証リストに明記する）。
- **粒子クラスの混合則**： bw（純水分子散乱）・bp（粒子散乱）・気泡の三系統を分離した上で、各クラスの散乱係数は体積分率で重み付けし、合成位相関数は散乱係数重みの平均で作る。各方向積分は 1 になるよう正規化する。混合則の形と係数表は実装ブリーフで固定する。
