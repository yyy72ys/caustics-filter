# BRIEF — ν のフェッチ効果と高波数尾部の切り分け（k_cut スイープ）（cf-0069、caustics-kcut-sweep）

## 目的
cf-0067（wave-groups-diag）の測定で、フェッチを 100 m → 10000 m に伸ばすと ν が 0.285 → 0.375 と増え、GF_S が 0.707 → 0.422 と下がった。発達した海ほど群れが長い、という見立てと逆である。モード集合から直接計算した ν は P1 0.3521／P5 0.3333／SWELL 0.3951 で、フェッチを 100 倍にしても狭帯域化しない。原因の候補は、elfouhaily-form の高波数カスケード（k から 1000 rad/m まで）がフェッチに依らず同程度に効き、周波数モーメントがカスケード側で決まること。このジョブは `k_cut` を下げた同一条件で ν がどこまで下がるかを測り、フェッチ効果と高波数尾部の寄与を分離する。

原料：`delivery/wave-groups-diag/REPORT-WAVE-GROUPS-DIAG.md` §7 原因候補 1 および §10-7（cf-0067 は `k_cut` を動かしていない＝生成器の既定のまま）。このブリーフの数値はすべてそのレポートから取ったものである。

## 対象の条件（cf-0067 と同じもの）
- **P5-CLEAR**：U=6.00 m/s、F=100 m、深さ 4.00 m、Elfouhaily-form／Arm D、窓 4.8000×3.5200 m、2048²。
- **SWELL-1**：U=6.00 m/s、F=10000 m、深さ 4.00 m、Elfouhaily-form／Arm D、窓 76.8000×56.3200 m、2048²。
- cf-0067 の既定値：高さ ν（プローブ）P5 0.285 ± 0.005／SWELL 0.375 ± 0.008、モード集合 ν P5 0.3333／SWELL 0.3951、高さ GF_S P5 0.707 ± 0.007／SWELL 0.422 ± 0.020、高さ GF_A P5 0.464／SWELL 0.411。
- **P1-WINDLANE は対象外**（Phillips スペクトルで、今回の切り分けの主題である elfouhaily-form の高波数カスケードとは別物。cf-0067 の §1 の申告参照）。

## 測る量
- 各 `k_cut` で、**モード集合から直接計算した ν** と、**プローブ記録から計算した高さ空間の ν** の両方を測る（cf-0067 の §2 の定義・推定量をそのまま使う：`run_v4_1_11.py` の `hilbert_batch`／`gf_batch`／`nu_batch` を import する。定義のドリフト禁止）。
- 高さ空間の **GF_S（SIWEH 型）と GF_A（包絡比型）** も各 `k_cut` で測る。傾き空間は副次（P5 は測れるが、SWELL は cf-0067 §5 のとおり格子が曲率帯域を表現できない。曲率空間は測らない）。
- 各 `k_cut` でスペクトル重心（k_centroid_height、λc）と、窓/λc も記録する。`k_cut` を変えるとモード集合が変わるので、何が変わったかを一緒に見ること。

## スイープの取り方
- **まず生成器の既定の `k_cut` をコードから読み、記録すること**（既定値がどこで決まるかはコードを読んで確認する。cf-0067 のレポートには既定値の数値が無い）。
- 既定値から下へ幾何級数的に下げる（例：既定、1/2、1/4、1/8、1/16。ν が下がり止まるまで）。各段で P5 と SWELL-1 の両方を測る。
- シードは cf-0067 と同じ 5 本（`3255045276382562994`、`8481896831540885908`、`4321956055262143624`、`8565340840216948583`、`7613826230457010363`。シード 1 は記録済みの本番シード）。プローブは cf-0067 と同じ 16×16=256 点、24 fps／192 フレーム（8.000 s）、間引きなし。
- cf-0067 の診断スクリプト `out/wave-groups-diag/run_wave_groups_diag.py` のパターンを再利用してよい（推定量・プローブ・集計の流儀を合わせること）。新規ファイルは `out/kcut-sweep/` 以下に置く。

## 判定の見方（事前に固定する）
- `k_cut` を下げるにつれてモード集合の ν が下がり、プローブの ν・GF がそれに追随するなら、**高波数尾部が ν を決めていた**ことになる（フェッチ効果は副次）。
- `k_cut` を下げても ν が下がらない（あるいは P5 と SWELL の ν の差が残る）なら、**フェッチ効果が ν を決めている**（あるいは別の機構。ω 量子化など cf-0067 §7 の候補 3 も参照）。
- どちらともつかない場合は、両方の数値をそのまま記録し、決着をつけないこと（測定ジョブは結論を捏造しない）。

## 禁止事項
- **k_cut はこのジョブの診断プローブであって、生成器の変更ではない。** 生成器の既定値を書き換えない。既存の `*.py` は変更禁止（新規ファイルのみ）。変更前後で全 `*.py` の SHA256 を取り、変更 0 件を証明すること。
- `run_prod_v4.py` は変更禁止。本番配線はしない。
- `patch_base_m` は動かさない（cf-0067 §10-7 のとおり、次のジョブの仕事として残す。ただし `k_cut` を変えた結果としてパッチが連動して変わる仕組みがあるなら、その連動を記録すること）。
