    評価し、結果はその画素の当該サンプルの寄与として重み 1/N_total で
    積算する。床成分とグリッター成分は分離したまま積算し、合成は
    積算後に行う（受入テスト (3) の分離検証のため）。D_app／D_glit は
    焦点設定・体制地図・受入テストの参照量として残るが、結像の入力では
    なくなる（R3 から不変）。
  **(2) 交点選択規則（R4 最低条件1）**：光は経路の順に相互作用するので、
  選択規則は**経路順の最近接**とする（エネルギー最大などの事後選択は
  採らない）。
  - 各区間では、現在の始点から光線方向に測った距離 t が最小の正の
    交点（t > 1e-6 m。自己交点の回避）を取る。水面（高さ場）との交点と
    床（高さ場）との交点の双方が候補になる場合は、小さい方の t を取る。
  - 空気側から水面へ入る交点では Snell 屈折で水中へ進む（空気側に
    全反射はない）。水中で水面下面へ再到達した場合は Fresnel で
    判定する：入射角が臨界角（asin(1/1.333) = 48.61°）以上なら
    全反射して水中を進む。それ未満なら、反射と屈折のうち Fresnel
    重みの大きい方へ進み（決定論的選択）、選んだ方の重みを放射輝度へ
    乗せる。屈折で空気側へ出た時点で status = EXIT として終端する。
  - 相互作用の回数の上限は4回とする。達した場合は status = ABSORBED
    とし、その時点までの L_vol のみを返して終端する（打ち切った
    重みは記録する）。
  - 多像は画素の側の性質として扱う：1本のサブレイの経路は上の規則で
    一意に決まる。異なるサブレイが同じ床点へ届くこと（多像化）は
    積算の結果として自然に現れ、選択の問題にはならない。D_app が
    必要な場面（受入テスト (4) の予測）では、多像域はマスク外
    （κ ≥ κ_crit）として D_app を使わない（v4-4.2）。
  **(3) 回折の生成機構（R4 最低条件1）**：幾何的サブレイ追跡だけでは
  回折は生じない（ピンホール極限で点が1点に収束する）。v1 の生成
  機構は次の畳み込みとする：結像段の幾何像（サブレイ積算の結果、
  線形 HDR）に対し、画素ごとに局所の実効 F 値
  N_w(x, y) = N·s_f/(s_f − f) から決まる Airy 核（直径
  2.44λ_d·N_w、λ_d = 550 nm）で畳み込む。根拠：回折は有限開口の
  瞳関数のフーリエ変換に由来する実在の物理であり、無収差・合焦の
  円形瞳ではその強度分布が Airy パターンそのものになる。デフォーカスを
  含む一般の場合は真の波動 PSF とずれる近似である（遷移域のずれは
  上の ※式の訂正の注記のとおり）。近似の誤差は受入テスト (5) で
  波動光学の独立参照（瞳関数の FFT 伝播、デフォーカス位相つき）と
  照合して測る。ピンホール極限（N → 大）では幾何像は入力に帰着するが
  Airy 核は広がり続けるため、波動込みの出力は帰着しない（出力欄の
  極限の整理と一致）。
  **(4) 許容差の分離**：ぼけ円直径など幾何量の照合には
  max(0.5 px, 5%) を適用する（差の絶対値が 0.5 px と参照値の 5% の
  うち**大きい方**以下であること。小さいぼけでは 0.5 px の絶対床が
  効き、交点は参照値 10 px）。**Airy 径の照合には 0.5 px 床を
  使わない**：許容差は max(0.02 px, 5%) とする。根拠：
  d_A = 2.44λ_d·N_w / 17.58 µm は N_w ∈ [1.4, 16] で
  0.107–1.222 px であり、0.5 px 床では N_w ≲ 6.5 の範囲で回折が
  皆無（測定 0）でも合格してしまう。0.02 px 床なら測定 0 は全範囲で
  不合格になる。平坦部での総光量保存は相対誤差 1e-3 以内。参照
  レンズ級は理想薄レンズ（収差なし）とし、実レンズの収差は v4-4.6 の
  範囲外に置く（R2 から不変）。
  **(5) 倍増収束規則（総数 N_total への一本化）**：サンプル数の収束は
  総数 N_total（v4-4.4 ※R4 の結合列）の倍増で判定する。n と 2n の
  結果について、(i) 像 RMS 相対差（(6) の定義）が 1e-3 以内、
  (ii) (6) のブロック条件を満たす、(iii) ぼけ径など代表スカラー量の
  変化が幾何量の許容差以内（Airy 径を代表量に使う場合は Airy 専用
  許容差）、のすべてを満たした時点で収束とし、その N_total を記録
  する。上限（N_total ≤ 2^20 = 1,048,576。旧 S ≤ 4096・M ≤ 256 の
  積と同等の総量予算）に達しても満たさない条件は、契約の適用外として
  記録し、**その条件の画像は納品物に含めない**（部分結果は検証用に
  のみ保持する）。壁時間は条件ごとに記録する。標準3枠の正準条件が
  適用外に落ちた場合は設計へ差し戻す（納品しない）。
  **(6) RMS 相対差の定義**：線形 HDR 像 I_n（総数 n）と I_2n について、
  画素平均の二乗差 D = sqrt(mean_p (I_2n(p) − I_n(p))²)、基準
  R = sqrt(mean_p I_2n(p)² + (1e-3 · mean_p I_2n(p))²) とし、
  相対差 = D/R とする（分母の第2項は暗部・ゼロ近傍での発散を防ぐ
  床で、平均輝度比 1e-3）。高輝度グリッターに分母が支配されて暗部の
  誤差が隠れることを防ぐため、ブロック条件を併用する：像を
  32×32 px のブロックに分け、ブロック平均が全体平均の 1% 以上の
  ブロックすべてで、同じ式によるブロック相対差が 3e-3 以内である
  こと（3e-3 は R4 の新規設計値。確認ラリー第4回の監査対象として
  明記する）。時間方向の収束（旧 M の役割）も同じ N_total の倍増で
  判定し、追加で露光内グリッター像の時間積分重心の移動量の変化が
  0.5 px 以内であることを課す（点列のストロボ誤差は全体 RMS では
  検出しにくいため）。
  **(7) 受入テスト群（6件必須。再設計。各件の合否は上の数値で
  判定する）**：
  (1) 波面ケース——波面のある場面で、**独立参照 B**（下記）とぼけ径
  max(0.5 px, 5%) 以内・像 RMS 相対差（(6) の定義）1e-3 以内で
  一致すること。同一トレーサの増量計算は収束確認には使えるが、
  本テストの参照には使わない。
  (2) 遮蔽境界——遮蔽の境界の像位置の差が参照 B に対して 0.5 px
  以内、境界を跨ぐ画素の輝度差が参照 B の値の 5% 以内であること
  （「参照」は参照 B と定義する。R3 の未定義の「参照」を固定した）。
  (3) グリッター対床——v4-4.2 の参照式の適用条件を満たす条件でのみ、
  D_glit 参照式の予測ぼけ径と案1の追跡結果（成分分離した積算）が
  幾何量の許容差以内で一致すること。適用条件を満たさない条件では
  本テストは実施不能として記録し、合否には数えない。
  (4) 空間変動 PSF——評価点は v4-4.2 のマスク内（境界から 1 px 以上
  内側）に限る。局所の D_app から予測したぼけ径と追跡結果が
  max(0.5 px, 5%) 以内で一致すること。
  (5) 参照照合——平坦水面の解析解（見かけ深さ・薄レンズぼけ・
  Airy 径）と照合し、ぼけ径は幾何量の許容差、Airy 径は Airy 専用
  許容差（0.5 px 床なし）で判定すること。あわせて波動光学の独立
  参照（瞳関数の FFT 伝播）で回折込み PSF を照合すること。
  (6) エネルギー保存——平坦部では総光量の相対誤差 1e-3 以内、
  非平坦部でも 5% 以内であること。非平坦部で保存量から外れる分は
  Fresnel 反射率の傾き依存と窓外逸脱として内訳を記録する
  （R3 の「gather 側の非保存」は案1に存在しない段の語であり
  現行無効——§9 無効リスト #7）。5% を超える条件は契約の適用外と
  する。
  **独立参照 B の定義**：本番トレーサとは別実装の検証用計算で、
  次のうち少なくとも1つを含むこと：(a) 平坦水面の解析解、
  (b) 交点求解法とサンプリング列が本番と異なる独立実装のトレーサ、
  (c) 波動光学 FFT 伝播（回折の照合用）。同一コードのサンプル数
  違いは独立参照に数えない。

### v4-4.4 焦点の時間制御（フォーカス移動）

- **目的**：動画で焦点を水面→中間→床へ移す操作を、s_f(t) の
