閉鎖の判定基準: 次の5点がすべて現行規則として一意に読めること。(a) 切替基準が ε_WKB の単一閾値に統一され、矛盾する数値基準（L_U/λ ≲ 3）が現行規則として残っていない。(b) 滞留が状態量 A_trap と収支式で定義され、シンクと区別され、その放出先が定義される。(c) 6成分の配分が、配分を一意に決める閉合則として働く。(d) Fr→1 の正則化が、臨界条件と接続先まで定まる。(e) 不可逆シンクの計上条件（移送先が定義され収支で確認できた F_brk・F_turb に限る。反射はシンクでない）が維持される。

争点:
(i) 配分の一意性: 各成分を別々のユニットの計算から求め、「合計が1」を確認し、合わなければ U2b へ進まない、という形は、配分を決める規則か、検算とゲートの規則か。6つの独立な評価が合計1にならない場合に、どの成分をどう調整して配分を確定させるかの規則は本文にあるか。なければ、配分の自由度は前回と同じく残るのではないか。
(ii) A_trap の流出の内訳: F_out は「下記の配分先への流出作用束の合計」と定義されるが、滞留した作用がどの成分へどれだけ流出するかの配分は定義されているか。τ_trap = A_trap / F_out は、F_out の内訳が決まらなくても診断量として閉じているか。
(iii) Fr→1 の「言い換え」: フルード数 U/c = 1 と、光線に沿う群速度の法線成分がゼロになる遮断条件は、採用する分散関係（有限水深・表面張力・流れ込み）の下で常に等価か。等価でない場合、「Fr→1 は遮断条件の言い換え」という定義自体が新たな混同にならないか。正則化の振り分け自体は 525行目に規則がある（転回点では Airy 型一様漸近で接続し、Airy の仮定（孤立した単純転回点）を満たさない面的な非 WKB 域は波解像伝播へ切り替える）。残るのは支配方程式の選択と接続手順のブリーフ登録である（525行目）— 前回の「別途特定」の先送りは、臨界条件の特定だけで解消したと言えるか。
(iv) C9′（221行目）の残存: 反射を含む「シンク」の旧文と L_U/λ₀ ∼ 0.5–3 の記述が §6.1 に物理的に残る。R2-11 経由の上書き（R2-11 の見出し → R3-2 の上書き）という二段の経由で、C9′ の旧文が現行規則でないと一意に読めるか。

#### K4 — 項目4: C16′ 散逸機構の帯固定（統合 §3 条件1）

前回の残件（統合 §2 項目4）: 「帯境界の場面決定を宣言したものの無次元決定基準がなく、R2-17（仮置き U5/Δ_η,brk）と R2-25（要否宣言）の調整および R2-17 三波共鳴と R2-5 1:2 共鳴の切り分け参照も未整備である」。

#### K5 — 項目5: U14 点渦の発散（統合 §3 条件1）

#### R2-4 — C3 の振幅率／エネルギー率の統一（§6.1 の C3′ を書き換える条文）

#### R2-5 — C6 の Wilton 共鳴振幅方程式（§6.1 の C6′ を書き換える条文）

**置き換える対象**： 親 §6.1 の C6′「Wilton は 1:2 三波共鳴として非線形枠組みの中で扱い、寄生毛細波は独立機構のまま別置する。QTF の適用域は宣言でなく固有値／残差の実測で決める。」

- **共鳴の定義**： Wilton 共鳴は、基本波と第2高調波の 1:2 共鳴として扱い、寄生毛細波とは別機構に置く。共鳴判定は、採用する有限水深・表面張力・流れを含む分散関係に対して、周波数整合 ω₂ = 2ω₁ および波数ベクトル整合 k₂ = 2k₁ を満たすかで行う。「1:2」と書くだけでは足りない。
- **結合振幅方程式**： 共鳴近傍では、非共鳴 QTF の単純評価を継続せず、共鳴する複数モードの振幅を同時に解く結合振幅方程式へ切り替える。基本波の振幅 a₁ と第2高調波の振幅 a₂ を同時に未知量とし、da₁/dt = i·V₁₂·a₁*·a₂、da₂/dt = i·V₂₁·a₁² の形で書く（V₁₂、V₂₁ は採用する二次核から決まる結合係数。係数の導出元と値は実装ブリーフで固定する）。QTF の残差・固有値診断は切替判定の一部とし、三波共鳴の解法そのものの代替とはしない。
- **QTF 適用性の判定**： QTF の適用性は、QTF が近似する二次自由表面境界条件の残差、共鳴分母の大きさ、対象モードの振幅誤差、曲率統計およびバイスペクトルの誤差で判定する。「固有値」を用いる場合は、対象とする線形化演算子または結合振幅系を明記し、QTF 単体の固有値とは呼ばない。
- **寄生毛細波との分離**： 寄生毛細波は独立機構のまま別置する（親の既定を維持）。Wilton 共鳴の振幅方程式と寄生毛細波の生成項を混同してはならない。

#### R3-1 — Wilton 結合振幅方程式の完成（R2-5 を書き換える条文）

**置き換える対象**： 親 §6.4 R2-5（結合振幅方程式の項と QTF 適用性の判定の項）および §6.1 C6′。

**根拠**： 統合 §1 K2（3席一致：結合方程式の形と共鳴整合条件は置かれたが、V₁₂・V₂₁ の導出元・値が実装ブリーフへ先送りで、QTF→結合方程式の切替閾値がない。Gemini は不成立：0D ODE 化・空間移流／減衰の欠落も指摘。GPT・Grok は条件付き）、§3 条件1。統合 §3 優先2の Grok P1「原文直接照合」は、結合係数の核からの再計算による照合で満たす（下記の検証を参照）。

- **係数の導出元**： V₁₂・V₂₁ は、採用する二次核（QTF の核と同じ、自由表面境界条件の二次核）を共鳴三つ組み (k, 2k) で評価した三波相互作用係数とする。導出は Zakharov 型ハミルトン形式の三波相互作用係数に準拠する。QTF の核と結合係数は同じ二次核から出るため、両者の整合は核の同一性で保証する。係数の数値は、採用する核から計算して実装ブリーフへ登録する。登録値は、核からの再計算で再現できることを検証条件とする。「導出元と値は実装ブリーフで固定する」という R2-5 の先送りは、導出元をここで固定し、値の計算と登録だけをブリーフへ委ねる形に改める。
- **保存則の検算**： 減衰・移流を除いた結合方程式の部分は、作用保存（Manley–Rowe 関係）を満たすこと。V₁₂・V₂₁ の符号と比は、保存則から検算する。保存則の形と関係式は、採用する振幅の規格化に合わせて実装ブリーフで明記し、登録値がその関係式を満たすことを検証条件とする。保存則を満たさない係数は採用しない。
- **空間移流と減衰（0D ODE は局所形に限定）**： 結合方程式の完全形は、各モードが自らの群速度で移流し、各モードが自らの減衰を受ける偏微分方程式とする。∂a₁/∂t + c_g1·∇a₁ = iV₁₂a₁*a₂ − γ₁a₁、∂a₂/∂t + c_g2·∇a₂ = iV₂₁a₁² − γ₂a₂。ここで c_g1、c_g2 は採用する分散関係（有限水深・表面張力・流れ込み）から計算した各モードの群速度、γ₁、γ₂ は各モードの不可逆減衰率（線形粘性はエネルギー率で 4νk²。R3-5 の統一に従う）＋該当する Marangoni・砕波寄与である。R2-5 の da₁/dt、da₂/dt の形は、空間一様・移流なしの局所近似としてのみ使う。0D ODE を完全形として扱ってはならない。
- **切替閾値（定量）**： QTF から結合方程式への切替は、無次元離調 δ = |ω₂ − 2ω₁|/ω₁ と QTF 残差ノルム R（R2-5 の適用性判定で定義した、二次自由表面境界条件の残差）で決める。切替の判定量は QTF の予測誤差 E_QTF(δ)（残差ノルムから評価した第2高調波の振幅誤差）であり、E_QTF が U8a の誤差予算を超える離調で結合方程式へ切り替える。数値の閾値 δ_c は、E_QTF(δ) の測定曲線と U8a の誤差予算から導出して実装ブリーフへ登録する（ここで数値を創作しない。導出手順：残差ノルムを離調の関数として測定し、誤差予算と交わる離調を δ_c とする）。切替判定は、離調だけ・残差だけの片方では行わない。
- **QTF 適用性判定との関係**： R2-5 の QTF 適用性判定（残差・共鳴分母・振幅誤差・曲率統計・バイスペクトル）は切替判定の一部として維持する。「固有値」を用いる場合は、対象とする線形化演算子または結合振幅系を明記する（R2-5 の既定を維持）。

#### R3-2 — 遮断シンクの閉合（R2-11 を書き換える条文）

**置き換える対象**： 親 §6.4 R2-11（WKB 適用性・切替閾値・遮断近傍の作用・Fr→1 の項）。

**根拠**： 統合 §1 K3（3席一致：ε_WKB < 0.15 と L_U/λ ≲ 3（ε_WKB ≈ 0.053）の重なりで 1.06 < L_U/λ < 3 の全域が衝突し、「滞留」の状態量・時間スケール・放出先が未定義、6 成分配分の閉合則がなく、Fr→1 は先送り。GPT・Gemini は不成立、Grok は条件付き）、§3 条件1。

- **単一の切替基準**： WKB 適用性の判定は ε_WKB = λ/(2πL_U) の単一の閾値で行う。閾値は ε_c = 0.15 と固定する（R2-11 の例示値を固定したものであり、新規の数値ではない）。ε_WKB < 0.15 の領域では WKB＋Airy/Pearcey 一様漸近を適用し、ε_WKB ≥ 0.15 の領域では波解像伝播へ切り替える。R2-11 の「L_U/λ ≲ 3 が面的に広がる場合は波解像伝播へ」という文は削除する。L_U/λ ≲ 1.06 は ε_WKB ≳ 0.15 と等価であり（1/(2π×0.15) = 1.06）、同じ単一基準の言い換えである。2つの異なる数値基準を並べない。
- **孤立と面的の定義**： Airy/Pearcey 一様漸近は孤立した単純転回点・焦線を仮定する。非 WKB 域（ε_WKB ≥ 0.15 の連結領域）の広がり（直径）が局所波長 λ 未満の場合は、その域内の転回点・焦線に Airy/Pearcey 一様漸近を適用する。広がりが λ 以上の場合は、その連結領域全体を波解像伝播で扱う（領域内で WKB と波解像を切り替えない）。広がりの測定は、ε_WKB の場から連結領域を抽出して行う。
- **「滞留」の定義（簿記としての貯蔵）**： 遮断点近傍に留まる作用は、状態量として捕捉作用密度 A_trap(x, y, t)（単位面積あたりの作用）で記録する。A_trap は貯蔵であり、シンクではない。その時間発展は収支式 ∂A_trap/∂t = F_in − F_out で与える。ここで F_in は遮断された光線管からの流入作用束、F_out は下記の配分先への流出作用束の合計である。滞留時間 τ_trap は入力定数ではなく、τ_trap = A_trap / F_out として定義する診断量とする（F_out = 0 の場合は τ_trap は未定義とし、無限大とは書かない）。
- **6 成分配分の閉合則**： 遮断された作用束 F_block は、次の6成分へ分解し、配分係数の合計を常に1とする：反射 F_refl、透過 F_trans、滞留への流入（∂A_trap/∂t への寄与）、散乱 F_scat、砕波 F_brk、乱流移送 F_turb。すなわち F_block = F_refl + F_trans + (∂A_trap/∂t の流入分) + F_scat + F_brk + F_turb。不可逆なシンクとして計上できるのは、移送先が定義され、作用または対応するエネルギー収支で確認できた F_brk と F_turb に限る（R2-11 の既定を維持）。反射・透過・散乱は保存的な移送であり、滞留は貯蔵である。各成分の流出先と評価方法は次のとおり：反射は U13 の岸境界条件（反射係数）から、透過は共通分散土台の分枝接続から、散乱は波解像伝播の散乱計算から、砕波は U2a の砕波散逸項から、乱流移送は U12 の乱流生成閉合から、それぞれ求める。配分係数が定まらない成分がある場合は、その成分を「未定」として記録し、F_block の配分合計が1になるまで U2b の最終閉合へ進まない。
- **Fr→1 の正則化**： 臨界条件は、採用する分散関係（有限水深・表面張力・流れ込み）に対する遮断条件、すなわち光線に沿う実験室系の群速度の法線成分がゼロになる条件とする。Fr はここでは流れのフルード数 U/c（c は対象波の位相速度）として定義し、Fr→1 は遮断条件の言い換えである。正則化は次のとおり：転回点では WKB 光線解を継続せず、Airy 型一様漸近で接続する。Airy の仮定（孤立した単純転回点）を満たさない場合（面的な非 WKB 域）は波解像伝播へ切り替える（上の単一切替基準と同じ規則を適用する）。正則化の支配方程式は、採用する分散関係を持つ波解像伝播（緩和緩勾配方程式／スペクトル結合ソルバ）または Airy 接続式とし、実装ブリーフで選択と接続手順を登録する。「別途特定」のままにしない。
- **検証**： U8b は、遮断点ごとに6成分の配分合計が1であること、A_trap の収支が閉じていること、ε_WKB の場から切替が上の規則どおりに再現できることを確認する。

#### R3-3 — 帯境界の無次元基準と三波参照・U5 一本化（R2-17・R2-25 を書き換える条文）

**置き換える対象**： 親 §6.4 R2-17（帯域境界・砕波形状の割当の項）および R2-25（砕波の形状変化オペレータの宣言と割当の項）。

**根拠**： 統合 §1 K4（3席一致の条件付き：帯境界を決める無次元基準がなく、R2-17 の「仮置き」と R2-25 の「要否宣言」の優先関係が一意でない。三波共鳴条件の参照（R2-7 の一般三波か R2-5 の 1:2 か）も未整備）、§3 条件1・条件3。

- **帯境界の無次元基準**： 重力帯・遷移帯・毛細帯の境界は、U3 で確定した環境パラメータ（温度依存の γ・ν・ρ、水深 H）と共通分散関係から場面ごとに決定する。境界を決める無次元数は次の2つとする。(a) 毛細波数 k_c = √(ρg/γ)（重力項 gk と毛細項 (γ/ρ)k³ が等しくなる波数。ℓ_c = √(γ/ρg) の逆数であり、U13 の ℓ_c ≈ 2.7 mm と同じ定義）。k < k_c を重力支配、k > k_c を毛細支配とし、k = k_c を重力‐毛細遷移帯の中心とする。(b) 有限水深パラメータ kH。kpH ≳ 3.5 はピーク付近の深水近似が良好となる目安であり（R2-17 の既定を維持）、高波数側の曲率・毛細波統計まで深水近似でよいことを意味しない（同上）。10–150 rad/m、250 rad/m 以上という値は、標準水条件（20°C、γ = 0.0728 N/m、ρ = 1000 kg/m³）における初期区分としてのみ保持し、全場面に共通する物理境界として扱わない（R2-17 の既定を維持）。場面の γ(T)・ρ・H が標準水条件と異なる場合は、k_c と kH を再計算して境界を決め直す。
- **三波共鳴条件の参照**： 三波共鳴条件を評価するときは、R2-7 の一般条件（採用する分散関係に対する周波数整合と波数ベクトル整合）を用いる。R2-5 の 1:2 は、Wilton 共鳴という特別な場合として参照する。R2-17 の「三波共鳴条件を満たさない帯域へ三波移送を適用しない」という文は、R2-7 の一般条件を指す。R2-7 の「三波移送 S_nl(3) を追加候補として評価する」と R2-5 の「1:2 共鳴として扱う」は、一般条件と特別な場合の関係であり、矛盾しない。
- **U5 一本化（R2-17 対 R2-25 の優先関係）**： 砕波の形状変化オペレータの要否と形式は、U2a で宣言する（R2-25）。R2-17 の「U5 へ仮置き」は、U2a の宣言までの暫定の置き場所であり、宣言が下りた時点で宣言に従う。要と宣言された場合は U5 で実装し（R2-17 の置き場所を確定とする）、U8b の検証対象に含める。否と宣言された場合は実装せず、「散逸のみで形状変化を近似しない」ことを明示し、その近似の誤差範囲を U8a の誤差予算に載せる（R2-25 の既定を維持）。U2a の宣言が下りる前に、R2-17 の仮置きを確定した仕様として扱ってはならない。
- **Δ_η,brk の扱い**： 微細砕波形状補正項 Δ_η,brk(x, y, t) は、U2a の宣言が「要」の場合に U5 の実装として置く。宣言が下りるまでの間は、Δ_η,brk は未定義の仮置き名として扱い、U5 の実装に含めない。

#### R3-4 — U14 の適用域・プロファイル固定・変形則（R2-1 を書き換える条文）

**置き換える対象**： 親 §6.4 R2-1（U14 の有限渦核半径・3強制の定義・第2段からの受け口の項）。

**根拠**： 統合 §1 K5（3席一致の条件付き：1/r² 発散そのものは Rankine 正則プロファイルと受け口定義で閉じたが、Rankine か Lamb–Oseen かの選択と r_c の決め方が実装ブリーフへ先送りで、η の値が一意に決まらない。外側解の適用条件（準定常・小振幅等）が未記載。boil ドーム・航跡傷は「定義せよ」という義務宣言だけで変形式がない）、§3 条件1。統合 §3 優先2の Grok P1「原文直接照合」は、正則プロファイルの原文ファイルでの直接照合で満たす（下記の検証を参照）。

- **プロファイルの固定**： 正則プロファイルは Rankine 渦に固定する。R2-1 の式（r < r_c：Δη(r) = −Γ²/(8π²g r_c²)·[2 − (r/r_c)²]、r ≥ r_c：−Γ²/(8π²g r²)）を採用式とする。Lamb–Oseen 渦は、実装ブリーフで明示的に登録された場合にのみ代替として許し、その場合は r = r_c での連続性と Γ の保存を Rankine と同じ検証項目で確認する。登録がない限り Rankine を使う。η の値は、プロファイル選択と r_c により一意に決まる。
- **r_c の決め方**： r_c は第2段の後流パラメータとして受け取る（R2-1 の既定を維持）。第2段は、障害物ごとに r_c の値を座標系と単位を明示して渡す。第1段は r_c を計算しない。r_c が供給されない障害物については、U14 の渦くぼみを適用せず、「未接続」として記録する（黙った既定値は使わない）。
- **適用域**： U14 の表面変形は、次の条件をすべて満たす場合にのみ適用する。(a) 準定常：後流渦の時間変化の時間スケールが、表面応答の時間スケール（対象帯域の波の周期 2π/ω）より十分長いこと。(b) 小振幅：|Δη| ≪ H（水深に対して小さい）かつ |Δη| ≪ λ（局所波長に対して小さい）こと。ここで Δη は U14 による表面変形の大きさ、H は局所水深、λ は対象帯域の局所波長とする。(c) 孤立渦：r_c が最寄りの他の渦・障害物までの距離より十分小さいこと。これらの条件を満たさない場合は、U14 の変形を適用せず、その理由とともに記録する。「十分」の判定は、U8b の検証で比率の実測値を報告し、適用可否を判定する（ここで数値の閾値を創作しない。比率の報告と判定は U8b の検証項目とする）。
- **boil ドームの変形則**： boil ドームは、湧昇のよどみ圧による表面上昇として表す。中心高さは η_boil(0) = W²/(2g)（W は第2段から受ける湧昇の中心鉛直速度、g は重力加速度）。水平形状はガウス型とし、η_boil(r, t) = (W(t)²/2g)·exp(−r²/(2L_boil²)) とする。ここで L_boil は第2段から受ける湧昇の水平スケール、r は湧昇中心からの水平距離、t は時刻とする。W(t) と L_boil は第2段の後流パラメータとして受け取り、第1段は計算しない。ガウス型は形状のモデリング選択であり、中心高さの W²/2g はよどみ圧からの導出である。
- **航跡の傷の変形則**： 航跡の傷は、障害物後方の航跡欠損に伴う表面のくぼみとして表す。障害物後方 x > 0（x は流れ方向の後方距離）において、η_scar(x, y, t) = −D(t)·exp(−y²/(2w(x)²))·exp(−x/L_decay) とする。ここで D(t) は中心線上のくぼみの深さ、w(x) は航跡の半幅（下流で広がる関数。第2段から受ける）、L_decay は下流方向の減衰長、y は航跡中心線からの横方向距離とする。D(t)、w(x)、L_decay は第2段の後流パラメータとして受け取り、第1段は計算しない。航跡の横方向の広がりと下流減衰の関数形は、それぞれガウス型と指数型に固定する。Kelvin 航跡の横波・発散波そのものは波動場の成分であり、U14 の平均表面変形には含めない。U14 が扱うのは航跡欠損による平均的な表面のくぼみのみとする。
- **3強制の検証**： U8b は、Rankine 断面との照合と Γ の保存に加え、boil ドームについては中心高さ W²/2g との照合、航跡の傷については第2段から受けた D・w・L_decay との照合を追加する。適用域の条件 (a)〜(c) については、適用した事例ごとに比率の実測値を報告する。

**2. 条件2の条文（K1・K6・K7・K8 の矛盾解消）**

#### R3-5 — 作用バランスのエネルギー率への統一（R2-4 と §6.1 C3′ を書き換える条文）

**置き換える対象**： 親 §6.4 R2-4（減衰側の分解の項）および §6.1 C3′（217行目）。
