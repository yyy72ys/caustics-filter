## STAGE 1 — Nikora 手順での測り直し

対象： パッチ床、帯状 r1、（同一性ゲート PASS なら）帯状 r2。方向は2つ（パッチは保存軸の x/y、帯状は流下＝長軸と横断）。

手順（固定。途中で変えない）：
1. 原フィールドそのまま（detrending なし）。2次構造関数の軸カット D(lx, 0) と D(0, ly) を 60-bin 対数ラダーで計算する。生成場は周期場であり np.roll の使用はその前提で正当（報告に明記）。軸カットの最大ラグはドメインの半分以下。
2. 折れの同定： log–log 上の2区間最小二乗フィット。折れ候補はラダー点のうち [0.25 × D50, 2 × D50] の範囲で総当たり（各区間4点以上）、総残差最小の折れを採る。同定した折れ（mm と ×D50）を報告する。
3. 報告する指数：
   - **H_Nikora**： [最小ラグ（格子間隔）, 折れ] への単一フィット（Hx / Hy 別記）。
   - **二帯域**： [最小ラグ, 折れ] と [折れ, 4 × D50] の2区間の傾き。
   - **感度**： 折れを ×0.8 / ×1.25（最近傍ラダー点）にずらしたときの H_Nikora の変化。使用した実ラグを numbers に残す。
   - **局所傾き**： H_loc(ℓ) の全ラダー値を numbers に残す。
4. あわせて記録： 各面の格子間隔（mm）、記録サイズ（×D50）、最小ラグの ×D50、σz / D50、歪度。

## STAGE 2 — 合成充填テスト（filleting の先行テスト）

対象： パッチ床のみ。事前予測（測定前に固定）： **δ = 0.5 σz の充填でも ΔH_fit ≤ +0.10**。

1. 充填面 F を priority-flood（窪地充填、Barnes 型・開境界）で計算する。充填後の面は z'(δ) = min(F, z + δ)、δ ∈ {0.25, 0.5, 0.75} × σz（σz は充填前の値）。
2. 各 δ について2つの物差しで測り直す： (a) 現行の固定帯 H_fit（run_v4_2_5.py verbatim、帯 0.4–3.6 cm）、(b) Nikora 手順の H_Nikora（折れは充填後の面で同定し直す）。
3. 報告： ΔH_fit(δ)、ΔH_Nikora(δ)、Δσz(δ)。予測との照合を明記する。
