### W2 — 製造用 RTE ソルバー：不成立（Gemini を採用。GPT・Grok の条件付きを覆す）

Gemini の不成立を親原文で裏取った。R2-5（161–171行）は「曲線光路上での決定論的解法（離散方向法）」と置くが、離散方向法は本来空間格子上で離散方向間の散乱源積分を解くオイラー的手法であり、「各光路に沿って方向別放射輝度を解く」とだけでは曲がって方向が連続変化する光線同士の再標本化・方向結合が未定義である。方向分割数・収束条件の事前登録は数値の先送りであって、輸送規則の定義ではない。さらに E(x,t) が循環する：R2-5（166行目）は E(x,t) を「製造ソルバーの出力」とし、R2-6（178行目）は E(x,t) を「3.2 の入力」とする。3.1 の出力は「E(x,t) の生成に使う集光情報」（177行目）であり、E(x,t) 自身が入力と出力の両方に立つ。切替え判定も不一致：R2-5（169行目）は「勾配スケールと光路長の比」の1指標、R2-7（184行目）は2指標（≥5 かつ鉛直層厚比 ≥5）で、鉛直層厚比が抜けている。加えて R2-5 には「置き換える対象」の明示が無く、参照も「§7 R2-7」（親に §7 は無く R2-7 は §6）と誤っている。「空間可変ハロのパラメータ」を何から抽出し v4-1.8 でどう畳み込むかも空白である。以上は文言の追加では閉じず、解法の数理定義そのものが要るため不成立とする。Grok の条件付きは短縮版審査で E(x,t) の循環まで読めていない点に留意する。

### W3 — MTT の適用条件＋仮想原点＋熱量収支：条件付き成立（3席一致）

閉じた点：R2-2（128–138行）が仮想原点 z₀ 付きスケーリング、適用域の判定入力の列挙、壁厚の独立化、熱量収支式と C10 感度検証を置いた。
残件：(1) z₀ の「代表半径相当」が非円形・複数・分布熱源で一意に決まらない。(2) 適用域の判定閾値が無い（成層抑制・乱流遷移・干渉を分ける数値基準が無く、代替モデルも未指定）。(3) 熱量収支式の次元・物理不整合。Gemini の指摘を採用する：Q_field = ∫ρc_p·ΔT dV は体積に蓄えられた熱エネルギー（J）であり、定常プルームの底入力は熱流束（W）である。R2-2（135行目）の |Q_field − Q_in| / Q_in ≤ ε_Q は、Q_in の積算時間と制御体積を定義しない限り計算できない。定常熱流束保存（鉛直対流熱流束 Q̇(z) = Q̇_in）または放熱込み時間積分への書き換えが要る。これは「設計の再考」に当たる。(4) C10 感度検証が dΔT/dz・db/dz のみで、GRIN 偏向を支配する水平勾配 ∇⊥ΔT（壁厚依存）への感度が無い。

### W4 — 界面・閉鎖の定量化：不成立（Gemini を採用。GPT・Grok の条件付きを覆す）

決定的なのは R2-3（148行目）の式である。「w_e = E(Ri)·ΔU は Ri>1 で E→0 になるため」と認めた上で「ΔU_eff を導入し、w_e = E(Ri)·ΔU_eff と書く」とするが、E(Ri) が 0 のままでは w_e = 0·ΔU_eff = 0 であり、ΔU_eff の関数形を決めても直らない。Ri を Ri_eff に再定義する記述も、風波混合を別項で足す記述も無い。Ri>1 の連行を原理的に出力できない式であり、文言では閉じない。(2) δ/λ ≤ 0.1 と「実厚さを解像できる格子」の併せ技：水中波長 λ ≈ 0.4–0.7 μm に対し δ ≤ 0.05 μm が階段近似の条件となり、実在の躍層（塩分拡散で 1 秒に δ ∼ 80 μm）はすべて階段から弾かれ、有限厚さ側では実厚さ解像の格子が強制される。Fresnel 反射の有無の基準と幾何光学ステップ近似の許容条件が混同されている。(3) (b) の曲率半径 R と画素サイズの比に閾値が無い。(4) k_field の較正先 3.4(c) が空振り：R2-4（152行目）は底加熱プルームの実測しか挙げておらず、3.3 の k_field・ΔU_eff を較正するデータ仕様が無い（参照も「§4 R2-4」と誤り）。
