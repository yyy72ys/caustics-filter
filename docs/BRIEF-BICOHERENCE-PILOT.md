# BRIEF-BICOHERENCE-PILOT — cf-0089 バイコヒーレンスのパイロット測定（案 C）

- 発注：2026-11-17（継続パトロール cf-0089 resume）
- 根拠：`delivery/phase-coupling/REPORT-PHASE-STATS.md` §7.3 の推奨（案 C）。cf-0085 の直後の次工程。
- 目的：現行生成器の場に 2 次束縛波の位相結合があるかを、バイコヒーレンス b(f_p, f_p) で測る。**測定そのものがこのジョブの仕事**（cf-0085 は測り方だけを決めて値を測っていない）。

## 入力（既存データのみ、新しい場の生成はしない）

- PC `offline\out\wave-groups-diag\probes-*.npz`（15 ファイル、3 条件 × 5 シード）。
- 各ファイル：256 プローブ × 192 サンプル、キー eta/gx/gy/lap/t。使うのは **eta（高さ）**。
- 条件とピーク：P1-WINDLANE（f_peak 1.0000 Hz、L=48 標本＝2 周期、記録あたりセグメント数 7）、P5-CLEAR（f_peak 1.8750 Hz、L=64＝5 周期、5 セグメント）、SWELL-1（f_peak 0.3750 Hz、L=64＝1 周期、5 セグメント）。
- **新しい場の生成は禁止**（生成器のコードに触れない、シードを増やさない、記録を延ばさない）。

## 推定器（案 C の仕様、§7.3 の手順通り）

1. 各記録・各プローブで、ピーク周期の整数倍長 L のセグメント（50% 重複、Hann 窓）で次を計算する：
   b = sum_s X_s(n)^2 conj(X_s(2n)) / sqrt(sum_s |X_s(n)|^4 · sum_s |X_s(2n)|^2)
   ここで n は**各記録自身のピークビン**（シードで動く。P1 は 1.0 Hz と 1.5 Hz が混在する）。
2. 統計量は |b| を 256 プローブ × 5 シードで平均したもの。条件ごとに 1 つの値。
3. 帰無分布：各周波数ビンで 256 プローブのクロススペクトル行列 S_pp'(n) を実測し、それを持つ複素ガウスを引いて位相結合だけを壊した代理記録を作る。**同じ統計量（256 プローブ × 5 シード平均の |b|）の分布を 2000 回分作る**。組み合わせ方はレポートに明記すること（シードごとに代理記録を作って同じ平均を取る形が筋）。
   - 実装上の注意：統計量に必要なのはビン n と 2n の 2 周波数だけなので、代理記録はその 2 ビンのクロススペクトル行列だけを保存すればよい。Cholesky 分解はビンごとに 1 回だけ行い、2000 回分はバッチで引くこと。
   - 代理データは 2 次（クロススペクトル）だけを保存し、4 次構造は保存しない。その限界はレポートに明記すること。
4. 床は代理分布の SD で定義する。実測値と帰無分布の差を、標準偏差何個分（z 値）かで報告する。

## 同一性ゲート（先に通すこと）

- N_eff を cf-0085 と同じ定義（トライアド積 X(n)^2·conj(X(2n)) のプローブ格子上の空間自己相関、正の相関だけを積分）で再計算し、cf-0085 の実測値（P1 26.0／P5 155.8／SWELL 148.7）と照合すること。許容 ±5%。外れたら止めて報告する（入力データの取り違えの疑い）。
- セグメント数と L が §7.1 の表と一致することを確認する（P1 7 セグメント／P5 5／SWELL 5）。

## レポートに必ず併記するもの

- 各記録で使ったピークビン（シードで動く：P1 は 1.0/1.5 Hz）。
- 代理データの |b| 分布（平均・SD・分位点）と実測値の並記。z 値。
- N_eff の実測値と、N_eff=1 の保守側の床（P1 0.088／P5 0.084／SWELL 0.093）の両方。
- 判定：条件ごとに「検出／不検出／判定不能（実測が帰無の 3σ 以内）／床が広すぎる（帰無 SD > 0.05）」のいずれかを明記する。
- ウェーブレット版（案 b）は間欠性の地図として併記してよい。主判定には使わない。

## フォールバックの判断（実行はしない）

- 帰無 SD が 0.05 を超える、または実測 |b| が帰無分布の 3σ 以内で判定できないときは、**案 a（49 記録まで増やす：P1 16／P5 15／SWELL 18 シード、推定 1.6 h）への格上げ判断をレポートに書くこと**。新しい場の生成を伴うので、このジョブでは実行しない。別途発注する。

## やってはいけないこと

- 代理データの帰無分布を出さずに |b| の絶対値を「検出」として引用する。
- 8 s 周期を保ったまま記録を延ばして自由度が増えたと主張する（同じ波形の繰り返し）。
- 既存の *.py を変更する（生成器・run_phase_stats.py を含む）。新しいスクリプト `run_bicoherence_pilot.py` だけを書く。
