問うこと：ε_ang ≤ 1% の根拠は十分か。ε_ang は B± 係数比の最大値（係数レベルの誤差）であり、Δm₂ ≤2% はスペクトル積分した増分の相対誤差である。第5回 C7 の Gemini の指摘は、まさにこの「別次元の誤差の加算」が問題だというものだった。R7 の根拠（「1% なら線を食い潰すことはない」）は、係数レベルの誤差と積分レベルの誤差の換算を裏付けているか、それとも同じ加算を別の形で繰り返していないか。U-1a の分離はきれいか（J0 の合格が角度依存の確定と誤読される余地は、本文のどこで塞いでいるか。U-1a 未閉鎖のまま試験 0 を回して J0 が通った場合、フェーズ1本採用判断以外の何かが J0 の合格だけで進んでしまわないか）。U-1a の照合仕様（Bredmose (2005) または Sharma & Dean (1981) の 2D 形との θ₁₂=30°, 60°, 90°, 135° での数値照合、ε_ang の定義）は、実行すれば一意に判定できる形になっているか。

### D6 — 最低条件 3：§2.6 項目 4 の Wilton 除外の一意化

R7 は §2.6 項目 4 の Wilton 除外を一意化した（R7 572行目）。相対離調の閾値は |ω₁±ω₂−ω(k₁±k₂)|/ω_± < 0.05 に固定する。ここで ω(k) は毛管重力の分散関係 ω(k) = √((g·k + (σ/ρ)·k³)·tanh(kh))（σ/ρ = 7.28e-5）であり、カーネルの純重力 ω ではない。共鳴判定の分散関係は毛管重力で一本化する（R6 は分母 ω(k±) の分散関係を明示しておらず、純重力と読む余地があった）。分離したペアの扱いは「除外＋寄与報告」とする：通常の QTF 評価（η₂ の場の計算）からは除外し、件数と m₂／m₄ への寄与を別途報告する。試験 0 の結果からは除外しない（報告に含め、合否の材料とする）。分母は max(|ω±|, ω(k±)) へ修正し、ω₋→0 でのゼロ除算を防ぐ。閾値 0.05 の感度（δ=0.04・0.05・0.06、応答増幅 約8.3〜12.5倍）は事前登録の手順として文書化した。合否が δ の選択で変わる場合は、試験 0 の合否は「閾値依存」として記録し、フェーズ1採用判断には使わない。分離ペアの m₂／m₄ への寄与が、対応する J0 の線（Δm₂ ≤2%・Δm₄ ≤7%）を超える場合は、試験 0 の合否は「Wilton 寄与依存」として記録し、フェーズ1採用判断には使わない（δ 感度と同じ扱い）。

問うこと：除外は本当に一意化されたか。「通常の QTF 評価（η₂ の場の計算）からは除外するが、試験 0 の結果からは除外しない」という二つの扱いは、試験 0 が比較する A（参照計算の直接二重和）と B（S1 の FFT 分離形）のどちらに掛かるのか。A と B で除外の扱いが違えば、試験 0 は除外の差を測ってしまうのではないか。分離ペアを S1 の場の積から除外する具体的な手順（3D (k, ω) 空間での (κ±, ω±) マスクを B にも適用する手順）は本文に書かれているか。第5回統合 C5 の条件が求めたのは、まさにこの手順の明記であった。共鳴判定の分散関係は毛管重力で一本化されたか（分母 max(|ω±|, ω(k±)) の ω(k±) は毛管重力か。本文の他の箇所で純重力の ω(k) が残っていないか）。「閾値依存」「Wilton 寄与依存」という記録は、合否の一意性を損なわないか（J0 の二値合否とは別に、第三の結果が復活していないか）。

### D7 — 最低条件 3：§5 の M=512 収束と帯域境界・Test B/E の ×2 規約

R7 は §5 の J2b に低・中・高波数帯の数値境界を追加した（R7 625行目）。低波数帯 k ≤ 30 rad/m、中波数帯 30 < k ≤ 100 rad/m、高波数帯 100 < k ≤ 240 rad/m。30 rad/m はピーク帯の上端（cf-0069 §8.1 で 10–30 rad/m 帯が m₀ の 87.8% を占める）、100 rad/m は k_QTF,max、240 rad/m は和波数の上限 2k_max である。ν_probe の M 収束を追加した：参照計算 A の ν_probe について A(512) と A(256) の差が |Δν| ≤ 0.005 以内、峰高 95% タイルの相対差が ≤5% 以内であること。満たさなければ M=1024 へ上げ、A(1024) と A(512) で同じ条件を確認する。§2.3 の M 収束条件（R7 424行目）にも帯域境界を追記した。`verify-2d-kernel.py` Test B/E の ×2 規約の取り違えは、§2.1 と §8.2 にスクリプト側の修正事項として登録した（R7 237行目）。スクリプト本体は凍結のため本改訂では書き換えない。試験 0 の実装ブリーフ（§8.2）には、照合の比較式として「Lambda2/h vs 2·h_s（2·h_d）」を必須と明記する。

問うこと：第5回統合 C4 の条件は、M 収束条件に J2b 指標として「ν_probe の差 ≤0.0025、峰高 95% タイル差 ≤2.5%」を追加することだった。R7 は |Δν| ≤ 0.005・峰高 95% タイル ≤5% を採用した。これは条件の半分の厳しさであり、J2b のゲート値そのもの（|ν−ν_ref| ≤ 0.005・峰高 95% タイル ≤5%）と等しい。収束条件がゲート値と等しいことに、余裕はあるか（A(512) と A(256) の差がゲート幅いっぱいまで許されると、参照計算 A 自体の安定性は担保されるか）。この緩和の根拠は本文に書かれているか。入力帯域の定義は一本化されたか（第5回 C4 の GPT の条件：「k≤100 で打ち切り」と「[100,120] テーパ」の併存）。J2b の Δ_ref 計算で、参照 A と本番 FFT の帯域内モード数差（M=512 は 1.5 m パッチの約 1,790 モードの約 29% しか含まない）によるバイアスが許容内であることを確認する規定は入ったか。Test B/E の ×2 規約は「スクリプト側の修正事項として登録」しただけで、スクリプト本体へのコメント・警告注記の追加も、×2 規約を反映した検証済みスクリプトの公式実行対象への明記も、まだ行われていない。第5回統合 C9 の条件はそのいずれかを求めていた。登録だけで C9 は閉じたと言えるか。将来の実行者が Test B/E を原文のまま実行して relerr 1.000 を見た場合、設計書 §8.1 の「G-C1-0 通過」と矛盾しないか。

### D8 — 優先順位 4：§10 のラリー引用照合規律

R7 は §10 に「ラリー引用の照合規律」を新設した（R7 808–814行目）。4 項からなる。(1) 引用は原文で照合する：確認ラリーの脚が引用する本書の式・数値は、統合時に本書の該当箇所（節番号・行番号）と直接照合する。引用が本書に存在しない式・数値である場合、その主張は「引用の誤り」として統合書に記録し、本文の不備とは分けない。例として、第4回で Gemini が引用した 2 式（R5 本文に不在）と、第5回で Gemini が引用した §2.6 項目 4 の末尾の逆文（R6 本文に不在）を記録した。(2) 判定は投票で決めない：脚の間で判定が割れた主張（特に数式の符号・係数の正誤）は、投票や多数決では決めない。決着は原文の直接読み・実コードの直接照合のみとする。例：C2 の pm 符号は `ref-sources/verify-s1-field.py` の直接照合で決着した。(3) プロンプト側の手続き：確認ラリーのプロンプトには、主張の根拠となる本書の箇所（節番号・行番号・引用文）を明記し、脚は引用箇所を原文で確認してから判定すること。引用箇所が確認できない主張は「引用未確認」として統合書に記録する。(4) ラリー記録は書き換えない：脚ファイル・統合書は着地後に書き換えない。引用の誤り・判定の訂正は、次改訂の草案と次回の統合書に記録する。

問うこと：規律は「必須」の手続きとして書かれているか、それとも推奨に留まるか。統合者（統合書を書く側）が脚の引用を原文と照合する義務は明記されているか（(1) は「統合時に照合する」と書いているが、照合しなかった場合の扱いはあるか）。「引用未確認」の主張はどう扱うか（判定の材料から外すのか、条件付きで残すのか）。この規律があれば、第4回・第5回の事故（存在しない式が統合の主因に据えられたこと）は再発しないか。§10 以外の箇所（§9 や今後のラリー手順）にも同じ規律が必要ではないか。

### D9 — 新出論点：C5 引用の誤りの記録と Wilton 一意化の当否

R7 は、Gemini の第5回 C5 の主張のうち「§2.6 項目 4 の末尾に『共鳴近傍ペアを試験 0 の結果から除外してはならない』と真逆の文がある」という引用は、R6 本文の再読では該当文が存在しないため、引用の誤りとして記録した（R7 572行目・814行目）。本文の真の不備として残っていたのは、「除外」の対象範囲の曖昧さと分散関係の未明示であり、本改訂で両方を一意化した、としている。資料 3 に R6 §2.6 項目 4 の原文抜粋（R6 563行目、全文）を付ける。所有チャットの grep 実測：R6 全文で「除外してはならない」を含む文は 1 件のみで、それは §2.3 の「分母が小さいことを理由に相対誤差の発散したケースを恣意的に除外してはならない」（R6 439行目）であり、共鳴近傍ペアに関する文ではない。「共鳴近傍ペアを試験」で始まる文も R6 には存在しない。

問うこと：資料 3 の原文抜粋を自分で読み、Gemini の引用した文が R6 §2.6 項目 4 に存在するかどうかを確認すること。存在しない場合、R7 の「引用の誤り」という記録は正しいか。存在する場合、R7 の記録は誤りであり、D6 の判定にどう影響するか。引用の当否とは別に、R7 の Wilton 除外の一意化（D6 の内容）は、物理的・仕様的に正しい選択か。R6 の「除外＋寄与報告」という記述だけでは、試験 0 を実行する実装者は何をすべきか決められなかったのか。R7 の一意化は、その曖昧さを本当に解消したか（D6 の問いと重なる部分は、D6 の判定を参照してよい）。
