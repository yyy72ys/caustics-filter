### E1 — 最低条件 1：Wilton の全ペア評価＋共鳴診断分離（方式 2）

R8 は §5 の J3' で λ₃,exact を定義し直した：「λ₃,exact は**2D 暫定採用カーネル（§2.1 の MF12 Lambda2）で、生成器と同一の離散スペクトル格子上で、独立ランダム位相の 400 本以上の実現について計算した λ₃ の標本平均（期待値）**である（R8 で定義し直し。CONFIRM6 D4）。中心値の標準誤差は σ_λ₃/√400 ≈ 0.05σ_λ₃ で、帯の半幅（2σ_λ₃/√5）の約 5.6% であり、帯の前提（中心は誤差を持たない）と矛盾しない。**1 シードの参照計算 A の λ₃ 実現値を λ₃,exact に流用してはならない**（その場合、中心自体が ±1σ の誤差を持ち、正しいモデルでも約 40% の確率で帯を外れる）」。σ_λ₃ は同一の MC 標本から出す（「この MC 標本は σ_λ₃ の推定に使う 400 本と同一の標本とし、その標本 SD が σ_λ₃ になる」）。独立性の記録は RNG 系列単位へ強化された（§5 の σ_λ₃ の求め方）：「独立性の記録は乱数系列単位とする。主走行 400 本と独立再現走行 400 本の RNG 系列（シード一覧）を併せて記録し、両走行の間で系列の重複がないことを確認する。重複が見つかった標本は独立標本として数えない。λ₃,exact の MC（σ と同一の標本）も同じ記録の対象とする」。15% 条件のブートストラップ確認が追加された：「15% 条件の誤判定率（正規近似で前半・後半 3.4%・独立再現 0.3%）は、400 本の λ₃ 標本からのブートストラップ再標本（リサンプル 10,000 回）でも確認する。σ̂ の再標本分布から前半・後半の差と独立再現の差の分布を直接作り、15% を外れる割合を実測の誤判定率として併記する。ブートストラップ側の誤判定率が正規近似と 2 倍を超えて食い違う場合は、正規近似の数値を根拠に使わず、ブートストラップ側を採用して記録する」。CI 幅条件の合否への接続が明記された：「σ の 95% CI の全幅が許容幅の 25% を超える場合は、σ 推定の精度不足で J3' の帯が確定しないため、**J3' は不合格（判定不能）として扱い、PASS にはしない**。一方、安定性条件（前半・後半 15%・独立再現 15%）を外れた場合は従来どおり「要調査」であって自動失敗ではないが、要調査のまま採用判断へ進む場合は、その旨を採用判断の材料として明記する」。§8.2 の出力 (c) にも「λ₃,exact と σ_λ₃（**同一の 400 本以上のモンテカルロ標本から出す**…**試験 0 の参照計算 A の 1 シード実現値は λ₃,exact に使わない（R8。CONFIRM6 D4）**）」と明記された。

### E5 — D5 の残件：U-1a の合格線と照合規定の精密化

R8 は §6 の U-1a で合否線と照合規定を精密化した。合否線：「合否線は **ε_ang < 10⁻¹²（G-C1-0 と同水準）** とする。規約の換算（B^± = 2h_s 等）は照合前に両側で揃え、換算で説明できない差は転記・導出の誤りとして扱う」。旧根拠は訂正された：「R7 の合否線 ε_ang ≤ 1% とその根拠（「ε_ang ≤1% なら J0 の Δm₂ ≤2% の線を食い潰さない」）は**訂正する**。Δm₂ は 2 次振幅の 2 乗に比例するため、係数 B± に相対誤差 ε があれば Δm₂ の相対誤差は約 2ε になり、ε = 1% は Δm₂ の線 2% を丸ごと食い潰し得る。旧根拠は係数レベルと積分レベルの換算を取り違えていた（Gemini の指摘）。また MF12 と Bredmose (2005)／Sharma & Dean (1981) は同一の 2 次理論の別表現であり、転記と規約換算が正しければ両者は機械精度で一致するはずである」。照合の試験格子は固定された：「θ₁₂ ∈ {30°, 60°, 90°, 135°}、(k₁, k₂) は k_p 基準の代表格子 {0.5, 0.7, 1.0, 1.4, 2.0}·k_p の順序なしペア 15 組（k_p は各水深の条件のピーク波数：h=0.6 では P1 の 4.02 rad/m、h=4.0 では P5 の 14.15 rad/m）、h ∈ {0.6, 4.0} m、pm は和・差の両方。計 4×15×2×2 = 240 点で測る」。ゼロ近傍での誤差定義も固定された：「B⁻ は交差角でゼロを跨ぐ（例：§2.1 (7) の dθ=π/2 で G− = −5.71e-02）ため、相対誤差の分母に |B_ref| をそのまま使うと発散する。誤差は ε = |B_MF12 − B_ref| / max(|B_ref|, B_floor) で測り、B_floor は同一 (k₁, k₂, h) における同方向（θ₁₂=0）の和周波係数 |B⁺| とする（ゼロを跨がない代表スケール）。B_floor も 0 になる退化点では絶対誤差 |B_MF12 − B_ref| で測る。ε_ang は全 240 点での ε の最大値とする」。あわせて「U-1a が通っても 2D 一般角形の「確定」は本人の採用判断による」と明記された。

(2005) の式 (59) H_{n,m} と (62) L_{n,m} は OCR で文字化けして信頼できる転記ができておらず（§6）、Sharma & Dean (1981) 原論文の方向形の直接の転記もしていない（§9）。

問うこと：(1) 合格線 < 10⁻¹² は妥当か。同一理論の別表現同士は機械精度で一致すべきという根拠は、照合相手の転記自体が未完である現状と矛盾しないか（転記誤差と理論間差異を ε_ang の 1 つの数値だけで区別できるか。区別できない場合、U-1a が落ちたときに何が起きるか——転記の直しに戻れる手続きは書かれているか）。(2) 試験格子 240 点は斜交角依存の誤差を拾うのに十分か。θ₁₂=45° の欠落、k 比が極端なペア（0.5·k_p と 2.0·k_p の組合せは 15 組に含まれる）の扱いはどうか。深水側（kh が大きい点）と浅水側の配分はどうか。(3) B_floor の定義（同方向の |B⁺|）はゼロ近傍の物差しとして妥当か。B_floor も 0 になる退化点では絶対誤差へ切り替えるが、絶対誤差の合否線（< 10⁻¹² と同じ物差しで測れるか）に規定がなくてよいか。

問うこと：(1) 誤記の訂正は意図どおりか（訂正後の文面「本文の不備と分けて記録する」に、別の読み違えの余地はないか）。(2) 照合パスの必須化は実行可能な手続きとして書けているか（誰が・いつ・何をもって「実行した」とするのか。照合の結果を統合書に記録する形式は十分か。照合パスを行わなかった統合書は「確定しない」とあるが、確定済みの統合書に後から照合漏れが見つかった場合の扱いは要らないか）。(3) 「引用未確認」を根拠から除外する規則は、引用の誤りへの対処として十分か。逆に、正しい指摘が引用箇所の特定に失敗しただけで根拠から落ちる副作用は許容できるか（その場合、指摘した脚が引用を直して再提出する経路はあるか）。この規律があれば、第4回・第5回の事故（存在しない式が統合の主因に据えられたこと）は再発しないか。

### E7 — 閉じられなかったものの扱い（§9）

R8 は §9 に、閉じられなかったものを明記した。Wilton 近傍応答の信頼性（R8 867行目）：「**Wilton 共鳴近傍の応答の信頼性は確立していない**（R8）。R8 は除外を撤回して全ペア評価としたため、近傍ペアの応答は場に含まれる。QTF 近似そのものが共鳴近傍で妥当かどうかは未検証であり、寄与依存の分類（§2.6 項目 4）が「Wilton 寄与依存」になった結果はフェーズ 1 採用判断に使わない。方式 1（ペア単位マスク保持）は桁落ちと (0,0) ビン処理の干渉のため採用しなかったが、この判断自体は確認ラリー第7回の検証対象である」。3D FFT の計算量（R8 868行目）：「**3D FFT の計算量は依然として推測である**（R8）。§2.2.4 の見積もりは前提を 128²×192 の一括評価へ整合させたが、実測は最初の 1 記録（J7）まで無い」。λ₃,exact の MC の前提（§9）：「**λ₃,exact の MC は M=512・同一格子を前提とする**（R8）。中心値のモード集合・格子への依存は、J2b のモード数差バイアス確認（§5）とは別に、J3' では MC と測定が同じ格子・同じモード集合を共有することで相殺する設計である。この相殺が成り立つのは「同じ離散モデル同士の比較」としてであり、連続スペクトルへの外挿を保証しない」。U-1a は未決のままである（§6・§9）：「U-1a が閉じなくても試験 0 は進むが、試験 0 が通っただけでは 2D 一般角形は確定しない」「U-1a が通っても 2D 一般角形の「確定」は本人の採用判断による」。§8.3 には「U-1a（Bredmose (59)/(62) の転記＋斜交角照合）が完了するまで、2D 一般角形を「確定」と呼ばず「暫定採用」として扱い、試験 0 の通過を 2D 一般角形の確定と呼ばない」が引き継がれた。

問うこと：これらを抱えたまま、R8 を「P5 の QTF 帯域内比較を行う試験 0 の採用判断にかけられる状態」と言えるか。特に：(1) Wilton 近傍応答の信頼性が未確立のまま全ペア評価にしたことで、J0・J2b の数値が近傍応答に支配される可能性を、寄与依存の分類（E1）だけで事後に捕捉できるか。捕捉できない場合、試験 0 の結果の解釈に何の留保が要るか。(2) 計算量が推測のままであることは、仕様の確定性とは別の問題として切り分けられるか（J7 で最初の 1 記録の壁時間を実測し、5 シード分の見込みが 2 時間を超えれば止めて報告する契約は §5 に既にある）。(3) U-1a が未決のままであることは、「暫定採用」の枠内での試験 0 の採用判断と矛盾しないか。矛盾しないとすれば、その境界（何が決まっていて何が決まっていないか）は本文のどこで読めるか。

## 回答形式（厳守）

- 最初に最終裁定を 1 行で書くこと：**採用判断にかけられる状態** か **差し戻し** か（意味は「役割」に書いた限定付きの採用判断である）。
- 次に主張 E1–E7 ごとに、判定（**成立／条件付き成立／不成立** のいずれか 1 つ）、最も強い反論、通るための条件、失敗条件を書くこと。
- 次に直しの優先順位（最も急ぐものから）を書くこと。
- 最後に、採用判断にかけられる状態になるための最低限閉じるべき条件を 3 つ以内で書くこと。
- 反論には必ず、草案のどの箇所（節番号・行番号・数値）が問題かを具体的に示すこと。引用する式・数値は資料の原文で照合した上で使うこと。照合できない引用は「引用未確認」と明記すること。数値の誤りを見つけたら、訂正値を計算して示すこと。
- 「未実行だから不成立」とは判定しないこと。問題は、測定を実行しても結果を一意に合否へ変換できない箇所が残っているかどうかである。
- 回答が途中で切れたら、同スレッドで続きを要求して補完すること。
