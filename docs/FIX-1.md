## 修正点 (実測スクリーンショット moth-preset1.png / moth-preset0.png に基づく)
1. **ハイライトの白飛び** (最優先)
   - コースティクス+グリッターが純白にクリップされ、広い面積で白抜けする。
     リファレンス(ref1/ref2)は光の網目が明るくても像が読める。
   - 対策: 最終出力にソフトなハイライトロールオフ(フィルム調トーンマップ、
     例: col = 1 - exp(-col * k) 系)を入れる。
     併せて env.js のコースティクス倍率 1.5 → 0.9 程度へ、
     shader.js のグリッター core 3.0 → 1.5 程度へ下げる。
     太陽・雲・濁りとの連動の仕組みは変えないこと。
2. **網目の粗さ・斜めの筋**
   - 網目が太い斜めの筋/破片状に見える。リファレンスは細かく均一な網目。
   - 対策: causticField の周波数を上げる(約1.5倍)、第2フィールドの向きを
     変えるなどして斜め方向への偏りを弱め、像の読みやすさを上げる。
     屈折の揺らぎ自体は現状でよい。
3. **favicon 404**
   - index.html に `<link rel="icon" href="data:,">` を追加し、
     コンソールエラーがゼロになるようにする。
