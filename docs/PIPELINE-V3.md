# パイプライン v3 brief（合成調整ラウンド — 輸送と状態は凍結）

前提：`docs/OUTPUT-SPEC.md`、`docs/PIPELINE-V2.md`。v2 のマスター（`offline/out/v2/C-t0.npy`、flow、metadata）とコードを再利用する。**状態生成と輸送は変更しない**。今回いじるのは像形成（image.py の合成段）だけ。

## 直す問題（v2 プレビューの実測所見）
1. **全体の暗さ**：環境光（E_amb＋水中散乱）が弱く、影部が潰れている。
2. **揺らぎの微細破砕**：写真（アルベド）のサンプリング変位に水面状態の高周波成分まで入っていて、樹皮のテクスチャが画素単位に千切れた「くしゃくしゃの箔」状になる。物理的には、目に見える屈折変位は水面の大きな勾配が支配し、微細法線は主にグリッター側に効く。変位に使う状態は帯域制限できるはず。

## やること：バリアント行列で測って選ぶ
プリセット1・t=0 の静止画で、次を振った 6 バリアントを作る：
- **環境光スケール A**：現行 ×1 / ×1.7 / ×2.6（E_amb と in-scatter の加算項にのみ掛ける。直接光項 E_base_dir×C は不変）
- **変位の帯域制限 B**：現行（全帯域） / ローパス（状態の高度・勾配を σ≈3px（2048²グリッド上）で平滑してから変位を計算）
各バリアントで次を測って numbers-v3.json に残す：
- トーンマップ前の線形平均
- 潰れ率（線形値 <0.02 の画素割合）と飛び率（ACES 後 >0.98 の割合）
- **破砕メトリクス**：揺らぎサンプリング後の写真と原写真の高周波エネルギー比（Laplacian エネルギーの比）。1.0 に近いほど千切れていない
- 実行時間
