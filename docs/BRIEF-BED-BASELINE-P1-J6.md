## 2. P1 — 無次元ラグでの再計測

- **問い**：d50 と H_loc の相関 r=0.89 が、固定物理ラグ窓 4–36 mm によるスケール・エイリアシングの錯覚かどうか。
- **手順**：各面について、ラグ ℓ をその面の d50 で割った無次元ラグ ℓ/d50 で H_loc を再計測する。帯は ℓ/d50 ∈ [0.25, 1.50]。x／y 方向別。cf-0081 の手順（構造関数ラダー S(ℓ) と H_loc(ℓ)=0.5·dlnS/dlnd）を無次元軸に置き換えただけのものである。無次元帯平均と d50 の相関 r を測る。
- **変数の優先順位（計算の前に決めること。E の自由度は最大 2 個、N=13）**：第 1 に d50、第 2 に選別度 d84/d50、第 3 に Qc。この順序でモデル比較を行う。順序を計算後に変えてはいけない。
- **決着規則（計算の前に事前登録すること。レポートの §2 冒頭に規則を書き、その後に数値を置くこと）**：
  - |r| < 0.3 → 錯覚確定。d50 は共変量のまま主軸には戻さない。
  - 0.3 ≤ |r| < 0.5（グレーゾーン）→ 信頼区間・leave-one-out・共変量モデル比較で決める。95% 信頼区間が 0 を含む、または leave-one-out の r の範囲が 0.3 を跨ぐなら「決着せず、d50 は共変量のまま」とする。
  - |r| ≥ 0.5 かつ 95% 信頼区間が 0.3 を含まない → d50 の寄与は実在と読む。ただしそれでも因果ではなく共変量のまま扱う。
  - **二分法（|r|<0.3＝錯覚確定／|r|≥0.5＝寄与実在）は採用不可**。グレーゾーンの決着規則なしに判定してはいけない。相関が残っても独立寄与とは言えない。
- **報告するもの**：r（x／y 別）、95% 信頼区間（Fisher z 変換またはブートストラップ）、leave-one-out の r の一覧と範囲、共変量モデル比較の表（d50 単独／d50＋選別度／d50＋Qc の 3 モデル。過剰適合の危険を明記すること）。
