## 絵コンテ（固定・v1.3で時系列を再定義）

時系列の嘘を消す（2者ラリー両席の一致指摘）：順序は「設定→計算→検査」。操作の意味は「今その場で計算する」ではなく「**実計算済みの条件を選んで読み込み、結果を検査する**」と定義する。画面のラベルもこの意味に合わせる（SELECT / LOAD / INSPECT 系）。操作は背骨として残すが、系統は「深さの選択」と「層の切替」の2つに絞り、各状態に最低約1.2秒の観察時間を確保する。起動アニメーションとカーソル移動は置かない（ラリーの削除指定）。

| 時刻 | 画面と操作 | 役割 |
|---|---|---|
| 0–1.2s | **設定と計算**：条件表示（U=6 / F=100 / z=4.0）が静かに揃い、計算の証拠（実ログの反復・残差の要約）が短く進んで確定する。分割表示：左＝高さ場、右＝最終画（同じ動き）。宣言タイポ「この水は、撮影なし。水なし。コードだけ」（対象は波だと明示） | フック＋証拠＋計算は結果の前 |
| 1.2–3.0s | **層の切替（検査）**：FINAL / CAUSTICS / WARP / 素 を切り替えて見せる（ラベル付き、1段ずつ観察できる速さで） | 仕組みの地図 |
| 3.0–5.5s | **深さの選択＝山場**：深さセレクタを 0.6→1.0→2.0→4.0 へ切り替えるたび、計算済みの結果が読み込まれ、模様が従って変わる（素材B）。実断面波形は固定スケール（自動拡縮禁止）でこの区間だけ併記 | 因果＋操作感の核 |
| 5.5–6.5s | **主役の数字**：実測ワープ量を測定対象ラベル付きで大きく出す（例：MAX DISPLACEMENT — ○○ px／frame 96 実測）。2秒以上保持の原則はこの提示に集約 | 数値の証拠 |
| 6.5–8.0s | **手を離す**：操作UIが退場し、綺麗なループが残る。小さく出自署名だけ残す：「PHYSICS SIMULATED — PERIODIC 2.00s」 | 解決＋ループ |

## 操作感の設計（v1.3で意味を再定義）

- 操作の意味は「選択・読込・検査」。「今リアルタイムに計算している」という演出はしない（数値も画像も本物でも、因果だけが演技になる状態を禁止する＝ラリーの核心指摘）。
- 操作するのは**実在のパラメータだけ**：深さの選択と層の切替の2系統。目盛りは実プリセット値（0.6 / 1.0 / 2.0 / 4.0 m）だけ。存在しない値・機能の操作は作らない。
- 操作には必ず**応答**を付ける：選択→結果が読み込まれて模様が変わる、切替→層が替わる。応答のない操作モーションは飾りとして禁止。
- 起動アニメーションとカーソル移動は置かない。操作UIは静かに現れて、選ぶ・切り替える動きだけを見せる。
- 操作音：選択の確定音と切替音のみ。実イベントにだけ付け、小さく短く（下記「音」）。
- 2秒ループ版では操作は入れない（ループは「手を離した後の水」が本体）。ただし2秒版にも出自署名の最小表示は入れる（単体で流れても「撮っただけ」に戻らないため）。

2秒ループ版は素材Aの最終画＋最小HUD（宣言1行と実数値のみ、全て (t mod 2.0) の周期関数）。

## HUD正本（制作前にファイル化する）

- 数字は等幅（tabular）、フォントは @font-face で同梱。色は白＋アクセント1色まで。
- 常設は**2要素まで**（v1.3で削減）：現在の物理条件1行＋主役の実測ワープ量。同時に動くのは1系統だけ。中央は空ける。
- 主役の数字は1つだけ：**実測ワープ量**。必ず測定対象のラベルを併記する（何の変位か・単位・最大か平均か・対象フレーム）。ラベルなしの大きな数字は証拠でなく装飾になる（ラリー指摘）。ラベルの正確さも台帳照合の対象にする。
- 禁止：何も追跡しない回転レティクル、ランダム文字列スクロール、水面上のレーダー、追加の平滑化（ぼけ主因＝Blow σ3 の上に重ねない）、フェイク数値、「ボタンで出た」演出、量の自慢の数字。
- 数値の出所：ワープ量は v19 の numbers（frame 96 の transport 実測、mean/p99）か、プロモ素材での再実測。風速・フェッチ・深さはプリセット実値。計算の証拠は実ログの反復回数・残差の要約のみ。**出所を台帳に書けない数字は画面に出さない。**

## 音（v1.4で本格設計。目標は映画の予告編級）

音は4層で設計する。全層とも「実在の場面に対応する音」だけを使い、出所は数字と同じく台帳（numbers-promo.json の音源欄）に記録する。音源は自前生成・自前合成・ライセンス確認済み素材のみ。

1. **BGM（音楽の層）**：器楽のみ。ACE-Step 1.5 のローカル生成を第一候補（固定シード、PC側の既存スタック）。性格は「静かな緊張感のあるミニマルなピアノ＋弦」系を叩き台に、8秒の弧（設定→検査→山場→解放）に合わせて盛衰を付ける。レベルは他の層の邪魔をしない下地（目安：主役の提示音より −20dB 前後）。最終ミックスの狙いは −14 LUFS 前後（図書館のジャンル実測）。
2. **波の音（主役の環境音）**：波のループ区間（6.5–8.0s と2秒ループ版）は水の音を主役にする。小さな池の水際の音（ちゃぷん、という軽い水音の繰り返し）。映像の波と喧嘩しないよう、強い波涛でなく水際の音にする。音もループで閉じる：水音はノイズ性なのでクロスフェードで継ぎ目を消せる（映像の網模様とは別扱い。網の二重像はぼけになるが、水音の重なりは自然）。
3. **虫の音（場所の層）**：後ろに薄く、夕方〜夜の池の虫の音（鈴虫・コオロギ系）を敷く。プロジェクトの主題（地球環境・実在の池）に対して「場所」を与える層。レベルは「意識すれば聞こえる」程度に抑え、全編を通す。季節感はプリセットの場面（小さな池・そよ風）と矛盾させない。
4. **機械の操作音（操作の層）**：選択の確定・層の切替・セレクタの移動に、重みのある機械音を付ける。安い電子音（ピッ）は禁止（ラリー席の「おもちゃ感」警告）。スイッチのカチッ、ダイヤルの目盛りのコツッ、という実物感のある音を、自前合成か実録系素材で作る。ピーク −12〜−20dB、100〜300ms。音も「実イベントにだけ」の原則は維持する。

区間ごとの音の弧：
- 0–1.2s：BGMの入り＋機械音（設定の確定）。虫の音は最初から薄く敷く。
- 1.2–5.5s：操作音と切替音が主役。BGMは下地。水の音はまだ入れない（水は「結果」側の音）。
- 5.5–6.5s：主役数字の提示に合わせて、BGMと低音の膨らみを1回だけ置く（予告編の「ドン」に相当する見せ場はここだけ）。
- 6.5–8.0s：操作音が消え、波の音＋虫の音＋BGMの尾だけが残る。「手を離した」ことが音でも分かる形にする。

ゲート連動：2秒ループ版は音もループで閉じること（波の音のクロスフェード継ぎ目を実測で確認）。8秒版の末尾は無音でなく環境音（波＋虫）で終わるため、旧「末尾無音」ゲートはループ版の音継ぎ目ゲートに置き換える。

## 組み立て（主軸スタック：Nano Banana × HyperFrames）

制作スタックの主軸はこの2つの組み合わせ（本人所感 2026-11-16「強そう」）。役割分担：HyperFrames＝決定論の精度（フレーム正確・数字が崩れない・(t mod 2.0) でループを構造保証）、Nano Banana＝質感の厚み（コードだけだと無機質になる部分の下地）。生成動画（Flow/Veo）が弱い「継ぎ目の保証」と「数字の正確さ」をコード側が担い、コードが弱い「有機的な質感」を画像生成が担う。

- 全アニメは登録タイムライン `tl` 上に置き、要素は「時刻 t の純粋関数」で書く。HUD要素を (t mod 2.0) の関数にすれば、2秒周期が構造で保証される。
- GSAP等はローカル同梱（CDN失敗で静止画化する事故の前例）。提出前に `npm run check` 0エラー＋snapshot目視。終了コードでなく実物で判定。
- Flow／Veo は使わない（無料枠は他部屋優先の決定済み。ループの核は決定論コードに固定）。
- **Nano Banana（無料 Lite）は補助として使用可**（本人許可 2026-11-16）。ただし「画像です！」という感じは出さない。使用箇所と禁止箇所は v1.2 で固定する：
  - 使用可：コンソール筐体の質感・背景の下地、操作UIの素材感（金属・ガラス等のテクスチャ）、投稿用カバー／サムネイルの下地、宣言タイポの背景処理。
  - 禁止：水そのもの、ループの核、証拠として見せる層（高さ場・ワープ・コースティクス単体）、数字や文字そのものの生成（文字は HyperFrames で組む。生成画像の文字は崩れるため）。
  - 判定基準：その部分だけ見て「生成画像だ」と分かるものは使わない。質感として溶けていること。
  - 対象範囲の明記（v1.3）：「コードだけ」の主張は波（水の生成）についてだけであり、動画の演出・質感は対象外（本人裁定）。だから Nano Banana の使用は宣言と矛盾しない。ただし筐体や背景に、実在ソフトの画面や実機だと誤認させる要素（偽ロゴ・架空の実機表示）は入れない（GPT席の条件）。筐体は抽象的な操作パネルとして作る。
