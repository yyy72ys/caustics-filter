## 問い

### 審査の前提

- 大原則: 自然を再現する。「それっぽい」は却下。数値手法・物差しが許容されるのは、(a) 中立な数値（同じ計算の誤差の形だけを変える）か、(b) 実在の物理に対応する場合のみである。物差しを甘くして通すための設計は、それ自体が不成立の理由になる。メモもこの原則を自らに課している（メモ冒頭 3–5 行目）。審査は、メモが自ら課した原則にメモ自身が従っているかを見る。
- 「デジタルな物差し」の定義はメモ §2（44–53 行目）: (i) 判定量が整数のカウント（または整数から作る量）である、(ii) そのカウントが指す対象が格子の切り方に依らない物理的な集合・事象である、(iii) PASS/FAIL が有限の回数の有限の計算で決まる、(iv) 閾値を甘くして通すのではなく、測る対象の変更を明示する。候補の審査はこの4要件への適合でも行うこと。

#### K1 — 候補 D1〜D4 の物理的根拠は本物か

メモは次の通り主張する: D1（超過面積カウント、§3 D1、56–63 行目）の根拠 (b) は「『床のうち、平均の T 倍より明るい面積がどれだけあるか』は実在の観測量である（検出器の画素が数える量そのもの）。fold 近傍で {C > T} の面積は、強度が d^(−1/2) で発散しても有限に定まる（発散点の近傍の測度は有限）。モーメントではなく集合の測度なので、§1.3 の特異性の問題を受けない。これは実在の物理に対応する物差しであり、数値的に中立でもある」。D2（固定ビンのカウント移動量、64–71 行目）の根拠 (b) は「分布の弱収束はモーメントの収束より弱い条件で成り立ち、fold 特異性を持つ分布でも有限の測度として定まる」。D3（折り重なりカウント、72–79 行目）の根拠 (b) は「折り返しはコースティクスシートそのものの幾何であり、水面場と幾何だけで決まる対象である。強度モーメントを経由しないので特異性の問題を受けない」。D4（保存台帳、80–87 行目）の根拠 (b) は「エネルギー保存は実在の物理そのもの」。

争点:
(i) D1 の測度の有限性: 強度が fold からの距離 d に対して d^(−1/2) で発散するとき、{C > T} の面積が有限に定まるという主張は正しいか。C > T の領域は fold 線から幅 ~T^(−2) の帯であり、その面積は T に対してどう振る舞うか。有限であることと、格子の切り方に依らず定まることは同じではない。画素化（736 × 540 への堆積と量子化）の段階で測度はどう変わるか。
(ii) D2 の弱収束の主張: 「分布の弱収束はモーメントの収束より弱い条件で成り立つ」は数学的には正しいが、本件で必要なのは弱収束そのものではなく「到達可能な 2 格子（1024² と 2048²）の間でビンカウントが実際に近い値に定まる」ことである。弱収束の存在は段間差が小さいことを保証しない。メモの主張はこの飛躍を埋めているか、それとも存在定理を実測の安定性の根拠に流用しているか。
(iii) D3 の対象のずれ: D3 が測るのは水面側の折り目幾何であり、床に届く明るさの分布ではない。メモ自身も §4 比較表で「G-CONV との対象のずれ: 大」と認めている。対象が大きくずれる候補を「G-CONV の代替候補」として並べ、§5 で補助監査に回す構成は正直か。それとも代替の見かけを作る混ぜ物か。
(iv) D4 の位置づけ: D4 は既に G-ENERGY として PASS している既存ゲートの再掲であり、新しい物差しではない。メモは「単独では G-CONV の代替にならない」「土台の監査」と明記している（86–87 行目）。候補として数えること自体が候補の水増しになっていないか。
(v) 中立性の主張: D1 (b) の「数値的に中立でもある（計算方法ではなく測る対象の変更）」は、大原則の分類 (a) 中立な数値／(b) 実在の物理、のどちらに依拠する主張か。測る対象の変更は (a) ではない。メモは (b) で立つべきところを (a) の言葉でも支えようとしていないか。

#### K2 — 判定は本当に有限の計算で厳密に決まるか

メモは次の通り主張する: D1 の有限性 (d)（62 行目）は「2 つの格子でカウントを取り、差が事前登録した個数幅（案: 全画素の ±0.5% = ±1,987 画素）以内なら PASS。整数の引き算 1 回で決まる」。D2 の有限性 (d)（70 行目）は「移動画素数が事前登録した上限（案: 全画素の 1% = 3,974 画素）以下なら PASS、という整数判定。2 回の有限計算で決まる」。D3 の有限性 (d)（78 行目）は「セル数は有限で、場が解像されれば折り返し集合は幾何として安定し、カウントの段間差は有限計算で決まる。連結成分数は整数の完全一致まで要求できる可能性がある」。D4 の有限性 (d)（86 行目）は「1 回の計算で決まる」。

争点:
(i) 算術照合: 全画素数 736 × 540 = 397,440 に対し、±0.5% は 1,987.2 画素、1% は 3,974.4 画素である。メモの ±1,987／3,974 は切り捨てであり、整数でない幅を整数に丸める規則（切り捨て／切り上げ／四捨五入）は判定の厳しさを変える。この丸めは本文で固定されているか。幅の定義が「案」の段階であることをもって未固定とすべきか、それとも §7 の事前登録で固定される前提で閉じていると言えるか。
(ii) D2 の判定量の整数性: 移動画素数 = (1/2) Σ |count_細 − count_粗| は、両格子の総画素数が等しい（どちらも 397,440）ため Σ の符号つき差が 0 になり、|差| の合計は偶数になるので整数になる。この理屈は正しいか。総画素数が等しくない比較（例: 出力格子を変えた比較）では破れるが、本設計の比較は出力格子固定か。本文から一意に読み取れるか。
(iii) 境界画素の揺れ: D1 (e)（63 行目）は「T の境界近くの画素は格子で出入りするため、カウントには境界分の揺れが残る（個数幅はこの揺れより大きく、かつ物理的に意味のある幅でなければならない）」と認めている。揺れの大きさは未実測である。揺れが幅より大きい可能性を排除できない段階で、「判定が厳密に決まる」は言えるか。メモ §7 の手順（初回は判定ではなく実測として段間差を取る）はこの未確定さを正しく扱っているか。
(iv) D3 の連結成分数: メモ (e)（79 行目）は「折り目の合体・分離が起きる境界条件では連結成分数が跳ぶことがある」と認めながら、(d) では「整数の完全一致まで要求できる可能性がある」と書く。跳ぶ量に完全一致を要求する設計は、G-CONV と同じ「判定が返らない」構造を別対象で再演しないか。
(v) D4 の実数性: D4 の判定量には相対誤差（実数）が含まれ、上限 1e-9 との比較は連続量への閾値当てである。要件 (i)「判定量が整数」に D4 は適合しないのではないか。メモは D4 を「整数監査＋固定上限」と併記で扱っているが、これは要件の緩和を無断でしていないか。

#### K3 — 測る対象の変更（モーメント→測度）は正当か。保証の切り分けは正直か

メモは次の通り主張する: §6（113–118 行目）「D1/D2 が PASS しても、『C の std がいくつか』には答えられない。std という量は、少なくとも現在の幾何光学モデルと到達可能な格子の範囲では、自然の側に格子に依らない値を持たない疑いが強い」「カウントの幅はすべて案であり、実測の段間差を見てから事前登録する性質のものである」「『デジタル』であることは正しさの保証ではない」。§5 理由1（107 行目）「G-CONV が本来保証しようとしたのは『C の水準・分布が格子に依らないこと』であり、D2 はその分布をモーメントではなく測度（カウント）で測り直す、対象のずれが最小の置き換えである」。

争点:
(i) G-CONV の保証対象の読み: G-CONV が保証しようとしたものは「分布全体の格子非依存」か、それとも「std・p99 という特定の統計量の格子非依存」か。前者と読めば D2 は同じ対象の測り直し、後者と読めば対象のすり替えである。一次資料（v4-1.15 §5 の定義）からどちらの読みが正しいか。

(i) ビン境界の恣意性: D2 (e)（71 行目）は「ビン境界の置き方に恣意性が残る（事前登録と、境界をずらした感度確認で対処する）」とする。感度確認は §7 の手順に明記されていない。境界をずらすと合否が変わる設計は、境界の置き方自体が新しい「アナログな自由度」にならないか。感度確認を手順に組み込むべきではないか。
(ii) 空間配置の不在: D1・D2 とも柄の空間配置（どこが明るいか）を見ない。分布が一致しても柄が全く違う場が PASS し得る。G-CONV も空間配置は見ていなかった（std・p99 は空間情報を捨てる）ので、これは置き換えで新たに失うものではない、という読みは正しいか。
(iii) 幅の順序の自己矛盾: §6 は「結果を見てから幅を決める手順を踏むと、それは物差しを甘くする行為になる。§7 の手順はこの順序を守るためにある」と書く。しかし §7 の手順2は「数表を見て個数幅を決め」るのであり、実測の段間差を見た後に幅を決める点では「結果を見てから決める」ことと紙一重ではないか。両者を分けるものは「段間差そのものではなく、境界画素の揺れの大きさと物理的な意味から決める」という規律だけだが、その規律は検証可能か。幅が段間差より小さく出た場合（実測が幅の案を超えた場合）の扱いは手順に書かれているか。
(iv) 校正の向き: 手順4の対比枠の校正は「新物差しが旧 PASS 条件で PASS に倒れる」ことの確認である。逆向き（新物差しが対比枠で FAIL した場合）に何が言えるか、校正が失敗した場合の手順はあるか。
(v) 実行可能性: 実測段は 1024² と 2048² の 48 フレームの C 場の取り直しを要する。高速堆積（transport_mesh_fast、ビット一致実証済み）で到達可能な範囲か（メモ §5 理由3は「48 フレーム数分〜1 時間級」と見積もる）。この見積もりは一次資料の速度実測（v4-1-16: 1024² で 17.60 s/フレーム級、v4-1-17 の 2048² の実測）と整合するか。

#### K6 — 最終主張: この設計で段の次（直し→確認）へ進めるか

K1–K5 を踏まえ、本メモの設計は「直し（メモの改訂）→確認ラリー」の段へ進める状態か。進めない箇所が残る場合、それは文面を書けば直る類か、設計の再考が要る類かを区別すること。あわせて、次段で最低限閉じるべき条件を検証可能な形で挙げること。なお、本ラリーの「進める」は採用ではない。採用判断は確認ラリーの後に本人が行う。
