# 修正指示 FIX-3 (FIX-2 の実ブラウザ照合で見つけた3点)

方針は FIX-2 のまま (環境→水の状態→光の輸送→像)。因果の向きは崩さない。
以下はメイン側が実ブラウザで撮影した moth-preset1.png / 書き出しPNG の実測所見。

## 欠陥1: 全面に規則的なドット格子が出る (最優先)
- プリセット0 (真夏の沖縄・正午) の書き出しPNGで、画面全体に
  ハーフトーンのような等間隔の点格子が乗る。自然界にあり得ない規則性。
- 容疑: 微細法線グリッターのサンプリング、またはヤコビアン有限差分の
  格子間隔 (eps) がそのまま模様として見えている。
- 対策: サンプリング位置にノイズでジッタを入れる / eps を広げる /
  グリッターは格子に整列した成分ではなく画素ごとの確率的な
  きらめきとして出す。**規則的な格子・縞が一切見えないこと**が条件。

## 欠陥2: プリセット1 (緑の川の浅瀬・午前) で網目がほぼ見えない
- 屈折の揺らぎは効いているが、集光の網目が弱すぎて
  「ほぼ元の写真」に見える。リファレンスは網目がはっきり主役級に光る。
- 対策: 密度のコントラストを上げる (例: 密度への冪カーブ、
  平均への引き戻しを弱める、水深ゲインの増強)。
  ただし欠陥1のような人工的な規則性は出さないこと。
  目標: リファレンス1枚目くらいの「網目の見え具合」。

## 欠陥3: プリセット0で像が白っぽく潰れる
- 露出過多気味で蛾の質感が飛ぶ。ロールオフ/露出の配分を見直し、
  最も強いプリセットでも像のディテールが残るようにする。
