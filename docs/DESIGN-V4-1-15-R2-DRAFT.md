## 1. 目標の定義 — 「2 次が入った」とは何か

### 1.1 目標は「場が 2 次の指紋を持つこと」である（R1 と同じ。合否の言い方だけ変わる）

**T1 — 「2 次が入った」とは、線形場 η₁ に 2 次束縛波 η₂ を §2 の手順で
足した場 η = η₁ + η₂ が、§5 のゲートを通ることである。**
見た目や「群れらしくなった」という印象は判定に使わない。
判定は歪度・バイコヒーレンス・峰高分布の 3 つのゲート量で読む。
ゲートの土台は cf-0085 の実測値（下の表）で、同じ定義・同じ車線
（プローブ中央値車線、cf-0085 §2 の定義）で測り直す。
**R2 での変更**：PASS には J1・J2a・J3'・J4' に加えて **J0（試験 0 の QTF 一致）が
必須**になる。バイコヒーレンスだけでは「正しい QTF を実装した」ことの
証明にならない（LEG-GPT.md §7.4、LEG-GEMINI.md C6）ため、J0・J3'・J4' の
3 つがそろって初めて「2 次が入った」と言う。

cf-0085 の実測値（土台。5 シード平均 ± SD、プローブ中央値車線。R1 と同じ）：

| P1-WINDLANE | 0.009 ± 0.007 | 2.375 ± 0.187 | 0.9835 | 0.69 | 1.82 |

### 1.2 目標値の置き方 — 解析の目安はゲートにしない（R1 と同じ＋期待範囲の追加）

**T2 — NOTE §8 の歪度目安（P5 ≈ 0.25）は上限寄りの目安であり、
ゲートの線にはしない。** 狭帯域・深水・一方向の式からの値で、現実の場は
広帯域＋方向分散なので実値は下がる。目安を予測値として読んではいけない
（NOTE §10）。ゲートの線は、参照 QTF からの計算値 λ₃,exact と実測の
ばらつきから引く（§5 の J3'）。
**R2 での追加**：広帯域＋方向分散での目減りの大きさは、実測風波（Forristall 等）で
概ね狭帯域値の 50–85%（LEG-GEMINI.md C6）。P5 の期待範囲は λ₃ ≈ 0.12–0.22。
λ₃,exact は §2.3 の試験 0 で厳密 QTF 二重和から計算し、この期待範囲と
照らし合わせる。目安との比（実測が目安の何割か）は報告するが、合否には使わない。

### 1.3 T3 の書き直し — 「スペクトル不変」は前提ではない（GPT の指摘を受けた修正）

**T3' — 2 次を入れると、合成場 η = η₁ + η₂ のスペクトルは動く。
それは物理的な 2 次補正が働いた結果であり、実装の誤りではない。**
R1 の T3（「ν・GF はほとんど動かないことが前提。動いたら実装がスペクトルを
変えた証拠であり前提違反」）は強すぎた（LEG-GPT.md §7.1）。
2 次束縛波は和周波・差周波に新しい成分を作る。その成分には分散があり、
線形場と 2 次場の相関もある。したがって合成場のスペクトルが変わること自体は、
物理モデルが働いた結果として当然に起こり得る。
**変わらないのは線形場 η₁ の方である**（J1 の SHA256 で保証する）。
合成場の統計の変化は、それ自体を実装誤りと判定せず、参照 QTF の予測と
照合する（§5 の J2b）。予測と合わない変化だけが、物理的 2 次寄与と
数値誤差・重複計上を分離して判定する対象になる。

## 2. 決めること

R1 は「決めること 3 つ」（カーネル・計算法・どこまで入れるか）だった。
R2 は 5 つに分ける。理由は GPT の指摘（LEG-GPT.md §7.2）：
「FFT で畳み込むこと」と「Hilbert 2 次式で計算すること」は同じ意味ではない。
前者は計算方式、後者は物理モデルの近似形であり、別の設計判断として分ける。
また「最初にやる試験」（試験 0）を決めることとして独立させた。

### 2.1 カーネル — 有限水深形を単一カーネルにする（式を本文へ転記する）

**決定：カーネルは有限水深形を 1 本だけ使う。深水形は別カーネルとして用意しない。**
R1 の決定そのものは維持する（C1 は 3 席とも条件付き成立）。
変わるのは、式を本書の本文へ転記し、転記元・版・記号規約・正規化を固定することである
（LEG-GPT.md C1、LEG-GEMINI.md C1、LEG-GROK.md C1 の共通条件）。

**転記元と版**：Sharma & Dean (1979, 1981), "Second-order directional seas and
associated wave forces", Soc. Petroleum Engrg. J. 21(1), 129–140。
有限水深の閉形式としては Marthinsen & Winterstein (1992)
"On the skewness of random surface waves", Proc. 2nd ISOPE Conf. の近似形を
併記する（WAFO の `qtf` 実装がこの形を使っている。出典は §10）。
**厳密形と近似形の区別**：Sharma & Dean の厳密形（Langley 1987 の形を含む）と、
Marthinsen & Winterstein の近似形は別物である。本書は両方を区別して書く。
試験 0 の参照計算は、まず M&W 形の直接ペア評価で行う（§2.3）。
厳密形への置き換えは、ゲート G-C1-0 の結果で決める（下記）。

**記号規約（本書で固定する。転記ミスの罠を塞ぐための定義）**：

- 線形場のモード m は振幅 a_m、波数ベクトル k_m、角周波数 ω_m > 0、位相 θ_m = k_m·x − ω_m t + ε_m を持つ。ω_m は生成器の分散関係（重力＋毛管。cf-0075 で確認済み）から決まる。**純重力の分散関係 ω² = gk·tanh(kh) ではない**。QTF の ω に生成器と同じ分散関係を入れることは近似であり、その誤差は D8 として残す（§6）。
- 2 次場は二重和で定義する（R1 と同じ定義。1/2 の前因子を含む）：
  η₂(x,t) = (1/2) Σ_m Σ_n a_m a_n [ B⁺_{mn} cos(θ_m+θ_n) + B⁻_{mn} cos(θ_m−θ_n) ]
- ペア (m, n) に対し：ω₊ = ω_m+ω_n、ω₋ = ω_m−ω_n、k₊ = |k_m+k_n|、k₋ = |k_m−k_n|、k_m·k_n は波数ベクトルの内積。h は各条件の水深（P1 0.6 m／P5 4.0 m／SWELL 4.0 m）。
- **WAFO の規約との対応（転記ミスの罠）**：WAFO の `qtf` は 1/2 を付けず η₂ = ΣΣ a_m a_n [h_s cos(θ_m+θ_n) + h_d cos(θ_m−θ_n)] と定義するため、**B⁺ = 2h_s、B⁻ = 2h_d** である。WAFO の数値をそのまま B⁺/B⁻ に読んではいけない（2 倍ずれる）。本書の式はすべて B⁺/B⁻（1/2 付き規約）で書く。

**深水極限（h → ∞。WAFO の h=inf 分岐と一致。検証のアンカーになる）**：

- B⁺_∞ = (|k_m|+|k_n|)/2、　B⁻_∞ = −||k_m|−|k_n||/2
- 1D・同方向では B⁺_∞ = (k_m+k_n)/2、B⁻_∞ = −|k_m−k_n|/2。
- 単色波（m = n = k）では B⁺ = k、B⁻ = 0 となり、Stokes 2 次高調波 (1/2)ka² と一致する。これが深水極限のアンカーである。

**M&W 有限水深形（WAFO の `qtf`、Marthinsen & Winterstein 分岐から転記。B = 2h に換算済み）**：

- T₁ = (1/2)·g·(k_m·k_n)/(ω_m·ω_n)
- T₂⁺ = (1/4)·(ω_m²+ω_n²+ω_m·ω_n)/g
- T₂⁻ = (1/4)·(ω_m²+ω_n²−ω_m·ω_n)/g
- B⁺ = 2·[ (T₁ − T₂⁺ + (1/4)·g·(ω_m·k_n²+ω_n·k_m²)/(ω_m·ω_n·ω₊)) / (1 − g·k₊·tanh(k₊h)/ω₊²) + T₂⁺ − (1/2)·T₁ ]
- B⁻ = 2·[ (T₁ − T₂⁻ − (1/4)·g·(ω_m·k_n²−ω_n·k_m²)/(ω_m·ω_n·ω₋)) / (1 − g·k₋·tanh(k₋h)/ω₋²) + T₂⁻ − (1/2)·T₁ ]
- 分母の (1 − g·k±·tanh(k±h)/ω±²) は共鳴分母 D± = ω±² − g·k±·tanh(k±h) を ω±² で割った形である。D± ≈ 0（共鳴近傍）での挙動は、実装前に別途確認する（GPT の検証項目 (6)）。
- **B⁻ の分母・末尾は WAFO 断片からの対称性による補完である**（検索で得た WAFO の `qtf` 断片は h_s の式までは完全だが、h_d の分母以降が欠けていた）。G-C1-0 で WAFO 原文と突き合わせて確定する。補完が間違っていた場合、B⁻ の式だけを差し替え、他の決定には影響しない。
- **方向への一般化**：WAFO の `qtf` は 1D（θ=0）である。本書は k_m·k_n をベクトル内積、k± をベクトル和・差の大きさと読む方向一般化を定義とする。この一般化が正しいことは、試験 0 の方向変化比較（§2.3）で検証する。一般化を仮定したまま実装へ進んではいけない。

**単色波の有限水深アンカー（M&W 形の検証に使う。Stokes 1847 の式）**：

- 単色波の 2 次高調波振幅は a₂ = (k·a²/4)·cosh(kh)(2cosh²(kh)+1)/sinh³(kh)。二重和の規約では B⁺(k,k) = (1/2)·k·cosh(kh)(2cosh²(kh)+1)/sinh³(kh) と等しくなければならない。
- 振幅比 a₂/a₁ = (1/4)·k·a·cosh(kh)(2cosh²(kh)+1)/sinh³(kh)。Gemini の実計算では SWELL 5.0%・P1 15.9%・P5 8.3%（§0 の表）。
- **ゲート G-C1-0（転記の検証。実装ブリーフを書く前に通す）**：(1) 深水極限で B⁺_∞・B⁻_∞ と相対差 ≤10⁻³ で一致すること（P5 で確認。LEG-GROK.md C1 の失敗条件）。(2) kh = 1.0、2.41（P1 相当）、56.6（P5 相当）の単色波ペアで、M&W 形と単色波 Stokes アンカーが相対差 ≤1% で一致すること。(3) 和周波・差周波の双方、(4) モード交換対称性 B±_{mn} = B±_{nm}、(5) 次元整合性（B± の次元は 1/m）、(6) 共鳴近傍 D± ≈ 0 での挙動の記録。(2) で 1% を超えるずれが出た場合、M&W 形は参照計算に使わず、厳密形（Sharma & Dean／Langley）への転記を先に行う。M&W 形はその場合、高速近似の候補へ格下げする。
- **数値安全な評価形（Gemini の条件）**：cosh(kh)／sinh(kh) の生評価を禁じる。tanh(kh) と指数減衰形（e^{−2kh} など）へ代数変形してから評価する。理由：P5 の水深 h=4.0 m、格子 2048²（Δx≈0.73 mm、k_Nyq≈4280 rad/m）では、Elfouhaily 高波数側 k>177.6 rad/m で kh>710.5 に達し、生の cosh/sinh は float64 で Inf へオーバーフローし Inf/Inf = NaN で全滅する（単精度なら k>22.3 rad/m で既に壊れる）。
- **Wilton 共鳴の注意（Gemini の指摘。D8 とも関係）**：純重力の Sharma & Dean 式には表面張力項がないため、k≈260 rad/m 近傍の Wilton 共鳴の物理が抜ける。v4-1.14 §6 C6' との整合が必要。本書では Wilton 共鳴帯を「QTF の適用外の帯」として記録し、試験 0 では k>200 rad/m のペアを除外して比較する。除外した帯の扱いは D8 へ。

**なぜ有限水深形 1 本か（R1 と同じ）**：kh → ∞ で深水形に帰着する。条件をまたいで同じコードで比較できる。P1・SWELL のピークは kh ≈ 2.3–2.4 で中間水深であり、深水形ではカーネルが系統的にずれる。
**R2 での訂正**：R1 の「P5（kh=56.6）は深水極限に帰着するので、P5 の試行は深水形の試行でもある」という言い方は過剰だった（LEG-GPT.md C1）。正しくは「ピーク近傍の代表的なモード対では深水極限との一致を期待できる」である。P5 の水深 4 m では、例えば k = 0.5 rad/m のモードは kh = 2 であり、低波数側を含むペアや差周波の小さいペアが深水極限に入るとは限らない。P5 の試行が深水形の試行だとは言わない。深水極限の一致は、ピーク近傍・低波数側・差周波小さいペアの 3 群に分けて測る（GPT の追加測定）。

### 2.2 計算法 — ペア依存 QTF を参照にし、FFT 分離形は高速近似の候補とする

**決定：物理カーネルはペア依存の QTF（§2.1）とする。計算方式として FFT を使う。
Hilbert 2 次式は、QTF との一致が確認された条件に限って使う高速近似の候補であり、
既定の物理モデルではない。**

R1 の決定（「線形場とその Hilbert 変換の 2 次式を FFT で畳み込む」）は撤回する。
理由は 3 席一致の不成立（C2・C3）である。k_p 一点での狭帯域近似と 1 方向 Hilbert 変換は、
どちらもダメだった。以下、置き換えを決める。

**2.2.1 参照計算 — ペア依存 QTF の直接評価（モード二重和、縮小帯域）**

- 参照計算は、モードの二重和を直接評価する。縮小したモード集合（例：ピーク付近の 100–200 成分、または Gemini の指定する M=256–512 モード）に対して、ペア (m, n) ごとに §2.1 の B⁺/B⁻ を評価し、η₂⁺・η₂⁻ を作る。O(M²) だが M が小さいので回る。
- 参照計算は「物理モデルそのもの」であり、近似ではない。試験 0 の比較対象になる（§2.3）。
- 全モードでの二重和（2048² 格子でモード数 数千〜数万）は回らないので、本実装の計算方式は別途決める（下記 2.2.2）。参照計算と本実装は別のものである。

**2.2.2 本実装の計算方式 — FFT による分離形（k_p 固定を回避する形）**

- 本実装も FFT を使うが、カーネルを k_p 一点で評価する形にはしない。Gemini の指摘する分離形を使う：2 次式を線形帯域の粗格子（例 128²）上で、η₁・∇η₁・∂ₜη₁ の積の和、または少数基底展開として評価する。分離形なら計算費を増やさず k_p 固定を回避できる（LEG-GEMINI.md C2）。
- 分離形が §2.1 の QTF と等しいことは、試験 0 で確認してから採用する。確認が通るまでは、分離形を「Sharma–Dean カーネルの実装」と呼んではならない（LEG-GPT.md C2）。
- 3/2 則のパディングは 2 次積のエイリアシング抑制に使うが、それだけで数値誤差が除去されたことにはならない（LEG-GPT.md §7.3）。格子収束・高波数切断・低波数分解能・共鳴近傍の誤差を別途評価する。和周波と差周波の双方について、解像度を変えた収束試験を行う。

**2.2.3 直交位相の作り方 — 1 方向 Hilbert は破棄する**

- R1 の「風向きへの 1 方向 Hilbert 変換」は破棄する。理由：(a) 風と直角方向のモード（k_x=0）では sgn(0)=0 となり η̃₁=0 で位相共役が消滅する。(b) 風上向き成分（k_x<0、ω>0）が存在する場合、空間 1 方向 Hilbert は時間的共役と符号が 180° 反転し、Q₊ と Q₋ が入れ替わる（LEG-GEMINI.md C3）。方向分散した場では数学的に破綻している。
- 代わりに、**時間的解析信号の虚部**を使う。生成器は各進行波モードの複素振幅 η̂₁(k)e^(−iω_k t)（ω_k>0）を保持しているため、η̃₁(x,t) = Im Σ_k η̂₁(k)e^(i(k·x−ω_k t)) とすれば、追加コストほぼゼロで全方向 θ∈[−π,π] に厳密になる。または **2D Riesz 変換**（−i·k/|k|·η̂₁ による勾配演算）を使う。どちらを選ぶかは試験 0 の実装で決め、両方の一致も測る。
- **注意（GPT の指摘）**：方向別の直交位相を作るだけではまだ不十分である。2 次相互作用は個別モードの位相直交だけでは決まらず、モード対の和・差周波相互作用を含む。方向ごとに別々に Hilbert 変換してから 2 次式を作ると、異なる方向のモード対について、どの直交位相をどう組み合わせるかという問題が残る。したがって、時間的解析信号・2D Riesz も「QTF の高速近似の部品」であって、QTF そのものではない。標準実装は、方向を含む波数ベクトル対に依存する QTF を保持する（§2.2.1）。直交位相を使う近似は、試験 0 で QTF との一致が確認された条件に限って使う。

**2.2.4 計算手順（1 フレームあたり。R1 の手順を置き換える）**

1. **線形場を取る**：生成器から η₁(x, y, t) を取る。生成器のコードは変えない。同じシード・同じ 192 フレーム（8 s、24 fps）・同じプローブ配置（cf-0067 と同じ 256 点）を使う。η₁ はビット単位で線形のままであること（J1 で検証する）。
2. **直交位相と勾配を作る**：時間的解析信号の虚部（または 2D Riesz 変換）で η̃₁ を作る。同じ FFT の往復で勾配場 ∂xη₁、∂yη₁ もスペクトル微分で作る。1 方向 Hilbert は使わない。
3. **2 次式を作る（実空間での積）**：和周波成分のもと Q₊ = η₁² − η̃₁²、Q₊′ = 2η₁η̃₁（解析信号 Z = η₁ + iη̃₁ の Z² の実部・虚部）。差周波成分のもと Q₋ = η₁² + η̃₁²（|Z|²、包絡の 2 乗）。有限水深形のカーネルが k₁·k₂ の項を含む場合、その部分は勾配場の積（∇η₁·∇η̃₁ など）で作る。**どの積がどのカーネル項に対応するかは、§2.1 の B⁺/B⁻ の式から対応表を作る。対応表は試験 0 で検証する。**
4. **カーネルを k 空間のフィルタとして掛ける**：各 2 次式を FFT し、出力波数 k に対してカーネル因子を掛ける。**k_p 一点での評価はしない。**分離形（§2.2.2）の因子は、出力波数と水深だけでなく、ペアの情報を保つ形で評価する。具体的な分離の形は、試験 0 の結果を見て実装ブリーフで固定する。
5. **実空間に戻す**：IFFT で η₂⁺、η₂⁻ に戻す。**パッチ平均の除去はここではしない。**平均水位の扱いは §2.4 で決める（診断用の静的 DC 項だけを除く）。
6. **場を足す**：η = η₁ + η₂⁺ + η₂⁻。勾配・曲率は η からスペクトル微分で作り直す。η₂⁺ と η₂⁻ は診断として別キーで残す（§5 の J5）。
7. **プローブで出す**：cf-0067 と同じ 256 プローブ・同じ 192 標本で η、η₂⁺、η₂⁻ をサンプリングし、同じ npz 形式（キー eta/gx/gy/lap/t）で出す。検証の道具（歪度・尖度・QD・峰高・バイコヒーレンス）は cf-0085 と同じ定義・同じ車線で回す。

**エイリアシングの扱い**：2 次式の積は、同じ格子で計算すると高波数成分が折り返す。3/2 則のパディング（積を作る前に場を 3/2 倍の格子へ広げ、積の後に元の格子へ戻す）で除去する。これは大原則の (a)「中立な数値手法」であり、物理の主張ではない。ただし 3/2 則だけでは、格子収束・高波数切断・低波数分解能・共鳴近傍の誤差は除去できない（§2.2.2）。

**計算量の見積もり（推測。実測ではない。R1 と同じ）**：1 フレームあたり FFT 8–10 回（2048²）で 2–4 秒、8 s 記録 1 本 400–800 秒、P5・5シードで 35–65 分。見積もりは推測であり、実装ジョブの最初の 1 記録で実測して確かめる（§5 の J7）。**試験 0 は縮小モード集合（M=256–512）での直接二重和なので、計算量は小さく、最初に回す。**

**大きさの事前見積もり（P5、解析式から。実測ではない。R1 と同じ）**：
η₂⁺ の標準偏差は k_p·σ_η² ≈ 14.15 × (0.0059)² ≈ 4.9×10⁻⁴ m で、線形 σ_η の約 8%（a₂/a₁ = 8.3% と整合する）。足される分散は (0.083)² ≈ 0.7%。勾配への寄与は波数が 2 倍になる分だけ大きく、ピーク急峻度 ε = 0.17 から勾配場への 2 次の寄与は振幅比で約 17% になる見込み。つまり「高さでは小さく、勾配・曲率では無視できない」というのが、この設計の効き方の見立てである。実測で確かめる（J2b・J5）。

### 2.4 どこまで入れるか — 和周波成分と差周波成分の両方を入れる（扱いを整理する）

**決定：和周波成分（η₂⁺）と差周波成分（η₂⁻、セットダウン）の両方を入れる。
ただし η₂⁺ と η₂⁻ は診断として分離して出力し、ゲートの寄与を
それぞれ読めるようにする。**（R1 の決定そのものは維持する。C4 は 3 席とも条件付き成立。）

- **なぜ両方か（R1 と同じ）**：同じ計算で両方出る。セットダウンは群れの包絡と一緒に動く低周波成分であり、群れの物理の一部である。歪度への寄与は両方にある。片方だけ入れて歪度が上がったとき、上がった分がどちらから来たのか分からなくなる。
- **大きさの見立て（R1 と同じ）**：歪度の主信号は和周波成分から来る。λ₃ ≈ 3·k_p·σ_η という標準的な式は、和周波成分の寄与だけで導ける。差周波成分は深水では k₁ ≈ k₂ でカーネルが 0 に近づくため、歪度への寄与はスペクトル幅のオーダーで小さい。つまり**差周波成分は歪度ゲートの主信号ではなく、群れの包絡の形（QD 波形の谷の形・平均水位の動き）の方に効く**と見立てる。実測で確かめる（J5 の寄与分離）。
- **R2 での整理 1 — パッチ平均の除去は「診断用」に限定する（3 席の共通条件）**：R1 の「パッチ平均を差し引く」は、物理場に対する操作と診断用の操作が混ざっていた。整理する：
  - **物理場には、η₂⁻ を含む全水位場を平均除去前の場として保持する。**パッチ平均の除去は物理的な 2 次成分の削除とはみなさない。
  - 除去してよいのは、**固定された静的 DC 項（Δk=0、Δω=0 成分）のみ**である。静的 DC 成分だけを固定水深 h の定義として引くなら、保存水深に一致し、3 次中心モーメント（歪度）は不変である（LEG-GEMINI.md C4）。
  - **各時刻のパッチ空間平均 η̄(t) を引く操作はしない。**パッチサイズと同程度の群れビートが通過するたびに水面全体の基準水位 h が時間的に上下動する非物理なピストン振動を生む。中立な数値操作ではない（LEG-GEMINI.md C4、LEG-GPT.md C4）。
  - 除去する平均の対象・空間窓・除去する波数帯を明示し、除去前後の統計を併記する（LEG-GPT.md C4）。除去した平均値の大きさは診断として記録する。
- **R2 での整理 2 — 差周波成分の検証は 1.5 m パッチ単体ではしない（3 席の共通条件）**：P5 のピーク波長は λ_p = 2π/14.15 = 0.444 m であり、1.5 m 周期パッチには約 3.4 波しか入らない。解像できる最小差波数は Δk_min = 2π/1.5 = 4.19 rad/m（約 0.30·k_p）で打ち切られる。Δk < 4.19 rad/m の長周期の群れセットダウンは、原理上パッチ内で消滅する（LEG-GEMINI.md C4）。したがって η₂⁻ の検証は、**大パッチ（≥6–8 m）または低域包絡条件付き QD 平均波形**で行う。1.5 m パッチで差周波成分が消えるという結論を採用するなら、パッチサイズを変えても結論が維持されるかを確認する（LEG-GPT.md C4）。
- **パッチの大きさとの関係（R1 の注意を維持する）**：差周波成分は群れのスケール（数 m〜数十 m）で変わる成分だが、パッチは約 1.5 m しかない。パッチの中では差周波成分はほぼ一様なオフセットに見える。残るのはパッチ内の傾きだけである。つまり差周波成分の「見え方」はパッチの大きさで決まる部分が大きく、歪度・QD・バイコヒーレンスで読むのが筋である。パッチの中でセットダウンの「くぼみ」が見えることを期待してはいけない。
- **失敗条件（Grok の指定）**：平均除去後の差周波分散が線形分散の 0.1% を下回る場合、信号が消えている証拠として扱い、除去の仕方を見直す。

## 4. 8 s ループ契約・ω 量子化との整合（「近似」として明示する）

- **数学的な周期性は保たれる**：η₂ の成分の周波数は ω₁±ω₂ で、ω₁・ω₂ はどちらも 2π/8 s の整数倍（cf-0075）なので、ω₁±ω₂ も 2π/8 s の整数倍である。η₂ は 8 s で厳密に周期であり、8 s ループ契約は構成上保たれる。時間発展のコードは変えない。
- **R2 での追加 — 数学的周期性と物理的群れの再現は別問題である（GPT・Grok の条件）**：8 秒ループの中では、非ゼロの差周波ビートは 8 秒以下の周期しか持てない。8 秒を超える群れの包絡変動は表現できない。具体的には、10 秒・20 秒のビートを作るには周波数差がそれぞれ 0.1 Hz・0.05 Hz 程度必要になるが、8 秒ループの周波数刻みは 0.125 Hz である。これらの差周波数は格子上に存在しない。同じ周波数同士の差はゼロ（平均成分）になり、隣接ビンの差は 0.125 Hz で周期 8 秒になる。これより長いビートは作れない。**長周期の群れが 8 秒ごとに再出現するように見える場合、それは自然な群れの時間発展を再現したのではなく、8 秒周期という数値契約が作った再帰性である。**8 秒周期を維持すること自体は問題ではない。8 秒周期で表現できない物理を、表現できていると扱うことが問題だ（LEG-GPT.md C8）。
- **R2 での追加 — 偽の定在セットダウン縞の確認（Gemini の条件）**：離散周波数ビンへの丸め（snapping）により、連続分散関係では ω(k₁)≠ω(k₂) となる異なる波数・角度のモード対でも、0.125 Hz 幅の同一ビン n に丸められると ω₁−ω₂=0 に縮退し、時間移動せず空間に張り付いた静止セットダウン縞（時間平均 ≠0 の偽定在波）を η₂⁻ 内に作り出す（特にスペクトルピーク近傍の高密度ビン n≈14–16 で顕著）。P5 の η₂⁻ 場について、8 s ループ上の時間平均場 ⟨η₂⁻(x,t)⟩_t の空間分散（ω₁−ω₂=0 へ落ちた静止成分の分散）を全 η₂⁻ 分散に対する比として測定し、同一方向対（k₁=k₂ の真の空間一様 DC）を除いた非一様静止縞（k₁≠k₂、ω₁=ω₂）の寄与が η₂⁻ 分散の何%を占めるかを定量確認する。
- **R2 での追加 — 差周波の時間自己相関の確認（Grok の失敗条件）**：差周波成分の時間自己相関が 4 s を超える遅延で有意な値を持ち、8 s 折り返し後に不自然な周期性を示す場合、8 s 折り返しは物理的時間発展と衝突しているとして扱う。確認は P5 の η₂⁻ 場で行う。
- **R2 での追加 — 長周期の別試験（GPT の追加測定）**：物理的な長周期群れの検証では、より長い基本周期（16 秒以上、可能なら 32 秒以上）または非周期時間発展を用いた別試験を行う。比べるもの：差周波スペクトルの低周波端、群れ包絡の自己相関、包絡変動の周期分布、セットダウンの時間変動、2 次成分の長周期側の分散。8 秒から 16 秒・32 秒へ延長したときに差周波統計が大きく変わるなら、8 秒契約は 2 次相互作用の物理的再現に制約を与えている。**この別試験は第 1 実装の前提ではない。第 1 実装では既存ループ契約との互換性を優先する。**
- **SWELL へ拡張しない**：P5 では 8 s 間に約 5 個の群れが通過する（τ_group ∼ (νf_p)⁻¹ ≈ 1.63 s）ため群れ折り返しは目立ちにくいが、仮に SWELL（T_p=2.667 s、8 s でわずか 3 波、群れ時間 ≳10 s）へ拡張すれば、Δf=0.125 Hz 刻みの 8 s 周期化自体が物理的群れ発展・η₂⁻ の時間統計と衝突する（LEG-GEMINI.md C8）。SWELL 限定試行（§2.5）でも、8 s 折り返しの影響は上記の確認とセットで報告する。
- **時間発展は変えない**：束縛波は親に追従する。η₂ は各時刻の η₁ から決まる（§2.2 の手順は各フレームで η₁(t) から η₂(t) を作る）。`_cascade_fields` の位相回転 exp(i·ω_q·t) はそのままでよい。新しい時間積分器は要らない。NLS のように時間発展の核を置き換える話ではない。
- **新しい乱数は引かない**：η₂ は η₁ の決定的な関数であり、乱数の引き直しはない。同じシード → 同じ η₁ → 同じ η₂。シード契約（同じ環境・同じシードで同じ場）は保たれる。シードで統計が大きく動く生成器は契約違反、という規律（床の設計 §3）もそのまま適用する（J6）。
- **ω 量子化は外さない**：cf-0079（生成器側で ω 量子化を外す実験）は本人の判断待ちのままであり、本設計とは別件である。η₂ の計算は量子化された ω のままで行う。差周波成分の低周波（ω₁−ω₂ = 0 や 2π/8 s）は、量子化された格子の上の成分として扱う。
- **lo／hi カスケードとの関係**：η₂ は、lo／hi のブレンド後の最終的な η₁ から計算する。lo と hi のモード同士も相互作用する（和・差のペアはカスケードをまたぐ）ので、カスケード別に η₂ を作ってブレンドしてはいけない。ブレンド後の 1 枚の場から作る。ブレンドの境目 K_X での raised-cosine の重みは、η₁ の側の話であり、η₂ の計算には直接現れない。
- **k_cut との関係**：線形場のスペクトルは k_cut = 1000 rad/m で切られている。η₂⁺ の波数は最大で 2·k_cut まで行くが、FFT 格子のナイキスト（2048² 格子で約 4360 rad/m）の内側である。η₂ は格子のナイキストまで残し、k_cut での切り捨てはしない。切り捨てたエネルギーの割合は診断として記録する。

  攻撃点 — M&W 形は近似形であり、厳密な Sharma & Dean 形ではない。厳密形の完全な代数形が本書にないままでは、実装仕様として通せるのか。G-C1-0 で M&W 形が単色波アンカーから 1% を超えてずれた場合、厳密形への転記を先に行うという分岐は、実装の順序を遅らせるのではないか。Langley 1987 の厳密形の転記は本書ではしていない。
- **D3（P1・SWELL の適用可否）**：主張 — P1・SWELL は保留とし、SWELL 限定試行と P1 の診断測定で適用可否を決める。ε₂ < 0.25 なら対象へ戻す。

- **D4（J3' の σ_λ₃ の求め方）**：主張 — σ_λ₃ は歪度推定量の有限標本 SD とし、400 本モンテカルロ（または 5 シード×3 空間）で求める。cf-0094 の \|b\| の SD は J3' には使わない。
  根拠 — 次元が違う（\|b\| の SD は歪度の SD ではない）。Gemini の指定する方法がそのまま使える。
  攻撃点 — 400 本モンテカルロの計算コストと、5 シード×3 空間の標本数の少なさ。σ_λ₃ の推定そのものの不確かさが、両側ゲートの幅を揺らがさないか。λ₃,exact の計算に使う「厳密 QTF 二重和」が M&W 形の場合、その近似誤差が λ₃,exact に混ざらないか。
- **D5（J2b の許容幅）**：主張 — 合成場の統計変化は、参照 QTF の予測と照合して判定する。\|Δν\| ≤ 0.02 は合否の線ではない。
  根拠 — ν の増加は物理現象であってバグではない（Gemini・GPT）。
  攻撃点 — 「予測と一致する」の許容幅の数値が本書にはない。試験 0 の結果を見て決めると書いたが、決める手順（誰が・どの数値で）が決まっていない。許容幅を後決めにすると、実装後に都合のよい幅を引く抜け穴になる。

  根拠 — Δk_min = 4.19 rad/m の打ち切りで、長周期の群れセットダウンは 1.5 m パッチ内で消滅する。
  攻撃点 — 大パッチ（6 m・12 m）のどちらで検証するのか。条件付き QD の「低域包絡」の定義（包絡上側 10% か、別の閾値か）が決まっていない。生成器のパッチが 1.5 m しかない場合、大パッチの場をどう作るのか（生成器の変更が要るのではないか）。
- **D7（8 s 折り返しの検証）**：主張 — 8 s 折り返しは「近似」として明示し、偽の定在セットダウン縞の寄与と差周波の時間自己相関（4 s 超の遅延）で確認する。長周期の別試験（16 秒・32 秒）は第 1 実装の前提ではない。
  根拠 — 数学的周期性は保たれるが、8 秒を超える包絡変動は表現できない。
  攻撃点 — 偽定在縞の「許容以下」の線が数値になっていない。別試験を「第 1 実装の前提ではない」と先送りしたことで、第 1 実装の結果が 8 s 契約のアーティファクトかどうか、判定できなくならないか。
- **D8（QTF の ω(k) と生成器の分散関係の整合・Wilton 共鳴）**：主張 — QTF の ω には生成器と同じ分散関係（重力＋毛管）を入れる。Wilton 共鳴帯（k≈260 rad/m）は QTF の適用外として記録し、試験 0 では k>200 rad/m のペアを除外する。

  攻撃点 — 純重力の QTF 式に毛管の ω を入れる近似の正当化がない。高波数側（k>200 rad/m）では毛管項が重力項を上回る（k=1000 rad/m で (σ/ρ)k³ ≈ 7.28×10⁴ に対し gk ≈ 9.81×10³）。除外した帯のエネルギーが η₂ にどれだけ寄与するかの見積もりがない。Wilton 共鳴帯を除外したまま、m2・m4 の比較が正しくできるのか。

## 7. やらないこと

- **k_p 一点での狭帯域近似は既定にしない**。試験 0 を通るまでは、FFT 2 次式を QTF の実装と呼んではならない。
- **1 方向 Hilbert 変換は使わない**。方向分散した場では数学的に破綻している。
- **N0 仕様のバイコヒーレンスは使わない**。P1 で z=+4.9 の誤検出を与える罠である。主判定は NF 仕様のみ。
- **各時刻のパッチ空間平均を引く操作はしない**。非物理なピストン振動を生む。除去してよいのは静的 DC 項（Δk=0、Δω=0）のみ。
- **歪度ゲート 0.05 は使わない**。撤回済み。J3' は λ₃,exact ± 2σ_λ₃ の両側ゲートである。
- **Ursell 数の壁 0.33 は使わない**。尺度違いだった。適用可否は ε₂ = σ_η₂/σ_η₁ と SWELL 限定試行・P1 の診断測定で決める。
- **NLS／変調不安定は範囲外**。時間発展の核の置き換えが要り、8 s ループ契約と衝突する。C3 で主要機構ではないと結論済みで、覆る材料は出ていない（NOTE §4）。
- **Zakharov／HOS は最後の手段として記録のみ**。生成器の作り直しになる。P5 の検証が通った後の拡張の候補として残す。
- **3 次補正は 2 次の後**。2 次が入って歪度が測れてからでないと話にならない（NOTE §5 d4）。
- **NewWave 型の位相固定は入れない**。対照として使い続ける（cf-0067 で較正済み）。定常ランダム波の場に決定論的な集束を入れることはしない。
- **スペクトル処方の変更なし**。S = S_l + S_h（Elfouhaily 形）の処方は変えない。2 次は後付けであり、スペクトルをいじって歪度を作ることはしない。
- **生成器の線形部は変えない**。`_draw`／`_realise`／`_cascade_fields` はそのまま。η₂ は新しいスクリプトで後付けする。
- **P1・SWELL への第 1 実装での適用なし**（§2.5）。ただし「範囲外」ではなく「保留」であり、診断測定は許可する。

## 8. 実装ジョブへの橋渡し（次の段で PC ジョブに渡すブリーフの材料）

### 8.1 試験 0 のブリーフ材料

- **入力**：生成器の線形場 η₁（P5-CLEAR、cf-0067 と同じ 5 シードのうちまず 1 シード、同じ 192 フレーム、同じ 256 プローブ配置）。条件パラメータは水深 h = 4.0 m、ピーク波数 k_p = 14.15 rad/m、k_cut = 1000 rad/m。カーネル式は §2.1（M&W 形。B⁻ の分母・末尾は G-C1-0 で WAFO 原文と突き合わせて確定する）。

### 8.2 本実装のブリーフ材料（試験 0 の合格後）
