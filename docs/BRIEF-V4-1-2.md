## ジェネレータ構造（1.2 の最終形）
- **(i) 直接底応答**： η̂ = T(k)·ζ̂（T は 1.1 の重力形、傾き上限は安全弁として維持）。水路の格子床では ζ は格子線のみ → 応答は実質ゼロになるはずで、それを数値で示して報告する（切るのではなく測る）。自然床では Nikora 系ガウス場。
- **(ii) 定常リング＋テール（Dolcetti & Krynkin 2017 のスペクトルモデルそのもの）**： k0 は静止条件 k0·U0 = √[(g·k0 + γk0³/ρ)·tanh(k0H)]（γ=0.0728, ρ=1000）の小さい方の解。U0 < c_min ならリングなし。方向分布は β=0,π 中心の Poisson 型（2017 の fit 形。使う形とパラメータを明記）。テールは k≥k0 で k^−α（α は 5 と 7 の両方を計算し、リング分率と併せて報告。主結果は α=6 相当ではなく、両端を出すこと）。リング分率は「入力」ではなくモデルの形から出る量として報告する。
- **(iii) 乱流成分（非定常）**： Horoshenkov 型 W(ρ)=exp(−ρ²/2σw²)·cos(2πρ/L0)。規約はこの形（½ あり）で統一し、σw は相関のパラメータであって振幅ではない（振幅は分散予算から別に決まる）。L0 は相関（L0/ks ≈ 0.045·exp(0.54·V̄/u*)、V̄=深さ平均流速）と L0/H≈1.8–2.9 の両方を計算し、L0 ≤ 2.5H でキャップ。時間発展は 1.1 と同じ（分散位相＋OU 更新、τ=H/u*）。
- **分散（σ）の閉じ方**： 総 σ² の目標は、上の13条件への単一の回帰で決める（例： σ = a·U0^b·H^c·s^d、または u*=√(gHs) を使った形。形の選択と当てはまり（条件別比）を報告する）。条件ごとの後付け調整は禁止。予算配分： リング＋テールが (ii) の形から決まる分率、残りが (iii)。ただし水路条件では (i) は実質ゼロなので、(ii)+(iii) で総 σ に一致させる。
- **U と U0 の関係**： シーン入力は深さ平均 U、水面流速 U0=1.15·U（1.1 の仮定を継承し、明記する）。
