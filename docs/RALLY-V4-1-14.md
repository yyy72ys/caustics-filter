## 2. 割れた点と裁定

### 2.1 C3（Plant τ(k)）— 2対2に割れたが、物理で裁定する：主張は落ちる

GPT と Gemini が独立に WRONG、Grok と dsh が STANDS。**裁定は WRONG 側を採る。** 決め手は Gemini の指摘で、これは好みの問題ではなく物理の非対称性である：Plant の成長率 β(k) ∝ (u_*/c)²ω は風があるときの**成長**の率であり、風が止めば u_*→0 で τ_Plant = 1/β → ∞ となり「波紋は永遠に減衰しない」という誤った予言になる。実際の突風の谷間の減衰は粘性減衰 2νk²・膜減衰・帯域間非線形移送が支配し、成長と減衰は非対称で、単一の対称な τ(k) には書けない。GPT も独立に「Plant 成長率は緩和モデルではない」と結論した。dsh の STANDS は「45 秒の実測と整合する唯一の第一原理 τ(k)」を根拠とするが、それは成長側の応答についての話であり、ステップ**ダウン**の失敗条件（λ=2 cm の波が ∼5 秒で消える間に τ_Plant→∞）に答えていない。
→ 書き換え：τ(k) は τ_grow(k)（Plant 系、成長側）と τ_decay(k)（粘性＋膜＋S_nl 移送、減衰側）の非対称ペアとする。瞬時平衡が 45 秒実測で反証済みな点は全席一致で維持。

## 6. 最終裁定

- **分解（U1–U13 が残作業を閉じる形か）は FALLS**（4席全員）。落ちた理由は3種ある：主張の誤り（C3 の対称 τ、C6 の Wilton 委譲、C9 の WKB 有効範囲、C15 の単一原因保証、C16 の帯域取り違え、C7 の数式誤り）、順序の依存違反（U3・水深・物差し・砕波が、それを食うユニットの後ろにいた）、そして欠落（L5 ユニットほか §5）。
- **骨格は維持する。** 在庫としての分解は dsh の言うとおり「大筋で正しい棚卸し」であり、ユニットを捨てる裁定は1件もない。維持の条件は再定義である：主張の書き換え（§2・§3）、U2 と U8 の分割、U10 の解体・統合、U11 の接口前倒し、U14 の新設、そして新順序（§4）。
