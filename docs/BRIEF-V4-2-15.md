## STAGE 1 — bed_gen3.py の実装（機構 A／B）
設計 §1.3（A-1／A-2／A-3）と §2.3（B-1／B-2／B-3）に忠実に実装する。`D:\yohey2026\dsh\muse\caustics-filter\offline\bed_gen3.py` を新規作成し、各ステップを独立に呼べる関数にすること。`run_v4_2_15.py` が要因計画を回す。
- **A-0 初期床**： bed_gen2 の粒配置をそのまま使う（全条件・全 seed で同一の初期床から始める）。
- **A-1 水力 winnow**： 二重平均せん断 τ0 = ρgHS0 に大粒の後流欠損（L_w ≈ 2–4·D_clast）を足した τ(x, y) を作ること（τ(x, y) が存在することが必須。τ なしの「wake に細粒を置く」は配置則であり却下済み）。各表面粒の突出量 p_i = (z_top,i − z_local_mean) / D_i（z_local_mean は 3×D_i 四方の近傍平均）。臨界突出量 p_c(τ\*) は Yager et al. 2018 型のモーメント釣り合いから決める（簡略形でよいが、p_c が τ\*・D_i・pivot 角・上載荷重の関数であること。D_i/D50 だけの式にしてはならない）。p_i > p_c の粒を WC 輸送関数 W\*_i(φ) に比例する確率で除去し、除去した粒は系外へ出す（下流端から出た分は補充しない）。τ\* は {0.03, 0.045, 0.06, 0.08, 0.10} を掃引する。各 τ\* で表面 D50 が地下 D50 の 2 倍（R_a = 2）に達するか、τ\* で動く粒がなくなったら停止する。停止しなければ τ\* を上げるのではなく「その τ\* では装甲ができない」と記録する。
- **A-2 粒状選別**： A-1 の停止面から、床内部の細粒を下へ動かす。細粒（d < Dc\*/3、Dc\* はくびれ径 ≈ 0.15–0.25·D_framework）は隙間を通って下へ浸透。d ≥ Dc\*/3 の細粒は橋かけして 2–5×D90 の深さで止まる。せん断がある層でのみ動かす（静止層では自発浸透のみ）。粗粒は squeeze expulsion で上に押し上げる（体積保存）。質量は系内に残す。地下の細粒分率の鉛直プロファイルを記録する。
- **A-3 interlock**： 残った表面粒を 3 点支持を満たすまで重力沈降させる（支持点が 3 点未満の粒は転がって安定姿勢を探す）。imbrication は「重なり」として入れる（下流の粒の上流縁が、上流の粒の下流縁の下に潜る。a–b 面の伏角は 15–40°、中央値 ≈ 28° から抽出）。a 軸の向きは混合既定（孤立した円盤状粒は流れに直交寄り、クラスタ内部では流下寄り。どちらか一方に決めない）。クラスタは表面の約 10% を覆い、寸法は粗粒尾部（D84–D90）でスケールする。空隙率は 0.30–0.45 の範囲に入ること。imbrication による空隙率の低下 ≈ 0.03（絶対値）を再現すること。
- **B-1 faceted 粒**： 各粒の滑らかな楕円体を Voronoi 破砕による多面体に置き換える（1 粒あたり 6–12 面、平らな割れ面、角は丸めない。円磨度 angular–subangular、Wadell 0.1–0.3 を目標）。粒形は扁平を保つ（b/a 0.67–0.74、Corey 形状係数 0.6–0.7。範囲を外れた粒は棄却して引き直す）。facet の大きさ分布を記録する。
- **B-2 planation**： 装甲面は近傍（3×D50 四方）の平均高さ ＋ k·σz（k ∈ {0.5, 1.0}）で決める。あるいは等価に近傍の summit 高さの上位 f 分率を切る（f ∈ {0.05, 0.10}）。2 亜種とも実装する（結果が違えば違ったまま報告する）： **B-2a ハードクリップ**（装甲面を超えた粒頭を面で切り落とす。粒は残る）、**B-2b 選択的除去**（突出量がしきい値を超えた粒を除去し、その場所を下の粒／ポケット細粒で埋める）。切り取った体積は系外へ出す。切り取りで生じた平らな面はそのまま残す（埋め戻さない）。
- **B-3 ポケットの細粒充填**： 粗粒の間の窪みに細粒を入れる（d < Dc\*/3 は下へ浸透、d ≥ Dc\*/3 は橋かけして 2–5×D90 で止まる。A7）。充填量は空隙率 0.30–0.45 の範囲内に収めること。
- 各ステップの実装後、そのステップだけの診断量を測って報告する（A-1：τ\* ごとの R_a と停止理由。A-2：地下の細粒分率プロファイル。A-3：支持点数・伏角分布・空隙率・クラスタ覆い率。B-1：facet 大きさ分布・円磨度。B-2：クリップ分率 f の実測値。B-3：充填量と空隙率）。

## STAGE 3 — 読み取り（事前登録。レポートはこの形で事実を整理する。設計判定は書かない）
- **実測 DEM はこのジョブには無い**。エンベロープ判定（global rank-envelope）は実測 DEM が届いてから v4-2.10 で行う。**このジョブではエンベロープの合否を出さない**。合成 fBm や他の生成床を参照集団の代わりに使うことは禁止する。
- このジョブで判定できるもの（OR 形、設計 §5.2–§5.4 のうち DEM を要しない部分）：
  - **G-A1 数値**： H_fit < 0.50 なら A はスケーリング帯の説明として落ちる（エンベロープ判定は保留）。H_fit ≥ 0.60 なら「エンベロープ待ちで生き残り」と記録する。
  - **G-A2 装甲の再現**： R_a が [1.5, 3.0] に入らない、または Sk が +0.4–+0.8 に入らない場合 → A の実装が装甲そのものを再現できていない。H が動いても、装甲の再現として不成立である（何を測ったのか分からない）。
  - **G-A3 A1/A2 の分離**： 地下の細粒分率プロファイルが A1 予測（不変）と A2 予測（2–5×D90 深さで上昇）のどちらとも合わない場合 → 選別の内訳が特定できない。機構の名前を変えて報告する。
  - **G-B1 数値**： H_fit < 0.50 なら B はスケーリング帯の説明として落ちる（エンベロープ判定は保留）。H_fit ≥ 0.60 なら「エンベロープ待ちで生き残り」と記録する。
  - **G-B2 facet の前提**： facet の線形寸法の中央値 < 10 mm の場合 → B8 の前提 (ii) が崩れている。H が動かなくても「facet が小さすぎた」という別の失敗として報告する（R1 により facet は H の前提条件としては失効し、形状の記録量に降格している点も併記する）。
  - **G-B3 歪度の緊張**： VB-a（B-2a）で Sk < +0.3 の場合 → B6 の緊張関係が確認されたことになる。B-2a は歪度の機構として落ちる。B-2b が Sk を回復できれば、B の生き残りは B-2b に限定される。
  - **VAB**： A・B のどちらかが生き残れば、VAB を評価する。**両方とも単独で落ちても、VAB を 1 回だけ評価する**（相互作用が機構である可能性は、単独の失敗からは否定できない）。VAB が落ちたら粒層のこの 2 機構は両方とも閉じる（次の候補は別設計で起こす。パラメータの漁りはしない）。
- **到達見込み**： A の H_Nikora は 0.50 前後、楽観で 0.60 を見込む（R14）。**0.79 を A の予測として書いてはならない**。
- しきい値 0.50／0.60 は較正値ではなく配置値である（H_fit の 0.50 は「現在の生成床 0.29 と目標 0.79 の中間よりやや上」、0.60 は「目標に半分以上近づいた」という運用上の目安）。
