## 算術の裏取り（統合側で R9 本文と数値により検証した）

### (a) K1 — sd_差 の主張文は、ゲートが働く唯一の構成で算術的に誤り

- R9 §6.2 V3(ii)「相関つき差分ゲート」（R9 行 1739）は、sd_差 = √( sd_1² + sd_2² − 2·f·sd_1·sd_2 )（ρ = f）を事前登録し、「同程度の sd では sd_差 は sd_1 以下になるため、この近似は解消を易しくする方向には働かない」と書く。
- sd_1 = sd_2 = σ と置くと sd_差 = σ√(2(1 − f)) であり、sd_差 ≤ σ は f ≥ 0.500 のときに限る。検算: f = 0.338 → √1.324 ≈ **1.151σ**（初回 sd より約 15.1% 大きい＝ゲートは緩くなる）。f = 0.500 → ちょうど 1.000σ。f ≈ 0.97 → 約 0.245σ。
- このゲートが実際に使われる構成は 1 つだけである。留保の解消条件 (2)（R9 行 1753）は「(a) の sd と初回 sd から作る相関つき sd_差（f = f_a = 0.338）」と固定する。(b) の sd は差分ゲートに使わない（同節に明記）とされ、(a2) は解消条件から外され診断報告のみである。つまり「sd_1 以下になる」が成り立つ f = 0.500（(b)）と f ≈ 0.97（(a2)）はどちらもゲートに使われず、ゲートに使われる f_a = 0.338 では主張文が**算術的に誤り**である。Gemini の刺し (a) は成立する。
- GPT はこの点を算術では刺していない。GPT の K1 側の指摘は「ρ = f の妥当性が未検証」（面積比と窓統計量の相関は別物であり、統計量ごとに相関構造が異なり得る）であり、Grok も「近似の妥当性を検証する手段がない」と同方向である。算術の誤りと根拠の欠落は別の欠陥として両方残る。

### (a') K1 — f の定義と Gemini の「約 65.1%」

- R9 §6.2 V3(ii)「面積重なり率の定義」は、f を「再検査の各窓について、**対応する初回窓**との共通面積 ÷ 窓面積」と定義し、窓ごとの f の平均をセットの f とする。(a) は流下シフト 0.73775 m（半窓）→ 0.500、横断シフト 0.35 m → (1.0828 − 0.35) / 1.0828 = 0.677、**f_a = 0.500 × 0.677 = 0.338**。この積自体は R9 の定義どおりで算術の誤りではない。
