## 共存の設計（v2 の核）
テンポは落とさない。落とすのは「同時に目に入る情報の数」。

1. **1画面1メッセージ**：各カットで読ませる対象は1つだけ。他の要素は消すか、背景（読む対象でない状態）に落とす。同時表示は詰め込みの主因なので、v1 の「分割表示＋宣言＋条件の同時提示」は解体する。
2. **文字と数字は残像で読ませる**：宣言と主役の数字は大きく出し、フェードで消さず残置する。カットが速く切り替わっても、文字だけは視界に残る時間を確保する。
3. **主張の反復**：宣言「この水は、撮影なし。水なし。コードだけ」は冒頭と末尾寄りの2回出す。1回目で読めなくても2回目で読める前提で組む。
4. **現在地の明示**：段階ラベル（例：01 SET → 02 INSPECT → 03 RESULT のような大きな段階表示）で、速い展開でも「今どこか」が分かるようにする。ラベルの文言はブリーフ v1.4 の操作の意味（選択・読込・検査）と矛盾させない。
5. **波と切替のキレは維持**：水の動き、層切替の速さ、機械音のタイミングは v1 のまま。間を作るのは文字・数字・ラベルの側だけ。

## 構成（8秒・骨格は v1、提示の仕方だけ変える）
- 0–1.2s：宣言だけの瞬間を先に置く（波を背景に大きく、他は何も出さない）。続けて設定と計算の証拠。
- 1.2–3.0s：層の切替。各層はラベルと一緒に1つずつ主役にする（重ねて見せない）。
- 3.0–5.5s：深さの選択（山場）。数字と波形は同時に出さず、波形はこの区間の後半だけ等、読む対象を時間で分ける。
- 5.5–6.5s：主役の数字（実測ワープ量、ラベル付き）。画面は数字だけに寄せる。
- 6.5–8.0s：手を離す＋宣言の2回目＋署名「PHYSICS SIMULATED — PERIODIC 2.00s」。
