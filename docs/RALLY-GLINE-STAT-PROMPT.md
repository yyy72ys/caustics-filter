# RALLY-GLINE-STAT-PROMPT — G-LINE 統計化の設計への攻撃検証（四者ラリー用原稿）

あなたはこの設計の**攻撃的レビュアー**です。設計者を守る必要はありません。主張ごとに判定を出し、反論と失敗条件を具体的に挙げてください。曖昧な賛成は要りません。

## 背景（確定済みの実測 — 攻撃の土台）

水面コースティクス（屈折で床に落ちる光の網）の合成画像について、軸平行 5–15 px 帯の変調深さ depth（‰）を 4 窓（smooth x / smooth y / bark x / bark y）で測り、同じ 4 窓の写真（63.7 / 61.6 / 47.4 / 39.3‰）と比べるゲート G-LINE がある。現行は単一 seed・単一フレーム（frame 24）で、全窓が写真以下なら合格。

v4-1.10 の実測（同じモデル・同じ合成器・seed だけ違う 5 本： 本番 + seed+1/+2/+3/+7、frame 24）：

| 窓 | 比（モデル/写真）の範囲 | 比の平均 | 本番 seed の比 |
|---|---|---|---|
| smooth x | 0.91 – 1.07 | 0.954 | 0.910 |
| smooth y | 0.93 – 1.02 | 0.984 | 1.016 |
| bark x | 0.78 – 1.07 | 0.946 | 1.070 |
| bark y | 0.97 – 1.29 | 1.120 | 1.168 |

- 4 窓すべてで写真以下になる realization は **5 本中 0 本**。系統的に写真を上回るのは bark y だけ（平均 +12.0%）。
- 振幅を揃えた正規化版でも範囲は同じ → 散らばりは振幅ではなくパターンの realization 由来。
- 窓原点の ±24 px シフトだけでも depth は動く（sd 2.2 / 2.4 / 4.7 / 2.4‰）。bark y の base 45.9 はシフト掃引の最大値 41.7 を上回る。
- 別ゲート G-LINE2（2D FFT の固定周期ピークの突出度 prom2d、24 窓中央値）： 写真 21.1 / 問題の作品 25.4（1.21×）対 本物の格子 105.6 / 116.2（5.0–5.5×）。写真自身の単窓最大 prom2d = 104（格子型並み）なので中央値が必須。副条件 modal_frac ≤ 0.20。

## 設計の提案（攻撃対象）

単発判定をやめ、窓ごとに**比の分布**で判定する。標本は R = 5 realization × F = 3 フレーム（2 秒ループから frame 0 / 24 / 47、n = 15）。窓合格は「平均 ≤ 1.05 かつ 90 パーセンタイル ≤ 1.25」、4 窓すべてで G-LINE-stat 合格。写真側は点ではなく窓配置ジッター（上記 sd を比の単位に直すと smooth x 3.5% / smooth y 3.9% / bark x 9.9% / bark y 6.1%）を測定床として併記し、平均の超過をジッター σ 単位でも表示する（bark y +2.0σ、他は −1.3σ〜−0.4σ）。q90 のブートストラップ区間が境界をまたげばその窓は「未解決」。G-LINE-stat（量の分布）と G-LINE2（固定周期か）を独立な 2 軸として併用する。土台が変われば（stage 2 の本物の 3D 床など）閾値を引き継がず測り直す。閾値 1.05 / 1.25 は観測ギャップへの配置値であって統計的導出ではない。

## 判定する主張

- **D1**： 単一 seed・単一フレームの G-LINE 合否はモデルの性質ではない。5 realization で全窓通過が 0 本という実測がそれを示す。
- **D2**： 窓ごとの比の分布（平均＋散らばり）で判定すれば、合否はモデルの性質になる。標本数 R = 5 × F = 3（n = 15）と平均の標準誤差を明記することがその条件である。
- **D3**： 写真側も分布として扱わなければならない。1 枚の写真の 4 窓を点としてモデル分布と比べるのは、同じ誤りを反対側で繰り返すことになる。窓配置ジッターを写真側の測定床として使うのが最小限の是正である。
- **D4**： 判定規則「窓平均 ≤ 1.05 かつ q90 ≤ 1.25、全 4 窓」は実測の散らばり（平均 0.95–1.12、最大 1.02–1.29）に較正されており、系統的超過（bark y +12%）と不利な引き（smooth y / bark x の本番 FAIL）を分ける。
- **D5**： 1 ループ内のフレームは独立標本ではない。実効標本数は realization 数で数えなければならず、フレーム数を n に水増ししてはいけない。
- **D6**： G-LINE-stat と G-LINE2 は独立な 2 軸として併用できる（量の分布 × 固定周期）。読み表の 4 組合せはすべて意味を持ち、どちらも本人の目の判定を上書きしない。

## 求める回答形式

主張ごとに **STANDS / WEAKENED / WRONG** の判定を出し、その根拠（数値・論理）を短く述べてください。さらに以下を必ず含めてください：

1. 各主張への**反論**（その主張が崩れる条件・データ・計算を具体的に）。
2. 設計の**失敗条件**（このゲートが誤った合格／誤った不合格を出すのはどんな場合か。例： n = 15 での q90 のノイズ、写真 1 枚という参照の薄さ、フレーム間相関の扱い、閾値の配置値であること、土台変更時の再較正の運用）。
3. **見落としている機構・論点**はないか（例： 窓の定義そのものの恣意性、depth 以外の統計量の方が分布判定に向いている可能性、4 窓の多重比較の問題、G-LINE2 との相関で 2 軸が実は独立でない可能性）。
4. 最後に、この設計を採用するなら**最低限直すべき点**を 3 つまで挙げてください（優先順位つき）。
