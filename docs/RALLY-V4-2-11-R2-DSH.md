前提（再論争しない土台として受領）：facet= H 上昇経路は撤回済み／Sk は独立チェック／旧比較「H_fit 0.29 vs Nikora 0.79」は同尺でなかった（0.79 は subgrain 帯の値、球充填では同手順で 0.94）。

## K1：差は実在する。同尺でも 0.43–0.45 vs 0.79。粒層自体を変える目標は維持される
- 判定：**STANDS**
- 理由：v4-2.12B の同尺（Nikora 手順：軸カット、折れ適応フィット、折れ探索窓 [0.25,2]×D50、第2区間 折れ〜4×D50）で H_Nikora = パッチ x 0.448/y 0.432、r1 x 0.435/y 0.438、r2 x 0.436/y 0.440。0.79 とのギャップは 0.34–0.36。別読み（第2区間をラダー末端まで）0.38–0.44 はむしろギャップを広げる方向（最大 −0.05）。折れ位置感度 ±0.013、6面内のばらつき約 0.016 に対しギャップは 20 倍以上。再現ゲートは旧物差し既報6値差 0.0、r2 は seed 再生成＋メタ28項目全一致＋同一性ゲート差 0.0 で手順バグ・偽物床の疑いは潰れている。折れ 10–18 mm（0.26–0.49×D50）の 5/6 が窓下端 0.25×D50 に張り付くのは物差しの欠陥疑いだが、別読みでも差が縮まらない以上「差そのもの」は残る。
- 判定が変わる条件：同一コードで参照側 DEM（Nikora 礫床）を測って ≤0.55 に落ちるか、窓を下側に広げた（例 [0.1,2]×D50）再測定でギャップが <0.10 まで潰れたら WEAKENED／WRONG に変える。逆に参照側が同窓で 0.75 以上を保てば STANDS は硬化する。

## K2：充填／filleting は H の機構として失格。機構Bのポケット細粒充填＋候補C は削除
- 判定：**STANDS**
- 理由：必要増分は 0.79−0.44 ≒ +0.35。合成充填（パッチ、priority-flood、δ=0.5σz）の実測は ΔH_fit 最大 +0.037（事前予測 ≤+0.10 と整合）、肝心の ΔH_Nikora 最大 +0.015（必要量の 4%）。δ=0.75σz でも ΔH_fit +0.055 が上限（16%）。文献の filleting 楽観上限 +0.05–0.15 を全部盛っても 0.44+0.15=0.59 <0.79 で届かず、交点は帯域の下。Nikora 系譜で H が上がったのは細粒の追加ではなく除去（winnow）と再配置・圧密であり、Mao 2011 の細粒充填での Hx 上昇も 0.1 級（0.45–0.60 の範囲内）で圧密と分離不能。合成実験と文献の独立2経路が同じ結論（1桁足りない）に収束した。
- 判定が変わる条件：充填のみの直接操作で ΔH_Nikora ≥+0.20（ギャップの半分超）が出るか、参照側／生成側の同一物差しペアテストで充填成分がギャップの 50% 超を説明できたら覆す。それまでは H 機構としての復活を認めない。σz・歪度の調整役としての残留はこの判定の範囲外。

## K3：次の主犯は粒径以下スケール。H_loc ≤0.49 は滑らか楕円体の署名。winnow／planation より先に立つ
- 判定：**WEAKENED**
- 理由：方向は有望だが優先順位の主張が証拠を越えている。H_loc が全ラグで最大 ≈0.49（最小ラグ 0.293 mm で最大、0.5 を一度も超えない）は確かに異常に低い。だがそれが「滑らかな楕円体の重ね合わせの上限の署名」であることの導出がない。粒接触のエッジ・オクルージョン・パッキング不連続も H_loc を抑える。真に滑らかな面なら最小ラグで H_loc→1 に近づくはずで、0.293 mm で 0.49 止まりが表面粗さかエッジ支配かは分解されていない。決定的欠落：参照側（0.79 を出す実床）の同一推定子による H_loc(lag) 曲線が示されていない。相手の subgrain 帯の H_loc が 0.5 を超えることの実証なしに「winnow や planation より先に立つ」とは言えない。
- 判定が変わる条件：STANDS 化には (a) 参照 DEM の同一 H_loc 推定子で subgrain ラグに >0.5（例 0.6–0.8）の隆起があること、かつ (b) K7 最小実験で H_loc が 0.5 を明確に超えて動くこと（ノイズ ±0.013 を超える +0.05 以上）の両方が必要。逆に K7 で H_loc が 0.50±0.02 に留まり H_Nikora も不動なら WRONG（主犯ではない）に落とす。

## K4：winnow＋interlock（機構A）は依然本命たりうる。ただし到達見込みを数値で
- 判定：**WEAKENED**
- 理由：「候補として残る」は正しいが「本命」は現数値が支えない。うちの床は既に装甲比 ≈1.9、σz/D50 0.39–0.46（実測装甲床帯域内）、パッチ歪度 +0.61 を持ちながら H_Nikora 0.44 に留まる。つまり装甲化だけでは +0.00 だった。文献の winnow 上昇報告の中心は 0.45–0.60 で、上振れいっぱい (0.60) を借りても 0.44→0.60 の Δ+0.16、0.79 まで残り 0.19–0.35 が残る。A 単独の到達見込みの数値回答は：現証拠での期待 ΔH_Nikora ≈ +0.0–+0.16、0.79 到達は未実証。到達には文献上限を +0.2 上回る新機構（強い interlock 秩序化など）の実証が要る。
- 判定が変わる条件：winnow＋interlock のみの制御実験で ΔH_Nikora ≥+0.25（0.44→0.69 以上）が出れば STANDS（本命復帰）。逆に制御 winnow で Δ ≤+0.05 なら WRONG（A 単独では届かない）に落とし、寄与役に降格する。

## K5：planation（粒頭選択除去、B-2b）は H 機構から落とし、σz・歪度調整役に降格
- 判定：**WEAKENED**
- 理由：落とす方向は正しそうだが、殺し方が消去法であって実測殺しではない。facet 経路死亡（前ラウンド全会一致）は受領する。削るだけでは正歪度は下がる方向（パッチ +0.61／帯状 −0.06／+1.00 の現状と衝突しやすい）もその通り。だが v4-2.12B で直接測られたのは充填だけであり、planation の ΔH_Nikora 実測はない。「充填が死んだので planation に経路は残っていない」は、winnow・interlock・表面粗さとの複合（削って噛み合わせが上がる等）を検証なしに否定する飛躍を含む。降格は妥当な仮置きだが確定ではない。
- 判定が変わる条件：直接の planation 操作（粒頭切断シミュレーション）で ΔH_Nikora ≤+0.02 かつ H 上昇の機構的経路なしの導出が出れば STANDS に硬化する。逆に planation 単独で ΔH_Nikora ≥+0.05 が出るか、planation＋interlock 複合で +0.10 級が出れば WRONG（H 機構として復活）に変える。

## K6：物差し固定 — 今回の Nikora 手順実装に固定し、定義つきでのみ語る。窓依存 −0.05 は併記
- 判定：**WEAKENED**
- 理由：同尺比較・定義つき言及・窓依存開示の方向は正しい。しかし 6本中5本が折れ探索窓下端 0.25×D50（≈9 mm）に張り付いた物差しを「固定」するのは早い。下端は格子 0.293 mm の 30 倍上であり、真の折れが窓下（<0.25×D50）にあれば系統バイアスが入る。同一物差し両側測定はバイアスを相殺する建前だが、参照側の折れが窓内部・生成側が下端張り付きなら切断バイアスは非対称に残る。別読み最大 −0.05 の併記は誠実だが、−0.05 はギャップ 0.35 の 14% であり無視できない。
- 判定が変わる条件：窓を下に広げた感度解析（例下端 0.1×D50）で順位・ギャップ（≥0.25）が不変かつ張り付きが解消されるか、参照側も同窓で同様に下端張り付きを示すなら STANDS に上げる。逆に窓シフトで両者差が >0.10 動くか順位が逆転したら WRONG（現窓での固定は破棄）に変える。

## K7：次の一手は bed_gen3 実装の前に粒 mm 凹凸／角張りの最小1面実験で K3 を殺しに行く
- 判定：**STANDS**
- 理由：順序として正しい。K2 死亡後の最大不確実性は K3 vs A であり、高コストの bed_gen3（機構A実装）の前に安価で決定的な片付け（1面だけ mm スケール表面凹凸／角張り粒を足し、H_Nikora と subgrain 帯 H_loc を測る）を置くのは合理的リソース配分。観測量の選び方も正しい（H_loc が 0.5 を超えて動くかが K3 の生死、H_Nikora が ±0.013 感度を超えて動くかが設計影響）。期待効果 +0.05 以上なら検出可能で検出力は足りる。
- 判定が変わる条件：WEAKENED 化は (a) 凹凸の振幅／波長（mm スケールの具体値）・1面の繰返し精度が規定されず再現性が ±0.03 を超える場合、(b) A の制御実験の方が安価・高速に回せる場合。その場合は最小実験の仕様化（振幅・波長・反復数 ≥2面）か順序入替を要求する。単一1面のままノイズと同程度の動きしか出なければ判定不能として再実験を命じる。

## 設計への最大の修正要求（1つのみ）
- **bed_gen3 の機構実装を凍結し、K3 最小実験（mm スケール表面凹凸／角張り粒の最小1面で H_Nikora と subgrain 帯 H_loc を測定）を先行ゲートにせよ。H_loc が 0.5 を超えて動くか・H_Nikora が感度 ±0.013 を超えて上がるかを確認するまで機構A実装に進むな。その間、H を上げる機構としての充填／filleting（機構Bのポケット細粒充填＋候補C）は設計から外しておけ。**
