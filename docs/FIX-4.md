# 修正指示 FIX-4 (FIX-3 実測の残件2点のみ)

方針は FIX-2 のまま (環境→水の状態→光の輸送→像)。メイン側の実測所見:

## 残件1: プリセット0でグリッターが格子状に並ぶ (最優先)
- FIX-3 の確率ゲート後も、書き出しPNGで星形のきらめきが
  等間隔の格子に並んで見える (特に蛾の翅の上)。
- 原因の読み: 微細法線が離散的な正弦波成分の和であるため、
  鏡面のピーク位置が準周期的に並ぶ。サンプリングのジッタでは消えない。
- 対策: 微細法線に、手続きノイズ (ハッシュベースの value noise
  2オクターブ、非周期) 由来の成分を混ぜる。振幅は水の状態 (風・微細成分) から決める。
  正弦波成分だけに依存しないこと。
- 条件: プリセット0の書き出しで、等間隔に並ぶ点・星が目視で
  認められないこと。きらめき自体は残す。

## 残件2: プリセット1の網目がまだ柔らかい
- FIX-3 でまだらな明暗は出たが、リファレンス1枚目のような
  「糸の輪郭のある網目」には届いていない。
- 対策: 密度に多重スケールを入れる — 広い eps の滑らかな密度に、
  細かい eps の鋭い密度を重ねる (どちらも同じ波高フィールドから)。
  冪カーブと再分配振幅の増強も可 (FIX-3 で明記された3係数が調整対象)。
- 条件: 像の読みやすさを保ったまま、網目の輪郭が立つこと。
  格子状の規則性は出さないこと。
