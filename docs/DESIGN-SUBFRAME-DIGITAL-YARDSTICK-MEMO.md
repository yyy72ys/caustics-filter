# DESIGN-SUBFRAME-DIGITAL-YARDSTICK-MEMO — サブ枠 G-CONV への「デジタルな物差し」設計案

状態: **設計案（未採用）**。cf-0169（2026-11-18 本人決定「別の手を新規項目で打つ」＋方向付け「別の物差しを。アナログではなくデジタルの」）の成果物。採用判断は本人の専権であり、本メモは推奨を「案」として提示するに留まる。
対象: サブ枠（窓 4.8000 × 3.5217 m、深さ 4.0 m、プリセット clear: U = 6.0 m/s / F = 100.0 m）で FAIL が確定したゲート G-CONV の物差しの設計。
大原則: 自然を再現する。「それっぽい」は却下。本メモは物差しを甘くして通すための設計ではない。判定が厳密になる代わりに測る対象が変わる候補については、その変更が物理的に何を意味するかを §6 に正直に書く。

## 0. 要約

- G-CONV は、C（コースティクス強度場）の std と p99 という**連続量のモーメント**が、格子を細かくしたときに 15% 以内に収まるかを見る物差しである。サブ枠では 512² → 1024² → 2048² と細かくしても差は縮まず、std はべき則（1 段ごとに約 0.7 倍、α ≈ 0.5）で下がり続けた。測定範囲では、この物差しは**有限の計算では永遠に判定を返せない**構造になっている（§1, §2）。
- 「デジタルな物差し」とは、連続量の漸近収束を閾値で見る代わりに、**数える量（整数のカウント）で判定する**物差しと定義する。候補は D1〜D4 の 4 件、却下候補 2 件（§3）。
- 第一候補（推奨案）は **D2（固定ビンのカウント移動量）＋ D1（超過面積カウント）の併用**。G-CONV が保証しようとした対象（C の分布・水準）そのものを、モーメントではなく「集合の測度＝画素数」で測り直す案である。補助に D3（折り重なりカウント）、既存の D4（保存台帳）はそのまま残す。

## 1. 実測の裏取り（一次資料）

出典: `BOARD.md`、`delivery/offline-v4-1-15/REPORT-V4-1-15.md`（§5, §5.1, §6）、`delivery/offline-v4-1-16/REPORT-V4-1-16.md`（§6.1）、`delivery/offline-v4-1-17/REPORT-V4-1-17.md`（§0, §2）、補助として `delivery/blur-discrim/REPORT-BLUR-DISCRIM.md`（§4、別条件の格子掃引）。

### 1.1 G-CONV の定義と FAIL の経緯

G-CONV の定義（v4-1.15 以来不変、基準値 15% は一度も動かしていない）: 同じ場を 2 つの水面格子で計算し、同じ出力格子（736 × 540）へ堆積した C の std と p99 の差が 15% 以内なら PASS。

| 比較 | std の差 | p99 の差 | 判定 |
|---|---|---|---|
| 256² vs 512²（frame 24） | +46.71% | +47.15% | FAIL |
| 512² vs 1024²（frame 24、上向き確認） | −33.81% | −26.00% | （15% 超） |
| 512² vs 1024²（48 フレーム、v4-1-16） | −31.68% | −25.64% | FAIL（48/48 フレームが 15% 超） |
| 1024² vs 2048²（48 フレーム、v4-1-17） | −28.63% | −17.68% | FAIL（15% 以内 0/48） |
| 512² vs 2048²（48 フレーム） | −51.25% | −38.80% | FAIL |

std の 48 フレーム平均は 512² で 0.6344 → 1024² で 0.4333 → 2048² で 0.3092。1 段ごとの比は 0.683 / 0.714 で、std ∝ N^(−α)、α ≈ 0.5 のべき則に乗り、**収束の兆候（比の 1 への接近）がない**。p99 は比 0.743 → 0.823 と減速が見えるが、std は減速していない。
さらに先の格子は物理的に回せない: 8192² はコミット 17.21 GB が物理メモリ 17.10 GB を超えて走らず、外挿 13.6 時間（ぼやけ判別測定での実測）。

### 1.2 堆積そのものは壊れていない

- エネルギー会計は全格子・全フレームで閉じている: サブ枠 STAGE B で相対誤差 1.1e-13（BOARD.md）、v4-1-16 で ≤ 2.90e-14、v4-1-17 で最大 8.06e-15。C の平均は全格子で 1.000000。
- 他ゲートはサブ枠でも通過している: G-ENERGY PASS、G-PEAK PASS（面積堆積のピークは点スプラット参照以上: std 比 1.436 / p99 比 1.333）、G-MOVE PASS（48/48）。G-LINE は合否のない診断で、写真超はあるが（最悪比 1.085）ゲートではない。
- つまり落ちているのは「計算の正しさ」ではなく、「C の std・p99 という統計量が格子に対して持つ振る舞い」だけである。

### 1.3 機構についての既存の所見（一次資料内）

- REPORT-V4-1-15 §5.1／結論: 「『半分グリッドと一致しない』ことは堆積の誤りではなく、**折り返した写像を有限の格子で切っていることの帰結**である」。
- ぼやけ判別測定（別条件）: 「折り返し由来の極端な値が平均化される（= スーパーサンプリング効果）」ため線幅は収束しても C の rms コントラストは 2048² でも 1 段 −24% で動き続けた。同測定では画素の 55% で det J < 0（折り返し）が起きている。
- 解釈上の疑い（本メモの見立て、実測ではなく推論として明記する）: 幾何光学のコースティクス強度は折り目（fold）の近傍で発散する特異性を持ち、画素値はその平均化である。std は二乗モーメントであり、分布の最も明るい裾に支配される。格子を細かくすると写像の切り方が変わり、裾の寄与がべき則で変わり続ける。**std は「格子を十分細かくすれば定まる量」ではない疑いが強い**——少なくとも到達可能な格子の範囲では定まらない。有限な太陽円盤や回折による正則化を入れていない純幾何光学の範囲では、連続極限の std が有限値として存在すること自体が保証されない。

## 2. 今の物差しの何が「アナログ」か

G-CONV の構造を分解すると、「アナログ」さは 3 点ある。

1. **測っている量が連続量のモーメントである。** std と p99 は実数値の統計量で、「正しい値」が連続極限にしか定義されない。有限の格子では常に近似値しか得られず、近似の良さ自体を別の近似と比較して推し量るしかない。
2. **判定が「漸近の途中経過」への閾値当てである。** 「連続する 2 段の差 ≤ 15%」は収束の代理指標にすぎない。べき則 std ∝ N^(−0.5) の下では、差の比は段によらず一定（約 −29%）なので、**この判定はどの段でも永遠に FAIL のまま**か、極限値が 0 でない場合でも到達不能な段数まで FAIL が続く。つまり判定不能が構造に埋め込まれている。
3. **測っている量が物理的に定まらない疑いがある。** §1.3 の通り、fold 特異性を持つ強度場の二乗モーメントは、正則化なしの幾何光学では格子（＝平均化の切り方）に依存する量であり、「自然の側に定まった値がある」保証がない。自然に存在しない量の収束を要求する物差しは、どれだけ厳密に運用しても判定を返せない。

対して「デジタルな物差し」に求める性質は次の通り: (i) 判定量が整数のカウント（または整数から作る量）である、(ii) そのカウントが指す対象が格子の切り方に依らない物理的な集合・事象である、(iii) PASS/FAIL が有限の回数の有限の計算で決まる、(iv) 閾値を甘くして通すのではなく、測る対象の変更を明示する。

## 3. 候補

### D1. 超過面積カウント（exceedance count）

- (a) 数えるもの: 出力格子 736 × 540 = 397,440 画素のうち、C > T を満たす画素数。T は平均（= 1）に対する物理的な倍率で事前に固定する（案: T ∈ {2, 4, 8}）。カウントは整数で、全画素数も有限。
- (b) 物理的根拠: 「床のうち、平均の T 倍より明るい面積がどれだけあるか」は実在の観測量である（検出器の画素が数える量そのもの）。fold 近傍で {C > T} の面積は、強度が d^(−1/2) で発散しても有限に定まる（発散点の近傍の測度は有限）。モーメントではなく集合の測度なので、§1.3 の特異性の問題を受けない。これは実在の物理に対応する物差しであり、数値的に中立でもある（計算方法ではなく測る対象の変更）。
- (c) 既存実測との接続: C の平均 = 1.000000 が全格子で厳密に保たれているため、T の基準（平均の倍率）は格子に依らず固定できる。エネルギー会計の閉鎖（1.1e-13〜8.1e-15）が、カウントの土台である堆積の正しさを保証する。G-LINE が診断として既に「面積・分布の言葉」で柄を見ていることとも整合する。
- (d) 有限性: 2 つの格子（例: 1024² と 2048²、どちらも高速堆積で実行可能圏）でカウントを取り、差が事前登録した個数幅（案: 全画素の ±0.5% = ±1,987 画素）以内なら PASS。整数の引き算 1 回で決まる。べき則の問題は測度には及ばない見込みだが、これは**見込みであり、初回は判定ではなく実測としてカウントの段間差を取る**こと（§7）。
- (e) 弱点: T を超えた先の明るさの分布は見ない（飽和する）。T の選択は事前登録が必須で、結果を見てから動かすと物差しを甘くする行為になる。T の境界近くの画素は格子で出入りするため、カウントには境界分の揺れが残る（個数幅はこの揺れより大きく、かつ物理的に意味のある幅でなければならない）。

### D2. 固定ビン・ヒストグラムのカウント移動量（bin-count migration）

- (a) 数えるもの: C の値域を物理的な固定ビン（案: 平均比で [0, 0.5), [0.5, 1), [1, 2), [2, 4), [4, 8), [8, ∞) の 6 ビン）に分け、各ビンの画素数（整数）を 2 格子で比べる。判定量は「ビンを移動した画素数」= (1/2) Σ |count_細 − count_粗|（全変動距離 × 全画素数）で、これも整数である。
- (b) 物理的根拠: 強度分布そのものを「どの明るさの面積がどれだけあるか」という測度の言葉で表すもので、D1 の一般化（D1 は累積ビンの特殊形）。分布の弱収束はモーメントの収束より弱い条件で成り立ち、fold 特異性を持つ分布でも有限の測度として定まる。実在の物理（床の明るさ分布）に対応する。
- (c) 既存実測との接続: std がべき則で流れ続ける一方で、平均は厳密に 1 に固定され、p99 は減速を見せている——分布の大域的な形はモーメントより安定している兆候が既にある。D2 はその安定性を直接の判定量にする。既存の numbers（std / p99 / max の系列）と併記すれば、旧物差しとの連続性も保てる。
- (d) 有限性: 移動画素数が事前登録した上限（案: 全画素の 1% = 3,974 画素）以下なら PASS、という整数判定。2 回の有限計算で決まる。D1 と同じく、初回は実測として段間差を取り、幅の妥当性を検証してからゲート化する。
- (e) 弱点: ビン境界の置き方に恣意性が残る（事前登録と、境界をずらした感度確認で対処する）。分布の形は見ても、柄の空間配置（どこが明るいか）は見ない。ビン内の移動は検出できない。

### D3. 折り重なりカウント（fold count / folded-cell audit）

- (a) 数えるもの: 水面メッシュのセルのうち det J < 0（折り返し）のセル数、その連結成分数、および折り返しセルの総面積（セル数の重み付き和）。すべて離散的な監査量。
- (b) 物理的根拠: 折り返しはコースティクスシートそのものの幾何であり、水面場（帯域制限されたスペクトルで定義され、格子に対して速く収束する）と幾何（深さ・太陽方向）だけで決まる対象である。強度モーメントを経由しないので特異性の問題を受けない。実在の物理（写像の折り目）に対応する。
- (c) 既存実測との接続: ぼやけ判別測定で det J の分布（p1 / p50 / p99、det < 0 の割合 55%）が既に測られている。G-CONV の FAIL の説明変数（「折り返した写像を有限の格子で切っている」）を、説明のまま終わらせず判定量に転用する候補である。
- (d) 有限性: セル数は有限で、場が解像されれば折り返し集合は幾何として安定し、カウントの段間差は有限計算で決まる。連結成分数は整数の完全一致まで要求できる可能性がある（ただし (e) の注意）。
- (e) 弱点: 測るのは水面側の折り目であり、床に届く明るさの分布そのものではない（G-CONV の代替としては対象がずれる）。折り目の合体・分離が起きる境界条件では連結成分数が跳ぶことがある。折り返し面積の収束速度自体は未実測。

### D4. 保存台帳の厳密照合（conservation ledger）— 既存・併用前提

- (a) 数えるもの: 堆積した全セルの寄与の合計と入射エネルギーの照合（相対誤差）、および「全セルがちょうど 1 回ずつ数えられたか」の整数監査。
- (b) 物理的根拠: エネルギー保存は実在の物理そのもの。現在の実測は相対誤差 1.1e-13（STAGE B）〜最大 8.06e-15（v4-1-17）で、事実上厳密に閉じている。
- (c) 既存実測との接続: 既に G-ENERGY として PASS している。デジタル化の追加要素は、誤差の上限を事前登録した固定値（案: 1e-9）にすることと、セル数の整数監査を併記することだけである。
- (d) 有限性: 1 回の計算で決まる。既に有限に判定できている。
- (e) 弱点: 保存は必要条件であり、柄の水準・分布の正しさは保証しない。単独では G-CONV の代替にならない。位置づけは「土台の監査」であり、D1/D2 と併用する前提の候補である。

### 却下候補

- **X1. ビット一致・再現性ゲート**（同一入力で出力がバイト一致するか）: デジタルではあるが、測るのは実装の同一性であり自然ではない。v4-1-16 の高速化の等価性確認としては有用だったが、G-CONV の代替としては却下（回帰検出用の補助には使える）。
- **X2. 変換統計（log-std、順位統計など）**: std の代わりに log C の std 等を見れば裾の支配は弱まるが、判定量は依然として連続量のモーメントであり、「漸近の途中経過への閾値当て」というアナログな構造は変わらない。デジタルな物差しの要件 (i) を満たさないため却下。なお「測る対象を変えずに甘くする」方向の案（15% の緩和、平均のみ判定への格下げ等）は、本メモの原則により検討対象外である。

## 5. 推奨（案）

第一候補は **D2 ＋ D1 の併用**とし、D3 を構造の補助監査、D4 を既存の土台として残す構成を推す。理由:

1. G-CONV が本来保証しようとしたのは「C の水準・分布が格子に依らないこと」であり、D2 はその分布をモーメントではなく測度（カウント）で測り直す、対象のずれが最小の置き換えである。D1 はその中で物理的に意味の読みやすい部分（平均の 2 倍・4 倍・8 倍より明るい面積）を個別に保証する。
2. fold 特異性に対して、モーメントは発散側の量だが測度は有限に定まる側の量である。「定まらない量の収束」を「定まる量の一致」に置き換えることが、甘くするのではなく物差しを正す行為である根拠になる。
3. 判定が整数の引き算で決まり、到達可能な格子（1024² / 2048²、高速堆積で 48 フレーム数分〜1 時間級）だけで運用できる。8192² のような到達不能な格子を要求しない。
4. D3 は FAIL の説明変数だった折り返しを監査量に転じさせるもので、D2 の分布の安定と折り目幾何の安定が同時に立つかどうかを見られる。片方だけでは見えない壊れ方を拾う保険になる。

## 6. 正直な注記 — 測る対象の変更が意味すること

- D1/D2 が PASS しても、「C の std がいくつか」には答えられない。std という量は、少なくとも現在の幾何光学モデルと到達可能な格子の範囲では、**自然の側に格子に依らない値を持たない疑いが強い**。写真との比較や他の段で std そのものが必要な場合は、その必要性を別途立てる必要があり、本物差しで肩代わりはできない。
- カウントの幅（D1 の ±0.5%、D2 の 1% など本メモの数値）はすべて**案**であり、実測の段間差を見てから事前登録する性質のものである。結果を見てから幅を決める手順を踏むと、それは物差しを甘くする行為になる。§7 の手順はこの順序を守るためにある。
- 「デジタル」であることは正しさの保証ではない。カウントは有限に決まるが、そのカウントが自然の何を表すかは (b) の物理的根拠の節に書いた通りであり、根拠の弱い候補は却下に回した。判定が返ることと、判定が意味を持つことは別の話として扱う。

## 7. 次の段（採用された場合の実施手順案）

1. **実測段（判定なし）**: サブ枠・48 フレーム・1024² と 2048² で C 場を取り直し（高速堆積 transport_mesh_fast、ビット一致実証済み）、D1 のカウント（T = 2, 4, 8）、D2 のビンカウントと移動画素数、D3 の折り返しセル数・成分数を、閾値判定なしで数表として出す。512² も添えて段間の傾向を見る。
2. **幅の事前登録**: 数表を見て、境界画素の揺れの大きさと物理的な意味から D1/D2 の個数幅を決め、BOARD に登録する。この登録より後に幅を動かす場合は、その事実と理由を記録する。
3. **ゲート化**: 登録した幅で 1024² vs 2048² の判定を行い、結果を G-CONV の後継ゲート（仮称 G-COUNT）として BOARD に記録する。旧 G-CONV の FAIL の記録は消さず、「物差しの変更とその理由」として本メモへの参照とともに残す。
