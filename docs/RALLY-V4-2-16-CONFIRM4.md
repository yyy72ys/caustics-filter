## 3席・2席で一致した急所

### 1. H3 の論理逆転（不成立。GPT・Gemini 一致、算術的事実として確定）

差分ゲートは |差| ≤ sd の形であり、独立窓 sd が大きいほどゲートは**緩く**なる。R5 は「大きい sd を使えば厳しくなる（甘い方を使わない）」と書いており、向きが逆。合否が変わる欠陥であり、言い換えでは直らない。Grok はこの逆転を検出せず条件付きとした（脆弱項目の「留保」扱いが全体合否にどう効くか未固定、という別の正しい指摘をした）。統合は GPT・Gemini の不成立を採用する。

### 2. H2 の本文矛盾（Gemini 不成立、GPT も同一箇所を指摘）

- §2.4 (B) は候補窓を「被覆率の良い帯から選ぶ」、§6.2 V2 は「面全体（u ∈ [−10,+10] m）を探索し中央値で選ぶ」。候補集合が節によって違う。面全体の被覆率上限は 31.6% で、面全体の中央値が 0.5 以上になる見込みは薄く、中央値近傍の窓を選ぶ規則と合わせると良被覆帯の外が選ばれうる。
- |∇z| 1.8–2.6 を V2 の合格包絡に入れる一方、V-H1 では ≥1.8 を棄却線にしている。同じ値が許容と棄却の両方になる。GPT は加えて「中央値 ≥0.5 かつ 25%以上が 0.5 以上」は数学的に冗長（中央値 ≥0.5 なら約半数が 0.5 以上）であること、重複候補窓の分布は独立した空間的証拠ではないこと、包絡を実測後に置き換えるなら事前固定の合格線ではないことを指摘した。

### 3. H1 の 1.8 棄却線の根拠（3席とも条件付き）

劣化で再現できたことと、Hodge の 2.1987 が人為的だということは別。枝 (b) はノイズと欠損を同時に入れるため原因の切り分けができない。Gemini の固有指摘: V-H1 の小ラグ閾値が「4–12 mm」と書きながら §1.6 で 4–5 mm をラダー誤差で除外済みであり矛盾する。1.4–1.8 域の感度 sweep に終了条件がない。Grok の条件: 1.4–1.8 帯の扱い（留保か、第2段の光学許容誤差 bound を事前固定して判定か）を一意に決めること。

### 4. H4 の V4 合格線の適用対象（Gemini 不成立）

V4 の合格線が「共通有効セル比較」に掛かるなら、マスクで揃えた比較では変化は恒等的に 0 で検出力ゼロになる。適用対象（補間全体比較へ固定）が未指定。Grok の条件: 両落ち時の例外承認を「本人の明示判断のみ」から「本人判断＋理由の文書化＋第三者確認」の3点セットにすること。

### 5. H8 の信頼ラグ下限（3席とも条件付き）

6 mm 下限の数値根拠自体は認められた。残る問題は上限側の停止線がないこと（Gemini）: 下限が跳ね上がって合否帯が極端に狭まった場合に (B) を不適格とする線がないため、帯を狭める方向の事後緩和の抜け道になる。Grok の条件: 「暫定値」を「V0 実行まで固定し、変更時は理由と新旧数値を明記して再登録」に書き換えること。
