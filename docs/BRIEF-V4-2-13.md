# BRIEF-V4-2-13 — Nikora 物差しの折れ窓感度較正（v4-2.13）

## 目的
v4-2.12B で固定した床 H の物差し（Nikora 手順の実装）について、ラリー第2ラウンド（RALLY-V4-2-11-R2 の改訂 R16）が要求した較正を行う。論点は2つ：
1. 生成床 3 面の折れのうち 5/6 が探索窓の下端（0.25×D50）に張り付いた。窓を下に広げると推定値はどう動くか、張り付きは解消するか。
2. 既知 H の合成場で測ると、この物差し（各窓設定）にどれだけ偏りがあるか。

判定は出さない。数値を出す仕事である。ただし「窓をどう変えても生成床と 0.79 の差（≥0.25）が残るか」は事実として報告すること。

## STAGE 0 — 前提確認（絶対パス。欠けたら STOP して報告。別ツリーを探さない）

- 12B の対象面3つが存在すること：
  - パッチ床の高さ場（12B が使ったもの。`out\v4-2-3\` 配下）
  - 帯状 r1 の高さ場（`out\v4-2-3\heightfield-long-r1.npy`、ヘッダなし float32 2048×10240）
  - 再生成 r2 の高さ場（`out\v4-2-12b\` 配下、12B が seed 再生成したもの）
- ゲート： 凍結窓 [0.25, 2]×D50 のまま 12B の H_Nikora を再現すること（パッチ x 0.4484 / y 0.4320、r1 x 0.4350 / y 0.4379、r2 x 0.4358 / y 0.4401、許容差 ±0.002）。再現しなければ STOP。

- W0 = [0.25, 2]×D50（基準、STAGE 0 と同じ）
- W1 = [0.15, 2]×D50
- W2 = [0.10, 2]×D50
- W3 = [0.05, 2]×D50
各面・各方向・各窓で報告： H_Nikora、折れ位置（mm と ×D50）、下端張り付きの有無、第2区間の傾き。あわせて 12B の別読み（第2区間をラダー末端まで）も W0 で再掲する。

## STAGE 2 — 既知 H 合成場での偏り較正
