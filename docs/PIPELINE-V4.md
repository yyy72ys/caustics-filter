# パイプライン v4 brief（本番ループレンダー — 全パラメータ凍結）

前提：`docs/OUTPUT-SPEC.md`、`docs/PIPELINE-V2.md`、v3 の合成確定（RESULT.md v3 節）。ここから先は新規判断なし。凍結値をそのまま全フレームに適用する。

## 凍結パラメータ
- プリセット1（緑の川の浅瀬・午前）、レシピ・シードは v2/v3 と同一
- 状態：2048² Phillips FFT、ω は 2π/8s の倍数に量子化（ループ周期性は v2 で実証済み）
- 輸送：決定論的ヤコビアン（det.py）、**Q=25**、ピクセルフィルタ σ0.75px、マスターは float32 のまま無クランプ
- 合成（v3 確定）：`render_frame_v3` の A=2.6（環境光スケール）＋変位ローパス σ3.0px@2048²、その上に露出プローブ（run_v3_exposure.py）と同じ C 層露出 **E=2.2**（直接項のみ）
- フレーム：**24fps × 192 フレーム**（8秒ループ）、t = frame/24 秒

## 実行要件（2時間超のジョブなので必須）
- **フレーム単位で冪等**：`offline/out/prod/` にフレーム成果物（C/flow の .npy と合成 PNG）が既にあればスキップして再開できること
- 進捗を `out/prod/progress.log` にフレームごとに追記（frame番号・経過秒・累計）
- 推定所要：192 × 約43秒 ≒ 約2.3時間
