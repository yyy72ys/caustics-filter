# @monoradio102 — Tilt to Peek（1枚絵→周回動画→傾きスクラブ）

対象投稿： https://x.com/monoradio102/status/2116746974716432602 （2026-11-01）
調査日： 2026-11-10。範囲： 本人スレッド（2投稿）＋公開リポジトリ README。直近50日の他作品ログは未確認。

## 手法
- 3D化はしていない。1枚の絵から「360°周回動画」を生成し、スマホの傾きに合わせて動画フレームを前後させることで立体感を出す（本人の明記）。
- 周回動画の生成： MiniMax H3 ＋ ORB360 LoRA（作者 MATLOW、HuggingFace 公開）。
- 公開デモ： https://monoradio102.github.io/tilt-to-peek/ （リポジトリ github.com/monoradio102/tilt-to-peek）。シーンごとに画像＋JSON（フレーム対応表）のペアで構成する単純な作り。
- 続報（2026-11-02）でデモを公開。返信では「回転方向が逆」という指摘あり（傾きと回転の符号合わせが勘所、と読める）。

## 蛾／コースティクスへの接続
- 蛾モデリング自体への処方ではない（分類 B）。
- 「1枚の成果物＋軽い仕掛けで立体感を足す」発想は、コースティクス web アプリや作品のスマホ展示（傾けると水面の奥が覗ける等）のプレゼン層に応用可能。
