閉鎖の判定基準: 次の4点がすべて現行規則として一意に読めること。(a) 支配機構を波数だけで固定しない。(b) 帯境界が U3 の環境パラメータと共通分散関係から場面ごとに決まる手続きがあり、10–150／250+ の値は初期区分へ格下げされる。(c) 砕波の形状変化の割当先が未割当でなく、発火の連動まで定まる。(d) 形状変形オペレータの要否宣言の手続き（U2a で宣言し、否なら誤差範囲を誤差予算へ載せる）がある。

争点:
(i) 二つの置き場の重なり: R2-17 は形状変化を U5／Δ_η,brk へ「仮置き」し、R2-25 は U2a で「要否と形式を宣言する」とする。仮置き（置くことが決まっている）と要否宣言（置かない選択がありうる）は両立するか。現行規則として、形状変化の扱いはどちらで一意に決まるか。

(iii) 三波移送の適用制限: R2-17（422行目）は「三波共鳴条件を満たさない帯域へ三波移送を適用しない」とする。この共鳴条件の判定は K2 の R2-5 の判定と同一のものを指すか。本文の相互参照はあるか。

### 回答形式（厳守）

- 最初の 1 行に最終裁定だけを書くこと: 「最終裁定: 閉鎖確認」または「最終裁定: 差し戻し」。

- §4 項目ごとの閉鎖判定として、項目 1–8 のそれぞれについて「閉鎖」「未閉鎖」の判定と理由を書くこと。

- **対象量の統一**： 突風応答は、成長側と減衰側を分離して記述する。ただし各率は、振幅 A(k) またはエネルギー E(k) のいずれを対象とするかを統一して定義する。線形粘性減衰 2νk² は振幅減衰率であり、エネルギー減衰率ならその2倍になる。Plant 系の成長率も、振幅・エネルギーのどちらを対象にするかで係数が変わる。異なる物理量の時定数を同じ表に並べてはならない。
- **減衰側の分解**： 減衰側は単一の静的参照表に固定しない。線形粘性＋状態依存の動的膜減衰率 τ_lin⁻¹(k, c(x, y, t)) = 2νk² + Δ_Marangoni(k, c, T) を局所状態（膜被覆 c(x, y, t)）から評価する。帯域間非線形移送 S_nl[N] および砕波散逸 S_ds,brk[N] は、緩和時間ではなく作用バランス内の非線形演算子として直接時間積分する。帯域間非線形移送は保存的なスペクトル流束であり、散逸ではない。ある帯域からエネルギーを奪っても別帯域へ移すため、符号も変わる。これを常に正の減衰率として 2νk² や膜減衰に加算してはならない。
- **τ の地位**： τ_grow(k) と τ_decay(k) は初期診断量である。突風後の実際の緩和時間は、非線形移送・空間伝播・履歴依存を含む時間発展方程式またはその線形化演算子から評価する。Plant 型成長率の逆数を、そのまま突風応答の緩和時間とは呼ばない。
- **U2b の記録（τ 表の廃止）**： U2b では単一の τ(k) 表を確定しない。振幅・エネルギーの別を明記した成長率、不可逆減衰率、保存的な帯域間移送、空間輸送、残差を別々に記録する。必要な場合は、これらの時間発展から得た成長・減衰の非対称な応答時間または応答核を示す。

#### R2-5 — C6 の Wilton 共鳴振幅方程式（§6.1 の C6′ を書き換える条文）

**置き換える対象**： 親 §6.1 の C6′「Wilton は 1:2 三波共鳴として非線形枠組みの中で扱い、寄生毛細波は独立機構のまま別置する。QTF の適用域は宣言でなく固有値／残差の実測で決める。」

- **共鳴の定義**： Wilton 共鳴は、基本波と第2高調波の 1:2 共鳴として扱い、寄生毛細波とは別機構に置く。共鳴判定は、採用する有限水深・表面張力・流れを含む分散関係に対して、周波数整合 ω₂ = 2ω₁ および波数ベクトル整合 k₂ = 2k₁ を満たすかで行う。「1:2」と書くだけでは足りない。
- **結合振幅方程式**： 共鳴近傍では、非共鳴 QTF の単純評価を継続せず、共鳴する複数モードの振幅を同時に解く結合振幅方程式へ切り替える。基本波の振幅 a₁ と第2高調波の振幅 a₂ を同時に未知量とし、da₁/dt = i·V₁₂·a₁*·a₂、da₂/dt = i·V₂₁·a₁² の形で書く（V₁₂、V₂₁ は採用する二次核から決まる結合係数。係数の導出元と値は実装ブリーフで固定する）。QTF の残差・固有値診断は切替判定の一部とし、三波共鳴の解法そのものの代替とはしない。
- **QTF 適用性の判定**： QTF の適用性は、QTF が近似する二次自由表面境界条件の残差、共鳴分母の大きさ、対象モードの振幅誤差、曲率統計およびバイスペクトルの誤差で判定する。「固有値」を用いる場合は、対象とする線形化演算子または結合振幅系を明記し、QTF 単体の固有値とは呼ばない。
- **寄生毛細波との分離**： 寄生毛細波は独立機構のまま別置する（親の既定を維持）。Wilton 共鳴の振幅方程式と寄生毛細波の生成項を混同してはならない。

#### R2-18 — C17′：渦寿命の追跡対象定義（§6.1 の C17′ を書き換える条文）
