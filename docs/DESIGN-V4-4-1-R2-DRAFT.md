## 1. 分解案

### v4-4.1 捕捉幾何（カメラの置き方と窓の実寸）

- **目的**：「写真＝窓」の約束を、有限位置のカメラ＋透視投影＋
  センサー寸法・焦点距離からの実寸対応に置き換える。
- **物理的根拠**：ピンホール／薄レンズの投影幾何。窓の実寸は
  W = W_s·(s/f − 1) で決まる（W_s = センサー幅、s = 合焦面距離）。
  カメラの位置・距離・角度が視線ベクトル場を決め、それが輸送側の
  Fresnel・屈折の入力になる。
- **入力**：カメラ位置（水面からの高さ・水平位置）、姿勢（視線角）、
  センサー寸法、焦点距離。場面側は水深と窓中心。
- **出力**：画素ごとの視線ベクトル場、床面上での窓の実寸と対応表、
  「直交・無限遠」極限で現行形に帰着することの確認データ。
  ※ラリー反映（2026-11-14）：視線場は輸送の**前段**で決める（有限カメラの
  視線角は Snell 屈折・Fresnel・水中路長を変え、直交前提の輸送結果を後段
  からは直せない — 順序の反転問題）。また有限開口の瞳サブレイの幾何
  （入射瞳の位置・大きさ・形状）もここで定義し、v4-4.3 の開口積分の入力に
  する。PRESETS の整合性は「逆算できる」だけでなく等価パラメータで同じ
  数値画像が再現されることまでを検査とする。窓のアスペクト（15:11）と
  マスター 2048²（1:1）の対応づけもここで固定する。
  ※R2 で固定（N1）：標準カメラはフルフレーム（幅 36 mm）、画素ピッチ
  17.58 µm（36 mm/2048）。記録の取り出しはマスター 2048² からの
  **中央クロップ（2048×1503 px 相当）、リサイズなし**とする（リサイズは
  ピッチを変え、MTF・Airy の px 換算を壊す）。正準カメラ高は三枠とも
  水面上 h_a = 1.0 m（枠は窓と深さだけで定義されていたため、カメラ高を
  ここで固定して一つのカメラ族にする）。焦点距離の逆算（s = h_a + d_w、
  W = W_s·(s/f − 1)）：メイン f = 38.11 mm（s = 1.6 m、W = 1.4755 m）／
  サブ f = 37.22 mm（s = 5.0 m、W = 4.8 m）／対比 f = 23.65 mm
  （s = 1.6 m、W = 2.4 m）。許容差：実装段で投影窓と指定窓の差が
  マスター解像度で 1 px 以内。床面窓式の一般形は
  W_bed(s_f) = W_s·s_bed(s_f − f)/(f·s_f) とし、現行式は合焦が床のときの
  特殊形として位置づける。入射瞳は薄レンズ面（水面上 h_a のレンズ位置）に
  置く円形瞳、径 D = f/N。サンプリングは K×K 規則格子とし、K は PSF が
  N3 の許容差内で収束するまで倍増させる（初期 K = 3、使用した K は
  条件ごとに記録する）。
  ※R2 追補（本人の指定、2026-11-16「50mm が好き」）：**50 mm 版を併記する**。
  形は2つ。(a) 同窓版（窓を三枠のまま、カメラを高くする）：メイン
  h_a = 1.4993 m／サブ h_a = 2.7167 m／対比 h_a = 2.7833 m。
  (b) 同高版（h_a = 1.0 m のまま、窓が狭まる）：深さ 0.6 m の枠は
  窓 1.1160 m（メインと対比は元の違いが窓だけだったため、50 mm 同高では
  同じ窓になる）、サブは窓 3.5640 m。50 mm 版の体制（ぼけ・回折・
  画角端の割れ）は計算ジョブ caustics-v4-4-map50 で実計算し、結果を
  N5 の地図に追補する。
- **検証**：既知寸法の標的（蛾の翅幅 40–53 mm／格子チャート）を場面に置き、
  実寸↔画素の対応が式どおりか測る。直交極限で既存の確定出力
  （v4-1.8 系）と一致を数値で確認。PRESETS 三枠をカメラパラメータへ
  逆算し、破綻がないかを示す。

### v4-4.2 見かけの距離場（輸送→カメラ段の受け渡し）

※ラリー反映（2026-11-14）：本節は「近軸・単一像枝の**有効**距離場」へ
格下げする。スカラー距離場は定義上1つの面であり、非点収差の2枚焦点も、
波の曲率で見かけ深さが ±∞ を通って水上に実像化する現象も表せない。
有効範囲（波の主曲率・視線角・開口）を数値で宣言し、範囲外は光線束／
波面情報への拡張対象として明記する。
  ※R2（N2）：有効範囲を数値で確定する（計算ジョブ caustics-v4-4-map、
  2026-11-16 実測。全文は delivery/v4-4-map/REPORT-V4-4-MAP.md）。
  視線角の上限 **θ_max = 31.8°**（見かけ深さの非点収差の割れが d_w の
  10% に達する角度は 31.82°、深さによらず同一＝スケール不変、Coddington
  式と 3e-7 まで一致して検証済み）。主曲率の上限 **κ_max = 53 /m**
  （メイン条件の実測 |κ1| p99、曲率半径 18.9 mm。|κ2| p99 は 22.1 /m）。
  サブ条件（preset 5）の曲率統計は未測定（presets_env に水面生成の
  パラメータが無く、対応づけは新しい基盤になるため測らなかった）ので、
  κ_max はメイン条件の値で暫定とする。開口の上限は N3 の契約
  （2D 近似＋誤差実測）の誤差実測を通る範囲とする。注意：対比枠は
  半画角 37.3° で画面端の割れが 13.6% となり θ_max を超える。対比枠の
  周辺部は有効範囲の外として扱い（拡張対象）、評価は中心部で行う。
  メイン・サブの半画角は 25.3°／25.8° で割れ 6.4%／6.6%、範囲内。

- **目的**：焦点と被写界深度が使う「距離」を、幾何距離ではなく
  水面屈折を通した見かけの距離として画素ごとに供給する。
- **物理的根拠**：平面屈折の虚像（近軸で実深さ/n、斜めでは非平面・
  非点収差）。波面では輸送の変位場が見かけの像そのものなので、
  距離場は変位場と対で輸送側から出す。
  ※訂正（2026-11-14、ラリー Gemini 脚）：幾何距離とのずれは「係数 n」では
  ない。空気層 h_a 込みでは s_app = h_a + d_w/n 対 s_geom = h_a + d_w で、
  メイン条件（h_a=1.0 m、d_w=0.6 m）では比 1.10、h_a=3.0 m では 1.04。
  n 倍はレンズが水面に接する場合の極限。
- **入力**：床の標高場（第2段）、水深、水面の状態、v4-4.1 の視線場。
- **出力**：見かけの距離場 D_app(x, y)（画素ごと）と、平坦水面・近軸条件で
  s_app = h_a + d_w/n に一致することの較正記録。
- **検証**：平らな床＋静水面の解析解（見かけの深さ = 実深さ/n）との一致。
  ※R2（N6）：放射輝度場は2成分で受け渡す。(a) 床成分（拡散・コースティクス）は
  D_app を使う。(b) グリッター成分（太陽の鏡面反射像）は別の見かけ距離場
  D_glit を持つ：ファセットの反射面内の法曲率 κ_n に対して
  D_glit = h_a + 1/(2κ_n)（鏡像の式。κ_n → 0 で無限遠。κ_n は水面場の
  曲率から輸送側が出す）。v4-4.3 の PSF は成分ごとに掛けてから合成する。
  D_app 単一場でグリッターを扱う形は採らない（C8）。
  斜め視線で距離場が単一面からどう外れるかを測定して記録（v1 で
  扱う範囲の宣言に使う）。

### v4-4.3 レンズ結像（焦点・被写界深度・ピント外し）

- **目的**：焦点合わせ、絞りによる被写界深度、ピント外しを、
  輸送後の放射輝度場に対する開口積分として実装する。
  ※ラリー反映（2026-11-14）：開口積分の**入力契約を明記すること**が確定
  条件。入力が単一視点の2D画像＋距離場のままでは真の開口積分にならない
  （瞳サブレイは水面の異なる点を通り、異なる屈折・遮蔽・体積散乱を受ける
  — 4席一致）。実装は「瞳サブレイ再トレース」か「2D近似である宣言＋
  誤差の実測」のどちらかを契約に書く。
- **物理的根拠**：薄レンズ式、ぼけ円 b = (f²/N)·|s − s_f|/(s(s_f−f))（幾何円の極限と Airy 盤の極限は分けて扱う）、
  開口積分＝開口上のピンホール像の重ね合わせ、回折 Airy 盤 2.44λN_w
  （N_w = N·s_f/(s_f−f)、有限共役の実効 F値）を PSF に合成。回折は本節の光学 PSF にのみ含め、v4-4.5 の記録 MTF には含めない。PSF は
  D_app から画素ごとに決まる。
  ※式の訂正（2026-11-14、ラリー Gemini 脚）：初版の分母 (s_f(s−f)) は
  s と s_f の取り違え。正しくは (s(s_f−f))。数値影響は小さい
  （C7 の例で 0.139→0.141 mm）が極限が誤っていた。あわせて、幾何円と
  Airy の単純畳み込みはデフォーカス 1–5 波長の遷移域で波動光学 PSF と
  ずれることを近似として明記する。cos⁴ 周辺減光と瞳の短縮（楕円ボケ）は
  レンズ固有収差でなく幾何として本節に含む。
- **入力**：放射輝度場（合成前の場、線形 HDR、クリップ前）、D_app、焦点距離 s_f（対象は
  水面／中間／床から選ぶ物理距離指定）、絞り N、焦点距離 f。
- **出力**：結像後の場。幾何光学 PSF はピンホール極限（N → 大、開口 → 0）で入力に
  帰着すること。波動光学 PSF（回折込み）はこの極限では入力に帰着しない（Airy 盤は N_w とともに
  広がる）。実カメラのピンホール極限では回折が支配的になる。
- **検証**：点光源チャートでぼけ円直径を実測し式と照合（許容差は
  設計時に固定）。2面チャート（水面相当面／床相当面）で合焦範囲が
  近点・遠点の式どおりか。平坦部での総光量保存（開口積分は平均を
  変えない）。回折側は点像の Airy 径を 2.44λN_w と照合（N_w = N·s_f/(s_f−f)。無限共役の条件で検証する場合は 2.44λN であることを明記する）。
  ※ラリー反映（2026-11-14）：「許容差は設計時に固定」を具体化すること
  ——PSF 検証の**許容差の数値と参照レンズ級を固定**しない限り C4 は
  反証不能（4席一致）。検証群は平坦水面＋解析解だけでは不足で、波面
  ケース・遮蔽境界・グリッター対床・空間変動 PSF・実レンズ PSF または
  高次光線追跡との照合を含む受入テスト群（統合 RALLY-V4-4-1.md の
  一致点4）として再編する。非平坦部では gather 型 PSF はエネルギーを
  保存しない点も検証対象。
  ※R2 で固定（N3）：入力契約は「2D 近似である宣言＋誤差の実測」を v1 の
  契約とする（現行スタックの輸送は単一視点の放射輝度場＋D_app を出す形で、
  瞳サブレイ再トレースの受け口が無い。再トレースは v2 の経路として残す）。
  誤差の実測は、テスト場面で瞳サブレイ再トレースの参照解と比べ、ぼけ径の
  差が許容差を超えた条件を契約の適用外として記録する形で行う。PSF 許容差：
  ぼけ円直径の式照合は max(0.5 px, 5%) 以内、Airy 径の照合は 5% 以内、
  平坦部での総光量保存は相対誤差 1e-3 以内。参照レンズ級は理想薄レンズ
  （収差なし）とし、実レンズの収差は v4-4.6 の範囲外に置く。受入テスト群は
  （波面ケース・遮蔽境界・グリッター対床・空間変動 PSF・高次光線追跡との
  照合・非平坦 gather のエネルギー非保存）の6件を必須とする。

### v4-4.4 焦点の時間制御（フォーカス移動）

- **目的**：動画で焦点を水面→中間→床へ移す操作を、s_f(t) の
  指定として実装する（2026-11-13 ユーザー着想 2-3 の正規スコープ）。
- **物理的根拠**：各瞬間の結像は v4-4.3 の静止形そのもの。時間方向の物理は二つある：(a) 焦点距離の軌跡 s_f(t)、(b) シャッター時間積分（露光中の水面・網目・グリッター・焦点の動きの積分＝モーションブラー）。(b) の入力はシャッター時間 t_shutter と露光区間、出力は時間積分後の記録像、検証はモーションブラーの実測照合とループ継ぎ目での時間積分連続性の検査とする。被写界深度の効く条件は体制地図（再計算後のもの）に限る。
- **入力**：s_f(t) のキー指定（時刻と対象面）、シャッター時間 t_shutter、露光区間、ループ長 T。
- **出力**：フレームごとの s_f と結像。境界条件 s_f(0) = s_f(T)
  （継ぎ目なしループ、SPEC の前提）。実効焦点距離の変化のうち
  レンズ固有分（ブリージング）は v1 では含めない（主張 C6）。
  ※ラリー反映（2026-11-14）：薄レンズでも導ける像面移動に伴う倍率・
  画角変化（面→床で 50 mm 級 5.6%、85 mm 級 10.2%）は「導けない」に
  含めない。v1 で両方とも固定するなら「定画角ピンホール＋薄レンズ DoF
  のハイブリッドである」と宣言すること。あわせて**シャッター時間積分**
  （露光中の水面・網目・グリッター・焦点の動きの積分＝モーションブラー、
  ループ継ぎ目の周期条件込み）は本節と v4-4.5 にまたがる必須項目として
  追加する（4席一致の見落とし）。
  ※R2 で固定（N4）：シャッター時間 t_shutter は場面パラメータとし、既定は
  フレーム間隔（24 fps）の 180° 相当＝1/48 s とする。時間積分は M 個の
  サブサンプルで近似し、M は積分像の変化が N3 の許容差内で収束するまで
  倍増させる（初期 M = 4、使用した M は記録する）。各時刻の評価順序は
  （水面状態→光輸送→焦点位置 s_f→PSF→センサー光量の蓄積）で固定する。
  周期境界条件は位置と速度の両方の連続性とする：s_f(0) = s_f(T) かつ
  s_f'(0) = s_f'(T)。水面状態も同じ周期で連続であることが前提
  （ループ作品の仕様）。
  ※R2（N5）：体制地図を実計算で確定する（caustics-v4-4-map、2026-11-16。
  全表は delivery/v4-4-map/REPORT-V4-4-MAP.md）。参照閾値 2 px
  （もう一方の面の実効ぼけ b_eff = sqrt(b² + d_A²) が 2 px 以下なら
  体制 A＝フォーカス移動が見えない、超えれば B＝移動が実在）：
  **メインは全 N で B**（b_eff の最小は 2.87 px、N = 18.3。絞っても
  A には届かない）、**サブも全 N で B**（最小 4.29 px）、**対比だけが
  A に入る**（N ∈ [5.2, 25.1]、ただし N = 16 では回折支配 D）。
  つまり作品の主条件ではフォーカス移動は常に実在する演出であり、
  「効かない条件」は対比枠の深い絞り側に限られる。検証アンカー
  （f = 35 mm、N = 2.8、水面合焦→床ぼけ 0.1407 mm = 8.01 px）も
  再現済み。
- **検証**：2面チャートの動画で、合焦面の移動が指定軌跡どおりか
  フレームごとに測る。シーム（t=0 と t=T の C 差分 max）を従来作と
  同じ物差しで記録。体制地図の外（両面とも合焦範囲内）では
  「変化なし」が正しい出力であることを確認する。

### v4-4.5 記録モデル（センサーと露出）と凍結合成の境界

- **目的**：標本化（画素ピッチ・画素開口）、MTF（画素開口 sinc・
