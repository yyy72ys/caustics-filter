# FIX-13: 網の細密化＋フィラメント sharpen＋微細波の等方化（検証経路が直った上での初の実測ベース調整）

## 前提（メイン側の実測で確定した事実）
- FIX-12 で検証経路が復旧。生の場 Cn を直接見た結果: fold 線・分岐（cusp）・セルというコースティクスの位相は実在する。蛾プリセット1では分岐点に分散フリンジを伴う放射状の網が確認できた。
- 残課題は場の統計3点に絞られた:
  1. **セルが大きく暗い**: 主波長（L帯の下限）が画角より大きく、画面内にセルが1〜2個しか入らない。リファレンス ref1 の網はもっと細かく、画面全体を覆う。
  2. **フィラメントが太く柔らかい**: バッファが描画解像度の 1/2 のため。スクラッチ実験で全解像度にすると線がフィラメント状に sharpen することを確認済み。
  3. **細部の縞が一方向に揃う**: 生 Cn にも斜め縞が存在（＝グリッターではなく場由来）。microSine の方向が4方向固定であることが主因候補。

## 変更要件
1. **バッファ全解像度化**（app.js）: `initCausticsTarget` の呼び出しを canvas.width / canvas.height（上限1024は維持）に変更。>>1 をやめる。
2. **スペクトル窓の引き上げ**（shader.js の FRAG / SPLAT 両コピー + CPUミラーの対応定数）: `KMIN = TAU / (6.0 * uSpecL)` の 6.0 → **4.0**。セル径 約2/3、セル数 約2.2倍を狙う。他の梯子定数（KMAX倍率 11.3137、NCOMP=36）は不変。
3. **microSine の等方化**（shader.js の FRAG / SPLAT 両コピー + CPUミラー）: 現行の4方向固定を、**8方向**（黄金角 2.39996 rad 刻みで回した方向列、各成分にハッシュ由来の位相）へ置換。振幅・空間スケール（周波数帯）は現行と同等に保つ（強さは変えず、方向の偏りだけを消す）。
4. DISP_K=2.0、帯域ゲイン、合成式、グリッター、FIX-12 のフィルタ選択は**不変**（凍結）。
