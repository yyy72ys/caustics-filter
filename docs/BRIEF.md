## Stage A: Webアプリ (本命・最優先で完成させる)
配置: `caustics-filter/web/` — ビルド不要の静的サイト
(index.html / styles.css / app.js / shader.js / env.js / recipe.js に分割可)

### 描画コア (WebGL)
- 入力メディア(画像/動画)をテクスチャにし、フラグメントシェーダーで:
  1. **波フィールド**: 方向性サイン波の重ね合わせ+ノイズ2オクターブで
     水面の高さ/法線を解析的に作る。時間は8秒周期で量子化し継ぎ目なしループ
  2. **揺らぎ**: 法線から屈折オフセットを求め入力画像をサンプル。
     RGBでオフセット量を僅かに変え色分散(虹色の縁、ref3)を出す
  3. **コースティクス**: 法線の発散/ヤコビアン系の集光項、または
     voronoi系の網目関数で光の網目を作り、太陽強度・水深・濁りで変調
  4. **グリッター/反射**: 太陽方向への高指数スペキュラで点状の鋭い輝き+
     フレネルで水面のツヤ。雲量が多いと鈍く拡散する
  5. **水の色**: 水深と色素(藻など)による吸収ティント。元の色を殺さない
- 物理の芯: 屈折率1.333相当の屈折量、太陽高度で光色が変わる(低い=橙)

### 環境ノード (UI)
- 通常モード = **繋がないノード**: 太陽/水/風と波/天気 の4ブロックを
  並べ、各ブロック内に実単位の変数を全部入れる
  (太陽: 時刻・日付・緯度 / 水: 水深m・透明度・濁り・色素 /
   風と波: 風速m/s・風向・波の細かさ・流れの速さ / 天気: 雲量%・大気の澄み)
- ブロック間の影響(雲→光の拡散、風→波、等)は内部で物理的に連動。
  影響関係は「表示のみ」の簡易ダイアグラムで見せる(編集不可)
- 上級モード: 結合エディタ — 結合の一覧(雲→太陽減衰、風→波高、
  太陽→コースティクス強度 等)の ON/OFF と重み(0–2)を編集できる
- **実在モード**: 地名+日時を入力 → ジオコーディング(Open-Meteo、
  キー不要)で緯度経度、太陽位置を天文計算、雲量・風速・風向・気温を
  Open-Meteo API から取得して各ブロックに流し込む。流し込み後は手編集可。
  API失敗時は太陽計算だけでも成立させ、天気は手動値のままにする

### 入出力
- 画像(png/jpg/webp)と動画(mp4/webm)を読み込み、動画は再生しながら適用
- 書き出し: 静止画PNG / ループ動画WebM(8秒、canvas captureStream+
  MediaRecorder)。動画入力時はプレビュー録画方式でよい
- レシピ: 全状態を単一JSON(schema v1、名前・実在モードの場所日時を含む)
  として保存/読込(localStorage一覧+ファイルdownload/upload)
- プリセット: 「真夏の沖縄・正午」「緑の川の浅瀬・午前」
  「夕方の湖」「曇りの日」「深い海」の5つ(refs の質感に寄せる)
- レイアウト: プレビュー最優先、詳細はオンデマンド。Edge-to-Edge
  (背景は端まで、重要UIはセーフエリア内)。スマホでも崩れないこと

## Stage B: Blender版 (Stage A の後)
配置: `caustics-filter/blender/caustics_from_recipe.py`
- レシピJSON+入力画像パスを引数で受け、Blenderシーンを生成:
  画像平面の手前に水の膜メッシュ(細分化+波変位、透過マテリアル IOR 1.333)、
  太陽ライトは太陽ノードの高度/方位/色から、レンダリングしてPNG出力
- Blender が PC に無い場合はインストールせず、スクリプト作成と
  `python -m py_compile` の構文確認まで行い、その旨を RESULT.md に書く
