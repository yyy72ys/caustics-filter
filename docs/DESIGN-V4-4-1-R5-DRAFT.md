### v4-4.2 見かけの距離場（輸送→カメラ段の受け渡し）

※ラリー反映（2026-11-14）：本節は「近軸・単一像枝の**有効**距離場」へ
格下げする。スカラー距離場は定義上1つの面であり、非点収差の2枚焦点も、
波の曲率で見かけ深さが ±∞ を通って水上に実像化する現象も表せない。
有効範囲（波の主曲率・視線角・開口）を数値で宣言し、範囲外は光線束／
波面情報への拡張対象として明記する。
  ※R3 で再定義（N2、統合 §6 項目3・4）：有効範囲を次の3量で宣言する。
  (1) 視線角の上限 **θ_max = 26.75°**。非点収差の割れの母数は像側の
  見かけ深さで割った **(d_s − d_t)/d_s** と定義する（訂正再計算 §5.3 の
  推奨を採る：d_s と d_t は同じ側の量で次元が揃い、判定は厳しい側に
  出る）。割れが 10% に達する角度は 26.753°（d_w によらず同一＝スケール
  不変、Coddington 式と 3e-7 まで一致して検証済み）。R2 の母数
  (d_s − d_t)/d_w（10% 到達 31.82°、31.82° での /d_s は 14.41%）は
  撤回する。三枠の半画角（Snell 精確 f の主光線）はメイン 27.357°／
  サブ 32.514°／対比 40.785° で、θ_max をそれぞれ 0.60°／5.76°／14.03°
  超える。したがって三枠とも画面端は有効範囲の外であり、評価は
  θ ≤ 26.75° の範囲で行い、周辺部は範囲外として扱う（50 mm 版は半画角
  20.4–24.7° で全変種が範囲内。R4 で補助分枝を採用した現行形では
  半画角は一様に 19.799° で全変種が範囲内）。(2) 主曲率の有効範囲は**単一像枝の
  臨界**で切る：κ_crit = n/((n−1)·d_w) = **6.67 /m（d_w = 0.6 m）／
  1.00 /m（d_w = 4.0 m）**。D_app が単一の見かけ距離として定義できるのは
  局所の主曲率が κ_crit 未満の領域に限る。メイン条件の実測
  |κ1| p99 = 53 /m は κ_crit の 7.94 倍（+46.33 /m）、|κ2| p99 =
  22.1 /m も臨界を超える。R2 の「κ_max = 53 /m を有効範囲の上限とする」
  宣言は撤回し、53 /m は観測事実（メイン条件の p99）の記録としてのみ
  残す。臨界を超えた領域では見かけ像は多像化・水上への実像化を起こし
  距離場では表せない。その領域の結像は距離場を経由せず、案1のサブレイ
  再トレース（v4-4.3）が各光線の実際の交点を取ることで直接扱う
  （範囲外＝拡張対象、という R2 の置き場は案1の本線化で解消する）。
  サブ条件の曲率統計は未測定のまま（暫定の扱いは変わらない。κ_crit は
  深さだけで決まる 1.00 /m）。(3) 開口の上限 **D_max = f/1.4**
  （体制地図の掃引 N ≥ 1.4 に対応する最大開口）：メイン 24.8 mm／

    方向の環境放射輝度を L_glit に入れる（status = SURFACE）。水面下面
    からの屈折で空気側へ出た場合は、出た先の環境放射輝度を L_env に
    入れて終端する（status = EXIT）。どこにも到達しない場合は全成分を
    0 とし、L_env にその方向の環境放射輝度を入れる（status = MISS）。
    遮蔽は (2) の最近接交点の順序で自動的に効く。体積散乱は水中区間に
    沿って積算し L_vol に入れる（積算の取り方は輸送側の定義に従い、
    第4段は関与しない）。
  - 決定性：同じ引数には同じ返却値を返す（隠れた乱数や、呼び出し順に
    依存する内部状態を持たない）。サンプリングは呼び出し側（第4段）
    だけが行う。
  - 対応関係：サブレイ（瞳サンプル・時刻）は呼び出しごとに1回だけ
    評価し、結果はその画素の当該サンプルの寄与として重み 1/N_total で
    積算する。床成分とグリッター成分は分離したまま積算し、合成は
    積算後に行う（受入テスト (3) の分離検証のため）。D_app／D_glit は
    焦点設定・体制地図・受入テストの参照量として残るが、結像の入力では
    なくなる（R3 から不変）。
  **(2) 交点選択規則（R4 最低条件1）**：光は経路の順に相互作用するので、
  選択規則は**経路順の最近接**とする（エネルギー最大などの事後選択は
  採らない）。
  - 各区間では、現在の始点から光線方向に測った距離 t が最小の正の
    交点（t > 1e-6 m。自己交点の回避）を取る。水面（高さ場）との交点と
    床（高さ場）との交点の双方が候補になる場合は、小さい方の t を取る。
  - 空気側から水面へ入る交点では、入射角 θ_i に対する非偏光 Fresnel
    反射率 R_F(θ_i) で2枝に分岐する（※R5）。屈折枝は重み 1 − R_F で
    Snell 屈折して水中へ進む。反射枝は重み R_F で鏡面反射方向 ω_r へ
    進み、その環境放射輝度 R_F·L_env(ω_r) を L_glit へ加算する（生成式
    は ※R5 (a)）。空気側に全反射はない。水中で水面下面へ再到達した場合は Fresnel で
    判定する：入射角が臨界角（asin(1/1.333) = 48.61°）以上なら
    全反射して水中を進む（重み 1）。それ未満なら反射枝（重み R_F）と
    屈折枝（重み 1 − R_F）の2枝に分割して両方を追跡し、各成分は両枝
    の重み付き和で返す（※R5 (b)。片枝切捨ては廃止）。status は重みの
    大きい方の枝の終端種別とし、診断用のみとする。屈折枝が空気側へ
    出た時点でその枝は status = EXIT として終端する。
  - 相互作用の回数の上限は4回とする。達した場合は status = ABSORBED
    とし、その時点までの L_vol のみを返して終端する。打ち切り時点の
    残り重み w_rem（経路上の分岐重みの積）は像へ加算せず、画素ごとの
    損失台帳 L_lost（無次元の重み）へ記録する（※R5 (c)）。
  - 多像は画素の側の性質として扱う：1本のサブレイの経路は上の規則で
    一意に決まる。異なるサブレイが同じ床点へ届くこと（多像化）は
    積算の結果として自然に現れ、選択の問題にはならない。D_app が
    必要な場面（受入テスト (4) の予測）では、多像域はマスク外
    （κ ≥ κ_crit）として D_app を使わない（v4-4.2）。
  ※R5（輸送契約のエネルギー保存。統合 §4 優先1・§5 条件1）：
  (a) 空気側 L_glit 反射枝の生成式：瞳サブレイが空気側から水面へ入る
  交点では、入射角 θ_i に対する非偏光 Fresnel 反射率
  R_F(θ_i) = (R_s + R_p) / 2 で2枝に分岐する。R_s =
  ((cosθ_i − n·cosθ_t) / (cosθ_i + n·cosθ_t))²、R_p =
  ((cosθ_t − n·cosθ_i) / (cosθ_t + n·cosθ_i))²（n = 1.333、θ_t は
  Snell 則 sinθ_t = sinθ_i / n）。反射枝は重み R_F で鏡面反射方向
  ω_r へ進み、その環境放射輝度 R_F·L_env(ω_r) を L_glit へ加算する。
  屈折枝は重み 1 − R_F で Snell 屈折して水中へ進む。R4 の「空気側
  から水面へ入る交点では Snell 屈折で水中へ進む」は、反射枝の欠落
  として現行無効とする（§9 無効リスト #15）。
  (b) 下面 Fresnel のエネルギー保存方式：水中で水面下面へ再到達した
  場合、臨界角以上なら全反射（重み 1）。それ未満なら反射枝（重み
  R_F）と屈折枝（重み 1 − R_F）の2枝に分割して両方を追跡する（片枝
  切捨ては廃止）。下面での R_F は (a) と同じ非偏光 Fresnel 反射率で、
  入射側が水（n1 = 1.333）・出射側が空気（n2 = 1.0）として計算する。
  2枝分割を選ぶ理由：決定論的で再現性があり、重みの和が 1 になって
  エネルギーを保存するため。不偏選択（乱数で1枝を選び重みで割る）は
  分散を入れるため、決定性を要求する本設計では採らない。各成分は両
  枝の重み付き和で返す。status は重みの大きい方の枝の終端種別とし、
  診断用のみとする（L の値には影響しない）。分岐のたびに相互作用
  回数を数える。
  (c) 4回打ち切り時の残余エネルギーと ABSORBED 時の像寄与規則：相互
  作用回数が4回に達した時点で追跡を打ち切り、status = ABSORBED と
  する。打ち切り時点の残り重み w_rem（経路上の分岐重みの積）は像へ
  加算せず、画素ごとの損失台帳 L_lost（無次元の重み）へ記録する。
  像への寄与はその時点までの L_vol のみとする（R4 から不変）。打ち
  切られた光のエネルギー見積りは w_rem × L_env（打ち切り方向の環境
  放射輝度）とし、テスト (6) の台帳に計上する。
  (d) L_vol／L_env の画素積算式：1画素の像は I(p) = (1/N_total) ·
  Σ_s [L_bed(s) + L_glit(s) + L_vol(s) + L_env(s)]（s はサブレイ、
  N_total は総数）とする。各成分は TR が重み込みで返した値であり、
  呼び出し側は重み 1/N_total で積算するだけである。L_vol は水中区間
  に沿った体積散乱の積算値（散乱係数・位相関数は輸送側の定義による。
  v1 は単一散乱の区間積分とする）、L_env は終端方向の環境放射輝度
  である。成分分離したまま積算し、合成は積算後に行う（(1) から
  不変）。
  (e) MISS／EXIT の意味：MISS は瞳からの光線が水面・床のどちらとも
  交わらず場面を素通りした場合とし、L_env には元の方向 ω の環境放射
  輝度を入れる。EXIT は水に入った光線が下面屈折で空気側へ出た場合と
  し、L_env には出た先の方向の環境放射輝度を入れる。両者の画素への
  寄与は同じ L_env の形であり、区別は経路の診断とテスト (6) の内訳
  （素通りと窓外逸脱の区別）のためだけに残す。
  (f) テスト (6) の 5% との数値接続：テスト (6) の合否は次のエネル
  ギー台帳で判定する。入力束の総量を E_in とし、画素ごとの像の総量
  E_img（L_bed + L_glit + L_vol + L_env の画素和）に、打ち切り損失
  の見積り E_lost（Σ w_rem × L_env、打ち切り方向の環境放射輝度で
  評価）と窓外逸脱分 E_esc（窓の外へ出た光線の輸送側での記録）を加
  えたものが E_in と一致すること。すなわち |1 − (E_img + E_lost +
  E_esc) / E_in| が、平坦部では 1e-3 以内、非平坦部では 5% 以内である
  こと（テスト (6) の数値そのもの）。台帳の各項が E_in へ合算される
  ことが、テスト (6) の 5% が輸送契約のエネルギー保存と接続している
  ことの数値的な意味である。
  **(3) 回折の生成機構（R4 最低条件1）**：幾何的サブレイ追跡だけでは
  回折は生じない（ピンホール極限で点が1点に収束する）。v1 の生成
  機構は次の畳み込みとする：結像段の幾何像（サブレイ積算の結果、
  線形 HDR）に対し、画素ごとに局所の実効 F 値
  N_w(x, y) = N·s_f/(s_f − f) から決まる Airy 核（直径
  2.44λ_d·N_w、λ_d = 550 nm）で畳み込む。根拠：回折は有限開口の
  瞳関数のフーリエ変換に由来する実在の物理であり、無収差・合焦の
  円形瞳ではその強度分布が Airy パターンそのものになる。デフォーカスを
  含む一般の場合は真の波動 PSF とずれる近似である（遷移域のずれは
  上の ※式の訂正の注記のとおり）。近似の誤差は受入テスト (5) で
  波動光学の独立参照（瞳関数の FFT 伝播、デフォーカス位相つき）と
  照合して測る。ピンホール極限（N → 大）では幾何像は入力に帰着するが
  Airy 核は広がり続けるため、波動込みの出力は帰着しない（出力欄の
  極限の整理と一致）。
  **(4) 許容差の分離**：ぼけ円直径など幾何量の照合には
  max(0.5 px, 5%) を適用する（差の絶対値が 0.5 px と参照値の 5% の
  うち**大きい方**以下であること。小さいぼけでは 0.5 px の絶対床が
  効き、交点は参照値 10 px）。**Airy 径の照合には 0.5 px 床を
  使わない**：許容差は max(0.02 px, 5%) とする。根拠：
  d_A = 2.44λ_d·N_w / 17.58 µm は N_w ∈ [1.4, 16] で
  0.107–1.222 px であり、0.5 px 床では N_w ≲ 6.5 の範囲で回折が
  皆無（測定 0）でも合格してしまう。0.02 px 床なら測定 0 は全範囲で
  不合格になる。平坦部での総光量保存は相対誤差 1e-3 以内。参照
  レンズ級は理想薄レンズ（収差なし）とし、実レンズの収差は v4-4.6 の
  範囲外に置く（R2 から不変）。
  **(5) 倍増収束規則（総数 N_total への一本化）**：サンプル数の収束は
  総数 N_total（v4-4.4 ※R4 の結合列）の倍増で判定する。n と 2n の
  結果について、(i) 像 RMS 相対差（(6) の定義）が 1e-3 以内、
  (ii) (6) のブロック条件を満たす、(iii) ぼけ径など代表スカラー量の
  変化が幾何量の許容差以内（Airy 径を代表量に使う場合は Airy 専用
  許容差）、のすべてを満たした時点で収束とし、その N_total を記録
  する。上限（N_total ≤ 2^20 = 1,048,576。旧 S ≤ 4096・M ≤ 256 の
  積と同等の総量予算）に達しても満たさない条件は、契約の適用外として
  記録し、**その条件の画像は納品物に含めない**（部分結果は検証用に
  のみ保持する）。壁時間は条件ごとに記録する。標準3枠の正準条件が
  適用外に落ちた場合は設計へ差し戻す（納品しない）。
  **(6) RMS 相対差の定義**：線形 HDR 像 I_n（総数 n）と I_2n について、
  画素平均の二乗差 D = sqrt(mean_p (I_2n(p) − I_n(p))²)、基準
  R = sqrt(mean_p I_2n(p)² + (1e-3 · mean_p I_2n(p))²) とし、
  相対差 = D/R とする（分母の第2項は暗部・ゼロ近傍での発散を防ぐ
  床で、平均輝度比 1e-3）。高輝度グリッターに分母が支配されて暗部の
  誤差が隠れることを防ぐため、ブロック条件を併用する：像を
  32×32 px のブロックに分け、ブロック平均が全体平均の 1% 以上の
  ブロックすべてで、同じ式によるブロック相対差が 3e-3 以内である
  こと（3e-3 は R4 の新規設計値。確認ラリー第4回の監査対象として
  明記する）。時間方向の収束（旧 M の役割）も同じ N_total の倍増で
  判定し、追加で露光内グリッター像の時間積分重心の移動量の変化が
  0.5 px 以内であることを課す（点列のストロボ誤差は全体 RMS では
  検出しにくいため）。
  ※R5（(6) の定義の固定。統合 §4 優先2・§5 条件2）：
  I_n の成分定義：I_n は総数 n の結合列で計算した最終の線形 HDR 像
  （納品像）とする。成分分離した床成分像 I_n^(bed) とグリッター成分像
  I_n^(glit) も同じ n で記録するが、(6) の像 RMS 相対差の合否は
  総和像 I_n = I_n^(bed) + I_n^(glit) で判定する。成分像は診断用に
  残し、合否には使わない（ブロック条件の例外は下記）。
  端数ブロックの処理：像は 2048×1503 px であり、32 px 単位では
  横 64 ブロック（2048/32、端数なし）、縦 46 ブロック（1472 px）
  ＋端数 31 px となる。端数 31 px（行 1472–1502）は 32×31 px の
  部分ブロックとして扱い、平均はその 992 画素で取る。部分ブロックにも
  同じ 1% 選択規則と 3e-3 判定を適用する。ブロック総数は 64×47。
  非グリッター基準のブロック判定：ブロック条件の選択と判定は床成分像
  I_n^(bed) で行う（グリッター成分は含めない）。すなわち、ブロック平均
  は床成分の平均、全体平均は床成分の全体平均とし、床成分の平均が
  床成分の全体平均の 1% 以上のブロックすべてで、(6) の式を床成分像に
  適用したブロック相対差が 3e-3 以内であること。グリッターのちらつきが
  ブロック判定を動かさないための規則であり、総和像の RMS 相対差は
  (6) のとおり総和像で判定する。
  グリッター時間積分重心の計算式：露光内のグリッター像の時間積分を
  G_n(p)（画素 p におけるグリッター成分の時間積分値、すなわち
  I_n^(glit) の p における値）とし、重心 c_n = Σ_p p·G_n(p) /
  Σ_p G_n(p)（p は画素座標の2次元ベクトル、和は全画素）とする。
  判定量は |c_2n − c_n|（ユークリッドノルム、単位 px）であり、
  0.5 px 以内を合格とする。

  （(6) の式を PSF 像に適用したもの）とし、許容差は 5% 以内とする。
