### F4 — 最低条件 3 の統計残件：RNG 補充規定とブートストラップの適用範囲（→ E3）

R9 は §5 の J3' の σ_λ₃ の求め方に 2 点を追記した。(a) 補充規定（R9 764行目）：「重複の除外によって有効標本数が 400 本を下回った場合は、既存の全系列と重複しない新規の RNG 系列で追加の実現を生成し、有効標本数を 400 本以上へ回復させてから σ_λ₃ と λ₃,exact を計算する。400 本未満の有効標本で J3' を判定してはならない。補充分の系列もシード一覧に記録し、非重複を同じ手順で確認する」。前提の R8 規定は、主走行と独立再現走行の RNG 系列（シード一覧）を併せて記録し、両走行の間で系列の重複がないことを確認する（重複した標本は独立標本として数えない）、というものである。(b) ブートストラップの適用範囲（R9 766行目）：「単一の 400 本標本からの復元抽出は、その標本内部のばらつきしか再現しない。独立再現走行の RNG 独立性はブートストラップでは再現できないため、独立再現の 15% 条件の確認は実際の独立再現走行そのもので行い、ブートストラップで代用しない。ブートストラップで確認する範囲は前半・後半の差の分布までとする。あわせて、前半・後半の確認には、400 本をランダムに 2 分割する置換を用いることも許容する」。ブートストラップ確認の本体（誤判定率を再標本 10,000 回で確認し、正規近似と 2 倍を超えて食い違えばブートストラップ側を採用）と CI 幅条件（CI 全幅が許容幅の 25% 超で不合格（判定不能））は R8 のままである。

問うこと：(1) 補充規定は実行時に閉じているか。補充の繰り返し（補充分同士・補充分と独立再現走行との重複が再び見つかった場合）の手順は「同じ手順で確認する」で足りるか。補充後の標本について、前半・後半の安定性条件はどう数え直すのか（「前半・後半」は生成順か、系列一覧の順か）。(2) ブートストラップの適用範囲の明記は十分か。「ブートストラップで確認する範囲は前半・後半の差の分布までとする」と、R8 の本体規定（誤判定率が 2 倍を超えて食い違えばブートストラップ側を採用する）の関係は一意か。独立再現の差についてはブートストラップ側の数値を採用する経路が閉じられたことが読めるか。(3) ランダム 2 分割の許容は、前半・後半条件の意味を変えないか。時間順の前半・後半の差は生成過程のドリフトを拾うが、ランダム 2 分割はそれを拾えない。両方を同列に許容することは条件の弱体化ではないか。使い分けの記録は要らないか。

### F5 — 最低条件 3 の U-1a 残件：発効条件・切り分け手順・退化点・θ₁₂=45°（→ E5）

R9 は §6 の U-1a（R9 800行目）に 3 点を入れた。(i) 発効条件：「本ゲート（合否線 ε_ang < 10⁻¹²・試験格子・誤差定義）は、照合相手である Bredmose (2005) 式 (59)/(62)（または Sharma & Dean の方向形）の**転記が完了した後に発効する**。転記が未完の間はゲートは未発効であり、照合の数値を出しても合否は付けない」。(ii) 切り分け手順：「まず転記と規約換算（B^± = 2h_s 等）の再照合を行い、転記の誤りが見つかれば転記を直して再測する。再照合でも差が説明できない場合に限り、導出検証（MF12 Lambda2 の導出と実装の検証）へ戻る。1 回の不合格をもって直ちに理論間差異と断定しない」。(iii) 退化点の無次元化：「B_floor も 0 になる退化点の誤差は |B_MF12 − B_ref| / k_p < 10⁻¹² で測る（B の次元 1/m を当該水深のピーク波数 k_p で割って無次元化する）。なお 300 点の格子上では B_floor = |B⁺(θ₁₂=0)| が 0 になる点は見込まれないが、規範として本分岐を閉じる」。あわせて試験格子に θ₁₂ = 45° を追加した：「θ₁₂ ∈ {30°, 45°, 60°, 90°, 135°}（45° は R9 で追加）、(k₁, k₂) は k_p 基準の代表格子 {0.5, 0.7, 1.0, 1.4, 2.0}·k_p の順序なしペア 15 組、h ∈ {0.6, 4.0} m、pm は和・差の両方。計 5×15×2×2 = 300 点で測る」。線・誤差定義の本体（ε_ang < 10⁻¹²、ε = |B_MF12 − B_ref| / max(|B_ref|, B_floor)）と、U-1a の期限・「暫定採用」の地位・独立ゲートであることは R8 のままである。前提の未完も変わらない：Bredmose (2005) 式 (59)/(62) は OCR で転記できておらず、Sharma & Dean (1981) の直接転記もしていない（§6・§9）。

実測の証拠：300 点の算術：5（θ₁₂）×15（ペア）×2（h）×2（pm）= 300 で、本文の数値と一致する。G-C1-0 の既存の照合実績は機械精度級である（単色波アンカー ≤5.4e-16、θ=0 での一致は和 ≤6.4e-15・差 ≤1.6e-14）。第7回 E5 の統合は、線・格子・誤差定義は閉じたが「発効条件と切り分け手順が未明記で、結果を一意に処理できない」として不成立寄りとした。

問うこと：(1) 発効条件の明記は、ゲートの仕様として閉じているか。転記の完了は誰が何をもって判定するのか（転記と原文の照合記録が完了の証拠になるのか）。未発効の間、U-1a の期限（フェーズ1本採用判断の前）はどう効くのか（転記が終わらない限り本採用判断へ進めない、という読みで一意か）。(2) 切り分け手順は終端を持つか。導出検証でも差が説明できない場合、その先（理論間差異として記録し、2D 一般角形の地位をどうするか）は書かれているか。再測の繰り返しに上限や停止条件は要らないか。(3) 退化点の /k_p 無次元化は妥当か。k_p は水深で異なる（4.02 と 14.15 rad/m）ため、同じ < 10⁻¹² の線でも絶対誤差の許容量は水深間で約 3.5 倍違う。この非対称は正当化できるか（B の大きさ自体が k_p に比例するなら相対的な物差しとして一貫する、という読みでよいか）。「退化は見込まれない」という留保つきで分岐を閉じる形は、規範として十分か。(4) θ₁₂ = 45° の追加で格子は十分になったか。残る角度の隙間（0°–30°、135° 超）は、θ=0 の照合実績と合わせて許容できるか。

### F6 — 最低条件 3 の §10 残件：照合パスの実行者・事後処理・救済（→ E6）

R9 は §10 の引用照合規律（R9 957–967行目）に運用の 3 点を追記した。(1) 実行者（R9 965行目）：「照合パスは統合書の作成者が実行し、引用箇所ごとの照合表（引用文・原文の有無・節番号・行番号）を統合書に付す。実行者と照合表のない照合パスは、行ったものとして扱わない」。(2) 事後処理（R9 966行目）：「確定済みの統合書に後から照合漏れが見つかった場合、統合書そのものは書き換えない。訂正は次改訂の草案と次回の統合書に記録し、漏れた引用に依拠していた根拠は無効化する。その根拠で支えられていた判定・修正条件は、次回統合で再判定されるまで根拠なしとして扱う」。(3) 救済（R9 967行目）：「脚の節番号・行番号の誤記など、引用箇所の特定に失敗しただけの主張は、直ちに「引用未確認」へ落とさない。統合者が本文を全文検索して原文の有無を確定させてから、「引用の誤り」（原文なし）か「本文の不備」（原文あり）かへ振り分ける。全文検索でも原文を特定できない場合に限り「引用未確認」とする」。規律の中核は R8 のままである（引用は原文で照合する／判定は投票で決めない／プロンプト側の手続き／ラリー記録は書き換えない／照合パスは必須チェックで、行わなかった統合書は確定しない／「引用未確認」は根拠から除外する）。

実測の証拠：引用の誤りの実例は 2 件記録されている（第4回の Gemini の 2 式、第5回の Gemini の末尾の逆文。いずれも本文に存在しない）。第7回の E6 の残件はこの運用 3 点だけであり、統合は「残るのは運用の 3 行の追記だけである」とした。

問うこと：(1) 実行者の明記と照合表の形式は、照合パスの実行可能性を閉じるのに十分か。照合の対象範囲（脚が引用したすべての式・数値・文章か、判定に使ったものだけか）は、中核の規定（「脚が引用した式・数値・文章の原文照合パス」）と合わせて一意か。(2) 事後処理の規則は運用可能か。「次回統合で再判定されるまで根拠なしとして扱う」間、その判定に依拠していた下流の作業（直しの発注・次の草案）は止まるのか、根拠なしのまま進むのか。無効化の記録を次回統合まで遅らせることに、記録の空白期間は生じないか。(3) 救済の規則は十分か。全文検索で原文が「部分的に一致する」場合（数値だけが違う等）の振り分けは決まっているか。脚が節・行番号を付けなかった引用にも救済は及ぶのか。この 3 点が入ったことで、第4回・第5回の事故の再発防止は構造的に閉じたと言えるか。

### F7 — 最低条件 3 の診断残件：共鳴診断への λ₃・|b| 差分の併記と支配的な場合の読み方（→ E7・E1）

R9 は §2.6 項目 4（R9 702行目）に共鳴診断の拡張を入れた：「共鳴診断の出力に、Δm₂^(W)・Δm₄^(W) に加えて、**近傍ペアあり／なしでの λ₃ と |b| の差**を併記する。定義は参照計算 A について：全ペアの場から出した λ₃・|b|（cf-0094 の NF 仕様と同じ推定器）と、近傍ペアだけの場 η₂^(W) を差し引いた場（η₂ − η₂^(W)）から出した λ₃・|b| との差を、Δλ₃^(W)・Δ|b|^(W) として記録する（η₂^(W) と残りの場の交差項を通じた寄与もこの差に含まれる）。**この 2 量は報告用であり、J0・J2b・J3'・J4' の合否計算には使わない。**寄与支配の留保判断にだけ使う。**支配的な場合の判定の読み方（R9 で事前に固定）**：|Δλ₃^(W)| が J0 の |Δλ₃| の線（0.02）を超えた場合、その条件の J0 の歪度項目は**判定不能**とする。|Δ|b|^(W)| が J0 の |Δb| の線（0.004）を超えた場合も、J0 のバイコヒーレンス項目は判定不能とする。J2b の歪度項目についても同様とする。根拠：近傍寄与だけで合否線の全体（線の 100%）を超える場合、その項目の数値は非共鳴の物理の検証として読めない。Δm₂^(W)・Δm₄^(W) の寄与依存の分類（フェーズ 1 採用判断に使わない）は従来どおり存続し、本項の判定不能とは別の扱いとして併記する」。§8.2 の出力 (j)（R9 862行目）にも Δλ₃^(W)・Δ|b|^(W)（報告用）が入った。既存の寄与依存の規則（R9 700行目）は存続する：寄与比が r_j（j=2 で 2%・j=4 で 7%）を超えれば「Wilton 寄与依存」として記録しフェーズ 1 採用判断に使わない。δ の分類感度（「閾値依存」）も同様である。

実測の証拠：第7回 E7 の核は「分類が見ているのは Δm₂^(W)・Δm₄^(W) だけであり、近傍ペアの応答が λ₃ や |b| を支配する場合を捕捉できない」ことと、Grok の「近傍寄与への事前の定量的上限が合否式に組み込まれていない」という指摘であった。統合の条件は「差分（報告用）を併記し、支配的になる場合の扱い（事前の上限を含む）を合否の読み方として明記すること」であった。R9 は上限を線の 100% に置いた。一方で、B 側の近傍寄与は未定量のままである（§2.3、R9 551行目。§9、R9 896行目）。

問うこと：(1) Δλ₃^(W)・Δ|b|^(W) の定義は妥当か。差し引いた場との差で定義し交差項の寄与まで含める置き方は、寄与の「大きさ」の物差しとして正しいか（交差項は近傍ペアと非近傍ペアの相互作用であり、純粋な近傍寄与とは別の量ではないか）。|b| は場の差し引きに対して線形に応答しない——その非線形な量の差を「寄与」と読む根拠は十分か。(2) 上限を線の 100% に置いた事前登録は妥当か。Δm₂・Δm₄ の規則は「寄与比が線を超えたら採用判断に使わない」という留保の規則であり、項目の判定不能とは重さが違う。λ₃・|b| について、より強い扱い（判定不能）を同じ 100% という数字で置くことの整合は取れているか。50% 等でなく 100% でよい根拠（線の内側の寄与は合否を歪めない、という読み）は成り立つか。(3) 項目単位の判定不能の接続は一意か。J0 は全項目が通って初めて合格である（§5）。歪度項目または |b| 項目が判定不能になった場合、J0 全体は不合格（判定不能）として扱われることが本文から読めるか。J2b についても同様か。(4) B 側の近傍寄与が未定量のままであることは、この拡張の捕捉範囲をどこまで制限するか。Δλ₃^(W) は A 側の診断であり、B 側の場が近傍応答に支配されていても A 側の差分には現れない。F1 の留保と合わせて、試験 0 の数値の解釈はどこまで担保されるか。

### F8 — 閉じられなかったものを抱えて「採用判断にかけられる状態」と言えるか（→ E7）

R9 は §9 に、閉じられなかったものを明記した。Wilton 近傍応答の信頼性（R9 896行目）：「**Wilton 共鳴近傍の応答の信頼性は確立していない**（R8）。…QTF 近似そのものが共鳴近傍で妥当かどうかは未検証であり、寄与依存の分類（§2.6 項目 4）が「Wilton 寄与依存」になった結果はフェーズ 1 採用判断に使わない。…**【R9】**共鳴診断に λ₃・|b| の近傍寄与差分（報告用）を追加し、近傍寄与が J0・J2b の線を超えた場合は該当項目を判定不能とする読み方を §2.6 項目 4 に事前登録した。ただし B 側の近傍寄与は依然として未定量であり（§2.3）、A/B 差のうち近傍応答に由来する部分は分離できないままである」。3D FFT の計算量（R9 897行目）：「**3D FFT の計算量は依然として推測である**（R8）。実測は最初の 1 記録（J7）まで無い」。λ₃,exact の MC の前提（R9 898行目）：「**λ₃,exact の MC は M=512・同一格子を前提とする**（R8）。…この相殺が成り立つのは「同じ離散モデル同士の比較」としてであり、連続スペクトルへの外挿を保証しない」。U-1a は未決のままである（§6・§9）：「U-1a が閉じなくても試験 0 は進むが、試験 0 が通っただけでは 2D 一般角形は確定しない」。§8.3 には「U-1a が完了するまで、2D 一般角形を「確定」と呼ばず「暫定採用」として扱う」が引き継がれた。あわせて §9 には、表面張力を含む QTF は未導出（U-3、フェーズ 2 の前提）、高次参照（HOS・3 次摂動）は未実装（U-4、P1・SWELL の復帰判定はできない）も明記されている。

問うこと：これらを抱えたまま、R9 を「P5 の QTF 帯域内比較を行う試験 0 の採用判断にかけられる状態」と言えるか。特に：(1) Wilton 近傍応答の信頼性が未確立で、B 側の近傍寄与が未定量のままであることは、F7 の診断拡張で十分に囲い込めたか。囲い込めていない部分は、採用判断の材料として明記すべき留保の形で本文に読めるか。(2) 計算量が推測のままであることは、仕様の確定性とは別の問題として切り分けられるか（J7 で最初の 1 記録の壁時間を実測し、見込みが 2 時間を超えれば止めて報告する契約は §5 に既にある）。F3 の A_full 切り替えの計算量も、この切り分けの内側にあるか。(3) U-1a が未決のままであることは、「暫定採用」の枠内での試験 0 の採用判断と矛盾しないか。F5 の発効条件が入ったことで、未決の意味は第7回時点より明確になったか。(4) §9 の残件のうち、試験 0 の採用判断と切り分けられないものが残っていないか。逆に、F1–F7 のすべてが閉じたとしても §9 の残件だけで差し戻しになるものがあるか。

## 回答形式（厳守）

- 最初に最終裁定を 1 行で書くこと：**採用判断にかけられる状態** か **差し戻し** か（意味は「役割」に書いた限定付きの採用判断である）。
- 次に主張 F1–F8 ごとに、判定（**成立／条件付き成立／不成立** のいずれか 1 つ）、最も強い反論、通るための条件、失敗条件を書くこと。
- 次に直しの優先順位（最も急ぐものから）を書くこと。
- 最後に、採用判断にかけられる状態になるための最低限閉じるべき条件を 3 つ以内で書くこと。
- 反論には必ず、草案のどの箇所（節番号・行番号・数値）が問題かを具体的に示すこと。引用する式・数値は資料の原文で照合した上で使うこと。照合できない引用は「引用未確認」と明記すること。数値の誤りを見つけたら、訂正値を計算して示すこと。
- 「未実行だから不成立」とは判定しないこと。問題は、測定を実行しても結果を一意に合否へ変換できない箇所が残っているかどうかである。回答が途中で切れたら、同スレッドで続きを要求して補完すること。
