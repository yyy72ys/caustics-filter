C3：風向き1方向のHilbert変換
不成立

あなたの懸念は正しい。ただし、解決策として「各モードの伝播方向に90度回転したHilbert変換」をそのまま導入するのも、まだ正しくない。

1方向Hilbert変換が失敗する理由

風向きに沿った座標を x とし、その方向にHilbert変換を定義すると、風向きに平行な波の位相直交成分は作れる。しかし、風向きと直角方向に進む波に対しては、同じ演算子がその波の伝播方向に沿った直交位相を返す保証がない。

方向関数が cos2θ 型で、直角方向にもエネルギーが残るなら、これは無視できない。

例えば、風向きに直交するモードでは、風向き方向の波数射影がゼロに近づく。そのモードのHilbert変換は、伝播方向に沿った位相直交成分を表すものではなくなる。

ただし「方向別Hilbert変換」も未完成

各モードの方向に沿ってHilbert変換を定義すれば、個々の平面波の直交位相を構成できる。しかし、二次相互作用は個別モードの位相直交だけでは決まらない。二つのモードの和・差周波相互作用を含むからだ。

方向ごとに別々にHilbert変換してから二次式を作ると、異なる方向のモード対について、どの直交位相をどう組み合わせるかという問題が残る。

つまり、問題はHilbert変換の方向だけでなく、二次カーネルのペア依存性を、単一の直交位相場へ押し込めていることにある。

修正文案

方向分散場に対して、風向き固定の1次元Hilbert変換を一般の二次カーネルの代替として用いない。方向別の直交位相場を構成する場合も、モード対の和・差周波相互作用を再現することを直接評価で確認する。標準実装は、方向を含む波数ベクトル対に依存するQTFを保持する。Hilbert変換由来の二次式は、特定の狭帯域・方向集中条件でQTFと一致することが確認された場合に限り、その適用域内の高速近似として使用する。

C7：ν とGFがほとんど動かないという前提
条件付き成立

「二次補正を加えてもスペクトルは大きく変わらない」という見立てはあり得る。しかし、分散の増加が0.7%だから ν とGFもほとんど動かない、という推論は成立しない。

m2 への寄与

提示されたP5では、

k_p = 14.15 rad/m

であり、二次和周波の代表波数は概ね

2k_p ≃ 28.3 rad/m

となる。これは m2 の74.5%が存在する10–30 rad/m帯の上端付近に入る。

分散寄与が0.7%であっても、m2 は波数二乗で重み付けされる。二次成分の代表波数を 2k_p、線形場の代表波数を k_p と単純化すると、

Δm2/m2 ∼ 0.007 × (2k_p/k_p)^2 = 0.028

すなわち、約2.8%程度の増加があり得る。

これは粗い上限寄りの見積もりであり、実際の値は二次成分の分布と交差項で変わる。しかし、少なくとも分散比0.7%だけから m2 も0.7%程度と結論することはできない。

m4 はさらに敏感

同じ単純化を使うと、

0.007 × 2^4 = 0.112

となり、m4 への寄与は約11.2%相当まで大きくなり得る。

もちろん、実際には m4 の線形場側の分布、二次成分のスペクトル形状、位相相関、交差項が必要なので、11.2%を予測値として使うべきではない。だが、高波数側の統計は分散比から想像するほど小さくないという警告にはなる。

ν とGFの定義が必要

草案では ν とGFの定義式がここに示されていない。したがって、Δm2 が ν にどう伝播するか、GFがどのモーメント・統計量に依存するかを確定できない。

特に、J2の

|Δν| ≤ 0.02

は、二次補正を物理的に無視できることの証明ではなく、既存の生成器契約との互換性条件にすぎない。

修正文案

二次補正による分散変化が0.7%程度であることをもって、ν・GF・高次スペクトル統計が不変とは仮定しない。J2では、分散 σ2 に加え、m2, m4、ν、GFを個別に計測する。二次成分の高波数寄与と線形場との交差項を含め、各統計量の変化を実測で評価する。既存契約の許容範囲を超える場合は、二次補正の実装誤りと即断せず、物理的な二次相互作用による統計変化か、数値誤差・重複計上かを参照計算で分離する。

C8：8秒ループを維持したまま差周波成分を入れること
条件付き成立

ここは数学的な主張と物理的な主張を分ける必要がある。

数学的な周期性は成立する

親波の角周波数が

ω_n = n 2π/8

という整数倍に量子化されているなら、和・差周波数も

ω_i ± ω_j = (n_i ± n_j) 2π/8

となる。したがって、二次成分も8秒周期になる。新しい乱数を引かず、η2 を η1 の決定的関数として作る限り、8秒ループの数学的な周期契約は維持できる。

ここまでは正しい。

しかし、長周期の群れは表現できない

問題は、周期性ではなく、表現可能なビート周期の範囲だ。

親波の周波数差は、

Δω = m 2π/8

となる。m が非ゼロ整数なら、差周波成分の周期は

T_beat = 8/|m| s

である。

つまり、8秒ループの中では、非ゼロの差周波ビートは8秒以下の周期しか持てない。8秒を超える群れの包絡変動は表現できない。

具体的には、10秒・20秒のビートを作るには、周波数差がそれぞれ0.1Hz・0.05Hz程度必要になるが、8秒ループの周波数刻みは0.125Hzである。これらの差周波数は格子上に存在しない。

同じ周波数同士の差はゼロ、つまり平均成分になる。隣接ビンの差は0.125Hzで、周期8秒となる。これより長いビートは作れない。

「折り返し」は物理的な群れの再現ではない

したがって、長周期の群れが8秒ごとに再出現するように見える場合、それは自然な群れの時間発展を再現したのではなく、8秒周期という数値契約が作った再帰性である。

これは、本人の前提である「自然を再現する」に照らして無視できない。

特に、差周波成分は長い群れ・セットダウンに関係する。8秒ループの周波数格子がその時間スケールを表現できないなら、差周波成分を計算していても、物理的に必要な長周期成分を落としている可能性がある。

修正文案

二次成分の和・差周波数は、親波の周波数格子が整数倍である限り、数学的に8秒周期を維持する。ただし、これは長周期の群れを物理的に再現できることを意味しない。8秒ループでは、非ゼロ差周波成分の最長周期が8秒に制限されるため、8秒を超える包絡変動・セットダウンの再現性は保証しない。第1実装では既存ループ契約との互換性を優先するが、物理的な長周期群れの検証では、より長い基本周期または非周期時間発展を用いた別試験を行う。8秒ループの再帰性を自然な群れの時間発展として解釈しない。

7. C1–C8以外に残る設計上の問題

ここはC1–C8の判定とは別に、草案全体で修正すべき点だ。

7.1 T3の「スペクトル不変」は物理的な二次補正と矛盾する

T3は、

2次を入れても線形場のスペクトルと ν・GFはほとんど動かないことが前提の一部。動いたら実装がスペクトルを変えた証拠であり、前提違反。

としている。

これは表現が強すぎる。

二次束縛波は、和周波・差周波に新しい成分を作る。その成分には分散があり、線形場と二次場の相関もある。したがって、二次場を加えた合成場のスペクトルが変わること自体は、物理モデルが働いた結果として当然に起こり得る。

問題は、変化が物理的なQTFに対応するものか、誤実装・エイリアシング・二重計上によるものかである。

J2の「足される分散≤2%」「|Δν| ≤ 0.02」は互換性ゲートとしては使える。しかし、それを物理的正しさの前提にしてはならない。

修正文案：

二次補正後の合成場では、和周波・差周波成分の追加に伴うスペクトル変化を許容する。J2は線形場 η1 の同一性を保証するゲートと、合成場 η1 + η2 の統計変化を監視するゲートに分ける。合成場のスペクトル変化は、それ自体を実装誤りと判定せず、参照QTF計算が予測する変化と照合する。許容幅を超えた場合は、物理的な二次寄与と数値誤差・重複計上を分離して判定する。

7.2 「FFTで畳み込む」と「Hilbert二次式で計算する」は同じ意味ではない

草案は、計算法を「線形場とHilbert変換・勾配場から作る二次式をFFTで畳み込む」としている。

しかし、FFTを使うことは計算方式であり、Hilbert二次式は物理モデルの近似形だ。両者を一つの決定事項として扱うと、後から近似誤差を検証しにくくなる。

FFTはモード二重和を高速化するために使える。

Hilbert二次式は、特定の条件でQTFを近似する表現である。

ペア依存QTFを保持したFFT畳み込みも、理論上は別の実装候補となる。

したがって、「FFTを使う」は維持してよいが、「Hilbert二次式を使う」は検証前に確定してはならない。

修正文案：

計算方式としてFFTを採用する。物理カーネルは有限水深QTFとし、FFT実装はそのペア依存性を保持する方法を基準とする。Hilbert二次式は高速近似候補として扱い、直接QTF評価との一致が確認された条件に限って使用する。FFT採用とHilbert近似採用は別の設計判断とする。

7.3 3/2則だけでは、二次場の全ての数値誤差は除去できない

3/2則のパディングは、二次積のエイリアシング対策として妥当だ。しかし、これだけで次の問題が解決するわけではない。

有限格子による高波数側の切断

周期境界に起因する長波長成分の不足

方向分散したモード対の離散化誤差

QTFの共鳴近傍の数値不安定

和・差周波成分の異なる解像度要件

特に差周波は低波数側に現れ、和周波は高波数側に現れる。両者は同じ格子で同じ精度が得られるとは限らない。

修正文案：

3/2則のパディングは二次積のエイリアシング抑制に用いるが、格子収束・高波数切断・低波数分解能・共鳴近傍の誤差を別途評価する。和周波と差周波の双方について、解像度を変えた収束試験を行う。3/2則を適用したことのみを数値誤差の除去証明とはしない。

7.4 バイコヒーレンスの「95パーセンタイル超え」は、検定単位を定義しないと危険

決定済みの代理データ案Cは維持してよい。しかし、95パーセンタイル超えという判定だけでは不足する。

周波数・波数の組み合わせごとに多数の値を調べる場合、各点で5%の誤検出率を許せば、全体では偽陽性が増える。また、バイコヒーレンスの値が高くても、それが二次束縛波の正しいQTFを示しているとは限らない。

修正文案：

バイコヒーレンスの帰無判定では、検定対象の周波数・波数領域と検定単位を事前に固定する。多数のビンを同時判定する場合は、多重比較を考慮した帰無分布または全体統計量を用いる。バイコヒーレンスの有意性は位相結合の存在を示すが、QTFの物理的正確性を単独で保証しない。QTF参照計算との一致を別の採用条件とする。

9. 最終裁定

設計骨格は維持できるが、現行草案はまだ実装仕様として通せない。

特に、次の2つは同時に成立させなければならない。

Sharma–Deanの有限水深QTFを物理モデルとして採用する。

Hilbert二次式によるFFT計算が、そのQTFを必要な精度で再現する。

現状は、この2つを同一視している。だが、方向分散と広帯域性があるP5で、その同一性はまだ証明されていない。ここを通さずに歪度0.05やバイコヒーレンス95パーセンタイルを調整しても、誤った二次場を精密に検出するだけになる。

次に、P5だけを対象にすることは第1実装の範囲として妥当だが、P1・SWELLの二次効果を否定したことにはならない。8秒ループも数学的には維持できるが、8秒を超える群れの時間発展は表現できない。

したがって、現時点での判定は次の通り。

物理モデルの方向：維持可能

計算方式：未確定

統計ゲート：未確定

8秒ループとの物理的整合：限定付き

実装開始：小規模な参照QTF比較試験に限って可

本実装への移行：不可
