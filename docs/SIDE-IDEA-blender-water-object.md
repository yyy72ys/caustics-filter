# 別アイディア: Blender「場に保たれる水の立体」(2026-11-09 すり合わせ中)

## ユーザーの発想(本人の言葉の流れ)
- Blenderで立体に対して、それ自体が水で、コアに引力で保たれているようなオブジェクトをコードで作れないか
- ただの丸じゃなくて、磁場を調整して立体を複雑な形で保つ
- それ自体は水で、外部環境で揺れてる状態

## 技術メモ(助手側)
- 点コア引力だけだと平衡形は球。複雑な形には「場」の設計が要る:
  複数の吸引/反発ポール配置 + 形状SDFフィールドで平衡形を彫る
- 物理の実在対応: 水は反磁性で超強磁場では浮揚する(磁気浮上)。
  見た目の近親はフェロフルイド(磁性流体)のスパイク造形
- 実装ルート候補: 自作SPH粒子(ポール場+圧力+表面張力)→メッシュ化、
  中間=粒子+メタボール、軽量=Geometry Nodesで場変形+水シェーダー
- 外部環境(風・振動などの外乱場)で平衡形の周りを揺れ続け、
  場の復元力で形に戻る、のが美学の核

## 形のイメージ(ユーザー確定 2026-11-09)
- 選択肢の上2つ **両方**: (1)像のような明確な造形 (2)有機的な不定形
- 理由(本人): 「コントロールできるのと、有機的なかんじ」
- → 合成解釈: **二層の場**で作る
  - マクロ層: 彫刻形のSDFフィールドで大まかな輪郭をコントロール(像・物体)
  - メソ層: ポール場で突起・触手・うねりが有機的に生え、動く
  - ミクロ層: 外部環境の外乱で表面が常時揺れる
  = 「輪郭は彫刻、中身は生き物」
