## 0. 位置づけ

- cf-0075 は解析側の再計算のみを行った。同じ実現モード集合（同じ k、同じ |H0|²）に対し、ω を量子化値 ω_q と分散関係の真値 ω_true で差し替えて ν を出し直し、「量子化で説明できる分はギャップの 17.1%、残存比 0.829」という結論を得た。
- しかし cf-0075 §8.2 が明記するとおり、ν_true は「そのモード集合を連続 ω で積分した値」であって「実現する場の ν」ではない。場を作り直せば、時間発展・位相・折り返しの効果が入る。プローブ ν は場そのものが 8 s 周期で構成されているため、場を作り直さない限り分離できない（cf-0075 §7）。
- 本実験は、生成器の**コピー**側で ω 量子化を外して場そのものを再生成し、実際の場の ν を測る。紙の上の 17.1% が場でも成り立つかどうかが、本実験の唯一の問いである。
- 大原則の確認: 真の分散関係 ω(k) が物理であり、量子化は 8 s ループを閉じるためだけの都合である。量子化を外すことは「それっぽくする」調整ではなく、物理に戻す操作である。逆に、本実験の結果をもって量子化側を正当化することはしない。

## 1. 問いと2つの競合する結末（判定基準は事前に数値で固定する）

### 1.1 問い

量子化を外して再生成した実際の場では、P5-CLEAR と SWELL-1 の ν ギャップはどうなるか。紙の再計算（cf-0075）が予測する「ギャップは 0.0680 から 0.0564 へ、残存比 0.829」どおりに場でも残るのか、それとも場では別の結果になるのか。

### 1.2 基準数値（cf-0075 の実測、全て5シード平均、seed 1 = 本番シード）

| 量 | P5-CLEAR | SWELL-1 | ギャップ（SWELL − P5） |
| --- | --- | --- | --- |
| ν_q（量子化 ω、モード集合） | 0.3272 | 0.3952 | 0.0680 |
| ν_true（真の ω、モード集合の紙再計算） | 0.3254 | 0.3817 | 0.0564 |
| ν_probe（量子化場のプローブ実測、cf-0067 保存 npz） | 0.2848 | 0.3755 | 0.0906 |

- 説明率（紙）= (0.0680 − 0.0564) / 0.0680 = 17.1%。残存比（紙）= 0.0564 / 0.0680 = 0.829（シード別 0.763–0.888）。
- 本番シード単独では gap_true = 0.0505（残存比 0.817）。連続スペクトルの解析ギャップ（cf-0077）も 0.0505 で、モード集合の真値ギャップ 0.0564 とは別経路で近い値に着いている。両 0.0505 の4桁一致は数値として確認済みだが（numbers-omega-quant.json stage2 より seed 1 の ν_true は P5 0.3308659、SWELL 0.3813662、差は 0.0505003）、独立した裏付けか偶然の一致かは判定材料がなく未判定である。R2 では 0.0505 を判定規則には使わない（帯の中心にも下側の参照値にもしない）。予測値の中心はプローブ尺度の紙相当値 0.0751 とする（§1.3）。

### 1.3 判定量と判定基準（測定前に固定する。測定後に動かさない）

主判定量は R_field 1つのみである。R_mode は §4.2 の内部ゲート専用であり、結末の判定には使わない（R1 では「主判定量は2つ」としていたが、結末条件に R_mode が現れない混同があったため外す）。

- G_q: 32 s 仕様で再測した量子化場のプローブギャップ（§4.3）。期待値は cf-0067 保存値 0.0906 の近傍だが、分母は保存値ではなく再測値を使う。
- g: 32 s 仕様で測った非量子化場のプローブギャップ。
- R_field = g / G_q。
- 紙予測値 g_paper = 0.829 × G_q（G_q = 0.0906 なら 0.0751）。予測帯は g_paper ± 25% とするが、上限は G_q で切る（量子化場のギャップを超える値は紙の機構の向きと合わないため、決着なしへ回す）。G_q = 0.0906 の場合、予測帯 = [0.0563, 0.0906]。§7 の貼り替え参考値 0.0747 もこの帯の内部にある。
- 結末 A「量子化は残りのギャップを（場でも）説明しない＝紙の結論が場で確認される」: g ∈ [0.80·G_q, G_q]（G_q = 0.0906 なら [0.0725, 0.0906]）。これは「g が予測帯に入る」かつ「R_field ≥ 0.80」の両方を満たす範囲である。g_paper = 0.0751 は A の内部にある。
- 結末 B「量子化が残りのギャップを場では説明する＝紙の結論は場では成り立たない」: g ∈ [0, 0.50·G_q]（G_q = 0.0906 なら [0, 0.0453]）。
- 決着なし: g ∈ (0.50·G_q, 0.80·G_q) ∪ (G_q, ∞)（G_q = 0.0906 なら (0.0453, 0.0725) ∪ (0.0906, ∞)）。数値そのものを報告し、§6 の出口規則に従う。cf-0075 §5 の教訓どおり、しきい値の上下ではなく数値を主張の中心に置く。
- 検算（G_q = 0.0906 の場合）: A は [0.0725, 0.0906] で非空（幅 0.0181）。B は [0, 0.0453] で非空。決着なしは (0.0453, 0.0725) ∪ (0.0906, ∞) で非空。3領域は互いに重ならず、和集合は gap_probe ≥ 0 全体を覆う。g_paper = 0.0751 は A の内部にある。G_q の実測値が 0.0906 からずれた場合は、上の数値例は使わず、式（0.80·G_q、0.50·G_q、0.829·G_q）から境界値を計算し直すこと。
- 閾値 0.80／0.50 は cf-0075 §5 の事前固定値の流用を継続する（紙との連続性のため）。適用尺度はプローブ尺度に統一した（R1 の尺度の取り違えを解消する）。バイアス予算は §4.3 の合成ゲートが担保する。A–B 分離幅は (0.80 − 0.50)·G_q = 0.0272 であり、合成ゲートの許容する gap バイアス 0.006 以下はその 1/4 未満である。
- シード単独での判定は禁止する。cf-0075 §5.1 のとおりシード別の残存比は 0.763–0.888 と 0.8 の線をまたぐため、判定は5シード平均で行い、シード別の値を必ず併記する。

### 2.2 真の分散関係（毛管項を含むコードの式を使う）

ω_true は `v8_physics.py` の `dispersion_omega`（凍結写し123–128行）そのものである。

    ω_true(k) = sqrt( (g·k + (σ/ρ)·k³) · tanh(k·h) )
    g = 9.81 m/s²（v8_physics.py:62）
    σ/ρ = 7.28e-5 m³/s²（同65行、SIGMA_SURF = 0.0728 N/m、RHO_W = 1000 kg/m³）
    h = 深さ（両条件とも 4.0 m）

- 毛管項 (σ/ρ)·k³ は必須である。cf-0075 §2 の実測では、k = 300 rad/m で毛管/重力比 0.668、k = 1000 rad/m で 7.421 に達し、重力のみの式では P5 の ν が大きく下がってギャップがむしろ広がる（説明率 −61.2%）。「真値」の定義を重力のみに取り替えることは本実験では行わない。
- 量子化の刻み Ω0 = 2π/8 = 0.7854 rad/s（v8_physics.py:71）は、コピー側ではもう使わない。ただし記録・照合のために定数自体は残す。
- 下限 n ≥ 1 の削除も変更の一部である。ω_true < Ω0 となるのは k < 0.131 rad/m のモードである（分散関係からの計算。k = 0.1 rad/m で ω_true = 0.611、SWELL の最低波数モード k = 0.082 で ω_true = 0.505）。これらはこれまで ω_q = Ω0 に切り上げられていた。コピーでは真値のまま進める。
- k = 0 のモードは振幅ゼロである（V10・V11 の `_realise` ともに `H0[0, 0] = 0.0`）。したがって厳密な静的モードは場にエネルギーを持たない。ω_true < Ω0 のモードの m0 シェアは、段1で実現モード集合から実測して条件ごとに記録する（式は §4.2）。本書では事前値を置かない。
- プローブ推定量との干渉は §4.3 で扱う。nu_batch は DC ビン（0番）を除外するため、時系列の平均は ν に入らない。近直流モードの有限窓漏れは §4.3 の合成ゲートで担保する。

- 【リスク R6】しきい値近傍: 紙の残存比 0.829 は 0.8 の線から 0.029 しか離れていない。場の R_field も線の近傍に着く可能性が高く、その場合は §1.3 のとおり数値の報告が成果になる。線の上下だけで結末を語らない。合成ゲートの許容する非対称バイアス 0.003 以下は A の幅 0.0181（G_q = 0.0906 の場合）の 1/6 未満であり、gap バイアス 0.006 以下も A–B 分離幅 0.0272 の 1/4 未満である。
- 【リスク R7】8 s ループの喪失の下流影響: 非量子化場は 8 s で戻らない。実験出力をループ前提の処理に流すと無言で壊れる。§5 の明記に加え、実験出力のメタデータにも非ループであることを機械可読な形で残す。
- 【閉鎖 R8】float32 保存: 真の ω を float32 で保存する丸め（相対 1e-7 級）は量子化刻み（低 n 帯で相対 10% 級）に対して無視できる中立な数値として扱う。段1のゲート（§4.2）で ν_mode の許容差を 1e-4 に固定したため、この扱いは仮置きではない。
- 【リスク R9】V11 の jonswap 分岐: `V11._realise` は `spectrum_source == "jonswap"` のとき親の `_realise` に委譲する。本実験の条件は elfouhaily-form であることを段0で値として記録する（§4.1）。条件を変えた場合は分岐を再確認すること。
