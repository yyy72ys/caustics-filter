# PIPELINE-V6 — コースティクス v3 チャンク2「雨（無風の凪に雨）」設計

根拠： `research-v3-variables/report.md` §3（雨）／§5（変数マップ）。前段： PIPELINE-V5（チャンク1、水と底、実装・ゲート通過済み）。順番はユーザー確定（チャンク1 水と底 → チャンク2 雨 → チャンク3 網膜）。基準の見え方は物理厳密のまま（ユーザー決定 2026-11-10、プリセット1の穏やかな基準はそのまま）。

## 0. このチャンクで入れるもの

新しいシーン入力は **雨量 R（mm/h）ただ1つ**。風は 0（凪）で、背景の水面は Cox–Munk の下限 σ² ≈ 0.003。雨滴が作る **輪波（ring waves）** を、既存のスペクトル状態へ物理統計として追加する。手続き的な輪テクスチャや1滴ごとの粒子シミュレーションは使わない（本プロジェクトの「 fake pattern 禁止」に反する。report §3.5 の方式2＝スペクトル法が本流）。

## 1. 雨滴の統計（全て R から導出）

- 滴径分布 Marshall–Palmer： N(D) = N₀·exp(−ΛD)、N₀ = 8000 m⁻³mm⁻¹、Λ = 4.1·R^(−0.21) mm⁻¹。
- 落下速度 Atlas–Ulbrich： v(D) = 9.65 − 10.3·exp(−0.6D) [m/s]（D は mm、適用域 0.5–5mm）。
- 衝突頻度 F = ∫ N(D)·v(D) dD [drops m⁻² s⁻¹]。検証表（report §3.3）： R=1 → ≈1.3×10³、10 → ≈4.2×10³、25 → ≈6.4×10³、50 → ≈8.6×10³。雨量が増えても衝突「回数」は緩やかにしか増えず、増える主役は滴の大きさと1発のエネルギー、という形を再現すること。
- 質量中央径 D₀ = 3.67/Λ（R=10 で ≈1.45mm）。平均運動エネルギー/滴は ½·m·v²（m = (π/6)ρD³）を分布で平均する。

## 2. 輪波バンド（スペクトルへの追加）

- 輪波は重力–毛管波で波長 1–2cm。分散 ω² = gk + (σ/ρ)k³（σ=0.072 N/m）の crossover λ_c ≈ 1.7cm が中心帯。バンドは k ≈ 310–630 rad/m、中心 k_ring ≈ 420 rad/m（λ≈1.5cm）。
- **k_ring は R の関数**： 大きな滴ほど長い輪を作る（ピーク周波数は滴径で決まり雨量そのものでは決まらない、というのが R への効き方）。k_ring は D₀(R) から導く（大きい D₀ → 小さい k_ring）。中心の置き方は単調減少であることをゲートで確認する。
- バンプは **等方的**（輪は方向を持たない。風スペクトルの異方性と対照的）。
- バンプの総分散（エネルギー量）： ∝ F(R) × 平均衝突運動エネルギー × 平均輪寿命。寿命は §3.4 の実測レンジ（輪が見えるのは衝突後 ~150ms プロセス内、直径 25–50cm まで）から取る。
- 導出できない定数は **η（衝突→輪波エネルギー変換効率）の1つだけ**。較正定数として名前を付けて numbers に明記する（勝手に他の所へ染み出させない）。粘性減衰 β はスペクトル形では寿命に畳み込む（独立定数にしない）。

## 3. 時間発展とループ

- 輪バンドの時間発展は重力–毛管分散 ω(k) = √(gk + (σ/ρ)k³) で行い、既存の仕組みと同じく ω を 2π/8s の倍数へ量子化して 8 秒ループを閉じる。
- 凪の背景： 風スペクトルは風速 0 で Cox–Munk 下限 σ² ≈ 0.003 の微小粗さだけ残す（完全な鏡面にしない）。

## 4. 雨の第二効果（カップリング）

- 雨は数 cm より長い既存の波を **減衰** させ、毛管バンドを強める（report §3.4）。無風シーンではほぼ no-op だが、雨＋風の混合に備えて機構だけ入れる： 輪バンドより低 k 側の風スペクトルに、R に応じた減衰係数（1 に近い、文書化した近似）を掛ける。係数の形は近似であることを numbers に明記する。

## 5. レシピ拡張（caustics-recipe/v2 へ追加）

- `rain.rate_mm_h`（デフォルト 0）。0 のとき v5 と完全同一の挙動（後方互換ゲート）。
- 既存フィールドは不変更。v1 レシピは従来どおり読めること。

## 6. 数値ゲート（numbers-v6.json に記録）

1. 後方互換： R=0 で v5 ベースラインと一致（C 平均・スチルの一致）。
2. F(R) 積分が §1 の検証表と一致（R=1/10/25/50、桁と傾向。DSD の正直な不確かさとして factor 1.5 以内）。
3. k_ring(R) が単調減少（R=1 → 50 で中心が低 k へ移動）し、バンド 310–630 rad/m の内側。
4. 輪バンド分散が R に対して単調増加。
5. C 平均 = 1.0（±1e-3）を維持。潰れ・白飛びが v5 ベースラインから非常識に悪化しない。
6. 較正定数は η のみ（名前・値・根拠を numbers に記載）。

## 7. 検証スチル（offline/out/v6/）

同一シーン（プリセット1の写真・太陽、ただし風 0・凪）で：
- R=0（凪・雨なし、基準）
- R=2（小雨）
- R=10（本降り）
- R=50（激しい雨）
の4枚＋並置パネル。2048² パッチ 1.48m では輪波長 1.5cm ≈ 21px なので、拡大クロップ1枚（輪の粒状感が見える倍率）も出す。σ²（凪下限＋輪バンド寄与の内訳）を numbers に出す。

## 8. やらないこと

- 1滴ごとの衝突シミュレーション、王冠（crown）や茎（stalk）の形状再現（統計の外）。
- 雨粒そのものの空中描画、跳ね返りの飛沫の見た目追加。
- 風シーンの作り直し（チャンク1の状態をそのまま土台にする）。
