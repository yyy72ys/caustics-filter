物理的に残る旧文: R2-11（386行目）は今も「L_U/λ ≲ 3 が面的に広がる礫・転石帯では線形分散・流れ結合を満たす波解像伝播（緩和緩勾配方程式／スペクトル結合ソルバ）へ切り替える」を含む。R3-2（521行目）の「削除する」は宣言上書きである。さらに §6.1 C9′（221行目）は今も「礫床場面では L_U/λ₀ ∼ 0.5–3 で WKB 条件自体が崩れる場所が多い。……**遮断された作用のシンク**（砕波・反射・乱流への移送）を必ず対にする」を含む。R3-2 の「置き換える対象」（517行目）は R2-11 のみを挙げ、C9′ は挙げていない（R2-11 の見出しが「§6.1 の C9′ を書き換える条文」である、という経由の上書きになる）。

閉鎖の判定基準: 次の5点がすべて現行規則として一意に読めること。(a) 切替基準が ε_WKB の単一閾値に統一され、矛盾する数値基準（L_U/λ ≲ 3）が現行規則として残っていない。(b) 滞留が状態量 A_trap と収支式で定義され、シンクと区別され、その放出先が定義される。(c) 6成分の配分が、配分を一意に決める閉合則として働く。(d) Fr→1 の正則化が、臨界条件と接続先まで定まる。(e) 不可逆シンクの計上条件（移送先が定義され収支で確認できた F_brk・F_turb に限る。反射はシンクでない）が維持される。

争点:
(i) 配分の一意性: 各成分を別々のユニットの計算から求め、「合計が1」を確認し、合わなければ U2b へ進まない、という形は、配分を決める規則か、検算とゲートの規則か。6つの独立な評価が合計1にならない場合に、どの成分をどう調整して配分を確定させるかの規則は本文にあるか。なければ、配分の自由度は前回と同じく残るのではないか。
(ii) A_trap の流出の内訳: F_out は「下記の配分先への流出作用束の合計」と定義されるが、滞留した作用がどの成分へどれだけ流出するかの配分は定義されているか。τ_trap = A_trap / F_out は、F_out の内訳が決まらなくても診断量として閉じているか。
(iii) Fr→1 の「言い換え」: フルード数 U/c = 1 と、光線に沿う群速度の法線成分がゼロになる遮断条件は、採用する分散関係（有限水深・表面張力・流れ込み）の下で常に等価か。等価でない場合、「Fr→1 は遮断条件の言い換え」という定義自体が新たな混同にならないか。正則化の振り分け自体は 525行目に規則がある（転回点では Airy 型一様漸近で接続し、Airy の仮定（孤立した単純転回点）を満たさない面的な非 WKB 域は波解像伝播へ切り替える）。残るのは支配方程式の選択と接続手順のブリーフ登録である（525行目）— 前回の「別途特定」の先送りは、臨界条件の特定だけで解消したと言えるか。
(iv) C9′（221行目）の残存: 反射を含む「シンク」の旧文と L_U/λ₀ ∼ 0.5–3 の記述が §6.1 に物理的に残る。R2-11 経由の上書き（R2-11 の見出し → R3-2 の上書き）という二段の経由で、C9′ の旧文が現行規則でないと一意に読めるか。

#### K4 — 項目4: C16′ 散逸機構の帯固定（統合 §3 条件1）

前回の残件（統合 §2 項目4）: 「帯境界の場面決定を宣言したものの無次元決定基準がなく、R2-17（仮置き U5/Δ_η,brk）と R2-25（要否宣言）の調整および R2-17 三波共鳴と R2-5 1:2 共鳴の切り分け参照も未整備である」。

対応条文は親 §6.4 第4項の R3-3（528–537行目）: 「境界を決める無次元数は次の2つとする。(a) 毛細波数 k_c = √(ρg/γ)（重力項 gk と毛細項 (γ/ρ)k³ が等しくなる波数。ℓ_c = √(γ/ρg) の逆数であり、U13 の ℓ_c ≈ 2.7 mm と同じ定義）。k < k_c を重力支配、k > k_c を毛細支配とし、k = k_c を重力‐毛細遷移帯の中心とする。(b) 有限水深パラメータ kH」（534行目）。「三波共鳴条件を評価するときは、R2-7 の一般条件（採用する分散関係に対する周波数整合と波数ベクトル整合）を用いる。R2-17 の「三波共鳴条件を満たさない帯域へ三波移送を適用しない」という文は、R2-7 の一般条件を指す」（535行目）。「砕波の形状変化オペレータの要否と形式は、U2a で宣言する（R2-25）。R2-17 の「U5 へ仮置き」は、U2a の宣言までの暫定の置き場所であり、宣言が下りた時点で宣言に従う」（536行目）。「微細砕波形状補正項 Δ_η,brk(x, y, t) は、U2a の宣言が「要」の場合に U5 の実装として置く。宣言が下りるまでの間は、Δ_η,brk は未定義の仮置き名として扱い、U5 の実装に含めない」（537行目）。

旧文の残存: R2-17（420–424行目）は物理的に残り、「場面ごとに決定する」の手続きなしの文と「U5 または Δ_η,brk へ仮置き」の文を含む。§6.1 C16′（228行目）も帯固定の旧文（「短重力帯（k ∼ 10–150 rad/m）の高 k 側の拘束は砕波散逸。……毛細テール（k ≳ 250 rad/m）の拘束は粘性散逸＋Marangoni 減衰＋三波／寄生移送であり、砕波ではない」）のまま残る（R2-17 経由の上書き）。

閉鎖の判定基準: 次の4点がすべて現行規則として一意に読めること。(a) 帯境界の無次元基準が定義式として固定される。(b) 三波共鳴条件の参照先が R2-7 の一般条件に一意化される。(c) 砕波形状変化の置き場が U2a の宣言優先で一意に決まる。(d) 10–150／250+ の値の初期区分への格下げが維持される。

(i) 基準の射程: k_c は重力‐毛細遷移の中心を与える。しかし前回の残件が問うた帯は散逸機構の帯（短重力帯の高 k 側の拘束は砕波か、毛細テールの拘束は何か）である。k_c と kH の2つの無次元数で、散逸機構の帯境界まで一意に決まるか。遷移帯は「中心」だけが決まり幅が定義されていないが、帯境界の決定として閉じているか。
(ii) kpH ≳ 3.5 の地位: 534行目はこの値を「ピーク付近の深水近似が良好となる目安」として R2-17 の既定を維持する。目安のままでは、有限水深の要否の判定量として閉じていないのではないか。

(iv) 「未定義の仮置き名」: Δ_η,brk を未定義と明言すること（537行目）は、置き場の一本化か、先送りの言い換えか。U2a の宣言が下りるまでの間、砕波の形状変化について現行規則として存在するものは何か。それが「何もない」である場合、C16′ の「散逸項だけで砕波中の幾何形状を表現したとはみなさない」という要求（R2-17、423行目）との関係はどうなるか。

#### K5 — 項目5: U14 点渦の発散（統合 §3 条件1）

閉鎖の判定基準: 次の5点がすべて現行規則として一意に読めること。(a) プロファイルが Rankine に固定され、r_c の供給により η の値が一意に決まる。(b) 適用域 (a)(b)(c) が、適用可否を実装の事前に決める判定規則として働く。(c) boil ドーム・航跡傷に変形則（式）がある。(d) 受け口と未接続の扱いが定義される。(e) U8b の検証が3強制に拡張される。
