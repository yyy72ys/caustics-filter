# FIX-6: 面（ドメイン）の復活と粒状感の除去

対象: `caustics-filter/web/`（shader.js / env.js）
前提: FIX-5 の構造（Choppy・44成分・ソフトクランプ・HDR乗算合成）は維持。パターン描画への回帰は禁止のまま。

## 実ブラウザ目視判定（メイン側、FIX-5 スクリーンショット moth-preset0/1）
進歩: 白飛び消滅、格子状の規則配列は解消、平均保存は機能。
残存する不合格点（リファレンス ref1/ref2 との差）:
1. **明るい「面」がない**: プリセット1は全面が均一な細粒のきらめき＋弱いにじみで、コースティクスの網目（フィラメントで区切られた明るいセル）がほぼ視認できない。深掘り調査の診断「線の間の明るい面が本体」が未達。
2. **プリセット0が粒状ノイズ状**: 高密度の白い粒が全面に散り、フィラメントの連続性がない。雪・ノイズのように見える。
3. **スケールが細かすぎる**: リファレンスの構造は「指1〜2本幅のセル＋その内側の微細構造」という2段構え。現行は微細構造だけが全面に出ている。

## 原因の仮説（この順で潰すこと）
- 細 eps 層（E_fine）が支配的になり、広 eps 層（E_broad）の作る大きな集光ドメインが (0.35+0.65·fine) の乗算で潰れている。
- 最高波数帯域（Nyquist 0.8 cap）が強すぎ、密度が画素粒径のスパイク列になっている。太陽3タップぼかしでは粒が繋がらない。
- プリセット0は伝播ゲイン dgL の圧縮上限（4.20）に張り付き、コントラストではなく粒の密度だけが上がっている。

## 変更指示
1. **層バランスの反転**: 合成を E_total = E_broad_norm × (0.55 + 0.45 × E_fine_norm) に変更（広層が主役、細層は縁の鋭さと内部の微細構造だけを担う）。さらに E_broad 側のコントラストを独立に持たせる: E_broad_norm を平均1正規化した上で pow 1.25 を掛け、セルの明暗（0.4〜2.2倍程度）が視認できるようにする。
2. **細層の空間スケール拡大**: 細 eps を現行の 0.45× から 0.8×（対 広eps）へ。最高波数帯域の振幅を −6dB（×0.5）に落とし、Nyquist cap は 0.65 へ。粒ではなく「短いフィラメント片」が繋がる粒度にする。
3. **太陽ぼかしの実効化**: 3タップ→着地点勾配方向に沿った 5タップ（ガウス重み 1-4-6-4-1 系）に拡張し、半径上限を 2px→3px に緩める。粒同士を光学的に繋ぐ目的。ただしプリセット1（浅瀬）では半径が sub-pixel のままになる問題があるため、水深に依らない下限として「画面短辺の 0.15%」を最低半径とする（物理の近似として RESULT.md に明記）。
4. **プリセット0 のゲイン見直し**: dgL 圧縮上限を 4.20→3.40 に下げ、代わりに kc をプリセット0のみ 0.8→1.0 に上げる（粒の密度ではなく面のコントラストで強さを出す）。他プリセットの kc は据え置き。
5. 数値検証の追加: verify-node.js に「空間自己相関の半値幅」相当の簡易指標（密度マップの隣接相関）を追加し、FIX-5 時点より相関長が伸びている（＝構造が画素粒径でなくなっている）ことを確認する。密度統計（平均1±0.15、min≤0.5、max 6〜12）は維持。
