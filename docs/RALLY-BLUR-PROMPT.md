# ラリー質問：初期スタックの「ぼやかす波」の主因（2026-11-15、ユーザー発案）

観察：初期実装（2026-11-10〜12、チャンク方式 v10〜v20 系）では波が「画像をぼやかす」ように見える。現行（面積保存メッシュ堆積）では折り目の効いた鋭い網になる。GPT／Gemini（AI Studio・Gemini 4 Hydrogen）の2席で検証する。

## プロンプト本文（両席に同一文を全文貼付）

あなたは敵対的レビュアーとして振る舞え。以下の候補を検証し、反論と失敗条件を必ず出せ。同意だけで終わらせるな。

水面コースティクス映像の初期実装（2026-11-10〜12、チャンク方式で構築した v10〜v20 系スタック）では、波が「画像をぼやかす」ように見える。現在の実装（面積保存メッシュ堆積）では折り目の効いた鋭いコースティクス網になる。初期スタックの実測仕様は次の通り。


- 像形成：底の画像（写真）を輸送変位場でサンプリングするワープ方式。変位の平均は出力画素で 13.25 px（深さ 4.0 m、パッチ 4.8 m）。v2 期の本編ループでは平均 ≈23 px。
- コースティクス場：2048² マスター格子上に堆積。当時のレポート自身が「変位がマスター格子の約40セル分あるため、折り目が格子上に引き伸ばされてピークが鈍る」と記録している。
- 合成：凍結レシピ A2.6 ＋ Blow（ローパス σ=3.0 px）＋ E2.2。コースティクス場に明示的なガウスぼかしが入る。
- 散乱：FF 位相関数＋FF-CDF カーネル、rms 半径 223.68 px、ハローの 92% を捕捉。澄んだ水のプリセットでも μ=3.37。
- v2 期：毎フレーム 400 万本のフォトンマッピング＋密度推定（カーネル平滑化が前提の方式）。

面積保存メッシュ堆積（三角形面積の厳密な配分、カーネルなし）。監査で確定済み：物理的な広がりは線の量を説明しない／線は基底テクスチャの帯域内容がワープで出入りするもの。

初期スタックで「波が画像をぼやかす」見え方になった主因はどれか。候補：
A. ワープ再サンプリング（変位場を通した画像の再標本化＝空間的に変化するローパス）
B. 合成の明示ローパス（Blow σ3 px）
C. 散乱ハロー（FF-CDF カーネル rms 224 px）
D. マスター格子の解像度（折り目のピークが格子に引き伸ばされる）
E. フォトン密度推定のカーネル（v2 期のみ）

候補ごとに「主因／副因／無関係」の判定＋根拠（数行）＋その判定をひっくり返す測定方法を1つ。最後に、実在の水中で波面が像を「ぼかす」ことが物理的にあり得るかを、瞬時像／時間積分／散乱に分けて答えよ。
