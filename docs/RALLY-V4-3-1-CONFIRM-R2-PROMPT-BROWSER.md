統合 §3-3: 「適用域の宣言、z₀ の導入、入力熱量と場の熱量の収支検証 ε_Q。§2 C10 の感度検証を 3.1／3.4 の検証に書く」。被上書き旧文は親 §1 v4-3.1 (i)（24行目）: 「プルームの形状パラメータ（幅・壁厚・希釈）は Morton–Taylor–Turner 型の浮力スケーリング（b ∝ αe·z、ΔT ∝ z^-5/3 希釈）で縛り、自由な形パラメータで信号振幅を決めない」。第1回の残課題は、MTT の適用条件（有限面積熱源・成層・熱源近傍）が未宣言、ΔT ∝ z^-5/3 は仮想原点 z₀ が無く底面 z=0 で発散、MTT は壁厚を決めない、3.1 単体での熱量収支の検証がない、§2 C10 の感度検証が §1 のどこにもない、の5点だった。

対応条文は親 §6 の R2-2（128–138行目）: 「MTT のスケーリングは仮想原点付きで書く。b(z) = α_e·(z + z₀)、ΔT(z) ∝ (z + z₀)^-5/3。z₀ は熱源の有限面積から決める（点源極限では z₀→0、有限面積熱源では熱源の代表半径相当）。z=0 で ΔT が発散する形は使わない」（131行目）。「MTT 型スケーリングは、浮力支配・定常・乱流の純粋プルーム領域に限定する。適用域の判定は次の入力から行う: 熱源形状（点源／有限面積）、熱流束、周囲水の成層（ブラント–ヴァイサラ振動数 N²）、Reynolds 数。判定の結果、適用域外（熱源近傍の境界層、成層による浮力抑制が支配的な領域、プルーム同士の干渉域）では MTT を使わず、実測入力または別の物理モデルを要求する」（132行目）。「MTT はプルーム半径 b(z) と中心過剰温度 ΔT(z) を決めるが、プルームの『壁厚』は決めない。壁厚は生成器の独立したパラメータとし、画像外の入力に固定する」（133行目）。「生成された温度場の体積積分熱量 Q_field = ∫ρc_p·ΔT dV と、ベッドから入力された熱量 Q_in の収支を検証項目に入れる。判定は |Q_field − Q_in| / Q_in ≤ ε_Q で、ε_Q は実装ブリーフで事前登録する」（135行目）。検証の追加 (vii)「§2 C10 の感度検証: 導関数（dΔT/dz、db/dz）と鉛直プロファイルへの感度を、生成パラメータの不確かさを伝播させて縛る」（137行目）。

閉鎖の判定基準: 次の4点がすべて現行規則として一意に読めること。(a) 仮想原点 z₀ が導入され、z=0 での ΔT の発散が消える。(b) MTT の適用域が宣言され、適用域外での接続先（実測入力または別の物理モデル）が固定される。(c) 入力熱量と場の熱量の収支検証が、定義式と登録の義務つきで検証項目に入る。(d) §2 C10 の感度検証が 3.1／3.4 の検証に配線される（R2-2 の検証 (vii) と R2-7 の配線条項を合わせて読む）。

争点:
(i) z₀ の決め方の一意性: 「熱源の代表半径相当」は、熱源が非円形・複数に分かれる場合に一意な決め方か。z₀ の値が生成器の入力に固定されメタデータに残ることで、再現性は担保されるか。それでも「決め方の規則」として閉じたと言えるか。
(ii) ε_Q の先送りの評価: R2-2 自身は「値の先送りではなく、定義式と登録の義務をここに固定する」と主張する（下書きの書き方を引き継ぐ）。判定式と登録義務の固定で (c) は閉じたと言えるか。閉鎖の物差しはどこに置くべきか、理由とともに判定すること。
(iii) 適用域判定の閾値の不在: 判定の入力（熱源形状・熱流束・N²・Reynolds 数）は列挙されたが、「成層による浮力抑制が支配的」かどうかを分ける判定量・閾値は条文にない。適用域の「宣言」の義務だけで (b) は閉じたか。それとも判定量の不在は、実装者ごとに適用域が変わる余地として未閉鎖か。

#### W4 — 項目4: 界面・閉鎖の定量化（統合 §3-4）

統合 §3-4: 「δ/λ ≤ 0.1 等の数値基準（1/c・ハロ幅は判定から外す）、H = h₁+h₂ の定義、E_field = k_field・E_Turner の二段構造、Ri>1 の混合を出力できる項」。被上書き旧文は親 §1 v4-3.3 (ii)（38行目）: 「基準は界面の実厚さ δ_interface と光学スケール（1/c、ハロ幅、勾配スケール）の比: δ が全てより十分小さければ階段（v4-3.1 の層状極限）」。あわせて §1 v4-3.3 の検証 (i)(ii)（40行目）: 「前線速度の参照形は有限水深比を入れた √(g′h₁h₂/H)」と「entrainment 閉鎖の係数は Turner (1986) から直接引く」— 後者は §1 v4-3.3 (i) の「現場スケール係数は 3.4 で実測較正する対象」と併存し、第1回で二重指定の矛盾とされた。

対応条文は親 §6 の R2-3（139–149行目）: 「階段（不連続 Snell＋Fresnel）で扱うか連続 GRIN で扱うかの判定に、散乱の減衰長 1/c やハロ幅を持ち込んではならない。判定は次の二つの比で決める: (a) 不連続 Fresnel 反射の有無は、界面厚さ δ と波長 λ の比 δ/λ で決める。(b) 幾何光学的な偏向の差は、界面の曲率半径 R と画素サイズ（および光線束の横幅）の比で決める」（143行目）。「階段近似を許す条件は δ/λ ≤ 0.1 とする（値は実装ブリーフで事前登録する。ここでは条件の形と登録の義務を固定する）」（144行目）。「参照形 √(g′h₁h₂/H) の H は全水深 H = h₁ + h₂ と定義する。この式は二層内部波の位相速度であり、非線形な重力流の先端速度とは区別する」（146行目）。「entrainment 閉鎖は E_field(Ri) = k_field · E_Turner(Ri) の二段構造で書く。E_Turner(Ri) は Turner (1986) の関数形と係数表を基準値として固定する（親の『Turner から直接引く』は『基準値として引く』に書き換える）。k_field は現場較正で推定する無次元のスケール係数で、k_field = 1 が『較正不要』の判定である。較正は 3.4 の実測データセットで行い、k_field の推定方法・許容範囲・データ要件は実装ブリーフで事前登録する」（147行目）。「混合速度に風・波の寄与を加えた実効速度 ΔU_eff を導入し、w_e = E(Ri)·ΔU_eff と書く。ΔU_eff の形は Turner 系の実験曲線の適用外として、3.4 の実測で較正する（関数形の候補と較正方法は実装ブリーフで固定する）」（148行目）。

閉鎖の判定基準: 次の4点がすべて現行規則として一意に読めること。(a) 界面判定の物差しから 1/c・ハロ幅が外れ、δ/λ ≤ 0.1 等の数値基準に置き換わる。(b) 前線速度の参照形の H が H = h₁+h₂ と定義され、位相速度と前線速度が区別される。(c) E の二段構造（E_field = k_field・E_Turner）で、Turner 直接引きと現場較正の二重指定が解消する。(d) Ri>1 でも風・波混合を出力できる項（ΔU_eff）が置かれる。

争点:
(i) δ/λ ≤ 0.1 の二重の地位: 数値は本文に書かれたが、同時に「値は実装ブリーフで事前登録する」とされる。本文の 0.1 が現行の確定値なのか、登録で変わりうる仮置きなのか、一意に読めるか。
(ii) ΔU_eff の形の不在: (d) の項は置かれたが、その関数形は実測較正と実装ブリーフへ委ねられ、現時点では形がない。「出力できる項を置く」ことで (d) は閉じたと言えるか。それとも形の不在は、Ri>1 の場面で実装が一意に決まらない余地として未閉鎖か。
(iii) 較正の接続: k_field の較正は「3.4 の実測データセットで行い、現場較正がどこで・どのデータで行われるかは 3.4 の検証 (c) に明記する（§4 R2-4 参照）」（147行目）とされる。R2-4 の実測必須化（W5）がこの受け皿になっているか、原文で確認すること。参照先の節番号（「§4」）の正しさは W6 で扱い、ここでは接続の実質だけを問う。

#### W5 — 項目5: 実測の必須化＋完全な分光閉合（統合 §3-5）

統合 §3-5: 「主要シーン（底加熱プルーム）の実測を必須にし、閉合式に水面反射・側面フラックス・上方正味フラックスを含める。側面境界の物理条件と選択基準、ループゲートの閾値」。被上書き旧文は親 §1 v4-3.4 の検証 (c)(e)(f)（46行目）: (c)「実測が無い項目は不確かさを全ゲートに伝播させて申告する」、(e)「分光エネルギー閉合監査（太陽入力＝水吸収＋底吸収＋上方透過）」、(f)「コースティクス時系列の自己相関によるループ周期性ゲート」。

対応条文は親 §6 の R2-4（150–160行目）: 「最初の場である底加熱プルームについては、温度場または光学的偏向の実測（BOS／シュリーレン実測、または温度プローブ横断）を必須とする。不確かさの伝播は、実測が無いことの代替にはならない。実測が無い項目は『未検証』として扱い、申告だけではゲートを通さない」（152行目）。「波長別に、入射フラックス（太陽）＝ 水面反射 ＋ 水中吸収 ＋ ベッド吸収 ＋ 上方境界の正味放射フラックス ＋ 側面境界の正味放射フラックス、とする。側面境界の物理条件（開放／反射／周期の選択基準）は 3.4 の検証 (d) に明記する。既定は開放境界（有限パッチの外側は同種の水が続くとみなす）とする」（153行目）。「ループ周期性のゲートを二つに分ける。(f1) ループの視覚的接続性: 画像の自己相関と、継ぎ目での不連続量（継ぎ目前後の画素差の統計）で測る。(f2) 物理時間発展の正しさ: 熱量・質量の時間変化、場の自己相関時間、保存則の充足で測る」（156行目）。「許容差の数値そのものは実装ブリーフで事前登録する。設計書に固定するのは、判定量ごとの許容差の定義式と登録の義務である。判定量は帯域エネルギー、ハロ内包率、線深さ分布、分離ベール（境界放射輝度）の四つとする」（155行目）。

閉鎖の判定基準: 次の4点がすべて現行規則として一意に読めること。(a) 主要シーン（底加熱プルーム）の実測が必須になり、「申告だけで通る」逃げ道が閉じる。(b) 分光閉合式に、水面反射・側面フラックス・上方正味フラックスが含まれる。(c) 側面境界の物理条件と選択基準が置かれ、既定が定まる。(d) ループゲートについて、測る量と合格の置き場（閾値またはその登録先）が定まる。

争点:
(i) 必須化の射程: 必須と明記されたのは「最初の場である底加熱プルーム」だけである。他の場面（汽水前線・濁度場）については「実測が無い項目は未検証として扱い、申告だけではゲートを通さない」が一般則として読めるか。読める場合、(a) は最初の場を超えて閉じたと言えるか。
(ii) ループゲートの閾値: (f1)(f2) とも測る量は書かれたが、合格の閾値の数値はない。統合 §3-5 の要求は「ループゲートの閾値」だった。測る量の分離と定義で (d) は閉じたか、それとも閾値の不在は未閉鎖か。MC 許容差についての「定義式と登録の義務」の形（155行目）がループゲートにも及ぶか、原文で確認すること。
(iii) 閉合式の旧文との関係: 新しい式の「上方境界の正味放射フラックス」は、旧文の「上方透過」を含む概念か（正味＝上向き透過と反射の差し引きとして読めるか）。旧 (e) は R2-4 の「置き換える対象」に明示されているため現行規則ではない、という読みで一意か。

#### W6 — 項目6: 文言掃除（統合 §3-6）

統合 §3-6: 「§1 の旧表記（『1–4 mm』画素換算なし、『分離ベール画像』）を §2 裁定に合わせる」。被上書き旧文は親 §1 v4-3.1 検証 (iv)（27行目）: 「底加熱ケースの変位量が導出帯（0.5 m 路径で見かけ変位 1–4 mm）に入るか」、§1 v4-3.2 検証 (iii)（33行目）: 「判定量は堆積の帯域エネルギー・ハロ内包率・線深さ分布に分離ベール画像を加える」、§1 v4-3.2（31行目）: 「『滑らかな単一集団場（勾配スケール ≫ 1/c かつ ≫ ハロ幅）』という適用域」— 澄んだ水（c≈0.2 ⇒ 1/c ∼ 3 m）と噛み合わない、と第1回 Gemini が指摘した。

対応条文は親 §6 の R2-7（182–189行目）: 「親 §1 v4-3.1 検証 (iv) の『0.5 m 路径で見かけ変位 1–4 mm』には画素換算を付ける。メイン枠（窓 1.4755×1.0828 m、736×540）では画素ピッチ約 2.0 mm/px のため、1–4 mm は約 0.5–2.0 画素である」（186行目）。「親 §1 v4-3.2 検証 (iii) の『分離ベール画像』という旧表記を『分離ベール（境界放射輝度）』に統一する」（187行目）。「適用条件を『場の勾配スケールが、光路長と鉛直層厚の両方より十分大きいこと』に書き換える。『十分大きい』の形は、勾配スケール／光路長 ≥ 5 および勾配スケール／鉛直層厚 ≥ 5 とする」（184行目）。あわせて気泡の位相関数（Mie 理論による球形気泡位相関数を既定、185行目）、§2 C10 の感度検証の配線（188行目）、粒子クラスの混合則（189行目）を含む。

閉鎖の判定基準: 次の4点がすべて現行規則として一意に読めること。(a) 「1–4 mm」に画素換算が付き、検証サイズごとの換算の置き場が定まる。(b) 「分離ベール画像」が「分離ベール（境界放射輝度）」に統一される。(c) FF-CDF の適用条件が、澄んだ水と噛み合う形（勾配スケールと光路長・鉛直層厚の比）に書き換わる。(d) §2 裁定と §1 の記述のズレ（C10 の感度検証の配線を含む）が解消する。

争点:
(i) 条文内部の相互参照のズレ（実測で確認された残存。資料の親全文で照合すること）: R2-5（169行目）は適用域を「§7 R2-7 の書き換え条件」と指すが、取り込み後の親に §7 はなく、R2-7 は §6（182行目）にある。R2-3（147行目）は較正の明記先を「§4 R2-4 参照」とするが、R2-4 は §6（150行目）にある。R2-6（178行目）の「§4 の太陽側追加」は、R2-4 の第6項（159行目、太陽側 GRIN の定義・入出力）を指すと読めるか。これらは下書き時代の節番号の残存である。指し先が一意に辿れるなら文言の整備事項か、辿れなければ現行規則の欠落か、区別して判定すること。
(ii) 旧文の物理的残存: §1 の旧表記（「分離ベール画像」33行目、「勾配スケール ≫ 1/c」31行目、「1–4 mm」27行目）は物理的には親に残っている。文言掃除の「完了」は、旧文が消えたことか、上書き宣言によって現行規則でないことが一意に読めることか。後者で足りるなら、その読みは §6 序文（103行目）の宣言で塞がっているか。
(iii) 射程を超えた追加: 気泡の位相関数（Mie 既定）と粒子クラスの混合則は、文言掃除ではなく新規の仕様追加である。これらは §3-6 の閉鎖には数えず、別途の仕様として妥当性を見るべきか。それとも下書き R2-7 の一部として本項目の判定に含めるか。含める場合は、その仕様の深さ（混合則の「形と係数表は実装ブリーフで固定」）も判定対象になる。

#### W7 — 最終主張: 取り込み後の親は「§3 の6件が閉じた土台」と言えるか

W1–W6 を踏まえ、取り込み後の親全体について次を判定すること。(i) 地位の文言: 親3行目「状態: DRAFT — 未採用。本人の採用判断はまだ無い」と99行目「本改訂後も本ファイルは DRAFT・未採用であり、採用は本人の判断による」に対し、5行目の取り込み注記と §6 は「R2 採用・取り込み済み（2026-11-18 本人決定）」とする。§1–§5 の地位（未採用の下書き）と §6 条文の地位（採用済み）の区別は、本文から一意に読めるか。(ii) §6 序文（103行目）の「次は確認ラリー第2回に回す」は、本ラリーを実施している今も残る文である。この種の残存は、閉鎖判定の障害になる水準か。(iii) 下書き §8 への依存: 数値の事前登録一覧は下書き §8 を正とする（103行目）。取り込み後の親は単体で現行規則として完結するか、それとも親と下書きの二文書体制が恒常化し、実装者は常に両方を引かなければならないか。(iv) W1–W6 の個別判定のほかに、§6 の条文同士の直接矛盾が残っていないか。閉じていない箇所は、文面を書けば直る類か、設計の再考が要る類かを区別すること。

### §3 項目ごとの閉鎖判定の求め

W1–W7 の判定に加えて、統合 §3 の項目ごとに「閉鎖」「未閉鎖」の判定と理由を書くこと。対応は次の通り: 項目 1（水面境界の輸送条件）= W1。項目 2（製造用 RTE ソルバー）= W2。項目 3（MTT の適用条件＋仮想原点＋熱量収支）= W3。項目 4（界面・閉鎖の定量化）= W4。項目 5（実測の必須化＋完全な分光閉合）= W5。項目 6（文言掃除）= W6。項目の一部だけが閉じている場合は、その項目は「未閉鎖」とし、残件を具体的に示すこと。

### R2-1 — 水面境界の輸送条件（親 §1 v4-3.1 (iii) と v4-3.2 の境界節を置き換える条文）

**置き換える対象**： 親の「水面での出入り口の屈折は局所 n（T/S 依存）で行い、体積 GRIN と面屈折を分離したまま足し合わせない」という一文。以下が置き換え後の条文である。

- **境界法線**： 水面の出入り口で使う法線は、第1段の水面形状から得る瞬時法線 n̂_s(x, y, t) とする。平面・平均法線による近似は使わない。
- **屈折**： 入射・出射とも、評価位置の局所屈折率 n(x, y, z, λ)（T/S 依存、Quan & Fry 1995）で Snell 則を適用する。出射時の n は水面の直下（水側）で評価し、入射時の n は直上（空気側、n≈1）で評価する。波長帯ごとに光線を追うか、無色収差近似の誤差 bound を示す（親の 3.1 の既定を維持）。
- **反射・透過**： Fresnel の振幅反射率・透過率（非偏光は s/p の平均）を境界条件として適用する。偏光は当面スカラー輸送の誤差 bound として記録する（親の 3.2 の既定を維持）。
- **放射輝度変換**： 境界通過時の放射輝度は L/n² 不変量で変換する（L₂ = L₁·(n₂/n₁)²）。光束は断面積の変化を含めて保存する（3.2 の光束ヤコビアンと同一の計算で扱い、二重補正しない）。
- **反射光の再入射**： 水面で反射された光は輸送対象に戻す（再入射させる）。反射を追う回数は、寄与が総エネルギーの 1% 未満であることを場面ごとに bound で示して切る。bound を示せない場面では回数を切らない。1% という値は実装ブリーフで事前登録する。
- **一つの輸送経路**： GRIN 内部の輸送と水面境界の輸送は、一つの光輸送経路として扱う。1本の光線は GRIN 内を曲がり、水面で屈折・反射し、再び体積に入るまでを一本の経路として追う。内部輸送と境界輸送を分離したまま足し合わせてはならない。
- **検証の追加**（親 §1 v4-3.1 検証へ追加）： (v) 水面境界のエネルギー収支： 入射フラックス＝反射フラックス＋透過フラックスを、波長帯ごとに監査する。(vi) 均一 n の極限で、境界条件が現行スタックの水面処理（Snell＋Fresnel）と一致する。

### R2-2 — MTT の適用条件と熱量収支（親 §1 v4-3.1 (i) を置き換える条文）

**置き換える対象**： 親の「プルームの形状パラメータ（幅・壁厚・希釈）は Morton–Taylor–Turner 型の浮力スケーリング（b ∝ αe·z、ΔT ∝ z^-5/3 希釈）で縛り」という一文。以下が置き換え後の条文である。

- **仮想原点**： MTT のスケーリングは仮想原点付きで書く。b(z) = α_e·(z + z₀)、ΔT(z) ∝ (z + z₀)^-5/3。z₀ は熱源の有限面積から決める（点源極限では z₀→0、有限面積熱源では熱源の代表半径相当）。z=0 で ΔT が発散する形は使わない。z₀ の値は生成器の入力に固定し、メタデータに保持する。
- **適用域の宣言**： MTT 型スケーリングは、浮力支配・定常・乱流の純粋プルーム領域に限定する。適用域の判定は次の入力から行う： 熱源形状（点源／有限面積）、熱流束、周囲水の成層（ブラント–ヴァイサラ振動数 N²）、Reynolds 数。判定の結果、適用域外（熱源近傍の境界層、成層による浮力抑制が支配的な領域、プルーム同士の干渉域）では MTT を使わず、実測入力または別の物理モデルを要求する。適用域の判定結果は生成器のメタデータに残す。
- **壁厚**： MTT はプルーム半径 b(z) と中心過剰温度 ΔT(z) を決めるが、プルームの「壁厚」は決めない。壁厚は生成器の独立したパラメータとし、画像外の入力に固定する（画像の見た目では決めない）。
- **プルーム間隔**： 「間隔は水深 H 級」という層流 Rayleigh–Bénard 由来の文言は削除する。間隔は MTT の独立プルーム条件（隣接プルームの間隔 ≫ b(z)）と、底加熱の実測入力（底アルベド／湧水入力）から決める。独立条件を満たさない場合は、干渉補正を入れるか実測入力に切り替える。
- **熱量収支の実装仕様**： 生成された温度場の体積積分熱量 Q_field = ∫ρc_p·ΔT dV と、ベッドから入力された熱量 Q_in の収支を検証項目に入れる。判定は |Q_field − Q_in| / Q_in ≤ ε_Q で、ε_Q は実装ブリーフで事前登録する（値の先送りではなく、定義式と登録の義務をここに固定する）。粒子（濁度）についても、供給量と場内に保持される粒子量の収支を同じ形で検証する。粒子の供給・除去・境界流出入の扱いは、生成器の入力仕様に明記する。
- **検証の追加**（親 §1 v4-3.1 検証へ追加）： (v) 熱量収支（上記の式）。(vi) 適用域の判定記録（MTT を使った領域と、実測入力・別モデルに切り替えた領域の区分）。(vii) §2 C10 の感度検証： 導関数（dΔT/dz、db/dz）と鉛直プロファイルへの感度を、生成パラメータの不確かさを伝播させて縛る。

### R2-3 — 界面と閉鎖（親 §1 v4-3.3 の改訂 (i)(ii) と検証 (i)(ii) を置き換える条文）

**置き換える対象**： 親の (ii)「基準は界面の実厚さ δ_interface と光学スケール（1/c、ハロ幅、勾配スケール）の比」、検証 (i)「前線速度の参照形は有限水深比を入れた √(g′h₁h₂/H)」、検証 (ii)「entrainment 閉鎖の係数は Turner (1986) から直接引く」。以下が置き換え後の条文である。

- **界面判定の物差し（訂正）**： 階段（不連続 Snell＋Fresnel）で扱うか連続 GRIN で扱うかの判定に、散乱の減衰長 1/c やハロ幅を持ち込んではならない。判定は次の二つの比で決める： (a) 不連続 Fresnel 反射の有無は、界面厚さ δ と波長 λ の比 δ/λ で決める（δ/λ ≪ 1 なら階段の Fresnel が立つ）。(b) 幾何光学的な偏向の差は、界面の曲率半径 R と画素サイズ（および光線束の横幅）の比で決める。親の「1/c、ハロ幅、勾配スケールとの比」という文言は、この訂正で置き換える。
- **「十分小さい」の定量化**： 階段近似を許す条件は δ/λ ≤ 0.1 とする（値は実装ブリーフで事前登録する。ここでは条件の形と登録の義務を固定する）。誤差の測り方は、階段近似と有限厚さ GRIN 解の間の放射輝度差とする。輸送精度に必要な厚さと、場生成モデルに必要な厚さは分けて記述する（前者は光学の判定、後者は流体力学の界面厚さ）。
- **GRIN 補間との整合**： 連続 GRIN 領域では n 場の補間に C¹ 級の滑らかさを要求する（親の 3.1 の既定）。不連続界面は補間で平滑化せず、境界条件として別処理する。有限厚さの界面は、実厚さを解像できる格子で補間する。この三つの扱いを混同してはならない。
- **前線速度の定義**： 参照形 √(g′h₁h₂/H) の H は全水深 H = h₁ + h₂ と定義する。この式は二層内部波の位相速度であり、非線形な重力流の先端速度とは区別する。検証は両者を別項目で測る： (i-a) 内部波の位相速度と参照形の一致、(i-b) 前線の実測位置の時系列との一致（相対誤差を実装ブリーフで事前登録）。親の検証文言「前線速度と実測級の収束（0.05 s⁻¹ 級）」は未定義のため削除する。
- **係数の二段構造（内部矛盾の解消）**： entrainment 閉鎖は E_field(Ri) = k_field · E_Turner(Ri) の二段構造で書く。E_Turner(Ri) は Turner (1986) の関数形と係数表を基準値として固定する（親の「Turner から直接引く」は「基準値として引く」に書き換える）。k_field は現場較正で推定する無次元のスケール係数で、k_field = 1 が「較正不要」の判定である。較正は 3.4 の実測データセットで行い、k_field の推定方法・許容範囲・データ要件は実装ブリーフで事前登録する。現場較正がどこで・どのデータで行われるかは 3.4 の検証 (c) に明記する（§4 R2-4 参照）。
- **Ri>1 の風・波混合**： w_e = E(Ri)·ΔU は Ri>1 で E→0 になるため、風・波の混合で entrainment が続く場面はこの式だけでは出力できない。混合速度に風・波の寄与を加えた実効速度 ΔU_eff を導入し、w_e = E(Ri)·ΔU_eff と書く。ΔU_eff の形は Turner 系の実験曲線の適用外として、3.4 の実測で較正する（関数形の候補と較正方法は実装ブリーフで固定する）。3.3 の検証対照には、Ri>1 でも entrainment が続く場面を含める（親の既定を維持）。

### R2-4 — 実測照合と分光エネルギー閉合（親 §1 v4-3.4 の検証 (c)(e)(f) と物理の根拠を置き換える条文）
