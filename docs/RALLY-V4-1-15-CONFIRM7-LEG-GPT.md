# R8草案・第6回統合に対する専門家レビュー

最終裁定：差し戻し

現状では、P5のQTF帯域内比較に限定した試験0の採用判断に進めない。最大の理由は、J3'の中心値λ₃,exactの定義が、草案内で一貫していないことだ。これは表現上の不備ではなく、合否判定の統計的な基準点を変えてしまう問題である。

## 1. E1–E7の判定

※以下は、受領資料の技術内容から確認できる論点別の判定である。K1–K9の各項目名とE1–E7の原文定義をこの場で逐語照合できないため、対応関係を推測して項目名を捏造することはしない。

### E1：λ₃,exactの定義とJ3'の中心値
不成立

最強反論

第5回統合C3の要求は、λ₃,exactが期待値なのか、有限標本の実現値に対応する予測値なのかを明記することだった。

ところが、提示された記述では、

- R7の定義は「2D暫定採用カーネルで、生成器と同一の離散スペクトル格子上で計算した値」
- §5 J3'および§8.2(c)は、1シードの参照計算Aから値を取得する構造
- 一方、R8の別箇所には400本以上のMC標本平均を使う記述がある

という不整合が残っている。

1シードの値を中心に置いたまま、5シード平均をλ₃,exact ± 2σ_λ₃/√5で判定すると、中心値自身の標本誤差を無視することになる。

独立な1シード中心値と5シード平均を仮定すれば、両者の差の標準偏差は√(1+1/5)σ_λ₃ ≈ 1.095σ_λ₃となる。帯の半幅は約0.894σ_λ₃なので、正しいモデルでも帯を外れる確率は約40%になる。これは許容帯の幅ではなく、中心値の置き方が原因である。

通過条件

- λ₃,exactを400本以上の独立ランダム位相MC標本の標本平均として定義する。
- §5 J3'と§8.2(c)の双方を同じ定義に統一する。
- 1シード参照計算Aの値を、J3'の中心値として流用しない。
- 400本の独立性、標本SDの推定量、95% CIの算出法、独立再現走行の系列非重複を明記する。

失敗条件

1シード由来の中心値がどこかに残る、または400本平均と1シード値の役割が曖昧なままなら不成立。

### E2：400本MCの独立性・再現性
条件付き成立

最強反論

400本という標本数だけでは、独立性は保証されない。RNG系列を記録するだけでも不十分で、系列の重複や再利用があれば実効標本数が400を下回る。

通過条件

- 主走行400本と独立再現走行400本のRNG系列が重複しないことを検査する。
- 標本SDはN−1分母で算出する。
- 95% CIの算出法を固定する。
- 前半200本／後半200本の安定性と独立再現走行間の安定性を別々に報告する。
- bootstrapを使う場合は再標本化回数と区間方式を固定し、正規近似との誤判定率比較を残す。

失敗条件

系列非重複の確認がなく、400本という件数だけで独立性を主張すること。

### E3：15本の補助データの位置づけ
条件付き成立

最強反論

「400本と15本で20%以上食い違えば失敗」という条項を削除した判断は妥当である。15本の補助データの偶然変動を、そのまま主推定の失敗と扱う根拠はない。

ただし、今回示された予測帯0.60σ̂₄₀₀ ≤ σ̂₁₅ ≤ 2.87σ̂₄₀₀は、設計上の参考帯として採用する前に、導出式と自由度を照合する必要がある。

特に、通常の独立正規標本の標本SDについて、15本と400本の標本SD比を単純なカイ二乗分布から導く場合、上限2.87は標準的な95%区間とは一致しない。したがって、数値をそのまま「95%予測帯」と呼ぶことはできない。どの統計量・自由度・予測対象から得た数値かを確認する必要がある。

通過条件

- 20%失敗条項を復活させない。
- 15本は補助的な整合参考値にとどめる。
- 0.60と2.87の導出式、自由度、対象統計量を明記する。
- 導出が確認できるまでは「95%予測帯」と確定表記しない。

失敗条件

導出未確認の数値を、統計的に保証された95%予測帯として使うこと。

### E4：J0の試験0とA/B比較
条件付き成立

最強反論

MF12 Lambda2を基準にしたA/B一致は、FFT分離形S1の実装一致を検証するものであって、2D一般角形そのものの物理的正しさを証明するものではない。

また、Wilton近傍ペアをA/Bで異なる方法で扱えば、比較結果は同じ物理カーネルの実装比較ではなくなる。

通過条件

- A/Bのモード集合・帯域マスク・ペア集合を一致させる。
- Wilton近傍ペアをA/B双方で除外しない。
- 近傍ペア件数と、その寄与によるΔm₂(W)、Δm₄(W)を別途診断する。
- J0はMF12基準の数値一致であると明記する。
- U-1aの独立した斜交角照合とJ0を混同しない。

失敗条件

A/BでWiltonペアの採否や入力帯域が異なる、あるいはJ0合格を2D QTFの物理的確定と扱うこと。

### E5：3D FFT仕様・S1分離形
条件付き成立

最強反論

S1の場積表はR7の符号修正後に直接照合されている。しかし、それは場積の代数的な一致を示すもので、実際の3D FFT実装における全経路の一致を自動的に保証しない。

通過条件

- 時間的解析信号Zを用いる仕様を維持する。
- 和周波・差周波の双方を評価する。
- 3D FFTの対象6本、順変換6回・逆変換2回という仕様を固定する。
- DC、共鳴ビン、端点処理を明記する。
- 生成器の線形部を変更しない。
- 逆変換後の虚部残差を診断する。
- 実装Aとの場レベル比較を省略しない。

失敗条件

場積表の検証済みという理由だけで、3D FFT実装全体の検証済みとすること。

### E6：参照値の誤差予算・M収束
条件付き成立

最強反論

M=512の参照値を採用するには、M=256との比較だけでなく、参照値の有限Mバイアスが各J2b判定線に対して十分小さいことが必要である。

M=512と256の差が小さくても、両者が同じ方向に偏っている可能性は残る。

通過条件

- A(512)とA(256)で|Δν| ≤ 0.0025、峰高95%点相対差≤2.5%を確認する。
- 不達なら1024へ進む。
- 1024でも不達なら参照未収束としてJ2bを判定不能とする。
- M=512と全帯域モード集合との差バイアスを別途確認する。
- 差バイアスが各J2b判定線の半分を超える場合は、A_fullへの切替または系統誤差の明示を要求する。

失敗条件

M=512の参照値を、収束性と全モード差バイアスを確認せずに「正解」と扱うこと。

### E7：第6回統合の訂正管理・記録の一貫性
成立

最強反論

ラリー記録を着地後に書き換えないという方針は、判断履歴の追跡可能性を守る。ただし、過去の記述が訂正された事実を、次改訂に明示しなければ、後続の実装者が旧記述を正本として参照する危険がある。

通過条件

- LEGファイルと統合書を着地後に書き換えない。
- 引用誤りや判定訂正は次改訂草案と次回統合書に記録する。
- R8では、旧記述・訂正理由・新しい定義・影響する節を対応づける。
- 第6回統合の着地内容と、R8での変更内容を混同しない。

失敗条件

旧記述が残っていること自体を問題にするのではなく、旧記述が有効な仕様として再利用される状態を放置すること。

## 2. 第6回統合の主要な訂正に対する判定

**400本と15本の20%条項削除**
成立

補助的な15本の結果を主推定の失敗判定に直結させないという変更は妥当。15本は400本の主推定を置き換えるものではなく、整合性の参考値である。

ただし、今回の0.60–2.87という数値は導出確認が必要であり、ここは別の未解決点として残る。

**ラリー記録を着地後に書き換えない**
成立

監査可能性を維持する方針として妥当。訂正は次改訂で扱うべきであり、過去のラリー記録を後から整形してはならない。

**Grok脚の送信・回収記録**
成立

送信失敗、許可された再試行、回答回収、2回のバイト一致確認という作業履歴は、実施記録として成立する。ただし、バイト一致は回収内容の再現性を示すもので、回答内容の技術的正しさを保証しない。

## 3. 直しの優先順位

最優先：J3'の中心値を統一する。§5 J3'と§8.2(c)の1シード参照値を排除し、400本以上のMC標本平均に統一する。標本平均・標本SD・95% CI・独立再現走行の役割を明示する。

次点：15本の予測帯の導出を確定する。0.60と2.87の統計的根拠を検算する。根拠が確認できなければ、95%予測帯という呼称を外し、補助参考値としてのみ扱う。

その次：参照値の有限M誤差を閉じる。M収束と全モード差バイアスを別々に判定し、未収束ならJ2bを判定不能にする。

WiltonペアのA/B同一性、3D FFTの実装仕様、U-1aの独立照合は、既存のゲートを維持して追跡する。試験0の数値一致だけで未解決の物理的不確実性を閉じない。

## 4. 採用判断にかけられる状態になるための最低限閉じるべき条件

最大3件に絞る。

J3'の中心値の不整合を解消する。§5 J3'と§8.2(c)を400本以上の独立MC標本平均に統一し、1シード値を中心値に使わない。独立性・SD推定・95% CI・再現走行を固定する。

15本の参考帯の統計的根拠を確定する。0.60–2.87の導出を示し、95%予測帯として成立するか検証する。成立しなければ呼称を変更する。20%失敗条項は復活させない。

参照計算の誤差予算を閉じる。M=512の収束性と全モード差バイアスを別々に確認し、許容線を超えた場合の切替・判定不能条件を仕様化する。

審査範囲：RALLY-V4-1-15-CONFIRM6のR8草案および第6回統合について、P5のQTF帯域内比較に限定した試験0の採用判断準備を審査。全帯域、毛管重力、P1、SWELLの採用判断は対象外。

結論：差し戻し。第6回統合の「15本を補助参考値へ格下げする」訂正は通る。しかし、J3'の中心値が1シード由来のまま残るなら、統計的な合否基準は成立しない。まずそこを閉じる必要がある。
