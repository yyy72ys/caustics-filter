## G1 — F1 の直し：J0 と J2b の数値矛盾

最も強い反論
J0 と J2b の数値は、単純に大小関係を整えればよいものではない。両者は比較対象が異なる。
• J0：直接ペア評価 A と FFT 分離形 B の数値的一致

J0 の許容誤差を満たせば J2b の物理的妥当性まで保証されるわけではない。
残る問題は次のとおり。
1. |Δb| ≤0.008 の根拠が弱い。
P5 の帰無分布 SD 0.008 の 1SD を、二つの実装の一致許容幅に採用している。しかし、帰無分布のばらつきと、実装 A・B 間で許容する数値誤差は別の量である。1SD を許容幅にする必然性は
2. Δm₂・Δm₄ の増分誤差は、分母不安定時に挙動が変わる。
R4 は m₂ 0.056%、m₄ 0.784% という切替値を明記したが、その閾値の適用対象・分母・絶対誤差の許容値が、この抜粋だけでは完全には検証できない。

4. 全帯域 m₄ と QTF 帯域 m₄ の扱いが混線しやすい。
