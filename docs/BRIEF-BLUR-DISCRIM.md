## 測定4件（安い順に 1 から 4 の順で実施）

### 測定1: Blow σ=0 の A/B（候補Bの寄与の分離）

- 同一フレーム・同一条件で、Blow σ=3 px（現行）と σ=0 の2通りを生成する。
- コースティクスの線の FWHM（px）を両方で測る。測り方（線プロファイルの取り方、対象線の選び方）はレポートに明記し、両条件で同一手順を使うこと。
- 成果: 両条件の FWHM 数値、線プロファイルの生データ（CSV か JSON）、使用フレームと条件の記録。

### 測定2: ワープ単体＋テストパターンの MTF（候補Aの格付け）

- ワープ再サンプリングだけを通す（フラット照明、散乱なし、コースティクス堆積なし）。入力はテストパターン（チェッカー／シーメンススター）。
- 出力から MTF を測る（MTF カーブと MTF50 等の代表値）。補間方式（コード上の実装）を特定して明記すること。
- 成果: MTF 数値とカーブの生データ、使用した補間方式、変位場の条件（勾配の大きさが分かる形で）。

### 測定3: 波高 0 ＋ 散乱 on/off（候補C が犯人か誤認か）

- 波高 0（平らな水面）で、散乱 on と off の2通りを生成する。
- 画面全体の霞み・コントラスト低下の指標（ハロー幅、コントラスト比等、定義を明記）を両方で測る。
- 成果: 両条件の指標数値。波が無くても散乱だけで霞むかどうかが分かる形にすること。

### 測定4: 格子 2048^2 → 8192^2（候補Dの切り分け）

- 堆積方式は不変、Blow はオフ。マスター格子だけを 2048^2 と 8192^2 で変えて同一条件を生成する。
- コースティクスの線の鋭さの指標（FWHM 等、測定1と揃える）を両格子で測る。
- 成果: 両格子の指標数値、計算時間とメモリ使用量の実測。
