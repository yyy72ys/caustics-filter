# 出力仕様（統合版 v1）— GPT/Grok 両ラリーの統合裁定

2026-11-09、無太郎による統合。根拠：GPTラリー最終合意仕様 v1、Grokラリー仕様 v1、一次リサーチ（realistic-caustics-techniques）、ラウンド1の実測。
両AIの一致点はそのまま採用。相違点は一次資料（全逆像合算が真の輝度という診断）を根拠に GPT 側を採用した。

## 1. 大原則
- 主出力は**物理量の分離パス**。合成済み画像・動画は派生物（プレビュー/配信用）であり、フィルターの本体ではない。
- マスターは線形・無クランプ・無トーンマップ。平均1への正規化もマスターにはしない（生値保存）。ACES/sRGB は表示層だけ。
- パラメータ（解像度・求積点数・ビット深度）は固定値で決めず、**収束・精度試験の実測で決める**。ゲート未達なら未完として明記する。

## 2. 出力の層構成
- **A層（底面平面座標マスター）**
  - `caustic` : 直接太陽光の無次元照度倍率 C = E_direct / E_base_dir（E_base_dir = 平均平面水面での底面基準照度、その定義と値をメタデータに記録）。1ch、生値。
  - `flow_backward` : 出力画素→入力写真の逆変位ベクトル。FLOAT 2ch、単位 px、座標規約（原点・画素中心・Y方向）をメタデータに明記。forward の detJ と混在させない。
  - 透過率・水深・吸収係数は定数/係数として metadata.json に持つ（毎フレームのパスにしない）。
- **B層（カメラ依存の派生）**: reflection_radiance、scatter_additive。A層と混ぜない。
- **C層（表示派生物）**: ACES 適用済み PNG/MP4。
- **検証アーカイブ**: 符号付き detJ、水面状態サンプル、フォトン統計（N_eff は重み付き有効数と分散由来の等価数の2種を区別）、検証レポート。

## 3. 合成式（C層の標準）
```
E_bottom(q,t) = E_amb(d) + E_base,dir(d) × C(q,t)     # 環境光は C で変調しない
L_camera = T_up × (ρ/π) × E_bottom + L_in-scatter + L_reflection
```
ラウンド1の失敗（全体が暗い）はこの分離が無かったことが主因：写真全体に平均0.59の場を掛けていた。

## 4. 輸送の主経路と検算
- **主経路 = 決定論的ヤコビアン法**：水面メッシュの forward 写像を、有限太陽円盤上の角度積分つきで評価し、全逆像の寄与を合算する（フォワードマッピングは構造上、全逆像を含む）。点光源特異点をクランプしない。画素フットプリントを積分に含める。
- **検算 = フォトンマッピング**（既存 transport.py）：同一条件・同一ピクセルフィルタで比較。暫定ゲート：log(1+γC) の MS-SSIM ≥ 0.9、加えて分位点・フィラメント幅・空間スペクトルを報告。不一致でも主経路を自動入替しない（原因切り分けが先）。
- 角度求積点数 Q は 9 / 25 / 49 で収束試験し、最小の合格数を採用（暫定目標：log照度RMSE ≤1%、主要分位点差 ≤1%、スペクトル主要帯域差 ≤2%）。

## 5. 解像度と形式
- 状態計算：2048²。マスター解像度：代表フレームで 2048² 版と面積平均ダウンサンプル 1024² 版を比較し、光束差 ≤0.1%・p99.9 差 ≤5%・トポロジー不変を満たせば 1024²、否なら E・flow とも 2048²。
- 保存：v2 では float32 .npy ＋ metadata.json を正とし、OpenEXR はライブラリが無理なく入る場合のみ（必須化しない）。将来の配布形式は EXR（可逆圧縮 ZIP/PIZ、DWAA はプレビュー専用）。
- 統計の常設報告：mean / p50 / p99 / p99.9 / max、p99.9/mean（Grok 側の目安 6〜12 は基準条件依存の参考値）、積分光束の基準比、空間スペクトルの帯域比。

## 6. ループ
- 位相量子化（ω を 2π/T の整数倍へ）は継続。全確率要素はフレーム番号 mod N の決定論的関数。
- ゲート：E の t=0/t=T RMS 差 ≤ 平均E の 0.5%、flow ≤ 0.05px、境界の時間微分差 ≤ フレーム間変化の 5%。
- 本番の fps/フレーム数（20fps×160 / 24×192 / 30×240）は本番発注時に実測コストで決める（ラリー間の相違点として保留）。

## 7. 基準条件（受け入れテスト用、Grok 案を採用）
太陽高度 45°、水深 1.0m、風速 3.0m/s、ドメイン L=8.0m、太陽角直径 0.53°＋弱い拡散コーン。プリセット実条件でのレンダリングとは別に、この基準条件で統計ゲートを測る。
