## 5. A_full 切替後の確認（(4)。設計 §5 R13）

- 確認 (i) プローブサンプリングの差：同一シード・同一の A_full 場について、組 A（本実装の 256 プローブ配置。cf-0067 と同じ）で出した Δ_ref・ν_ref と、組 B（1.5 m パッチ上の 32×32 均等格子点 1024 点。座標は x_i = i·1.5/32、y_j = j·1.5/32、i, j = 0…31。セル中心は使わない）で出した Δ_ref・ν_ref を比較し、両組の差が ν ≤ 0.0025、m2 ≤ 1.5%、m4 ≤ 5%、歪度 ≤ 0.01 以内であること。**峰高 95% タイルは (i) の対象外**（R13-2）。
- 確認 (ii) 時間エイリアシング漏れゼロ：同一シード・同一の A_full 場を 24 fps（192 標本）と 48 fps（384 標本、同じ 8 s）でサンプリングし、(a) 48 fps 側の [12, 24 Hz] 帯パワーの合計／全帯域（0–24 Hz）パワーの合計（漏れ比）が 10⁻¹² 未満、(b) |ν_24 − ν_48| < 10⁻¹²。スペクトルは未窓 DFT（窓関数なし・ゼロ詰め禁止）の片側パワー、プローブ平均の E(ω) からモーメントを取る（R13-3 の規約どおり）。

## 6. J2b 本体の線（(5) の照合。設計 §5、事前登録）

シードごとに、合成場（η₁+η₂）の統計変化量 Δ（合成場 − 線形場）と参照 QTF の予測 Δ_ref の差：
- Δm₂：増分相対誤差 ≤ 3%
- Δm₄：増分相対誤差 ≤ 10%（評価帯は QTF 対象帯 ≤240 rad/m）
- 歪度 λ₃：絶対誤差 ≤ 0.02
- 峰高 95 パーセンタイル：相対誤差 ≤ 5%
- |ν − ν_ref| ≤ 0.005、かつ Δm₂ > 0・Δν > 0 の符号一致
- ν = √(m₀m₂/m₁² − 1)。m_j はプローブ時系列の片側パワースペクトル E(ω) のモーメント。ν_ref は同一シードの参照計算 A から出した ν_probe との決定論的 1 対 1 照合（アンサンブル平均比較は使わない）。
- GF も cf-0069／cf-0077 と同じ診断で併記する。帯域別（低 k ≤ 30／中 30 < k ≤ 100／高 100 < k ≤ 240 rad/m、和周波・差周波・交差項）にも分けて測る。交差項は m_j(η₁+η₂) − m_j(η₁) − m_j(η₂)。参照値・実装値・差・誤差の 95% 区間を保存する。
- Wilton 共鳴診断と Δλ₃^(W)・Δ|b|^(W) の扱いは設計 §2.6 項目 4・§5 の規定どおり（J2b の歪度項目：Δλ₃^(W) が 0.02 を超えたら当該項目は判定不能）。
- D_± == 0.0 に一致して計算を停止した記録がある場合、その記録を使う判定は判定不能とする（シード差し替えによる解除は認めない）。
