判定： 不成立

最も強い反論： 試験 0 の参照計算 A が U-2 閉鎖まで実行できないという依存関係の明記自体は段の順序として正しい。しかし 設計書 R4 の置き方は「設計書を閉じてから実装ブリーフへ渡す」構造が壊れており、このまま実装ブリーフへ進めば U-1・U-2・U-8（および見せかけ閉鎖の U-7）で実装者の暗黙の選択が不可避に発生する：

U-2（P₁ 第 3 項・原式照合）＋ G-C1-0(a) の時刻矛盾： G-C1-0 は「実装ブリーフを書く前に通す」と書きながら手順 (a) に「実装時に WAFO 原文を取得」と書いており、手順通りには実行できない。しかも WAFO if 0: は 5 クロール一致で g * 2. の次元破綻バグを抱えており使えない可能性が極めて高く、ブリーフ担当者が独自に Langley (1987) や Kaihatu & Kirby (2005) や近似 M&W を引っ張ってくる暗黙のカーネル選択が起きる。

U-1（2D 方向一般化）と U-8（分離形 S1）： S1 は「1D 切片のみ仕様固定」であり、2D 本番用 S1（ベクトル内積・勾配項の展開）は書かれていない。このまま進めると 2D S1 の構成を実装者が勝手に補う暗黙選択になるか、本番 2D コードが何も書けない。

U-7（セットダウン基準）の偽りの閉鎖： 未決 U-1・U-2 に依存する 2D 厳密 B⁻ を基準に置いて「R4 で閉じた」と宣言している。

通るための条件：

実装前に閉じるべきもの： U-1（2D 方向一般化）、U-2（原著による P₁ 含む完全 2D 式確定）、U-8（2D 分離形 S1 の対応表完成）、および U-7 の U-1/U-2 依存解消。これらは設計書 R5 として実装ブリーフの前に必ず閉じること。

未決のまま進めてよいもの： U-3（表面張力 QTF 経路 A） および U-4（高次参照 HOS/3 次摂動） — ただしフェーズ 1 の適用対象を「P5 の重力帯（k ≤ 100 rad/m）のみ、全帯域 m₄・P1・SWELL はフェーズ 2 保留」と厳密限定する場合に限る。

失敗条件： U-1・U-2 が未確定のまま実装ブリーフへ進み、実装者が WAFO 以外の 2D 式や 2D S1 対応表をレビューなしに記述して試験 0（または本実装）の既成事実を作る場合。

直しの優先順位（残っている問題の順序）

1 番：U-1・U-2・U-8（G2・G9） — 原著（Sharma & Dean 1981 / Langley 1987 / Kaihatu & Kirby 2005）から 2D 一般角形の厳密有限水深式（P₁ 第 3 項含む）を本文確定し、2D 分離形 S1 の対応表を完成させ、G-C1-0 の「実装時」矛盾を取り除く。

2 番：1D/2D の混在解消とゲート数式の訂正（G1・G4・G5・G6） — 試験 0 を 2D へ戻して 2D 指標と整合させ（または 1D 指標を分離し）、G4 の反転 χ₄² 予測帯（0.60–2.87 → 0.35–1.67）と J3' の λ₃,exact 算出元、G5 の ν 定義（E(ω) 周波数モーメント統一・5 シード 2D 参照確保）、および G6（U-7）の依存整理を直す。

3 番：帯域・加速度・8 s 比較の境界細部の修正（G3・G7・G8） — a_z < −0.5g の重力帯限定、[100, 120] テーパに対する 2k_max = 240 rad/m・0.51% 再確認・max(|ω_±|, ω(k_±)) 分母修正、および 8 s vs 16 s の低周波定義・シード数・静止縞分離を固定する。

最終裁定

差し戻し

採用判断にかけられる状態になるために最低限閉じるべき条件（3 つ）：

1. 2D 厳密有限水深 QTF と 2D 分離形 S1 の設計書本文での確定（U-1・U-2・U-8 の同時閉鎖）： WAFO 死蔵コードの g * 2. 問題を原著照合で切り分け、2D 一般角形の B± 式と 2D S1 対応表を本文に確定転記し、G-C1-0 の手順矛盾を解消すること。

2. 試験 0（G1）・J2b（G5）・J3'（G4）・U-7（G6）の 1D/2D 及び統計定義の整合修正： 試験 0 の 1D 限定と 2D 指標の混在を解消し、ν の定義（周波数 E(ω) モーメント統一）・J3' の λ₃,exact 算出元（1D 縮小モード A からの流用禁止）・15 本予測帯の反転 χ₄² 修正（[0.35, 1.67] σ̂₄₀₀）を完了すること。

3. 局所限界・帯域カットオフ数値の不整合修正（G3・G7・G8）： a_z < −0.5g の重力帯限定、[100, 120] rad/m テーパに伴う 2k_max = 240 rad/m と k > 100 rad/m 線形エネルギー比の再確認・差共鳴分母 max(|ω_±|, ω(k_±)) 修正、および 8 s vs 16 s 比較の低周波帯域・シード数・静止縞除外を明記すること。
