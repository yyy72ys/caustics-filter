新たな矛盾・誤り

1. 3.2 と §3 の板挟みによる「製造用 RTE ソルバーの消滅」
改訂によって 3.2 は「局所 FF-CDF 評価」を滑らかな場のみの近似へ降格させ、同時に「体積内コースティクス放射場 E(x,t)」と「空間変化する散乱源項を持つ RTE」を要求した。しかし §3（範囲外）が依然としてフォトンマッピング／ビームトレーシングおよび MC の製造利用を禁止しているため、3.3 の成層プルームや急勾配場で不均一ハロや E(x,t) を計算する製造アルゴリズムが設計書から消滅している。

2. 3.3 と 3.4 の間での E(Ri) 較正の空中分解、および 3.3 内の自己矛盾
3.3 (i) が「3.4 で現場較正する対象」と書き換えたのに、同じ 3.3 の検証 (ii) は「Turner (1986) から直接引く」をそのまま残し、肝心の 3.4 には E(Ri) 較正が存在しない。さらに 3.3 検証 (i) が要求する「Ri > 1 でも続く風・波混合」を出力できる項が 3.3 の方程式 (w_e = E(Ri)·ΔU) に無い。

3. 3.3 (ii) の「1/c・ハロ幅 vs δ_interface」という誤った光学スケール比較
屈折率界面を階段（不連続 Snell + Fresnel）で扱うか連続 GRIN で扱うかの判定に吸収・散乱の減衰長 1/c やハロ幅を持ち込んだのは物理的誤りである（不連続 Fresnel 反射の有無は波長 λ との比、幾何光学偏向の差は曲率半径・画素サイズとの比で決まる）。

4. 3.1 ↔ 3.2 の非逐次宣言と逐次 I/O の矛盾、および 3.1 の特異点
本文で逐次処理を否定しつつ I/O は「3.1 の曲がった光路 → 3.2」の逐次形のまま。また 3.1 に新設された ΔT ∝ z^-5/3 は底面 z = 0 で無限大に発散し、仮想原点・初期厚さの指定を欠いている。

5. §2 の裁定文言と §1 の記述のズレ
§2 C2 裁定は「閾値は画素数で書く」とし、C5 裁定は「境界放射輝度」としたが、§1 3.1 検証 (iv) には「1–4 mm」が画素換算なしで残り、3.2 検証 (iii) には「分離ベール画像」という旧表記が残っている。
