J6 — 双線形 |∇z| 縮小バイアス対策（§6.2 V4）

判定：不成立

理由：§6.2 V4 に新設された「双線形補間の |∇z| 縮小バイアス」の対策手順は、数式・参照データ・物理的妥当性の 3 面で仕様として破綻している。

符号定義の致命的曖昧さ（「縮小量を差し引く」）：本文は「補間前後の |∇z| の差を縮小量として測る。V4 の |∇z| の比較は、この縮小量を差し引いた上で判定する」と書く。元の面より補間後が小さくなる（例：1.0 → 0.7）とき、「差」を 補間後 − 補間前 = −0.3 と取るなら引く（−(−0.3)）ことで縮小が打ち消されるが、「縮小量」を正の大きさ 0.3 と取るなら「差し引く」ことで差をさらに悪化（−0.3 を拡大）させてしまう。計算式と符号の定義がない。

参照する Aberle 面と解像度変換が未固定：V4 は「同じ穴マスクを、既知の |∇z| を持つ Aberle 面に適用して双線形補間し」と書くが、Aberle 13 面のうちどの面（または全 13 面平均）を使うのか事前固定されていない（結果を見て都合の良い面を選べる）。さらに Hodge の穴マスクは 2 mm 格子であり、より高解像度な Aberle 面に「同じ穴マスク」をどう適用するのか（Aberle を先に 2 mm へ落としてから適用するのか等）の手順が未記載である。

物理的非転用性と「補正値」合格の自己欺瞞：Aberle の |∇z|（0.7249–1.1739）と Hodge の |∇z|（2.1987）は勾配の大きさが 2–3 倍異なり、線形補間の平滑化縮小量は元の勾配振幅に比例するため、Aberle で測った縮小量は Hodge と一致しない。さらに、補正後の差で V4 を合格させても第 2 段に渡す実メッシュは補正されていない平滑化済み DEM であり、非中立性を補正計算で隠して通すことになる。加えて、補間候補の採用規則（片方合格／両方合格なら双線形）を縮小量補正の前後どちらで適用するか、縮小量測定不能で |∇z| が留保になった場合の §5.2 E1 での処理（§5.2 E1 に記載なし）も未定義である。

通るための条件：(1) もし縮小バイアスの定量報告のみ行うなら、V4 の合否判定からは縮小量の差し引きを外し（平滑化による実変化をそのまま 窓 sd で判定し、縮小量は参考報告とする）、(2) どうしても補正比較を行うなら、使用 Aberle 面の事前固定、2 mm 格子整合手順、厳密な符号つき数式、採用規則との適用順序、および E1 側の留保処理規則をすべて明記すること。

失敗条件：V4 実行時に Aberle のどの面を使うか・差の符号をどう取るかで結果が変わり、あるいは平滑化された床が補正計算により V4 を素通りして第 2 段へ送られる。

判定：条件付き成立

理由：§6.2 V2 で同点処理 (1)「欠損率が小さい窓」が削除されて座標順のみ（流下 u 小 → 横断 v 小）へ一本化され、§1.5・§3.1 S1'・§6.2 V-Q1 で Hodge の d84/d50 が欠損の間は E を d50 のみで鍵かけし V-Q1 で同じ資料から確認する仕様が明記された点は CONFIRM6 の最低条件 3 に沿っている。ただし 2 点の弱点が残る：

1 成分 E = (d50) での一意識別不能リスク：§3.1 S1' は「E が決まれば床は一意に決まる」と契約しているが、Hodge には Run 1・Run 2・Run 3 の 3 つのランがある（§2.4）。V-Q1 で Qc* も d84/d50 も欠損のままだった場合、d50 のみでは Run 1–3 のうちどのランを選ぶか（あるいは複数ランが同じ d50 を持つ場合）が一意に決まらない可能性がある（切り替え規則も V-Q1 で見つかった場合「値を入れ」とあるが、§3.1 での適用条件を明記するとよい）。

上流位置バイアスと低被覆側選択：u が小さい窓（水路上流側）を機械的に優先すると水路入口側の発達過程の領域を選びやすく、また中央値上下等距離同点では被覆率の低い側（median − δ）が選ばれ得る。

通るための条件：§3.1 S1' に「d50 のみでの鍵かけ時に Run 1–3 間で d50 が一致または近接した場合の識別子（ラン番号の扱い）および V-Q1 で d84/d50 が見つかった場合は 2 成分鍵かけへ切り替える旨」を明記すること。

失敗条件：V-Q1 で Qc*・d84/d50 とも得られず、かつ Run 1–3 の切り出しで d50 のみでは床が一意に決まらずシード契約 S1' が破綻する。

J8 — E1(d) 再評価規則と E1 が閉じる前提（§5.2 E1(d)）

判定：条件付き成立

理由：§5.2 E1(d) に V-H1 の 3 分岐（M ≥ 1.8 不要／M ≤ 1.4 やり直し／1.4 < M < 1.8 未決のまま E1 へ）および「第 2 段側から数値で供給されて初めて E1 が閉じる」前提が明記された点は CONFIRM6 の条件に対応している。ただし 2 つの論理的緊張が残る：

第 2 段目標未供給時のデッドロックと循環構造：§5.2 E1(d) は一方では「第 2 段設計の完成を待たず... パラメトリックな感度計算の形でよい（段階間の循環待ちにしない）」と書きながら、直後で「比較基準である「第 2 段の設計目標」は、第 2 段側から数値で供給されて初めて E1 が閉じる。数値が供給されるまで (d) は判断材料不足として E1 を提示しない」としており、第 2 段側の目標数値が確定するまで実質的に段階間の待機（循環）が残る。

未決枝 1.4 < M < 1.8 の無限ループ的提示：E1 を開くための判断材料であるはずの (d) を「未決のまま E1 へ上げる」とし、さらに M ≤ 1.4 では「光学許容誤差の bound」でやり直すため Hodge の実勾配不在のまま許容限界の自己テストになる点も J4 と同じく残る。

通るための条件：§5.2 E1(d) の「第 2 段の設計目標」について、第 2 段設計の完成ではなく事前設計仕様として既存定義から引き出せる数値であることを明記し、および 1.4 < M < 1.8 で (d) が未決のまま E1 へ上がる際の本人の判断手順（(d) なしに許容できるか、追加計測を命じるか）を書き添えること。

失敗条件：第 2 段側から「第 2 段の設計目標は床仕様確定後に決める」と返されて E1 が永久に開けなくなる。
