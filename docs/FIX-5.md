# FIX-5: リサーチ統合 — 水の状態の作り直し＋光の密度の正しい扱い

対象: `caustics-filter/web/`（主に shader.js、必要なら env.js）
前提: FIX-2〜4 の物理コア（スペクトル波高場→屈折着地点写像→ヤコビアン密度→乗算再分配）は維持する。本FIXは「パターンを描く」方向には一切戻らない。環境→水の状態→光輸送→像、の創発構造を守ること。

根拠（4チャンネル統合、詳細はメイン側保持）:
- 深掘り調査＋Grok＋GPT が一致: 白線化は構造問題。(a) 密度は全逆像の合計が本体で、単一分岐だけでは線間の明るい面が消える (b) スペクトルの低周波偏りで折れ目が単純・規則的になる (c) 表示がHDRでなく白に潰れる。
- GPT追加: 水平変位（Choppy）の欠落、ソフトクランプ式の訂正、太陽ぼかしは主因でない（浅い水深では sub-pixel）。
- Grok追加: det処理は pow(1/max(|det|,ε), 0.85) 系＋clamp が実務定番。Hoskins型の独立パターン層はユーザー指定により採用しない。

## A. 水の状態（最優先）
1. **Choppy水平変位を入れる**: 各波成分について水平変位 D = −Σ k̂/|k| · h_k を計算し、変位した水面点から勾配・着地点を求める（λ=0.85 固定でよい、ノード化不要）。山が尖り法線変化が非線形化するのが目的。
2. **帯域別の方向分布**: 成分を L/M/H 帯域に分け、方向の中心を L=風向、M=風向+20°、H=風向−30° とし、帯域内のばらつきは現行の異方性を維持。
3. **スペクトル拡張**: 成分数を現行（16+6）から 40〜48 へ。3〜4オクターブ、最高波数はサンプリング Nyquist の 0.8 倍まで、Phillips重み（1/k^系減衰＋風向異方性）は維持。全成分 ω を 8秒ループ量子化（ω=2π·m/8）すること。最高帯域のみ毛細波分散 ω²=(gk + (σ/ρ)k³)·tanh(kd)（σ/ρ=7.2e-5 m³/s²）を使ってよい。
4. FIX-4 のハッシュ微細法線は残すが、振幅は風速ノード連動のまま、密度計算の「微細 eps 側」にのみ効かせる（広い eps 側には効かせない）。

## B. 光輸送
5. **ソフトクランプ式の置換**: 密度 E = 1/√(det² + δ²)、δ=0.0833（上限≈12）。det は現行どおり無次元化された写像の行列式であることを確認し、コメントに明記。現行の pow 1.9 カーブと (0.25+1.65d)/1.90 再分配は廃止し、この式＋下記 7 の合成に一本化する。
6. **多分岐の近似**: 広い eps の密度（滑らか・大域）と細かい eps の密度（鋭いフィラメント）の2層は維持し、合成を乗算型に変える: E_total = E_broad × (0.35 + 0.65 × E_fine_norm)。E_fine_norm は平均≈1 になるよう数値検証で定数を決める（下記検証参照）。狙いは「線の間に明るい面が残り、暗いセルも残る」こと。
7. **HDR合成（表示の作り直し）**: 合成を L = photo × max(0.1, 1 + kc·(Cn − 1)) に変更。Cn は平均1正規化した密度、kc=0.8 をデフォルト（プリセット側で 0.5〜1.1 の範囲で調整可）。加算の白乗せは廃止。最後に現行のソフトロールオフ（トーンマップ）を1回だけ通す。密度の平均が 1 から大きく外れる場合は正規化定数を直すこと（露出でごまかさない）。
8. **分散**: 着地点オフセットを RGB 別に計算（IOR: R 1.3313 / G 1.3343 / B 1.3393）。差は小さいので誇張しない。鋭いフィラメントの縁にだけ薄く出ればよい。
9. **太陽の有限角度**: 着地点方向に沿った 3 タップの軽いぼかし。半径は 0.0093×水深（UV換算）を上限とし、実効 2px を超えないこと。主修正ではないので重くしない。
10. **水深の焦点**: 密度コントラストに焦点係数を掛ける: 水深ノードの値に対して焦点深度（デフォルト 0.8m、レシピの水深に連動）でピーク、その後は exp(−0.35×(depth−focal)) で減衰（focal 以下では線形に立ち上げ）。Beer-Lambert 吸収は維持し、純水開始値を β=(R 0.34, G 0.057, B 0.0092) /m とし、濁り・色素ノードでスケールする現行構造を守る。

## C. 衛生・検証
11. 最細オクターブに fwidth フェード（サブピクセル化したら絞る）。highp 維持。8秒ループ: t=0 と t=8 の一致を数値で確認（現行チェックに含める）。
12. verify-node.js に追加: (a) 密度フィールドの平均・最小・最大（目標: 平均 1±0.15、最小 ≤0.5、最大 6〜12） (b) Choppy 変位の発散チェック（NaN/極端値なし） (c) 帯域別成分数の出力。
13. プリセット名・UI・レシピJSONスキーマは変更しない。露出プリセット値は 7 の新合成に合わせて再調整可（RESULT.md に変更値を記録）。

- 白の加算合成への回帰。平均を露出で合わせる調整。
