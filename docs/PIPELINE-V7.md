# PIPELINE-V7 — コースティクス v3 チャンク3「人間の網膜（観察者ステージ）」設計

根拠： `research-v3-variables/report.md` §4。前段： チャンク1（水と底、version 3.1）、チャンク2（雨、version 3.2）。本チャンク = version 3.3。順番はユーザー確定（水と底 → 雨 → 網膜）。

## 0. このチャンクの性質 — 水ではなく「見る側」

§§1–3（チャンク1・2）が出すのは放射輝度場（物理量）。本チャンクはそれを**人間の目がどう受け取るか**の後段（observer post-stage）であり、水のシミュレーションではない。したがって：

- 適用位置は合成（composite）の**後**、最終画像に対してのみ。
- マスター（分離パス、線形・無クランプ）は一切変更しない。観察者ステージは表示用の変換として別出力にする（OUTPUT-SPEC の原則どおり）。
- レシピで OFF にすれば 3.2 とビット一致（後方互換ゲート）。

## 1. 前提（これ無しに数字が意味を持たない）

網膜の全ての式は **順応輝度 L_a（cd/m²）** を入力とする。よって最初に「表示の物差し」を1つ固定する：

- `observer.displayPeak_cd_m2`（デフォルト 200）： レンダーの線形ピークが表示では何 cd/m² になるか。
- L_a は表示画像の時間平均輝度から導く（レシピで直接指定も可）。瞳孔も適応も CSF も、全部この L_a（と下記の視野条件）からの導出量であり、独立したスライダは作らない。

## 2. 部品（全て report §4 の式どおり）

### 2.1 瞳孔径 D
- Watson & Yellott (2012) 統一式。入力： L_a、順応野の面積 a（deg²、視野条件から）、年齢（デフォルト 28.58 ＝ 式の基準年齢）。
- D はフレームあたり1つのスカラ。実瞳孔の遅れ（0.2–1s）は注記のみ（本チャンクは定常）。
- D の使い道： 網膜照度（trolands = L × 瞳孔面積）を通じて適応に効き、§2.3 のぼけの大きさを決める。放射輝度そのものは変えない。

### 2.2 適応（ゲイン）
- Weber 型の除算正規化：知覚コントラスト ≈ (L − L_a)/L_a（L_a 近傍）。低輝度側（〜0.3 cd/m² 以下）は de Vries–Rose（√ 則）へブレンド。
- 「適応」スライダは作らない。L_a が唯一の入力。
- 暗順応の時間経過（〜30分、錐体/桿体の2相）は入れない。静止画・8秒ループに順応状態は1つしかない、が正直な限界。

### 2.3 網膜ぼけ（焦点ずれ）
- 幾何学： 角ぼけ ≈ p·ΔD（rad）。p = 瞳孔径、ΔD = 焦点ずれ（D）。
- 採用するのは report の選択肢 (i) **一様ぼけ** のみ： PSF は p·ΔD から決まるガウス型。`observer.focusError_D`（デフォルト 0 ＝ ぼけなし。表示にピントが合っている視聴者が既定）。
- 選択肢 (ii) 水深マップを使った擬似被写界深度は**物理ではないので本チャンクでは入れない**（芸術として欲しくなったら、名前を明示した別ノードとして後付けする）。

### 2.4 CSF（コントラスト感度）— まず解析用
- Mannos & Sakrison (1974)： H(f) = 2.6·(0.0192 + 0.114f)·exp(−(0.114f)^1.1)、ピーク ≈ 8 cpd。
- 周波数軸には視野条件（表示サイズ＋視距離 → pixels/degree）が要る。`observer.viewing` に置く（デフォルトを明記）。
- 既定の使い道は**解析**： チャンク2の輪バンド等の空間周波数成分が、知覚の重み H(f) を通すとどれだけ残るかを numbers に報告する。
- 周波数領域での知覚整形（perceptual shaping）はラベル付きオプションとして実装可だが**デフォルト OFF**。CSF は水の性質ではなく視聴者の感度であり、黙って作品に焼き込まない。

## 4. 数値ゲート（numbers-v7.json に記録）

1. 後方互換： observer OFF で 3.2 の出力とビット一致。マスター不変。
2. 瞳孔： L に対して単調減少、生理範囲 2–8mm 内。Moon & Spencer 形の既知値（L=0.01 → ≈6.9mm、1 → ≈4.9、100 → ≈2.9）と ±0.5mm 以内で整合（統一式との差の範囲として）。
3. 適応： 一様場 L = L_a が中立点（知覚コントラスト 0）を通る。L_a 近傍の局所ゲインが Weber 形と一致。低輝度側で √ 則へ漸近。
4. ぼけ： ΔD=0 で恒等。PSF の実測幅が p·ΔD の予測と線形に一致（±10%）。カーネル正規化（エネルギー保存）。
5. CSF： H(f) のピークが 6–10 cpd の範囲。既定の視野条件で、チャンク2の輪バンド（k≈420 rad/m 相当の像側周波数）の知覚残存率を報告（合否ではなく記録）。

## 5. 検証スチル（offline/out/v7/）

同一シーン（プリセット1、3.2 の状態・合成）で：
- (a) observer OFF（基準）
- (b) observer ON、表示ピーク 200 cd/m²（昼間の適応状態）
- (c) observer ON、表示ピーク 20 cd/m²（暗い表示：瞳孔が開き、適応曲線が変わる）
- (d) 焦点ずれペア： ΔD=0 vs ΔD=1.0（ぼけノードの効きを正直に見せる）
- (e) 診断パネル： 適応ゲイン曲線、L_a と瞳孔径の読み値、CSF 曲線と輪バンド位置の重ね描き

## 6. 正直な限界（numbers と README に明記）

- 適応は定常のみ（時間経過は扱わない）。
- CSF は高輝度での固定フィット。輝度依存の Barten モデルは将来の差し替え先。
- 瞳孔径は集団平均（同輝度でも個人差 ±1mm 程度）。
- 擬似被写界深度（水深キーぼけ）は物理でないため未実装。
