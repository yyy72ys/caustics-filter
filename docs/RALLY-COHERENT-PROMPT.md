あなたは流体力学と水面光学の査読者として、以下の主張群を攻撃してください。各主張に STANDS / WEAKENED / WRONG のいずれかを付け、反論と成立条件・失敗条件を述べてください。最後に、我々が見落としている「雲のように見える水面のコヒーレント構造」の機構があれば挙げてください。

前提（確立済みとして扱うこと）：対象はコンピュータで水面とコースティクスを物理計算する作品。計算枠は「スペクトルで水面の高さ場を作り、光を輸送する」。線形重ね合わせの水面生成と、流れ場では Dolcetti–Krynkin 型の強制モデル（床応答＋定常波リング）を実装済み。見た目のための装置は禁止で、実在の物理だけが許される。主場面は池（窓 1.5–4.8 m、深さ 0.6–4 m）と小さい川。

主張：
C1：風波の群性（包絡）は線形重ね合わせに既に内在する。不足は生成でなく診断（群性係数 GF と帯域幅 ν を測り実測範囲と比べること）。同じスペクトルでも位相の組み方で GF は 0.57 にも 0.95 にもなる。
C2：線形に本当に欠けるのは位相結合（束縛高調波）で、Sharma–Dean の QTF と固有分解で現実的なコストで計算できる。ただし急峻度 ka≈0.01–0.1 の場面では峰への効果は数％で、優先度は中。
C3：Benjamin–Feir 型の集束は我々の場面では発動しない（BFI≪1、成長長がフェッチを桁で超える）。範囲外で正しい。
C4：流れの中の定常パターンは静止位相条件 (k·U)²=ω²(k) で決まり、山岳波の定在雲と数学的に同型。床応答＋リングで実装済みであり、持続・減衰・破壊の条件（底面摩擦で下流減衰、ak≳0.3 で破壊）は文献通り。
C5：池の場面で最大の欠落は突風の空間構造（猫の足跡）と表面膜である。実装形は帯域分割変調：突風場 U(x,y,t) を余分に1枚生成し、応答する高 k 帯だけを局所平衡で振幅変調する。膜の Marangoni 減衰は同じ機構の裏表。
C6：川では基底流 U(x,y) の場所変化が定常波を伸縮・消滅させる（λ0∝U_s²、U_s<c_min≈0.23 m/s で消滅）。本物のブロッキング（作用輸送）の機械は池の風吹送流では過剰で不要。
C7：よれ・潮目（シア境界の収束線）は高さ場の波ではない。水面収束に泡・膜・ゴミが集まる素材線であり、「波として描く」のは物理的に嘘になる。正しい実装は、流れ場から継ぎ目を生成し素材線＋帯域変調レーンに載せること。
C8：水中の岩の上の boil/scar は岩ごとの強制フィーチャタイルで計算可能（boil は H/R≈3 で水面到達、渦芯直上の窪みは Γ²/(8π²gr²) で mm〜cm 級）。カルマン渦列は 2DH 速度レーンが要り、2次流セルの力学は範囲外。
C9：密度系では河川プルーム前線が最も目に見えて最も計算可能（2層レーン＋素材線）。塩水くさびの KH ビローの水面署名は主に slick/粗さバンドで、解像した渦形状は CFD のみ。密度シュリーレンは画像形成そのものを変える唯一の項目（第3段の GRIN 輸送）。二重拡散は範囲外。密度系は汽水場面＋第3段所属で、淡水の池に作るべきではない。
