### J1 — H3再検査の構造再設計
**不成立**

通った点

R9 §6.2 V3(ii)は、再検査を「独立した再測定」と呼ぶことを撤回した。これは正しい修正である。

CONFIRM7統合「最低条件1（H3を閉じる：J1・J2）」および「3席が一致した急所」のJ1では、初回と再検査の窓が空間的に重なるため、独立した証拠の追加とは扱えないことが問題にされた。

R9はこれを受け、§6.2 V3(ii)で次のように変更している。

- 初回と重ならない再検査配置はHodgeの寸法内では不可能と算術で示す。
- 再検査を「ずらし再測定（空間相関つき）」と呼ぶ。
- 初回との面積重なり率を用いて相関つきsd差を計算する。
- 独立な証拠の追加とは主張しない。
- Run 1–3を別々に判定し、3 Runすべてで条件を満たす場合だけ留保を解消する。

これはCONFIRM7の最低条件1にあった二つの選択肢のうち、後者を選んだものだ。

すなわち、初回と重ならない配置を無理に主張するのではなく、独立再測定という主張を撤回し、空間相関を扱う判定法を数値で登録する方向である。この方針転換自体は通った。

残る問題1：面積重なり率を相関係数と同一視している。

R9 §6.2 V3(ii)は、

sd_差 = √(sd_1² + sd_2² − 2f·sd_1·sd_2)

とし、面積重なり率 f をそのまま相関係数 ρ として使用する。

さらに、次の仮定を置いている。

- 重複部分は完全相関。
- 非重複部分は独立。
- 重複外にも空間相関が及ぶなら真の相関は f より大きくなり、sd差はさらに小さくなる。

この仮定を明示したことは前進だ。しかし、面積重なり率が実際の窓統計量の相関係数になることは、本文中で検証されていない。

空間的な重なり面積と、H_loc・Sk・Skew・|∇z|という窓統計量の相関は同じものではない。窓の重なりが同じでも、統計量ごとに空間相関の距離・方向・強さは異なり得る。

「重複外の相関があればさらに厳しくなる」という説明も、相関が正である場合の説明である。相関構造が統計量ごとに異なる可能性や、面積比を相関係数と置くモデル誤差は解消されていない。

したがって、R9の式は事前登録された設計仮定としては読めるが、空間相関を適切に評価する方法として確定したとは言えない。

CONFIRM7が要求したのは、独立性を撤回するだけでなく「空間相関を扱う判定法（誤差評価含む）を数値で事前登録」することだった。R9は数値を置いたが、相関モデルの根拠までは閉じていない。

残る問題2：横断方向の脆弱比の誤差評価が不整合。

R9 §6.2 V3(ii)は、横断方向の脆弱比について、

- 窓統計全体、つまり流下33位置×横断3位置＝99窓のsdを使う。
- 横断3位置・自由度2なので、単独推定誤差は約50%とする。
- 横断だけのsdは作らず、vetoのみに使う。

という仕様を置く。

ここには計算上の説明不足がある。

99窓からsdを計算するなら、99個の観測値のばらつきと、横断3位置しかないことによる独立情報量の制限を区別しなければならない。横断位置を独立な3クラスターとして扱うなら自由度2という説明は理解できるが、その場合は99窓のsdがどのように3クラスターの誤差評価へ結びつくのかを定義する必要がある。

逆に、99窓を独立観測に近いものとして扱うなら、自由度2という説明は成立しない。流下方向の空間相関があるため99を独立標本と数えられない、というだけでは、自由度2を採用する具体的な推定法にはならない。

これはCONFIRM7で指摘された横断方向の再評価の弱さを、名称だけ変えて残している可能性がある。

最低限必要な修正

- ρ = f を使う理由を、統計量別の相関構造または保守的な上限評価として説明する。根拠が出せないなら、設計仮定としての限界と適用範囲を明記する。
- 横断方向について、99窓のsd算出式、独立単位、自由度2の導出を一つの計算手順として示す。
- その計算手順で得られる値が、留保解消ではなくvetoだけに使われることを維持する。

J1は不成立。独立性の撤回は通ったが、空間相関モデルと横断方向の誤差評価はまだ閉じていない。

## 6. 採用判断へ進むために残る修正

優先順位順に、最低限必要な修正を示す。

**最優先1：J1の再検査モデルを閉じる**

- ρ = f の扱いを、統計量別に妥当性を説明できるモデルとして確定する。
- 説明できない場合は、相関係数としての扱いを撤回し、保守的な設計仮定として判定上どこまで使えるかを定義する。
- 横断方向の99窓sdと自由度2の誤差評価を、独立単位・計算式・誤差の導出まで一つの仕様にする。
- 再検査が独立証拠の追加ではないという限界は維持する。

**最優先2：J2の閾値の位置づけを決着させる**

- 4面という閾値を、既知のSkew 5面・Sk 1面に依存しない根拠で再設定する。
- それが不可能なら、4面を妥当性の確立した閾値と扱わず、暫定的な設計選択として扱う。
- V-Q2の結果が得られるまでは、分離規則の暫定発動を維持する。
- 「最大2つ」も10.5%という算術だけで妥当性が確立したとは扱わない。

**次点：E1の残件を閉じる**

- J1・J2の未閉鎖をE1が自動的に解消した扱いにしない。
- 第2段の設計目標が数値として供給されるまでE1(d)を閉じない。
- 第2データセットが取得されるまではV-Q2の検証を未完了として扱う。
- 本人のリスク承認後も、Hodge単一データセット依存・独立検証不能を限界として残す。
