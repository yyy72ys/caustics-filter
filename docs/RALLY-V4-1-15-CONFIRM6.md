### D6 — §2.6 項目 4 の Wilton 除外の一意化：不成立（3席一致）

- **3席が独立に同じ結論へ達した。理由は 3 層ある。**
- **第 1 層（GPT の指摘が最も深い）**：Wilton 判定はモード対 (m, n) 単位の条件だが、S1 の 3D FFT は実空間の 2 次積を (k_x, k_y, ω) 空間でフィルタする方式であり、異なる複数のモード対が同じ出力 (κ, ω) ビンへ寄与し得る。したがって出力側の (κ, ω) マスクだけでは、特定の共鳴ペアだけを除いて同じビンの非共鳴ペアを残すことは一般にできない。参照 A（直接二重和）ではペア単位の除外ができても、B では畳み込んだ後に同じ除外を再現できるとは限らない。A と B で異なるペア集合を比較する限り、J0・J2b の相関や誤差の数値に意味がない。
- **第 2 層（Gemini）**：そもそも §2.2.4 ステップ 4（B の 3D FFT フィルタ）に、離調 < 0.05 の (κ_±, ω_±) ビンを除外する手順が一切書かれていない。このままでは A だけが除外し B が除外しない（あるいは両方とも除外せず、δ 感度確認自体が A/B の差とずれる）状態になる。加えて離調式の分子の ω₁, ω₂ がカーネルの純重力 ω か生成器の毛管重力 ω_cap かが未指定で（どちらを入れるかで共鳴ペア集合が変わる）、分母は max(|ω±|, ω(k±)) へ直されたのに式の表記は /ω_± のまま残っている。
- **第 3 層（Grok）**：「通常の QTF 評価からは除外するが試験 0 の結果からは除外しない」の二つの扱いが、試験 0 が比較する A と B のどちらに掛かるのかが曖昧なままである。「閾値依存」「Wilton 寄与依存」の記録については、Gemini は「フェーズ 1 採用判断に使わない」保守規則として機能すると読んだが、Grok は J0 の二値合否の外に第三の結果を復活させていると読んだ。統合の扱い：この記録自体は、名称と位置づけを「不合格側の記録（採用判断には使わない）」と明記すれば一意性を壊さない。ただしそれは副次的な問題で、本項の不成立は第 1・第 2 層で確定する。
