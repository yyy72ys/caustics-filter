## 1. 分解案

### v4-4.1 捕捉幾何（カメラの置き方と窓の実寸）

- **目的**：「写真＝窓」の約束を、有限位置のカメラ＋透視投影＋
  センサー寸法・焦点距離からの実寸対応に置き換える。
- **物理的根拠**：ピンホール／薄レンズの投影幾何。窓の実寸は
  W = W_s·(s/f − 1) で決まる（W_s = センサー幅、s = 合焦面距離）。
  カメラの位置・距離・角度が視線ベクトル場を決め、それが輸送側の
  Fresnel・屈折の入力になる。
- **入力**：カメラ位置（水面からの高さ・水平位置）、姿勢（視線角）、
  センサー寸法、焦点距離。場面側は水深と窓中心。
- **出力**：画素ごとの視線ベクトル場、床面上での窓の実寸と対応表、
  「直交・無限遠」極限で現行形に帰着することの確認データ。
  ※ラリー反映（2026-11-14）：視線場は輸送の**前段**で決める（有限カメラの
  視線角は Snell 屈折・Fresnel・水中路長を変え、直交前提の輸送結果を後段
  からは直せない — 順序の反転問題）。また有限開口の瞳サブレイの幾何
  （入射瞳の位置・大きさ・形状）もここで定義し、v4-4.3 の開口積分の入力に
  する。PRESETS の整合性は「逆算できる」だけでなく等価パラメータで同じ
  数値画像が再現されることまでを検査とする。窓のアスペクト（15:11）と
  マスター 2048²（1:1）の対応づけもここで固定する。
- **検証**：既知寸法の標的（蛾の翅幅 40–53 mm／格子チャート）を場面に置き、
  実寸↔画素の対応が式どおりか測る。直交極限で既存の確定出力
  （v4-1.8 系）と一致を数値で確認。PRESETS 三枠をカメラパラメータへ
  逆算し、破綻がないかを示す。

### v4-4.2 見かけの距離場（輸送→カメラ段の受け渡し）

※ラリー反映（2026-11-14）：本節は「近軸・単一像枝の**有効**距離場」へ
格下げする。スカラー距離場は定義上1つの面であり、非点収差の2枚焦点も、
波の曲率で見かけ深さが ±∞ を通って水上に実像化する現象も表せない。
有効範囲（波の主曲率・視線角・開口）を数値で宣言し、範囲外は光線束／
波面情報への拡張対象として明記する。

- **目的**：焦点と被写界深度が使う「距離」を、幾何距離ではなく
  水面屈折を通した見かけの距離として画素ごとに供給する。
- **物理的根拠**：平面屈折の虚像（近軸で実深さ/n、斜めでは非平面・
  非点収差）。波面では輸送の変位場が見かけの像そのものなので、
  距離場は変位場と対で輸送側から出す。
  ※訂正（2026-11-14、ラリー Gemini 脚）：幾何距離とのずれは「係数 n」では
  ない。空気層 h_a 込みでは s_app = h_a + d_w/n 対 s_geom = h_a + d_w で、
  メイン条件（h_a=1.0 m、d_w=0.6 m）では比 1.10、h_a=3.0 m では 1.04。
  n 倍はレンズが水面に接する場合の極限。
- **入力**：床の標高場（第2段）、水深、水面の状態、v4-4.1 の視線場。
- **出力**：見かけの距離場 D_app(x, y)（画素ごと）と、平坦水面・近軸条件で
  実深さ/n に一致することの較正記録。
- **検証**：平らな床＋静水面の解析解（見かけ深さ = 実深さ/n）との一致。
  斜め視線で距離場が単一面からどう外れるかを測定して記録（v1 で
  扱う範囲の宣言に使う）。

### v4-4.3 レンズ結像（焦点・被写界深度・ピント外し）

- **目的**：焦点合わせ、絞りによる被写界深度、ピント外しを、
  輸送後の放射輝度場に対する開口積分として実装する。
  ※ラリー反映（2026-11-14）：開口積分の**入力契約を明記すること**が確定
  条件。入力が単一視点の2D画像＋距離場のままでは真の開口積分にならない
  （瞳サブレイは水面の異なる点を通り、異なる屈折・遮蔽・体積散乱を受ける
  — 4席一致）。実装は「瞳サブレイ再トレース」か「2D近似である宣言＋
  誤差の実測」のどちらかを契約に書く。
- **物理的根拠**：薄レンズ式、ぼけ円 b = (f²/N)·|s − s_f|/(s(s_f−f))、
  開口積分＝開口上のピンホール像の重ね合わせ、回折 Airy 盤 2.44λN_w
  （N_w = N·s_f/(s_f−f)、有限共役の実効 F値）を PSF に合成。PSF は
  D_app から画素ごとに決まる。
  ※式の訂正（2026-11-14、ラリー Gemini 脚）：初版の分母 (s_f(s−f)) は
  s と s_f の取り違え。正しくは (s(s_f−f))。数値影響は小さい
  （C7 の例で 0.139→0.141 mm）が極限が誤っていた。あわせて、幾何円と
  Airy の単純畳み込みはデフォーカス 1–5 波長の遷移域で波動光学 PSF と
  ずれることを近似として明記する。cos⁴ 周辺減光と瞳の短縮（楕円ボケ）は
  レンズ固有収差でなく幾何として本節に含む。
- **入力**：放射輝度場（合成前の場）、D_app、焦点距離 s_f（対象は
  水面／中間／床から選ぶ物理距離指定）、絞り N、焦点距離 f。
- **出力**：結像後の場。ピンホール極限（N → 大、開口 → 0）で入力に
  帰着すること。
- **検証**：点光源チャートでぼけ円直径を実測し式と照合（許容差は
  設計時に固定）。2面チャート（水面相当面／床相当面）で合焦範囲が
  近点・遠点の式どおりか。平坦部での総光量保存（開口積分は平均を
  変えない）。回折側は点像の Airy 径を 2.44λN と照合。
  ※ラリー反映（2026-11-14）：「許容差は設計時に固定」を具体化すること
  ——PSF 検証の**許容差の数値と参照レンズ級を固定**しない限り C4 は
  反証不能（4席一致）。検証群は平坦水面＋解析解だけでは不足で、波面
  ケース・遮蔽境界・グリッター対床・空間変動 PSF・実レンズ PSF または
  高次光線追跡との照合を含む受入テスト群（統合 RALLY-V4-4-1.md の
  一致点4）として再編する。非平坦部では gather 型 PSF はエネルギーを
  保存しない点も検証対象。

### v4-4.4 焦点の時間制御（フォーカス移動）

- **目的**：動画で焦点を水面→中間→床へ移す操作を、s_f(t) の
  指定として実装する（2026-11-13 ユーザー着想 2-3 の正規スコープ）。
- **物理的根拠**：各瞬間の結像は v4-4.3 の静止形そのもの。時間方向に
  新しい物理は「焦点距離の軌跡」だけであり、被写界深度の効く条件は
  体制地図（調査 §2.4）に限る。
- **入力**：s_f(t) のキー指定（時刻と対象面）、ループ長 T。
- **出力**：フレームごとの s_f と結像。境界条件 s_f(0) = s_f(T)
  （継ぎ目なしループ、SPEC の前提）。実効焦点距離の変化のうち
  レンズ固有分（ブリージング）は v1 では含めない（主張 C6）。
  ※ラリー反映（2026-11-14）：薄レンズでも導ける像面移動に伴う倍率・
  画角変化（面→床で 50 mm 級 5.6%、85 mm 級 10.2%）は「導けない」に
  含めない。v1 で両方とも固定するなら「定画角ピンホール＋薄レンズ DoF
  のハイブリッドである」と宣言すること。あわせて**シャッター時間積分**
  （露光中の水面・網目・グリッター・焦点の動きの積分＝モーションブラー、
  ループ継ぎ目の周期条件込み）は本節と v4-4.5 にまたがる必須項目として
  追加する（4席一致の見落とし）。
- **検証**：2面チャートの動画で、合焦面の移動が指定軌跡どおりか
  フレームごとに測る。シーム（t=0 と t=T の C 差分 max）を従来作と
  同じ物差しで記録。体制地図の外（両面とも合焦範囲内）では
  「変化なし」が正しい出力であることを確認する。
