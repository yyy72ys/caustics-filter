## 実装内容
1. **天空モデル**： Perez et al. (1993) all-weather 天空輝度分布（公表係数表を実装し、採用した表・式を REPORT に明記）。入力： 直達率 η = DNI/(DNI+DHI)、全体放射量、天頂輝度相当量、濁度（既定 3）。
2. **実在モード**： Open-Meteo から direct_radiation / diffuse_radiation / direct_normal_radiation を分離取得して η を決める経路を用意する。取得は環境解決ステップとして分離し、描画器は解決済み η・放射量を入力に取る。取得失敗時は記録の上で代表値（晴天 0.8／曇天 0.05 級）に落とし、処理は止めない。
3. **輸送結合**：
   - 直達成分： 従来の決定論輸送（有限太陽円盤）を DNI 份额で。
   - 拡散成分： 天空ドームの方向求積（Perez 輝度×入射余弦で重み付け、64–128 方向）で同じヤコビアン輸送を方向合計。拡散 C は 512² マスターで計算し、正当性（拡散 C の p99/平均と空間スペクトルで微細構造が無いこと）を numbers に記録する。
   - 拡散の水中減衰は直達とは別の平均路程係数を持ち、採用値と根拠を記録する。
   - 合成（A2.6+Blow+E2.2 凍結）は変更しない。変えるのは光の場 C → C_total（加重和）のみ。
4. **レシピ**： `sky.directFraction` / `sky.mode` を追加。天空指定のないレガシーレシピは η=1 として 3.4 と完全一致。

## ゲート（全て数値で REPORT-v9-gates.md へ）
1. η=1 で 3.4 の C・スチルと一致（差分を数値で）。
2. 平水面では任意の η で C_total ≡ 1（最大偏差を記録）。
3. η 掃引（1.0/0.75/0.5/25/0）でコントラスト統計（p99、p99.9、標準偏差）が単調低下。η=0（拡散のみ）の場の振幅を実測記録。
4. エネルギー収支： 底面総量と (DNI+DHI)×透過の収支が許容内（許容値を明記）で閉じる。
5. 実在モード： 晴天／曇天の実サンプル（または代表値）で η が桁の正しい範囲。取得可否を記録。
6. 標準プリセットで crush は従来 bound（0.0325）以内、blow = 0。
