# PIPELINE-V5 — v3 チャンク1（水と底の変数）設計

土台： `research-v3-variables/report.md` §1・§2・§5。対象はオフライン物理パイプライン（v2 公開分が本体）。
進め方はいつも通り： brief → dsh 実装 → 数値ゲート＋検証スチル → Muse が検分して納品。

## 追加・変更する変数（全て report の式に基づく導出量／物理量。気分スライダーは作らない）

### 1. 波高 H_s（state.py）
- 風駆動モード（既定）：今の Phillips スペクトルのまま。実スペクトルを数値積分して H_s = 4√m₀ を**読み出し値**として numbers に出す（読み取り専用ノード）。
- 高さ駆動モード（新入力）：スペクトルの積分が m₀ = (H_s/4)² に一致するようスカラー倍率を掛ける。ピーク波数は風・フェッチ側が決めた位置のまま（Bretschneider 型の二パラメータ化）。物理キャップ： Stokes 限界 H/λ ≈ 1/7 を超える場合はキャップして numbers に明記。
- ゲート：高さ駆動モードで、実現した H_s が目標の ±5% 以内。

### 2. 穏やかさ = 平均二乗勾配 σ²（state.py + composite）
- フレームごとに FFT 勾配から実現 σ² = ∫k²S(k)dk を計算し、ノード「穏やかさ」として表示（単位 rad²、現在風速での Cox–Munk 参照値 σ² = 0.003 + 5.12×10⁻³U を併記）。
- スペクトルの高波数側を、実現 σ² が Cox–Munk 値に合うよう較正する（解像帯域内の話として numbers に偏差を出す）。
- キラめき（glitter）は異方性ガウス (σ_a², σ_c²) でサンプルする（σ_a² = 3.16×10⁻³U、σ_c² = 0.003 + 1.92×10⁻³U）。等方版はその特殊ケースとして置き換える。

### 3. 波の影（composite、統計版が第一歩）
- 直接光の項に Smith の G₁(sun) を掛ける。α = 実現 rms 勾配。**近似であることを numbers と README 側メモに明記**。
- レイ厳密版（フットプリント再交差テスト）は今回はやらない。二重に掛けない（どちらか一方）。

### 4. 反射の分離（composite）
- 水面 Fresnel：**ノード化しない**（IOR と角度から計算される量。現行どおり）。
- 底アルベド ρ_b：新ノード。基質プリセット（sand 0.24–0.30 / rock 0.10–0.25 / vegetation ≈0.12（海草、500–600nm では 0.10 以下）/ mud ≈0.05）をチャンネル別ゲインとして E_base,dir に適用する。写真が「底」である現行構成では、線形値へのスペクトルゲインとして caustic 乗算の前に掛ける。

### 5. ボトムレンジ＝水深のスペクトル減衰（transport は不変、composite の絶対項へ）
- Beer–Lambert：直接項に exp(−c(λ)·s↓)、底からの戻り光に exp(−c(λ)·s↑)。s↓ = z/cos θ_w（θ_w は屈折後の水中太陽角、≤48.6°）。
- c(λ) = a(λ) + b(λ)。a は Pope & Fry 純水吸収表をチャンネル実効波長（≈650/550/470nm と明記）で補間。濁度は Δa+Δb として加算（スペクトルは平坦寄り）。
- 既存の場当たり的な「深さで一様に暗くする」処理があれば置き換える。
- ゲート（計算例の再現）：清水・z=2m・垂直太陽・往復で 550nm ≈ 0.80、650nm ≈ 0.26（±0.02）。

### 6. 深さとコントラスト（新スライダーは作らない）
- 幾何学的なコントラストは transport の計算どおり（z 依存はレイ形状に内在）。
- 深さがコントラストに効くのは物理チャンネル経由のみ： (i) 上記スペクトル減衰、(ii) 濁度による散乱ブラー（C を σ_blur ∝ √(b·z) のカーネルで畳み込む）。

## 成果物と検証
- 実装： PC `caustics-filter/offline/` に v5 系（run_v5.py 等、既存ファイルは壊さない）。numbers は `numbers-v5.json`。
- 検証スチル（プリセット1、同一 seed）：
  1. 基準（v3 最終合成と同一条件）との並置
  2. 深さペア： z=0.5m vs z=3m（赤が先に死ぬスペクトル変化が見えること）
  3. 基質ペア： sand vs vegetation
  4. 波高ペア： 風駆動（読み出し H_s 併記）vs 高さ駆動 H_s=0.3m 固定
- 数値ゲート： C の平均 = 1.0（従来どおり）、潰れ・白飛びが v3 最終（7.9% / 0%）より悪化しないこと、上記 1・5 の個別ゲート。
- 失敗したら数値と一緒に報告（成功したことにしない）。
