### L1 — 相関つき差分ゲート

条件付き成立

成立した部分

R11は、相関つき差分ゲートを sd_ゲート = min(sd_差, sd_1) と定義し、初回より緩い閾値にならないようにしています。

また、実行時に対応窓対(A0,O1)の標本相関を算出し、設計仮定の ρ = f_a = 0.338 と照合・報告する診断を追加しました。これはCONFIRM9の最低条件1に対する適切な修正です。

残る問題

標本相関の照合は、ρ=fという仮定の妥当性を検証するための診断であり、真の相関を確定するものではありません。単一床の実現から得た標本相関を、母相関の検証結果として扱うことはできません。

また、sd_差 < sd_1 となるのは、sd_2 < 2f·sd_1 = 0.676 sd_1 の場合だけです。したがって通常の領域ではsdゲートはsd₁に張り付きます。照合を追加しても、この領域の閾値が自動的に変わるわけではありません。

成立条件

- 実行時相関は仮定の診断として報告し、真のρの検証結果と呼ばない。
- 窓対数、欠落数、欠落理由、標本相関を報告する。
- 仮定と実測値が乖離しても、その場で閾値を変更しない。変更には再登録を要求する。
- sd差・sdゲートを真の差分分布の推定値として扱わない。

失敗条件

- 標本相関を母相関の確証と扱う。
- 実行結果を見て閾値や相関仮定を事後変更する。
- sdゲートのキャップを、ρ=fの妥当性が証明されたことと読み替える。

### L2 — 脆弱比32%の誤差評価

条件付き成立

成立した部分

R11は32%を、分子側sdの相対誤差20%を40%の線に組み込んだ設計値として扱っています。誤差の二重計上を避け、下限・上限の読み替えも対称に整理しました。

残る問題

脆弱比は、窓sd／分母 です。R11の20%誤差評価は分子のsdに関するものであり、分母の不確実性を含んでいません。

分母は事前登録固定値として扱われていますが、固定値と不確実性がゼロであることは同義ではありません。

分母の標本不確実性が定量化されていない以上、32%という境界を完全な誤差評価に基づく線とは呼べません。

成立条件

- 32%は分子側の誤差だけを反映した設計上の境界であると明示する。
- 分母の不確実性が未定量であることを限界として残す。
- 分母を再登録で変更した場合は、脆弱比を再計算する。
- 分母側の不確実性を含めた誤差評価を主張するなら、別途その推定手順を事前登録する。

失敗条件

- 32%を脆弱比全体の不確実性を含む境界と説明する。
- 分母が固定値であることを、分母に不確実性がないことと読み替える。

### L3 — (b)の計算手順接続

成立

R11は、R10の手順(2)で計算される横断3位置の位置別平均を、手順(3)(4)の判定計算へ接続しないと明確にしました。

位置別平均は参考報告へ移し、判定は 点推定 = sd_96 ÷ 分母 および 誤差帯 = 点推定 × (1 ± 0.50) で行う構成です。

これは「接続したように見せる」修正ではなく、根拠のない接続を撤回して、判定に使う量と参考報告する量を分離したものです。

成立条件

- 位置別平均を誤差評価の導出に使用しない。
- 0.50は自由度2から導出されたsd₉₆の標準誤差ではなく、事前登録された設計上の誤差帯として扱う。
- 96窓を独立96標本と主張しない。

失敗条件

- 位置別平均を、実際には使用していないのにsd₉₆の推定誤差の根拠として説明する。
- 0.50を実測で裏付けられた相対標準誤差として扱う。

### L4 — 横断方向のveto

成立
