### K4 — 双線形の差し引きの廃止と縮小量の参考報告化（§6.2 V4）【CONFIRM7 の J6・J3 への回答】

R9 は、双線形補間の |∇z| 縮小量の差し引きを V4 の合否判定から外す道を選んだと主張する。
- 理由は 3 点：(1) 転用可能性の根拠が示せない。Aberle 面の面平均 |∇z| は 0.7249–1.1739 であり Hodge の 2.1987 と 2–3 倍違う。縮小量は面の勾配分布に依存する量であり、勾配の大きさが 2–3 倍違う面の間で縮小量が等しくなる根拠はない。(2) 「等価と仮定する」補正は、大原則の許容範囲（(a) 中立な数値、(b) 実在の物理に対応する量）のどちらにも当たらない調整であり、仮定で統計を戻すことは「それっぽい」補正になる。(3) 差し引きを外せば仕様は一意になる。双線形の平滑化による |∇z| の低下は、中立でない加工による実変化としてそのまま判定に現れる。
- 新しい規則：V4 の |∇z| の比較は、補間後の実測変化をそのまま窓 sd と比べて判定する（補正は一切しない）。補間候補の採用規則（片方だけ合格ならその 1 つ、両方合格なら双線形）は、この補正なしの実測変化に対して適用する（適用順序の問題は、補正を外したことで消える）。
- 縮小量は合否に使わないが参考報告として測る：使用する Aberle 面は III_Qc240・III_Qc180・III_Qc120 の 3 面すべてと事前固定し（V-H1 の劣化面と同じ 3 面）、各面に Hodge と同じ穴マスクを適用して双線形補間し、補間前後の |∇z| の差（補間後 − 補間前。符号つきで記録する）を面ごとに報告する。最近傍補間についても同じ手順で測り報告する。
- 縮小量が測れない場合でも、|∇z| の比較は留保にしない（合否は実測変化で決まる。R8 の「縮小量測定不能による留保」の経路は廃止する。K6 の経路 4）。
- 争点：差し引きを外すことで、双線形は平滑化による実変化の分だけ系統的に不利になる。採用規則が「両方合格なら双線形」を優先する設計と合わせると、双線形が落ちやすく最近傍が残りやすい構造にならないか。それは意図した設計か。V4 自身が「補間は統計を保存しないことを前提に検証する」と書く以上、実変化そのままで判定することは、補間候補の双方を不合格にしやすくする。両落ち時の分岐（(B) 不成立、例外承認は 3点セット）との関係で、この厳しさは設計として一貫しているか。参考報告の縮小量は合否に使わない。測る目的は何か（E1 の判断材料になるのか、将来の版で差し引きを復活させる布石か）。3 面の選択（III_Qc 系列のみ）は、V-H1 の劣化面と同じであることを根拠にできるか。

2. 主張ごとの判定（K1–K9＋訂正8 の各項目について「成立／条件付き成立／不成立」のいずれか 1 つ）＋理由＋通るための条件＋失敗条件。
3. 直しの優先順位（箇条書き。最も急ぐものから）。
4. 最低条件（最大 3 件。R9 を直す場合に最低限閉じるべき条件を、具体的・検証可能に書く）。

## 引用照合手続き（必須）

- R9 の本文を引用する際は、節番号（§0.2・§1.6・§3.1・§4.2.2・§5.2・§6.2 など）と、引用する文の前後の文脈を添えて引用すること。節番号のない引用はしないこと。
- R6・R7・R8 の本文を引用する際は、R9 の §0.3 訂正7・訂正8 の記録（行番号・文脈）が根拠であることを明記し、R6・R7・R8 の原文を自分で grep したとは主張しないこと（R6・R7・R8 の全文は本プロンプトの資料に含まれていない）。
- CONFIRM7 統合を引用する際は、その統合の該当箇所（最低条件 1–3、統合判定表、3席が一致した急所）を節名つきで引用すること。
- 引用できない主張（資料にない文を引用する主張）は、引用の誤りとして記録し、その主張の判定に反映すること。
- 判定は投票で決めないこと。3席の判定が割れた場合、統合では各席の理由の強さを比べる。多数決で裁定を決めないこと。
- 「V0–V-Q2 が未実行であること」自体は不成立理由にしないこと。問うのは、実行した場合に判定規則が閉じているかである。
- 設計上の選択（数値・線・規則）は測定値と区別すること。「設計上の選択である」と R9 が明記しているものは、その選択の妥当性を問うこと。測定値であると誤読しないこと。
- 回答は日本語で書くこと。数値は原文の数値をそのまま使うこと（丸め直さないこと）。

## 範囲の明記

回答の末尾に、審査の範囲を 1 行で明記すること（例：「資料1 R9 全文および資料2 CONFIRM7 統合全文に基づく。R6・R7・R8 の実ファイルは提示されていないため、訂正8 の判定は R9 の記録の十分性として行う」）。
