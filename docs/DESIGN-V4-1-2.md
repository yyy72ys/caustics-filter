## 1.1 の失敗の正しい内訳（掘り直しで判明）
1. **ゲート自体の誤り**： v1.1 の G1 は Dolcetti の全条件を混ぜた横断包絡と比べ、しかも評価した (H,U) の組は彼の実験条件に存在しない組合せだった。正本は Table II の13条件・条件別 σ。
2. **k0 の nature**： Table II の k0 は実測でなく論文 Eq.(9) の予測値。実測ピークは本文に2–3点のみ。条件1（U0=0.19 < c_min≈0.23）には定常波が存在しない。
3. **σ 過大の物理**： 実数・特異な伝達関数が原因。文献の応答は底面摩擦で正則化された複素関数（共振で位相が π/2 になる「2次系」の形）。
4. **球床の扱い**： 球床のスペクトルは格子線（247–285 rad/m）で侵入深さ ~4 mm ≪ H、水面には届かない。効くのは粗度 ks/z0 と分散で選ばれる k0。ガウス型の底スペクトル代理は格子床には使わない。
5. **分散の主役**： U0>c_min では定常波リング（|k|=k0）が分散の 81–94%。乱流成分のスケールには実測相関（L0/ks ≈ 0.045·exp(0.54·V̄/u*)、R²=0.95；L0/H ≈ 1.8–2.9）がある。

## 1.2 の設計変更
- **複素伝達関数**： T を底面摩擦で正則化した複素形にする（Saint-Venant 2022 の閉形式 |H1|/B1 = √[1 + (2Fr²−1)/(Fr⁴|det A_h|²)] の系統＋位相。実装する式と摩擦パラメータ（Chézy C または λ=kC²）の出所を明記）。砕波の傾き上限は安全弁として残す。
- **成分の再定義**： η = 底応答（複素 T × 底）＋ 定常リング（k0 のリング。振幅は分散シェア 81–94% を上限側の目安に、σ の総量と整合させる閉じ方を明記）＋ 乱流テール（k^−α、α=5–7 の帯＋Horoshenkov 型相関）。リングは「広帯域の強制が共振で拾われる」成分として、独立の自由パラメータにしない（総 σ への寄与率で閉じる）。
- **床モデルを床タイプで分ける**： 格子床（球・水路）＝粗度 ks のみで入れ、底スペクトル応答は使わない。ランダム礫床（自然）＝Nikora 系のガウス場統計（H=0.79 等）を使う。
- **乱流成分のスケール則**： L0 は L0/ks 相関から、σ_C は σ≈2.4·u*²/g（導出値・交絡あり、とラベル）を初期閉じに使う。σw の規約差（√2）に注意。
- **ゲート G1' （作り直し）**： Dolcetti Table II の13条件すべてで条件別に σ を比較（各条件の実測 σ に対して比を出し、全条件の比が 0.5–2.0 の帯に入ることを合格とする。帯の根拠： モデルの不確かさと写像仮定）。k0 は予測対予測の参考値として併記し、合否には使わない。実測ピークのある条件（13, 7, 1）では本文値との照合を参考記録する。条件1では「定常波なし」が再現されること（リング寄与ゼロ）も条件に含める。

## ラリーで攻撃させる主張（第2ラウンド、同じスレッドで）
- **D1**： 底面摩擦で正則化した複素伝達関数（共振で位相 π/2）が、実数特異 T の正しい置き換えである。
- **D2**： 水面は 底応答＋k0 リング＋乱流テールに分解でき、リングの振幅は分散シェア（81–94%）で閉じられる。
- **D3**： 条件別検証（Table II の σ、比 0.5–2.0）が正しいゲートで、k0 は合否に使わないのが正しい。
- **D4**： 格子床では底スペクトル応答を切り、粗度 ks だけで入れるのが正しい。
- **D5**： 乱流成分の閉じ（L0/ks 相関、σ_C ≈ 2.4·u*²/g）は初期実装として使える。
