# BRIEF-OMEGA-QUANT — ω 量子化の切り分け（cf-0067 §7 候補 3）

cf-0075。測定ジョブ。設計変更・本番配線・既存コード変更なし。
解析側の再計算のみ。生成器も場の周期も変えない。

## 背景（実物の記録から）

- cf-0067 §7 は、フェッチだけを変えた比較で期待と逆の結果（高さ空間で
  GF_S 0.707 → 0.422、ν 0.285 → 0.375）を記録し、原因候補を 3 つ残した。
- 候補 1（高波数尾部）は cf-0069 で決着：P5 は尾部が ν を決めていたが、
  SWELL は尾部を切っても ν が動かず、2 条件の ν の差は尾部では説明できない。
- 候補 2（窓/λc）は cf-0073 で直接棄却：窓/λc を揃えてもギャップは
  残存比 r = 1.03–1.09 でほぼ不変。
- **残る名指しの候補は候補 3（ω 量子化）だけ**である。
  patch-double §9 も「残る説明はフェッチ／別機構（スペクトル形状そのもの、
  ω 量子化、位相の引き方など）」と記録し、§10-5 は「ω 量子化は
  動かしていない。全段で 2π/8 s = 0.7854 rad/s のまま」と明記した。
  **本ジョブがその切り分けである。**

## 候補 3 の中身（cf-0067 §7 の記録）

ω は 2π/8 s = 0.785 rad/s の整数倍に量子化されている。SWELL の
卓越角周波数は 2.36 rad/s（T = 2.667 s）なので、隣のビンとの差は
**約 33%**、周期にして ±0.89 s 程度の不確かさになる。ν は量子化された
周波数モーメントから出るので、低周波側の解像度がこの刻みに制限される
（P1 は T = 1.000 s なので 12.5% で影響は小さい）。

## 目的

同じモード集合から ν を 2 通りで計算し、P5 と SWELL の ν のギャップの
うち、ω 量子化で説明できる分を測る。

- (a) 量子化 ω：生成器が使った ω_q = n·(2π/8 s)（現行の ν_mode の定義）
- (b) 真の ω：同じ k に対して分散関係 ω² = g·k·tanh(k·d)（d = 4.0 m、
  g = 9.81 m/s²）から出した ω_true。重み |H0|² と k は (a) と同一。

## 方法（cf-0067・cf-0069 と同一の条件・シード）

1. **コードを読んで ω_q の導出を確認すること。** 生成器が k から ω_q を
   どう決めているか（分散関係の真値を刻みに丸めているのか、別の規則か）
   を `v10_state`／`v10_spectrum` あたりから実物で確認し、レポートに
   定義箇所と式を記録する。推測で決めない。分散関係の形（深さの扱い、
   g の値）もコードの実物に合わせる。
2. **条件・シード。** P5-CLEAR（U=6、F=100、深さ 4.0）と SWELL-1
   （U=6、F=10000、深さ 4.0）。シードは cf-0067 と同じ 5 本
   （seed 1 は本番シード `3255045276382562994`）。k_cut は既定 1000 rad/m
   のまま、パッチは既定のまま（P5 4.8 m／SWELL 76.8 m）。
3. **ν_mode を 2 通りで出す。** 同じ実現モード集合（|H0|²、k）に対し、
   モーメント m0/m1/m2 を (a) ω_q と (b) ω_true でそれぞれ計算し、
   ν = √(m0·m2/m1² − 1) を出す。推定量の定義は cf-0067 から動かさない。
   帯域分解（cf-0069 §8.1 と同じ k 帯）も (a)(b) 両方で出し、どの帯が
   量子化で動くかを記録する。
4. **プローブ ν は分離できないことを明記する。** プローブ記録は 8 s 周期の
   場そのものなので、その時間系列の ω 内容は本質的に量子化されている。
   本ジョブの切り分けはモード集合の ν_mode で行い、プローブ ν については
   「場を作り直さない限り分離できない」と記録する。ただし参考として、
   プローブ記録のスペクトルを ω_true の格子へ補間し直した ν の値も
   出してよい（その場合は補間の方法と限界を明記する）。
5. **同一性ゲート（測る前）。** (a) の ν_mode が cf-0067 の保存値と
   差 0.00 で一致すること（P5 0.3333／SWELL 0.3951、seed 1 の値）。
   一致しなければ測定を進めず、モード集合の取り出し方を切り分ける。
6. **判定の見方（事前に固定する）。**
   - ギャップ（SWELL − P5）の量子化版を gap_q、真値版を gap_true とする。
   - 説明できる分 = (gap_q − gap_true) / gap_q。
   - |gap_true| ≤ 0.5·|gap_q| → **量子化がギャップの主因**
   - |gap_true| ≥ 0.8·|gap_q| → **量子化は主因でない**
   - その間 → 決着をつけない。
   - しきい値は上の 0.5／0.8 を使うが、実測の値がしきい値から遠ければ
     その旨を明記する（cf-0069 §6.2、cf-0073 §9 と同じ扱い）。
