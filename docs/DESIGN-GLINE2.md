# DESIGN-GLINE2 — 判別ゲート G-LINE2 の設計と検証（提案）

**状態： 提案（PROPOSAL）。ゲートの新設は本人の判断事項であり、本書は測定と定義案まで。**
起源： 2026-11-13 知見循環の持ち帰り（`~/workspace/global-exchange/bringback/caustics/2026-11-13.md`）の代理指標パターン（測れない欠陥は測れる物理量の代理で落とす／代理の限界を明記する／合成で測らず分離して測る／0 と欠測を分ける）。
測定実装： `tools-gline2/measure_gline2.py`（本書の数値はすべてこのスクリプトの実測、2026-11-13）。

## 1. 何を判別するか

既存の G-LINE（`depth_e3`、軸平行 5–15 px 帯の変調深さ）は帯の**量**しか測らない。量が多い理由が

- (a) 計算グリッドに anchored した**固定周期の格子**（人工物。落とすべき欠陥）なのか、
- (b) 本物の**微細なコースティクスの網**（物理。量の過多は G-LINE の問題だが格子ではない）なのか

を区別できない。v4-1.8 の残差（66.2 vs 写真 63.7）がまさにこの壁で、REPORT-V4-1-8 §4.1 は場当たり的な診断（窓ごとの period と 1 次元 prom の比較）で格子説を退けたが、ゲートにはなっていなかった。

G-LINE2 は別の問いを測る： **「帯のパワーが、窓が変わっても同じ位置に立つ単一の固定周期ピークに集中しているか」**。格子なら集中する（グリッドは画面全体で同一だから）。網ならパワーは多数のビンに散り、ピークの位置は窓ごとにさまよう。

G-LINE の置き換えではない。併用する（§5 の読み表）。

## 2. 測定法

土台は既存 G-LINE 測定と**逐語同一**（run_v4_1_5.py 由来、run_v4_1_8.py の複製と同一であることを照合済み）：

- 緑チャンネル、float64、8 bit スケール
- ハイパス： 全画像に `g − gaussian_filter(g, σ=3.0, reflect)`
- 窓： 256×256。位置は元写真のタイルグリッド（stride 92×90、全 24 窓）で固定し、全画像に同じ原点を当てる。指定窓は同グリッドの最小 std タイル = `smooth` (460, 0)、最大 std タイル = `bark` (368, 270)
- Hann 窓、平均除去、2D FFT、パワー `P = |F|²`
- 帯： 周期 5–15 px ＝ 半径 `r = √(kx²+ky²)` が [256/15, 256/5] = [17.07, 51.2] ビンの環

**複製の検証**： スクリプトが複製した既存 1 次元行（depth_e3 / period / prom）は、納品済み numbers-v4-1-5/1-7/1-8.json の値と最大相対偏差 **7.7e-16**（機械精度）で一致した。以下の新統計はこの土台の上にある。

新しい統計量（窓ごと）：

| 名前 | 定義 | 意味 |
|---|---|---|
| `prom2d` | 環内の最大パワー / 環内の中央値パワー | 単一ピークの突出度（主統計） |
| `prom2d_axis` | 軸近傍ビン（\|kx\|≤2 または \|ky\|≤2）に限った最大 / 同じ中央値 | 軸平行の線に限った突出度 |
| `peak_share` | 最大パワー / 環の総パワー | 1 ビンへの集中度 |
| `top4_share` | 上位 4 ビンの合計 / 環の総パワー | 共役対＋漏れを含めた集中度 |
| ピークビン | (kx, ky)（共役を折畳み）、周期 = 256/r [px]、`axis_off = min(|kx|,|ky|)` | ピークの位置と向き |

24 窓の集計：

| 名前 | 定義 |
|---|---|
| `prom2d` 中央値 / 最大 | 窓ごとの prom2d の中央値（ゲートの主値）と最大 |
| `modal_frac` | ピークビンの最頻クラスタ（最頻ビンから Chebyshev 距離 ≤1）に属する窓の割合。「固定」の検査 |
| `axis_frac` | ピークが軸近傍（axis_off ≤ 2）の窓の割合 |
| 周期の中央値 / IQR | 窓ごとのピーク周期の散らばり |

帯にパワーが無い窓は **0 ではなく欠測（missing）** として記録する（「格子なし」と「測れていない」は別の結果）。

## 4. 分離するか — する（観測範囲では）

- **prom2d 中央値に約 5 倍のギャップがある**： 写真型（写真 21.1、1.5 = 21.5、1.8 = 25.4）対 格子型（1.4 = 105.6、1.7 = 116.2）。期待された順序（写真 ≈ 1.8 が低く、1.7 が高い）と一致する。
- **1.7 の網は「自然な網」ではなく格子型と出た**。根拠と整合する： 1.7 の折り返しは輸送グリッドのセルに anchored しており、指定 2 窓ともピークが kx=28（周期 9.14 px）に立ち、全窓で axis_frac = 1.00。つまり 1.7 の帯過多は「物理の網の量」ではなく「計算グリッド由来の周期構造」で、本判別器はそれを正しく人工物側に分類する。
- **1.5 は実フレームで写真型**（prom2d 中央値 21.5、modal 0.125）。帯域制限は固定周期性を実際に壊していた — 1.5 の失敗は格子ではなくコントラスト喪失だった、という従来の切り分けと一致する。
- **1.8 は写真型**（25.4、写真比 1.21×）。§4.1 の「残差は堆積の格子ではなく C の柄」という診断を、独立した統計で裏付ける。傍証： 1.8 の smooth 窓のピーク (18, −15) は写真の (17, −15) とほぼ同じ斜めビン — 同じテクスチャ族（地の写真の柄）がピークを作っている。
- **modal_frac も同方向**： 格子型 0.292（24 窓中 7 窓が同じビン近傍）対 写真型 0.125（偶然の床に近い）。ただし分離幅は prom2d より小さい。単独ではなく副条件として使う。
- **peak_share も同方向**（0.0048–0.0050 対 0.0017–0.0020、約 2.7 倍）。prom2d の裏付け用。

分離しない／注意が要る点：

- **1.8 の axis_frac = 0.33 は写真（0.04）より明確に高い**。軸寄りの弱いピークは残っている（§4.1 の言うフレーミングの画素ピッチ差＋軸平行な折り成分）。ただしそのピークは突出も固定もしていない。**axis_frac 単独でゲートを組んではいけない** — 組むと 1.8 を誤って落とす。
- **写真自身の単窓最大 prom2d = 104**（格子型並み）。最大値でゲートを組むと写真が落ちる。必ず窓の中央値で見る。

## 5. ゲート定義（案）

- **測るもの**： 合成フレーム frame 24（将来ランでは C レーンにも同じ窓・同じ統計を当てる。§6 の留保つき）。
- **主統計**： 24 窓の prom2d 中央値 `P2`。参照 `P2_photo` は同じラン・同じコードで写真から測る（固定値を持ち回らない）。
- **合格条件（主）**： `P2 ≤ 2.0 × P2_photo`。
  - 較正の根拠（今回の実測）： クリーン側の最大は 1.8 の 1.21×、格子側の最小は 1.4 の 5.01×。2.0× は観測ギャップ [1.21, 5.01] の中にある。導出値ではなく配置値であり、初回実運用後に見直す（§6）。
- **合格条件（副）**： `modal_frac ≤ 0.20`（クリーン側 0.125、格子側 0.292）。
  - 主・副の両方を満たして G-LINE2 合格。
- **欠測の扱い**： 帯パワーゼロの窓は欠測として数える。欠測が 24 窓中 7 窓を超えたらゲート結果は「未測定」であって合格ではない。
- **G-LINE との併用（読み表）**：

| G-LINE（帯の量） | G-LINE2（固定周期か） | 読み |
|---|---|---|
| 合格 | 合格 | 問題なし |
| 不合格 | 合格 | 格子ではない。帯の量が多い＝場（物理）側の話。堆積法の欠陥ではない（1.8 の残差がここ） |
| 不合格 | 不合格 | 計算由来の周期人工物（1.4、1.7 がここ）。方法を直す対象 |
| 合格 | 不合格 | 量は少ないが周期構造がある。薄い格子の疑いとして報告する（未観測の組合せ） |

## 6. 限界（代理指標の作法として、本ゲートはこの限界とセットで運用する）

1. **測っているのは「固定周期の格子らしさ」の代理であって、格子そのものではない。** 本指標が検出できるのは、今回の失敗系（グリッド anchored・軸平行・単一周期・全窓で同一ビン）に限る。
2. **周期が窓ごとにずれる格子、複数周期の重なり、斜めの格子**はピークが割れて prom2d が下がる — すり抜けうる。modal_frac も同様。
3. **1.5 の視覚判定との緊張を記録しておく**： 納品当時、本人の目には「格子がまだある」と映ったが、本指標（と depth）では 1.5 は写真水準だった。本指標が測れるのは「1 ビンに立つ周期」だけであり、拡散した弱い規則性は届かない。**本指標は目の判定を上書きしない**（最終の美的判定は常に従来どおり本人）。
4. **参照母集団は「この写真」**。写真が変われば参照も変わる。強い準周期テクスチャ（織物、砂紋、鱗状の樹皮など）が大きく写る写真では、自然物でも prom2d が上がりうる — その場合は写真側の分布自体が跳ねるので、比ではなく絶対値と分布の形も併せて見ること。
5. **frame 24 の 1 枚だけ**が検証範囲。時間方向（フレーム間でのみ現れる周期性）は対象外。
6. **較正は n=5 画像・写真 1 枚**。閾値 2.0× / 0.20 は観測ギャップへの配置であり、統計的な導出ではない。v4-1.9 での初回実運用の結果で見直すこと。
7. **C レーンは未検証**。prom2d は正規化不要の比なので C 配列（平均 1 の浮動小数）にそのまま定義できるが、閾値 2.0× は合成フレームでの較正値であり、C レーンに流用する前に C での写真相当の参照（または既知ケース）で再較正が要る。本書の検証は合成のみ。
8. **測定の約束への依存**： prom2d の値は HP σ=3.0・Hann・256² 窓・帯 5–15 px という既存 G-LINE の約束の上での数値。約束を変えたら写真の参照から測り直す。
