# 前提（この設計の要点。本文はこの1通で自己完結する）

対象は、物理ベースの水面コースティクス・レンダラの「第4段＝カメラ側」の設計。パイプラインは水面状態と床面の放射輝度場を受け取り、第4段がカメラ結像を担う。構成は v4-4.1 カメラ幾何と瞳／v4-4.2 見かけ距離場 D_app と有効範囲／v4-4.3 ぼけ PSF（幾何円＋Airy、瞳積分）／v4-4.4 時間積分・シャッター・焦点軌跡／v4-4.5 センサー記録（線形 HDR、クリップは後段）。大原則は「自然を再現する。それっぽいでは駄目」で、数値の調整は中立な数値誤差か実在の物理に対応する場合だけ許される。

決定済み事項 Q1：レガシー合成の E=2.2／A=2.6 は「出自明記のレガシーグレード」としてカメラの外に残す。ただし物理に反するなら反映させない。再判定はしない（記録の正確さと混入の有無だけが監査対象）。

第1回の確認ラリーでは三席一致で NOT CONFIRMED。要求は項目1〜6（下記）と新矛盾 X1〜X5 の解消だった。以下はその改訂第2弾（R2）の判定依頼である。

---

あなたは第4段（カメラ側／レンズ層）設計の敵対的レビュアー。第1回の確認ラリーで三席一致 NOT CONFIRMED だった設計の改訂第2弾（R2）を判定し、さらに「もっと良くなるか」を先行研究・確立した実務の観点から攻撃してほしい。

## 第1回で要求されたこと（要約）

項目1 瞳パラメータ表＋PRESETS 再現誤差＋15:11↔2048² 変換規則／項目2 有効範囲の数値＋較正の s_app 統一／項目3 入力契約の選択＋PSF 許容差＋参照レンズ級＋受入テスト／項目4 シャッター数値仕様／項目5 体制地図の実計算／項目6 記録の正確さ。新矛盾 X1 回折の二重計上／X2 ピンホール極限／X3 接続点の二重定義／X4 グリッター分離／X5 時間変数の未統合。判定は全項目 PARTIAL（Grok のみ一部 FIXED）。

## R2 で入れたもの（実在する条文・数値）

- N1：標準カメラ＝フルフレーム 36 mm、ピッチ 17.58 µm、取り出しは中央クロップ 2048×1503・リサイズなし。正準カメラ高 h_a = 1.0 m。焦点距離の逆算：メイン 38.11／サブ 37.22／対比 23.65 mm。床面窓式の一般形 W_bed(s_f) = W_s·s_bed(s_f−f)/(f·s_f)。瞳＝薄レンズ面の円形瞳、径 f/N、サンプリングは K×K 格子で PSF が許容差内で収束するまで倍増（初期 K=3、使用 K は記録）。
- 50 mm 版を併記（本人の指定）：同窓版 h_a = 1.4993／2.7167／2.7833 m、同高版は窓 1.1160 m（深さ 0.6 m）／3.5640 m（サブ）。50 mm 版の体制の実計算は実施中（本プロンプト時点では未着地）。
- N2：θ_max = 31.8°（非点収差の割れ 10% 点＝31.82°、深さによらず同一、Coddington 式と 3e-7 まで一致して検証済み）。κ_max = 53 /m（メイン条件の実測 |κ1| p99、曲率半径 18.9 mm。サブ条件は未測定のため暫定と明記）。対比枠は半画角 37.3° で画面端の割れ 13.6% → 周辺部は有効範囲外と明記。較正は s_app = h_a + d_w/n に統一。
- N3：入力契約は「2D 近似の宣言＋誤差の実測」を v1 契約に決定（瞳サブレイ再トレースは v2 の経路）。PSF 許容差：ぼけ径 max(0.5 px, 5%)、Airy 径 5%、平坦部の総光量保存 1e-3。参照レンズ級＝理想薄レンズ（収差なし）。受入テスト群6件（波面ケース・遮蔽境界・グリッター対床・空間変動 PSF・高次光線追跡との照合・非平坦 gather のエネルギー非保存）を必須化。
- N4：t_shutter 既定＝1/48 s（24 fps の 180° 相当）。時間積分は M サブサンプル、M は収束まで倍増（初期 4）。評価順序は（水面状態→光輸送→焦点位置 s_f→PSF→センサー光量の蓄積）で固定。周期境界条件は位置と速度の C1 連続。
- N5：体制地図を実計算（検証アンカー：f=35 mm・N=2.8・水面合焦→床ぼけ 0.1407 mm = 8.01 px を再現）。メイン・サブは全 N で体制 B（実効ぼけの最小 2.87／4.29 px、体制 A は到達不可）、対比のみ A 区間 N∈[5.2, 25.1]、回折支配 D は対比 N=16 のみ。
- N6：放射輝度場は2成分で受け渡す（床成分は D_app、グリッター成分は D_glit = h_a + 1/(2κ_n) の鏡像式）。PSF は成分ごとに掛けてから合成。
- X1 は分離案 A（回折は光学 PSF のみに置き、記録 MTF に含めない）、X2 は幾何／波動のピンホール極限を分離、X3 は線形 HDR・クリップ前で一本化、X5 は t_shutter と露光区間を入力に追加。Q1 は再判定しない（第3分岐は決定済み。記録の正確さと E/A 混入だけが監査対象）。

## 判定してほしいこと（形式固定）

1. 項目1〜6 それぞれ：FIXED / PARTIAL / UNRESOLVED と、根拠を1〜2行。
2. X1〜X5 それぞれ：解消したか否かと根拠。
3. 総合：CONFIRMED / NOT CONFIRMED。
4. 記録監査：数値・決定の引用に誤りや E/A 混入があれば指摘。

## 改善質問（今回の追加・形式固定）
