- **C7 — 体制地図の必須性は確定、代表計算は作り直し**。地図なしでは

  異方性を測ってから言うこと（GPT）。「ほぼ真上」「代表値」の定義も

## 一致した攻撃（主張を横断する収束点）

1. **瞳（pupil）の光線束が設計のどこにもない**（4席全員）。画素あたり

   形状まで含めて v4-4.1↔v4-4.3 のインターフェースに書くこと。
2. **シャッターの時間積分が抜けている**（4席全員）。シャッター時間は
   明るさの倍率ではなく、動く水面・網目・グリッター・移動する焦点の
   時間積分。8秒ループの継ぎ目条件も含む。
3. **偏光**（4席全員が言及）。水面の Fresnel は偏光依存で、グリッター対
   床のコントラスト比に効く。輸送側か第4段か、置き場の決定が要る
   （v1 で外すなら外すと宣言し、4.6 のレンズ固有項目に押し込まない — GPT）。
4. **検証が平坦水面＋解析解に偏っている**（4席全員）。実レンズ PSF または
   高次光線追跡との照合（Grok／GPT）、波面ケース、遮蔽境界、グリッター対
   床、空間変動 PSF、放射量較正まで含む受入テスト群が要る（GPT の V1–V15、
   dsh の受入スイート提案を統合して設計に取り込む）。
5. **HDR の線形順序・飽和・ノイズ**（GPT／Gemini／dsh）。PSF 畳み込みは
   線形 HDR の上で、クリップ・量子化より前に行う。凍結合成がすでに
   クリップ済みなら物理 PSF は掛けられない（Q1 の判別証拠でもある）。
   フルウェル・ショットノイズ・読み出しノイズの置き場は v4-4.5。
6. **順序の反転問題**（Gemini、GPT も同旨）。有限カメラの視線場は輸送の
   結果を変える（Snell の角度・Fresnel・水中路長）。v4-4.1 を輸送の後段に
   置く現在の並びは、直交・正射の輸送結果を後から直せない。視線場は
   輸送の前段で決めるか、多光線のライトフィールドとして扱うこと。
7. **プリセット整合性**（Grok／Gemini／GPT）。PRESETS はカメラパラメータ
   への「逆算可能性」だけでなく、等価パラメータで**同じ数値画像が再現
   されること**までを硬い検査にする。アスペクト比（15:11 の窓 vs 2048² の
   正方形）の扱いも未定のまま（Gemini）。

## Q1 判断材料（決定は本人 — ここでは判断しない）

### 全席収束の前提整理

- **E と A は同種の量ではない**（GPT／Gemini／dsh の3席が独立に同じ結論、
  Grok も「両方とも見た目の定数」とした）。E=2.2 は直接項だけに掛かり、
  A=2.6 は環境項だけに掛かる。実在のカメラ露出（シャッター×開口面積×
  ゲイン×量子効率）は入射した全光子への単一スケールであり、光の出所で
  倍率を変えることはできない。
- したがって記録モデルが引き受けられるのは**全体への1スケールだけ**。
  **比 A/E ≈ 1.18 は、太陽光と空の光のバランスを変える量であり、環境・
  光輸送側の量**（Gemini の定式：I = E·(L_direct + (A/E)·L_ambient) と
  書けば分離が見える）。この比をカメラ側に置く分岐は、どちらの分岐でも
  そのままでは物理として成立しない。
- dsh の追加の疑い：A は第2・3段の輸送不足（水中多重散乱・空・床 BRDF の
  欠けたエネルギー）の補填、E は見た目の「効き」を作るグレード、という
  出自の可能性。つまり両者はカメラの問題である前に、**出自の監査**が要る。

### 分岐1 REINTERPRET（数値を保ち、カメラの露出結果として読み直す）への攻撃

- 直接項だけに掛かるゲインを露出と呼ぶのは物理として不可能（全席）。
- 露出の物理（N や シャッターを振ると明るさが連動する）を塞ぐ：数値を
  固定する限り、絞りを振っても明るさが変わらない非物理なカメラになる
  （Gemini／Grok）。
- 凍結合成がクリップ済みなら、その後の PSF は線形 HDR でなくクリップ済み
  値への畳み込みになり、ハイライトの滲みが壊れる（Gemini）。
- 下流の PJ9 が絶対輝度（cd/m²）を失い、順応・CSF の物理量が入らない
  （Gemini／GPT）。

### 分岐2 REPLACE（定数を退役させ、物理露出で置換する）への攻撃

- 入力の放射輝度が物理単位で較正されていなければ、物理露出式に入れても
  出てくる明るさは任意（黒かクリップ）（Gemini／GPT／dsh）。
- A を消すと直接／環境の比が 2.2/2.6 → 1.0 に変わり、影の深さと場面の
  コントラストそのものが変わる。比の置き場（環境側の照度比として再定義）
  を同時に行わない置換は、記録モデルの導入と照明の再定義を混ぜる（GPT）。
- 全プリセット・凍結合成・ループの見た目の基準が失われ、再検証が全面に
  及ぶ（Grok／dsh）。dsh：2つの既知の誤魔化しを、5つの未知の物理入力
  （太陽・空の絶対照度、水の透過、センサー飽和電子数、トーン曲線）で
  置き換えることになり、不確かさは減るのでなく増える、との指摘。

### 第三の分岐（Grok と dsh が独立に提示 — 設計に無かった形）

**E/A をカメラの外に置く。** E/A は「出自を明記したレガシーグレード」
（見た目の定数であり物理ではない）として凍結合成側に残し、第4段の記録
モデルはそれとは独立に物理のまま作る（dsh の形：記録側は正規化した相対
単位＋自前の較正済みゲイン列で回し、A の再導出は輸送側の閉合項目として
別に持つ。Grok の形：RAW が形成された後に掛かるグレードノードとして
明示する）。長所：凍結した見た目と検証基準を壊さず、記録モデルも物理の
ままにできる。短所（攻撃側の留保）：グレードが恒久化し、絶対放射量の
閉合を先送りする構造になる（dsh 自身が「判別証拠なしの先送りは不可」と
条件を付けている）。

### 判別証拠（どの分岐でも、判断の前に取れる実測）

1. **単位監査**：凍結合成の E/A 適用前の L_direct／L_ambient の生値と
   単位を確認し、地表の晴天の太陽／空の照度比（約4:1–8:1）と比べる。
   輸送が既に物理単位なら E/A は見た目の上乗せ、無次元の正規化値なら
   A/E は欠けた環境バランスの代用、E は欠けた放射ゲインの代用（Gemini）。
2. **HDR クリップ確認**：凍結合成の出力がコースティクスの尖端と
   グリッターで 1.0 超の線形値を保持しているか。クリップ済みなら
   分岐1 は即座に失格（物理 PSF を掛けられない）（Gemini）。
3. **絞り掃引**：シャッター・ISO 固定で f/2.8→f/8 と振り、明るさが
   1/N² で直接項・環境項に**一様に**掛かるか。項ごとに違う応答なら
   定数は露出ではない（Gemini／Grok の 1段テスト）。
4. **グレーウェッジ線形性＋絶対照度閉合**：較正済み拡散ウェッジと平坦
   水面の解析ケースで、直接項と環境項の傾きが共通か（dsh）。置換分岐を
   取るなら、全体スケールの再フィットなしに絶対照度から生の数値を
   予測できることが条件（dsh／GPT）。

### 本人への提示形

判断は次の3択（＋現状維持の明示）として提示するのが統合側の推奨：
(1) REINTERPRET（ただし A/E 比は環境側へ切り分けた上で）、
(2) REPLACE（比の再定義と絶対較正を同時に）、
(3) 第三分岐（E/A は出自明記のグレードとしてカメラ外に残し、記録モデルは
物理で新設）。いずれを選ぶ前でも、判別証拠 1・2 は安価に取れる。
