K3 — プローブνの測定条件は比較可能な形で固定されているか
条件付き成立

記録長を32秒以上にする算術は正しい。しかし、32秒という条件だけでは、場のνを偏りなく比較できることは保証されない。

設計案§4.3の条件は、Δω = 2π/T_obs ≤ Ω0/4 であり、Ω0=0.7854 なので、T_obs ≥ 2π/(0.7854/4) ≈ 32.0 s となる。この算術は成立している。

問題は、その分解能条件が今回の低n帯の誤差を分離するのに十分だという根拠がないことだ。SWELLでは 0.5–1.0 rad/m 帯が m0 の62.4%を占め、n=4級のモードが効いている。32秒の窓でその帯の周波数成分をどこまで分離できるかは、合成信号などを用いた推定誤差の検証が必要である。

また、§4.3の「同じ記録長」と T_obs >= 32s の関係も確定していない。cf-0067の保存npzが32秒未満なら、量子化側の再測も同じ新仕様にする必要がある。§8のR1にはこの分岐が書かれているが、どちらの仕様で比較するかは未決である。

より重要なのは、窓関数を両腕で同一にしても、スペクトル漏れのバイアスが同一になるわけではない点だ。

量子化側のωはΩ0の整数倍であり、8秒周期の場として閉じる。

非量子化側のωは一般に8秒周期で閉じない。

そのため、同じ矩形窓や同じ窓関数を適用しても、有限窓による漏れの影響は両者で異なる。

これは単なる実装差ではなく、比較する測定量そのものに非対称な誤差が入る問題である。窓を同じにするだけでは「共通の既知の限界」にはならない。

折り返しの扱いも不十分だ。75.4 rad/s は24 fpsのナイキスト上限として整合するが、帯外の |H0|² シェア約0.1%はP5についての値である。SWELL側のシェアや、折り返した成分がギャップへ与える影響は示されていない。したがって、§4.3の「両腕で共通の既知の限界」という表現は強すぎる。

直しの種類：一部は記載追加、一部は設計の再考。

記録長・サンプリング周波数・窓関数・推定量・比較対象を段2開始前に固定するのは記載で直せる。しかし、窓漏れの非対称性と折り返しの影響は、仕様を文章で固定するだけでは解消しない。合成信号などで推定バイアスの上限を評価し、今回の予測差と比較できる水準に収まることを確認する必要がある。

結末B

決着なし
