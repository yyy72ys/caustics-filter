## 2. 順序の裁定

採用する骨格は **GPT の再編案15順序**（U3 → 共通分散土台 → U1 → U2a → U8a → U4 → U5 → U6 → U12 → U13 → U14 → U8b-a 診断 → U2b → U8b-b 最終受入 → U9）。Gemini・Grok の順序指摘はこの骨格に折り込む：
