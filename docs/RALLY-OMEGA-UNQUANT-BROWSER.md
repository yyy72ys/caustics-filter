#### K2 — 判定基準は事前に閉じているか（R_field の閾値 0.80／0.50 と予測帯 [0.0423, 0.0705]）

設計案は次の通り主張する（§1.3、31–43 行目）: 主判定量は R_mode（モード集合の残存比、分母 0.0680）と R_field（プローブ ν の残存比、分母 0.0906）である。結末 A「紙の結論が場で確認される」は R_field ≥ 0.80 かつ gap_probe（非量子化場）が予測帯 [0.0423, 0.0705] の中にあること。予測帯は 0.0564 ± 25%（cf-0077 の前例）で作り、0.0505 を含む。結末 B「量子化が場では残りを説明する」は R_field ≤ 0.50（gap_probe で 0.0453 以下）。中間（0.50 < R_field < 0.80）または帯の外は決着をつけない。判定は5シード平均で行い、シード単独の判定は禁止する。

争点:
(i) **結末 A の同時成立可能性（プロンプト作成側の検算。必ず自ら検算すること）**: R_field ≥ 0.80 は、分母 0.0906 に対して gap_probe ≥ 0.0906 × 0.80 = 0.0725 を意味する。しかし予測帯の上限は 0.0705 であり、0.0725 > 0.0705 である。すなわち結末 A の2条件は同時に満たし得ず、A は空集合ではないか。さらに、場が紙の比率どおり（残存比 0.829）に振る舞った場合の gap_probe は 0.0906 × 0.829 = 0.0751 で、帯の外（上限超）になる。設計案が「紙の結論が場で確認される」場合に予測する値そのものが自らの A の帯に入らないとすれば、判定基準は測定前に閉じているどころか、最もありうる結果を「決着なし」へ倒す構造になっていないか。
(ii) 尺度の取り違え: 予測帯 [0.0423, 0.0705] はモード集合のギャップ（0.0564、量子化側 0.0680）から作られている。一方 gap_probe の量子化側の値は 0.0906 で、モードのギャップとは尺度が違う（プローブ ν はモード ν と系統的にずれる量であり、cf-0075 §7 の貼り替え参考値でもギャップは 0.0747 でモードの 0.0564 とは一致しない）。モード尺度の帯をプローブ量の判定にそのまま使うことは正当か。正当でないなら、帯はプローブ尺度で作り直すべきではないか（例: 貼り替え参考値 0.0747 を中心とする帯）。
(iii) 閾値 0.80／0.50 の出自と場への転用: この2値は cf-0075 §5 が紙の再計算に対して事前固定した分岐（|gap_true| ≤ 0.5·|gap_q| → 主因、≥ 0.8·|gap_q| → 主因でない）の流用である。場の測定には紙にない分散要因（有限窓の漏れ、折り返し、プローブ推定のばらつき）が加わる。同じ閾値を場の量へ無調整で転用する根拠は本文にあるか。25% という帯の幅も cf-0077 の前例の引用のみで、本実験のばらつきからの導出ではない。この2点は「事前に固定した」ことと「妥当な値である」ことは別である、という批判に耐えるか。

### 結論（§0、§5）

同じ実現モード集合（同じ k、同じ |H0|²）から ν を2通りで出した。ν_q（量子化 ω）は P5-CLEAR 0.3272／SWELL-1 0.3952、ギャップ 0.0680。ν_true（分散関係の真値、コードの式＝重力＋毛管）は P5 0.3254／SWELL 0.3817、ギャップ 0.0564。量子化で説明できる分は 17.1%、残存比は 0.829。事前固定の判定は「量子化はギャップの主因でない」。ただし残存比 0.829 は 0.8 の線から 0.029 しか離れておらず、シード別では残存比 0.763–0.888（5本中2本が 0.8 未満）と線をまたぐ。主張の中心は分岐名ではなく「説明率 17%」という数値そのものである（§5、§5.1）。

### 参考列（§0、§5）

真の ω を重力のみの式（g·k·tanh(k·h)）で取ると、ν は P5 0.2670／SWELL 0.3766、ギャップ 0.1096、説明率 −61.2% になる。毛管項は k = 300 rad/m で毛管/重力比 0.668、k = 1000 rad/m で 7.421 に達する（§2 の表）。

### 帯域の機構（§6）

量子化の刻みは ω に比例しない固定刻みのため、誤差は低い n の帯に集中する。P5 は m0 の 87.8% が 10–30 rad/m 帯（n ≈ 19）にあり量子化誤差が小さく、ν はほとんど動かない（ν_q − ν_true = +0.0019、5シード平均）。SWELL は 0.5–1.0 rad/m 帯が m0 の 62.4% を占め（n = 4 級、刻みが ω の 12.5% 相当）、ν が 3.54% 高く見える（差 +0.0135）。n ≤ 6 の m0 シェアは P5 で 1.25e-14%、SWELL で 94.7%。白色雑音モデル（丸め誤差を独立一様雑音とみなす予測）は実測の 1.9–3.8 分の 1 で足りず、効いているのはビンごとの系統的な偏りの差である（§6.3）。

### プローブ ν（§7、参考値）

プローブ記録は 8 s 周期の場そのものであり、場を作り直さない限りプローブ ν から量子化を外すことはできない。cf-0067 の保存 npz の生の ν は P5 0.2848／SWELL 0.3755（ギャップ 0.0906）で記録値と一致。各時間ビンをモードの |H0|² 重み付き平均 ω_true に貼り替えた参考値では P5 0.2839／SWELL 0.3586、ギャップ 0.0747、説明率 17.5%。これは再測定ではない。

### 限界（§8）

生成器は動かしていない。ν_true は「そのモード集合を連続 ω で積分した値」であって実現する場の ν ではない。毛管項の扱いで結論の数値は動く。判定は 0.8 の線に近い。帯域分解は seed 1 の1状態。曲率は測っていない。k_cut・パッチ・場の周期は既定のまま。
