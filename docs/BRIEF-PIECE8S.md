# BRIEF — 本編8秒・土台レンダー（Blender、蛾2匹、ループ継ぎ目つき）

土台： proto5（PC `blender-moth-proto5` の build_moth.py v5）。仕様： 832×480、24fps、**192フレーム＝8.000秒**、Eevee 64 samples、モーションブラー、カメラ完全固定、背景プレート不変。作業コピーは PC `blender-piece8s`。モデルは deepseek-v4.1-flash 固定。この段階は土台のみ（水のコースティクス合成は別工程）。

## タイムライン（24fps、f0 がループ継ぎ目）
- **f0–f55 静止**： 2匹とも止まる。proto5 の静止生活を継続（右蛾の Xanthotype 型部分挙上イベントと両触角スイープをこの区間に配置、左蛾にも小さな触角イベント1回まで可）。
- **左蛾の離陸**： 実測構造（翅先行→地上挙上が離陸前区間の約79%→短い保持＋前傾→ダウンドストロークと同時に離陸）は proto4/5 で確定済み。そのまま使い、**離陸（脚が離れる）≈f72、画面外への完全退出 ≈f84**（離陸から約0.5秒 — ユーザー判定「速い退出が自然」）。挙上開始は離陸タイミングから逆算して配置する。
- **f84–f139 右蛾のみ**： 静止生活を継続。相手の不在への反応は作らない（データなし — 意図的省略を RESULT に明記）。
- **左蛾の帰還**： f140 頃に退出した方向（左上）から入場し、減速しながら元の止まり位置へ。**着地 ≈f168**。着地の振付は実測データがないため設計（発明）と RESULT に明記する — ただし不自然な急停止にせず、翅のブレーキと小さな沈み込みで受ける。
- **f168–f191 セトル**： 翅が静止姿勢へ下がり切り、**f191 の姿勢パラメータが f0 と完全一致**する（ループ継ぎ目）。右蛾も f191 までに静止姿勢へ戻り切っていること。

## 飛行の規則
- 羽ばたき 8.0 Hz（proto5 の転移値）、シード固定の不規則係数（proto5 の流儀を踏襲）、前後翅は位相ロック、飛行中は腹部が見えてよい（離陸時の規則どおり）。
- 退出・帰還の軌道は滑らかに（キーフレームの補間でジャンプを作らない）。

## 継ぎ目の検証（必須・数値で）
1. アニメーションデータ上で、両蛾の全姿勢パラメータが f191＝f0 と一致（キー値の直接比較）。
2. f0 と f191 のレンダー差分： 蛾の領域外は従来基準（平均差 ≤0.002、Eevee TAA の非決定性として記録）、蛾の領域内も姿勢一致の範囲であることを差分統計で示す。
