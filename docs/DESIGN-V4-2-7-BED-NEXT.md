## 1. (A) ゲートの形の見直し — 局所指数の下限から参照プロファイルとの比較へ

### 1.1 旧ゲートが何を測っていたか

旧 STAGE 1 ゲートは「帯内すべてのラグで局所指数 H_loc(ℓ) ≥ 0.70」という**一点下限**だった。
2.6 §4.3 の物差し上限検査が示したのは、この形が二重に間違っていることである。

- 第一に、**理想場すら通らない**。H_gen=0.79 の自己アフィン場は 0.6 m 箱で帯内局所指数が
  0.74 → 0.62 へすべる（4 seed 平均のプロファイル 0.74 0.73 0.71 0.69 0.66 0.62）。
  有限箱のバイアスが帯の上端で局所指数を約 0.1 食う。ゲートは「H≈0.79 の場」を
  判定する物差しになっていない。
- 第二に、**通る場は間違っている**。平均で 0.70 に届くのは H_gen ≥ 0.92。
  旧ゲートを通るのは「ほぼ滑らかな面」であって、水流作用床ではない。
  しかも 0.92 級の場は H_fit 0.781 と STAGE 3 の H_fit 帯（0.70–0.85）にも入るため、
  旧ゲート＋H_fit 帯の組合せは「滑らかすぎる床」を合格させる側に偏っている。
  一方で粒床（H ≈ 0.3）は当然落ちる。つまり旧ゲートは**両端を間違える**：
  本物を落とし、偽物を通す。

**A1 — 旧ゲート「局所指数 ≥ 0.70 全域」は廃止する。理由は測定上の欠陥であり、
機構の失敗ではない。** 2.6 の 0/22 は「機構が弱い」ことの証拠としては読めるが、
「ゲートが正しい」ことの証拠にはならない。ゲートの形を変えても 2.6 の機構別
ランキング（支持・堆積が最も効く、imbrication は効かない、GSD 幅は効かない）は
そのまま残る。根拠: REPORT-V4-2-6 §4.3 の物差し上限表。限界: この主張は
0.6 m 箱・cell 1.17 mm および 0.293 mm での検査に依存する。箱・セルを変えれば
上限値は動く（§1.4 の較正で箱ごとに測り直す）。

### 1.2 新ゲートの定義 — プロファイル対プロファイル

**A2 — 新しい STAGE 1 ゲートは「生成床の局所指数プロファイル H_loc(ℓ) が、
同じ物差し・同じ箱で測った理想 H_gen=0.79 場の参照プロファイルと一致するか」
の比較検定とする。** 比較する量は単一の H 値ではなく、帯内（0.4–3.6 cm）の
プロファイル全体の**形**である。D2 裁定と整合する形である：
H はスケーリング領域の適合値なのだから、判定もその領域のプロファイル全体で行う。
単一の適合値（H_fit）だけでは 2.5 の教訓（0.713 iso は帯内で 0.79→0.61 とすべる
曲線の平均にすぎない）を繰り返す。

- 測る量: 方向別（x 流下・y 横断）の局所指数 H_loc,d(ℓ)、ℓ は帯内のラダー全ビン
  （60 ビンラダーの帯内 ≈ 18–20 ビン）。iso（x と y の平均）も併記するが、
  合否は方向別で読む（2.6 は最悪方向で判定した。異方性は実床の性質なので、
  iso だけでは隠れる）。
- 参照プロファイル: §1.3 の手順で作る。比較は**同じ箱・同じセル・同じ物差し**でのみ行う。
  0.6 m パッチの床は 0.6 m パッチの参照と、3.0 m 帯状床は 3.0 m 帯状床の参照と比べる。
  箱をまたいだ比較はしない（2.5 §6.1: 同じ基盤で H が 0.69 と 0.94 に分かれる）。

> **（改訂 R1：ラリー収束・4者一致）** A2 の「理想 H_gen=0.79 場の参照プロファイル」は主参照としては失効する。実床は D50 付近の折れ目と D90 以遠の飽和を持ち、スケールフリーな fBm とは形が違う（RALLY-V4-2-7 §2-3）。**主参照は実測装甲床 DEM（Bertin et al. 等）を同じ物差し・同じ箱で測ったプロファイルとする。** 合成 fBm プロファイル（下記 A3 の手順）は**推定量較正のヌル**としてのみ残す（有限箱バイアスと推定量の誤差率を測るためのもので、物理比較の相手ではない）。DEM の入手可能性は別途調査する（`~/workspace/research_notes/bed-dem-availability-20261113/report.md`）。入手できない場合の代替は同調査の結論に従う。なお A2 の「プロファイル対プロファイル」という比較の形そのものは維持する（A2 は GPT のみ STANDS、他 3 脚は参照の中身を理由に WEAKENED）。

**A3 — 参照プロファイルの作り方（固定手順）。（改訂 R1）以下の手順は較正ヌル（合成 fBm）の作り方として残る。物理比較の主参照は実測 DEM のプロファイルであり、その測定手順は DEM 入手後に本節と同形式で追記する。**

### 1.3 比較指標と合格則（仮置き値 — 較正で決める）

**A4 — 比較指標は方向別・ラグ別の z スコアとし、合格則は次の 3 条件の論理積とする
（数値はすべて仮置き。較正計画 §1.5 で決め直す。導出値ではない）。**

各方向 d ∈ {x, y}、各帯内ラグ ℓ について

    z_d(ℓ) = (H_loc,bed,d(ℓ) − μ_ref,d(ℓ)) / σ_ref,d(ℓ)

とし、次を満たせば PASS とする。

| 条件 | 内容 | 仮置き値 |
|---|---|---|
| C1（中心の一致） | 帯内ラグ平均の \|z\| が両方向で | ≤ **1.0** |
| C2（外れラグなし） | 任意の 1 ラグの \|z\| が両方向で | ≤ **3.0** |
| C3（すべりの形の一致） | プロファイルの落差 Δ = H_loc(0.41 cm) − H_loc(3.28 cm) について \|Δ_bed − Δ_ref\| が両方向で | ≤ **0.10** |

- C1 は「プロファイルの中心が理想場の実現ばらつきの 1σ 以内にある」こと、
  C2 は「どこか 1 ラグだけ大きく外れていない」こと、C3 は「帯内でのすべり方
  （有限箱バイアスの形）が理想場と同じ」ことを見る。3 条件はそれぞれ別の
  失敗を殺す: C1 は粒床のような全体の低さ（H ≈ 0.3、z ≈ −5〜−8）を殺し、
  C2 は局所的な折れ・段差を殺し、C3 は「平均は合っているが形が違う」
  （2.5 の 0.713 iso 型のすべり平均）を殺す。
- **両側検定である。** H_gen=0.92 級の滑らかすぎる場は z が正側に大きく外れて
  FAIL になる（旧ゲートでは PASS だった）。これが意図どおりである。
  「H が高いほど良い」ではない。「H=0.79 の場と同じプロファイル」が合格である。
- 方向は両方とも条件を満たすこと（最悪方向で判定。2.6 の判定と同じ）。
  iso は記録のみとし、合否には使わない（異方性を隠すため）。

根拠: 2.6 §4.3 の数値からの目安 — 理想場の実現間ばらつきは帯端で
最良–最悪 ≈ 0.04（4 seed で局所指数最小の平均 0.62 / 最悪 0.58）なので
σ_ref ≈ 0.02–0.05 の桁。粒床のプロファイル（0.42→0.32）は参照（0.74→0.62）から
0.3 以上離れており、z にして −6 以下になる見込みで、C1 は粒床を確実に落とす。
限界: しきい値 1.0 / 3.0 / 0.10 は**観測された隔たりの中に置いた仮置き値**であり、
較正ではない。G-LINE-stat ラリーの教訓（しきい値を観測ギャップに置くのは
較正ではない）をここでも守る: §1.5 の較正で決め直すまで、これらの数値で
合否を確定させてはならない。

> **（改訂 R2：ラリー収束・4者一致）** しきい値 1.0 / 3.0 / 0.10 は較正ではなく**配置値**であり、この明示は採用後も維持する（Grok は A4 を WRONG と判定 — 配置値を合否則の形で書くこと自体が問題、という指摘）。運用判定に使うのは、(i) 較正スイートで Type-I/II 誤差率を実測し、(ii) ラグ間相関を無視した z の平均・最大ではなくプロファイル全体の同時検定（方向は global rank-envelope 検定、Myllymäki et al. 2017。dsh・GPT の提案）で多重性を制御し、(iii) 較正の実現数を n ≥ 39 級まで増やしてからである。それまでは A4 は「診断の物差し」であって「合否の物差し」ではない。

### 1.4 推定量バイアスの較正（先にやる。M1–M6 と共通）

**A5 — 参照プロファイルは箱ごとに作ることで有限箱バイアスを相殺するが、
それだけでは較正にならない。較正スイートを先に走らせる。**

較正スイート（生成のみ。床は作らない。合成場だけ）:

1. 既知 H_gen の純粋 fBm 場: H_gen ∈ {0.70, 0.79, 0.85, 0.92} × 箱 {0.6 m パッチ,
   3.0 m 帯状床} × 各 R = 8（パッチ）/ 4（帯状床）実現。同じ物差しに通し、
   A4 の合格則を適用する。
2. 合格則の較正受入条件（仮置き。較正で決め直す）:
   - H_gen=0.79 の場は **7/8 以上**（パッチ）/ **3/4 以上**（帯状床）が PASS すること。
   - H_gen=0.70 および H_gen=0.92 の場は **1/8 以下**が PASS こと

   - 既存の粒床（v4-2.2 パッチ、帯状床 r1・r2）は **0/3** が PASS すること

     判定対象の床の測定後に動かさない（事前登録。§1.6）。
3. セルサイズ感度: 0.6 m パッチで 1024² と 2048² の両方で参照を作り、
   合格則の判定がセルで変わらないことを確認する（2.6 §6.2: ΔH_x = −0.001 で
   無視できる見込みだが、測って確認する）。
4. 穴の埋め方感度: 判定対象の床と参照は**同じ埋め方**で測る。埋め方は測定前に

根拠: DESIGN-V4-2-6-MESO §1 の「較正なしに帯を実測床へ適用してはならない」と
同じ原則。2.3 で見つかった物差しの低バイアス ≈ 0.26 は、箱を変えれば
プロファイルの形ごと変わる（2.5 §6.1）。限界: 較正スイートは合成場の
バイアスしか測れない。実在床の推定量バイアス（DEM のノイズ・解像度）は
§3.4 の実測 DEM 比較でしか測れない。

### 1.5 H_fit 帯（STAGE 3 の主判定）との関係

**A6 — H_fit の帯 0.70–0.85 は残すが、地位を下げる。主判定はプロファイル比較
（A4）とし、H_fit は粗いスクリーンとする。**

- 理由: H_fit は帯内の両対数回帰の傾き 1/2 であり、理想場なら 0.6 m で 0.719、
  2.4 m で 0.750 と帯に入る（2.6 §4.3）。到達可能な量である。
  しかし 2.5 の教訓のとおり、H_fit だけでは「帯内で 0.79→0.61 とすべる曲線の
  平均がたまたま帯に入る」場合と「真のスケーリング則」を区別できない。
  だから H_fit PASS だけでは合格としない。プロファイル PASS が必要である。
- 扱い: プロファイル PASS かつ H_fit 帯内 → PASS。プロファイル PASS だが
  H_fit 帯外 → **未解決**（箱効果・実現ばらつきの疑い。実現を増やして再測定。
  PASS とはしない）。プロファイル FAIL → FAIL（H_fit の値によらない）。
- 箱依存の開示: 基盤のみの H_fit は 0.6 m で 0.686、3.0 m で 0.863–0.942 と
  箱で 0.25 以上動く（2.5 §6.1）。H_fit を箱を明記せずに読んではならない。
  プロファイル比較も H_fit も、箱つきの量として報告する。

根拠: REPORT-V4-2-5 §7(3) および REPORT-V4-2-6 §4.3。限界: H_fit と
プロファイル比較は同じ曲線から出る量なので、完全に独立な二重チェックではない。
独立性を主張しない。 **（改訂 R9）「プロファイル PASS＋H_fit 帯外＝未解決」の三値化は
dsh が強く批判した（通す道と棄権する道が多く、落ちる道が狭い棄権装置になりうる）。
GPT は設計どおりの未解決扱いを支持した。本書では三値化を維持するが、未解決を
放置せず較正の再実行で解消する運用とし、論点としては未決着に残す。**

### 1.6 PASS / FAIL の意味の再定義と実施手順

**A7 — 新ゲートでの PASS / FAIL の意味。**

- PASS = 生成床のスケーリング領域プロファイルが、同じ物差し・同じ箱で測った
  理想 H=0.79 場のプロファイルと、較正済みの許容幅の範囲内で一致する。
  すなわち「この床は、測れる解像度で、Nikora のスケーリングを**持っている**」。
  PASS は「この床が実在の水流作用床である」ことの証明ではない。
  メソ帯のゲート（M1–M6）・他の 7 ゲート（歪度・σz・D84/D50・装甲比・傾斜角・
  クラスター被覆率・空隙率）が別に要る。
- FAIL = プロファイルが参照から外れている。低すぎる場合（粒床型）と
  高すぎる・滑らかすぎる場合（H_gen ≥ 0.92 型）の両方がある。
  FAIL は「非物理」ではない。「この統計量が合っていない」という事実だけである。
- 未解決 = 較正が通っていない、埋め方で合否が変わる、H_fit とプロファイルが
  食い違う、実現数が足りない、のいずれか。未解決は FAIL でも PASS でもない。
  実現を増やす・較正をやり直す・埋め方を固定する、のいずれかで解消する。

**A8 — 実施手順（順序固定）。**

1. 較正スイート（§1.4）を走らせ、しきい値 C1–C3 を決めて**事前登録**する
   （しきい値・実現数・埋め方・箱・セルを測定前に固定し、記録する）。
2. 参照プロファイルを作る。箱ごとに別々に作る。**（改訂 R1）主参照は実測 DEM の
プロファイル（入手後に手順を追記する）、§1.3 の合成プロファイルは較正ヌルとして併走させる。**
3. 判定対象の床を同じ物差し・同じ埋め方で測り、A4 を適用する。
4. 結果は「PASS / FAIL / 未解決」の三値で報告する。旧ゲートの二値（PASS/FAIL）
   には戻さない。
5. しきい値は判定対象の測定後に動かさない。動かす場合は較正スイートから
   やり直し、理由を記録する（G-LINE-stat ラリーの教訓と同じ規律）。

### 2.3 局所粒径・装甲・hiding — P が決めるもの

**B3 — P(x,y) は 3 つの局所量を決める。粒径、装甲比、細粒の shelter。**
**（改訂 R3）このうち 3 番目（細粒の shelter）は削除された。P が決めるのは粒径と装甲比の 2 つである（§2.3(3) の改訂注記）。**

1. **局所粒径**: 各粒の位置で m(x, y) = exp(α·P − α²/2) を読む。
   局所中央粒径 = D50_input·m(x, y)、局所選別度は補償式で絞る。
   全体の D84/D50 を守るための補償式（2.4 §2.3）:

       σ_ln,local² = σ_ln,global² − α²

   ただし **実現可能性ガード**を入れる: σ_ln,local ≥ 0.25（σg_local ≥ 1.28）を
   満たさない (α, σg) の組合せは棄却する。本床（σg = 2.1、σ_ln,global = 0.742）では
   α_max = √(0.742² − 0.25²) ≈ **0.70**。α = 0.64 では σg_local = 1.46（2.4 と同じ）。
   α = 0.80 は実現不能（σg_local が虚数になる。D4 の攻撃そのもの）。
   m の幾何平均を 1 にする（−α²/2 項）ので表面 D50 の中央値は動かない（装甲比ゲートの保護）。
2. **局所装甲比**: R_a(x, y) = 2.0·m(x, y)^γ、γ ∈ {0, 0.5}（掃引）。
   表面層の中央粒径 = 下層の中央粒径 × R_a(x, y)。γ = 0.5 のとき、
   粗パッチ（m = 1.9）では R_a ≈ 2.76、細パッチ（m = 0.53）では R_a ≈ 1.46。
   全体の装甲比は幾何平均で ≈ 2 を保つ。根拠: 装甲比 ≈ 2 は実在の既知量
   （Bunte & Abt、Umpqua 平均 2.3）。局所装甲の空間変動そのものは
   仮説であり、実測の裏づけは Bertin の丘/窪 D84 比（1.04–1.52）のみである。
   γ = 0 は「装甲は一様」という対照であり、γ の効果を分離するために要る。
3. **細粒の shelter（hiding/exposure の地形への翻訳）**: 細粒（D < D16_local）は
   粗粒の lee/wake（アンカー粒の下流 1–2·D_anchor 以内）と粒間隙に
   優先的に置く。根拠は Wilcock & Crowe (2003) の hiding 関数
   （細粒は粗粒の間に nestle し、粗粒が細粒の輸送を抑える）と、
   Bertin の丘/窪選別（丘が粗い）である。**ただし hiding は輸送の概念であり、
   配置の概念ではない。** 輸送法則を配置則に翻訳する正当化は、
   「shelter された細粒が最終的にそこに残る」という定常状態の議論に依存する。
   これは本設計の最も弱い翻訳であり、§4 Q6 のラリー攻撃対象である。
   実施は副次バリアントとする（主バリアントは hiding なし。効果が測れなければ捨てる）。
**（改訂 R3 — 削除）ラリー裁定（dsh WRONG、Grok WRONG、GPT WEAKENED、Gemini も Q6 で
「形成過程のない looks-like 調整」と判定）により、この配置則は生成則として**削除**する。
Wilcock & Crowe の hiding は輸送の閉形式であって配置の法則ではない。本項は元の設計文を
記録として残すが、実施はしない。残るのは研究メモとしての扱いのみ: 輸送を前向きに
回したとき（τ 場＋hiding 関数の順方向積分。§2.5（改訂 R8）の winnow と同系）に
wake の細粒が結果として残るかを調べる課題であり、効果の主張からは外す。**

根拠: 2.4 §2.3・§3.2、Wilcock & Crowe (2003)、Bertin et al. 2017、
RALLY-V4-2-4 D4 裁定（局所絞りが D84/D50 = 1.85 で虚数になる指摘への回答が
実現可能性ガードである）。限界: γ の値・hiding の翻訳は仮置き。
特に hiding は「細粒が粗パッチの wake に残る」ことを課す設計であり、
形成過程をシミュレーションしていない。

### 2.4 支持・堆積・imbrication との合成（bed_gen3 への組み込み方）

**B4 — パッチ層は 2.6 で試した機構と合成する。置き換えるのではなく、足す。**

既存の生成器（`bed_gen2.populate`、1852 粒の母集団）はそのまま使う。
`bed_gen3.py` の実装スケッチ（設計のみ。コードは書かない）:

1. **P(x,y) の生成**: 帯状床グリッド（3.0 m × 0.6 m、cell 0.293 mm）上で
   1 枚生成する。スペクトルフィルタ（Matérn ν=1.5、ℓc,x/ℓc,y は §2.2）。
   0.6 m パッチ較正では同じ場から切り出す（場を作り直さない）。
2. **粒径の局所化**: 各粒の位置で m(x, y) を読み、粒径を対数正規から引く
   （中央値 D50_input·m、σg = σg_local）。数密度は n ∝ 1/m²
   （面積被覆率を一定に保つ。2.4 §3.2）。
3. **支持・堆積配置**（2.6 の機構 (c)）: 支持統計 max または p75、q ∈ {0.10, 0.20}。
   q は粒径単位の突出量なので、局所粒径に合わせて q·D_local を使う
   （2.6 は一様な D での掃引だった。局所化は本設計の追加）。
   落下順はランダム。局所緩和は接触と非貫入だけ（平滑化なし）。
4. **imbrication**: 傾斜 25–35°（一様分布）、方位は上流向き。2.6 で H への効果は
   ほぼ無い（ΔH_x = +0.019）ことが分かっているが、**傾斜角ゲート（25–35°）と

5. **クラスター**: アンカー中心の抽選確率を m(x, y) に比例させる

   v4-2.2 のまま（アンカー >D90、stoss D74–D94、wake D8–D46、被覆率 0.05–0.15）。
6. **基盤**: fBm H_gen=0.79 + 低次モード + 歪み変換は v4-2.2 のまま。

8. **較正ステージ（先にやる）**: 0.6 m パッチで α × ℓc × q の掃引（各組 3 実現）。

### 2.5 期待する動き（正直な見積もり）と較正の進行条件

**B5 — パッチ層に期待する動きは、メソ帯の閉合である。スケーリング帯の閉合ではない。**

| 帯・量 | 現状（粒床のみ） | パッチ層の期待する動き（仮置きの見積もり） |
|---|---|---|
| スケーリング帯 H_fit（0.4–3.6 cm） | 0.29–0.35 | **0.35–0.50**（混合効果 +0.05–0.10、支持・堆積 +0.05–0.08、重なりは部分的。0.79 には届かない見込み） |
| スケーリング帯 H_loc プロファイル（A4） | 参照から z ≈ −6 以下 | 参照に近づくが、C1（\|z\| ≤ 1.0）を通る見込みは**低い**。プロファイルの形がどう動くかを測ることが較正の目的 |
| メソ帯 Φ(6.6 cm) | ≈ 0.84（粒だけ床のモデル値） | **0.56–0.60**（実測中心）へ向かう |
| メソ帯 Φ(20 cm) | ≈ 1.00（完全飽和＝メソ成分なし） | **0.75–0.91** へ向かう |
| メソ帯 H_meso | ≈ 0.08 | **0.13–0.19** へ向かう |
| 異方性 S_x/S_y @20 cm | ≈ 1.00（等方） | **≈ 0.83** へ向かう |

- 混合効果（mixture-of-cutoffs）の仮説: 局所 D50 が空間的に変動すると、
  粒起伏の飽和ラグ（≈ D50 付近）も空間的に変動する。合成の S(ℓ) は
  局所曲線の面積加重平均になるため、単一の局所曲線より長く立ち上がり続け、
  見かけの傾きが上がる。これがスケーリング帯で期待できる唯一の機構である。
  **ただしこれは仮説である。** 局所曲線の平均が本当に傾きを上げるかは、
  bed_gen3 を作る前に**安い数値チェック**で確かめる（§2.6 F-B0）:
  2–3 本の局所曲線（D50 を 0.5×/1×/1.9× にした粒起伏の S(ℓ)）を
  面積加重平均し、合成の H_loc プロファイルがどう動くかを計算する。
  動かなければ、パッチ層はスケーリング帯には何もしないことが確定する。
- 較正の進行条件（旧 2.4 の「H ≥ 0.72」に代わるもの）:
  **メソ帯の Φ(6.6 cm) が 0.84（粒だけ床）から 0.78 以下へ動き、かつ
  他の 7 ゲート（§2.4 の表と同じ帯）を壊さない組が 1 つ以上あること。**
  スケーリング帯の H は進行条件にしない（届かない見込みが高いため、
  進行条件にすると較正が必ず止まる）。スケーリング帯は測定・記録し、
  A4 の z スコアで報告する。帯も σz 目標も動かさない。

根拠: h-meso report §3 の 2 成分モデル（粒だけ床 Φ(6.6) ≈ 0.84 / Φ(20) ≈ 1.00 /
H_app ≈ 0.08 対 中央ケース 0.56–0.60 / 0.75–0.91 / 0.13–0.19）、
REPORT-V4-2-6 §3.3 の支持・堆積の +0.084、DESIGN-V4-2-6-MESO §2 の M1–M6 帯。
限界: 上の「期待する動き」は**見積もり**であり、測定ではない。
特にスケーリング帯の +0.05–0.10 は混合効果の仮説に依存し、F-B0 の
数値チェックで否定される可能性がある。メソ帯の動きも、パッチ項の振幅 b が
Bertin の σ_B（≈ 8 mm、本床換算）に届くかどうかに依存する。
b の見積もりは 2.4 §2.2 結論 3（突出だけでは ~8 mm、残りを包絡項で足す）に
依存しており、舗装なしでは b の上限が下がる可能性がある。
**パッチ層がメソ帯を閉じられない場合、それはそれで測定結果として報告する。**

> **（改訂 R8：ラリー収束）** パッチ層の地位をここで確定する： **パッチ層はメソ帯専用の機構**であり、スケーリング帯の本命ではない。重ね合わせの算術（小ラグでは最も粗い成分＝粒起伏 H ≈ 0.34、帯内分散のほぼ 100% が傾きを支配する）のとおり、滑らかな場を足してもスケーリング帯は上がらない。スケーリング帯への候補は**粒層そのものの変更**に移す — (i) 輸送を前向きに回す選別（winnow： 細粒の表面からの除去）＋接触で固定する interlock（dsh の提案）、(ii) 流体せん断による粒頭の削り（planation： 突出上位 5–10% の切り取り、正の歪度 +0.5–+0.7 の再現）＋角ばった faceted 粒（Gemini の提案）。どちらの機構が実際に効くかは未検証であり、§2.6 のキラーテストを通してから設計を起こす。パッチ層の較正（進行条件・F-B1/F-B2）はメソ帯の判定としてのみ意味を持つ。

### 2.6 反証条件 — パッチ層を殺すデータ

**B6 — 次のいずれかが測れれば、パッチ層の設計はその形では死ぬ。**

> **（改訂 R7：順序の決着）** キラーテストの順序はラリーで 2 対 2 に割れた（GPT・Gemini： 安い F-B0 を先に／dsh・Grok： 実測 DEM＋F-B4 が決定的で先）。本人の「全部やる」原則により、**F-B0 と実測 DEM キラー（F-B4・F-B5）の両方を並行の前提条件**とする。どちらか一方でも落ちれば bed_gen3 は作らない。合成床の較正（§1.4）は DEM を待たずに進めてよいが、ビルドの可否は両テストで決まる。

- **F-B0（混合効果なし）**: 2–3 本の局所曲線の面積加重平均で、合成の
  H_loc プロファイルが局所曲線のいずれとも変わらない（ΔH_fit < +0.02）。
  → スケーリング帯への寄与は無い。パッチ層はメソ帯専用の機構になる。
- **F-B1（スケーリング帯が動かない）**: α の掃引（0.40→0.64）で
  スケーリング帯 H_fit の動きが **+0.05 未満**。→ パッチ層はスケーリング帯の
  機構ではない。メソ帯だけを見る設計に切り替える。
- **F-B2（メソ帯が動かない）**: 最大 α でも Φ(6.6 cm) が **0.80 以上**のまま。
  → パッチ項の振幅 b が足りないか、相関長が帯の外にある。ℓc の掃引範囲を
  見直すか、パッチ層ではメソ帯を閉じられないと結論する。
- **F-B3（他ゲートが先に壊れる）**: H が動く前に D84/D50・装甲比・空隙率・
  歪度のいずれかが帯を外れる。→ 2.4 の D4 の失敗モードそのもの。
  パッチ層は H を上げる前に床を壊す設計だったことになる。
- **F-B4（3-D 粒のキラーテスト）**: 平らな基盤（b = 0、σ_form = 0）の上に、
  傾斜角ゲートと GSD ゲートを満たす 0.5 m × 0.5 m の 3-D 粒充填を作り、
  粒内起伏 a_eff を測る。**a_eff > 3.0 mm**（S_grain(6.6 cm) > 18 mm²）なら、
  粒層そのものの分散予算が破綻しており、パッチ層以前の問題である
  （RALLY-V4-2-4 の Gemini のキラーテストをそのまま採用）。
  → 粒の配置モデルそのもの（3-D の粒の重なり・支持の扱い）を見直す必要がある。
- **F-B5（実測 DEM との不一致）**: §3.4 の実測 DEM 比較で、生成床の方向別
  2-D 構造関数が実測装甲床とスケーリング領域で一致しない（H が合っても
  方向別共分散・スペクトル分布が違う）。→ 2.4 ラリーの収束したキラーテスト。
  H の一致だけでは物理的主張は立たない。

### 2.7 箱の制約 — 0.6 m パッチではメソは測れない

**B7 — パッチ層の 2 つの期待効果は、別々の箱に住んでいる。**

- スケーリング帯の効果（混合効果）は 0.6 m パッチ（16.7 D50）で測れる。
  0.6 m パッチには 40–50 cm 相関の場が 1–2 個分しか入らないが、
  スケーリング帯のラグ（0.4–3.6 cm）に対しては場はほぼ一様であり、
  混合効果は「パッチ間のばらつき」としてではなく「実現間のばらつき」として現れる。
  だから 0.6 m パッチの較正では、**実現数を増やして**混合効果を測る
  （R ≥ 8。異なる P の実現で H_fit の分布を見る）。
- メソ帯の効果（Φ・H_meso・異方性）は **3.0 m 帯状床（83 D50）でしか測れない**。
  Bertin et al. は粒 σ の安定にすら (12–18 D50)² の窓を要し、bedform σ は
  最大窓でも安定しなかった（DESIGN-V4-2-6-MESO §1）。
  0.6 m パッチでメソゲートを測ってはならない。
- したがって較正は二段構えになる: (1) 0.6 m パッチでスケーリング帯＋他 7 ゲートを
  較正し、(2) 通った組だけを 3.0 m 帯状床でメソゲート（M1–M6）にかける。
  (1) で通らなければ (2) には進まない（2.4 §5 と同じ段取り）。

根拠: DESIGN-V4-2-6-MESO §1（帯状床のみ・83 D50）、h-meso report §2.2
（Bertin の窓の要求）、v4-2.3 の教訓（パッチ寸法の偏りを両方で確認する）。

### 3.1 テクスチュア・パッチ（粒径の空間分布）

**B8 — 川底は「似た粒径の領域（パッチ）」のモザイクである。パッチは実測の基本構造である。**

| 事実 | 出典 |
|---|---|
| テクスチュア・パッチは「地図化できる領域（約 0.1–1 チャンネル幅）」として定義される。直線区間では粗いバー頂と細かい淵が対応する | Nelson et al. 2010 (JGR-ES 115, F4); Nelson et al. 2014; Prado et al. 2025 による整理 |
| 形成機構はバー上での境界せん断応力の低下による粒径選択的な輸送（強制パッチ）。粗いバー頂 / 細かい淵 | Nelson et al. 2015 (JGR-ES 120, 1687–1707) |
| パッチ間の粒径コントラストは大きい。水理粗度が大きい区間では観測 D50 がバンクフルせん断応力からの予測より最大 90% 小さい（細かいパッチが卓越） | Buffington & Montgomery 1999 (WRR 35, 3507–3522) |
| テクスチュア・パッチの分類手順（2 層の三元図による facies 分類）が標準化されている。現場テストで中央粒径と分散の統計的識別が確認されている | Buffington & Montgomery 1999 (WRR 35, 1903–1914) |
| 選別度の悪い材料だけでも、確率的な粒配置から**メートル規模の細・混合・粗パッチが自発的に生じる**。ただしそれだけでは D84/D50 ゲートを保ったまま H を閉じるには足りない（2.4 §2 の計算） | Prado et al. 2025 (Geomorphology 471, 109565)。4 本のスイス礫バー（Emme 川・Sense 川）の DEM・オルソモザイク・粒径データとの比較 |
| 蛇行水路実験では 5 種のパッチ型ができ、淵の粗いパッチ D50 = 3.7 mm が記録されている | White et al. 2023 (JGR-ES) |

**設計への含意**: パッチの存在そのものは疑いようがない。ただし実測のパッチは
**バー規模（メートル〜チャンネル幅）**の現象であり、本設計の 40–50 cm という
相関長は、実測パッチの下端〜それ以下である。40–50 cm を選ぶ根拠は
Powell・Bertin のメソ地形のスケール（§3.3）であって、テクスチュア・パッチの
実測スケールではない。この点は設計の弱さであり、§4 Q4 の攻撃対象である。
また Prado et al. の「選別度だけでメートル規模パッチが自発的に生じる」という
結果は、**課すパッチが要らない可能性**を示唆している。ただし 2.4 §2 の計算が
示すとおり、自発パッチだけでは D84/D50 ゲートを保ったまま H を閉じられない。
自発パッチの寄与を定量化する（現行生成器の粒径場のバリオグラムを測る）ことは、
較正ステージの前段として安くできる。**現行生成器にすでに自発パッチがあるかどうかを
測らずにパッチ層を課してはならない。**

### 3.2 クラスター（粒の集まりの内部構造）

**B9 — クラスターはパッチとは別レイヤーである。クラスターは「粒の集まりの内部構造」、
パッチは「粒径そのものの空間分布」である（2.4 §1.3）。混同しない。**

| 事実 | 出典 |
|---|---|
| アンカーは >D90（典型 D98–D99）。stoss は D74–D94、wake は D8–D46。長さ 0.1–1.2 m（平均 ~0.29 m）、長さ ≈ 2×幅、被覆率 ~10%、非周期 | Brayshaw 1984 ほか（v4-2-1 研究報告 §2 に再掲） |
| 潜在的なアンカー石のうち、クラスター形成を可能にするのは**約 5 分の 1 だけ**。クラスター被覆率は実験で 5–34%。pebble 型と heap 型が最も多い | Heays, Friedrich & Melville 2014 (WRR, doi:10.1002/2013WR014208)。実験室研究 |
| クラスター形状は line / rhomboid / triangular / ring など。形成→中立→崩壊の 3 相（sink / neutral / source）がある。間隔は流れへの最大抵抗を与えるように決まるという仮説 | Wittenberg 2008（フラクタル・アプローチ）; Hassan & Reid 1990（間隔仮説）; Strom & Papanicolaou 2008（形状分類） |
| クラスター密度 6–68.3 個/m²、被覆率 2–17%。最高密度では流れ抵抗が**最大 8 倍**になる。密度が上がると wake が干渉し、クラスター高さにせん断層ができる | Little & Venditti 2014 (AGU Fall Meeting)。固定礫床の水路実験 |
| クラスターの空間分布は、主に大きい粒（>D84）と中くらいの粒（D50–D84）によって決まる。最近接統計による | Amoreaux & Gibson 2013（最近接空間統計） |
| 粗粒のクラスタリング度合いは、D84 よりも水理粗度をよく予測する。**空間組織そのものが D84 より強い制御因子になりうる** | Johnson et al. 2017 (GRL 44, 3653) |
| 階乗クリギング＋現場・画像データでクラスターを地図化し、形態を抽出できる。アンカーの優位性（>D90）を確認 | Wu et al. 2018 |
| クラスターは流れ・土砂・平面形状のフィードバック相互作用の結果であり、確率的な性質を持つ。bed-load sheet やバーとの関係で低起伏 bedform として現れる | Church et al. / 低起伏 bedform 研究（J. Sediment. Res. 65） |

**設計への含意**: クラスターは v4-2.2 で既に実装済み・ゲート PASS（被覆率 0.0767、帯 0.05–0.15）である。
本設計で変えるのはアンカー配置の偏り（粗パッチに寄せる）だけである。
ただし Heays et al. の「5 分の 1 のアンカーしかクラスターを作らない」という結果は、
**アンカーを粗パッチに寄せるだけではクラスター被覆率が上がらない可能性**を示唆する。
アンカー配置の偏りが被覆率・クラスター形状に与える影響は較正で測る。
また Johnson et al. の「クラスタリングが D84 より強い」という結果は、
パッチ層の設計動機を裏づける一方で、**クラスタリングそのものを直接測る監査**
（Ripley の K、2.4 §5 の P3）をパッチ層の評価にも入れるべきことを示す。
クラスターとパッチの寄与を分離せずに H の動きをパッチのせいにしてはならない。

### 3.3 メソ地形（bedform）— パッチ層の対応物

**B10 — 6.6–20 cm 帯の S(ℓ) を立ち上げるのは、粒起伏ではなくメソ地形（bedform）である。
Bertin et al. の分離がその対応物である。**

| 事実 | 出典 |
|---|---|
| 35 パッチの実測で、bedform 成分の鉛直粗度は全体の中央値 **64%**（IQR 59–68%）を占める。σ_B/D50 中央値 **0.26**（IQR 0.21–0.31）。合成式 σz = 0.71σ_G + 0.82σ_B | Bertin, Groom & Friedrich 2017 (WRR 53, 6841–6856)。移動窓デトレンド（フィルター径 2.5·D90）による分離 |
| 粗い粒の集まりが表面にハンプ（隆起）を作り、その背後に細かい粒が shelter される。粒の鉛直粗度は表面粒径と強い線形関係にある | Bertin et al. 2017（同上） |
| 丘と窪の選別: D84(丘)/D84(窪) = **1.04–1.52**。形成 Shields 応力とともに増大する（実験サブセットで R² = 0.91） | Bertin et al. 2017（同上）。**機構の署名** — 丘は粗粒でできている |
| bedform の相関は 20–25 D50 で再帰する（次の bedform）。相関の減衰の異方性は 5 D50 未満のラグからすでにある | Bertin et al. 2017（同上） |
| メソ地形は流下に伸びた ridge/trough。variogram range ≈ **200 mm 流下 / ≈100 mm 横断**（Ds50 ≈ 16 mm）。方向別では γ(流下) < γ(横断) | Powell et al. 2016 (JGR-ES 121)。移動装甲の水路実験 |
| 有意相関楕円は **100 × 40 mm**（D50A ≈ 19.5 mm の床）。長軸は流れから 5° 以内。D50 換算で 5.1 × 2.1 D50 | Qin et al. の方法、Aberle et al. 2018 (Water 10, 561) に適用 |
| 3 領域記述（subgranular / granular / bed morphology）と nested variogram（短距離＋長距離の 2 成分）が複数の研究で一致する | Butler, Lane & Chandler 2001; 階乗クリギング研究（Open Geosci. 2018） |
| **測られていないこと**: D50 30–48 mm・D84/D50 ≈ 2 の実測 DEM で Φ(6.6)・Φ(20) を直接測った例はない。σ_B の母集団は本床より細かく選別度の良い床が中心である。6.6–20 cm 帯の H を測った文献はない（帯はスケーリング領域ではないため） | h-meso report §2.4・§5（F1・F2） |

**設計への含意**: パッチ層の物理的対応物は Bertin の bedform DEM である。
ただし Bertin の bedform は「粒 DEM を引いた残り」として定義されたものであり、
**パッチ場 P(x,y) そのものではない**。P を課す設計が Bertin の bedform と
同じ統計（σ_B/σz、相関長、丘/窪選別）を再現するかどうかは、較正で測るしかない。
特に M5（分離 σ_B と丘/窪 D84 比）がその判定項目である（DESIGN-V4-2-6-MESO §2）。
M5 を通らずに Φ・H_meso だけを通るパッチ層は、「高さだけ」の偽パッチである。

### 3.4 hiding/exposure 相関 — 輸送の概念と地形の署名

**B11 — hiding/exposure は輸送の概念である。地形への翻訳は「細粒が粗粒の wake に
shelter される」という 1 点に絞る。それ以上を主張しない。**

| 事実 | 出典 |
|---|---|
| 細粒は粗粒の間に nestle し、粗粒が細粒の輸送を抑える。逆に砂含有量が増えると礫の輸送が増える（潤滑効果）。hiding 関数は粒径級の相互依存を定量化する | Wilcock & Crowe 2003（表面ベースの掃流砂式）。HEC-RAS 技術文書による要約も参照 |
| 均等移動度（equal mobility）に近づくほど、粗粒と細粒の輸送しやすさの差は縮まる。hiding 係数を上げると装甲層ができにくくなる | Parker 1990 ほか。HEC-RAS hiding/exposure 文書 |
| 装甲層の発達過程で、細粒含有量の減少と hiding/exposure 効果の変化が連動する。予測誤差は河川で 2.9%、水路実験で 4.1%（装甲層 GSD の予測） | Decoding bed armoring（2025、Sci. Direct）。装甲化の 3 状態交換モデル |
| 地形の署名: 丘の D84 は窪の D84 の 1.04–1.52 倍。粗い粒の集まりが丘を作り、細粒が窪に shelter される | Bertin et al. 2017（§3.3 と同じ） |
| **測られていないこと**: 「局所細粒分率と局所粗粒密度の空間相関」を直接測った研究は、本設計の調査範囲では見つかっていない。hiding の地形への翻訳は、輸送実験からの推論である | 本設計の調査結果（不在の明記） |

**設計への含意**: hiding を配置則として課す（§2.3(3)）のは、輸送の定常状態からの
推論にすぎない。**（改訂 R3）ラリー裁定（dsh・Grok WRONG、GPT・Gemini WEAKENED）により、
配置則は削除された（§2.3(3) の改訂注記）。本節のインベントリ（輸送の概念としての
hiding と、地形の署名である丘/窪選別）は参照集団として残るが、生成則の根拠にはしない。
丘/窪の D84 比は M5 の照合項目として生きる — 測る対象であって、課す対象ではない。
元の設計文（副次バリアントに留める、差が測れなければ捨てる、「hiding があるから細粒が
ここに残る」という説明は主張として弱い）は、削除の経緯としてこの段落に残す。**

  B2 のパラメータ範囲、M1–M6 の帯は、いずれも較正・ラリーで決め直す前提の
  仮置き値である。導出値として読んではならない。
- **実現数は少ない。** 参照プロファイルは R = 8 / 4 の仮置きであり、
  2.6 の機構別結果は 1 実現ずつである。機構間の差（0.03–0.10）は
  実現間ばらつきと同じ桁なので、個々の順位は確定しない（REPORT-V4-2-6 §6.6 と同じ留保）。
- **穴の埋め方は第一級の交絡因子である。** H_x が 0.134 動く。
  埋め方で合否が変わる床は「未解決」とする規律（A5(4)）を守らなければ、
  ゲートは埋め方の選択を測る物差しになる。
