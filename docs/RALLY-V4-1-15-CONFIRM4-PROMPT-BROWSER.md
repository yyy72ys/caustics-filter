*Proc. 2nd ISOPE Conf.*。もとの理論は Sharma, J. N. & Dean, R. G.

**記号規約（本書で固定する。転記ミスの罠を塞ぐための定義）**：

- 線形場のモード m は振幅 a_m、波数ベクトル k_m、角周波数 ω_m > 0、位相 θ_m = k_m·x − ω_m t + ε_m を持つ。
- 2 次場は二重和で定義する（R1・R2 と同じ定義。1/2 の前因子を含む）：

- ペア (m, n) に対し：ω₊ = ω_m+ω_n、ω₋ = ω_m−ω_n、k₊ = |k_m+k_n|、k₋ = |k_m−k_n|、k_m·k_n は波数ベクトルの内積。h は各条件の水深（P1 0.6 m／P5 4.0 m／SWELL 4.0 m）。
- **WAFO の規約との対応（転記ミスの罠）**：WAFO の `qtf` は 1/2 を付けず η₂ = ΣΣ a_m a_n [h_s cos(θ_m+θ_n) + h_d cos(θ_m−θ_n)] と定義するため、**B⁺ = 2h_s、B⁻ = 2h_d** である。WAFO の数値をそのまま B⁺/B⁻ に読んではいけない（2 倍ずれる）。下記の転記は WAFO の h_s／h_d の形のまま書く。B への換算は ×2 である。
- **WAFO 内部の記号**：WAFO は 2 つのモードを (w_1, k_1)・(w_2, k_2) と書き、w12 = w_1·w_2、w1p2 = w_1+w_2、w1m2 = w_1−w_2、k12 = k_1·k_2、k1p2 = k_1+k_2、k1m2 = |k_1−k_2| と置く。k_1・k_2 は θ=0 の符号付き波数で、k は純重力の分散関係 ω² = gk·tanh(kh) から決まる（WAFO の `w2k`）。本書の (m, n) との対応は、1 次元切片では ω_m ↔ w_1、ω_n ↔ w_2、k_m ↔ k_1、k_n ↔ k_2 である。

5. **次元整合性（項ごとの同次性）**：B± の次元は 1/m。**加えて P₁・P₃ の各括弧の中身が項ごとに同次元であることを確認する。**P₁ の括弧 (w_2⁴ − g²·k_2²)・(w_1⁴ − g²·k_1²) はいずれも 1/s⁴、(k12·g² − w12²) は 1/s⁴ でなければならない。1 項でも次元が合わない場合は、その項の転記は誤りとして G-C1-0 は不合格とし、原文ファイルの直接読みで正す。**この検査は R4 の P₁ 第3項の問題（`g * 2.` は 1/(m·s²) で次元不整合）を検出した。**【R5 の結果：通過】**訂正形（g²）は全項が同次元。原文まま（`g * 2.`）は本検査で不合格となり、WAFO Langley 分岐の破棄の根拠になった。

8. **対角項の扱い**：h_d の対角は P₃/P₄ の式でなく h_dii で置くことを確認する（ω₋ = 0 で P₃/P₄ の形は特異）。**【R5 の結果：通過】**h_dii は h_d の極限として確認：ω₂→ω₁ の列（ε=1e-1〜1e-4）で h_dii へ線形に収束し、ε=1e-4 での相対誤差は 1.0e-04（h=0.6・4.0、ω=1.0・2.0 の全点）。対角の生の P₃/P₄ 評価は特異で意味が無いため、実装では必ず h_dii で置く。`verify-2d-kernel-2.py` の項目 (h)。

**カーネルの地位（R5 の結論）**：2D 一般角形は MF12 Lambda2 で確定し、1D 切片の厳密形は g² 訂正 Langley 形で確定した。**G-C1-0 は通過した。試験 0 の参照計算 A は実行可能である。**参照計算 A は MF12 Lambda2（2D）の直接二重和で行い、1D の g² 訂正 Langley 形は θ=0 での照合用とする。WAFO `qtf` は Langley 分岐・M&W 分岐の両方が壊れており、参照実装としては使わない（照合用の式は訂正形でのみ使う）。M&W 形は比較用（C）のままであり、参照計算に昇格させない。M&W 形で参照計算を回して J0 を通すことは、近似形を厳密形と偽ることになるため禁止する。**残る文書化の項目は U-1a（Bredmose (59)/(62) の転記）のみであり、試験 0 を止めない。**

**「P5 の試行は深水形の試行でもある」とは言わない（R2 の訂正を引き継ぐ）**：P5 の水深 4 m では、例えば k = 0.5 rad/m のモードは kh = 2 であり、低波数側を含むペアや差周波の小さいペアが深水極限に入るとは限らない。深水極限の一致は、ピーク近傍・低波数側・差周波小さいペアの 3 群に分けて測る。


## 抜粋 4：§2.2.2 本実装の計算方式 — FFT による分離形（候補 S1）

**2.2.2 本実装の計算方式 — FFT による分離形（候補 S1。試験 0 で検証する唯一の候補）**（R4 で書き直し）

**決定：本実装の計算方式は、以下に固定する分離形の候補 S1 とする。S1 以外の
分離形を試験 0 で試すことはしない。**S1 の具体式・対応表・方向依存・正規化は
本節で固定し、試験 0 の結果を見て変えることはしない（F9(8) の直し）。
S1 が §2.1 の QTF と等しいかどうかは、試験 0 で確認する。確認が通るまでは、
S1 を「Sharma–Dean カーネルの実装」と呼んではならない（LEG-GPT.md C2）。
**R5 での変更：S1 は 2D 一般角形の分離形である。**U-1 が閉じたため、S1 の
2D 形を本節で固定する。試験 0 は 2D 本番場で行う（§2.3）。

**S1 の構造（§2.1 の MF12 Lambda2 から導く。導出の筋道）**：Lambda2 の分子は
単一モード因子の積の和（分離可能）であり、分母 β_± = cosh(hκ_±)·D_± の
cosh を分子の α_±・γ_± と相殺すると、残るのは出力 (ω_±, κ_±) だけの
フィルタ 1/D_± と κ_±·tanh(hκ_±)/D_± である。したがって B^{±} は「分離可能な
積の和」に「出力波数だけのフィルタ」を掛けた形へ、近似なしに書き直せる。
この書き直しが S1 である。**S1 は 2D 一般角形に対する厳密な分離形である。**
θ=0 では R4 の 1D S1（Langley P₁ 形からの分離）に帰着し、両者は 1.4e-14 で
一致する（`ref-sources/verify-s1-2d.py`）。

**記号（R3 §2.1・§2.2.3 と同じ）**：解析信号 Z(x,t) = Σ_m a_m e^{iθ_m}、
θ_m = k_m·x − ω_m t + ε_m、η₁ = Re(Z)、η̃₁ = Im(Z)。**ここで使う ω は
カーネルの純重力の分散関係 ω² = gk·tanh(kh) から決まるもの**であり、
生成器の毛管入り ω ではない（§2.1 の注記。食い違いは §2.6 で帯域を切って
抑える）。B⁺ = 2h_s、B⁻ = 2h_d のため、(1/2) の前因子は相殺され、
η₂⁺ = ΣΣ a_m a_n h_s(m,n)·cos(θ_m+θ_n)、η₂⁻ = ΣΣ a_m a_n h_d(m,n)·cos(θ_m−θ_n)
と書ける（R3 §2.1 の定義）。

**S1 で使うフィルタ済み場（すべて Z からスペクトル乗算で作る）**：

| 場 | 定義（スペクトル乗算子） | 担う因子 |
|---|---|---|
| Z | 1 | a_m |
| Z_t = ∂ₜZ | −iω | ω_m |
| Z_tt = ∂ₜ²Z | −ω² | ω_m² |
| Z_ttt = ∂ₜ³Z | iω³ | ω_m³ |
| ∇Z（ベクトル場） | ik | k_m（ベクトル） |
| ∇Z_t（ベクトル場。R5 で追加） | ωk | ω_m·k_m（ベクトル） |
| L = −∇²Z（R5 で追加） | k² | k_m² |
| W（ベクトル場） | k/ω | k_m/ω_m |
| Y | k²/ω | k_m²/ω_m |

**積の対応規則（機械的に決まる）**：単一モード因子 μ(k,ω)·ν(k,ω) の積は、
解析信号の積 Z^μ·Z^ν に対応する。積の合成乗算子が実数の場合は実部 Re、
純虚数の場合は虚部 Im を取る。合成乗算子の虚数性は、∇（因子 i）と奇数階の
時間微分 ∂ₜ（因子 −iω）の個数の偶奇で決まる：i の総次数が偶数なら実数（Re）、
奇数なら純虚数（Im）。和周波側は Z^μ·Z^ν（θ_m+θ_n）、差周波側は
Z^μ·(Z^ν)*（θ_m−θ_n、* は複素共役）を使う。**対応表の展開は本規則から
機械的に決まる。展開結果は試験 0 の準備記録として残し、単色波アンカー
（G-C1-0 (1)）で検証する。展開を試験 0 の結果を見て変えることはしない。**

**対応表（2D S1。h_s^{±} = B^{±}/2。和周波側 pm=+1・差周波側 pm=−1 の共通形）**：

h_s^{±} = ( U₂^{±} + κ_±·tanh(hκ_±)·V₂^{±} ) / D_±。ただし D_± = ω_±² − g·κ_±·tanh(hκ_±) は出力 (ω_±, κ_±) だけの関数（共鳴分母。安全形で評価する）。

- U₂^{±} = (g/4)(κ_m²+κ_n²) + (g/2)·pm·d + (g/4)·pm·[ (ω_n/ω_m)(κ_m²+pm·d) + (ω_m/ω_n)(κ_n²+pm·d) ]、d = k_m·k_n（ベクトル内積）
- V₂^{±} = (g²/4)·d/(ω_mω_n) + (pm/4)·ω_mω_n − (1/4)·ω_±²
- 出力フィルタは 2 つ：F^{(U)}_±(k,ω) = 1/D_±(k,ω)（U₂ の積の和に掛ける）、F^{(V)}_±(k,ω) = κ·tanh(hκ)/D_±(k,ω)（V₂ の積の和に掛ける）。第 7 項（−(1/4)ω_±²）は出力だけの因子であり、フィルタ −(ω²/4)·κ·tanh(hκ)/D_± として Re[Z·Z] に掛ける。

| 分離可能な項（h_s の内訳） | S1 での場の積（和周波側 pm=+1） | 備考 |
|---|---|---|
| (g/4)(κ_m²+κ_n²) | (g/2)·Re[L·Z] | L = −∇²Z（乗算子 k²）。二重和の対称性で (κ_m²+κ_n²)/2 が k_m² 1 項で表せる |
| (g/2)·d | −(g/2)·Re[∇Z·∇Z] | ∇Z·∇Z はベクトル場の内積。合成乗算子は −(k_m·k_n) で実数 |
| (g/4)[(ω_n/ω_m)(κ_m²+d) + (ω_m/ω_n)(κ_n²+d)] | (g/2)·(−Im[Z_t·Y] + Re[(∇Z_t)·W]) | Z_t·Y の合成乗算子は純虚数のため Im（符号に注意）。(∇Z_t)·W はベクトル場の内積で、合成乗算子は (ω_m/ω_n)(k_m·k_n) で実数。二重和の対称性で 2 項が 1 式にまとまる |
| (g²/4)·d/(ω_mω_n) | (g²/4)·Re[W·W] | W·W はベクトル場の内積。合成乗算子は d/(ω_mω_n) で実数 |
| (1/4)·ω_mω_n | −(1/4)·Re[Z_t·Z_t] | Z_t·Z_t の合成乗算子は −ω_mω_n で実数のため、Re を取ると符号が反転することに注意 |
| −(1/4)·ω_±²（出力だけの因子） | 出力フィルタ −(ω²/4)·κ·tanh(hκ)/D_± を Re[Z·Z] に掛ける | 場の積は要らない（定数 1×1） |

- **差周波側（pm=−1）も同じ表**：上の式の pm に −1 を入れた代数形がそのまま差周波側の仕様である。場の積は第 2 の場を複素共役にした Z^μ·(Z^ν)* を使う（上記の対応規則）。pm=−1 の符号は代数形に含まれており、場の積の Re/Im の取り方は対応規則から機械的に決まる。**差周波側の展開結果は試験 0 の準備記録として残し、単色波アンカー（G-C1-0 (1)）と θ=0 での訂正 Langley 形との一致で検証する。展開を試験 0 の結果を見て変えることはしない。**
- **正規化の検証**：上の係数（B⁺ = 2h_s の 1/2 の相殺を含む）の正しさは、主張ではなく G-C1-0 (1) の単色波アンカー（相対誤差 <10⁻¹²）で検証する。アンカーが通らなければ、S1 の係数展開が誤っているとして直す。アンカーを通さずに試験 0 へ進んではいけない。**【R5 の検証記録】**本表の h_s は、一般角度（dθ ∈ {0, 0.3, 0.7, 1.2, 2.0, 3.0}）・両 pm・h=0.6/4.0 の 96 通りで、Lambda2/(2h) および B_S1/2 と **最大相対誤差 1.2e-14** で一致する。θ=0 では 2×WAFO-g²訂正版と 1.4e-14 で一致する。検証スクリプト `ref-sources/verify-s1-2d.py`（`hs_table`）。R4 の 1D 対応表（Langley P₁ 形）は θ=0 での照合用として `ref-sources/verify-2d-kernel.py` の `wafo_qtf_langley(corrected=True)` に残し、本書では重複させない。

- **対角項（m = n）は h_dii で置く（R5 でも同じ）**：差周波側の対角（ω₋ = 0）では上の式は特異になる。WAFO の h_dii（§2.1）で置き換える。h_dii が h_d の極限であることは G-C1-0 (8) で確認済み（ω₂→ω₁ の列で線形に収束）。対角項の寄与は η₂⁻_diag = Σ_m a_m²·h_dii(k_m) であり、空間一様な静的 DC 項（Δk=0、Δω=0）として別に扱う（§2.4 の静的 DC の扱いと同じ）。
- **正規化の検証**：上の係数（1/2 の相殺を含む）の正しさは、主張ではなく G-C1-0 (1) の単色波アンカー（相対誤差 <10⁻¹²）で検証する。アンカーが通らなければ、S1 の係数展開が誤っているとして直す。アンカーを通さずに試験 0 へ進んではいけない。
- **格子**：2 次式の積は線形帯域の粗格子（128²）上で評価する（LEG-GEMINI.md C2）。1.5 m パッチで Δk = 2π/1.5 = 4.19 rad/m、ナイキストは 268 rad/m であり、和波帯の上限 2k_QTF,max = **240** rad/m（R5 で訂正。テーパ [100,120] に対する和波数の上限）を覆う。3/2 則のパディングは 2 次積のエイリアシング抑制に使うが、それだけで数値誤差が除去されたことにはならない（LEG-GPT.md §7.3）。格子収束・高波数切断・低波数分解能・共鳴近傍の誤差を別途評価する。和周波と差周波の双方について、解像度を変えた収束試験を行う。
- **方向の扱い（S1 の適用範囲。R5 で変更）**：S1 の上記の式は 2D 一般角形（ベクトル内積 k_m·k_n、ベクトル和・差の大きさ κ_±）のものである。U-1 が閉じたため、**S1 を 2D 方向分散場にそのまま適用する。**試験 0 は 2D 本番場で行い、方向変化の比較（§2.3）も試験対象に含める。1D 切片への限定は解除する。
- **帯域の統一（R4 で変更。D8→F8）**：S1 が評価するペアは §2.6 の k_QTF,max ≤ **100** rad/m の内側に限る。試験 0 と本番で帯域を変えない。カットオフ関数は §2.6 の raised-cosine（[100, 120] rad/m）を使う。

**2.2.3 直交位相の作り方 — 1 方向 Hilbert は破棄する**（R2 と同じ）

- R1 の「風向きへの 1 方向 Hilbert 変換」は破棄する。理由：(a) 風と直角方向のモード（k_x=0）では sgn(0)=0 となり η̃₁=0 で位相共役が消滅する。(b) 風上向き成分（k_x<0、ω>0）が存在する場合、空間 1 方向 Hilbert は時間的共役と符号が 180° 反転し、Q₊ と Q₋ が入れ替わる（LEG-GEMINI.md C3）。方向分散した場では数学的に破綻している。
- 代わりに、**時間的解析信号の虚部**を使う。生成器は各進行波モードの複素振幅 η̂₁(k)e^(−iω_k t)（ω_k>0）を保持しているため、η̃₁(x,t) = Im Σ_k η̂₁(k)e^(i(k·x−ω_k t)) とすれば、追加コストほぼゼロで全方向 θ∈[−π,π] に厳密になる。または **2D Riesz 変換**（−i·k/|k|·η̂₁ による勾配演算）を使う。どちらを選ぶかは試験 0 の実装で決め、両方の一致も測る。
- **注意（GPT の指摘）**：方向別の直交位相を作るだけではまだ不十分である。2 次相互作用は個別モードの位相直交だけでは決まらず、モード対の和・差周波相互作用を含む。方向ごとに別々に Hilbert 変換してから 2 次式を作ると、異なる方向のモード対について、どの直交位相をどう組み合わせるかという問題が残る。したがって、時間的解析信号・2D Riesz も「QTF の高速近似の部品」であって、QTF そのものではない。標準実装は、方向を含む波数ベクトル対に依存する QTF を保持する（§2.2.1）。直交位相を使う近似は、試験 0 で QTF との一致が確認された条件に限って使う。

**2.2.4 計算手順（1 フレームあたり。R2 と同じ）**

1. **線形場を取る**：生成器から η₁(x, y, t) を取る。生成器のコードは変えない。同じシード・同じ 192 フレーム（8 s、24 fps）・同じプローブ配置（cf-0067 と同じ 256 点）を使う。η₁ はビット単位で線形のままであること（J1 で検証する）。
2. **直交位相と勾配を作る**：時間的解析信号の虚部（または 2D Riesz 変換）で η̃₁ を作る。同じ FFT の往復で勾配場 ∂xη₁、∂yη₁ もスペクトル微分で作る。1 方向 Hilbert は使わない。
3. **2 次式を作る（実空間での積）**：和周波成分のもと Q₊ = η₁² − η̃₁²、Q₊′ = 2η₁η̃₁（解析信号 Z = η₁ + iη̃₁ の Z² の実部・虚部）。差周波成分のもと Q₋ = η₁² + η̃₁²（|Z|²、包絡の 2 乗）。有限水深形のカーネルが k₁·k₂ の項を含む場合、その部分は勾配場の積（∇η₁·∇η̃₁ など）で作る。**どの積がどのカーネル項に対応するかは、§2.1 の B⁺/B⁻ の式から対応表を作る。対応表は試験 0 で検証する。**
4. **カーネルを k 空間のフィルタとして掛ける**：各 2 次式を FFT し、§2.2.2 の候補 S1 の対応表に従って出力波数 k に対してカーネル因子を掛ける。**k_p 一点での評価はしない。**分離形の具体式は §2.2.2 で固定済みであり、試験 0 の結果を見て変えることはしない。ペアの帯域は §2.6 の k_QTF,max ≤100 rad/m で切る。対角項（m = n）の差周波寄与は h_dii で別に扱い、静的 DC 項として分離する（§2.2.2）。
5. **実空間に戻す**：IFFT で η₂⁺、η₂⁻ に戻す。**パッチ平均の除去はここではしない。**平均水位の扱いは §2.4 で決める（診断用の静的 DC 項だけを除く）。
6. **場を足す**：η = η₁ + η₂⁺ + η₂⁻。勾配・曲率は η からスペクトル微分で作り直す。η₂⁺ と η₂⁻ は診断として別キーで残す（§5 の J5）。
7. **プローブで出す**：cf-0067 と同じ 256 プローブ・同じ 192 標本で η、η₂⁺、η₂⁻ をサンプリングし、同じ npz 形式（キー eta/gx/gy/lap/t）で出す。検証の道具（歪度・尖度・QD・峰高・バイコヒーレンス）は cf-0085 と同じ定義・同じ車線で回す。

**エイリアシングの扱い**：2 次式の積は、同じ格子で計算すると高波数成分が折り返す。3/2 則のパディング（積を作る前に場を 3/2 倍の格子へ広げ、積の後に元の格子へ戻す）で除去する。これは大原則の (a)「中立な数値手法」であり、物理の主張ではない。ただし 3/2 則だけでは、格子収束・高波数切断・低波数分解能・共鳴近傍の誤差は除去できない（§2.2.2）。

**計算量の見積もり（推測。実測ではない。R2 と同じ）**：1 フレームあたり FFT 8–10 回（2048²）で 2–4 秒、8 s 記録 1 本 400–800 秒、P5・5シードで 35–65 分。見積もりは推測であり、実装ジョブの最初の 1 記録で実測して確かめる（§5 の J7）。**試験 0 は縮小モード集合（M=256–512）での直接二重和なので、計算量は小さく、最初に回す。**

**大きさの事前見積もり（P5、解析式から。実測ではない。R2 と同じ）**：
η₂⁺ の標準偏差は k_p·σ_η² ≈ 14.15 × (0.0059)² ≈ 4.9×10⁻⁴ m で、線形 σ_η の約 8%（a₂/a₁ = 8.3% と整合する）。足される分散は (0.083)² ≈ 0.7%。勾配への寄与は波数が 2 倍になる分だけ大きく、ピーク急峻度 ε = 0.17 から勾配場への 2 次の寄与は振幅比で約 17% になる見込み。つまり「高さでは小さく、勾配・曲率では無視できない」というのが、この設計の効き方の見立てである。実測で確かめる（J2b・J5）。

**誤差の定義（R3 で書き直し。D1 の直し）**：m2・m4 の誤差は総場では測らない。
R2 の線（総場の m2 ≤3%・m4 ≤10%）は、P5 の物理変化そのもの（Δm₂/m₂ ≈ 2.8%、
Δm₄/m₄ ≈ 11.2%）と近似誤差を分離できない。特に総場 m4 ≤10% は、η₂ の寄与を
ほぼ取り違えた近似でも通ってしまう（LEG-GEMINI.md D1）。
R3 では増分で定義する：Δm_j ≡ m_j(η₁+η₂) − m_j(η₁)（j = 2, 4）を A・B それぞれで
計算し、誤差は |Δm_j(B) − Δm_j(A)| / Δm_j(A) とする。これは「物理予測（A）を
別途計算し、近似誤差のみを見る差分線」である（LEG-GROK.md D1）。

**分母が不安定な場合の切替条件（R4 で事前登録。LEG-GPT.md F1）**：Δm_j(A) が
小さいと相対誤差の分母が不安定になり、符号反転・ゼロ近傍では合格線自体が
意味を失う。次の場合、相対誤差による判定は行わず、絶対誤差による判定に切り替える。
切り替えの条件と絶対誤差の線は、試験 0 の着手前に本項で固定する。
- **期待増分比の導出（R5 で文書化。G1 の直し）**：P5 の 2 次 Stokes 振幅比 a₂/a₁ = 8.3%（§0）より、η₂ の分散比は (0.083)² ≈ 0.7%。和周波成分は線形の約 2 倍の周波数に載るため、m₂（ω² 重み）への寄与は約 2² = 4 倍、m₄（ω⁴ 重み）への寄与は約 2⁴ = 16 倍になる。したがって Δm₂/m₂ ≈ 4×0.7% = **2.8%**、Δm₄/m₄ ≈ 16×0.7% = **11.2%**。これは桁の見積もりであり、実際の増分は試験 0 の参照計算 A から出す。見積もりは切替敷居と絶対誤差の線を決めるためだけに使い、合否の線そのものには使わない。
- 切替条件：Δm_j(A) ≤ 0（符号反転・ゼロ）の場合、または |Δm_j(A)|/m_j(η₁) が
P5 の物理増分の期待値の 1/10 未満の場合。期待値は上の導出より Δm₂/m₂ ≈ 2.8%・
Δm₄/m₄ ≈ 11.2% であり、切替の敷居は m₂ で 0.28%・m₄ で 1.12% とする。
- 絶対誤差の線：|Δm_j(B) − Δm_j(A)|/m_j(η₁) ≤（J0 の相対線）×（P5 の期待増分比）。
m₂：2% × 2.8% = **0.056%**、m₄：7% × 11.2% = **0.784%** とする。
- **符号反転は自動失敗**：増分誤差が合格線の内側でも、Δm_j(A) と Δm_j(B) の
符号が逆転している場合は不合格とする（LEG-GPT.md F1 の失敗条件）。
分母が小さいことを理由に相対誤差の発散したケースを恣意的に除外してはならない。
- **J0 と J2b は別ゲートである（R5 で明記。G1 の直し）**：J0 は「参照計算 A と分離形 B の数値実装一致」を測るゲートであり、比較対象は A と B の 2 つだけである。J2b は「QTF 予測と合成場の物理統計の一致」を測るゲートであり、比較対象は参照 QTF の予測する変化量 Δ_ref と合成場の実測変化量 Δ である。J0 の数値は 2D P5 場の数字であり、1D 切片の数値と混在させない（R5 で試験 0 は 2D 本番場へ戻したため、混在は解消した）。J0 を通った分離形が J2b で落ちることは、実装誤差ではなく物理予測との不一致であり、別の失敗として扱う。

**対象の定義（R4 で固定。LEG-GPT.md F1）**：

（低振幅領域だけを分母に取るなど、不適切な分母での計算はしない）。

## 抜粋 6：§2.6 表面張力と帯域

### 2.6 表面張力と帯域 — QTF の物理モデルの整合（D8 の直し。新設）

**問題の所在**：生成器は重力＋表面張力の分散関係を使う。一方、§2.1 の QTF は
純重力波の相互作用係数である。表面張力は分散関係だけでなく、自由表面の
力学的境界条件（圧力跳躍）にも入る。したがって **QTF 側の ω(k) だけを毛管側に
合わせても、物理モデルは一致しない**（LEG-GPT.md D8）。R2 の扱い
（「QTF の ω には生成器と同じ分散関係を入れる。近似として認める」）は、
近似であることの明記としては残すが、整合の主張としては使わない。

**当面の仕様（R4 で固定）**：

1. **帯域の統一**：QTF の入力側に滑らかな高波数カットオフを適用し、**k_QTF,max ≤ 100 rad/m** を試験 0 と本番の両方で使う（LEG-GEMINI.md F8 の提案。R3 の 150 から引き下げる）。試験 0 で除外して合格した実装を、本番で除外帯まで動かすことはしない。カットオフの根拠は、毛管項が有意になる帯域と Wilton 共鳴（k ≈ 260 rad/m）を QTF の適用外に置くことである。毛管項比 (σ/ρ)k²/g は k = 100 rad/m で **7.4%**、k = 120 rad/m で **10.7%**、k = 150 rad/m で **16.7%**、k = 200 rad/m で **29.7%**、k = 240 rad/m で **42.7%**（σ/ρ = 7.28e-5 は cf-0075 の確定値。数値検証済み）。**2k_max = 240 rad/m < 260 rad/m で、Wilton 和共鳴を構造的に回避する**（LEG-GEMINI.md F8。R4 の 200 は誤りで、テーパ [100,120] に対する和波数の上限は 240 である）。カットオフ関数は **raised-cosine（[100, 120] rad/m で 1→0）**として固定する（事前登録の設計選択である）。**フェーズ 1 は「入力ペアは重力帯」として限定する**：出力側（和波数上限 240 rad/m）では毛管項比が 42.7% に達するため、出力側の毛管汚染は帯域別に報告し、重力帯として主張しない。高波数側では毛管項が重力項を大きく上回る（k = 1000 rad/m で毛管項は重力項の約 7 倍。LEG-GROK.md D8）。なお生成器の線形場そのもの（k_cut = 1000 rad/m）は変えない。切るのは QTF のペア評価の入力側だけである。
2. **m4 の 2 本立て報告**：m4 は「全帯域 m4」と「QTF 帯域（k ≤ k_QTF,max）の m4」の 2 本立てで測って報告する（LEG-GEMINI.md D8）。除外帯（k > k_QTF,max）が全 m2・m4 に占める割合を定量して併記する。
3. **除外帯の失敗線**：除外帯の線形エネルギーが全エネルギーの **5% 超**なら失敗とする（LEG-GROK.md D8）。P5 の実測では除外帯の線形エネルギー比は 0.51%（cf-0069 §8.1）なので、この線は自動失敗にはならない。**【R5 の再確認】**0.51% は **k>100 rad/m で測ったもの**（seed 1、1実現状態の |H0|²、量子化 ω。P5 の m0 シェア：100–300 帯 0.005、300–∞ 帯 0.001（丸め値）。合計の精密値は 0.51% と本文 §6.4 に記載）であり、k>150 からの流用ではない。Gemini の懸念は原文確認で解消した。ただし seed 1・1実現の値であること、テーパ重み付きの除外エネルギーは 0.51% 以下になること、失敗線 5% には十分余裕があることを明記する。**R3 にあった「除外の前後で m4 が 10% 以上変われば失敗」は削除する（LEG-GEMINI.md F8）。**m4 の大部分が k>150 側（R4 では k>100 側）にあるため、この線はほぼ自動失敗になる。代わりに、**QTF 帯域の m4 変化率と全帯域の m4 変化率を分離報告し、全帯域 m4 の主張には毛管側を合算するまで留保を付す**（LEG-GEMINI.md F8）。除外帯の m4 寄与が **1% 超**なら、全帯域 m4 の合格を主張しない規則は残す（その場合は QTF 帯域の m4 を検証済みの量として報告する。LEG-GPT.md D8）。Elfouhaily スペクトルではこの規則は事実上常に発動し、全帯域 m4 の主張は最初から留保される。
4. **Wilton 共鳴はペア単位で扱う**：Wilton 共鳴は単一の波数カットオフでは判定できず、相互作用する波数ペアの関係で評価する（LEG-GPT.md D8）。ペア (m, n) ごとに、和成分 (k₊, ω₊) と差成分 (k₋, |ω₋|) が毛管重力の分散関係の自由波条件にどれだけ近いか（相対離調）を測り、共鳴近傍のペアを通常の QTF 評価から分離して記録する。非対称な和共鳴（例：k₁ と k₂ の組合せで分母がゼロを跨ぐ場合）もこの検出で拾う（LEG-GEMINI.md D8）。**相対離調の閾値は |ω₁±ω₂−ω(k₁±k₂)|/ω_± < 0.05 に固定する（LEG-GEMINI.md F8・LEG-GROK.md F8 の例示値）。分離したペアの扱いは「除外＋寄与報告」とする（件数と m₂／m₄ への寄与を記録する）。**粘性による正則化はフェーズ 2 の代替案として記録のみとし、フェーズ 1 では使わない。**【R5 での固定（G8 の直し）】**閾値 0.05 の根拠：相対離調 δ=0.05 では分母 D± ≈ 2δ·ω² ≈ 0.1·ω² となり、非共鳴時の約 1/10 に縮んで応答が約 10 倍に増幅される領域を「共鳴近傍」として分離する事前登録の設計選択である。由来は LEG-GEMINI.md F8・LEG-GROK.md F8 の例示値で、物理定数ではない。**分母は max(|ω±|, ω(k±)) へ修正し、ω₋→0 でのゼロ除算を防ぐ。**
5. **表面張力の扱いは 2 経路のどちらかで閉じる**：
   - **経路 A（導出）**：表面張力を含む QTF を導出する。力学的境界条件に表面張力の曲率項を含め、相互作用係数と共鳴分母 D± を毛管重力の分散関係で組み直す。**本書では導出しない（§6 の U-3）。経路 A はフェーズ 2 の必須経路である。着手期限は「P5 試験 0 の判定（J0–J7）の着地時。遅くともフェーズ 2 の開始前。期限を過ぎても未着手ならフェーズ 2 は開始しない」と明示する（R5 で追加。G8 の直し）。**
   - **経路 B（独立参照との比較）**：単色波ペアについては、毛管重力の Stokes 2 次解を独立参照としてアンカー照合する（式の転記は実装ブリーフ時に行う）。**一般ペアの参照として経路 B は採用しない（LEG-GPT.md F8・LEG-GROK.md F8）。**単色アンカーだけでは一般ペアを確定できないためである。一般ペアについては経路 A 待ちとする。**フェーズ 1 は重力帯（k ≤ 100 rad/m）に厳密限定し、毛管重力 QTF はフェーズ 2 の前提として残す。**
   - どちらの経路も閉じるまでは、純重力 QTF に生成器の (k, ω) を入れた計算は**「近似」として記録し、物理的に整合したと主張しない**。
6. **呼び方の規律**：k_QTF,max で切った試験 0 は「QTF 帯域の検証」と呼ぶ。全帯域の検証とは呼ばない（LEG-GPT.md D8 の同旨）。
