# ラリー第2ラウンド — 粒層設計 v4-2.11 の改訂判断

あなたは敵対的レビュアーである。前ラウンドの裁定を前提に、新しい実測で設計の残りを攻撃せよ。同調は不要。各主張に STANDS / WEAKENED / WRONG のいずれかを付け、理由と「判定が変わる条件」を書け。

## 確定済みの土台（再論争しない）
- プロジェクト原則：自然を再現する。「それっぽい」は理由にならない。数値手段は中立な誤差形か実在の物理に対応する場合のみ可。
- 前ラウンド全会一致：facet（粒の平面）が H を上げる経路は逆（撤回済み）。歪度の緊張は実在（Sk は独立チェック）。
- 旧来の比較「うちの H_fit 0.29 vs Nikora 0.79」は同尺でなかった（監査で確定）。0.79 は subgrain 帯（解像度下限〜折れ≈D50）の値であり普遍定数でもない（球充填床では同手順で 0.94）。

## 新しい実測（v4-2.12B、今回の入力）
既存の生成床3面（パッチ 0.6 m、帯状 r1・r2 各 3.0 m、D50 36–38 mm、格子 0.293 mm）を Nikora 手順（軸カット、折れ適応フィット、折れ探索窓 [0.25, 2]×D50、第2区間は折れ〜4×D50）で測り直した。
- 再現ゲート：旧物差しの既報6値は差 0.0 で再現。r2 は seed 再生成＋メタ28項目全一致＋同一性ゲート差 0.0 で本物と確認。
- **H_Nikora：パッチ x 0.448 / y 0.432、r1 x 0.435 / y 0.438、r2 x 0.436 / y 0.440。** 折れは 10–18 mm（0.26–0.49×D50）。6本中5本で折れが探索窓の下端（0.25×D50）に張り付いた。別読み（第2区間をラダー末端まで）では 0.38–0.44（最大 −0.05）。折れ位置の感度は ±0.013 以内。
- **H_loc は全ラグで最大 ≈0.49（最小ラグ 0.293 mm で最大）。どのラグでも 0.5 を超えない。**
- 床の現状値：σz/D50 は 0.39–0.46（実測装甲床の帯域内）、歪度はパッチ +0.61（帯状は −0.06 / +1.00）、装甲比 ≈1.9。粒は滑らかな楕円体。
- 合成充填テスト（パッチ、priority-flood、δ = 0.5σz）：ΔH_fit 最大 **+0.037**（事前予測 ≤+0.10 どおり）、ΔH_Nikora は最大 **+0.015**。δ=0.75σz でも ΔH_fit +0.055 が上限。
- 文献調査（filleting）：谷埋めの楽観的上限でも +0.05–0.15、交点は帯域の下にあり主因にはならない。Nikora 系譜で H が上がったのは細粒の「除去」（winnow）と再配置・圧密であって追加ではない。Mao 2011 の細粒充填での Hx 上昇は 0.1 級（0.45–0.60 の範囲内）で圧密と分離不能。

## 主張（K1–K7）
- **K1**：差は実在する。同尺（Nikora 手順）でも 0.43–0.45 vs 0.79。したがって「粒層そのものを変える」という改訂設計の目標は維持される。折れの窓下端張り付きは H_Nikora の定義を曖昧にするが、別読みでも差は縮まらない（むしろ広がる）。
- **K2**：充填／filleting は H の機構として失格。合成充填の実測（ΔH_Nikora ≤ +0.015）と文献調査が独立に一致した。設計の機構Bの「ポケット細粒充填」成分と候補C（filleting）は削除すべきである。
- **K3**：次の主犯候補は粒径以下のスケールにある。うちの床は H_loc が全ラグで 0.5 を超えない（滑らかな楕円体の重ね合わせの上限の署名）。実床が subgrain 帯で 0.79 に達するなら、不足は粒表面の mm スケールの凹凸・角張り（うちの粒に無いもの）にある可能性が、winnow や planation より先に立つ。
- **K4**：winnow＋interlock（機構A）は依然として本命たりうる。ただし留保：うちの床は既に装甲比 ≈1.9・σz/D50 帯域内・パッチ歪度 +0.61 を持ちながら H_Nikora 0.44 に留まる。文献でも winnow による上昇は 0.45–0.60 の範囲の報告が中心で、0.79 への到達は未実証。A 単独の到達見込みを数値で述べよ。
- **K5**：planation（粒頭の選択的除去、B-2b）は H の機構としては落とすべきである。前ラウンドで facet 経路は死に、削るだけでは歪度は下がる方向。充填（K2）が死んだ今、planation に H を上げる経路は残っていない。σz・歪度の調整役への降格が妥当。
- **K6**：物差しの固定：床 H の物差しは今回の Nikora 手順の実装（折れ窓 [0.25, 2]×D50、第2区間 折れ〜4×D50、軸カット、Hx/Hy 別記）に固定し、値は常にこの定義つきでのみ語る。実測 DEM 到着後のキラーテストも同じ物差しで参照側と生成側を測る。窓依存（別読みで最大 −0.05）は開示として併記する。
- **K7**：次の一手の順序：bed_gen3 の機構実装の前に、最小実験で K3 を殺しに行く。粒に mm スケールの表面凹凸／角張りを足した最小の床を1面だけ作り、H_Nikora と subgrain 帯の H_loc を測る。H_loc が 0.5 を超えて動かなければ K3 は死に、機構Aの実装に戻る。逆に動けば設計の主軸を粒形状へ移す。

## 回答形式（固定）
