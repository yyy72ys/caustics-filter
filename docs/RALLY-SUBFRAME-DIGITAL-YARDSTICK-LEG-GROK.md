最終裁定: 差し戻し

K1 物理的根拠: 条件付き成立（設計の再考）

(i) 「発散しても有限に定まる」は測度論的には正しい方向だが、「格子の切り方に依らず定まる」ことと同義ではない。メモは「fold 近傍で {C > T} の面積は、強度が d^(−1/2) で発散しても有限に定まる（発散点の近傍の測度は有限）。モーメントではなく集合の測度なので、§1.3 の特異性の問題を受けない」（§3 D1 (b)、56–63 行付近）と述べるが、有限性と格子独立性を同一視している。有限測度であることと、離散格子上の画素カウントが格子細分化に対して安定であることは別問題であり、境界画素の出入り（同所 (e)）がその差を直接示す。
(ii) D2 の弱収束言及は存在定理の流用に近い。「分布の弱収束はモーメントの収束より弱い条件で成り立ち、fold 特異性を持つ分布でも有限の測度として定まる」（§3 D2 (b)）は正しいが、「到達可能な 2 格子間で段間差が小さい」ことを保証しない。弱収束は連続テスト関数に対する収束であり、固定ビンの経験測度差が自動的に小さくなるわけではない。
(iii) D3 は「対象のずれが『大』」（§4 比較表および §3 D3 (e)）と自ら認めつつ代替候補に並べており、正直さに欠ける。
(iv) D4 は既存 G-ENERGY の再掲であり、候補の水増しに見える。「単独では G-CONV の代替にならない。位置づけは『土台の監査』」（§3 D4 (e)）と書いている以上、独立候補として同列に置くのは過剰。
(v) 「数値的に中立でもある」は (a) 中立数値と (b) 物理対応の混線。D1 は物理対応を主に主張しているのに、中立性を補強語として使っている。
条件は「D3 を代替候補から外し補助監査に格下げする」「有限性と格子独立性を分離して書き直す」「弱収束を安定性の根拠に使わない」で、設計の再考側。

K2 有限性・厳密さ: 不成立

(i) 397,440 の 0.5% は 1,987.2、1% は 3,974.4。メモの ±1,987／3,974 は切り捨てであり、丸め規則（切り捨て固定か、四捨五入か、偶数丸めか）が明示されていない。整数判定を標榜する以上、丸め規則は事前登録必須。
(ii) 「移動画素数が整数になる」理屈は正しい（総画素数が等しいため Σ|差| は偶数となり、1/2 で整数になる）。出力格子固定（736×540）は引用範囲から一意に取れる。ここは成立。
(iii) 境界画素の揺れが未実測の段階で「厳密に決まる」とは言えない。§7 の「初回は実測として段間差を取る」扱いは正しいが、揺れ幅の事前見積もりなしに「個数幅はこの揺れより大きく」（D1 (e)）と書いている点が矛盾。
(iv) D3 連結成分数が「跳ぶ」ことを認めつつ完全一致を要求し得るとするのは、判定が返らない構造の再演。メモ自身が「折り目の合体・分離が起きる境界条件では連結成分数が跳ぶことがある」（§3 D3 (e)）と書いている。
(v) D4 は相対誤差（実数）を判定量に含み、要件 (i)「判定量が整数のカウント（または整数から作る量）」に適合しない。
全体として整数厳密性の主張が部分的に崩れているため不成立。

K3 対象変更の正当性と切り分け: 条件付き成立（書けば直る）

(i) G-CONV の定義は「同じ出力格子へ堆積した C の std と p99 の差が 15% 以内」（確定前提）。保証対象は明示的に std・p99 であり、「分布全体」ではない。メモの「G-CONV が本来保証しようとしたのは『C の水準・分布が格子に依らないこと』」（§5）は定義を超えた解釈。一次資料定義に従えば std・p99 の格子非依存が正しい読み。
(ii) G-PEAK が同じ std・p99 比でサブ枠 PASS しているのに触れていない点は切り分け不完全。同じ問題を抱える既存ゲートへの影響を明示する必要がある。
(iii) std・p99 を使っている既存用途の洗い出しなしに「別途立てる」で済ませるのは不十分。
(iv) 対象変更の根拠が「解釈上の疑い（実測ではなく推論として明記する）」（§1.3）のままでは弱い。正則化（有限太陽円盤・回折）を入れた場合に std が定まるかの確認は次段に要る。
条件は「G-CONV の保証対象を定義どおり std・p99 と明記し、分布全体への拡張は別主張として分離する」「G-PEAK 等既存ゲートへの影響を洗い出す」で、書けば直る側。

K4 却下 X1・X2: 条件付き成立（書けば直る）

(i) X1 は要件 (i)(iii) を最も強く満たす。代替ではないが「併用の必須監査」への格上げは検討に値する。メモは「回帰検出用の補助には使える」と認めている。
(ii) X2 の順位統計（分位点）は分布の測度に近く D2 と地続き。一括却下は D2 自身の根拠を弱める。「測る対象を変えずに甘くする方向の案」と一緒に外している点が粗い。分位点ベースと D1 の境界（閾値 T による超域カウント）は連続的であり、明確な線引きが必要。
(iii) 「甘くする案は検討対象外」の一括扱いは、個別に却下理由を書くべき案まで外している可能性がある。
条件は「X1 を必須監査として位置づけ直す」「X2 の分位点案を D2 の近縁として再検討し、却下理由を個別化する」で、書けば直る側。

K5 第一候補 D2+D1 と幅の順序: 不成立

(i) ビン境界の恣意性への対処（感度確認）が §7 の手順に明記されていない。組み込むべき。
(ii) D1・D2 が空間配置を見ない点は G-CONV も見ていなかったので、置き換えで新たに失うものではない読みは正しい。
(iii) §7 手順2「数表を見て幅を決める」と §6「結果を見てから幅を決めると甘くする行為になる」は紙一重。両者を分ける規律（例: 幅の候補を実測前に複数事前登録し、実測後にその中から選ぶだけにする、など）が検証可能に書かれていない。段間差が案を超えた場合の扱いも書かれていない。
(iv) 対比枠の校正が FAIL した場合の手順がない。
(v) 実測段の時間見積もりは一次資料速度との照合が引用範囲になく「引用未確認」。
幅決定の順序と規律が破綻しているため不成立。

K6 最終主張: 不成立
K1–K5 を総合すると、物理的根拠の混線、整数厳密性の穴、対象変更の定義逸脱、幅決定手順の甘さ防止規律の欠如が残る。これらは「書けば直る」部分（定義の明記、X1 格上げ、感度確認の手順追加）と「設計の再考」部分（D3 の位置づけ、有限性＝格子独立性の分離、弱収束の使い方、幅決定の事前規律）が混在しており、現設計のまま次段（直し→確認）へ進める状態ではない。差し戻しが妥当。
