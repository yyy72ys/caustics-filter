## 1. 目標の定義 — 「2 次が入った」とは何か

### 1.1 目標は「場が 2 次の指紋を持つこと」である（合否の土台は R2 と同じ）

**T1 — 「2 次が入った」とは、線形場 η₁ に 2 次束縛波 η₂ を §2 の手順で
足した場 η = η₁ + η₂ が、§5 のゲートを通ることである。**
見た目や「群れらしくなった」という印象は判定に使わない。
判定は歪度・バイコヒーレンス・峰高分布の 3 つのゲート量で読む。
ゲートの土台は cf-0085 の実測値（下の表）で、同じ定義・同じ車線
（プローブ中央値車線、cf-0085 §2 の定義）で測り直す。
**PASS には J1・J2a・J3'・J4' に加えて J0（試験 0 の QTF 一致）が必須**である。
バイコヒーレンスだけでは「正しい QTF を実装した」ことの証明にならないため、
J0・J3'・J4' の 3 つがそろって初めて「2 次が入った」と言う。
**R3 での変更**：J0 の合格線は η₂ 増分基準へ定義し直し、J2b の許容幅は
事前登録済みの数値になった（§2.3、§5）。線の内側・外側の言い方だけが変わり、
ゲートの構成は R2 と同じである。

### 1.2 目標値の置き方 — 解析の目安はゲートにしない（R2 と同じ）

**T2 — NOTE §8 の歪度目安（P5 ≈ 0.25）は上限寄りの目安であり、
ゲートの線にはしない。** 狭帯域・深水・一方向の式からの値で、現実の場は
広帯域＋方向分散なので実値は下がる。目安を予測値として読んではいけない
（NOTE §10）。ゲートの線は、参照 QTF からの計算値 λ₃,exact と実測の
ばらつきから引く（§5 の J3'）。
広帯域＋方向分散での目減りの大きさは、実測風波（Forristall 等）で
概ね狭帯域値の 50–85%（LEG-GEMINI.md C6）。P5 の期待範囲は λ₃ ≈ 0.12–0.22。
**R3 での変更**：λ₃,exact は §2.1 で転記した厳密カーネル（Langley 形）で、
生成器と同一の離散格子上で計算する（§5 の J3'）。近似カーネルで計算した値を
λ₃,exact とは呼ばない。目安との比（実測が目安の何割か）は報告するが、
合否には使わない。

### 1.3 T3' — 「スペクトル不変」は前提ではない（R2 と同じ）

**T3' — 2 次を入れると、合成場 η = η₁ + η₂ のスペクトルは動く。
それは物理的な 2 次補正が働いた結果であり、実装の誤りではない。**
R1 の T3（「ν・GF はほとんど動かないことが前提」）は強すぎた。
2 次束縛波は和周波・差周波に新しい成分を作る。その成分には分散があり、
線形場と 2 次場の相関もある。したがって合成場のスペクトルが変わること自体は、
物理モデルが働いた結果として当然に起こり得る。
**変わらないのは線形場 η₁ の方である**（J1 の SHA256 で保証する）。
合成場の統計の変化は、それ自体を実装誤りと判定せず、参照 QTF の予測と
照合する（§5 の J2b）。予測と合わない変化だけが、物理的 2 次寄与と
数値誤差・重複計上を分離して判定する対象になる。
**R3 での変更**：J2b の「予測と一致する」の幅は、R2 では未定義だったが、
R3 では §5 に事前登録した数値で判定する（D5 の直し）。

**記号規約（本書で固定する。転記ミスの罠を塞ぐための定義）**：

- 線形場のモード m は振幅 a_m、波数ベクトル k_m、角周波数 ω_m > 0、位相 θ_m = k_m·x − ω_m t + ε_m を持つ。
- 2 次場は二重和で定義する（R1・R2 と同じ定義。1/2 の前因子を含む）：
  η₂(x,t) = (1/2) Σ_m Σ_n a_m a_n [ B⁺_{mn} cos(θ_m+θ_n) + B⁻_{mn} cos(θ_m−θ_n) ]
- ペア (m, n) に対し：ω₊ = ω_m+ω_n、ω₋ = ω_m−ω_n、k₊ = |k_m+k_n|、k₋ = |k_m−k_n|、k_m·k_n は波数ベクトルの内積。h は各条件の水深（P1 0.6 m／P5 4.0 m／SWELL 4.0 m）。
- **WAFO の規約との対応（転記ミスの罠）**：WAFO の `qtf` は 1/2 を付けず η₂ = ΣΣ a_m a_n [h_s cos(θ_m+θ_n) + h_d cos(θ_m−θ_n)] と定義するため、**B⁺ = 2h_s、B⁻ = 2h_d** である。WAFO の数値をそのまま B⁺/B⁻ に読んではいけない（2 倍ずれる）。下記の転記は WAFO の h_s／h_d の形のまま書く。B への換算は ×2 である。
- **WAFO 内部の記号**：WAFO は 2 つのモードを (w_1, k_1)・(w_2, k_2) と書き、w12 = w_1·w_2、w1p2 = w_1+w_2、w1m2 = w_1−w_2、k12 = k_1·k_2、k1p2 = k_1+k_2、k1m2 = |k_1−k_2| と置く。k_1・k_2 は θ=0 の符号付き波数で、k は純重力の分散関係 ω² = gk·tanh(kh) から決まる（WAFO の `w2k`）。本書の (m, n) との対応は、1 次元切片では ω_m ↔ w_1、ω_n ↔ w_2、k_m ↔ k_1、k_n ↔ k_2 である。
- **ω の出所の食い違いは隠さない**：カーネル式の前提は純重力の分散関係である。一方、生成器のモードの ω_m は重力＋毛管の分散関係から決まる（cf-0075 で確認済み）。ペア評価に生成器の (k_m, ω_m) をそのまま入れると「純重力 QTF に毛管の ω を入れる」近似になる。この不整合は §2.6 で扱う。転記した式の内部では、ω と k は純重力の分散関係で結ばれているものとして読む。

**深水極限（h → ∞。WAFO の h=inf 分岐と一致。検証のアンカーになる。R2 と同じ）**：

- B⁺_∞ = (|k_m|+|k_n|)/2、　B⁻_∞ = −||k_m|−|k_n||/2
  （WAFO の形では h_s = 0.25·(|k_1|+|k_2|)、h_d = −0.25·||k_1|−|k_2||、対角 h_dii = 0）
- 1D・同方向では B⁺_∞ = (k_m+k_n)/2、B⁻_∞ = −|k_m−k_n|/2。
- 単色波（m = n = k）では B⁺ = k、B⁻ = 0 となり、Stokes 2 次高調波 (1/2)ka² と一致する。これが深水極限のアンカーである。

**厳密形 — Langley 形（WAFO `qtf` の Langley 分岐から転記。R3 で新規）**：

WAFO の補助量をそのまま使う（添字は WAFO の w_1・w_2 記法）：

- P₁ = [ −2·w1p2·(k12·g² − w12²) + w_1·(w_2⁴ − g²·k_2²) + w_2·(w_1⁴ − g²·k_1²) ] / (4·w12)
- **⚠ P₁ 第3項は未確定であり、R3 の転記は原文と食い違う疑いが強い（R4 で格下げ）**：R3 は「写しで `g * 2.` と読める箇所があった」ことを記録した上で、次元整合性から `g²·k_1²` と読んで転記した。R4 で検索インデックス経由の複数クロール（コミット d308357c・f8dfd57a・dc309453・48e9b777・8ba9e7e1、5件が一致）を取ったところ、原文は `w_2 * (w_1 ** 4 - g * 2. * k_1 ** 2)` と読める。`2g·k_1²` の次元は 1/(m·s²) であり、同じ括弧の中の w_1⁴（1/s⁴）と合わない。P₁ の分子の他の項はいずれも 1/s⁵ で揃っている。つまり **原文のままでは P₁ は次元不整合であり、WAFO の Langley 分岐はこの1項が壊れた死蔵コードである疑いが強い**。R3 の `g²` 読みは次元を合わせるための推論による修正であり、原文の確定ではない。**本書の P₁ 式は、G-C1-0 の手順 (a)（原文ファイルの直接読み）で確定するまでの暫定形とする。**G-C1-0 (a) で `g * 2.` が確認されれば、WAFO Langley 分岐は参照として使えず、参照は Langley (1987) 原著または独立導出（Kaihatu & Kirby 2005 等）から取り直す（§6 の U-2）。P₁ 第3項を推論で確定したまま試験 0 の参照計算に使うことは禁止する。
- P₂ = w1p2²·cosh(k1p2·h) − g·k1p2·sinh(k1p2·h)
- **h_s = −(P₁/P₂)·w1p2·cosh(k1p2·h)/g − (k12·g² − w12²)/(4·g·w12) + (w_1² + w_2²)/(4·g)**
- P₃ = [ −2·w1m2·(k12·g² + w12²) − w_1·(w_2⁴ − g²·k_2²) + w_2·(w_1⁴ − g²·k_1²) ] / (4·w12)
- P₄ = w1m2²·cosh(k1m2·h) − g·k1m2·sinh(k1m2·h)
- **h_d = −(P₃/P₄)·w1m2·cosh(k1m2·h)/g − (k12·g² + w12²)/(4·g·w12) + (w_1² + w_2²)/(4·g)**

- **対角項（m = n。h_d の対角は P₃/P₄ の式では置かない）**：w1m2 = 0 では P₃/P₄ の形は特異になる。WAFO は h_d の対角を別式 h_dii で置き換える：
  - 群速度（純重力）：c_g = (g/(2w))·[ tanh(kh) + kh·(1 − tanh²(kh)) ]（k・w はそのモードの値）
  - **h_dii = (1/2)·{ [ (1/2)·g·(k/w)² − (1/2)·w²/g + g·k/(w·c_g) ] / (1 − g·h/c_g²) − (1/2)·k/sinh(2kh) }**
  - WAFO は h_d の対角成分を h_dii で上書きし、h_dii の NaN（ゼロ除算由来）は 0 に置く。本書もこの扱いを仕様とする。深水では h_dii = 0 で、B⁻(k,k) = 0 と一致する。
- **数値安全な評価形（恒等変形。転記した式と代数的に等しい）**：P₂ = cosh(k1p2·h)·D₊、P₄ = cosh(k1m2·h)·D₋ と書ける。ただし D± = ω±² − g·k±·tanh(k±h) は R2 で記録した共鳴分母そのものである。したがって第 1 項は
  - h_s の第 1 項 = −P₁·w1p2/(g·D₊)、　h_d の第 1 項 = −P₃·w1m2/(g·D₋)
  と cosh を消した形で評価できる。cosh/sinh の生評価は禁じる（R2 の Gemini 条件：P5・2048² 格子では kh > 710 に達し float64 でも Inf/Inf = NaN で全滅する）。h_dii の k/sinh(2kh) も指数減衰形 2k·e^{−2kh}/(1 − e^{−4kh}) で評価する。安全形と原形の一致は G-C1-0 の項目 (7) で確認する。
- **方向への一般化は未確定であり、1D 転記からは原理的に復元できない（R4 で明記）**：WAFO の `qtf` は 1D（θ=0）である。1D（θ=0）ではベクトル内積 k₁·k₂ とスカラー積 k₁k₂ が完全に縮退するため、(k₁k₂−k₁·k₂) のような方向交差項が 1D 式から原理的に消滅しており、1D 転記から 2D カーネルを一意に復元できない（LEG-GEMINI.md F2）。本書の k_m·k_n（ベクトル内積）、k±（ベクトル和・差の大きさ）という読みは、θ=0 切片でのみ転記と一致する方向一般化の**仮説**であり、転記の一部ではない。**この仮説を試験 0 に入れて「通ったから確定」とすることはしない**（Grok の案は採用しない。通った瞬間に確定仕様になる危険があるため）。閉じ方は、Sharma & Dean (1981) または Langley (1987) 原著／Kaihatu & Kirby (2005) から 2D 一般角形（一般交差角 θ₁₂）の厳密有限水深式を本文へ確定転記すること（§6 の U-1）。それが済むまで、試験 0 の適用範囲は 1D 切片（同一方向ペア、θ₁₂=0）に限定し、方向変化の比較は試験対象外とする（§2.3）。一般化を仮定したまま実装へ進んではいけない。

**近似形 — M&W 有限水深形（WAFO `qtf` の Marthinsen & Winterstein 分岐。比較用に格下げ）**：

R2 で転記した形（B = 2h に換算済み）をそのまま置く：

- T₁ = (1/2)·g·(k_m·k_n)/(ω_m·ω_n)
- T₂⁺ = (1/4)·(ω_m²+ω_n²+ω_m·ω_n)/g
- T₂⁻ = (1/4)·(ω_m²+ω_n²−ω_m·ω_n)/g
- B⁺ = 2·[ (T₁ − T₂⁺ + (1/4)·g·(ω_m·k_n²+ω_n·k_m²)/(ω_m·ω_n·ω₊)) / (1 − g·k₊·tanh(k₊h)/ω₊²) + T₂⁺ − (1/2)·T₁ ]
- B⁻ = 2·[ (T₁ − T₂⁻ − (1/4)·g·(ω_m·k_n²−ω_n·k_m²)/(ω_m·ω_n·ω₋)) / (1 − g·k₋·tanh(k₋h)/ω₋²) + T₂⁻ − (1/2)·T₁ ]

**単色波の有限水深アンカー（両形の検証に使う。Stokes 1847 の式。R2 と同じ）**：

- 単色波の 2 次高調波振幅は a₂ = (k·a²/4)·cosh(kh)(2cosh²(kh)+1)/sinh³(kh)。WAFO 規約では h_s(k,k) = (k/4)·cosh(kh)(2cosh²(kh)+1)/sinh³(kh)、二重和の規約では B⁺(k,k) = (1/2)·k·cosh(kh)(2cosh²(kh)+1)/sinh³(kh) と等しくなければならない。
- 振幅比 a₂/a₁ = (1/4)·k·a·cosh(kh)(2cosh²(kh)+1)/sinh³(kh)。Gemini の実計算では SWELL 5.0%・P1 15.9%・P5 8.3%（§0 の表）。
- この係数は M&W 近似でも厳密形でも解析恒等式であり、正確な式なら数値誤差は 10⁻¹⁴ 程度しか出ない（LEG-GEMINI.md D2）。1% のズレを許す線は、転記ミスや近似破綻を見逃す。だから合格線は機械精度寄りに置く（G-C1-0 の項目 (1)）。

**ゲート G-C1-0（転記の検証。実装ブリーフを書く前に通す。R4 で書き直し）**：
**G-C1-0 は試験 0 の前提条件である。G-C1-0 を通さずに試験 0 の参照計算 A を実行してはいけない。**P₁ 第3項が未確定（U-2）の間、参照計算 A は実行できない。

照合の手順を先に固定する：(a) 実装時に WAFO 原文ファイル（pywafo `wafo/spectrum/core.py` の `qtf` 関数。取得した版・コミットを記録する）を入手し、本書の転記と1行ずつ突き合わせる。食い違いが出たら原文を正として本書を訂正し、訂正を記録する。**R4 時点での検索インデックス経由の証拠（§0、§2.1 の P₁ 警告）は直接読みではないため、(a) の直接読みが必須である。(a) で `g * 2.` が確認されれば、WAFO Langley 分岐は参照として使えず、参照は Langley (1987) 原著または独立導出（Kaihatu & Kirby 2005 等）から取り直す。**(b) 下記の数値項目を通す。(c) Sharma & Dean (1981) 原論文、または Kaihatu & Kirby (2005) の厳密バイクロマチック伝達関数との独立照合は、入手できた時点で追加する（§6 の U-2）。(c) は任意の追加ではなく、(a) で WAFO 分岐が使えないと判明した場合の必須の代替経路である。

4. **モード交換対称性**：B±_{mn} = B±_{nm}（Langley 形の P₁・P₃ の構造からも解析的に確認する）。
5. **次元整合性（項ごとの同次性）**：B± の次元は 1/m。**加えて P₁・P₃ の各括弧の中身が項ごとに同次元であることを確認する。**P₁ の括弧 (w_2⁴ − g²·k_2²)・(w_1⁴ − g²·k_1²) はいずれも 1/s⁴、(k12·g² − w12²) は 1/s⁴ でなければならない。1 項でも次元が合わない場合は、その項の転記は誤りとして G-C1-0 は不合格とし、原文ファイルの直接読みで正す。**この検査は R4 の P₁ 第3項の問題（`g * 2.` は 1/(m·s²) で次元不整合）を検出するためのものである。**
6. **共鳴近傍の挙動の記録**：D± ≈ 0（Langley 形では P₂・P₄ ≈ 0 と等価）での挙動を記録する。毛管側の共鳴（Wilton）は §2.6 で別に扱う。
7. **安全形と原形の恒等性**：中程度の kh で、安全形（cosh を消した形）と原形が相対差 <10⁻¹² で一致すること。
8. **対角項の扱い**：h_d の対角は P₃/P₄ の式でなく h_dii で置くことを確認する（ω₋ = 0 で P₃/P₄ の形は特異）。

**カーネルの地位（R4 の結論）**：1D（θ=0）切片の厳密形は転記済みであるが、**P₁ 第3項が未確定（U-2）のため、1D 切片すら確定していない**。R3 の「B⁻ の式は原文で確認済み」は P₃・h_s・h_d の行については検索インデックス経由の証拠で支持されるが、P₁ 第3項が原文と食い違う疑いがある以上、Langley 形全体を「原文で確認済み」とは言えない。GPT の条件「厳密形の転記が完了するまで B± の仕様は未確定とする」は、1D 切片についても未確定のまま残す。方向形は未確定である（U-1）。**試験 0 の参照計算 A は、G-C1-0（特に手順 (a) の直接読み）が通るまで実行できない。**M&W 形は比較用（C）のままであり、参照計算に昇格させない。M&W 形で参照計算を回して J0 を通すことは、近似形を厳密形と偽ることになるため禁止する。

**「P5 の試行は深水形の試行でもある」とは言わない（R2 の訂正を引き継ぐ）**：P5 の水深 4 m では、例えば k = 0.5 rad/m のモードは kh = 2 であり、低波数側を含むペアや差周波の小さいペアが深水極限に入るとは限らない。深水極限の一致は、ピーク近傍・低波数側・差周波小さいペアの 3 群に分けて測る。

### 2.2 計算法 — ペア依存 QTF を参照にし、FFT 分離形は高速近似の候補とする

**決定：物理カーネルはペア依存の QTF（§2.1）とする。計算方式として FFT を使う。
Hilbert 2 次式は、QTF との一致が確認された条件に限って使う高速近似の候補であり、
既定の物理モデルではない。**（R2 と同じ）

R1 の決定（「線形場とその Hilbert 変換の 2 次式を FFT で畳み込む」）は撤回済みである。
理由は 3 席一致の不成立（C2・C3）。k_p 一点での狭帯域近似と 1 方向 Hilbert 変換は、
どちらもダメだった。**R3 での変更は参照形だけである**：参照計算は M&W 形ではなく
§2.1 の Langley 厳密形で行う。

**2.2.1 参照計算 — ペア依存 QTF の直接評価（モード二重和、縮小帯域）**

- 参照計算は、モードの二重和を直接評価する。縮小したモード集合（例：ピーク付近の 100–200 成分、または Gemini の指定する M=256–512 モード）に対して、ペア (m, n) ごとに §2.1 の Langley 形 B⁺/B⁻（方向一般化の仮説を含む）を評価し、η₂⁺・η₂⁻ を作る。O(M²) だが M が小さいので回る。
- 参照計算は「物理モデルそのもの」であり、近似ではない。試験 0 の比較対象になる（§2.3）。λ₃,exact はこの参照計算から出す（§5 の J3'）。
- M&W 形の直接評価は比較対象（C）として併記し、厳密形との差を記録する。
- 全モードでの二重和（2048² 格子でモード数 数千〜数万）は回らないので、本実装の計算方式は別途決める（下記 2.2.2）。参照計算と本実装は別のものである。

**2.2.2 本実装の計算方式 — FFT による分離形（候補 S1。試験 0 で検証する唯一の候補）**（R4 で書き直し）

**決定：本実装の計算方式は、以下に固定する分離形の候補 S1 とする。S1 以外の
分離形を試験 0 で試すことはしない。**S1 の具体式・対応表・方向依存・正規化は

- **帯域の統一（R4 で変更。D8→F8）**：S1 が評価するペアは §2.6 の k_QTF,max ≤ **100** rad/m の内側に限る。試験 0 と本番で帯域を変えない。カットオフ関数は §2.6 の raised-cosine（[100, 120] rad/m）を使う。

**2.2.3 直交位相の作り方 — 1 方向 Hilbert は破棄する**（R2 と同じ）

- R1 の「風向きへの 1 方向 Hilbert 変換」は破棄する。理由：(a) 風と直角方向のモード（k_x=0）では sgn(0)=0 となり η̃₁=0 で位相共役が消滅する。(b) 風上向き成分（k_x<0、ω>0）が存在する場合、空間 1 方向 Hilbert は時間的共役と符号が 180° 反転し、Q₊ と Q₋ が入れ替わる（LEG-GEMINI.md C3）。方向分散した場では数学的に破綻している。
- 代わりに、**時間的解析信号の虚部**を使う。生成器は各進行波モードの複素振幅 η̂₁(k)e^(−iω_k t)（ω_k>0）を保持しているため、η̃₁(x,t) = Im Σ_k η̂₁(k)e^(i(k·x−ω_k t)) とすれば、追加コストほぼゼロで全方向 θ∈[−π,π] に厳密になる。または **2D Riesz 変換**（−i·k/|k|·η̂₁ による勾配演算）を使う。どちらを選ぶかは試験 0 の実装で決め、両方の一致も測る。
- **注意（GPT の指摘）**：方向別の直交位相を作るだけではまだ不十分である。2 次相互作用は個別モードの位相直交だけでは決まらず、モード対の和・差周波相互作用を含む。方向ごとに別々に Hilbert 変換してから 2 次式を作ると、異なる方向のモード対について、どの直交位相をどう組み合わせるかという問題が残る。したがって、時間的解析信号・2D Riesz も「QTF の高速近似の部品」であって、QTF そのものではない。標準実装は、方向を含む波数ベクトル対に依存する QTF を保持する（§2.2.1）。直交位相を使う近似は、試験 0 で QTF との一致が確認された条件に限って使う。

**2.2.4 計算手順（1 フレームあたり。R2 と同じ）**

1. **線形場を取る**：生成器から η₁(x, y, t) を取る。生成器のコードは変えない。同じシード・同じ 192 フレーム（8 s、24 fps）・同じプローブ配置（cf-0067 と同じ 256 点）を使う。η₁ はビット単位で線形のままであること（J1 で検証する）。
2. **直交位相と勾配を作る**：時間的解析信号の虚部（または 2D Riesz 変換）で η̃₁ を作る。同じ FFT の往復で勾配場 ∂xη₁、∂yη₁ もスペクトル微分で作る。1 方向 Hilbert は使わない。
3. **2 次式を作る（実空間での積）**：和周波成分のもと Q₊ = η₁² − η̃₁²、Q₊′ = 2η₁η̃₁（解析信号 Z = η₁ + iη̃₁ の Z² の実部・虚部）。差周波成分のもと Q₋ = η₁² + η̃₁²（|Z|²、包絡の 2 乗）。有限水深形のカーネルが k₁·k₂ の項を含む場合、その部分は勾配場の積（∇η₁·∇η̃₁ など）で作る。**どの積がどのカーネル項に対応するかは、§2.1 の B⁺/B⁻ の式から対応表を作る。対応表は試験 0 で検証する。**
4. **カーネルを k 空間のフィルタとして掛ける**：各 2 次式を FFT し、§2.2.2 の候補 S1 の対応表に従って出力波数 k に対してカーネル因子を掛ける。**k_p 一点での評価はしない。**分離形の具体式は §2.2.2 で固定済みであり、試験 0 の結果を見て変えることはしない。ペアの帯域は §2.6 の k_QTF,max ≤100 rad/m で切る。対角項（m = n）の差周波寄与は h_dii で別に扱い、静的 DC 項として分離する（§2.2.2）。
5. **実空間に戻す**：IFFT で η₂⁺、η₂⁻ に戻す。**パッチ平均の除去はここではしない。**平均水位の扱いは §2.4 で決める（診断用の静的 DC 項だけを除く）。
6. **場を足す**：η = η₁ + η₂⁺ + η₂⁻。勾配・曲率は η からスペクトル微分で作り直す。η₂⁺ と η₂⁻ は診断として別キーで残す（§5 の J5）。
7. **プローブで出す**：cf-0067 と同じ 256 プローブ・同じ 192 標本で η、η₂⁺、η₂⁻ をサンプリングし、同じ npz 形式（キー eta/gx/gy/lap/t）で出す。検証の道具（歪度・尖度・QD・峰高・バイコヒーレンス）は cf-0085 と同じ定義・同じ車線で回す。

**エイリアシングの扱い**：2 次式の積は、同じ格子で計算すると高波数成分が折り返す。3/2 則のパディング（積を作る前に場を 3/2 倍の格子へ広げ、積の後に元の格子へ戻す）で除去する。これは大原則の (a)「中立な数値手法」であり、物理の主張ではない。ただし 3/2 則だけでは、格子収束・高波数切断・低波数分解能・共鳴近傍の誤差は除去できない（§2.2.2）。

**計算量の見積もり（推測。実測ではない。R2 と同じ）**：1 フレームあたり FFT 8–10 回（2048²）で 2–4 秒、8 s 記録 1 本 400–800 秒、P5・5シードで 35–65 分。見積もりは推測であり、実装ジョブの最初の 1 記録で実測して確かめる（§5 の J7）。**試験 0 は縮小モード集合（M=256–512）での直接二重和なので、計算量は小さく、最初に回す。**

**大きさの事前見積もり（P5、解析式から。実測ではない。R2 と同じ）**：
η₂⁺ の標準偏差は k_p·σ_η² ≈ 14.15 × (0.0059)² ≈ 4.9×10⁻⁴ m で、線形 σ_η の約 8%（a₂/a₁ = 8.3% と整合する）。足される分散は (0.083)² ≈ 0.7%。勾配への寄与は波数が 2 倍になる分だけ大きく、ピーク急峻度 ε = 0.17 から勾配場への 2 次の寄与は振幅比で約 17% になる見込み。つまり「高さでは小さく、勾配・曲率では無視できない」というのが、この設計の効き方の見立てである。実測で確かめる（J2b・J5）。

**誤差の定義（R3 で書き直し。D1 の直し）**：m2・m4 の誤差は総場では測らない。
R2 の線（総場の m2 ≤3%・m4 ≤10%）は、P5 の物理変化そのもの（Δm₂/m₂ ≈ 2.8%、
Δm₄/m₄ ≈ 11.2%）と近似誤差を分離できない。特に総場 m4 ≤10% は、η₂ の寄与を
ほぼ取り違えた近似でも通ってしまう（LEG-GEMINI.md D1）。
R3 では増分で定義する：Δm_j ≡ m_j(η₁+η₂) − m_j(η₁)（j = 2, 4）を A・B それぞれで
計算し、誤差は |Δm_j(B) − Δm_j(A)| / Δm_j(A) とする。これは「物理予測（A）を
別途計算し、近似誤差のみを見る差分線」である（LEG-GROK.md D1）。

**分母が不安定な場合の切替条件（R4 で事前登録。LEG-GPT.md F1）**：Δm_j(A) が
小さいと相対誤差の分母が不安定になり、符号反転・ゼロ近傍では合格線自体が
意味を失う。次の場合、相対誤差による判定は行わず、絶対誤差による判定に切り替える。
切り替えの条件と絶対誤差の線は、試験 0 の着手前に本項で固定する。
- 切替条件：Δm_j(A) ≤ 0（符号反転・ゼロ）の場合、または |Δm_j(A)|/m_j(η₁) が
P5 の物理増分の期待値の 1/10 未満の場合。期待値は Δm₂/m₂ ≈ 2.8%・
Δm₄/m₄ ≈ 11.2%（R3 §2.3 の見積もり）より、切替の敷居は m₂ で 0.28%・
m₄ で 1.12% とする。
- 絶対誤差の線：|Δm_j(B) − Δm_j(A)|/m_j(η₁) ≤（J0 の相対線）×（P5 の期待増分比）。
m₂：2% × 2.8% = **0.056%**、m₄：7% × 11.2% = **0.784%** とする。
- **符号反転は自動失敗**：増分誤差が合格線の内側でも、Δm_j(A) と Δm_j(B) の
符号が逆転している場合は不合格とする（LEG-GPT.md F1 の失敗条件）。
分母が小さいことを理由に相対誤差の発散したケースを恣意的に除外してはならない。

**対象の定義（R4 で固定。LEG-GPT.md F1）**：
- |Δb| は (f_p, f_p) のバイコヒーレンス（cf-0094 の NF 仕様と同じ推定器）で測り、
最大値ではなくそのビンの値を取る。ビンの集約（平均化）はしない。
- η₂⁺・η₂⁻ の場の相関は、1.5 m パッチの全格子点での Pearson 相関で測る。
RMS 相対誤差は RMS(B−A)/RMS(A) とし、分母は全領域での RMS(A) とする
（低振幅領域だけを分母に取るなど、不適切な分母での計算はしない）。
プローブ時系列での相関・RMS も別に報告するが、合否は場の値で決める。

### 2.4 どこまで入れるか — 和周波成分と差周波成分の両方を入れる（検証の置き場を分ける）

**決定：和周波成分（η₂⁺）と差周波成分（η₂⁻、セットダウン）の両方を入れる。
ただし η₂⁺ と η₂⁻ は診断として分離して出力し、ゲートの寄与を
それぞれ読めるようにする。**（R2 の決定そのものは維持する。C4 は 3 席とも条件付き成立。）

- **なぜ両方か（R2 と同じ）**：同じ計算で両方出る。セットダウンは群れの包絡と一緒に動く低周波成分であり、群れの物理の一部である。歪度への寄与は両方にある。片方だけ入れて歪度が上がったとき、上がった分がどちらから来たのか分からなくなる。
- **大きさの見立て（R2 と同じ）**：歪度の主信号は和周波成分から来る。λ₃ ≈ 3·k_p·σ_η という標準的な式は、和周波成分の寄与だけで導ける。差周波成分は深水では k₁ ≈ k₂ でカーネルが 0 に近づくため、歪度への寄与はスペクトル幅のオーダーで小さい。つまり**差周波成分は歪度ゲートの主信号ではなく、群れの包絡の形（QD 波形の谷の形・平均水位の動き）の方に効く**と見立てる。実測で確かめる（J5 の寄与分離）。
- **整理 1 — パッチ平均の除去は「診断用」に限定する（R2 と同じ。3 席の共通条件）**：
  - **物理場には、η₂⁻ を含む全水位場を平均除去前の場として保持する。**パッチ平均の除去は物理的な 2 次成分の削除とはみなさない。
  - 除去してよいのは、**固定された静的 DC 項（Δk=0、Δω=0 成分）のみ**である。静的 DC 成分だけを固定水深 h の定義として引くなら、保存水深に一致し、3 次中心モーメント（歪度）は不変である（LEG-GEMINI.md C4）。
  - **各時刻のパッチ空間平均 η̄(t) を引く操作はしない。**パッチサイズと同程度の群れビートが通過するたびに水面全体の基準水位 h が時間的に上下動する非物理なピストン振動を生む。中立な数値操作ではない（LEG-GEMINI.md C4、LEG-GPT.md C4）。
  - 除去する平均の対象・空間窓・除去する波数帯を明示し、除去前後の統計を併記する（LEG-GPT.md C4）。除去した平均値の大きさは診断として記録する。
  - **R3 での追加（GPT の D6 条件）**：平均除去の前後で、平均・分散・低波数スペクトル・QD 波形を保存する。差周波成分が除去操作で消えていないかを後から追えるようにするためである。
- **整理 2 — η₂⁻ の検証は 2 つに分ける（R3 で書き直し。D6 の統合裁定）**：R2 は「1.5 m パッチ単体では検証しない。大パッチまたは条件付き QD で行う」としていた。確認ラリーで置き場が割れたため、R3 では両方を採り、役割を分ける：
  - **(i) 本番パッチの実装検証は試験 0 に含める**：P5 のピーク波長は λ_p = 2π/14.15 = 0.444 m で、1.5 m 周期パッチには約 3.4 波しか入らない。解像できる最小差波数は Δk_min = 2π/1.5 = 4.19 rad/m（約 0.30·k_p）で打ち切られる。Δk < 4.19 rad/m の長周期の群れセットダウンは原理上パッチ内で消滅するが、**解決されている Δk ≥ 4.19 rad/m のモードについては、本番パッチの場そのもので B⁻ 二重和と照合できる**（相関 ≥0.99・RMS 相対誤差 ≤5%、§2.3）。大パッチだけの検証では、本番パッチ内の符号反転した B⁻ のバグを見逃す（LEG-GEMINI.md D6）。
  - **(ii) 長群れの物理検証は 8 m 以上の粗格子診断として分離する**：低波数モードを含めて再生成した 8 m 以上の診断場で行う。仕様は重力帯粗格子（k ≤ 100 rad/m、512²、生成器変更不要の診断用計算。LEG-GEMINI.md D6）。1.5 m パッチをタイル連結したものを代用にしない（存在しない長波長成分は復元されず、周期境界の人工的な反復を作るだけ。LEG-GPT.md D6）。必要なら 12 m も追加する（LEG-GPT.md D6）。**適用対象は P5 級の波数帯に限定する（R4 で追加。LEG-GPT.md F6）。**8 m 箱の基本波数間隔は 2π/8 ≈ 0.785 rad/m であり、SWELL の k_p = 0.566 rad/m より大きく、ピーク波数を表現できない。8 m 診断は SWELL の長群れ検証には使えない。SWELL の k_p を検証するなら、箱長を 2π/k_p ≈ 11.1 m より十分長くし、ピーク周辺を複数モードで解像すること（実装ブリーフで箱長 L と Δk = 2π/L を記録し、Δk < k_p を満たすこと）。
  - **低域包絡の選択基準（R4 で基準を確定）**：包絡は、k ≤ 2k_p で低域通過した η₁ の Hilbert 包絡とする。条件領域は包絡の**上側 10%** のピーク領域とする（LEG-GEMINI.md D6）。**比較基準は、未定の「解析的な群れセットダウン予測式」ではない。「8 m 以上（512² 重力帯格子）における 2D 厳密 Sharma & Dean B⁻ 二重和の包絡上側 10% 平均値」とする（LEG-GEMINI.md F6）。**これなら方向・広帯域が完全一致し、±5–10% で厳密照合できる。検証基準：その領域での η₂⁻ の平均値が、この B⁻ 二重和の値と **±10% 以内**で一致すること。あわせて中央値と上側裾の両方を比較し、包絡条件領域と非条件領域の差も比較する（LEG-GPT.md F6）。**補助として、1D 狭帯域 Longuet-Higgins & Stewart (1962) 式の値との乖離比も記録する**（P5 は広帯域 ν_mode=0.3272 かつ cos2θ 方向分散のため、1D 狭帯域式と 2D 広帯域有限水深 QTF のセットダウン深さは交差角減殺と深水 Δk 依存により 30–50% 以上食い違う。LEG-GEMINI.md F6）。包絡の選択閾値を結果を見てから変更しない。なお線形場そのものが 1.5 m 有限格子の効果で QD の谷が 8–38% 浅い（§0）ため、条件付き QD は線形場の有限ボックス歪みと交絡する。この交絡は (i) の直接照合で切り分ける。QD だけで η₂⁻ の合否を判定しない。
  - **「平均を保存」の訂正（R4 で追加。LEG-GEMINI.md F6）**：平均除去の前後で保存するのは、平均そのものではない。**Δk≠0 成分の平均除去は行わず、Δk=0 静的 DC 除去のみを行い、分散・スペクトル（k>0）・中心化 QD 波形を保存する。**DC 除去により平均自体はゼロへ変わるため、「平均を保存」という文言は使わない。
- **パッチの大きさとの関係（R2 の注意を維持する）**：差周波成分は群れのスケール（数 m〜数十 m）で変わる成分だが、本番パッチは約 1.5 m しかない。パッチの中では差周波成分はほぼ一様なオフセットに見える。残るのはパッチ内の傾きだけである。つまり差周波成分の「見え方」はパッチの大きさで決まる部分が大きく、歪度・QD・バイコヒーレンスで読むのが筋である。パッチの中でセットダウンの「くぼみ」が見えることを期待してはいけない。
- **失敗条件（Grok の指定。R2 と同じ）**：平均除去後の差周波分散が線形分散の 0.1% を下回る場合、信号が消えている証拠として扱い、除去の仕方を見直す。

| 5 | **m4 が線形場の 1.5 倍超** | Grok |

- **谷反転バンプ率の判定アルゴリズム（R4 で固定）**：η₁ の谷底（極小）で、全場の曲率 ∂²(η₁+η₂)/∂x² の符号が反転（η₁ では >0、全場では <0）した谷を「反転」と数える。分母は η₁ の谷の数。曲率は x 方向と y 方向の両方で評価し、いずれかで反転した谷を数える。谷底の検出は η₁ の極小（離散格子上の局所極小）で行う。
- **6 項目それぞれの計算対象と標本不確かさの扱い（R4 で固定）**：計算対象は合成場（η₁+η₂）、全パッチ・全 8 s、シード別に測る。合否は 5 シードの**中央値**で判定し、シード間範囲を不確かさとして併記する。1 シードだけの外れで破綻と判定しない。ただし中央値が線を割っていても、シード間のばらつきが大きく線の近傍にある場合は「要調査」として記録する。

- R3 で残していた「負の分散は分解した寄与を指す」という定義は、項目 4 の削除に伴い**撤回する**。分解した分散寄与の負値は非物理ではなく、谷浅化の実在の物理である。したがってこの項目は破綻兆候として使わない。

**復帰判定は摂動次数の収束性で行う（R3 で変更。GPT の条件）**：P1・SWELL を
対象へ戻すかどうかは、ε₂ ではなく、2 次 QTF の結果と独立な高次参照

### 2.6 表面張力と帯域 — QTF の物理モデルの整合（D8 の直し。新設）

**問題の所在**：生成器は重力＋表面張力の分散関係を使う。一方、§2.1 の QTF は
純重力波の相互作用係数である。表面張力は分散関係だけでなく、自由表面の
力学的境界条件（圧力跳躍）にも入る。したがって **QTF 側の ω(k) だけを毛管側に
合わせても、物理モデルは一致しない**（LEG-GPT.md D8）。R2 の扱い
（「QTF の ω には生成器と同じ分散関係を入れる。近似として認める」）は、
近似であることの明記としては残すが、整合の主張としては使わない。

**当面の仕様（R4 で固定）**：

1. **帯域の統一**：QTF の入力側に滑らかな高波数カットオフを適用し、**k_QTF,max ≤ 100 rad/m** を試験 0 と本番の両方で使う（LEG-GEMINI.md F8 の提案。R3 の 150 から引き下げる）。試験 0 で除外して合格した実装を、本番で除外帯まで動かすことはしない。カットオフの根拠は、毛管項が有意になる帯域と Wilton 共鳴（k ≈ 260 rad/m）を QTF の適用外に置くことである。毛管項比 (σ/ρ)k²/g は k = 100 rad/m で **≤7.4%**、k = 150 rad/m で **16.7%**（σ/ρ = 7.28e-5 は cf-0075 の確定値）。**2k_max = 200 rad/m < 260 rad/m で、Wilton 和共鳴を構造的に回避する**（LEG-GEMINI.md F8）。カットオフ関数は **raised-cosine（[100, 120] rad/m で 1→0）**として固定する（事前登録の設計選択である）。高波数側では毛管項が重力項を大きく上回る（k = 1000 rad/m で毛管項は重力項の約 7 倍。LEG-GROK.md D8）。なお生成器の線形場そのもの（k_cut = 1000 rad/m）は変えない。切るのは QTF のペア評価の入力側だけである。
2. **m4 の 2 本立て報告**：m4 は「全帯域 m4」と「QTF 帯域（k ≤ k_QTF,max）の m4」の 2 本立てで測って報告する（LEG-GEMINI.md D8）。除外帯（k > k_QTF,max）が全 m2・m4 に占める割合を定量して併記する。
3. **除外帯の失敗線**：除外帯の線形エネルギーが全エネルギーの **5% 超**なら失敗とする（LEG-GROK.md D8）。P5 の実測では除外帯の線形エネルギー比は 0.51%（cf-0069 §8.1）なので、この線は自動失敗にはならない。**R3 にあった「除外の前後で m4 が 10% 以上変われば失敗」は削除する（LEG-GEMINI.md F8）。**m4 の大部分が k>150 側（R4 では k>100 側）にあるため、この線はほぼ自動失敗になる。代わりに、**QTF 帯域の m4 変化率と全帯域の m4 変化率を分離報告し、全帯域 m4 の主張には毛管側を合算するまで留保を付す**（LEG-GEMINI.md F8）。除外帯の m4 寄与が **1% 超**なら、全帯域 m4 の合格を主張しない規則は残す（その場合は QTF 帯域の m4 を検証済みの量として報告する。LEG-GPT.md D8）。Elfouhaily スペクトルではこの規則は事実上常に発動し、全帯域 m4 の主張は最初から留保される。
4. **Wilton 共鳴はペア単位で扱う**：Wilton 共鳴は単一の波数カットオフでは判定できず、相互作用する波数ペアの関係で評価する（LEG-GPT.md D8）。ペア (m, n) ごとに、和成分 (k₊, ω₊) と差成分 (k₋, |ω₋|) が毛管重力の分散関係の自由波条件にどれだけ近いか（相対離調）を測り、共鳴近傍のペアを通常の QTF 評価から分離して記録する。非対称な和共鳴（例：k₁ と k₂ の組合せで分母がゼロを跨ぐ場合）もこの検出で拾う（LEG-GEMINI.md D8）。**相対離調の閾値は |ω₁±ω₂−ω(k₁±k₂)|/ω_± < 0.05 に固定する（LEG-GEMINI.md F8・LEG-GROK.md F8 の例示値）。分離したペアの扱いは「除外＋寄与報告」とする（件数と m₂／m₄ への寄与を記録する）。**粘性による正則化はフェーズ 2 の代替案として記録のみとし、フェーズ 1 では使わない。
5. **表面張力の扱いは 2 経路のどちらかで閉じる**：
   - **経路 A（導出）**：表面張力を含む QTF を導出する。力学的境界条件に表面張力の曲率項を含め、相互作用係数と共鳴分母 D± を毛管重力の分散関係で組み直す。**本書では導出しない（§6 の U-3）。経路 A はフェーズ 2 の必須経路である。**
   - **経路 B（独立参照との比較）**：単色波ペアについては、毛管重力の Stokes 2 次解を独立参照としてアンカー照合する（式の転記は実装ブリーフ時に行う）。**一般ペアの参照として経路 B は採用しない（LEG-GPT.md F8・LEG-GROK.md F8）。**単色アンカーだけでは一般ペアを確定できないためである。一般ペアについては経路 A 待ちとする。**フェーズ 1 は重力帯（k ≤ 100 rad/m）に厳密限定し、毛管重力 QTF はフェーズ 2 の前提として残す。**
   - どちらの経路も閉じるまでは、純重力 QTF に生成器の (k, ω) を入れた計算は**「近似」として記録し、物理的に整合したと主張しない**。
6. **呼び方の規律**：k_QTF,max で切った試験 0 は「QTF 帯域の検証」と呼ぶ。全帯域の検証とは呼ばない（LEG-GPT.md D8 の同旨）。

## 4. 8 s ループ契約・ω 量子化との整合（検証を数値化する。D7 の直し）

- **数学的な周期性は保たれる**：η₂ の成分の周波数は ω₁±ω₂ で、ω₁・ω₂ はどちらも 2π/8 s の整数倍（cf-0075）なので、ω₁±ω₂ も 2π/8 s の整数倍である。η₂ は 8 s で厳密に周期であり、8 s ループ契約は構成上保たれる。時間発展のコードは変えない。
- **数学的周期性と物理的群れの再現は別問題である（R2 と同じ）**：8 秒ループの中では、非ゼロの差周波ビートは 8 秒以下の周期しか持てない。8 秒を超える群れの包絡変動は表現できない。10 秒・20 秒のビートを作るには周波数差がそれぞれ 0.1 Hz・0.05 Hz 程度必要になるが、8 秒ループの周波数刻みは 0.125 Hz である。これらの差周波数は格子上に存在しない。**長周期の群れが 8 秒ごとに再出現するように見える場合、それは自然な群れの時間発展を再現したのではなく、8 秒周期という数値契約が作った再帰性である。**8 秒周期を維持すること自体は問題ではない。8 秒周期で表現できない物理を、表現できていると扱うことが問題だ（LEG-GPT.md C8）。
- **静止縞の定量ゲート（R3 で 1 本に決める。D7 の直し）**：離散周波数ビンへの丸め（snapping）により、連続分散関係では ω(k₁)≠ω(k₂) となる異なる波数・角度のモード対でも、同一ビンに丸められると ω₁−ω₂=0 に縮退し、時間移動せず空間に張り付いた静止セットダウン縞（時間平均 ≠0 の偽定在波）を η₂⁻ 内に作り出す（特にスペクトルピーク近傍の高密度ビンで顕著）。ゲートは次の 1 本とする：
  - **Var_x(⟨η₂⁻⟩_t) / ⟨Var_x(η₂⁻)⟩_t ≤ 0.05**（k₁=k₂ の空間一様 DC を除く。P5 の η₂⁻ 場で測る）
  - **採用の理由**：候補は Gemini の分散比 ≤0.05 と Grok の「偽定在縞の分散寄与 ≤ η₂⁻ 全分散の 10%」だった。両者は同じ対象（ω₁−ω₂=0 へ落ちた非一様静止成分）を指すが、Gemini の形は推定量として定義が完結している（時間平均場の空間分散 ÷ 空間分散の時間平均）。Grok の形は「寄与」への分解の定義が別途要り、二重定義になる。数値も Gemini の 0.05 が厳しい側であり、GPT の条件（周期ストライプが全 η₂⁻ 分散に占める割合 5% 未満）とも一致する。よって Gemini の定義と値を採る。
- **「4 s 超の遅延の自己相関」は廃止する（R3 で変更）**：R2 の確認項目だったが、厳密に 8 s 周期の信号の自己相関 R(τ) は R(4+δ)=R(4−δ) かつ R(8 s)=1 を数学的に強制される。8 s ループ単体で τ>4 s の自己相関を測っても物理的減衰は読めず、周期折り返しを見ているだけになる（LEG-GEMINI.md D7）。この項目は検証として無効なので削除し、下の比較診断に置き換える。
- **長周期との比較診断（R3 で第 1 実装の診断に含める）**：8 s の結果だけで折り返しの妥当性を主張しない（LEG-GPT.md D7、LEG-GROK.md D7）。
  - **16 s 版との比較（R4 で変更）**：**時系列の正規化 RMSE ≤10% は削除する（LEG-GEMINI.md F7）。**周波数ビン刻みが 0.125 Hz（8 s）と 0.0625 Hz（16 s）で違い、位相がドリフトするため実行不可能である。代わりに次の統計・相関比較で判定する：低周波 η₂⁻ 分散の差 ≤10%／ラグ別自己相関 R(τ)（τ∈[0, 4 s]）の最大絶対差 ≤0.05／自己相関積分時間 τ_int = ∫₀^{4s}|R(τ)|dτ の相対差 ≤10%（LEG-GEMINI.md F7 の式）。**時間平均は t∈[0, 8 s] 全区間、空間領域は 1.5 m パッチ全域、DC 除外は k₁=k₂ の空間一様 DC のみ、過渡区間の除外はなし**（場は t=0 から周期的でスピンアップ過渡が存在しないため）。時間平均で消える周期成分の診断として、周期位相別の分散も記録する（LEG-GPT.md F7）。
  - **32 s 粗格子比較**：重力帯粗格子で 32 s 周期（Δf = 0.03125 Hz）の診断（1 シード）を第 1 実装の診断に含め、τ ∈ [0, 4 s] の自己相関と η₂⁻ 分散が 8 s 版と ≤10% で一致することを確認する（LEG-GEMINI.md D7）。**32 s 比較も同じ統計・相関比較（上の 16 s 版と同じ 3 量）で行う（R4 で追加）。**P1・SWELL へ 8 s 仕様を適用する場合は、各条件で別途行う（LEG-GPT.md F7）。
  - 比較で線を超える差が出れば、8 s 契約が 2 次相互作用の物理的再現に制約を与えているとして記録し、第 1 実装の結果の読み方に反映する。
- **SWELL へ拡張しない（R2 と同じ）**：P5 では 8 s 間に約 5 個の群れが通過する（τ_group ∼ (νf_p)⁻¹ ≈ 1.63 s）ため群れ折り返しは目立ちにくいが、仮に SWELL（T_p=2.667 s、8 s でわずか 3 波、群れ時間 ≳10 s）へ拡張すれば、Δf=0.125 Hz 刻みの 8 s 周期化自体が物理的群れ発展・η₂⁻ の時間統計と衝突する（LEG-GEMINI.md C8）。SWELL 限定試行（§2.5）でも、8 s 折り返しの影響は上記の確認とセットで報告する。
- **時間発展は変えない**：束縛波は親に追従する。η₂ は各時刻の η₁ から決まる（§2.2 の手順は各フレームで η₁(t) から η₂(t) を作る）。`_cascade_fields` の位相回転 exp(i·ω_q·t) はそのままでよい。新しい時間積分器は要らない。NLS のように時間発展の核を置き換える話ではない。
- **新しい乱数は引かない**：η₂ は η₁ の決定的な関数であり、乱数の引き直しはない。同じシード → 同じ η₁ → 同じ η₂。シード契約（同じ環境・同じシードで同じ場）は保たれる。シードで統計が大きく動く生成器は契約違反、という規律（床の設計 §3）もそのまま適用する（J6）。
- **ω 量子化は外さない**：cf-0079（生成器側で ω 量子化を外す実験）は本人の判断待ちのままであり、本設計とは別件である。η₂ の計算は量子化された ω のままで行う。差周波成分の低周波（ω₁−ω₂ = 0 や 2π/8 s）は、量子化された格子の上の成分として扱う。
- **lo／hi カスケードとの関係**：η₂ は、lo／hi のブレンド後の最終的な η₁ から計算する。lo と hi のモード同士も相互作用する（和・差のペアはカスケードをまたぐ）ので、カスケード別に η₂ を作ってブレンドしてはいけない。ブレンド後の 1 枚の場から作る。ブレンドの境目 K_X での raised-cosine の重みは、η₁ の側の話であり、η₂ の計算には直接現れない。
- **k_cut との関係（R4 で §2.6 と整合させる）**：線形場のスペクトルは k_cut = 1000 rad/m で切られている（生成器は変えない）。η₂ のペア評価は §2.6 の k_QTF,max ≤100 rad/m の内側のモード同士に限る。R2 の「η₂ は格子のナイキストまで残し、k_cut での切り捨てはしない」は、QTF 入力帯域の統一（D8）により置き換える。切り捨てた帯の寄与は §2.6 の項目 2・3 で定量する。

## 5. 判定ゲート J0–J7
