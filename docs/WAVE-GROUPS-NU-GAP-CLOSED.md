# WAVE-GROUPS-ν-GAP-CLOSED — 波の群れの ν ギャップ切り分け連鎖（統合メモ）

作成：2026-11-16（cf-0082）。新しい計算なし。連鎖 cf-0067 → cf-0069 → cf-0073 → cf-0075 → cf-0078 → cf-0077 の結論だけを並べたもの。

## 問い

フェッチ 100 m（P5-CLEAR）から 10000 m（SWELL-1）へ延ばすと、モード集合の ν は 0.3272 → 0.3952 と広がり、ギャップ 0.0680 が出る。プローブ ν でも 0.2848 → 0.3755、ギャップ 0.0906。見立ては「フェッチが延びればスペクトルが狭帯域化して ν は下がる」だったので、逆向きの結果である。何がギャップを作っているか。

## 切り分けの積み上げ

| 段 | ギャップ | その段で外したもの | 変化 | 出所 |
| --- | --- | --- | --- | --- |
| gap_q（現行） | 0.0680 | — | — | cf-0075 §5 |
| gap_true | 0.0564 | ω の量子化（2π/8 s の丸め） | −0.0116（17.1%） | cf-0075 |
| gap_analytic | 0.0505 | 標本化・窓・k_cut（連続極限） | −0.0058（基準の 10.3%） | cf-0077 |

現行ギャップ 0.0680 のうち、量子化が 17.1%、スペクトル形状そのものが 74.3% を担う。残る 0.0058 は k_cut の切り方と標本化ゆらぎの範囲にある。

## 各候補の結論

- **高波数尾部（cf-0069）**：P5 では尾部が ν を決めていた（k_cut を 1/32 にすると ν −60.3%）が、SWELL では −5.1% しか動かない。ギャップは尾部では説明できない。副産物：GF は ν に追随しない（GF で尾部の寄与を読んではいけない）。
- **窓／λc（cf-0073）**：P5 の窓を SWELL と同じ波長数に揃えてもギャップは残存比 1.03–1.09 でほぼ不変。窓は主因でない。副産物：`patch_base_m` の二重化はこの生成器では no-op（パッチは 8λp 以上へ量子化される）。
- **ω 量子化（cf-0075）**：ギャップの 17.1% を作るが主因でない（残存比 0.829、0.8 の線まで 0.029 と近く、シード別では線を跨ぐ。主張は 17% という数値に置く）。機構：SWELL の分散は n=4 の低ビン帯に集中し、刻みが ω の 12.5% になる。教訓：ブリーフの重力のみの分散式は誤りで、生成器の実物は毛管項を含む（重力のみだと説明率が −61.2% に反転する）。
- **位相の引き方（cf-0078）**：新しい計算なし。5シードのばらつきが位相＋振幅サンプリングの上限で、プローブ側 21%・モード側 31% とギャップより十分小さい。位相だけでは説明できない。限界：ランダム位相の家族の中での話で、コヒーレントな場は別物の設計。
- **スペクトル形状そのもの（cf-0077）**：連続 Elfouhaily スペクトルだけで ν は P5 0.3309／SWELL 0.3815、ギャップ 0.0505。基準 0.0564 との差 0.0058 は許容 0.0141 の内側。**主因で閉じる。** 内訳：P5 は S_h が m0 の 6.9% なのに m2 の 19.2% を担って ν を押し上げ、SWELL は S_l 自身が広い。同じ B_h カーネル・同じ風で fetch だけが違う条件設定がこの非対称を作っている。2 条件は同じ帯を見ていない（P5 の m2 は 10–30 rad/m 帯が 74.5%、SWELL は 1–3 rad/m 帯が 36.8%）。

## 結論

**ν ギャップは Elfouhaily スペクトルそのものの形から来ている。** サンプリング・窓・k_cut・量子化・位相のどれも主因ではない。フェッチが延びると ν が広がるのは、このスペクトル形の性質である。

## 残る問い（この連鎖では扱わない）

- 群れの位相結合：現行生成器の群れは線形・ランダム位相の群れで、位相結合（非ガウス性）がないことが cf-0067 で分かっている。非ガウス性を入れる方法は cf-0083 の設計調査へ。
- 生成器側で ω 量子化を外す実験：cf-0079 で本人の判断待ち（生成器の変更＋8 s ループ契約の変更になるため）。
