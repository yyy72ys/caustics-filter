## 定数・約束（先行ジョブと同一）

- W_s = 36 mm、ピッチ p = 17.578 µm、λ = 550 nm、n = 1.333
- b = (f²/N)·|s − s_f|/(s·(s_f − f))、d_A = 2.44·λ·N_w、N_w = N·s_f/(s_f − f)、b_eff = sqrt(b² + d_A²)
- 体制：A = もう一方の面の b_eff ≤ 2 px／B = それ以上／D = ぼけた面で d_A > b
- N の格子 {1.4, 2, 2.8, 4, 5.6, 8, 11, 16}、合焦先 {水面, 床}
- 見かけ距離：s_surf = h_a、s_bed = h_a + d_w/n
