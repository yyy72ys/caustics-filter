### R2-1 — U14 に有限渦核半径（§6.1 に C19 を新設、§6.2 の U14 と U8b を書き換える条文）

**置き換える対象**： 親 §6.2 の U14 行「boil ドーム／渦のくぼみ −Γ²/(8π²gr²)／航跡の傷の3表現を別強制として実装」と、親 §6.1 の U14 に対応する主張の欠落。

- **渦くぼみの式（置き換え）**： 点渦式 η(r) = −Γ²/(8π²gr²) は、外側解としてのみ使う。中心部は有限コア速度分布と圧力場から正則化する。正則プロファイルは次のいずれかとし、実装ブリーフで選択と r_c の決め方を固定する： Rankine 渦 Δ η(r) = −Γ²/(8π²g r_c²)·[2 − (r/r_c)²]（r < r_c）、−Γ²/(8π²g r²)（r ≥ r_c）。または Lamb–Oseen 渦の同等形。r = r_c での連続性（内外とも −Γ²/(8π²g r_c²)）を確認項目に入れる。r_c は第2段の後流パラメータとして受け取る（下記）。
- **3強制の定義**： 各強制（boil ドーム／渦くぼみ／航跡傷）には、生成条件、強度パラメータ、空間スケール、移流速度、時間減衰、背景流との相互作用を定義する。形状を高さ場へ追加する際は、既存の波・流れ場との重複を交差統計で監査し、任意のへこみスタンプで代用しない。
- **第2段からの受け口（追記）**： 第2段は、障害物形状・後流渦の位置・循環 Γ・コア半径 r_c・移流速度・時間変化を、座標系と単位を明示して第1段へ渡す。第1段 U14 は受け取ったパラメータから表面変形を計算し、任意の形状スタンプを受け取って適用する方式にはしない。
- **U6 との重複監査**： U6 は乱流による波の散逸・移送を扱い、U14 は障害物後流渦が平均自由表面形状へ与える圧力・運動量効果を扱う。両者は同じ渦パラメータを共有してよいが、U6 の乱流モデルが含む平均圧力・表面変形成分を U14 で再加算しない。両ユニットの寄与は、平均場と波動場を分離した収支で監査する。

### R2-4 — C3 の振幅率／エネルギー率の統一（§6.1 の C3′ を書き換える条文）

**置き換える対象**： 親 §6.1 の C3′「成長側 τ_grow(k)（Plant 系）と減衰側 τ_decay(k)（粘性 2νk²＋膜減衰＋帯域間非線形移送）の非対称ペア」。

- **対象量の統一**： 突風応答は、成長側と減衰側を分離して記述する。ただし各率は、振幅 A(k) またはエネルギー E(k) のいずれを対象とするかを統一して定義する。線形粘性減衰 2νk² は振幅減衰率であり、エネルギー減衰率ならその2倍になる。Plant 系の成長率も、振幅・エネルギーのどちらを対象にするかで係数が変わる。異なる物理量の時定数を同じ表に並べてはならない。
- **減衰側の分解**： 減衰側は単一の静的参照表に固定しない。線形粘性＋状態依存の動的膜減衰率 τ_lin⁻¹(k, c(x, y, t)) = 2νk² + Δ_Marangoni(k, c, T) を局所状態（膜被覆 c(x, y, t)）から評価する。帯域間非線形移送 S_nl[N] および砕波散逸 S_ds,brk[N] は、緩和時間ではなく作用バランス内の非線形演算子として直接時間積分する。帯域間非線形移送は保存的なスペクトル流束であり、散逸ではない。ある帯域からエネルギーを奪っても別帯域へ移すため、符号も変わる。これを常に正の減衰率として 2νk² や膜減衰に加算してはならない。
- **τ の地位**： τ_grow(k) と τ_decay(k) は初期診断量である。突風後の実際の緩和時間は、非線形移送・空間伝播・履歴依存を含む時間発展方程式またはその線形化演算子から評価する。Plant 型成長率の逆数を、そのまま突風応答の緩和時間とは呼ばない。
- **U2b の記録（τ 表の廃止）**： U2b では単一の τ(k) 表を確定しない。振幅・エネルギーの別を明記した成長率、不可逆減衰率、保存的な帯域間移送、空間輸送、残差を別々に記録する。必要な場合は、これらの時間発展から得た成長・減衰の非対称な応答時間または応答核を示す。

### R2-5 — C6 の Wilton 共鳴振幅方程式（§6.1 の C6′ を書き換える条文）

**置き換える対象**： 親 §6.1 の C6′「Wilton は 1:2 三波共鳴として非線形枠組みの中で扱い、寄生毛細波は独立機構のまま別置する。QTF の適用域は宣言でなく固有値／残差の実測で決める。」

- **共鳴の定義**： Wilton 共鳴は、基本波と第2高調波の 1:2 共鳴として扱い、寄生毛細波とは別機構に置く。共鳴判定は、採用する有限水深・表面張力・流れを含む分散関係に対して、周波数整合 ω₂ = 2ω₁ および波数ベクトル整合 k₂ = 2k₁ を満たすかで行う。「1:2」と書くだけでは足りない。
- **結合振幅方程式**： 共鳴近傍では、非共鳴 QTF の単純評価を継続せず、共鳴する複数モードの振幅を同時に解く結合振幅方程式へ切り替える。基本波の振幅 a₁ と第2高調波の振幅 a₂ を同時に未知量とし、da₁/dt = i·V₁₂·a₁*·a₂、da₂/dt = i·V₂₁·a₁² の形で書く（V₁₂、V₂₁ は採用する二次核から決まる結合係数。係数の導出元と値は実装ブリーフで固定する）。QTF の残差・固有値診断は切替判定の一部とし、三波共鳴の解法そのものの代替とはしない。
- **QTF 適用性の判定**： QTF の適用性は、QTF が近似する二次自由表面境界条件の残差、共鳴分母の大きさ、対象モードの振幅誤差、曲率統計およびバイスペクトルの誤差で判定する。「固有値」を用いる場合は、対象とする線形化演算子または結合振幅系を明記し、QTF 単体の固有値とは呼ばない。
- **寄生毛細波との分離**： 寄生毛細波は独立機構のまま別置する（親の既定を維持）。Wilton 共鳴の振幅方程式と寄生毛細波の生成項を混同してはならない。

### R2-6 — C1′：膜輸送の位相平均／瞬時の分離（§6.1 の C1′ を書き換える条文）

- U1 は、界面上の瞬時 Euler 速度 u_E(z=η, t)、時間平均 Euler 流 U_E(z)、Stokes ドリフト U_S、および風駆動流の鉛直プロファイルを別々に出力する。
- 膜輸送は、位相平均した U_mat で行うのか、波解像の瞬時軌道速度 u_orb(z=η)＋平均流で行うのかを分ける。位相平均の作用格子輸送には U_mat = Euler 平均表層流 + U_S + 表皮シア流を用いる。波位相を解像するラグランジュ／瞬時膜輸送を行う場合は U_S を落として Euler 平均表層流 + 表皮シア流 + u_orb(z=η) を用いる（両者の混用・二重計上は禁止）。前者の場合、波頂での膜圧縮・波谷での伸長（軌道収束 ∇_H · u_orb による位相変調）が欠落することを明記する。
- 風駆動表皮シア流は U_E(z) の構成要素として定義し、Euler 平均流に含めた場合は別項として再加算しない。U_S は Lagrangian 平均輸送の補正としてのみ使用し、瞬時速度へ機械的に加算しない。
- 質量閉じ（戻り流）は、閉鎖池（正味質量流束ゼロ）と開水路（正味流量指定）で境界条件を分ける。0.02–0.035 U₁₀ は普遍係数ではなく、風の基準高度・成層・フェッチ・波齢・流れ場に依存する経験的目安として扱う。

### R2-7 — C2′：三波・四波の共存（§6.1 の C2′ を書き換える条文）

- 重力‐毛細遷移帯では、四波相互作用 S_nl(4) のみで十分とは仮定しない。有限水深・表面張力を含む分散関係から三波共鳴条件を判定し、条件を満たす帯域では三波移送 S_nl(3) を追加候補として評価する。
- 三波項と四波項は代替関係とせず、寄与・相互作用・収支への影響を分けて監査する。Plant 型風入力の適用性は、非線形移送の次数とは独立に検証する。

### R2-8 — C4′：準非滑りの条件化（§6.1 の C4′ を書き換える条文）

- 膜の力学効果は、単一の共鳴周波数による自由滑り／準非滑りの切替として固定しない。表面弾性・表面粘性・表面拡散・吸着脱離・バルク交換を含む界面構成則から、波数・周波数ごとの境界条件と減衰を評価する。
- 準非滑り近似は、界面速度または応力の残差が事前設定した許容誤差以下となる領域に限る。
- 膜から空力学的粗度 z₀ へのフィードバックは、膜による界面応力変化を介する別の閉合として扱い、波の膜減衰と同じ係数で代用しない。膜が風応力を変える機構と、表面波の減衰を変える機構を分ける。

### R2-9 — C7′：36% の書き方（§6.1 の C7′ を書き換える条文）

- 高さ比 (1/2)ka、曲率振幅比 2ka は、採用する非共鳴二次近似と基本波・第2高調波の比較における基準式として扱う。
- ka ≲ 0.3 から得られる (2ka)² ≲ 0.36 は、両モードの曲率分散を独立に比較した場合の目安であり、全 m4 に対する一般的な上限とはみなさない。実際の寄与は、位相相関・交差項・有限水深・QTF 係数を含めて評価する。
- 束縛波は候補の一つとして残し、曲率尖度・歪度・バイスペクトル・スペクトル別 m4 によって寄与を判定する。

### R2-10 — C8′：QTF 格子数の固定解除（§6.1 の C8′ を書き換える条文）

- QTF 評価は低ランク性を採用条件としない（親の既定を維持）。
- 直接評価・FFT・低ランク近似のいずれを使うかは、計算コストと物理量の誤差で選ぶ。格子数 N は固定値を既定にせず、対象波数範囲、共鳴近傍の解像度、曲率統計 m4、バイスペクトルの収束によって決定する。粗い部分格子（N ∼ 64–128）は探索・コスト見積もり用と位置付け、物理的な採否判定には収束確認済みの評価を使う。

### R2-11 — C9′：遮断シンクの配分（§6.1 の C9′ を書き換える条文）

- WKB 適用性は、帯域・場所ごとに評価する。判定量は ε_WKB = λ/(2πL_U) とし、閾値（例： ε_WKB < 0.15）は実装ブリーフで事前登録する。
- WKB 不成立域では、単純転回点には Airy 型、適切なカスティック近傍には Pearcey 型等の一様漸近を候補とし、それらの仮定を満たさない領域では波解像伝播または散乱計算へ切り替える。Airy は典型的な単純転回点、Pearcey は特定のカスティック構造に対応するものであり、すべての非 WKB 領域を救う汎用解ではない。
- 礫床河川では転石周りで全域的に L_U ≲ λ となり得るため、WKB+Airy と波解像伝播の切替閾値を明記する： ε_WKB が閾値を満たし孤立焦線／遮断点のみを持つ場合は WKB＋Airy/Pearcey 一様漸近を適用し、L_U/λ ≲ 3 が面的に広がる礫・転石帯では線形分散・流れ結合を満たす波解像伝播（緩和緩勾配方程式／スペクトル結合ソルバ）へ切り替える。
- 遮断近傍の作用は消失させず、反射・透過・滞留・散乱・砕波・乱流移送に分解して収支を閉じる。不可逆なシンクとして計上できるのは、砕波・乱流散逸等の移送先が定義され、作用または対応するエネルギー収支で確認できた成分に限る。反射された作用はシンクではない。
- Fr→1 の正則化は、該当する支配方程式と臨界条件を別途特定して実施する。

### R2-12 — C10′：相対風の閉合（§6.1 の C10′ を書き換える条文）

- 風入力は、空気・水の共通並進に対して不変な相対速度と応力で評価する。ただし U10−U_surface の単純差を風入力の完全な閉合とはみなさない。
- 基準高度から界面までの空気側速度・応力プロファイル、界面の水面流、波の位相速度を区別し、風入力 S_in は空気側境界層と波齢を含むモデルで評価する。水面流と波の位相速度を同一視してはならない。
- 相対風の定義、風速基準高度、波の位相速度の定義を U3 の環境パラメータ契約で統一する。

### R2-13 — C11′：シア基準の適用条件（§6.1 の C11′ を書き換える条文）

- 有効ドップラー速度は、有限水深の重み核 K(z) = 2k cosh[2k(z+H)]/sinh(2kH) を用いた一次近似として評価する。ただし、この有効速度で分散関係を代表できるのは、鉛直せん断が固有関数・位相速度へ与える補正が許容誤差内にある場合に限る。
- 強いせん断、臨界層、固有関数の大きな変形がある場合は、せん断流を含む固有値問題を直接解く。
- プロファイル曲率 U″(z) と臨界層の扱いは未解決のまま放置しない： 対数則流れ U″(z) ∝ −u*/(κz²) や c_r ≈ U_surface 付近の定常波で Stewart–Joy 弱シア積分自体が成立しない領域を、U_eff − U_surface だけでは検出できない。シア偏差基準は、U8a の誤差予算から逆算する方針を維持するが、誤差予算を満たすことを未検証の近似式の正当化には使わない。
- 注： Gemini の C11′ 修正文案はページ表示自体が途中で切れており全文が取れていない。GPT の修正文案を条文にし、Gemini の文案は統合時に回収する（§3 参照）。

### R2-14 — C13：粘性カットオフの所有権と連続スペクトル（§6.2 の U8a と §6.3 を書き換える条文）

- 高波数側の物理的制限は、単一の硬い k_max ではなく、粘性・膜・砕波・非線形移送等による連続的な散逸・移送として定義する。数値 k_max は物理的制限を代替せず、その外側に未解像の物理寄与が残らないことを収束・感度試験で確認するための数値境界とする。
- 粘性＋膜＋渦粘性カットオフの物理式自体は、新順2（共通分散・散逸土台）または U2a／U4／U6 の物理項として明示する。U8a は「その物理カットオフの下で数値格子収束（m4 不変性）が成立するかを測る純粋な監査役」に限定する。検証ユニットが発電器側の物理項を決める設計にしてはならない。
- §6.3 の「粘性カットオフを物理項として明示（U2／U8a）」は「粘性カットオフを物理項として明示（U2a／U4／U6 の物理項、U8a は監査）」に書き換える。

### R2-15 — C14′：交差スペクトル監査（§6.1 の C14′ を書き換える条文）

- 成分帰属監査は、σ²、m2、m4 の帯域別寄与に加え、成分間の交差スペクトルおよび必要な位相相関を評価する。
- 分散の加算が正当化されるのは、対象成分間の交差項が許容誤差以下であることを確認した場合に限る。重なりが構造的にゼロと主張する場合も、その根拠となる直交性・独立性・投影定義を記録する。

### R2-16 — C15′：閾値≠因果（§6.1 の C15′ に追記する条文）

- 事前宣言した閾値は分類の再現性を担保するものであり、因果同定を保証しない。閾値判定、原因帰属の確信度、識別不能の理由を別々に記録する。

### R2-17 — C16′：帯域境界の場面決定と砕波形状の割当（§6.1 の C16′ を書き換える条文）

- 短重力帯および毛細テールの散逸・移送機構は、波数だけで支配機構を固定しない。砕波、粘性、膜減衰、三波・四波移送、寄生毛細波の各寄与を、風況・波齢・水深・膜状態ごとに評価する。
- 重力帯・遷移帯・毛細帯の境界は、U3 で確定した環境パラメータと共通分散関係から場面ごとに決定する。10–150 rad/m、250 rad/m 以上という値は、既定の標準水条件における初期区分としてのみ保持し、全場面に共通する物理境界として扱わない。
- 砕波は短重力帯の高波数側における有力な候補として扱うが、支配性は測定または収支残差で確認する。毛細テールも粘性・膜・非線形移送の相対寄与を分け、三波共鳴条件を満たさない帯域へ三波移送を適用しない。
- いずれの帯域でも、散逸項だけで砕波中の幾何形状を表現したとはみなさない。砕波中の非気泡性・局所波頂形状変化（微細砕波の非対称段差・ボア前傾）は、第1段の高さ場責務として U5（非線形表面形状補正）または新設の微細砕波形状補正項 Δ_η,brk(x, y, t) へ仮置きし（気泡・飛沫のみ第2段）、U2a／U4 の砕波散逸項と連動して発火させる。「別途定める」のまま未割当にしない。
- C12′ への追記： kpH ≳ 3.5 はピーク付近の深水近似が良好となる目安であり、高波数側の曲率・毛細波統計まで深水近似でよいことを意味しない。有限水深の要否は対象統計ごとに判定する。

### R2-18 — C17′：渦寿命の追跡対象定義（§6.1 の C17′ を書き換える条文）

- τ ∼ H/u* は外層渦の時間スケール推定として扱い、渦寿命の普遍式とはしない。
- 検証では、追跡対象を明示したラグランジュ相関（流体粒子速度または渦構造量）を用い、ω−k 線幅から得る時間スケールと照合する。追跡対象（粒子速度／渦構造の中心／渦度・渦識別量）を定義せずに相関時間を測ってはならない。
- ω−k 線幅にはせん断・空間不均一・有限窓の寄与が含まれるため、それらを分離したうえで渦寿命を推定する。スケール依存・非指数減衰を許容し、単一の τ へ強制しない。

### R2-19 — C18′：メニスカスのサブグリッド（§6.1 の C18′ を書き換える条文）

- 静的メニスカスの限局性は、平衡接触角・濡れ性・幾何形状が既知で、接触線が静止または準静的である場合の基準として扱う。
- 動的接触線では、接触角ヒステリシス、ピン止め、動的接触角、毛細波放射を含む境界条件を用いる。
- 格子間隔 Δx > ℓ_c（ℓ_c ≈ 2.7 mm）の通常格子では、メニスカスを離散高さ格子へ直接焼き込まず、接触線距離場 d_contact に基づく解析的サブグリッド法線・曲率補正（または接触帯の局所細分化）として光輸送交差側へ渡すか解析評価し、格子解像度依存性を排除する。格子が毛細管長を解像できない場合は、未解像境界層として扱い、解析勾配との一致だけでなく、接触角・接触線位置・境界力の収束を確認する。

### R2-20 — U5 寄生毛細波の保存結合と U12 乱流生成閉合（§6.3 の追加義務を書き換える条文）

- **U5 の寄生毛細波エネルギー生成量 ΔE_pc(x, y) の保存結合**： U5 の寄生毛細波エネルギー生成量 ΔE_pc(x, y) を空間平均して、次ステップまたは反復収束で U4 の S_ds,pc へ返す保存結合手順を明記する。空間局所の波頂急峻度で発火するポスト段（U5）と、作用収支の体積生成／散逸項 S_ds,pc の間を片道でつないではならない（閉ループなしでは必ず誤差が出る）。
- **U12 の乱流生成閉合**： §6.1 に対応主張を追加する（C20 とする）：「流れ乱流の生成・移送・減衰は U12 が閉合し、底面から表面までのエネルギー移送経路を明示する。Horoshenkov 経験式（σ_C ∼ u*²/g）の置き換えは、生成閉合の形で定義する。」U8b-b の検証項目に、Dolcetti 実測 σ_C との照合を追加する。
- **第1段⇔第3段の CL 渦力の受け渡し**： 第1段と第3段の間では、波の軌道運動、Stokes 輸送、波に由来する平均力、Langmuir 循環の表面速度を別の物理量として受け渡す。各量の定義、平均化時間、座標系、符号、保存対象を接口契約に記載し、同一の運動量輸送または平均流を二重計上しない。第3段から第1段へ返す u_LC は、波由来の速度成分を含むか否かを明示する。

### R2-21 — U4/U5 の S_nl 接口と U2a の砕波（§6.2 の U4・U5・U2a の責務を書き換える条文）

- U4 は、波作用収支の演算子インターフェースと、既存の四波移送の実装を担当する。U5 は、束縛波による位相結合、Wilton 共鳴、寄生毛細波等の追加機構を独立項として実装する。U5 の追加項は U4 の演算子契約へ接続し、U2b で全項を含む最終収支を閉じる。U4 の完了は、後続機構を追加できるインターフェースが検証されたことを意味し、全非線形移送が確定したことを意味しない。
- U2a では砕波の収支項、入力変数、出力変数、保存対象、幾何形状への影響の接口を定義する。係数・適用域・高波数側の拘束強度は U8a の物差しと実測に基づいて校正し、U2b で最終閉合する。U2a で砕波の支配性や係数を先行確定しない。

### R2-22 — U8a の格子条件の分離と QTF 適用性判定（§6.2 の U8a と §6.1 の C6′ への追記）

- 格子収束は、少なくとも波動スペクトルの高波数制限、曲率統計、接触線・メニスカスの境界層を別々の解像条件として評価する。毛細管長 ℓ_c の解像性を、粘性・膜による高波数散逸の解像性の代用にしない。各物理スケールについて、未解像時の境界条件または有効モデルを明示する。
- QTF の適用性は、QTF が近似する二次自由表面境界条件の残差、共鳴分母の大きさ、対象モードの振幅誤差、曲率統計およびバイスペクトルの誤差で判定する（R2-5 と同じ）。
