### U1 土台：表面運動学の出力ポート

- **目的**: 現行ジェネレータの出力は高さ場 η(x,y,t) だけである。膜輸送（U4）・素材線（第2段）・表面収束場はすべて「表面がどう動くか」を必要とし、η から場当たりに導いた速度では物理が違う。本ユニットは表面運動学を状態量として正式に出す口を作る。
- **物理的根拠**: 線形波の軌道速度（速度ポテンシャルから z=η での表面軌道速度）、2 次の平均ラグランジュ輸送である Stokes ドリフト、Euler 的な表面流速の三者は別物として区別する。流れレーンでは強制成分ごとの表面速度を合成する。
- **既存生成器への変更**: 風波レーン・流れレーン双方に出力ポートを追加する： 表面軌道速度 u_orb(x,y,t)、Stokes ドリフト U_S(x,y)、素材輸送速度 U_mat = 表面流速 + U_S。η の生成式そのものは変えない。
- **入力／出力**: 入力は既存の場面パラメータのみ。出力は上記 3 場（η と同じ格子・時刻列）。
- **検証（見た目でなく測定）**: 単色波 1 本での閉形式照合（軌道速度・Stokes ドリフトの解析値と一致）。周期箱での Euler 平均流速の正味ゼロ確認。エネルギー流束との整合（群速度流束と一致）。

### U2 土台：風波エネルギー収支の閉合

- **目的**: Elfouhaily スペクトルは「釣り合った形」を処方しているだけで、収支が点検されたことは一度もない。L2（U4）の緩和率の供給源として、また処方スペクトル自体の監査として、収支を計算可能にする。GPT の位置づけどおり **L2 の前提**。
- **物理的根拠**: 波作用／エネルギーバランス ∂E/∂t + ∇·(c_g E) = S_in + S_nl + S_ds。S_in は Miles／Plant 系の風入力、S_nl は非線形移動、S_ds は粘性＋砕波＋寄生毛細波への散逸（U10 と接続）。処方スペクトルと場面の風を与えたとき各項が釣り合うかを帯域ごとに採点する。
- **既存生成器への変更**: 風波レーンに収支モジュール（診断層）を追加する。当面は η の出力を変えない。帯域別緩和率 τ(k) の表を U4 へ渡すのが本ユニットの納品物。
- **入力／出力**: 入力＝処方スペクトル、U10、フェッチ等の場面量。出力＝帯域別 S_in／S_nl／S_ds と不均衡量、τ(k) 表。
- **検証**: 深水・十分発達の極限で収支が許容誤差内に閉じること。フェッチ制限成長（JONSWAP 成長則）との照合。不均衡が大きい帯域は「処方形が場面と釣り合っていない帯域」として名前を付けて報告する（黙って通さない）。

### U4 L2：波作用バランス＋帯域別緩和＋独立膜場（L1 の口を含む）

- **目的**: 突風構造（cat's paws）を正しい形で入れる。局所平衡は棄却済み（λ=0.2 m で緩和 約45秒）。同時に、表面膜を独立した物理場として持ち、その輸送に必要な表面収束・ひずみ場の口を第1段に開ける（L1 の決着：第1段が出す状態量。Langmuir の渦ロール自体は第3段、素材の見た目は第2段 — §3 参照）。
- **物理的根拠**:
- 波作用バランス： ∂N/∂t + ∇·((c_g + U)N) = S_N/ω。帯域別緩和時間 τ(k) は Plant の成長率から（U2 が供給）。風の場 U10(x,y,t) は自身の移流速度で動き、波の場は履歴を積分する。**後掛けの乗算変調は禁止**（RALLY-COHERENT C5 決着： 作用保存を破り、偽の勾配・曲率を作る）。
- 膜場： 濃度 c(x,y,t) を持つ独立スカラー。移流は U1 の素材輸送速度、源泉／消失（拡散・取り込み）を持ち、減衰は Marangoni 共鳴帯（3–10 Hz 級）の追加散逸として作用バランス側に入る。グレースケールマスク＋一様減衰係数は物理モデルとして認めない（GPT の指摘を採用）。
- 膜は風のない場面でも要る（流れ・湧水・生物起源の膜）。風レーン専用にしない。
- 収束・ひずみ口： 表面速度場から ∇·u_s とひずみ率成分を出力する。これが膜と（第2段の）素材線を運ぶ場になる。筋を高さ場に描くことはしない（全席一致）。
- **既存生成器への変更**: 風波レーンに作用バランスの時間発展層（少なくとも突風帯）を追加し、処方スペクトルの静的生成と併存させる（併存の境界は τ(k) で決める）。膜場を新しい状態として追加。流れレーンにも収束・ひずみ口と膜場を共通の形で付ける。
- **入力／出力**: 入力＝突風の風場、膜の初期被覆・弾性、環境スカラー。出力＝η、膜場 c、収束・ひずみ場。

### U5 L3：束縛波（Sharma–Dean）＋寄生毛細波

- **目的**: 線形・ランダム位相の面に 2 次の位相結合を入れる。狙いは高さではなく**曲率**： 線の密度は ∇²η で決まるため、束縛波は細線過剰（未解決）の有力候補である（Gemini の指摘を記録済み）。
- **物理的根拠**:
- Sharma–Dean 型 QTF： 和・差周波数の 2 次補正 η₂。重力帯が対象。ただし表面張力を入れた分散では Wilton 共鳴近傍で分母が発散し、池の主帯域（λ 1–20 cm）で純重力 QTF は破綻しうる（RALLY-COHERENT C2 決着）。→ 分母は表面張力込みで評価し、共鳴近傍は QTF の適用外として切り分け、寄生毛細波側で扱う。
- 寄生毛細波は別機構： 急峻な峰の前面に位相固定で付く小波（Longuet-Higgins 系）。QTF の平均からは出ない。峰の勾配・曲率が閾値を超えた場所に、親峰から決まる形で生成する。
- 前提条件（決着済み）： QTF カーネルの低ランク性を先に実測する（固有分解の再構成誤差と実測コスト）。低ランクでなければコストの前提が崩れる。
- 浅水（H=0.6 m 級）では Ursell 数を点検し、2 次で足りない帯域は適用外として明記する。
- **既存生成器への変更**: 両レーンの線形場への後段補正として η = η₁ + η₂ を表面状態に挿入する（光学側ではなく水面状態側で足す）。寄生毛細波は流れレーン・風波レーン共通の生成段として追加。
- **入力／出力**: 入力＝線形場 η₁ とそのスペクトル。出力＝補正後の η と、帯域別の曲率変化量（m4 への寄与、U8 と接続）。
- **検証**: Stokes 波テスト — 解析的な峰／谷非対称（skewness の符号と大きさ）を再現すること。出力のバイ・スペクトルが QTF の予言する三つ組みに位相結合を持つこと（線形場ではゼロ）。m4 の変化量を測定して報告すること（見た目の線の増減では判定しない）。

### U6 L4：U(x,y) 2分枝分散＋波作用保存（＋風×流れ結合＋鉛直シア基準）

- **目的**: 流れレーンの「一様な U」前提を外す。流れが場所で変わる場面で、定常波の波数・振幅・消滅（遮断）を物理で決める。あわせて風×流れの結合と、鉛直シアを無視できる条件の判定基準を同じ枠で決着させる。
- **物理的根拠**:
- 静止位相条件を局所化する： 固有周波数 σ(k) = k·U(x,y)、完全分散 σ² = (gk + γk³/ρ)tanh(kH) は **2 分枝**（下流の重力枝＋上流の毛細枝 λ<1.73 cm）を与える。分枝の合体・遮断がありうる（GPT の注意を採用）。
- 振幅は波長伸縮だけでは決まらない。**波作用の保存**（光線に沿う ∇·((U + c_g)N) = 源）を振幅の閉じ方にする。屈折・焦散・減速域での急峻化はここから出る。
- WKB（緩変）レジーム判定を必須とする： 流れの変化スケール L_U ≫ λ の帯域だけに適用し、外れる場所（遮断近傍・焦散）は「適用外」と旗を立てる（黙って補間しない）。
- 風×流れ： S_in の風は**相対風** U10 − U_surface で評価する（3 席独立に指摘）。逆流での圧縮・急峻化と遮断は作用保存から出る。単純加算は分散と作用保存に反するので採らない。
- 鉛直シア基準： 一様流近似が許せる条件を帯域ごとに判定する基準を作る。有効ドップラー速度 U_eff(k)（鉛直プロファイルの e^{2kz} 重み平均）と表面流速のずれが、その帯域の位相速度に対して閾値を超えたら、その帯域はシア扱いが必要か適用外かを明記する。
- **既存生成器への変更**: stream_surface3.py — リング半径 k0 を k0(x,y) の場にし、振幅の閉じを局所 σ 回帰のみから作用保存に移す。DK テールは光線に沿って移流させる。底応答 (i) の会計（DESIGN-V4-1-4）は不変。
- **入力／出力**: 入力＝U(x,y) 場（と鉛直プロファイル、必要な場面のみ）、H(x,y)。出力＝η、帯域別の適用可否マップ（WKB 判定・遮断位置）。
- **検証**: 一様極限で現行 v4-1.4 の出力を厳密に再現すること（回帰）。解析テスト — U が 2 倍になる領域へ入る波列の波長・振幅変化が作用保存の予言と一致すること。遮断テスト — U = c_g となる条件で上流枝が止まること。

- **目的**: Elfouhaily は深水前提だが、うちの場面は H 0.05–1.0 m で kH ≲ 2 の帯がある。その帯では深水形は中立な近似ではない。風波レーンに有限水深を入れる。

- **入力／出力**: 入力＝H（場面の水深、必要なら H(x,y)）。出力＝補正後の η と、帯域別の補正量。

### U12 流れ乱流の時間減衰

- **目的**: 流れレーンの乱流成分は凍結した Taylor 移流に近い。渦パッチは変形・減衰・再生するもので、その時間尺度 τ ∼ H/u* を入れる。

### U13 接触線メニスカス

- **目的**: 水面に出た岩・岸・植生との接触線に立つ毛細管曲面を、第1段の境界条件として扱う。

- **既存生成器への変更**: 両レーンに境界条件の口を用意するだけ（形状そのものは第2段から来る）。接触角は場面入力。
- **検証**: 解析メニスカス形状との照合（ℓ_c での指数減衰、勾配の連続性）。

#### R2-5 — C6 の Wilton 共鳴振幅方程式（§6.1 の C6′ を書き換える条文）

**置き換える対象**： 親 §6.1 の C6′「Wilton は 1:2 三波共鳴として非線形枠組みの中で扱い、寄生毛細波は独立機構のまま別置する。QTF の適用域は宣言でなく固有値／残差の実測で決める。」

- **共鳴の定義**： Wilton 共鳴は、基本波と第2高調波の 1:2 共鳴として扱い、寄生毛細波とは別機構に置く。共鳴判定は、採用する有限水深・表面張力・流れを含む分散関係に対して、周波数整合 ω₂ = 2ω₁ および波数ベクトル整合 k₂ = 2k₁ を満たすかで行う。「1:2」と書くだけでは足りない。
- **結合振幅方程式**： 共鳴近傍では、非共鳴 QTF の単純評価を継続せず、共鳴する複数モードの振幅を同時に解く結合振幅方程式へ切り替える。基本波の振幅 a₁ と第2高調波の振幅 a₂ を同時に未知量とし、da₁/dt = i·V₁₂·a₁*·a₂、da₂/dt = i·V₂₁·a₁² の形で書く（V₁₂、V₂₁ は採用する二次核から決まる結合係数。係数の導出元と値は実装ブリーフで固定する）。QTF の残差・固有値診断は切替判定の一部とし、三波共鳴の解法そのものの代替とはしない。
- **QTF 適用性の判定**： QTF の適用性は、QTF が近似する二次自由表面境界条件の残差、共鳴分母の大きさ、対象モードの振幅誤差、曲率統計およびバイスペクトルの誤差で判定する。「固有値」を用いる場合は、対象とする線形化演算子または結合振幅系を明記し、QTF 単体の固有値とは呼ばない。
- **寄生毛細波との分離**： 寄生毛細波は独立機構のまま別置する（親の既定を維持）。Wilton 共鳴の振幅方程式と寄生毛細波の生成項を混同してはならない。

#### R2-6 — C1′：膜輸送の位相平均／瞬時の分離（§6.1 の C1′ を書き換える条文）

#### R2-18 — C17′：渦寿命の追跡対象定義（§6.1 の C17′ を書き換える条文）

- τ ∼ H/u* は外層渦の時間スケール推定として扱い、渦寿命の普遍式とはしない。

- ω−k 線幅にはせん断・空間不均一・有限窓の寄与が含まれるため、それらを分離したうえで渦寿命を推定する。スケール依存・非指数減衰を許容し、単一の τ へ強制しない。
