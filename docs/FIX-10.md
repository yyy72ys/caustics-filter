# FIX-10: 勾配スペクトルの帯域別再較正（変位は長波長から作る）

対象: `caustics-filter/web/`（shader.js / env.js）
前提: FIX-9 の三角形メッシュ前方方式・単一較正の枠組みは維持。パターン描画への回帰は禁止。

## 実ブラウザ目視判定（メイン側、FIX-9）
- プリセット0拡大: FIX-8 とほぼ不変（粒のまま）。プリセット1: 斜めの規則的なドット列が出現（新たな人工感）。
- dsh の分析と一致: DISP_K=5 の一様増幅では、短波長成分まで増幅されて 7〜13層の多重折り畳み＋単画素カスプが発生し、max 66.9 爆発・孤立点率上昇。K=1.5 では面は coherent だが変位 std が目標未達。
- 結論: 不足しているのは変位の「量」ではなく「波長構成」。実在の水面では変位（＝勾配×水深）の大半は長波長成分が担い、短波長は縁の微細構造だけを担う。

## 変更指示
1. **帯域別変位ゲイン**: 着地点変位の計算に使う勾配を帯域別に重み付けする。波成分を波長で3帯域に分け、変位寄与のゲインを L（長波長）=1.0、M=0.55、H（短波長）=0.25 を初期値とする（法線・反射など変位以外の用途の勾配は現行どおり全帯域）。帯域境界は現行の L/M/H 分けを流用。
   - 狙い: 変位 std 0.02〜0.15 を、短波長を暴れさせずに長波長の折り畳みで達成する。
2. **DISP_K の再較正**: 上記ゲイン導入後に、単一の DISP_K を再較正する（手順は FIX-9 と同じ: 全プリセットで変位 std が範囲内、かつ max が 6〜12 に収まる K を選ぶ）。K の候補は 1.5〜3.5 の範囲を優先し、それでも std 未達の場合のみ上限を広げる（理由を RESULT.md に記録）。
3. **指標の是正（dsh の申送り採用）**: 「孤立点率の半減」は点描画ベースライン前提で三角形方式には不適合だったため廃止し、代わりに次を合格条件とする:
   - max（高解像ミラー）6〜12、平均 1±0.15、min ≤0.5（従来どおり）
   - 相関が FIX-5 水準以上（従来どおり）
   - 新規「面の指標」: 密度マップを画面幅の 1/32 ブロックで平均した粗視化マップについて、ブロック値の標準偏差/平均（変動係数）が 0.25 以上（＝大きなスケールの明暗＝面のドメインが存在する）。FIX-9 時点の同指標をベースラインとして RESULT.md に併記する。
4. プリセット1の斜めドット列について: 帯域別ゲインで H 帯域の変位寄与が下がることで緩和される想定。残る場合は、方向分布の離散性（成分数に対する方向量子化）を疑い、H 帯域の方向サンプルを増やす／位相に成分ごとの微小ジッタを入れる、の範囲で対処する（模様の追加は禁止のまま）。
5. その他の完了条件は従来どおり（node --check、ループ一致、RESULT/STATUS 記録、ブラウザ実測はメイン側）。
