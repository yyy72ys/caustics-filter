以下に、設計案に対する攻撃的レビューの結果を示す。

1. 主張ごとの判定と反論
D1：単一 seed・単一フレームの G-LINE 合否はモデルの性質ではない

判定：WEAKENED

根拠：smooth x（0.91–1.07）、smooth y（0.93–1.02）、bark x（0.78–1.07）の 3 窓はすべて 1.00 を跨いでおり、単窓レベルでは seed 依存の確率的揺らぎが大きい。

反論：

引用根拠の論理矛盾：「5 realization で全窓通過が 0 本」という事実は、単一 seed 判定が「モデルの性質ではない」ことではなく、むしろ**「単一 seed でも現行ゲートは 100%（5/5）一貫して FAIL を返しており、bark y の系統的超過（平均 +12.0%）＋4 窓 AND の厳しさを安定して検出できていた」**ことを示している。単一 seed の結果が揺れると言うなら、比較すべきは全窓合否ではなく「各窓の通過率のばらつき」である。

単一フレームへの飛躍：背景データには frame 24 以外の実測が一切ない。フレーム間変動の実測値ゼロのまま「単一フレームもモデルの性質ではない」と断定するのは根拠不在である。

D2：窓ごとの比の分布（平均＋散らばり）で判定すれば、合否はモデルの性質になる（R = 5 × F = 3, n = 15 と SE 明記が条件）

判定：WRONG

根拠：分布を見ること自体は単発より情報が増えるが、R = 5, F = 3 の設計で「合否がモデルの性質になる」という主張は統計的に成立しない。

反論：

D5 との自己矛盾：D5 で「ループ内フレームは独立でない」と認めながら、n = 15 として標準誤差 SE = s / √15 を算出すれば、真の SE を最大 √3 ≈ 1.73 倍 過小評価する。

R = 5 の圧倒的標本不足：実効標本数が R = 5（自由度 4、t_{4, 0.975} = 2.776）のとき、例えば bark x（範囲 0.78–1.07、概算 sd ≈ 0.11）の平均の 95% 信頼区間は ± 2.776 × (0.11 / √5) ≈ ±0.14（幅 0.28）に達する。真の平均が 1.00 の無偏モデルでも、5 本の引き次第で mean > 1.05 を踏んで容易に不合格になり、逆に真の平均が 1.08 の不良モデルも普通に合格する。

q90 の崩壊：R = 5 の 90 パーセンタイルは実質「5 本中の最大値（または上から 1〜2 番目）」であり、1 本の極端な seed に支配される。これに基づく二値合否は依然として「引きの運」であり、モデルの性質にはならない。

D3：写真側も分布として扱うべきで、窓配置ジッター（sd 3.5〜9.9%）を測定床にするのが最小限の是正である

判定：WEAKENED

根拠：写真 1 枚を無誤差の点（真値）とみなす誤りを指摘した点は正しい。しかし、提案された「窓配置ジッター」はその是正になっていない。

反論：

分散の種類の取り違え（疑似反復）：モデル側の散らばりは「異なる波の realization（seed 差）」由来であるのに対し、写真側の ±24 px シフトは「同一の 1 枚の写真内部の空間的非定常性（主に床の木目や局所テクスチャのズレ）」しか測っていない。もしその 1 枚の写真自体が現実の水面の「たまたま穏やかな瞬間（-10% の引き）」だった場合、窓を ±24 px 動かしても分母全体のバイアスは 1ミリも補正されない。

実測の不一致：写真ジッター sd は smooth x 3.5%・bark x 9.9% と窓ごとに約 3 倍違うが、これはコースティクスの性質ではなく bark テクスチャの空間的不均一性 を拾っている可能性が高い。

判定規則への未反映：測定床として併記すると言いながら、合格閾値は全 4 窓一律 1.05 / 1.25 のままである。smooth x の +5% は +1.4σ なのに bark x の +5% は +0.5σ に過ぎず、「写真側を分布として扱う」という主張と判定ロジックが接続していない。

D4：判定規則「窓平均 ≤ 1.05 かつ q90 ≤ 1.25、全 4 窓」は実測に較正されており、系統的超過と不利な引きを分ける

判定：WRONG

根拠：v4-1.10 の 5 本（非問題窓の平均 0.946–0.984・最大 1.02–1.07 対 問題窓 bark y の平均 1.120・最大 1.29）の隙間を縫うように線を引いている。

反論：

循環論法（Texas Sharpshooter 誤謬）：設計自身が「1.05 / 1.25 は観測ギャップへの配置値」と認めている通り、これは単一バージョン・5 seed の手元データの隙間に事後的に線を引いただけ（overfitting）であり、別モデルや視覚的良否の独立データに対する汎化能力はゼロである。「較正されている」という表現は虚偽に近い。

相関データでの q90 ≤ 1.25 と「未解決」トラップ：フレーム間相関が高ければ、5 seed 中たった 1 seed が全 3 フレームで高値（例：1.26）を出しただけで 3/15 = 20% が汚染され、q90 はその 1 seed の値で確定する。さらに、seed 単位のブロック・ブートストラップを行えば、5 seed 中の最大値（例：1.26）が再標本から外れる確率は (4/5)^5 = 32.8% もあるため、2 番目が 1.10 以下なら q90 の 95% 信頼区間は [≤1.10, 1.26] となって確実に 1.25 を跨ぎ、ゲートが慢性的に「未解決」を吐いて停止する。

分母依存の非対称性：写真の基準 depth は smooth x = 63.7‰ に対し bark y = 39.3‰ と 1.6 倍差がある。同じ +4.5‰ の絶対過剰でも、比にすると smooth x は +7.1%、bark y は +11.5% に化ける。比だけで一律 1.05 を課す正当性がない。

D5：1 ループ内のフレームは独立標本ではない、実効標本数は realization 数で数えるべきである

判定：STANDS（※ただし原理としては正しいが、提案設計自身がこれに違反・不整合を起こしている）

根拠：同一 seed の時間連続フレームには強い正の自己相関（級内相関 ρ）があるため、フレーム数倍で有効サンプル数が増えるように扱うのは典型的な疑似反復である。

反論（不完全な点と設計との矛盾）：

厳密な式の欠落：実効標本数は必ず R 固定ではなく、級内相関 ρ に応じて N_eff ≈ R·F / (1 + (F - 1)·ρ) となる。ρ を実測せずに「常に R で数えよ」と言い切るのは最悪ケース（ρ = 1）の決め打ちである。

フレーム選定の致命的バグ：提案は「2 秒ループから frame 0 / 24 / 47」を抽出しているが、24 fps の 2 秒ループ（48 フレーム：0〜47）では frame 47 と frame 0 はループ境界を挟んで 1 フレーム（約 42 ms）しか離れていない隣接フレーム である。実質的に独立な位相は「0/47 付近」と「24」の 2 点しかなく、F = 3 のうち 1 枚分を自らドブに捨てている（等間隔なら 0 / 16 / 32 にすべき）。

D2・D4 へのブーメラン：n = 15 で q90 や SE を語る D2・D4 は、まさに D5 が禁止した「水増し」に依存している。

D6：G-LINE-stat と G-LINE2 は独立な 2 軸として併用でき、4 組合せはすべて意味を持ち、どちらも本人の目の判定を上書きしない

判定：WEAKENED

根拠：振幅分布（depth）と空間周期性（2D FFT 突出度 prom2d）は別側面を測ろうとしている点には一定の合理性がある。

反論：

物理的・統計的に独立ではない：G-LINE は「5–15 px 帯の変調深さ」を測る。もし 5–15 px 帯に固定周期の格子ノイズが乗れば、パーセバルの等式により同帯域のパワーが増え、prom2d だけでなく depth も同時に押し上げる（正の相関）。また写真自身の単窓最大 prom2d = 104 が格子並みに達している事実は、G-LINE2 も G-LINE（bark x 9.9% ジッター）と同様に背景の床テクスチャ（木目等）に強く交絡していることを示す。

2×2 の破綻と検出力不足：G-LINE-stat に「未解決」が追加された時点で組合せは 4 通りではない。さらに G-LINE2 の実測では、「問題の作品」が 25.4（写真の 1.21×）に対し本物の格子が 105.6〜116.2（5.0〜5.5×）であり、問題の作品と写真（21.1）の差はわずか 1.21× しかない。G-LINE2 は「問題の作品」を明確に分離できていない可能性がある。

「目を上書きしない」の無力化：合格でも目視で落とせ、不合格でも目視で通せるなら、それは意思決定ゲートではなく単なる参考ログであり、都合の悪い FAIL を人間の主観で握り潰す抜け道（確証バイアス）になる。

2. 設計の失敗条件（誤った合格／誤った不合格）

誤った不合格（False Fail）の量産：

4 窓 × 2 指標（計 8 条件）の AND 判定による多重検定：仮に無偏・正常なモデルでも各窓の棄却率が 10% あれば、4 窓全通過確率は 0.9^4 ≈ 65.6% まで落ち、約 34% が運悪く落ちる（または「未解決」に陥る）。

q90 の 1 本釣りとループ境界バグ：R = 5 のうち 1 seed だけが 1.26 を引いた場合、frame 0 / 47 がほぼ同じ値を返すため 15 点中 2〜3 点が 1.26 になり q90 ≤ 1.25 を即座に落とす。

誤った合格（False Pass）の抜け道：

参照写真 1 枚の偏り：唯一の参照写真（特に最も低い bark y = 39.3‰ や高い smooth x = 63.7‰）が現実の水面分布の中で極端な引きだった場合、それに合わせた ≤ 1.05 は視覚的に過剰・不足なモデルを堂々と合格させる。

5–15 px 帯以外・斜め方向の破綻：軸平行（x / y）かつ 5–15 px に限定しているため、45° 方向の格子縞や、16–30 px の低周波モヤ・3 px 以下の高周波ザラつきは完全に素通りする。

「土台変更時の再較正」によるゴールポスト移動：

「stage 2 で閾値を測り直す」運用は、独立した複数枚の写真や事前登録基準がない限り、「新しいステージのモデルが通るように閾値を引き直す」という自己正当化ループに直結する。

3. 見落としている機構・論点

統計量としての depth（変調深さ）の限界：

コースティクスの「らしさ」は明暗の幅（depth）だけでなく、尖度・歪度（鋭い光の筋と広い暗い谷の非対称性） や 2 次元空間周波数スペクトルの傾き に宿る。ぼやけた正弦波と鋭い網目模様は同じ depth を持ち得るため、平均と q90 を追っても視覚品質と乖離する。

時間領域の実測ゼロ（F = 3 の妥当性未検証）：

異なるフレームで depth がどれだけ動くのか（級内相関 ρ が 0.99 なのか 0.2 なのか）の実測がないまま F = 3 を決めている。もし ρ ≈ 0.99 なら複数フレーム取得は計算コストの無駄であり、逆に ρ ≈ 0 ならわずか 5 seed × 3 frame より 1 seed × 15 frame の方が低コストで分散を削れる。

軸平行 4 窓の定義と空間サンプリングの恣意性：

bark x で ±24 px ずらすだけで sd 9.9% も動くのは、窓サイズまたは位置設定が局所的な樹皮テクスチャと干渉している証拠である。特定の 4 窓を固定して追うこと自体が空間的オーバーフィットを生む。

4. 採用するなら最低限直すべき点（優先順位つき 3 点）

擬似反復の廃止：解析単位を realization に統一し、n = 15 の q90 を捨てる

まず数 seed でフレーム間相関 ρ を実測し、ループから採るなら等間隔位相（例：0 / 16 / 32）で取得して**各 seed 内で 1 つの要約値に集約（seed 内平均や最大値）**する。その上でゲート判定は seed 単位（N = R）のみで行い、R = 5 のまま不安定な q90 と「未解決ブートストラップ」は廃止する（最低でも R ≥ 10〜15 に増やすか、平均＋seed 内最大値の単純上限に切り替える）。

写真側の「1 枚シフト」を本物の複数参照（または窓別許容誤差への組み込み）へ改める

1 枚の写真の ±24 px シフトを「写真の分布」と呼ぶのをやめ、可能な限り複数の実写写真（または別時刻・別領域の独立カット）で実測分布を取る。どうしても写真 1 枚しか入手できないなら、全窓一律の 1.05 をやめ、測定済みの床由来ジッター（3.5%〜9.9%）を各窓個別の許容マージン（または z-score）として判定式に直接組み込む。

ゲートの権限と G-LINE2 との結合を事前検証で固定する

「目視を上書きしない」を改め、ゲート不合格時は原則ブロック（例外解除には別理由の明文化を必須化）とする。同時に、既知の良作・問題作（「問題の作品」prom2d = 25.4 を含む）で depth と prom2d の相関を測り、v4-1.10 の隙間ではない事前定義の基準値（Stage 2 移行前ロック）として確定させる。
