## 検証する主張

### K1 — 条件 1：P₁ 第3項の原文確定と B± 採用式の固定（U-2・U-1）

R5 は WAFO 原文の直接読みで P₁ 第3項を `g * 2.` と確定し、WAFO Langley 分岐を破棄した。2D 一般角形の採用式は MF12 Lambda2 で確定し、単色波アンカー（≤5.4e-16）・θ=0 での訂正 Langley 形との一致（≤1.5e-14）・自己相互作用・対称性・極構造で検証した。G-C1-0 の「実装時」矛盾を「設計承認前」へ訂正した。

問うこと：`g * 2.` の確定は原文の直接読みとして成立しているか。WAFO 分岐の破棄は正しいか。MF12 Lambda2 を採用式とすることの検証は十分か。g² 訂正形を「推論であり原著の確定ではない」と明記した置き方は正しいか。θ=0 での一致だけで 2D 一般角形を確定したと言えるか。

### K2 — 条件 2：分離形 S1 の事前固定（U-8）

R5 は 2D 分離形 S1 の具体式・対応表・正規化を §2.2.2 に固定し、Lambda2・訂正 Langley 形と 1.2e-14 で一致することを確認した。試験 0 実装前に固定した。

問うこと：S1 の対応表・正規化は試験 0 の前に仕様として閉じているか。1D 切片で通った分離形を 2D へ無検証で外挿する余地は残っていないか。

### K3 — 条件 4 前半：G4・G5 の数式訂正

R5 は χ₄² 予測帯を [0.60, 2.87] から [0.35, 1.67] へ訂正した（R4 の帯は真の σ の 95% 信頼区間 [sqrt(4/11.143), sqrt(4/0.484)] = [0.599, 2.875] を予測帯として誤用したもの。正しくは自由度 4 の標本 SD の予測帯 [sqrt(0.484/4), sqrt(11.143/4)] = [0.348, 1.669]）。λ₃,exact の算出元を 2D 厳密カーネル（MF12 Lambda2）＋生成器と同一の 1.5 m 離散スペクトル格子へ固定した。ν_probe をプローブ時系列の片側パワースペクトル E(ω) の周波数モーメントに統一し、帯域ラベルを「低・中・高波数帯」へ直し、Δm₄ の評価帯を QTF 対象帯 ≤200 rad/m と明記した。5 本の 2D 独立検証シードの計算枠を確保した。

問うこと：予測帯の訂正は数学的に正しいか。λ₃,exact の算出元は 2D 本番場と整合しているか。ν の定義の統一は、空間分散式と時系列周波数モーメントの不一致（束縛波 η₂ は線形分散に乗らず 2k_p で 2ω_p を持つ）を解消しているか。5 本の 2D 参照の経路は設計上存在するか。

### K4 — 条件 5 前半：G8 の Wilton 閾値・2k_max・分母

R5 は Wilton 閾値 0.05 の根拠を固定した（相対離調 δ=0.05 では分母 D± ≈ 2δ·ω² ≈ 0.1·ω² となり非共鳴時の約 1/10 に縮んで応答が約 10 倍に増幅される領域を「共鳴近傍」として分離する事前登録の設計選択。由来は LEG-GEMINI.md F8・LEG-GROK.md F8 の例示値で、物理定数ではない）。テーパ [100,120] に対する 2k_max を 200 から 240 rad/m へ訂正した（毛管項比は k=120 で 10.7%、k=200 で 29.7%、k=240 で 42.7%）。分母を max(|ω±|, ω(k±)) へ修正し、ω₋→0 のゼロ除算を防いだ。経路 A の着手期限を「P5 試験 0 の判定（J0–J7）の着地時。遅くともフェーズ 2 の開始前。期限を過ぎても未着手ならフェーズ 2 は開始しない」と明示した。

問うこと：Wilton 閾値 0.05 の根拠は「例示値を事前登録した」というだけで十分か。2k_max=240 への訂正は正しいか。出力波数側の毛管項比の評価は十分か。経路 A の着手期限は、フェーズ 1 の「重力帯に限定」の永久化を防ぐものになっているか。

### K5 — 条件 5 後半：G3・G7 の境界細部

R5 は a_z < −0.5g を重力帯（k ≤ 100 rad/m へ低域通過した η₁+η₂）に限定した。0.5g の根拠は純重力 Stokes 波頂の限界加速度、1% は谷反転バンプ率と同じ 1% 水準に揃えた事前登録の設計選択であることを明記した。破綻兆候の項目数の不整合を 5 項目に統一した。「低周波 η₂⁻」を f < 0.5·f_p（P5 で f_p=1.875 Hz → 0.9375 Hz）とし、5 シード平均で測ると固定した。R(τ) は静止成分 ⟨η₂⁻⟩_t を分離除去した変動成分について測り（静止成分は Var 比 ≤0.05 で独立判定）、τ_int の積分範囲 [0,4s]・打ち切り規則を固定した。8 s と 16 s の一致を「長周期が十分」と言い換えない。

問うこと：a_z の重力帯限定は、毛管項が支配する短波長毛細波の誤判定を防ぐものになっているか。m₄ > 1.5 m₄,lin の評価帯域は QTF 帯域と明記されているか。低周波の定義とシード数は、8 s 記録に包絡群れが ~5 個しか入らない標本揺らぎに対処できているか。τ_int の打ち切り規則は一意か。

### K6 — G1・G6：試験 0 の 2D 化とゲート分離

R5 は切替閾値の導出（m₂ 0.056% = 2%×2.8%、m₄ 0.784% = 7%×11.2%）を §2.3 に文書化した。U-1・U-2 が閉じたため試験 0 は 2D 本番場へ戻し、J0 の数値と 1D 切片の数値の混在を解消した。参照 A と比較対象 B は同一モード集合（または B 側への同帯域マスク）で照合する。J0 は「A と B の数値実装一致」、J2b は「QTF 予測と合成場の物理統計の一致」と明示的に別ゲートとした。U-7 の「閉じた」宣言を取り下げ、U-1・U-2 完了後に発効する依存項目へ戻したうえで、R5 で U-1・U-2 が閉じたため発効する。8 m 診断の比較は「同一 8 m 格子・同一シードにおける 2D 厳密 B⁻ 二重和 vs 2D 分離形 S1 の決定論的比較（シード数と空間モード数 M を明記）」と明確化した。

問うこと：切替閾値の導出は、線形場の標本 SD の何倍か等の統計的根拠として成立しているか。|Δb| ≤0.008 の根拠（P5 の帰無分布 SD 0.008 の 1SD を A・B 間の一致許容幅に採用）は、別の量の流用ではないか。U-7 の依存整理は循環を解消しているか。

### K7 — 未決 U-1a・U-3・U-4 の置き方

R5 は未決を U-1a（Bredmose (59)/(62) の転記。文書化のみで試験 0 を止めない）・U-3（毛管重力 QTF。フェーズ 2 の必須経路）・U-4（高次参照。フェーズ 2 の開始前）に絞った。各未決には「決定者」「決定期限」「決定に使う根拠」「決定前に禁止する実装」を付けた。

問うこと：U-1a を「文書化のみで試験 0 を止めない」とした置き方は正しいか（Bredmose (59)/(62) は第2の独立な 2D 原典の照合に使うはずのものではないか）。U-3・U-4 をフェーズ 2 へ先送りしたまま、フェーズ 1 の採用判断にかけられるか。未決のまま実装ブリーフへ進むと実装者の暗黙の決定が起きないか。

### K8 — 2D 角度依存の支持の十分性

R5 は 2D の角度依存を、θ=0 での 2 経路（訂正 Langley 形・MF12 Lambda2）との一致＋内部整合性（対称性・滑らかな角度依存・対向波での符号反転）で支持し、第2の独立な 2D 原典との照合は未了であることを §2.1・§6・§9 に明記した。

問うこと：θ=0 での一致と内部整合性だけで、2D 一般角形の採用式を確定したと言えるか。角度依存の部分は検証されていないのではないか。未了であることを明記しただけでは、試験 0 の土台として十分か。

### K9 — 出典訂正と g² 訂正形の扱い

R5 は R4 の出典「Kaihatu & Kirby (2005)」が誤りで、正しくは Bredmose et al. (2005) であると訂正した。g² 訂正形は次元整合＋単色波アンカー（≤1.9e-15）＋MF12 との一致（≤1.5e-14）で支持されるが、それ自体は推論であり原著の確定ではないと明記した。

問うこと：出典の訂正は正しいか。g² 訂正形を採用式として使うことは、推論を確定式として使うことにならないか。WAFO の Langley 分岐が壊れている以上、訂正 Langley 形との一致は独立な検証にならないのではないか。
