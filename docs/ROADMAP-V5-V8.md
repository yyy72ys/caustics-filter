# ROADMAP V5–V8 — バージョン地図への追加（ユーザー定義 2026-11-10 18:14）

既存： v3 シリーズ完走（3.1 水と底／3.2 雨／3.3 網膜）。v4 = コースティクスそのもの＋3段階（1st 現行、2nd 立体ボトム＋物体、3rd 立体水面）、調査済み・保管中（research-v4-caustics/）。v6 = 地球の水に影響する全要素のメタ地図（ユーザー指示で保留中、変更なし）。

## v5 — 環境が水面・水中・ボトムに与える要素の研究

環境側の変数が、水面／水中／ボトムの状態と光にどう効くかを研究する。ユーザーが挙げた例：
- 水圧
- 水温
- 外気温
- 外の湿度
- 気圧
- （等、環境要素全般）

進め方はいつも通り： 研究 → 機構への接続（SYNTHESIS）→ 設計 → チャンク実装 → 数値ゲート。どの要素が独立変数で、どれが導出量で、どれが池スケールでは正直に無視できる量か（チャンク0調査で磁場がそうだった）を、式と実測で仕分ける。

## v7 — 水生生物アセットの数学的再現

水の中の生物を、数学的に再現したアセットとして作る。v4 の 2nd（ボトムに物体を置く有機的シミュレーション）の「生き物」側レイヤーに接続する想定。切り抜きや既成モデルでなく、数理で形と動きを作る（蛾の造形と同じ作法）。

## v8 — 地天・宇宙レベルの数字の取り込み

地球と太陽の影響など、宇宙レベルの数字を取り込む。例： 太陽フレア。その他、太陽活動・地天の関係から来る大きなスケールの入力を、環境変数の上流として扱う。v5 の環境変数（気圧・気温・水温…）の、さらに上流に位置する層として設計する。効き方が直接か間接か、池スケールで有意かは研究で正直に仕分ける。
