### v4-4.2 見かけの距離場（輸送→カメラ段の受け渡し）

※ラリー反映（2026-11-14）：本節は「近軸・単一像枝の**有効**距離場」へ
格下げする。スカラー距離場は定義上1つの面であり、非点収差の2枚焦点も、
波の曲率で見かけ深さが ±∞ を通って水上に実像化する現象も表せない。
有効範囲（波の主曲率・視線角・開口）を数値で宣言し、範囲外は光線束／
波面情報への拡張対象として明記する。
  ※R3 で再定義（N2、統合 §6 項目3・4）：有効範囲を次の3量で宣言する。
  (1) 視線角の上限 **θ_max = 26.75°**。非点収差の割れの母数は像側の
  見かけ深さで割った **(d_s − d_t)/d_s** と定義する（訂正再計算 §5.3 の
  推奨を採る：d_s と d_t は同じ側の量で次元が揃い、判定は厳しい側に
  出る）。割れが 10% に達する角度は 26.753°（d_w によらず同一＝スケール
  不変、Coddington 式と 3e-7 まで一致して検証済み）。R2 の母数
  (d_s − d_t)/d_w（10% 到達 31.82°、31.82° での /d_s は 14.41%）は
  撤回する。三枠の半画角（Snell 精確 f の主光線）はメイン 27.357°／
  サブ 32.514°／対比 40.785° で、θ_max をそれぞれ 0.60°／5.76°／14.03°
  超える。したがって三枠とも画面端は有効範囲の外であり、評価は
  θ ≤ 26.75° の範囲で行い、周辺部は範囲外として扱う（50 mm 版は半画角
  20.4–24.7° で全変種が範囲内）。(2) 主曲率の有効範囲は**単一像枝の
  臨界**で切る：κ_crit = n/((n−1)·d_w) = **6.67 /m（d_w = 0.6 m）／
  1.00 /m（d_w = 4.0 m）**。D_app が単一の見かけ距離として定義できるのは
  局所の主曲率が κ_crit 未満の領域に限る。メイン条件の実測
  |κ1| p99 = 53 /m は κ_crit の 7.94 倍（+46.33 /m）、|κ2| p99 =
  22.1 /m も臨界を超える。R2 の「κ_max = 53 /m を有効範囲の上限とする」
  宣言は撤回し、53 /m は観測事実（メイン条件の p99）の記録としてのみ
  残す。臨界を超えた領域では見かけ像は多像化・水上への実像化を起こし
  距離場では表せない。その領域の結像は距離場を経由せず、案1のサブレイ
  再トレース（v4-4.3）が各光線の実際の交点を取ることで直接扱う
  （範囲外＝拡張対象、という R2 の置き場は案1の本線化で解消する）。
  サブ条件の曲率統計は未測定のまま（暫定の扱いは変わらない。κ_crit は
  深さだけで決まる 1.00 /m）。(3) 開口の上限 **D_max = f/1.4**
  （体制地図の掃引 N ≥ 1.4 に対応する最大開口）：メイン 24.8 mm／
  サブ 20.2 mm／対比 14.9 mm。これを超える開口（N < 1.4）は v1 の
  有効範囲外とする。

- **目的**：焦点と被写界深度が使う「距離」を、幾何距離ではなく
  水面屈折を通した見かけの距離として画素ごとに供給する。
- **物理的根拠**：平面屈折の虚像（近軸で実深さ/n、斜めでは非平面・
  非点収差）。波面では輸送の変位場が見かけの像そのものなので、
  距離場は変位場と対で輸送側から出す。
  ※訂正（2026-11-14、ラリー Gemini 脚）：幾何距離とのずれは「係数 n」では
  ない。空気層 h_a 込みでは s_app = h_a + d_w/n 対 s_geom = h_a + d_w で、
  メイン条件（h_a=1.0 m、d_w=0.6 m）では比 1.10、h_a=3.0 m では 1.04。
  n 倍はレンズが水面に接する場合の極限。
- **入力**：床の標高場（第2段）、水深、水面の状態、v4-4.1 の視線場。
- **出力**：見かけの距離場 D_app(x, y)（画素ごと）と、平坦水面・近軸条件で
  s_app = h_a + d_w/n に一致することの較正記録。
- **検証**：平らな床＋静水面の解析解（見かけの深さ = 実深さ/n）との一致。
  ※R2（N6）：放射輝度場は2成分で受け渡す。(a) 床成分（拡散・コースティクス）は
  D_app を使う。(b) グリッター成分（太陽の鏡面反射像）は別の見かけ距離場
  D_glit を持つ：ファセットの反射面内の法曲率 κ_n に対して
  D_glit = h_a + 1/(2κ_n)（鏡像の式。κ_n → 0 で無限遠。κ_n は水面場の
  曲率から輸送側が出す）。v4-4.3 の PSF は成分ごとに掛けてから合成する。
  D_app 単一場でグリッターを扱う形は採らない（C8）。
  斜め視線で距離場が単一面からどう外れるかを測定して記録（v1 で
  扱う範囲の宣言に使う）。
  ※R3（N6・X4、統合 §6 項目9）：D_glit の適用条件を明記する（案2の分布
  積分は不採用のため、単一距離の式の適用条件として書く）。D_glit =
  h_a + 1/(2κ_n) の κ_n は、入射面内（反射光と法線を含む面内）の法曲率
  とする。適用できるのは次の条件をすべて満たす画素のグリッター成分だけ
  である。(a) κ_n > 0（入射面内で凸）。κ_n = 0 の極限は D_glit = ∞
  （無限遠の像として扱う）。数値上は D_glit > 100 m を無限遠として
  記録する。κ_n < 0（凹）では鏡像が水面上に実像化し式値は h_a 未満〜
  負値になり得るため、その画素は単一距離モデルの適用外とする。
  (b) 非点分裂：2主曲率 κ_1・κ_2 が異なると鏡像は D_1 = h_a + 1/(2κ_1)
  と D_2 = h_a + 1/(2κ_2) の2焦点に分裂する。単一の D_glit で代表できる
  のは、分裂幅 |D_1 − D_2| がその条件の被写界深度（体制地図で
  b_eff ≤ 2 px を満たす焦点距離の幅）に収まる場合だけとし、収まらない
  画素は適用外として記録する。(c) 体積散乱の置き場：体積散乱は輸送段の
  性質であり、第4段は独自の散乱項を持たない。グリッター・床の両成分
  とも、水路の散乱は輸送側が各サブレイに与える放射輝度に含まれる形で
  受ける。D_glit は幾何の像距離だけを定義し、散乱による減衰・ぼけは
  含まない（二重適用禁止リストの水中散乱ブラーと混同しない）。適用外の
  画素のグリッターは距離場では扱わず、案1のサブレイ再トレースの結果を
  そのまま結像に使う。

### v4-4.3 レンズ結像（焦点・被写界深度・ピント外し）

- **目的**：焦点合わせ、絞りによる被写界深度、ピント外しを、
  輸送後の放射輝度場に対する開口積分として実装する。
  ※ラリー反映（2026-11-14）：開口積分の**入力契約を明記すること**が確定
  条件。入力が単一視点の2D画像＋距離場のままでは真の開口積分にならない
  （瞳サブレイは水面の異なる点を通り、異なる屈折・遮蔽・体積散乱を受ける
  — 4席一致）。実装は「瞳サブレイ再トレース」か「2D近似である宣言＋
  誤差の実測」のどちらかを契約に書く。
- **物理的根拠**：薄レンズ式、ぼけ円 b = (f²/N)·|s − s_f|/(s(s_f−f))（幾何円の極限と Airy 盤の極限は分けて扱う）、
  開口積分＝開口上のピンホール像の重ね合わせ、回折 Airy 盤 2.44λN_w
  （N_w = N·s_f/(s_f−f)、有限共役の実効 F値）を PSF に合成。回折は本節の光学 PSF にのみ含め、v4-4.5 の記録 MTF には含めない。PSF は
  D_app から画素ごとに決まる。
  ※式の訂正（2026-11-14、ラリー Gemini 脚）：初版の分母 (s_f(s−f)) は
  s と s_f の取り違え。正しくは (s(s_f−f))。数値影響は小さい
  （C7 の例で 0.139→0.141 mm）が極限が誤っていた。あわせて、幾何円と
  Airy の単純畳み込みはデフォーカス 1–5 波長の遷移域で波動光学 PSF と
  ずれることを近似として明記する。cos⁴ 周辺減光と瞳の短縮（楕円ボケ）は
  レンズ固有収差でなく幾何として本節に含む。
- **入力**：放射輝度場（合成前の場、線形 HDR、クリップ前）、D_app、焦点距離 s_f（対象は
  水面／中間／床から選ぶ物理距離指定）、絞り N、焦点距離 f。
- **出力**：結像後の場。幾何光学 PSF はピンホール極限（N → 大、開口 → 0）で入力に
  帰着すること。波動光学 PSF（回折込み）はこの極限では入力に帰着しない（Airy 盤は N_w とともに
  広がる）。実カメラのピンホール極限では回折が支配的になる。
- **検証**：点光源チャートでぼけ円直径を実測し式と照合（許容差は
  設計時に固定）。2面チャート（水面相当面／床相当面）で合焦範囲が
  近点・遠点の式どおりか。平坦部での総光量保存（開口積分は平均を
  変えない）。回折側は点像の Airy 径を 2.44λN_w と照合（N_w = N·s_f/(s_f−f)。無限共役の条件で検証する場合は 2.44λN であることを明記する）。
  ※ラリー反映（2026-11-14）：「許容差は設計時に固定」を具体化すること
  ——PSF 検証の**許容差の数値と参照レンズ級を固定**しない限り C4 は

  書き換えることで解消する。D_app／D_glit は焦点設定・体制地図・
  受入テストの参照量として残るが、結像の入力ではなくなる）。計算量は
  サンプル数 S に比例する（旧 K×K 格子の K² 倍という形は案3で置換済み）。
  **許容差の明文化（項目8）**：「max(0.5 px, 5%) 以内」とは、差の絶対値が
  0.5 px と参照値の 5% のうち**大きい方**以下であること（小さいぼけでは
  0.5 px の絶対床が効き、交点は 10 px）。ぼけ円直径の式照合と Airy 径の
  照合の両方にこの規則を適用する。平坦部での総光量保存は相対誤差
  1e-3 以内。参照レンズ級は理想薄レンズ（収差なし）とし、実レンズの
  収差は v4-4.6 の範囲外に置く（R2 から不変）。
  **倍増収束規則（項目8）**：サンプル数（瞳の S、時間の M に共通）の
  収束は倍増で判定する。n と 2n の結果について、(i) 結像の線形 HDR 像の
  RMS 相対差が 1e-3 以内、(ii) ぼけ径など代表スカラー量の変化が
  max(0.5 px, 5%) 以内、の両方を満たした時点で収束とし、その n を記録
  する。上限（S ≤ 4096、M ≤ 256）に達しても満たさない条件は、契約の
  適用外として記録する。
  **受入テスト群（6件必須。各件の合否は上の数値で判定する）**：
  (1) 波面ケース——波面のある場面で、サンプル数を4倍にした参照計算と
  ぼけ径 max(0.5 px, 5%) 以内・像 RMS 相対差 1e-3 以内で一致すること。
  (2) 遮蔽境界——遮蔽の境界の像位置の差が 0.5 px 以内、境界を跨ぐ画素の
  輝度差が参照の 5% 以内であること。(3) グリッター対床——D_glit の
  適用条件（v4-4.2 の ※R3（N6・X4））を満たす条件で、グリッター成分と
  床成分の合焦が別々に式の予測どおりであること（ぼけ径で判定）。
  (4) 空間変動 PSF——画面内の複数点で、局所の D_app から予測したぼけ径と
  max(0.5 px, 5%) 以内で一致すること。(5) 参照照合——平坦水面の解析解
  および独立な参照計算（S を4倍にした同一トレーサ）と照合し、ぼけ径
  max(0.5 px, 5%) 以内・像 RMS 相対差 1e-3 以内であること。
  (6) エネルギー保存——平坦部では総光量の相対誤差 1e-3 以内、非平坦部でも
  5% 以内であること。5% を超える条件は gather 側の非保存として記録し、
  契約の適用外とする。

### v4-4.4 焦点の時間制御（フォーカス移動）

- **目的**：動画で焦点を水面→中間→床へ移す操作を、s_f(t) の
  指定として実装する（2026-11-13 ユーザー着想 2-3 の正規スコープ）。
- **物理的根拠**：各瞬間の結像は v4-4.3 の静止形そのもの。時間方向の物理は二つある：(a) 焦点距離の軌跡 s_f(t)、(b) シャッター時間積分（露光中の水面・網目・グリッター・焦点の動きの積分＝モーションブラー）。(b) の入力はシャッター時間 t_shutter と露光区間、出力は時間積分後の記録像、検証はモーションブラーの実測照合とループ継ぎ目での時間積分連続性の検査とする。被写界深度の効く条件は体制地図（再計算後のもの）に限る。
- **入力**：s_f(t) のキー指定（時刻と対象面）、シャッター時間 t_shutter、露光区間、ループ長 T。
- **出力**：フレームごとの s_f と結像。境界条件 s_f(0) = s_f(T)
  （継ぎ目なしループ、SPEC の前提）。実効焦点距離の変化のうち
  レンズ固有分（ブリージング）は v1 では含めない（主張 C6）。
  ※ラリー反映（2026-11-14）：薄レンズでも導ける像面移動に伴う倍率・
  画角変化（面→床で 50 mm 級 5.6%、85 mm 級 10.2%）は「導けない」に
  含めない。v1 で両方とも固定するなら「定画角ピンホール＋薄レンズ DoF
  のハイブリッドである」と宣言すること。あわせて**シャッター時間積分**
  （露光中の水面・網目・グリッター・焦点の動きの積分＝モーションブラー、
  ループ継ぎ目の周期条件込み）は本節と v4-4.5 にまたがる必須項目として
  追加する（4席一致の見落とし）。
  ※R2 で固定（N4）：シャッター時間 t_shutter は場面パラメータとし、既定は
  フレーム間隔（24 fps）の 180° 相当＝1/48 s とする。時間積分は M 個の
  サブサンプルで近似し、M は v4-4.3 の倍増収束規則（像 RMS 相対差 1e-3 以内かつ代表量の変化が max(0.5 px, 5%) 以内）を通るまで倍増させる（初期 M = 4、上限 M = 256、使用した M は記録する）。各時刻の評価順序は
  （水面状態→光輸送→焦点位置 s_f→PSF→センサー光量の蓄積）で固定する。
  周期境界条件は位置と速度の両方の連続性とする：s_f(0) = s_f(T) かつ
  s_f'(0) = s_f'(T)。水面状態も同じ周期で連続であることが前提
  （ループ作品の仕様）。瞳サンプルと時間サブサンプルは独立に採らず、(u_pupil, v_pupil, t) の3次元低差異列（PMJ02 級）として結合して採る（案3、統合 §5）。
  ※R3 で差し替え（N5、統合 §6 項目1）：体制地図は Snell 精確 f と
  √(2CD) の最小値式で再計算済み（caustics-v4-4-recalc、2026-11-16。
  全表は delivery/v4-4-recalc/tables-v4-4-recalc.md）。参照閾値 2 px
  （もう一方の面の実効ぼけ b_eff = sqrt(b² + d_A²) が 2 px 以下なら
  体制 A＝フォーカス移動が見えない、超えれば B＝移動が実在）：
  **メインは A 区間を持つ**（最小 1.872 px、水面合焦で N ∈ [12.86, 21.77]、
  床合焦で [12.57, 22.26]。R2 の「全 N で B」は旧 f と √2 倍の過大評価の
  両方に由来する誤りで、撤回する）、**サブは全 N で B**（最小
  2.346 px）、**対比は A**（最小 1.106 px、N ∈ [3.97, 25.34]、N = 11・16
  では回折支配 D）。つまり作品の主条件でも、メイン・対比では深く絞った
  側にフォーカス移動が見えなくなる帯があり、「効かない条件」はその帯に
  限られる。50 mm 版は同窓3種が A（最小 1.784／1.749／1.025 px）、
  同高3種が B（最小 2.522／2.522／3.284 px）。検証アンカー
  （f = 35 mm、N = 2.8、水面合焦→床ぼけ 0.1407 mm = 8.01 px）は不変で
  再現済み。
- **検証**：2面チャートの動画で、合焦面の移動が指定軌跡どおりか
  フレームごとに測る。シーム（t=0 と t=T の C 差分 max）を従来作と
  同じ物差しで記録。体制地図の外（両面とも合焦範囲内）では
  「変化なし」が正しい出力であることを確認する。

## 7. 両席の食い違いの扱い（統合の裁定・記録）

下準備 cf-0045 の §6 の裁定を、R2 への適用結果とともに記録する。

- **0.139 mm の扱い**：GPT は §4 の 0.139 mm = 7.9 px を「計算としては整合している」と読んだ。Gemini は「訂正前の古い値が残っている」と読んだ。食い違いではない。§1 の訂正値 0.141 mm が正しい値であり、R2 では §4 をそれに合わせた（0.141 mm = 8.0 px）。GPT の読みは §4 単独の計算が合っているという指摘であって、0.139 mm を正しい値とする主張ではない。Grok が修正優先順位で書いた「ぼけ 7.9 px を浸透させる」は旧値の伝播であり、R2 では採用しない（正は 0.141 mm／8.0 px）。
- **Q1 の「E/A が計算に入り込んでいないか」**：GPT は「§1 の入力・計算式を確認した限り、E/A を第4段の計算式に直接投入する記述は見当たらない」とした。Gemini は「後段配置を選べば E/A が第4段の計算に入り込む」とした。食い違いではない。現行の計算式に混入は無いが、§0 の後段配置が残っている限り将来の混入の余地がある。R2 の §3（3a・3b・3c）はその余地を塞ぐものである。
