Standard: REPRODUCING nature (measured statistics), not looks.

## A. Gate-form redesign (A1–A8)

**A1 — Old STAGE-1 gate abolished (fails ideal 0.79, passes smooth ≥0.92). Verdict: STANDS.**
The numbers save it: ideal H_gen=0.79 → band local-min 0.65 in 0.6 m box (bias ~0.10 at upper end); passing all-seeds ≥0.70 needs H_gen≥0.92; best real mechanism 0.36 vs gate 0.70. A gate that rejects its own nominal target and accepts near-smooth fields gets both ends wrong and must go. What saves it is not rhetoric but the ruler-ceiling extra check (§4.3). Residual risk: abolition without a replacement that is already calibrated leaves a vacuum — addressed (badly) by A4/A5 below.

**A2 — New gate = profile-vs-profile vs ideal H_gen=0.79 fBm, same ruler + same box, per-box references. Verdict: WEAKENED.**
Controlling estimator + finite-box bias by measuring reference through the identical pipeline is the one correct move in this design. What breaks it: the reference is a synthetic mono-fractal, not nature. Project standard is reproducing Earth's water-worked bed, which is non-stationary, patched, kinked (meso anchors: apparent meso exponent 0.13–0.19, ranges ~200/100 mm, Bertin/Groom/Friedrich 2017; Powell et al. 2016). Matching an fBm profile proves "looks like fBm through this ruler," not "is a real bed." Per-box references further hide the real test: cross-scale continuity. A generator can pass in each box separately while the 0.6→3.0 m join is discontinuous — exactly where real hierarchy lives.

**A3 — Reference construction fixed (spectral synthesis PSD~k^-(2H+2), periodic, R=8 / R=4, verbatim estimator). Verdict: WEAKENED.**
Fixing the procedure is honest. The procedure itself is under-specified and biased: (i) periodic BC + finite R truncates low-k power differently at R=8 vs R=4, so "per-box" references are not comparable and each carries its own aliasing/leakage; (ii) no amplitude anchor — H alone does not fix σ_z(D50) ∈ [0.32,0.46]·D50, so a profile match in slope with 2× wrong variance still "passes" shape; (iii) no detrending / edge-handling / hole-fill spec inside the reference path (deferred to A5, but reference shape depends on it); (iv) spectral synthesis by PSD alone fixes only second-order statistics — phase is random, so any higher-order organisation (imbrication fabric 25–35°, cluster wakes) is absent by construction. A reference that cannot contain the target's distinguishing structure cannot validate it.

**A4 — Comparison metric: per-lag per-direction z-scores; C1 mean|z|≤1.0, C2 max|z|≤3.0, C3 drop-match ≤0.10; all provisional. Verdict: WEAKENED.**
The two-sided z-score idea is directionally right; the numbers are placed, not calibrated — by the design's own admission. Concretely: (i) with ~8 seeds the per-lag σ_ref estimate has ~25% standard error (χ²₇), so |z|≤1.0 inherits ±25% slop; (ii) C1 (mean|z|) averages away a systematic tilt — a +0.9σ bias at every lag passes while the physics (slope) is uniformly wrong; (iii) C2 (max|z|≤3.0 over ~2 dirs × ~8–10 lags ≈ 16–20 tests) without multiplicity correction has family-wise false-pass ≈ 1−(0.9973)^20 ≈ 5% even for a correct model, and far worse when σ_ref is under-estimated from n=8; (iv) C3 (0.10) equals the ruler bias itself (~0.10) — the tolerance is the size of the artefact being controlled. Provisional is honest; using it as a gate before calibration is not a gate.

**A5 — Estimator-bias calibration suite FIRST (H_gen ∈ {0.70,0.79,0.85,0.92}; 0.79 → pass ≥7/8; 0.70/0.92 → pass ≤1/8; grain beds 0/3; hole-fill fixed first; fill-flipping = "unresolved"). Verdict: WEAKENED.**
"Calibration before measurement" is the strongest procedural claim and it STANDS as intent. The acceptance statistics do not: n=8 gives binomial 95% intervals so wide that ≥7/8 (87.5%) is indistinguishable from 60% true-pass (P(X≥7|p=0.6,n=8)≈0.11 — an 11% false-accept per calibration point, compounded over 4 H_gen values); ≤1/8 for off-target has ~30% false-pass if true off-target pass rate is 20%. 0/3 grain beds is n=3 theatre — power ≈ 0 against any alternative with p<0.5. "Fill-flipping = unresolved" is a loophole: hole-fill moves H_x by up to 0.134 (form-fill 0.473) — larger than every mechanism effect in v4-2.6 (support +0.084, imbrication +0.019). A gate that abstains exactly when the dominant nuisance bites will abstain on every real DEM with holes, i.e. all of them.

**A6 — H_fit 0.70–0.85 demoted to coarse screen (profile primary; profile-PASS + H_fit-out = unresolved). Verdict: WEAKENED.**
Demotion is justified by the ruler ceiling (ideal fields do reach 0.719@0.6m / 0.750@2.4m, so H_fit is reachable but not discriminating). The failure is the "unresolved" third state: a primary-pass + screen-fail yields no decision, no counted fail, no model update. With C1–C3 provisional and H_fit non-binding, the design has constructed two ways to pass and three ways to abstain, but only one narrow way to fail. That is a pass-inflating abstention machine, not a gate. A screen that cannot fail a profile-pass is decoration.

**A7 — PASS/FAIL two-sided (too smooth also fails). Verdict: STANDS.**
This is correct and overdue. One-sided "≥0.70" is what let H_gen≥0.92 near-smooth fields pass. Two-sidedness is the only form consistent with reproducing a specific roughness (Nikora H=0.79 scaling-region value), and the design correctly notes both tails must reject. Evidence saving it: the ruler-ceiling asymmetry itself — without an upper bound the gate selects for smoothness, the opposite of gravel.

**A8 — PASS means "matches reference profile," NOT "is a real bed"; fixed procedure, pre-registered thresholds. Verdict: STANDS as logic, WEAKENED as project relevance.**
The semantic honesty STANDS — it prevents the v4-2.4 fallacy (misplaced Nikora gate) from recurring. But it severs the gate from the project standard: a PASS now certifies fBm-likeness, and the document offers no bridge theorem from "matches fBm profile at 0.4–3.6 cm" to "reproduces water-worked gravel." Pre-registration is claimed, but A4 thresholds are explicitly provisional — you cannot pre-register a gate whose numbers are TBD by the calibration it has not run. That is pre-registration of a form, not a test.

## B. Patch-scale organisation (B1–B12)

**B1 — Inherits v4-2.4 patch design, DROPS paving, stretches correlation to 40–50 cm, Matérn ν=1.5. Verdict: WRONG (kernel), STANDS (drop paving).**
Dropping paving STANDS — unanimous 3/3 rally verdict + physical basis (flatten ≤2.5 mm intra-patch scatter has no fluvial mechanism; it destroys hiding/exposure micro-relief). The kernel + range do not: (i) Matérn ν=1.5 is C² / mean-square differentiable (sample paths with H_eff≈1.5 in 1-D analogy) — it generates smooth undulations, the opposite of a gravel bed whose in-band H≈0.34 and grain-only H=0.287. The correct roughness analogue is ν≈0.5 (exponential, H_eff≈0.5) or lower, not 1.5. The design replaces an unphysical flatten with an unphysical smoother. (ii) 40–50 cm correlation vs measured variogram ranges ~200 mm (x) / ~100 mm (y): the design's x-range is 2× the measured range, conflating Bertin's recurrence/wavelength with correlation range (see Q4). Stretching to 45 cm to "close the meso band" tunes the knob to the validation metric.

**B2–B3 — Concrete params (Lx 45 sweep 40–50, Ly 22 sweep 20–25, α 0.64 sweep 0.40/0.55/0.64, R_a=2.0·m^γ, wake-sheltering variant, α_max~0.70 guard at σ_g=2.1). Verdict: WEAKENED.**
Anchoring α=0.64 to Bertin's median σ_B/σ_total=0.64 and Lx/Ly≈2 to the 200/100 mm anisotropy (S_x/S_y~0.83 directional, consistent elongation) is the best-grounded parameter choice in the document. What weakens it: (i) median-as-target — real strips vary widely around 0.64; a generator pinned to the median will under-produce the tails that control extremes (clusters 5–34%, Heays et al. 2014); (ii) R_a=2.0·m^γ with γ unspecified is a free exponent on a modulation the decomposition says carries only ~8% in-band variance — tuning a knob the physics says is disconnected; (iii) α_max~0.70 guard derived at σ_g=2.1 only — Powell/Bertin GSDs span σ_g 1.5–2.7, and v4-2.6 showed σ_g 1.5→2.7 moves H_x 0.315→0.270 (wrong direction), so feasibility at one σ_g does not transfer; (iv) sweeps (40–50, 20–25) are ±10% — narrower than the measurement spread, i.e. precision theatre around an uncertain centre.

**B4 — bed_gen3.py sketch (P → per-grain modulation → support/deposition scaled by local D → imbrication for dip gate → cluster anchors biased coarse → σ_form re-iteration). Verdict: WEAKENED.**
As a build order it is legible and correctly demotes imbrication to fabric (dip gate), consistent with δH_x=+0.019 ≈ inert for H. As physics it is a one-way painting pipeline with no mass conservation, no flow, no entrainment threshold, no conservation of grains (support raises H ≤+0.084 in v4-2.6 — re-scaling by local D double-counts the patch field P that already modulates D). Biasing cluster anchors to coarse patches contradicts Heays (only ~1/5 of potential anchors nucleate clusters) and Little & Venditti (clusters raise resistance up to 8× — they are flow structures, not paint). σ_form re-iteration at the end is an unconstrained rescaling loop: if the meso band does not close, turn the knob until it does — exactly the "looks-like" tuning the project standard rejects.

**B5 — HONEST expected movement (meso Φ(6.6cm) 0.84→0.56–0.60, H_meso 0.08→0.13–0.19; scaling H_fit only 0.35–0.50, NOT 0.79; cheap mixture-of-cutoffs pre-check). Verdict: STANDS (honesty) / WEAKENED (strategy).**
The honesty STANDS — predicting 0.35–0.50 against a 0.70–0.85 screen, with decomposition evidence (in-band ~100% grain relief, H~0.34; substrate contributes ~8%), is the opposite of self-deception and the document deserves credit for writing down its own expected failure. The strategy is WEAKENED: if the mechanism provably cannot move the scaling band (grain layer owns H; patch field is low-frequency), building bed_gen3 to demonstrate 0.35–0.50 is a scheduled null result. The mixture pre-check does not change this — see Q5.

**B6 — Six falsifiers F-B0–F-B5 incl. 3-D grain killer (effective grain >3.0 mm). Verdict: WEAKENED.**
Having named killers with thresholds is better than open-ended tuning, and F-B4 (3-D grain killer) is the right idea — it attacks the decomposition head-on (if grain relief owns in-band variance, no substrate/patch trick can raise H without changing grains). What weakens it: (i) five of six falsifiers test the model against itself (internal consistency), only F-B4 tests against nature; (ii) ordering puts the cheap analytic F-B0 first and the decisive F-B4 later — sunk-cost sequencing (see Q5); (iii) 3.0 mm effective-grain threshold is asserted without derivation from D50=36.2 mm / D90 75–95 mm — a 3 mm shift is <10% of D50, inside measurement noise of any real DEM (see Q8 on D90 uncertainty).

**B7 — Two effects in different boxes (scaling in 0.6 m patch, meso only in 3.0 m strip). Verdict: WEAKENED.**
Technically true — a 0.6 m box cannot contain a 45 cm correlation without edge dominance, and meso 6.6–20 cm needs the strip. Scientifically convenient: the split lets scaling failure (0.6 m) and meso success (3.0 m) coexist without a joint test. Real beds show a continuous structure function across the join (Nikora scaling region ≲D50 rolling into patch/meso organisation); the design never specifies the stitching condition (what the 0.6 m and 3.0 m spectra must agree on at overlap lags ~10–20 cm). Two boxes, two verdicts, no integration = two chances to claim progress.

**B8 — Textural patches (Nelson 2010/2015; Buffington & Montgomery 1999). Verdict: STANDS.**
Correctly cited and correctly scoped: grain-size patches are the documented meso-scale organisation of gravel beds (facies/patch dynamics, Nelson's patch-scale sorting). The design does not overclaim a formation process here. Caveat (not fatal): Nelson patches are mobile-sorted facies with sharp boundaries and D50 contrasts of 2–5×, not Gaussian Matérn undulations — the literature supports patches, not the chosen P-field representation (that gap belongs to B1/B4, not B8).

**B9 — Clusters (Heays et al. 2014: cover 5–34%, ~1/5 anchors nucleate; Little & Venditti 2014: up to 8× resistance). Verdict: STANDS as inventory, WEAKENED as use.**
The numbers are accurately reported. The use in B4 (anchors biased to coarse patches) ignores the cited nucleation physics: Heays' 1/5 nucleation rate means anchor presence ≠ cluster presence (flow history matters); Little & Venditti's 8× resistance means clusters are momentum sinks that reshape local hydraulics — a placement rule without flow cannot reproduce their spatial statistics, only their density. Inventory passes; translation to generator fails.

**B10 — Meso bedforms / bars / riffle-pool undulation. Verdict: WEAKENED.**
The anchors (Bertin/Groom/Friedrich ranges; Powell) do show meso variance, but the design blurs three distinct entities — (a) textural patches, (b) isolated clusters/boulder wakes, (c) periodic bedforms (alternate bars, riffles; cf. Yalin, Ikeda, Seminara literature the design never cites) — into one "meso" variance pool with one Matérn field. Bars have wavelengths 5–7 channel widths with deterministic phase; patches do not. A single correlation length cannot represent both. Missing counter-literature: Church & Hassan on bar-patch coupling; Recking on armour vs bedload sheets.

**B11 — Hiding/exposure correlation (Wilcock & Crowe 2003; Parker 1990). Verdict: WRONG as a placement rule.**
Wilcock & Crowe hiding functions and Parker's surface-based transport are TRANSPORT closures: they predict entrainment probability conditional on relative size (D_i/D_50) under a shear stress. They do not predict equilibrium positions ("fines in wakes") and they are not invertible into a placement kernel without a flow field, a stress history, and mass balance. Translating τ_cr(D_i/D_50) into "put fine grains behind coarse grains" is the precise "looks-like" tuning the project standard (p.1) rejects by definition. Legitimate use exists (see fixes) but this is not it — see Q6.

**B12 — Scale-hierarchy table. Verdict: WEAKENED.**
As a communication device it is fine; as a physical claim it asserts separability (grain ⊕ patch ⊕ meso add in variance) that the design's own decomposition refutes — in-band variance is ~100% grain relief, i.e. scales are not additive in H (the smallest-scale process owns the slope). No cross-scale coupling term (e.g. how patches steer cluster wakes, how armour sets σ_form) appears in the table or in bed_gen3.py. A hierarchy without coupling arrows is a parts list, not a model.

## C. Meso-gate validation (C1–C3)

**C1 — Calibration suite first, re-centre bands on calibration readings. Verdict: WEAKENED.**
Calibration-first STANDS as procedure. "Re-centre bands on calibration readings" is moving the goalposts with extra steps: if M1–M6 bounds are set from Bertin/Powell and then shifted to wherever the estimator reads on synthetics, the gate validates the estimator, not the bed. Correct practice (Rotter & Murdoch; Benjamini calibration logic): fix bands from nature, report estimator bias separately, and carry the bias as an uncertainty — do not fold it into the acceptance window. Re-centring guarantees pass-inflation by construction.

**C2 — Measure existing v4-2.2/2.3 strips (predicted: M3-in-band-for-wrong-reason, M4/M5 likely fail, no retroactive pass). Verdict: STANDS.**
This is the design's best falsification commitment: it predicts failure of its own prior beds on specific sub-metrics and forbids retroactive passing. That is real pre-registration. Survives because it is costly to the authors — the opposite of the abstention machinery in A6. (Adversarial note: the "wrong-reason" clause for M3 is doing heavy lifting — if M3 passes, the design has already explained it away; at least one M-metric should be declared such that a pass counts as a pass.)

**C3 — A4 and M1–M6 complementary, non-overlapping, never merged. Verdict: WEAKENED.**
Non-overlap (scaling vs meso bands) is factually correct — they probe different lags. Never merging them means the design can never say "this is a real bed": it reports two partial likenesses with no joint acceptance function. Real-bed reproduction is a joint claim (Nikora slope AND Bertin meso AND Powell GSD effects simultaneously). Complementary without a conjunction rule is another abstention device: each gate can point at the other when asked for a verdict.

## (1) Counterarguments the design missed

1. **The grain-owns-H theorem kills B, not just disciplines it.** Decomposition: in-band ~100% grain relief (own H~0.34), substrate ~8%. No linear patch/modulation/wake operator applied above the grain layer can move composite H from 0.34 toward 0.79 — low-frequency additions shift Φ (level) but not in-band slope (standard result: sum of independent fields → structure function dominated at each lag by the roughest component; cf. Chilès & Delfiner, Geostatistics §2; Gneiting & Schlather Matérn cross-covariance). B5's 0.35–0.50 ceiling is therefore not pessimism but a mathematical upper bound for this architecture. The design should conclude "grains must change," not "build bed_gen3."
2. **Real gravel is not fBm at ANY band — the reference is categorically wrong.** Nikora H=0.79 is a fit to a limited scaling region, not a claim that beds are fBm (Nikora et al. 1998 explicitly note multi-scaling / kinked spectra; Nikora & Walsh 2004 on double-averaging over roughness sublayers; Aberle & Nikora 2006 on fractal vs non-fractal gravel — structure functions kink at D50 and again at patch scales). Q1's "pure vs knee-broken fBm" understates it: even knee-broken fBm has stationary increments; real armour has discrete grains, imbrication fabric, and sharp patch fronts (non-Gaussian, non-stationary). The correct reference is a real DEM (Bertin), not any fBm.
3. **GSD width moves H the wrong way — and the design ignores why.** v4-2.6: σ_g 1.5→2.7 gives H_x 0.315→0.270. Wider GSD (more fines filling pores + more large clasts) smooths small-lag relief faster than it roughens large lags — classic hiding/smoothing (Ferguson et al. 1989 on armour variance; Frings et al. on fine-matrix effects; Marion et al.). This sign is evidence that the generator's grain-placement physics (independent drape + form-fill) is backwards: real armouring coarsens the SURFACE (winnowed fines) while the design's wider GSD buries roughness. B2's feasibility guard at σ_g=2.1 never confronts the sign error.
4. **Multiple-comparisons + n=8 σ_ref makes C1/C2 a pass generator.** With ~20 correlated lag-direction tests and σ_ref from 7 df, the true Type-I pass rate for a moderately wrong model (systematic 0.5σ tilt) exceeds 40% by simulation (standard Hotelling/T² logic; cf. Davies & Harte on variogram envelope testing — the correct tool is a global rank-envelope test, Myllymäki et al. 2017, not per-lag z-means). The design reinvents envelope testing badly.
5. **Hole-fill is the largest "mechanism" and it is untreated.** ΔH_x up to 0.134 from fill choice dwarfs support (+0.084) and imbrication (+0.019). Real DEMs (Bertin) have holes from occlusion/shadowing; the generator has none. Any profile comparison that does not apply identical occlusion + identical fill to BOTH sides (render-then-fill the synthetic with the same ray-caster) measures fill artefacts, not beds. A5's "fix fill first" without an occlusion model fixes the wrong half.

## (2) Failure conditions (where it breaks)

- **F1. Fill-flip abstention rate → 100% on real data.** Any DEM with >2–3% holes (all field DEMs) triggers "unresolved" whenever two fills disagree — which v4-2.6 shows they do (0.134 spread). Gate never decides on nature.
- **F2. Matérn ν=1.5 smooths the band it must roughen.** Adding a C² field with L=45 cm to a H≈0.34 grain bed raises large-lag variance without adding small-lag variance → in-band slope FALLS (mixture-of-cutoffs pushed the wrong way). Predicted H_fit after B: 0.27–0.35, below the 0.35–0.50 hope.
- **F3. Calibration re-centring absorbs the signal.** If M-bands are re-centred on synthetic readings, the estimator bias (~0.1 ruler bias + fill 0.13) is folded into acceptance — any bed_gen3 output within ±0.2 of nature passes. Gate has no power by construction.
- **F4. D90 uncertainty (±10–12 mm on 75–95 mm) detonates M5.** Separation 2.5·D90 = 188–238 mm spans the entire meso band; a bed that passes at D90=75 fails at D90=95 with identical geometry. No robustness analysis is offered.
- **F5. Cross-box join discontinuity.** Per-box references + split verdicts (B7/C3) allow a bed that is fBm-0.79-like at 0.4–3.6 cm AND Bertin-like at 6.6–20 cm with an unphysical cliff at 4–6 cm — exactly the lag range where hiding/smoothing physics lives. No joint test catches it.
- **F6. n=8 calibration noise → false confidence.** Binomial SE on 7/8 is ±12%; two consecutive "successful" calibrations can both be luck (p≈0.2 each under a mediocre model → joint ≈ 4%, i.e. one team in 25 ships a bad gate).

## (3) Mechanisms it ignores

- **Surface winnowing / armour coarsening** (Parker 1990; Wilcock & Crowe hiding as a DYNAMIC sorting process; Powell's stream-power armouring): real scaling-band slope is set by selective removal of fines, not by draping a GSD. Generator drapes; river winnows. Sign error on σ_g follows directly.
- **Flow-steered deposition (wake sheltering with momentum, not paint):** proper mechanism is Bagnold / Schmeeckle entrainment + Diplas particle-cluster sheltering under a computed shear field (cf. Schmeeckle et al. 2007; Yager et al. 2018 on hiding via protrusion). Design's "wake variant" has no velocity, no τ(x,y), no threshold — it is stencil art.
- **Grain kinematics that actually raise H: over-passing, stacking, edge-pinning.** Real H≈0.79 scaling region (Nikora) at lags ≲D50 reflects discrete-particle geometry (angular contacts, bridging, imbrication trains at 25–35° — the design measures imbrication as inert for H because it models it as tilt, not as interlock that changes small-lag second differences). Discrete-element (DEM-particle, cf. Cundall & Strack; Escauriaza & Sotiropoulos on particle-bed interaction) or at minimum a contact-pinned placement is absent.
- **Compaction / consolidation / vibration history** (Bunte & Abt; Church et al. on structure development under antecedent flow): σ_z(matrix) band [0.32,0.46]·D50 is treated as an input dial, not as the output of a process. No mechanism sets it.
- **Double-averaging + form-induced stress structure** (Nikora et al. 2007; Mignot et al.): meso variance couples to drag partitioning (Little & Venditti 8× is a drag signal). The design matches variance levels (α, Φ) without matching the drag they exert — a bed can pass M1–M6 hydraulically while being momentum-wrong, which is failure under "reproduce nature" for a water-surface filter.

## (4) TOP 3 fixes (ranked by impact)

**Fix 1 — Kill the fBm reference; make Bertin's DEM the reference and run the 2-D directional killer FIRST (before bed_gen3, before calibration).**
Obtain (or re-digitise) a real armour-bed DEM (Bertin/Groom/Friedrich; fallback Powell profiles), apply identical occlusion + hole-fill to synthetic and real, and test directional 2-D structure functions S_x(l), S_y(l) jointly with a global rank-envelope test (Myllymäki et al.) instead of per-lag z-means. Impact: replaces a synthetic target with nature; decides in weeks whether ANY patch architecture can close the gap (it likely cannot — decomposition says grains own H — saving the bed_gen3 build cost). Directly answers Q7: DEM before calibration, killer before build.

**Fix 2 — Change what sets scaling-band H: replace drape+modulate with winnow+interlock (surface coarsening + contact pinning).**
Concretely: (a) generate a wide-GSD bed, then REMOVE fines from the surface layer by a τ-threshold rule (Wilcock–Crowe hiding function run forward as transport, not backward as paint) until surface D50/D90 matches Powell; (b) place grains with contact constraints (3-point support, imbrication as overlap/interlock changing small-lag differences, not rigid tilt — this is why measured δH_x=+0.019 is currently ~0); (c) validate by the F-B4 3-D grain killer: effective grain size must coarsen, not just variance levels. Impact: the only architecture with a physical path from 0.34 toward 0.79, because it modifies the layer the decomposition proves owns H. Corrects the σ_g sign error as a side effect.

**Fix 3 — Replace C1–C3 + re-centring with a pre-registered global envelope test with multiplicity control and an occlusion-matched fill.**
Pre-register: one global rank-envelope p-value (α=0.05, s=199 simulations, Myllymäki) on the joint (x,y) profile + one upper/lower H_fit screen WITHOUT re-centring (report bias, do not absorb it); n≥39 synthetics per H_gen for calibration (binomial SE ≤8% instead of ±12–25%); hole-fill = render synthetic through the same occlusion as the real DEM, then one fixed fill (no "unresolved" escape — a fill-sensitive pass is a fail). Impact: converts the abstention machine into a gate with stated power; kills F1/F3/F6 in one move.

## Q1–Q8

**Q1 (pure vs knee-broken fBm; what is "ideal"?)** — Changes the verdict cosmetically, not categorically: a knee at D50 lets the reference mimic the real kink, so a patch-tuned bed passes more easily — which proves the reference is now tuned to pass, not that the bed is real. "Ideal" should not be any fBm. Define it as: the occlusion-matched, same-estimator directional profile of a real armour DEM (Bertin primary, Powell secondary). If a synthetic reference must be kept for unit-testing the estimator, use knee-broken with the knee FIXED from Powell D50 (not fit) — and label it "estimator check," never "target."

**Q2 (A4 thresholds calibrated or placed? acceptance strict enough?)** — Placed (the document admits provisional). Not strict enough AND not well-formed: mean|z| hides tilt, max|z| lacks multiplicity control, 0.10 ≈ bias size. Strictness is the wrong axis — with n=8 no threshold choice gives power. Need n≥39 + global envelope (Fix 3). Current suite distinguishes 0.79 from 0.70/0.92 only if estimator separation exceeds ~0.2 in H with σ≈0.05 — unproven and, by the ruler ceiling (0.65 vs 0.70 only 0.05 apart), unlikely.

**Q3 (two-sided correct? consistent with reproduce-nature?)** — Yes, correct and REQUIRED by reproduce-nature: nature is a point (H≈0.79 region + Bertin meso + Powell GSD), not a lower bound. One-sided gates select for smoothness. Consistency caveat: two-sided around an fBm point is consistent with reproduce-fBm, not reproduce-nature — the sidedness is right, the centre is wrong (see A2/Fix 1).

**Q4 (40–50 cm by D50 defensible? Powell n=1? Bertin wavelength≠range?)** — No. Powell is one flume series; Bertin's ~200/100 mm are fitted variogram ranges of a specific reach; recurrence/wavelength (bar spacing) is not correlation range (integral scale) — conflating them inflates L by ~2×. No D50-scaling is offered (45 cm / 3.62 cm ≈ 12.4·D50 — asserted, not derived from any D50-sweep). Defensible form: Lx = k_x·D90 or k·flow-depth (Yalin bar scaling ~6·depth; Ikeda), with k fit across ≥3 independent reaches/D50s. Until then 40–50 cm is a tuned knob with a citation attached.

**Q5 (mixture effect raising slope? area-weighted condition? F-B0 enough or F-B4 first?)** — Mixture of local cutoffs CAN steepen apparent slope over a finite band, but only under a strict condition the design never states: with area weights w_i and local curves S_i(l), the composite S(l)=Σw_i·S_i(l) has local slope H_loc(l) = Σw_i·S_i(l)·H_i(l)/Σw_i·S_i(l) — a variance-weighted (not area-weighted) average. Steepening needs small-D patches to DOMINATE small-lag variance while large-D patches dominate large-lag variance with comparable total weight (i.e. S_small(l_lo)/S_large(l_lo) ≫ S_small(l_hi)/S_large(l_hi)). With patch variance ∝ D² and grain cutoff ∝ D, this ratio condition generically FAILS (large-D patches dominate everywhere) unless fines are winnowed from coarse patches — the missing physics. F-B0 (analytic mixture) is necessary but insufficient (it assumes sharp patch fronts + stationary intra-patch S_i, ignoring the Matérn transition width ~L/3 that smears the effect). F-B4 (3-D grain killer) must come FIRST: if the grain layer with spatially varying D cannot steepen slope in full 3-D with real contacts, no analytic mixture bound matters. Current order wastes a build cycle.

**Q6 (hiding/exposure as placement rule legitimate?)** — No — as formulated ("fines in wakes") it is looks-like tuning without a formation process (see B11). Wilcock–Crowe/Parker are entrainment-rate closures given τ; they become legitimate ONLY run forward: compute τ(x,y) (even a coarse double-averaged shear + wake deficit behind large clasts, cf. Schmeeckle; Yager protrusion), integrate entrainment/deposition to an equilibrium surface, and let wake fines EMERGE. Placement-by-stencil inverts causality: it paints the equilibrium pattern of a flow it never computed. Minimal legitimacy test: the rule must predict a TRANSPORT rate that matches Wilcock–Crowe for the same GSD/τ — the current R_a=2.0·m^γ predicts no rate at all.

**Q7 (killer before build? DEM or calibration first?)** — Killer before build, DEM before calibration. Order: (1) obtain Bertin DEM (fallback: Powell + Aberle & Nikora gravel DEMs, or new flume scan — state the fallback chain with dates, not "obtain DEM" as an unbounded prerequisite); (2) run directional 2-D killer on EXISTING v4-2.2/2.3 beds vs real DEM with occlusion-matched fill (cost: days, decides whether patch architecture has any headroom); (3) calibration suite on synthetics (validates the estimator, not the bed); (4) build bed_gen3 ONLY if (2) shows a gap closable by grains-plus-patches (decomposition says expect NO — be ready to pivot to Fix 2 instead of building). Calibrating the ruler before knowing the target's shape is polishing a ruler for the wrong exam.

**Q8 (M3 0.08 vs grains-only 0.079? M6 D50 scaling? M5 2.5·D90 sensitivity?)** — All three bounds are fragile: (i) M3 lower 0.08 vs grains-only 0.079: separation 0.001 with estimator σ≈0.03–0.05 → discriminability ≈ 0.02σ — the bound is the null, not above it; any grains-only bed passes M3 by noise (the design's own "in-band-for-the-wrong-reason" prediction concedes this). Raise to ≥0.11 or drop M3 as a discriminator. (ii) M6 D50 scaling: σ_B/D50 median 0.26 mixes grain and form variance; scaling by D50 assumes self-similarity across GSDs that v4-2.6 refutes (σ_g widening lowers H — non-self-similar). Scale by D84 or by measured σ_g-dependent armour factor (Ferguson/Powell), not D50 alone. (iii) M5 2.5·D90 with D90∈[75,95]: separation 188–238 mm (±12%) straddles the meso-band edge (200 mm range); band-edge metrics have maximal leverage — a 12% edge shift moves Φ by ~0.05–0.08, comparable to the entire hoped-for signal (0.84→0.56 is Φ, but H_meso 0.08→0.13–0.19 window is only 0.06–0.11 wide). Propagate D90 uncertainty into M5 as an interval gate or fix separation in mm from Bertin's measured range (200 mm), not from the uncertain D90 multiple.
