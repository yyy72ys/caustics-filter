## Part 1: 体制地図

距離は見かけ距離で扱う：水面 s_surf = h_a、床 s_bed = h_a + d_w/n。

- ぼけ円（訂正済みの式）：b = (f²/N)·|s − s_f|/(s·(s_f − f))
- Airy 径：d_A = 2.44·λ·N_w、N_w = N·s_f/(s_f − f)
- 実効ぼけ：b_eff = sqrt(b² + d_A²)（二乗和の約束として明記する）
- 格子：N ∈ {1.4, 2, 2.8, 4, 5.6, 8, 11, 16}、合焦先 ∈ {水面, 床}、三枠すべて
- 各セルで報告：もう一方の面での b（mm と px）と b_eff（px）、合焦面での d_A（px）
- 体制の分類（参照閾値として明記）：A = もう一方の面の b_eff ≤ 2 px（フォーカス移動が見えない）／B = b_eff > 2 px（移動が実在）／D フラグ = ぼけた面で Airy が幾何ぼけを上回る（回折支配）
- 検証アンカー（必ず再現すること）：h_a = 1.0 m、f = 35 mm、N = 2.8、水面に合焦 → 床のぼけ b = 0.141 mm = 8.0 px。合わない場合は計算を疑い、原因を報告する
