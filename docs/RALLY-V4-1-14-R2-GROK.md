新規の誤り・矛盾

C1′ と C5′ のポート衝突リスク
C1′ で u_LC 受け口を U1 に持たせ、C5′ で「第1段は起源しない」と書いたが、U1 の出力仕様に「u_LC が未接続のときのデフォルト値（ゼロか、警告か）」が定義されていない。未接続時にゼロ埋めされると、膜輸送が黙って間違った場で動く。
修正文案：
「U1 の u_LC 受け口は、第3段から値が供給されない場合は『未接続』フラグを立て、U4 の膜移流はそのフラグを見て Langmuir 寄与をゼロとして扱うことを明示する。黙ったゼロ埋めは禁止。」

共通分散土台（新順2）と U5 の有限水深 QTF
共通分散土台で有限水深分散を先に置く一方、U5 の QTF はまだ「有限水深版の扱い」が C 群に明示されていない（§6.3 で U8 監査に触れているだけ）。浅水で QTF を深水核のまま使うと、C6′ の「適用域は実測で決める」と矛盾する。
修正文案：
「U5 の QTF は共通分散土台が提供する有限水深分散関係を分母に用いる。深水核のままでの評価は kH → ∞ の回帰検証用に限定する。」

U2b と U9 の順序
U2b（最終収支閉合）が U9（弱風4マス処置）の前に来るため、弱風セルで物理閉合が選ばれた場合に τ 表や残差が後から変わる可能性を残している。
修正文案：
「U9 で物理閉合が選ばれたセルがある場合は、その変更を U2b にフィードバックして τ 表と残差を再確定する。U2b は『初回確定』と『U9 反映後の最終確定』の二段階とする。」
