# コースティクス+水面揺らぎフィルター — すり合わせ仕様 【凍結 v1.0 / 2026-11-09 04:39 ユーザー確定】

## テーマ(ユーザー明言 2026-11-09)★最上位
**これは「地球環境をコードで作る、それを視覚的に表現する」というテーマの《作品》**。
単なる便利フィルターではない。彼の美術の軸「物質そのものの保存を超えて
環境という単位での保存を目指す」(memo.txt) と地続き:
環境をコードとして記述できれば、環境は任意の像の上に再現・保存できる。
→ 設計含意: ノードは「エフェクトのつまみ」ではなく「環境の記述」として扱う。
太陽・水・風・天気は互いに影響し合う一つの系として作る。

## 決まったこと
- 形: 写真・動画を読み込んでかける **Webアプリ**(スマホ/PC両対応、Edge-to-Edge標準適用)
- 核の見え方(ユーザー確定 2026-11-09):
  **2D(動画でも画像でも)を揺らがせる + コースティクスの反射もある**
  = 入力メディア自体が水面の波で屈折して揺らぎ、その上をコースティクスの光と反射が遊ぶ
- リファレンス4枚(refs/ 配下に保存):
  - ref1: 緑の川面、細波の歪み+上部の太陽グリッター
  - ref2: エメラルドの水面、斜めに流れる波紋+点状グリッター
  - ref3: 波の縁に虹色の分散(色にじみ)
  - ref4: **絵画**(実写ではない)。ただしイメージは似ている:
    フラットな面が水面のツヤと歪みで「水」になる感じ
  - 緑が多いのはたまたま(川底・周囲の緑が由来)。**色は緑固定ではない**

- 構造モデル(ユーザー確定 2026-11-09, ref5=型ガラス越しの花束):
  **フィルターは「手前に置かれた水/ガラスの膜」そのもの**。
  奥の対象は立体でも、静止画として捉えれば2D。その2Dが膜の凹凸で歪む。
  ref5(型ガラス越しの花束)も refs/ に保存済み
- Blender 2D版ルート(ユーザー指摘): Blender空間に
  画像平面+手前に水面メッシュ(透過・屈折)を置いてレンダリングでも作れる。
  Webシェーダー版と等価な「膜モデル」の物理レンダリング版

## 効果の分解(仮)
1. 揺らぎ: 細波ノーマルによる屈折歪み(大きな波ではなく細波メイン、時間で流れる)
2. コースティクス反射: 光の網目+グリッター(太陽条件で変化)
3. 水の色: 環境ノード由来のティント(入力の色を活かす)

- 動き・書き出し(ユーザー確定 2026-11-09):
  静止画入力でも揺らぎは **動く**。本命は **ループ動画書き出し**(静止画書き出しも選べる)。
  動画入力はそのまま動画書き出し。ループは継ぎ目なし(seamless)が前提

- 環境ノード範囲(ユーザー確定 2026-11-09): **フルセット+実在モード**
  - 系統: 太陽 / 水 / 風と波 / 天気 (互いに影響し合う一つの系として実装)
  - 実在モード: 実在の場所+日時を指定 → その地球環境をそのまま再現
    - 太陽位置: 緯度経度+日時から天文計算(確定論的に再現可能)
    - 天気・風: 実測/アーカイブ気象データ取得が候補(Open-Meteo等、キー不要の無料API)
    - 読み込んだ後も各ノードは手で上書き・調整できる前提

- 実装ルート(ユーザー確定 2026-11-09): **両方**
  - Web版: レシピ(環境記述)をリアルタイムに組み立て・プレビュー・書き出し
  - Blender版: 同じレシピを読み込み、物理レンダリングで最終出力もできる
  - → 含意: **環境レシピは単一のデータ形式(JSON)として設計**し、
    WebシェーダーとBlenderシーン生成スクリプトの両方がそれを読む。
    作品の本体はレシピ(=環境のコード)であり、描画系は交換可能な窓

## 決まったこと(追加)
- ノード形式(ユーザー確定 2026-11-09): **ハイブリッド**
  - 通常モード: 積み上げ式 = 「繋がないノード」。環境は信号フローではなく
    状態記述であり、太陽/水/風/天気は一つの環境を同時に構成する。
    変数は全部入り。相互の影響線は表示のみ(物理で固定)
  - 上級モード: 影響の結合(どの現象が何に効くか・重み・ON/OFF)を
    繋ぎ変え/編集できる逸脱レイヤーとして解放する
  - 背景: ユーザー自身の問い「繋がないノードってこの場合あり得る?」から
    通常=無配線が導かれた。その上で最終選択はハイブリッド

## 助手側デフォルト(最終確認で提示、異議なければ採用)
- ループ長: 8秒・継ぎ目なし (シェーダーの時間周期化で保証)
- レシピ保存: 名前付きJSONとして保存/読込/書出。実在モードの
  場所+日時もレシピに含む = 「その環境」がファイルになる
- 物理の度合い: 実物理ベース(太陽天文計算・IOR 1.333・フレネル)、
  ただし最終の見えはリファレンス4枚+ref5の質感に合わせて調整
- UI: 日本語。プレビュー最優先・詳細はオンデマンド(認知負荷最小)
