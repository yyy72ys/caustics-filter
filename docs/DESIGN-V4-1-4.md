# DESIGN-V4-1-4 — 予算会計の修正（底応答は別枠）

## 問題（v4-1.3 REPORT §4 の実測）

v4-1.2 の予算式は `var(ii)+var(iii) = σ_reg² − var_i`。実寸シーンでは
var_i/σ_reg² = 2.395 となり、流れ成分 (ii)(iii) が恒等的にゼロになった
（48 フレーム同一＝静止画）。

## 会計の誤り

Dolcetti 2016 の σ（回帰の元データ）は、直接応答 (i) がほぼゼロの床
（球格子床、v4-1.2 で実測 3.14e-04）で測られた水面全体の σ である。
したがって回帰が閉じるべきなのは**流れが作る成分 (ii)+(iii)** であって、
底応答込みの合計ではない。底応答は伝達関数で別途計算される物理量であり、
合計は二乗和で合成するのが一貫した会計である。これはラリー第2ラウンドの
統合（「直接の底応答 T·ζ は別項として保持」）の帰結でもある。

## v4-1.4 の変更（これだけ）

- `var(ii) = φ · σ_reg²`、`var(iii) = (1−φ) · σ_reg²`（φ はモデル形から出る分率、従来どおり）
- (i) は従来どおり計算し、分散は合計に二乗和で加える: `σ_total² = σ_reg² + var_i`
- var_i = 0 と置けば v4-1.2 の配分と厳密に一致すること（単体確認を必須とする）
- 水路13条件では var_i ≈ 0 なので G1'' の数値は v4-1.2 から実質不変のはず。
  変わったら、それは会計ではなく実装の差であり、報告で切り分けること。
