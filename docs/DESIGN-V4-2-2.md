# DESIGN-V4-2-2 — 床の作り直しと監査の較正

v4-2.1 の G-BED FAIL（8項目中1 PASS）を、所有チャットの切り分け
（delivery/offline-v4-2-1 の台帳 closeout）に基づいて直す。
実装側の「ゲートは相互に矛盾する」という主張は半分だけ正しい。
矛盾ではないものは生成側で解き、検証が成立していないものは監査側を直す。

## 生成側の修正（bed_gen2.py）

1. **突出分布に正の裾を持たせる** — v2.1 の planing は上面を到達形態で
   切り取ったため matrix の歪度が −0.073（均した床の符号）になった。
   各粒の上面は形態に対して突出量 p を持ち、p の分布は非対称
   （大半は埋まり、一部が最大 ~0.5·D まで顔を出す）とする。
   目標: matrix 歪度 +0.3〜+0.9。
2. **σz は実測で閉じる** — 基盤振幅の固定点は粒の寄与を過小評価した
   （目標 8 mm に対し実測 15.6 mm）。生成→深さマップ実測→構成パラメータ
   （埋没深さ・基盤振幅）調整の反復で σz(matrix) を 0.40·D50_surface 中心に
   閉じる。反復は最大4回、全試行を報告する（ゲート後に帯を動かすのは禁止、
   帯に合わせて作るのは設計）。
3. **空隙率と被覆率** — バルク層の過充填を緩めて空隙率 0.30–0.45、
   アンカー密度でクラスター被覆率を 10% 中心（帯 5–15%）に置く。
4. 基盤 fBm は H=0.79 のまま。振幅は σz の予算の中で配分する
   （粒 ~6 mm + 基盤 ~5.5 mm → 合成 ~8 mm の見込み）。

## 監査側の修正（測り方）

1. **粒径と装甲は「正確な監査」を正とする** — 粒リストから、各粒の露出
   上面面積で重み付けした表面 GSD と、表面層/下層の D50 比を直接計算する。
   v2.1 の復元演算子（残差→極大→ボロノイ）は既知入力で 2.10→1.20 と読む
   偏りが実証されたため、ゲートには使わない。演算子は較正用に併記する:
   装甲なし参照床と本床の両方に掛け、生値と偏りを報告する（方法の記録）。
2. **H は折れ点で分けて測る** — 構造関数を実測の折れ点で2区間に分け、
   ゲートは折れ点より大きい側（形態スケール）の指数に適用する。
   折れ点の位置（×D50）と両区間の指数を報告する。
3. **σz/D50 の D50 は表面（装甲後）の D50** — 文献の回帰（D50=2.18σz 等）が
   表面の床材料に対するものであることに合わせる。入力 D50 での値も併記する。
4. **断面の納品** — 高さ場 .npy と、流れ方向・横断方向の断面図（mm 単位、
   D50 のスケールバー付き）を成果物に含める。断面は監査の一部である
   （粒スケールの起伏と非対称が目で見える形）。

## 輸送

v4-2.1 の輸送（run_v4_2_1.py の経路）を新しい床で再実行し、
G-TRANS（エネルギー保存・岩の影）を再確認する。場面定数は v4-2.1 と同一。

## 主張の範囲（ラリー E1/E2 の裁定どおり）

楕円体近似（角の無さ）は既知の限界として開示を続ける。
