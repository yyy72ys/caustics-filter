N4 — 照合報告目安0.30とsd差が効く領域
条件付き成立 — 文言修正で閉じられる

通った点
R12 §6.2 V3(ii)は、|r_emp − f_a| > 0.30 を「大きく外れた」場合の報告目安として追加した。

また、窓対数13の場合、1/√(13−3) ≈ 0.32 であることを示し、窓対数が異なる場合は 1/√(n−3) で読み替えるとした。

さらに、sd差がsd_gateを実際に決めるのは、sd_2 < 0.676 sd_1 の場合に限られることも追記した。それ以外ではsd_gateはsd1となり、照合結果はゲート値に影響しない。

CONFIRM10で欠けていた数値目安と適用領域の限定は、かなり補われた。

残る欠陥
ただし、Fisher zの標準誤差と、相関係数そのものの差を同じ尺度として扱っている。

1/√(n−3) はFisher z尺度の標準誤差である。一方、R12の報告対象は |r_emp − f_a| という相関係数尺度の差である。

f_a = 0.338 付近では、局所的な変換係数は概ね 1 − r² ≈ 0.886 となる。したがって、z尺度の0.32と相関係数尺度の0.30を「同程度」とする説明は、尺度変換を省略している。

また、窓対数が統計量・Run・方向・ラグごとに異なる場合、どの単位の窓対数を使って報告目安を読み替えるかを、対応窓ごとに固定する必要がある。

通るための条件
• Fisher z尺度とr尺度の違いを明記する。
• 0.30を経験的な報告目安として置くのか、推定誤差から導く値として置くのかを区別する。
• 窓対数は対応する統計量・Run・方向・ラグの有効窓対数を使うと明記する。

なお、0.30は合否判定に使わず、超過は記録のみとする規則は通っている。ここで必要なのは、報告目安の統計的意味を誤読させないことだ。

2. 直しの優先順位
残る問題は影響順に次の3件。いずれも、単なる説明追加ではなく、判定の再現性に直結する。

優先1 — V-H1の窓定義と品質不良判定を実行可能にする
対象：§6.2 V-H1、§5.2 E1
修正内容：
• 窓配置の原点・位相・座標系・端数処理を固定する。
• 欠損セルを含む窓の有効条件を数値化する。
• 基準(2)と基準(3)の対象集合を明記する。
• 元Aberle面から2mm劣化面までの範囲対応を固定する。
• 品質不良条件の面平均値をM≥1.8判定に使える条件を明記する。
• 判定に使えない場合はM未確定として選択肢(2)を制限する。
• 3点セットの確認時点と、M未確定時の(d)・第2段設計サイクルの優先関係を明記する。

ここが閉じないと、V-H1の品質不良基準(3)とE1の受け皿は実行可能な規則にならない。

優先2 — 「検出力なし」とRun別判定の伝播を閉じる
対象：§4.2.2、§5.2経路1・経路2、§6.2 V3-prep・V3(ii)、§7
修正内容：
• §7に残る「検出力なし」の意味を、48%以上の定義と整合させる。
• grep記録の自己除外範囲と、現行規則に対する分類を明記する。
• §5.2成立基準(2)で、差分ゲートと(b) vetoの双方が3 Runすべてに適用されることを明記する。
• (b)点推定のRun別判定を明記する。
• 経路2の「差」を§4.2.2の加工前後差へ明示的に接続する。

優先3 — 照合と残存リスクの意味を固定する
対象：§6.2 V3(ii)、§7、§6.2 V-Q2
修正内容：
• 0.30の報告目安について、Fisher z尺度とr尺度を区別する。
• 窓対数の読み替え単位を固定する。
• 0.50帯がsd96推定誤差の保証ではないことをvetoの解釈に明記する。
• V-Q2の照合結果を3席がどう審査し、どの条件で分離規則を再開するかを事前固定する。

3. CONFIRM10最低条件1–3の閉鎖判定

| CONFIRM10最低条件 | R12での対応 | 判定 |
| 1. V-H1基準(3)の実行可能性＋E1受け皿の迂回封じ | 窓寸法・ストライド・面ごとの事前固定総数、M≥1.8歯止め、M未確定時の(d)を追加。ただし窓配置・有効窓の定義と品質不良値の適用条件が未確定 | 未閉鎖 |
| 2. 「検出力なし」の全文統一 | §4.2.2旧文を修正。(b)帯を別呼称に変更し、厳密式を採用 | 閉鎖 |
| 3. 照合・Run別算出・文言束・訂正11 | 0.30目安、0.676適用領域、Run別sd1、経路1のRun指定、§1.5参照、R11全文grepを追加。ただし照合の尺度とV-Q2再開条件に追加の明確化が必要 | 条件付き成立 |

最低条件2は、CONFIRM10が指摘した具体的な定義衝突をR12が修正したため、要求された範囲では閉じたと判断する。

最低条件3は、指定された修正の多くが実装された。ただし、照合目安の統計的な尺度の扱いとV-Q2再開条件には追加の明確化が必要である。

最低条件1は未閉鎖。窓総数を事前固定すると書いただけでは、窓配置と有効窓の計算規則が一意にならない。

4. 最終判断
R12は、CONFIRM10で問題となった旧文の残存、(b)帯の呼称衝突、Run別sd1の供給不足、M≥1.8の迂回路などに対して、具体的な修正を行った。これは前進である。

しかし、V-H1の品質不良基準(3)は、窓総数を事前固定したという宣言だけでは実行可能にならない。E1受け皿も、品質不良値を棄却線判定に使える条件がまだ明瞭でない。さらに、Run別判定・照合の尺度・V-Q2再開条件にも、判定の再現性を左右する残件がある。

よって最終裁定は「差し戻し」。

次版で新しい仕組みを増やす必要はない。まずは、既に書いた規則の分母・適用条件・判定単位・参照先を一意にすること。これらを閉じた後に、改めて「採用判断にかけられる状態」かを審査する。
