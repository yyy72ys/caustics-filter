## チャンク構成

### 前提タスク（チャンク4 のゲート0として実施）
ラリーで「未確認」とされた検証項目を先に潰す。
- **E: Smith 影のコード確認** — 現在の実装（直達項のみ・統計的 G1）が、実現場の解像済み遮蔽と二重計上になっていないかをコードで読み切り、判定を記録する（維持／スケール分離を明示／除去 のいずれか）。Gemini の「全廃」案は、前方ヤコビアン写像が遮蔽テストを内蔵しない点で前提が強い — 判定はコードの実態で決める。
- **Q 収束試験** — 太陽円盤求積 Q=9/25/49 で、ピーク輝度・トポロジー・面積平均それぞれの収束を測る（⟨C⟩=1.0 はピーク収束の保証ではない、という GPT の指摘に応える）。
- **MS-SSIM の分解** — フォトン検算との一致を、ピーク輝度の絶対誤差とピーク位置ズレに分けて記録する。

### チャンク4 = バージョン 3.4 — 波スペクトルの決定を完成させる
対象： ラリー確定 P0-C（＋F のクランプ、GPT のパッチカバレッジ）。
- 分散関係を **ω² = (gk + γ/ρ k³) tanh(kh)** へ更新（有限水深＋表面張力）。深水近似は廃止。8 秒ループの量子化（ω を 2π/8 の整数倍へ）は新分散の下で再構成する。
- **較正アンカーの置換**： Cox–Munk（海洋・完全発達）をゲート目標から外し、無次元フェッチ F̃ = gF/U² に基づく短フェッチ傾斜統計（JONSWAP／Donelan 系）へ替える。池 F̃≈39 で高周波傾斜を潰さないことが目的（Gemini の桁： 現行アンカーは σ² を 1/2–1/3 に過小評価しうる）。
- 方向分布 D(θ) を明示変数として持つ（現行 Phillips の古典的方向因子を、フェッチ・浅水条件でどう変えるかを式で記録）。
- 毛管側の扱い： 表面張力項入りの分散＋高波数テールの物理的カットオフを式で固定（Δx≈0.72mm が毛管スケールを解像する以上、テールの形はカスプの鋭さに直結する）。
- **砕波クランプ**： H_max = min(0.142λ, 0.78h) を追加（Stokes キャップと併記。浅端で H>h の幾何破綻を防ぐ安い保険 — GPT／Gemini の裁定どおり）。
- パッチと波長カバレッジの明示： 最大波長＝パッチサイズ（現行 1.48m 級）であることをレシピ／出力メタデータに記録し、低波数切断が効く条件（長波が支配的な強風時）を honest note に残す。パッチ拡大は計算量と相談し本チャンクでは行わない。
- shoaling／波の屈折は**水深勾配 ∇h が前提**で、現行の均一水深シーンでは発動しない → v4（立体ボトムで ∇h が実在する）へ送り、本チャンクの範囲外として明記する。
- ゲート案： (1) R=0・雨なし・既定プリセットで 3.3 との差分が「分散とアンカー変更で説明できる範囲」に収まること（全面一致は求めない — 物理が変わるため。差分の内訳を数値で記録）。(2) kh≪1 の検証ケースで位相速度が √(gh) に漸近。(3) 新アンカーでの σ² ゲート通過（旧 Cox–Munk 値との差を記録）。(4) クランプ発動ケース（h=0.1m 級）で H≤0.78h。(5) C 平均 1.0・crush/blow は従来ゲート維持。

### チャンク5 = バージョン 3.5 — 天空光（直達／拡散の分離）
対象： ラリー確定 P0-A（3者一致・最大の欠陥）。
- 実在モード： Open-Meteo の直達放射（DNI 相当）と拡散放射（DHI 相当）を分離取得し、直達率 **η = DNI/(DNI+DHI)** を状態変数にする。手動モードでは η と天空の明るさを直接指定できる。
- 輸送の分離： 直達成分は従来の全 preimage ヤコビアン輸送（有限太陽円盤つき）。拡散成分は天空ドーム積分による弱集光＋下地照度として、同じ波面統計から導く（手続き的な環境光の定数項で済ませない）。
- 結合： 曇天（η→0）でコースティクス・コントラストが物理的に漸近して消えること。晴天（η≈0.8 級）で従来の見えに近づくこと。
- 天空モデルは Perez 系の標準形を第一候補とし、採用式と出典を設計追記で確定する（チャンク5 の設計詳細は着手時に本書へ追記）。

#### チャンク5 設計詳細（2026-11-11 追記、ユーザー承認済み）
- **天空モデル**： Perez et al. (1993) の all-weather 天空輝度分布を採用（ε／Δ ビンの公表係数表）。入力は直達率 η、全体日射量、天頂輝度相当量、濁度（既定 3、入力として保持）。
- **実在モードの η**： Open-Meteo の direct_radiation / diffuse_radiation（DNI 相当は direct_normal_radiation）を分離取得して η を実測値から決める。取得は環境解決ステップの責務とし、オフライン描画器は解決済みの η と放射量を入力に取る（描画の決定性・オフライン性を保つ）。取得に失敗した場合は記録の上で代表値に落とし、ブロックしない。
- **輸送の結合**： 直達成分は従来の決定論輸送（有限太陽円盤）を DNI 份额で。拡散成分は天空ドームを Perez 輝度×入射余弦で重み付けした方向求積（64–128 方向目安）で走らせ、同じヤコビアン輸送を方向ごとに合計する。拡散 C は微細構造を持たないため 512² マスターで計算し拡大する — その正当性は拡散 C の統計（p99/平均、空間スペクトル）で検証して記録する。拡散の水中路程は直達より長い平均路程係数を別に持ち、採用値を記録する。
- **合成との境界**： 凍結済み合成（A2.6+Blow+E2.2）は変更しない。本チャンクが変えるのは光の場： C を C_total（直達・拡散の加重和、平均 1 の意味は従来どおり）へ置き換える。環境光乗数の物理的読みは元々表示側の定数であり、その旨を正直に記録する。
- **レシピ**： `sky.directFraction`（η）、`sky.mode`（manual/real）を追加。天空指定のないレガシーレシピは η=1（純直達）として 3.4 と完全一致させる。
- **ゲート（確定）**： (1) η=1 で 3.4 の結果と一致。(2) 平水面では任意の η で C_total ≡ 1。(3) η 掃引（1.0/0.75/0.5/0.25/0）でコントラスト統計（p99、p99.9、標準偏差）が単調低下し、η=0 の拡散のみ場の振幅を実測して記録。(4) エネルギー収支： 底面総量が (DNI+DHI)×透過の収支と許容内で閉じる。(5) 実在モードの η が晴天／曇天で桁の正しい範囲に入る（取得できない場合は代表値で代替し明記）。(6) crush/blow の従来 bound 維持。
- ゲート案： (1) η=1 で 3.4 の直達のみ結果と一致（拡散 0）。(2) η 掃引でコントラスト（C の p99/中央値など）が単調に低下。(3) エネルギー保存： 全入射に対する底面総量の収支が閉じる。(4) 実在モードで実天気（晴れ／曇り）の η が桁で正しい。

### チャンク6 = バージョン 3.6 — 水中光輸送（吸収・散乱の分離）
対象： ラリー確定 P0-B。
- 濁度スカラーを廃し、**a(λ) 吸収係数と b(λ) 散乱係数を分離**（プリセットは粒子種から a/b 比を引く）。位相関数は Henyey–Greenstein（g はプリセット、淡水の前方散乱 g≈0.85 を基準候補）。
- 単散乱までを輸送に入れる： 前方散乱による焦線のソフト化は、現行の経験ブラー σ∝√(b·z) を「散乱積分から導かれる形」へ置き換える（ブラー自体は数値表現として残してよいが、σ の決まり方が物理から出ること）。
- CDOM 吸収の差し込み口を a(λ) の加算項として用意する（中身の変数化は v5 の領分 — 本チャンクでは口だけ）。
- ゲート案： (1) b→0 で 3.5 の結果へ一致。(2) 同じ減衰係数 c=a+b でも a/b 比で色とコントラストが分かれる（ラリーの反証条件）。(3) 前方散乱で焦線ピークが下がり裾が広がる方向が単調。(4) 往復光路（底で反射して戻る光）の減衰が両経路で効く。
