G-LINE-stat 設計への敵対的査読

総合判定

条件付き採用・現状のままでは統計的な合格判定に使えない

この設計の方向性は妥当です。しかし、重大な問題が3つあります。

1. n=15という標本数の説明が、独立した情報量を保証していない。
2. 平均＋q90という判定規則は、観測された散らばりに配置されているだけで、誤判定率が検証されていない。
3. 写真側の窓配置ジッターは、写真そのものの自然変動を推定していない。

特にD2とD4は、統計化によって判定がモデルの性質に近づいたという主張を強くしすぎています。

設計変更としては前進ですが、「統計的にモデルの性質を判定できるようになった」と結論する段階にはありません。

D1：単一 seed・単一フレームの合否はモデルの性質ではない

STANDS

根拠

5 realizationで全4窓通過が0本。さらに、窓ごとの本番seedの結果は次のとおりです。

- smooth x：0.910
- smooth y：1.016
- bark x：1.070
- bark y：1.168

同じモデルでもseedによって写真との比が変わり、特にbark yでは0.97〜1.29まで動いています。

したがって、単一seedの合否をモデル全体の性質と同一視するのは不適切です。

反論・崩れる条件

ただし「単一seedではモデルの性質を測れない」は言いすぎです。

モデルが確率的でなく、seedが単なる決定論的な初期条件なら、特定seedでの結果にも意味があります。

また、制作物が実際にそのseedでレンダリングされ、そのフレームを完成品として提出するなら、単一seedの結果は作品そのものの品質判定として有効です。

問題は測定自体ではなく、測定対象の取り違えです。

- 単一seed：特定realizationの性質
- 複数seed：realization間の変動
- モデル全体：生成過程の統計的性質

この3つを混同してはいけません。

失敗条件

単一seedを廃止することで、逆に実際の完成品に存在する局所的な問題を見逃す可能性があります。

例えば、平均的には合格するが、本番seedだけに強い格子状のパターンが出る場合です。

判定：STANDS。ただし単一seed判定を捨てるのではなく、対象を限定して残すべきです。

D2：平均＋散らばりで判定すれば合否はモデルの性質になる

WRONG

ここが設計の最大の論理的飛躍です。

複数realizationを測定することは、モデルの生成特性を推定するための必要な方向性です。

しかし、分布を測定しただけでは、合否がモデルの性質になるわけではありません。

反論1：n=15は独立標本数15ではない

R=5、F=3という構造です。

同一realizationの3フレームには時間的相関が存在します。

したがって、15個の測定値を独立標本として平均の標準誤差を計算すると、過小評価する可能性があります。

さらに、フレーム間相関だけでなく、realization間にも共通のモデル構造による依存性があります。

有効標本数は単純に15とは置けません。

反論2：平均の標準誤差を表示しても判定の信頼性は上がらない

例えば、realizationごとの3フレーム平均を X_r とすれば、

X̄ = (1/5) Σ_{r=1}^{5} X_r

標準誤差は、

SE(X̄) = s_X / √5

です。

この計算なら、フレームを独立標本として水増しする問題は回避できます。

しかし、R=5では標準誤差そのものも不安定です。

また、SEは平均の不確実性であって、生成分布の上側の挙動を保証しません。

反論3：15標本でq90は極めて不安定

n=15の場合、90パーセンタイルはほぼ上位1〜2個の値に支配されます。

つまり、q90≤1.25という条件は、実質的に最大値付近の値によって左右されます。

ブートストラップを使っても、元データに存在しない極端値を生成できるわけではありません。

5 realizationしかない以上、bootstrap区間もrealization間の変動を十分に捉えられない可能性があります。

失敗条件

- フレーム相関が強い。
- 5 seedが生成過程の多様性を十分に代表していない。
- seedの選択に偏りがある。
- 作品の時間変化が3フレーム以外で大きくなる。
- q90の推定誤差が判定境界より大きい。

修正すべき表現：

「合否はモデルの性質になる」ではなく、

「合否を、指定したseed生成条件・時間サンプリング条件下におけるモデルの生成分布の推定値として扱える」

とすべきです。

この限定は重要です。

D3：写真側も分布として扱う必要がある

WEAKENED

問題提起は正しいですが、提案された是正方法には統計的な飛躍があります。

反論1：窓配置ジッターは写真の自然変動ではない

提示されたジッターは、

- smooth x：3.5%
- smooth y：3.9%
- bark x：9.9%
- bark y：6.1%

です。

これは窓原点を±24px移動した際の測定変動です。

つまり、測定位置の変更による感度を測っています。

しかし、写真の個体差、撮影条件、光源の違い、表面状態の違いは測っていません。

次の2つは別の確率変数です。

σ_placement ≠ σ_photo population

窓配置ジッターを写真側の測定床として表示することには意味があります。

しかし、それを写真の参照分布として扱うことはできません。

反論2：bark yの+2.0σは過剰な解釈を招く

bark yの平均超過+12%を、配置ジッター6.1%で割ると約1.97です。

これは確かに約2σ相当です。

しかし、これは正規分布に基づく有意差ではありません。

配置ジッターは母集団からの独立抽出ではなく、限定された窓シフト操作の感度です。

したがって、

「+2σだから統計的に有意」

とは言えません。

正しい表現は、

「窓配置感度の標準偏差の約2倍に相当する超過」

です。

失敗条件

写真が1枚しかない場合、写真側の分布は推定できません。

さらに、同じ写真内の4窓は独立した写真4枚ではありません。

4窓を写真の4サンプルと扱えば、空間的な依存性と窓の選択バイアスが入ります。

判定：WEAKENED。配置ジッターの併記は採用してよいが、写真側の分布推定と呼んではいけません。

D4：平均≤1.05かつq90≤1.25は実測散らばりに較正されている

WRONG

この主張は、閾値設定の正当性を過大評価しています。

反論1：観測ギャップに配置したことと較正は違う

閾値1.05 / 1.25は統計的に導出されていません。

設計者自身もそれを認めています。

したがって、これは観測結果を踏まえた暫定的な運用境界です。

「実測の散らばりに較正されている」という表現は不適切です。

較正という言葉を使うなら、少なくとも次の情報が必要です。

- 望ましい作品が誤不合格になる確率
- 格子状の作品が誤合格になる確率
- 閾値変更による両者のトレードオフ
- 独立データでの再現性

現状ではどれも不明です。

反論2：bark yの系統的超過と他窓の偶発的超過を分けられるとは限らない

提示された平均は、

| 窓 | 平均比 |
| smooth x | 0.954 |
| smooth y | 0.984 |
| bark x | 0.946 |
| bark y | 1.120 |

bark yだけが平均で1を超えています。

この差は注目すべきです。

しかし、5 realizationでは、bark yがモデル固有の系統的問題なのか、サンプリングしたseedの偏りなのか、時間変化の影響なのかを確定できません。

また、平均1.05という境界は、bark yの平均1.12を落としますが、真に危険なモデルを必ず落とすわけではありません。

反論3：q90≤1.25は危険な上側裾を十分に制御しない

例えば次の2つの分布を考えます。

A：ほぼ全て1.0、少数だけ1.24

B：ほぼ全て1.0、少数だけ1.80

標本数15で極端値がサンプルに現れなければ、どちらも合格し得ます。

q90は最悪ケースを制御する指標ではありません。

反論4：全4窓AND判定は多重比較の問題を持つ

4窓それぞれに平均とq90の2条件があるため、合計8条件です。

個々の条件の誤判定率が十分小さくなければ、全体の誤不合格率は上昇します。

逆に、各窓の測定誤差に相関がある場合、単純な多重比較補正も適切ではありません。

さらに、全4窓AND判定では、1窓だけが測定位置の偶然で悪化した作品も不合格になります。

判定：WRONG。暫定的な運用閾値としては使用可能ですが、統計的較正済みとは主張できません。

D5：1ループ内のフレームは独立標本ではない

STANDS

これは正しいです。

2秒ループのframe 0 / 24 / 47は、時間的に連続した同じ生成過程の観測です。

フレーム数をそのまま標本数にすることは危険です。

特に、隣接フレームの水面形状が滑らかに変化する場合、3フレームは強く相関します。

ただし、反論・追加論点

「実効標本数はrealization数で数える」という表現にも注意が必要です。

R=5を5独立標本とみなせる条件が必要です。

例えば、

- seedが独立に抽出されている。
- seed間で乱数生成の状態が共有されていない。
- 初期条件が共通であっても、seed以外の潜在的な依存がない。

これらが満たされなければ、5も独立とは限りません。

また、フレームを捨てる必要はありません。

フレームは時間変動の推定に利用できます。

重要なのは、階層構造を維持することです。

realization → frame → window

同じrealization内のフレームを独立したrealizationとして扱わないことが重要です。

判定：STANDS。集計単位はrealizationにするべきです。

D6：G-LINE-statとG-LINE2は独立な2軸として併用できる

WEAKENED

併用することには賛成です。

ただし、独立な2軸という表現は未証明です。

反論1：測定対象が違っても統計的に独立とは限らない

G-LINE-statは軸平行5–15px帯の変調深さ。

G-LINE2は2D FFTの固定周期ピーク突出度。

前者は局所的な方向性を含む変調量、後者は周期構造の突出度です。

測定原理が異なることは、統計的独立性の証明になりません。

例えば、強い周期構造が出れば、

- 特定方向の変調深さが増える。
- FFTピーク突出度も増える。

という共通原因が存在します。

その場合、両者は相関します。

反論2：G-LINE2の中央値と最大値の問題

写真自身の単窓最大prom2dが104であるのに対して、中央値は21.1です。

問題の作品の中央値25.4は1.21倍。

格子の中央値105.6 / 116.2は約5倍です。

この差は有用です。

しかし、中央値だけでは局所的な格子構造を見落とす可能性があります。

写真の最大値104という実測が、それを既に示しています。

一方、最大値を判定に使うと、写真側の偶発的なピークで誤不合格になりやすい。

したがって中央値を主判定にすること自体は合理的ですが、局所異常をどのように扱うかは別途必要です。

4組合せの意味

| G-LINE-stat | G-LINE2 | 解釈 |
| PASS | PASS | 量・周期性の両方で基準内 |
| PASS | FAIL | 変調量は許容範囲だが、固定周期構造が疑われる |
| FAIL | PASS | 固定周期性は弱いが、変調量が過大 |
| FAIL | FAIL | 両方に問題がある |

4組合せを維持することには意味があります。

ただし、これらは測定上の状態分類であって、作品の視覚的な良し悪しの4分類ではありません。

本人の目による判定を残すことは正しいです。

判定：WEAKENED。独立2軸ではなく、異なる特徴を測る補完的2軸と定義すべきです。

追加で見落としている重大論点

ここからは、D1〜D6の枠外にある問題です。

1. 窓の定義そのものに測定者の恣意性が入る

これはかなり重要です。

現在の4窓は、

- smooth x
- smooth y
- bark x
- bark y

という分類ですが、そもそもなぜその4窓なのか。

また、軸平行5–15px帯を採用する理由は何か。

例えば、実際のコースティクスにおける線状構造が斜め方向に発生した場合、軸平行測定では過小評価される可能性があります。

45度方向の線状構造が強くても、x/y方向の測定だけなら見逃すことがあります。

つまり、G-LINEは「線状構造全般」の測定ではなく、「指定した方向と周波数帯における変調深さ」の測定です。

名称と測定対象を一致させる必要があります。

追加提案： 斜め方向を含む方向別スペクトル評価を補助指標として検討する。ただし、現段階で測定軸を増やしすぎると多重比較が悪化するため、まずは診断用に限定する。

2. depthの分布以外に、分布形状を表す指標が必要かもしれない

平均とq90では、同じ平均・q90を持つ異なるパターンを区別できません。

例えば、

- 均一な細線が広く分布する画像
- 一部に強い線が集中する画像
- 線が断続的に発生する画像
- 線が束状に集まる画像

これらはdepthが似ていても、見た目が異なります。

コースティクスの視覚的特徴には、空間的な連続性や集中度も関係します。

検討すべき補助量は次のとおりです。

- 局所depthの分散
- 空間自己相関
- 方向別パワースペクトル
- 線状成分の連結性
- 高変調領域の面積率

ただし、これらをすぐに合否条件へ追加するのは反対です。

まず、写真と問題作品を識別する能力があるか検証すべきです。

3. seedとframeの交互作用

現在の構造では、

X_{r,f}

というrealizationとframeの二重構造があります。

しかし、seedによって時間変化の幅が違う可能性があります。

例えば、

- seed A：全フレームで安定
- seed B：frame 24だけ強くなる
- seed C：frame 0と47で強くなる

この場合、realizationごとの3フレーム平均だけでは時間変動の異常が隠れます。

したがって、平均を集約するだけではなく、realizationごとの最大値・時間変動幅も診断用に残すべきです。

4. bootstrapの単位が未定義

これは実装時に必ず問題になります。

15個の観測値を無作為に復元抽出する通常のbootstrapでは、フレーム間相関を壊します。

推奨するのは、realizationを単位としたcluster bootstrapです。

具体的には、

- 5 realizationを復元抽出する。
- 抽出したrealization内の3フレームをまとめて保持する。
- その構造を保ったまま平均・q90を再計算する。

ただし、5 clusterではbootstrap分布も粗く、区間推定の信頼性には限界があります。

cluster bootstrapを採用すれば問題解決、とは言えません。

5. 写真1枚とモデル5 realizationの非対称性

ここは設計の根本的な限界です。

モデル側は確率的な生成過程を測定しています。

写真側は特定の一枚の画像です。

この非対称性を、窓配置ジッターだけで解消することはできません。

本当にモデルが写真のような外観を再現しているかを検証したいなら、写真の追加収集が必要です。

ただし、現段階で写真を大量に集められないなら、比較対象を明確に限定すればよいです。

「この参照写真に対する適合性」であって、「自然界の水面コースティクス一般に対する適合性」ではない、と定義すべきです。

6. 閾値が実測に合わせて後付けされている問題

1.05 / 1.25は観測ギャップへの配置値です。

これは悪いことではありません。

初期ゲートの閾値は仮説的に置くことがあります。

問題は、今後も同じデータを見ながら閾値を調整すると、評価対象への過剰適合が発生することです。

例えば、今回の5 realizationで1.05 / 1.25を設定し、その5 realizationで合格を確認する。

これは独立検証ではありません。

閾値を固定した後、新しいseed群で再評価する必要があります。

このゲートが誤判定する具体的条件

| 誤判定 | 発生条件 | 原因 |
| 誤合格 | 少数の極端な異常が15標本に現れない | q90の上側裾の見落とし |
| 誤合格 | 3フレームの間に異常が発生する | 時間サンプリング不足 |
| 誤合格 | 斜め方向の線状構造が強い | 軸平行窓の盲点 |
| 誤合格 | 局所的な格子が中央値に埋もれる | G-LINE2の中央値 |
| 誤不合格 | 1つのseedに偶然強い変調が出る | realization数不足 |
| 誤不合格 | 窓配置が偶然強い領域に当たる | 空間配置感度 |
| 誤不合格 | 写真の局所的な自然変動を再現した | 参照写真1枚への過剰適合 |
| 誤不合格 | 4窓のうち1窓だけ測定誤差が大きい | 全窓AND判定 |

特に重要なのは、誤合格と誤不合格を同じ問題として扱わないことです。

誤合格を避けたいなら上側裾を厳しく見る必要があります。

誤不合格を避けたいなら測定不確実性を許容する必要があります。

両方を同時に最小化するには、閾値と標本数の設計が必要です。

最低限直すべき点：優先順位

P1 最優先

n=15の統計的意味を修正する

集計単位をrealizationにする。

3フレームはrealization内の反復測定として扱う。

平均のSEはrealization平均5個から計算する。

q90は推定値として表示し、15標本で安定した尾部推定ができるとは主張しない。

bootstrapはrealization単位のcluster bootstrapにする。

P2

閾値を暫定運用値と明記する

1.05 / 1.25は統計的に較正された閾値ではなく、現時点の暫定境界とする。新しいseed群を使って、閾値固定後の独立検証を行う。境界をまたぐbootstrap区間はPASS/FAILに押し込まずUNRESOLVEDとする。

P3

写真側の測定床と参照分布を区別する

窓配置ジッターは測定位置感度として表示する。写真の自然変動や母集団分布とは呼ばない。写真1枚への適合性という評価対象の限定を明記する。

最終裁定

| 主張 | 判定 | 裁定 |
| D1 | STANDS | 単一realizationの限界を正しく指摘 |
| D2 | WRONG | 分布化とモデル特性の確定を混同 |
| D3 | WEAKENED | 配置ジッターは有用だが写真分布ではない |
| D4 | WRONG | 閾値は暫定配置値であり統計的較正ではない |
| D5 | STANDS | フレームの独立標本扱いは禁止 |
| D6 | WEAKENED | 補完的2軸としては有効、独立性は未証明 |

私の最終判断：G-LINE-statの導入自体は採用してよい。ただし、現段階では「統計的合否ゲート」ではなく「複数realizationによる分布診断ゲート」と位置付けるべきです。

特に、現状の5×3という設計でできることは、生成結果の不安定性を可視化することです。モデルの一般的な合格性を保証することではありません。

そして、最も避けるべきなのは、単一seedの不安定な合否を廃止した結果、今度は不安定なn=15のq90を使って、より科学的に見えるだけの合否判定を作ってしまうことです。

統計化によって判定の見た目が精密になることと、判定の妥当性が高まることは別です。
