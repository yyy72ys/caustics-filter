# BRIEF-SPECTRUM-SHAPE — スペクトル形状そのものの切り分け（cf-0077）

## 目的

P5-CLEAR と SWELL-1 の ν のギャップ（モード集合の真値で 0.0564、cf-0075 §5）が、**Elfouhaily スペクトルそのものの形**から来ているかどうかを測る。サンプリング・量子化・窓・k_cut を一切入れず、連続スペクトルだけの ν を出す。

## 背景（ここまでの切り分け）

cf-0067 §7 の候補 3 つは全部切り分けた。

- 高波数尾部（cf-0069）：P5 では尾部が ν を決めていたが、SWELL では決めていない。ギャップは尾部では説明できない。
- 窓／λc（cf-0073）：窓を揃えてもギャップは残存比 1.03–1.09 でほぼ不変。窓は主因でない。
- ω 量子化（cf-0075）：ギャップの 17.1% を作るが、主因でない（残存比 0.829）。

残る説明は「スペクトル形状そのもの」か「位相の引き方」。位相は cf-0078 で既存データから切り分けた（シード間のばらつきがギャップより十分小さい）。ここではスペクトル形状を測る。

## 方法

1. **スペクトル関数はコードの実物から読む。** 生成器が実際に使っている S(k)（`v10_spectrum.py`、Elfouhaily 形 / Arm D）をそのまま使う。論文から式を写し直さない。使う関数のファイル名・行番号・引数をレポートに記録する。
2. **分散関係もコードの実物。** ω(k) は `v8_physics.dispersion_omega`（重力＋毛管、σ/ρ = 7.28e-5 m³/s²）。**ブリーフの重力のみの式は使わない**（cf-0075 §2 の教訓。重力のみだと P5 の高波数帯の ω を小さく見積もり、結論が反転する）。
3. **連続積分で ν を出す。** m_j = ∫ S(k)·ω(k)^j dk（j = 0, 1, 2）を細かい対数格子で数値積分し、ν = √(m0·m2/m1² − 1) を出す。サンプリングなし、量子化なし、窓なし、k_cut なし。格子は ν の変化が 1e-4 未満になるまで細かくする（収束検算をレポートに残す）。
4. **帯域分解も出す。** どの k 帯が解析的ギャップを動かしているか（cf-0069 §8.1 と同じ k 帯を使う）。
5. **照合ゲート（測る前）。** (a) 使った S(k) が生成器のものと同一であること：実現モード集合の |H0|² の k 分布（cf-0067／cf-0075 の numbers から）と S(k) の形を重ね、ピーク位置と傾きが一致することを確認する。(b) m0 の整合：解析的 m0 がモード集合の m0 とサンプリング誤差の範囲で一致すること（桁が合わない場合は測定に進まない）。

## 判定の見方（事前固定）

- gap_analytic = ν_analytic(SWELL) − ν_analytic(P5)
- 比較する基準はモード集合の真値ギャップ **0.0564**（P5 0.3254／SWELL 0.3817、cf-0075 §5）。
- |gap_analytic − 0.0564| ≤ 0.25 × 0.0564 → **スペクトル形状がギャップの主因**
- gap_analytic ≤ 0.25 × 0.0564 → **スペクトル形状は主因でない**
- その間 → **部分的**（スペクトル形状はギャップの一部を作るが、全部ではない。数値を読む）

## していないこと（禁止事項）

- 生成器を動かさない。場を作り直さない。既存 `*.py` の変更は 0 件（新しいスクリプトだけ `out/spectrum-shape/` に置く）。
- ω の量子化を外す実験はしない（それは cf-0079、本人の判断待ち）。
- 本番配線・設計変更・ビルド・動画化なし。曲率は測らない（cf-0067 §5）。
