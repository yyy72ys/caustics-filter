K1 — H3 再検査の相関つき組み替え（§4.2.2・§6.2 V3(ii)・§7）

判定：不成立

理由：R9 は CONFIRM7「採用判断にかけられる状態になるための最低条件」1 を受け、「独立した再測定」を撤回して空間相関つきの「ずらし再測定」へ組み替えた。重なりゼロの配置が存在しない算術（§6.2 V3(ii)「前提の確定」：流下最小重なり 0.6571 m／44.5%、横断最小重なり 0.3656 m／33.8%、面積最小約 15%）自体は正しい。しかし新しく事前登録した判定契約には致命的な算術・統計上の誤りがある。

相関つき sd_差 の式の破綻（sd_差 > sd_1 になる逆転）：§6.2 V3(ii)「相関つき sd_差」は閾値を sd_差 = √( sd_1² + sd_2² − 2·f·sd_1·sd_2 )（ρ = f、f_a = 0.338）と定義し、「同程度の sd では sd_差 は sd_1 以下になるため、この近似は解消を易しくする方向には働かない」と主張する。これは算術的に誤りである。 sd_1 ≈ sd_2 = σ と置くと、sd_差 = σ √(2(1 − f)) であり、sd_差 ≤ σ が成り立つのは f ≥ 0.500 の場合に限られる。f_a = 0.338 を代入すると sd_差 = σ √(2 − 0.676) = σ √1.324 ≈ 1.151 σ > σ となり、初回の sd_1 よりも閾値が約 15.1% 緩くなる（解消を易しくする方向に働く）。そもそも √(sd_1² + sd_2² − 2ρ·sd_1·sd_2) は 2 標本（Window 1 と Window 2）の差の標準偏差であり、|切り出した場面窓 − 面全体| の差分ゲートに当てはめる量ではない。

失敗条件：f_a = 0.338 のまま sd_差 = 1.151 σ で差分ゲートを再判定し、初回より 15% 緩い閾値で留保が不当に解消される。

通るための条件：(1) §6.2 V3(ii) (b) の「流下 33 位置 × 横断 3 位置 = 99 窓」を「流下 32 位置 × 横断 3 位置 = 96 窓」へ訂正すること、(2) 横断位置が初回と同一（重なり率 1.000）かつ 96 窓プール sd が流下方向分散に支配されているため、(b) の veto は真の横断独立再評価ではなく「0.6 m スケールの配置シフトに対する 40% veto のみ」である旨を正確に定義すること（分子・分母の対応も H_loc x/y ごとに明記）。

失敗条件：実行時に P1 = −9.70 m から 33 位置を切り出そうとして境界外エラーになる、または暗黙に 32 位置へ削って本文の「99 窓」と食い違う。
