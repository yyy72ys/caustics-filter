## 作業

新規ファイルのみ: `transport_mesh.py`、`run_v4_1_8.py`。
既存ファイルは一切変更しない。

1. **場の生成**: stream_surface3 の会計で川の環境（H=0.60, U=0.80,
   U0=0.92, S0=0.002, D84=0.09, seed=20261112, 媒体 algae_pond）。
   生成パッチ = 画面の窓そのもの: **L = 1.4755102 m**（v2 と同じ）、
   グリッド 512×512、ループ規則 n=1・T=2 s。これが「画像を波に
   合わせる」形であり、引き伸ばし倍率は存在しない。
2. **堆積（新方式）**: 水面の各セル（四辺形→2 三角形）について、
   角の屈折着地位置を既存輸送段と同じ屈折計算で求め、射影された
   三角形とフレーム画素（736×540）との**厳密な重なり面積**に
   比例して、そのセルのエネルギーを画素へ分配する。
   セルごとのエネルギー重みは既存 C レーンの定義を verbatim 再利用
   （変えるのは分配の仕方だけ: 点/カーネル → 面積）。
   **カーネル・ジッタ・帯域制限は一切使わない。**
   C の平均 1 への強制正規化はしない。フレームごとの堆積総量
   （= 総エネルギー）をそのまま記録する。合成段が従来規約の
   正規化を要する場合は、原の総量と適用した係数を併記すること。
3. **ベース画像**: 元写真を窓 1.4755102 m に合わせる（v2 と同じ
   フレーミング）、屈折の水深 z=0.60 m、歪みレーンは既存のまま。
   合成は凍結形 A=2.6 / Blow σ=3 / E=2.2 / Q=25。
4. **参照計算（同一フィールド・frame 24）**: 従来の点スプラットでも
   C を計算し、ピーク統計の比較材料にする（本編には使わない）。
