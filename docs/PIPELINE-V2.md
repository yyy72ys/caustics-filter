# パイプライン v2  brief（ラウンド2：輸送の主経路転換と出力分離）

前提文書：`docs/PIPELINE.md`（v1）、`docs/OUTPUT-SPEC.md`（統合出力仕様 — 必ず全文読むこと）。
v1 の状態生成（state.py）とフォトン輸送（transport.py）は活かす。今回の変更は「主経路の転換」「合成式の分離」「ゲート試験の実施」。

## 変更点
1. **決定論的ヤコビアン輸送（新規 det.py）を主経路にする。**
   - 水面状態（2048²、Choppy 変位後の実頂点）から forward 写像を構成し、底面グリッドへ面積重みつきで蓄積する。全逆像はフォワードマッピングにより構造的に含まれる。
   - 有限太陽円盤：太陽方向を中心に Q 点の角度求積（円盤内サンプリング、半径は既存 sun_disc_rad）。Q は試験で決める（下記）。
   - 受光画素フットプリントを考慮すること（最低限、蓄積セルの面積で正規化し、点サンプル扱いにしない）。
   - 出力は無次元倍率 **C = E_direct / E_base_dir**（E_base_dir は同一条件・平均平面水面での底面照度。定義と値を numbers に記録）。**マスター C にクランプ・平均正規化・ソフトショルダーを一切かけない。**
   - 基盤は NumPy でも PC の GPU（WebGL2 float RT 等）でもよい。数学とゲートが固定、実装手段は自由。
2. **合成式の分離（image.py 改修）**：OUTPUT-SPEC §3 の式に変える。環境光 E_amb は C で変調しない。直接光分のみ C を掛ける。透過（T_up/down）と散乱・反射は従来項を流用するが、C との合成順序を仕様どおりにする。
3. **flow_backward パスの保存**：像形成で使う逆変位を float32 2ch .npy で書き出す（座標規約を metadata に明記）。
4. **マスター保存**：C を float32 .npy＋metadata.json で `offline/out/v2/` に出す（EXR は任意）。

## ゲート試験（すべて numbers-v2.json に実測を残す）
- **角度求積の収束**：t=0 で Q=9 と Q=25 を比較 — log照度RMSE、p50/p99/p99.9 の相対差、帯域別スペクトル差。暫定目標は OUTPUT-SPEC §4。Q=25 でも収束しなければ Q=49 を追加。
- **フォトン検算**：t=0 で既存 transport.py の場を同じ C 定義に換算し、log(1+γC)（γ は固定し記録）の MS-SSIM と分位点差を報告。暫定ゲート MS-SSIM ≥ 0.9（未達なら未完として理由を切り分けて記録 — 主経路の自動入替はしない）。
- **解像度判定**：C（2048²）の面積平均ダウンサンプル 1024² 版と比較 — 積分光束差、p99.9 差、連結成分数の差。判定結果（1024 採用可否）を記録。
- **統計**：C の mean/p50/p99/p99.9/max、積分光束の基準比（=全面平均 C と一致するはずの量）、帯域別スペクトル比。
