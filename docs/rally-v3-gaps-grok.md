# Rally v3-gaps — Grok 初回回答全文（2026-11-10）

1. 不足している変数・機構

- 完全な入射放射輝度場（天空散乱光／天空ドームモデル）： 天空光は晴天でも全放射照度の20–50%以上、曇天・薄暮では支配的。物理天空モデル（Hosek-Wilkie/Preetham）とスペクトル結合が無ければ「環境そのもの」にならない。桁： 直達に対して O(0.2–1) 以上。v3 に必須。入れないとコントラスト過大・硬質になり、曇天や低高度太陽で嘘。
- 完全な方向性波スペクトルと実現場（JONSWAP/PM＋ピーク周波数・方向広がり・フェッチ依存、毛細波含む）： Hs と Cox–Munk σ² だけでは統計的傾き分布しか得られない。池・川（数m）ではフェッチが短く海洋用 Cox–Munk がそのまま当てはまらない。桁： 短波成分で σ² の数十%。統計だけでは「手続き模様禁止」の趣旨に反する。
- 体積散乱（散乱係数＋位相関数）、単散乱以上： 濁度を Beer–Lambert 減衰だけにすると吸収のみ。自然水では散乱が吸収と同程度かそれ以上。桁： 局所照度に O(0.1–数倍）。少なくとも単散乱を v3 に。
- 底面 BRDF（粗さ・湿潤スペキュラー）： ランバートだけでは濡れた質感とコースティクスの接着が弱い。桁： 局所コントラスト O(0.1–1)。v3 優先。
- 波長依存屈折率（分散）： 可視域で Δn≈0.01。強い集光部の色フリンジ。後回し可だが v3 後半に価値。
- 河川の平均流（流速ベクトル）： 波の屈折・ドップラー・有効スペクトルを変える。桁 O(0.1–1)。川シーン指定として v3 に。
- 泡・白波（高風速時）： 局所反射率を数倍変える。後バージョン可、閾値処理程度は v3 に欲しい。

2. 結合の欠落
- 入射放射場（太陽＋天空）と波面傾き場の完全結合（拡散成分も preimage 積分しないとエネルギー保存が崩れる）
- 波スペクトル→経路長変動→減衰・散乱の非線形結合
- 風・フェッチ・深さ・流れの相互作用（独立変数化すると「手で調整したパラメータセット」になる）
- スペクトル全体の一貫性（太陽×大気×水×底）

3. 実装済みの問題点
- Cox–Munk/Smith は海洋長フェッチ前提。池では統計がずれ、二重計上リスク。
- Beer–Lambert は散乱を無視し、経路長を平均深さで近似すると誤差累積。
- 太陽： 天空放射輝度場へのマッピングが明示されていない。エアロゾル/オゾンのスペクトル影響も欠ける。
- 雨： 運動量入力や既存波との非線形相互作用が無ければ加算スペクトルになりやすい。
- 網膜： 入力がトーンマップ済みだと二重処理。カメラ応答の方が目的に近い場合がある。
- 「統計量から直接ヤコビアン」に飛ばすと高さ場の空間コヒーレンスが失われる（※我々の実装は FFT 高さ場を実現場として持つ — Grok の前提との差異。統合時に反論材料とする）。

4. v3 が完成と言える条件
- 太陽＋天空の物理的入射放射輝度場が波面と完全結合し、エネルギー保存したヤコビアン集光ができること。
- 波はフェッチ・流れを考慮した方向スペクトルから高さ場を実現し、毛細波まで自己一貫すること。
- 少なくとも単散乱の体積効果が入り、底面応答とスペクトル全体が一致し、0.3–5m 浅瀬で写真レベルに破綻しないこと。
