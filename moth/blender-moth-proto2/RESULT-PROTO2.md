# RESULT-PROTO2 — Blender 蛾プロトタイプ第2版（造形改良＋2秒再試作）

結論: proto1 の5つの造形課題（翅の分離感・ストライプ帯・ミント色・V字姿勢・接地影）すべてに手を入れ、機構面は proto1 と同一（背景ドリフトゼロ、カメラ完全固定、振付正確）を維持したまま再試作した。見た目は「ベクターイラスト」からは一段進んだが、まだ完全にはCG感を脱していない（正直な残課題は末尾）。

## 環境・成果物
- Blender 4.2.3 LTS（PC 既存）、Eevee、64 samples、モーションブラー ON、832×480、48f @24fps
- ビルドスクリプト: `build_moth.py`（本フォルダ。PC 作業場所 `D:\yohey2026\dsh\muse\caustics-filter\blender-moth-proto2\`、proto1 フォルダとは分離）
- シーン: `proto2.blend`、背景プレートは proto1 と同一（`background-bark-832x480.png`）
- レンダー: 48フレーム 29.6 秒。組立: assemble.py（フレーム検証 48/48 OK）
- 出力: `proto2.mp4`（ffprobe 検証済み: h264 / 832×480 / 24fps / 48 frames / duration 2.000000s / 264,839 B）

## 振り付け（スチル目視）
- f00: 2匹とも平らに静止。f24: 左は左端で離脱中（モーションブラーあり）、右は静止。f47: 左は画面外、右は同じ位置。背景ドリフトなし。

## proto1 からの変更と効果（正直な比較）
1. **翅の輪郭** — 前翅・後翅の別パーツ（細い葉状×4）を廃止し、参照写真の輪郭をなぞる前縁／外縁カーブから片側1枚の扇型メッシュに変更。前翅と後翅が一体のシルエットとして読めるようになり、境目には薄い折り目状の陰影だけを残した。最大の改善点。
2. **姿勢** — 静止角を 16°（V字）→ 3°にし、キャンバーも削減。樹皮に平らに広げる本来の止まり方になった。
3. **帯** — 等間隔の斜めストライプを廃止。外縁と平行に走る横帯2本＋途切れの強い亜端帯を、弓なり＋ノイズのうねり＋ノイズマスクの途切れで構築。写真の波打つ帯の読みに近づいた。
4. **色** — 写真から実測サンプリング（翅ピクセルの中央値 #6e9c90、暗部 #5f826c、明部 #83afa4）し、低周波ノイズの斑を追加。proto1 の明るい一様ミント（#8ccb9a 基調）の「貼った」対照は大幅に減った。
5. **接地影** — 楕円グラデーションを廃止し、扇シルエットをラスタライズ（スキャンライン充填＋ボックスぼかし）した影テクスチャに変更。太陽と反対側に三日月状の縁として現れる。影デカールを外した比較レンダーとの差分測定で実在を確認（両個体とも輪郭沿いに暗化、最大 Δ71 輝度）。ただし合成スチル上では樹皮が暗く煩雑なため、効きは控えめ。

## 制作中に見つけて直したバグ
- 左の影デカールのキーフレーム基準位置が、アニメーション後のルート位置（最終フレーム値）を読んでいて影が画面外に飛んでいた。静止位置をアニメーション前に確定させるよう修正。
- 影の核 α を 1.0（真っ黒な切り抜き）→ 0.72（暗化）に変更し、ぼかし幅も拡大。

## まだCGに見える点（正直）
- 翅面がまだ均一でクリーン。実物の鱗粉の質感・透けのムラ・縁のフリッジ（毛状突起）は未再現で、輪郭も写真の三角形状に比べるとまだ丸みがある（前縁が直線的でない）。
- 体（特に腹部）が翅の上に乗った滑らかなカプセルとして読める。実物は腹部が後翅の内縁の下に隠れ、見えるのは毛の生えた胸部が中心。この構造差は未解消。
- 接地影は実在するが弱い。翅の縁直下の AO 的な濃い影までは踏み込んでいない。
- 脚・触角はこのスケールではほぼ読めない（proto1 と同様）。
