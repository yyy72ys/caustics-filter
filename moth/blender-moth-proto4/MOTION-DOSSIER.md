## 実測できたこと

### 離陸の手順（2本・別亜科で同じ型）— 今回の主成果
1. **最初に動くのは翅**。脚の押し出し・体の移動・触角の動きは、翅が開き始める前に検出できない（両クリップ共通）。
2. **離陸前に「翅の持ち上げ」が独立した相としてある**。翅は閉じた/平らな姿勢から V 字に持ち上がり、その間 脚はまだ接地している。
   - Nemoria: 最初の動き f2089 → 翅が上がり切る f2100 → 小さな前のめり（接地したまま）f2101–2102 → 離陸 f2103。**持ち上げ相 = 最初の動き→離陸の全区間の約 79%**(22/28 フレーム）。
   - Arichanna(5×): 最初の動き f620 → 離陸 f626。区間 6 フレーム = 再生 200ms = **実時間 40ms**。
3. **持ち上げの大きさ**（Nemoria、シルエット実測）: 左右端を結ぶ線の傾き **4.59° → 30.65°**、縦の広がり **142px → 161px（+19px、約+13%）**。ただし後方斜め視点の2次元投影であり、3次元の開き角そのものではない。
4. **離陸の直後に最初の打ち下ろし**が続く。Nemoria の最初の打ち下ろしは約8撮影フレーム（近似、画角外に一部出る）。
5. **両翅は一緒に動く**（定性）。交互打ち・左右交互のストロークは見えない。フレネルムで前後翅が連結する構造（ドシエ F)と整合。
6. 体のピッチ： Nemoria で腹部軸がほぼ垂直 → 離陸までに前方へ（2次元で約75°→約35°、粗い読み）。

→ 離陸の型は「しゃがむ→跳ぶ→飛ぶ」ではなく **「翅が先に開く → 短い保持 → 体が傾ぐ → 打ち下ろして離陸」**。

### 静止中の翅の動き（傍証1件）
- Ant Lab の *Hypagyrtis* 区間（f2664–2736）では、止まったままの蛾（中央と右）が**繰り返し翅を掃くように持ち上げる**のが見える。左の1匹は姿勢を変えない。機能（暖機？)は解釈であって実測ではないが、「止まったまま翅を持ち上げる反復」は観察事実として記録する。

### 静止微動のリズム — 「周期的ではない」ことだけは言える
- *G. papilionaria* クリップ2で差分スパイク候補9件（1–3フレーム長）。間隔は 2.600, 0.600, 2.433, 2.700, 1.200, 1.067, 1.033, 1.367 秒、**CV = 0.505**。ただし拡大しても姿勢変化が見えず、コーデック残差と区別できないため**「候補」のまま未確認**。
- クリップ3の候補18件は全フレームに広がる変化で**コーデックのアーティファクトと証明済み**（棄却）。そちらの CV = 1.164 は参考値にもならない。
- 結論： **周期的な静止リズムは実測されなかった**。規則正しい繰り返しには根拠がなく、不規則な間隔とは矛盾しない、が正確なところ。

## 未確立（この footage では測れなかったこと）
1. 静止微動の**振幅・持続時間・リズム**（上記。確認できた微動イベントはゼロ）。
2. **触角の動き**： 2本のクリップで触角は見えるが、頭に対して1px 未満しか動かない。イベントなし。
3. **2匹の相互作用**： 隣の蛾が飛び去ったときに止まっている蛾が反応するか — 該当場面が無い（複数個体区間は合成の可能性もあり同時性自体が未確立）。
4. *G. papilionaria* **本種の離陸**（同定確実なクリップ1は標本、クリップ2は離陸なし）。離陸の型は近縁2種からの外挿。
5. Nemoria クリップの**実時間**（6000fps/200× の表示がフレーム数と矛盾し、換算すると離陸 4.7ms になってクリップ3の 40ms と8倍ずれる。速度ランプ処理と判断し、実時間は主張しない）。
6. 翅の3次元運動学（開き角・ストローク面・周波数）、脚の関節運動、翅の変形・空力 — いずれも未確立。
7. 左右非対称なストローク — **観察されていない**（両翅同時が定性的な読み）。
