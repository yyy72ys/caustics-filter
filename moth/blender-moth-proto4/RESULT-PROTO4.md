# RESULT — Blender 蛾プロトタイプ proto4

土台: proto3 の build_moth.py（PC `blender-moth-proto4/`、Blender 4.2.3 LTS、Eevee 64 サンプル、モーションブラー、832×480、48f @24fps、カメラ固定、背景プレート不変）。メッシュ生成 AI 不使用・全面コード生成（ユーザー決定どおり）。
物差しは2つ： ①`MOTH-DOSSIER.md`（種・解剖チェックリスト A–F） ②`MOTION-DOSSIER.md`（実 footage のフレームステップ実測。proto4 で新規作成）。
進め方： ステージB（細部： 色→胸部→接地影→シルエット、1要素ずつ実測）→ ステージC（振付 v2、実測した離陸手順＋シード固定の不規則微動）。詳細な実測記録は `stageB-results.md` と `motion-results.md`、工程は `STAGE-LOG.md`。

成果物検証: `proto4.mp4` を VM 側 ffprobe で独立確認 — h264 / 832×480 / 24fps / 48 フレーム / 2.000s / 252,750 B ✓

**色についての正直な注記**: ステージB の実測では、proto3 のレンダーは写真より「明るすぎ」ではなく **約23% 暗く、かつ平坦**だった（翅中央値 90,122,108 vs 写真 112,157,148、p25–p75 の広がり 6 vs 14)。そのため「深くする」という当初表現ではなく、ブリーフ自身の数値ルール（写真中央値に最も近い試行を採る）に従い、**中央値を写真に一致させ（→ 111,156,148)、平坦さをムラとグレインで潰す**方向に倒した。「淡く均一に見える」の主因は平坦さだった、というのが実測の結論。副次効果として、背景プレート（写真の樹皮より暗い実測値で固定）との明暗差が広がり、1× では proto3 より少し「切り貼り感」が増した面がある。プレートは不変条件のため、この段階では触っていない。

### 退出エンベロープについての食い違い（隠さない）
- proto3 の RESULT は「f24 で約85% が画面外」と記していたが、proto4 のステージC で proto3 自身の f24 フレームを実測すると、シルエット面積では大半がまだ画内で、proto4（経路・姿勢とも proto3 の f24 値を厳密に継承）でも**画外は約11.3%**、左上隅にクリップした状態だった。「f24 で外」は proto3 の記述が面積実測と合っていない。proto4 は指示どおり proto3 の退出経路を変えず、**完全に画外に出るのは f47（0 px で検証済み）**。85% に合わせて退出を速める改変はしていない。

## proto3 との比較（要点）
- 色: 翅中央値が写真に一致（90,122,108 → 111,156,148、写真 112,157,148)。平坦さはムラ 0.25＋グレイン強化で改善（D1 +25%)。ただし写真の同指標 12.1 にはまだ遠い。
- 胸部: 卵形の読みは弱まった（PCA 1.505→1.358、凹凸と毛シェル追加）。体の色（オリーブ vs 写真の褐色系）が残る最大の色不一致。
- 接地影: 中域と最暗部は締まったが、輪郭直下 0–3px の平均はトレードオフで微減。ハロー化を避けた結果。
- シルエット: 実質不変（A2 +0.005)。0.90 ゲートは構造的に到達不能のまま。
- 動き: proto3 の「定期的な羽ばたき＋即離陸」から、実測型の「持ち上げ→保持→前のめり→打ち下ろし」へ再構成。静止微動は周期を持たない小さな単発イベントとして両蛾に配置し、全てシード表（SEED=20261110、MOTION_TABLE のリテラル）で再現可能にした。

## 残課題（正直な記録）
1. **A2 IoU 0.90 未達**（0.78)。対称アセットと非対称な写真ポーズの構造差。proto3 の判断（歪めて追わない）を継承。
2. **体の色**が写真の褐色系でなくオリーブで、明るくなった翅から暗く浮く。ステージB の変更範囲（翅パレット）外だったため未着手 — 次に手を入れるなら筆頭候補。
3. **D1 は目標 +30% に届かず (+25%)**、写真の 12.1 に対して 4.96 と絶対水準も遠い。832×480 の指標飽和があるため、本番解像度での再評価が要る。
4. **E3 の 0–3px 平均は proto3 より弱い**。「自然な接触線」と「帯平均の強化」は現行の投射デカールでは両立しなかった。ゼロオフセット接触/AO レイヤーが本対策。
5. **ピクセル決定性は Eevee の性質上不可**（パラメータ決定性は確保）。ビット同一が必要なら Cycles＋固定シード等、レンダラー変更の判断が要る。
6. **f24 の退出量**は proto3 の記述（85%）と実測（約11%）が食い違う。proto4 は経路を継承したため、見た目の退出完了は f47。8秒本編では退出タイミング自体の再設計が選択肢。
7. 静止微動・触角・右蛾の「残ってからの翅上げ」は**実測ではなく創作**（ドシエに明記）。実物の静止微動そのものは、入手可能な 360p footage では今も未確立。
8. 翅が明るくなった分、固定の樹皮プレートとの明暗差が広がり、1× でやや切り貼り感。プレート側の再グレーディングは不変条件のため未実施。
