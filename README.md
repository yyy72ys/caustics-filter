# Caustics Filter — 地球環境ノード

写真や動画の上に「水の膜」をかけるWebアプリ。太陽・水・風・天気の環境ノードを動かすと水面の状態が変わり、屈折の揺らぎとコースティクス(集光模様)が物理ベースで描画される。

使い方: ページを開いて写真/動画を選ぶだけ。プリセット5種と、実在モード(地名+日時から太陽位置と実天気を取得)つき。静止画PNGと8秒ループ動画の書き出しができる。

---

## オフライン物理パイプライン（v2）

Webアプリと同じ物理モデルを、GPUを使わずPythonだけで計算し、8秒ループ動画を書き出すオフラインパイプラインです。`offline/` に実装、`docs/` に仕様（`SPEC.md` / `PIPELINE*.md` / `OUTPUT-SPEC.md`）があります。

### (a) 仕組み

1. **環境パラメータ** — レシピJSON（`blender/recipe-1.json` など）に太陽の日時・緯度経度、水深・透明度・濁り、風速・風向、雲量などを書き、`env.py` が実際の環境値（太陽高度・色温度・波スペクトルなど）に解決する。
2. **水面状態シミュレーション** — `state.py` が Phillips スペクトルから 2048² の波面（高さ場）を FFT で生成し、風向・流速・周期からフレームごとの水面状態を決める。ループ用に周期を 8 秒の倍数へ量子化しているので、192フレーム目が1フレーム目に連続的につながる。
3. **光輸送** — `det.py` が水面法線から屈折方向を求め、太陽ディスクを面積光源として 25 サンプル／画素のレイを追跡する。水中での吸収・濁りによる減衰、全反射、集光（コースティクス）の強度は物理量として計算される。
4. **合成** — `image.py` が写真の反射率と光輸送結果を合成し、露出・ACES トーンマップをかけて sRGB PNG を出力する。

**全フレームがコード計算です。** 模様のテクスチャを後から貼る、動画をループ加工する、といった後付けは一切していません。写真は反射率（アルベド）としてのみ使われ、その上に載る光の模様は毎フレーム物理計算で生成されます。

### (b) 必要なもの

- Python 3.10 以上
- numpy（`requirements.txt` 参照。Pillow / scipy なども使用）
- ffmpeg（MP4 エンコード用。PATH に通すか `offline/make_video_v4.py` の `FFMPEG` を自分のバイナリに向ける）

**目安:** 2048² のマスターで、RTX 3060 Ti 級の PC だと **約50秒／フレーム**。192フレームなので、おおよそ2.5〜3時間です（CPU のみで計算します）。

```bash
pip install -r requirements.txt
```

### (c) 再現手順

1. **自分の写真を用意する。** 明るくコントラストのある写真ほど模様が見えます。リポジトリには入力例として `samples/moth-on-bark.jpg` が入っています。
2. **`offline/run_prod_v4.py` の入力パスとプリセットを確認する。** 冒頭付近のデフォルト値が実際の配置と合っているか見てください（既定は `--photo ../samples/moth-on-bark.jpg`、`--preset 1`、`--recipe ../blender/recipe-1.json`、`--out out/prod`）。別の写真を使うなら `--photo` を書き換えるか引数で渡します。
3. **レンダリングする。** `offline/` ディレクトリで実行します。

   ```bash
   cd offline
   python run_prod_v4.py --preset 1
   ```

   フレームは `offline/out/prod/frame-XXXX.png`（735×539）に出力されます。途中で止まっても、出力済みフレームはスキップされるので再実行で続きから進みます。
4. **動画にまとめる。** 同じく `offline/` で実行します。

   ```bash
   python make_video_v4.py
   ```

   735×539 の奇数サイズを右端・下端の1px複製で 736×540 にそろえ、H.264（yuv420p, crf 18, 24fps）でエンコードします。
5. **ループ MP4 ができる。** `offline/out/prod/loop8s-736x540.mp4` が成果物です。8秒・192フレームで、最初と最後が連続するのでそのままループ再生できます。

### (d) サンプル動画の条件

リポジトリに置いてある8秒ループ動画は、次の条件で生成したものです。

| 項目 | 値 |
| --- | --- |
| 入力写真 | `samples/moth-on-bark.jpg`（ガの止まった樹皮） |
| プリセット | プリセット1（`blender/recipe-1.json` / 緑の川の浅瀬・午前） |
| 乱数シード | 固定（`run_prod_v4.py` の `SEED_V2`。同一環境なら毎回同じ結果） |
| フレームレート | 24fps |
| フレーム数 | 192（8秒ループ） |
| 出力解像度 | 736×540 |
| マスター解像度 | 2048² |

同じ写真・同じプリセット・同じシード・同じバージョンの numpy/scipy であれば、同じ動画が再現できます。
